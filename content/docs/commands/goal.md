## `/goal`이 뭔가요?

> 🍱 **비유로 설명하면**: "설거지 다 끝날 때까지 계속 해"라고 했더니, 내가 하나하나 "이제 그릇 씻어", "이제 냄비 씻어" 시키지 않아도 알아서 끝날 때까지 하는 것과 같아요.

`/goal` 뒤에 **완료 조건**을 적으면, Claude가 그 조건이 충족될 때까지 자동으로 여러 번 작업을 이어서 합니다.

```
/goal 테스트 전부 통과하고 lint 에러가 0개가 될 때까지
```

설정하자마자 Claude가 바로 작업을 시작하고, 매번 턴이 끝날 때 "아직 조건 안 됐으니까 계속"을 판단합니다.

---

## 어떤 상황에 좋을까요?

✅ **이럴 때 효과가 커요:**

- 🧪 "테스트가 전부 통과할 때까지 버그 고쳐줘"
- 📋 "구현 목록에 있는 항목이 모두 체크될 때까지 작업해줘"
- 📁 "파일 크기가 전부 500줄 이하가 될 때까지 쪼개줘"
- 📬 "이슈 큐(queue)가 빌 때까지 하나씩 해결해줘"

❌ **이럴 때는 비추:**

- 조건이 명확하지 않은 것 ("좋아질 때까지 고쳐줘" → 너무 막연해요)
- 끝이 없을 수 있는 것 (조건 없이 무한 반복)

## 기본 사용법

### 목표 설정하기

```
/goal [완료 조건]
```

예시들:

```
/goal npm test가 0개 실패로 통과할 때까지

/goal git status가 clean하고 npm run build가 성공할 때까지

/goal 미해결 이슈가 5개 미만이 될 때까지
```

목표를 설정하면 화면에 `◎ /goal 활성화` 표시가 나타나고, 조건이 충족될 때까지 자동으로 반복합니다.

### 현재 상태 확인

인수 없이 `/goal` 만 입력:

```
/goal
```

현재 목표, 진행된 턴 수, 소비된 토큰, 마지막 평가 결과를 보여줘요.

### 목표 취소

```
/goal clear
```

`stop`, `off`, `reset`, `cancel`도 같은 동작이에요.

## 효과적인 조건 작성 팁

> 🍱 **비유**: "집 정리해줘"보다 "거실 바닥에 물건이 없고 소파 쿠션이 정렬됐을 때"가 훨씬 명확하죠?

Claude가 실제로 확인할 수 있는 **측정 가능한 조건**을 쓰세요:

| 좋은 예 | 이유 |
|---------|------|
| `npm test가 exit 0으로 종료될 때까지` | 구체적인 명령어 결과 |
| `git status가 clean할 때까지` | 확인 가능한 상태 |
| `5개 파일 모두 100줄 미만이 될 때까지` | 숫자로 측정 가능 |
| `ESLint 경고 0개가 될 때까지` | 명확한 수치 |

| 애매한 예 | 문제 |
|-----------|------|
| "코드가 깨끗해질 때까지" | "깨끗함"이 뭔지 불명확 |
| "더 나아질 때까지" | 기준이 없음 |

**턴 제한 추가하기** (무한 반복 방지):

```
/goal 모든 테스트 통과 또는 20턴 후 중단
```

## `/loop`와 뭐가 다른가요?

| | `/goal` | `/loop` |
|--|--------|--------|
| 다음 턴이 시작되는 조건 | 이전 턴이 끝나면 바로 | 시간 간격마다 |
| 멈추는 조건 | 설정한 조건이 충족될 때 | 수동으로 또는 Claude 판단 |
| 주된 사용 | "완료 상태가 될 때까지" | "X분마다 점검해줘" |

예: "에러 없을 때까지 계속 고쳐" → `/goal`  
예: "30분마다 새 이슈 확인해줘" → `/loop 30m`

## 비대화형 모드에서 쓰기

터미널 스크립트에서도 사용 가능:

```bash
claude -p "/goal CHANGELOG.md에 이번 주 merge된 PR이 모두 기록될 때까지"
```

`Ctrl+C`로 중간에 멈출 수 있어요.

## 자주 묻는 질문

**Q: 조건 판단은 누가 해요?**  
A: Claude와 별개인 작은 AI(Haiku 클래스)가 매 턴마다 대화 내용을 보고 조건이 충족됐는지 판단해요. 판단 비용은 매우 작아요.

**Q: 세션을 재개하면 목표도 살아있나요?**  
A: 네! `--resume`으로 세션을 이어하면 활성 목표도 복원돼요. 단, 턴 카운터와 타이머는 리셋됩니다.

**Q: `/goal`과 오토 모드(auto mode) 함께 쓰면?**  
A: 이 둘은 잘 맞아요. 오토 모드는 도구 사용 허가를 자동 처리하고, `/goal`은 종료 시점을 자동 결정해요. 같이 쓰면 완전 자율 실행이 됩니다. ⚠️ 단, 오토 모드는 신중하게 사용하세요.
