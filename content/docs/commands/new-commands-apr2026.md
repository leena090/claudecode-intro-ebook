## 전체 13개 명령어 상세 설명

### `/powerup` — 내장 튜토리얼

```bash
/powerup
```

> 🍱 **비유로 설명하면**: 게임 첫 실행 시 뜨는 튜토리얼 같은 거예요. 하나씩 기능을 보여주면서 "이런 것도 돼요!" 안내해줍니다.

**이런 분께 추천:**
- "Claude Code 설치는 했는데 뭐부터 해야 할지 모르겠어요"
- 처음 쓰는 분, 또는 새 기능이 업데이트됐을 때

**사용 예시:**
```
/powerup 입력
→ 애니메이션 데모 시작
→ "와, 이런 기능이 있었어?"
```

<div class="note-circle">
○ v2.1.90(2026-04-01)에 새로 추가됐어요.
</div>

### `/recap` — 지금까지 작업 요약

```bash
/recap
```

> 🍱 **비유로 설명하면**: 드라마의 "지난 이야기" 코너예요. 처음 틀었을 때 "지금까지 이런 일이 있었습니다" 하고 정리해주는 것처럼, Claude가 지금까지 뭘 했는지 요약해줍니다.

**이런 분께 추천:**
- 오전에 작업하다가 오후에 돌아왔을 때
- 작업이 길어져서 "내가 어디까지 했지?" 헷갈릴 때

**사용 예시:**
```
/recap 입력
→ "지금까지 auth 모듈 수정, 테스트 3개 통과, 1개 실패 중"
```

<div class="note-circle">
○ v2.1.108에 추가됐어요.

### `/focus` — 마지막 답변만 크게 보기

```bash
/focus
```

> 🍱 **비유로 설명하면**: 프레젠테이션 전체화면 버튼이에요. 이전 슬라이드 다 숨기고 지금 슬라이드만 화면 꽉 채워서 보여주는 것처럼, 마지막 답변만 딱 보여줍니다.

**이런 분께 추천:**
- 대화가 너무 길어져서 마지막 답변이 어디 있는지 모를 때
- 화면이 복잡해서 눈이 피로할 때

**사용 예시:**
```
/focus 입력
→ 마지막 답변만 크게 화면 가득 표시
→ 다시 /focus 입력하면 원래 화면 복귀
```

<div class="note-circle">
○ v2.1.110에 추가됐어요.
</div>

### `/tui` — 화면 렌더링 전환

```bash
/tui
```

> 🍱 **비유로 설명하면**: 구형 TV에서 신형 TV로 바꾸는 것처럼요. 화면이 깜빡거리거나 글자가 어지러울 때 부드러운 렌더링 방식으로 전환해줍니다.

**이런 분께 추천:**
- 화면 표시가 어딘가 이상하게 보일 때
- 터미널 환경에서 글자 깨짐이 있을 때

**사용 예시:**
```
/tui 입력
→ 화면 렌더링이 부드럽게 전환됨
```

<div class="note-circle">
○ v2.1.110에 추가됐어요.

### `/loop 시간 명령` — 반복 자동 실행

```bash
/loop 5m 빌드 상태 확인해줘
/loop 10m 에러 로그 체크
```

> 🍱 **비유로 설명하면**: 알람 시계예요. "5분마다 빌드 됐나 확인해줘" 설정해두면 알아서 체크해줍니다. 직접 보고 있을 필요 없어요.

**이런 분께 추천:**
- 오래 걸리는 작업을 기다리는 동안 다른 일 하고 싶을 때
- 주기적으로 상태를 체크해야 할 때

**사용 예시:**
```
/loop 5m 빌드 상태 확인해줘
→ 5분마다 자동으로 빌드 상태 체크 후 보고
```

기본 간격은 10분이에요. 숫자+m으로 변경 가능합니다.

<div class="note-circle">
○ v2.1.71에 추가됐어요.
</div>

### `/effort low|medium|high` — 작업 깊이 조절

```bash
/effort low
/effort medium
/effort high
```

> 🍱 **비유로 설명하면**: 택시 기본요금 vs 모범택시예요. 간단한 거 물어볼 땐 `low`로 빠르게, 중요한 코드 짤 땐 `high`로 꼼꼼하게.

| 레벨 | 특징 | 언제 쓰나요? |
|------|------|-------------|
| `low` | 빠르고 간결 | 간단한 질문, 짧은 수정 |
| `medium` | 기본값 | 일반적인 작업 대부분 |
| `high` | 깊고 꼼꼼 | 결제 시스템, 보안 코드 등 중요한 작업 |

**사용 예시:**
```
/effort high
→ "이건 결제 기능이니까 아주 꼼꼼하게 만들어줘"

/effort low
→ "이 단어 영어로 뭐야?" 같은 간단한 질문
```

<div class="note-star">
★ v2.1.94(2026-04-07)부터 기본값이 <code>high</code>로 올라갔어요. 예전엔 <code>medium</code>이었지만 이제 기본이 <code>high</code>입니다.
</div>

<div class="note-circle">
○ v2.1.76에 추가됐어요.

### `/plugin` — 기능 확장팩 관리

```bash
/plugin
/plugin install 이름@마켓플레이스
```

> 🍱 **비유로 설명하면**: 앱스토어예요. Claude Code에 추가 기능을 검색하고 설치하고 삭제할 수 있어요.

**4가지 탭:**
| 탭 | 설명 |
|----|------|
| Discover | 설치 가능한 플러그인 검색 |
| Installed | 현재 설치된 플러그인 목록 |
| Marketplaces | 연결된 마켓플레이스 |
| Errors | 오류 있는 플러그인 확인 |

**사용 예시:**
```
/plugin 입력
→ 탭 화면 표시
→ Discover에서 원하는 기능 찾기
→ /plugin install 이름@마켓플레이스 로 설치
```

<div class="note-circle">
○ v2.1.84 이상에서 사용 가능해요.
</div>
