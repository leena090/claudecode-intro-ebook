## Claude 5.5 시리즈가 뭔가요?

2026년 9~10월, Anthropic이 **Claude 5.5 시리즈** 세 모델을 차례로 발표했어요.

> 🏎️ **비유로 설명하면**: 자동차 회사가 같은 라인업에서 럭셔리(Opus)·일반(Sonnet)·경차(Haiku)를 업그레이드한 것처럼, Claude 5 라인업이 통째로 한 단계 올라간 거예요.

---

## 세 모델 한눈에 비교

| 모델 | 출시일 | 특징 | 이전 대비 |
|------|--------|------|-----------|
| **Opus 5.5** | 2026-09-22 | 에이전틱 코딩·지식 작업 최고 성능 | 비용 **40% 감소** |
| **Sonnet 5.5** | 2026-09-28 | 속도·비용 균형, 일상 개발 최적 | **30% 빠르고** 비용 **최대 30% 저렴** |
| **Haiku 5.5** | 2026-10-07 | 고속 소형 모델, 대량 작업 특화 | 서브에이전트·요약에 최적 |

---

## Opus 5.5 — "코딩 에이전트의 정상"

### 무엇이 달라졌나요?

- 에이전틱 코딩(Claude Code)과 지식 업무에서 **역대 최고 성능**
- **Opus 5 대비 운영 비용 40% 감소** — 같은 돈으로 더 많이 쓸 수 있어요

> 💡 **쉽게 말하면**: Opus 5가 최고 등급 주방장이었다면, Opus 5.5는 같은 실력에 재료비가 40% 싸진 셈이에요.

### Claude Code에서는?

Claude Code의 **Fast Mode**(빠른 모드)가 이제 **Opus 5.5** 기반으로 업그레이드됐어요.
- 요금: **$8/$40 per million tokens** (입력/출력) — 이전 Opus 4.8 기반 $30/$150에서 대폭 인하!
- 소비 기반 플랜(API)에서 사용 가능

---

## Sonnet 5.5 — "일상 개발자의 주력 모델"

### 무엇이 달라졌나요?

- **Sonnet 5 대비 명확한 성능 향상**
- 속도 **30% 이상 빠름**
- 대부분의 작업에서 비용 **최대 30% 저렴**

> 🚗 **비유**: Sonnet 5가 준중형차였다면, Sonnet 5.5는 같은 연비에 더 빠른 업그레이드 모델이에요.

### 언제 쓰면 좋아요?

- 매일 하는 코드 작성·리뷰·설명
- PR 요약, 이슈 분석
- 빠른 답변이 필요한 일반 개발 작업

---

## Haiku 5.5 — "대량 작업의 숨은 강자"

### 무엇이 달라졌나요?

- **가장 빠르고, 가장 저렴한 소형 모델**
- **서브에이전트·요약·브라우저 사용** 같은 고볼륨 작업에 최적화

> 🏍️ **비유**: 오토바이처럼 작고 빠르지만, 좁은 골목길(반복 작업)에서는 트럭(Opus)보다 훨씬 효율적이에요.

### Claude Code에서 서브에이전트로 쓰기

```bash
# 여러 파일을 동시에 요약할 때 Haiku로 서브에이전트 실행
# 빠르고 저렴하게 대량 처리 가능
```

서브에이전트(여러 Claude가 동시에 일하는 방식)를 쓸 때 **Haiku 5.5로 비용을 대폭 줄일 수 있어요**.

## 정리: 어떤 모델을 써야 할까요?

| 상황 | 추천 모델 |
|------|-----------|
| 복잡한 코드 리팩토링·아키텍처 설계 | **Opus 5.5** |
| 일상적인 버그 수정·기능 추가 | **Sonnet 5.5** (기본값) |
| 대량 파일 요약·반복 처리 | **Haiku 5.5** |
| 빠른 응답이 최우선 | **Sonnet 5.5** or **Fast Mode** |
