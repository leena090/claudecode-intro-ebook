## 한눈에 보는 5.5 모델 비교표

> 🍳 **비유**: Sonnet 5.5는 "빠른 주방장(업그레이드)", Haiku 5.5는 "알바생(빠르고 저렴)", Opus 5.5는 "총주방장(가장 뛰어남)"이에요.

| 모델 | 별명 | 가장 잘 하는 것 | 속도 | 비용 | 출시일 |
|---|---|---|---|---|---|
| **Claude Sonnet 5.5** | 올라운더 | 코딩·에이전트·일반 업무 | Sonnet 5 대비 30%↑ | Sonnet 5 대비 30%↓ | 2026-09-28 |
| **Claude Haiku 5.5** | 초고속 경량 | 요약·서브에이전트·브라우저 사용 | 가장 빠름 | 가장 저렴 | 2026-10-07 |
| **Claude Opus 5.5** | 최고 성능 | 에이전트 코딩·복잡한 지식 업무 | 약간 느림 | Opus 5 대비 40%↓ | 2026-09-22 |

## Sonnet 5.5 — "30% 빠르고 30% 저렴해진 올라운더"

### 뭐가 달라졌나요?
- **Sonnet 5 대비 30% 이상 빠른 응답** — 코드 한 줄 고치는 것부터 긴 리팩토링까지 체감 속도가 올라요
- **비용도 30% 절감** — 많이 쓸수록 절약 효과가 커요
- **정확도 유지** — 속도를 올렸지만 답변 품질은 Sonnet 5보다 더 좋아요 (공식 발표 기준)

### Claude Code에서 적용하기

```bash
# /config에서 모델 설정
/config
# → Model 항목에서 claude-sonnet-5-5 선택

# 또는 환경변수
export CLAUDE_MODEL=claude-sonnet-5-5
```

## Haiku 5.5 — "서브에이전트용 고속 경량 모델"

### 뭐가 달라졌나요?
- **고성능 빠른 작업에 최적화** — 요약·분류·브라우저 조작처럼 단순하지만 반복적인 작업에 딱이에요
- **서브에이전트(subagent) 비용 절감** — 대형 워크플로에서 여러 에이전트를 돌릴 때 Haiku 5.5를 쓰면 전체 비용을 크게 낮출 수 있어요
- **동시 처리량 증가** — 빠른 응답 덕분에 동시에 더 많은 요청을 처리할 수 있어요

> 🏎️ **비유**: Haiku 5.5는 고속도로 주행 차선의 경차예요. 짐은 적지만 속도가 빠르고 연료비가 적게 들어요. 무거운 짐을 옮길 때는 Opus 5.5(트럭)를 써야 해요.

### 언제 써야 할까요?

| ✅ Haiku 5.5 추천 | ❌ Haiku 5.5 부적합 |
|---|---|
| 로그 파일 요약 | 복잡한 아키텍처 설계 |
| URL 목록에서 정보 추출 | 긴 코드 리팩토링 |
| 반복적인 파일 분류 | 미묘한 버그 추적 |
| 브라우저 자동화 반복 작업 | 멀티 파일 종속 분석 |

## Opus 5.5 — "에이전트 코딩 최강자, Opus 5보다 40% 저렴"

### 뭐가 달라졌나요?
- **에이전트 코딩·지식 업무 1등** — 복잡한 멀티 에이전트 코딩, 긴 맥락 분석에서 최고 성능
- **Opus 5 대비 40% 비용 절감** — 최고 성능 모델이 훨씬 더 쓰기 쉬워졌어요
- **Fast Mode 지원** — Opus 5.5를 대상으로 한 초고속 모드 (가격: **$8/$40 per million tokens**, 추정 — 공식 발표 기준)

### Fast Mode와 함께 쓰기

```bash
# Fast mode는 /fast 명령어로 토글
/fast
# → Fast 모드 ON: Opus 5.5 고속 버전 활성화

# 또는 UI에서 번개 아이콘 클릭
```

> ⚡ **Fast Mode 비용**: 리서치 프리뷰 기준 **$8/$40 per million tokens** (입력/출력). 소비 기반 플랜(consumption plan)에서 사용 가능. 구독 플랜은 사용 크레딧 차감. `[공]`
