## 뭐가 바뀌었나요?

Claude Code 공식 문서 주소가 바뀌었습니다.

| 구분 | 주소 |
|------|------|
| 기존 (구) | `docs.anthropic.com/en/docs/claude-code/...` |
| 현재 (신) | `code.claude.com/docs/en/...` |

기존 주소로 접속하면 새 주소로 자동으로 이동합니다. 하지만 **북마크 해두신 분들은 새 주소로 갱신해두세요.** 언젠가 자동 이동이 없어질 수 있어요.

---

## 주요 페이지 새 주소

자주 찾는 페이지들의 새 주소입니다.

| 페이지 | 새 주소 |
|--------|--------|
| 전체 개요 | `code.claude.com/docs/en/overview` |
| 변경 로그 | `code.claude.com/docs/en/changelog` |
| CLI 레퍼런스 | `code.claude.com/docs/en/cli-reference` |
| 설정 | `code.claude.com/docs/en/settings` |
| MCP | `code.claude.com/docs/en/mcp` |
| 메모리 | `code.claude.com/docs/en/memory` |
| 문제 해결 | `code.claude.com/docs/en/troubleshooting` |

## 전체 문서 목차 (LLM용)

모든 문서 페이지 목록을 한 파일로 볼 수 있어요.

```
code.claude.com/docs/llms.txt
```

AI 도구나 스크립트에서 문서 전체 구조를 파악할 때 유용합니다.

---

## 왜 이사했나요?

> 🍱 **비유로 설명하면**: 작은 방에서 살다가 큰 집으로 이사한 거예요. 가족(Anthropic 전체)이 쓰던 큰 집에서 독립해서 Claude Code만의 집을 마련한 것입니다. 살림(내용)은 그대로지만 주소(URL)가 바뀐 거예요.

Claude Code가 Anthropic의 여러 제품 중 하나가 아니라, **독립적인 개발 도구**로 성장했기 때문이에요. 전용 사이트를 가질 만큼 커진 거죠.

<div class="note-circle">
○ 이전 시기: 2026년 4월 초. docs.anthropic.com의 Claude Code 섹션은 그대로 유지되지만, 새 내용은 code.claude.com에서 먼저 업데이트됩니다.
</div>

## 빠른 체크리스트

- 기존 북마크를 새 주소로 업데이트했나요?
- 팀 위키나 공유 문서에 구 주소가 있다면 교체하세요
- VS Code Extension이나 JetBrains 플러그인의 도움말 링크도 새 주소를 확인하세요
