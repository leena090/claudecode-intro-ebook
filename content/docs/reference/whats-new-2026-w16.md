## 1. 🧠 Claude Opus 4.7 — 새 사고 레벨 `xhigh`

### `xhigh`가 뭔가요?

기존에 `/effort` 명령어로 **low / medium / high** 3단계로 사고 깊이를 조절할 수 있었는데, 이번에 **`xhigh`(극강 집중)** 레벨이 추가됐어요.

> 🍱 **비유로 설명하면**: 음식 온도 조절기가 "약불 / 중불 / 강불"이었는데, 이번에 **"최강 화력"** 단계가 생긴 거예요. 웬만한 건 강불로 충분하지만, 아주 복잡한 설계 결정엔 최강 화력이 필요할 수 있어요.

```bash
/effort xhigh     # Opus 4.7 전용 — 최대 사고 깊이
/effort high      # 일반 꼼꼼 모드 (대부분 이걸로 충분해요)
/effort medium    # 보통
/effort low       # 빠르게
```

| 레벨 | 특징 | 언제 쓰나요? |
|---|---|---|
| `low` | 빠름, 토큰 적게 | 단순 조회·오타 수정 |
| `medium` | 균형 | 일반 코딩 작업 |
| `high` | 꼼꼼 (기본값) | 버그 추적, 리팩터링 |
| **`xhigh`** ⭐ | 최대 집중 | 대형 아키텍처 결정, 복잡한 알고리즘 |

<div class="note-star">
★ <strong>주의</strong> — <code>xhigh</code>는 <strong>Opus 4.7 전용</strong>이에요. Sonnet 4.6에서 쓰면 적용 안 됩니다.
<br />★ 사고에도 토큰이 소모되니, 꼭 필요할 때만 쓰세요. <code>[공식]</code>
</div>

## 2. ☁️ /ultrareview — 클라우드 멀티 에이전트 코드 리뷰

### 뭔가요?

`/ultrareview`는 **클라우드에서 여러 AI 에이전트가 동시에 내 코드를 다각도로 검토**해주는 명령어예요. 이번 Week 16에서 정식 출시됐어요.

> 🍱 **비유로 설명하면**: 내 코드를 친구 한 명한테 보여주는 게 아니라, **경험 많은 개발자 10명한테 동시에 검토받는 것**과 같아요. 한 명이 놓친 버그를 다른 명이 잡아줘요.

```bash
# 현재 브랜치 전체 리뷰
/ultrareview

# 특정 PR 번호로 리뷰
/ultrareview 123
```

| 일반 코드 리뷰 | /ultrareview |
|---|---|
| 내가 직접 읽음 | AI 에이전트 여러 개 동시 분석 |
| 시간이 많이 걸림 | 클라우드에서 병렬 처리 |
| 놓치는 패턴 있음 | 보안·로직·성능 다각도 검토 |
| 무료 | Max/Pro 플랜에서 사용 가능 |

<div class="note-star">
★ git 저장소 안에 있어야 작동해요.
<br />★ 결과는 PR에 댓글 형태로 달리거나 터미널에 출력돼요. <code>[공식]</code>
</div>

## 3. 🌐 웹에서도 Routines(루틴) 사용 가능

### 루틴이 뭔가요?

루틴(Routines)은 **반복 작업을 미리 설정해 두고 자동으로 실행**되게 하는 기능이에요. 이전까지는 터미널에서만 됐는데, 이제 **Claude Code on the web(웹 브라우저)**에서도 루틴을 만들고 실행할 수 있어요.

> 🍱 **비유로 설명하면**: 세탁기 예약 기능이 드럼세탁기에만 있었는데, 이제 일반 세탁기에도 생긴 거예요.

```yaml
# 루틴 예시: 매일 오전 9시에 PR 리뷰 실행
name: "daily-pr-check"
schedule: "0 9 * * *"
task: "열린 PR 목록 확인하고 오래된 것 알림"
```

## 4. 📊 /usage — "어디서 한도를 이렇게 많이 써?"

### 뭔가요?

Claude Code를 쓰다 보면 "왜 이렇게 한도가 빨리 찼지?" 궁금할 때가 있어요. 이제 `/usage`를 치면 **어떤 작업이 토큰을 얼마나 썼는지 한눈에 볼 수 있어요**.

```bash
/usage     # 현재 세션의 토큰 사용량 분석 표시
```

출력 예시:

| 항목 | 소모 토큰 |
|---|---|
| 파일 읽기 (Read) | 12,450 |
| 클로드 응답 | 8,320 |
| 사고 (Thinking) | 5,100 |
| MCP 도구 결과 | 3,800 |
| **합계** | **29,670** |

> 🍱 **비유로 설명하면**: 전기 사용량 고지서가 "전기세 5만원"이라고만 나왔는데, 이제 "에어컨 2만원, 냉장고 1만원, TV 8천원..." 식으로 항목별로 나오는 거예요.

## 5. ⚡ 네이티브 바이너리 전환

### 뭔가요?

Claude Code CLI가 내부적으로 JavaScript 번들 방식에서 **각 운영체제(OS)에 맞는 네이티브 바이너리(native binaries)**로 바뀌었어요.

사용자 입장에서 명령어나 사용법은 달라진 게 없지만:
- ✅ **실행 속도 향상** — 명령어 입력 후 반응이 더 빨라졌어요
- ✅ **메모리 사용량 감소**
- ✅ **설치 크기 축소**

> 🍱 **비유로 설명하면**: 같은 자동차인데, 엔진을 수입 부품 조립식에서 국산 최적화 엔진으로 바꾼 거예요. 핸들이나 페달은 똑같지만 가속이 더 부드러워진 것과 같아요.
