## 가나다 순 용어 목록

---

### 🔄 에이전틱 루프 (Agentic Loop)

**"클로드가 스스로 생각하고 → 도구를 쓰고 → 결과를 보고 → 다음 단계를 정하는 반복 사이클"**

일반 AI 챗봇은 질문 하나에 답 하나를 줘요. 하지만 Claude Code는 다릅니다.

1. 내 요청을 받는다
2. 어떤 도구(파일 읽기, 코드 실행 등)를 써야 할지 스스로 판단
3. 도구를 쓴다
4. 결과를 보고 다음 단계를 결정
5. 완료될 때까지 2~4를 반복

> 🍱 **비유**: 심부름꾼 친구한테 "마트에서 저녁 재료 사와"라고 했을 때, 그 친구가 마트 가서 → 재료 확인하고 → 없으면 대체품 찾고 → 계산하고 → 돌아오는 과정 전체가 "에이전틱 루프"예요.

---

### 📁 CLAUDE.md

**"클로드한테 '이 프로젝트는 이렇게 해줘'라고 미리 써두는 안내문"**

프로젝트 폴더에 `CLAUDE.md` 파일을 만들어 두면, 클로드가 매번 물어보지 않아도 그 내용을 기억하고 따라요.

```markdown
# CLAUDE.md 예시
- 한국어로만 답해줘
- 커밋 메시지는 영어로
- 테스트 파일은 __tests__ 폴더에 넣어줘
- import는 상대경로 말고 절대경로 써줘
```

> 🍱 **비유**: 새로 온 팀원한테 "우리 팀 규칙이에요"라고 건네는 **온보딩 문서**예요. 한 번 써두면 매번 설명 안 해도 돼요.

- **위치**: 프로젝트 루트 또는 `~/.claude/CLAUDE.md` (전체 글로벌 설정)
- **자동 로드**: 클로드 시작 시 자동으로 읽어요

---

### 🗜️ 컴팩션 (Compaction)

**"대화가 길어지면 클로드가 오래된 내용을 요약해서 압축하는 것"**

클로드는 한 번에 볼 수 있는 글자 수(컨텍스트 윈도우)에 한계가 있어요. 대화가 아주 길어지면, 오래된 메시지들을 **자동으로 요약·압축**해서 빈 공간을 확보해요.

> 🍱 **비유**: 업무 노트가 꽉 찼을 때, 오래된 기록을 "4월 1주차: A안 완료, B안 보류" 식으로 요약해서 뒷장으로 옮기는 것과 같아요.

<div class="note-star">
★ 컴팩션 중에는 아주 오래전 맥락은 잊을 수 있어요.
<br />★ <code>/compact</code> 명령으로 수동으로도 할 수 있어요. <code>[공식]</code>
</div>

---

### 🖥️ 컨텍스트 윈도우 (Context Window)

**"클로드가 한 번에 볼 수 있는 글자/코드의 양"**

클로드는 무한정 대화를 기억할 수 없어요. 한 번에 처리할 수 있는 글자 수가 정해져 있는데 이걸 **컨텍스트 윈도우**라고 해요.

> 🍱 **비유**: 책상 위에 놓을 수 있는 서류 양이에요. 책상이 넓을수록 더 많은 서류를 동시에 보면서 일할 수 있어요.

| 항목 | 규모 감 |
|---|---|
| 컨텍스트 윈도우 크기 | 수십만~수백만 글자 (모델마다 다름) |
| 코드 파일 1개 | 보통 수천~수만 글자 |
| 대규모 프로젝트 | 컨텍스트 넘어갈 수 있어서 압축(컴팩션) 필요 |

---

### 🪝 훅 (Hooks)

**"클로드가 특정 행동을 할 때마다 내가 만든 스크립트를 자동 실행하는 것"**

클로드가 파일을 수정하기 전, 작업을 마친 후 등 **특정 시점에 자동으로 실행할 명령어**를 미리 설정해 두는 기능이에요.

```json
// settings.json 예시
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Write|Edit",
      "hooks": [{"type": "command", "command": "prettier --write $FILE"}]
    }]
  }
}
```

위 설정은 "클로드가 파일을 수정할 때마다 자동으로 코드 정렬(prettier)을 실행해"라는 뜻이에요.

> 🍱 **비유**: 외출할 때마다 자동으로 현관 불이 켜지는 것처럼, 특정 상황이 생기면 **자동으로 내가 정한 행동이 실행**되는 거예요.

---

### 🔌 MCP (Model Context Protocol)

**"클로드와 외부 도구들 사이의 공통 연결 규격"**

Claude Code가 GitHub, Slack, 데이터베이스 같은 외부 서비스와 대화하려면 일종의 "어댑터"가 필요해요. MCP는 바로 그 어댑터의 표준 규격이에요.

> 🍱 **비유**: 전 세계 전기 콘센트 모양이 나라마다 달라서 어댑터가 필요하잖아요? MCP는 클로드와 모든 외부 서비스 사이에 끼우는 **만능 어댑터 규격**이에요.

```json
// MCP 서버 설정 예시 (settings.json)
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"]
    }
  }
}
```

### 🤖 서브에이전트 (Subagents)

**"큰 작업을 쪼개서 각 부분을 전담하는 전문 AI"**

Claude Code 안에서 특정 역할만 담당하는 **서브에이전트**를 만들 수 있어요. 예를 들어 "코드 리뷰 전담", "테스트 작성 전담" 등이요.

> 🍱 **비유**: 큰 프로젝트를 혼자 하는 게 아니라, 디자인 담당·개발 담당·QA 담당처럼 **역할별로 팀원을 나눠** 병렬로 일하는 거예요.

| 서브에이전트 | 담당 |
|---|---|
| Explore | 코드 탐색·검색 전문 |
| Plan | 설계 계획 수립 전문 |
| 커스텀 서브에이전트 | 내가 직접 만들 수 있음 |

---

### 🛠️ 스킬 (Skills)

**"클로드에게 새로운 특기를 추가하는 패키지"**

스킬은 Claude Code에 새로운 `/명령어`나 능력을 추가하는 **확장 기능 묶음**이에요. 예를 들어 `/ultrareview`, `/ultraplan`, `/loop` 같은 명령어들이 스킬 형태로 되어 있어요.

> 🍱 **비유**: 스마트폰 기본 앱 외에 추가로 앱을 설치하는 것처럼, 클로드의 기본 기능에 **새로운 기능 앱을 설치**하는 거예요.

```bash
# 스킬 목록 보기
/skills

# 특정 스킬 실행
/ultrareview
/loop 5m /check-prs
```

### 🔑 권한 모드 (Permission Modes)

**"클로드가 내 컴퓨터에서 얼마나 자유롭게 행동할 수 있는지 수준"**

클로드가 파일을 읽거나, 수정하거나, 명령어를 실행할 때 **매번 허락을 받을지, 자동으로 할지** 설정하는 거예요.

| 모드 | 의미 | 언제 쓰나요? |
|---|---|---|
| 기본 (Default) | 파일 수정·명령어 실행 시 허락 요청 | 일반적인 사용 |
| Auto | 신뢰된 작업은 자동 허가 | 자동화·CI/CD |
| 수동 (Manual) | 모든 행동에 허락 요청 | 중요한 프로덕션 작업 |

> 🍱 **비유**: 집에 청소 아주머니를 부를 때, "모든 서랍 알아서 정리해도 돼요"(auto) vs "정리 전에 물어봐 주세요"(default) vs "제가 같이 있을게요"(manual)의 차이예요.

단축키: `Shift+Tab`으로 순서대로 모드를 바꿀 수 있어요.

---

### 🔁 루틴 (Routines)

**"스케줄이나 이벤트에 맞춰 클로드가 자동으로 실행하는 작업"**

루틴을 설정해두면 클로드가 **정해진 시간에, 또는 특정 이벤트 발생 시** 자동으로 작업을 수행해요.

> 🍱 **비유**: 매일 아침 6시에 자동으로 커피를 끓여주는 **커피 메이커 예약 기능**이에요.

```yaml
# 루틴 예시
- 매일 오전 9시: PR 목록 확인 및 요약
- 새 이슈 생성 시: 자동 분류 및 담당자 지정
- API 호출 시: 지정 작업 실행
```

---

### 📜 헤드리스 모드 (Headless Mode)

**"터미널 UI 없이 클로드를 자동으로 프로그램처럼 실행하는 방법"**

보통 Claude Code는 터미널에서 대화하며 써요. 헤드리스 모드는 **사람이 직접 채팅하지 않고**, 파이썬·타입스크립트 스크립트에서 클로드를 호출하는 방식이에요.

> 🍱 **비유**: 카카오톡을 직접 열어서 대화하는 게 일반 모드라면, 카카오 API로 자동 메시지를 보내는 게 **헤드리스 모드**예요.

```python
# Python Agent SDK 예시
from claude_code_sdk import query

result = await query(
    prompt="이 코드의 버그를 찾아줘",
    options={"cwd": "/my/project"}
)
```

---

### 🔧 채널 (Channels)

**"외부에서 클로드 세션 안으로 메시지·이벤트를 밀어 넣는 통로"**

CI/CD 결과, 모니터링 알림, Slack 메시지 같은 **외부 이벤트를 실시간으로 클로드에게 전달**하는 기능이에요.

> 🍱 **비유**: 클로드가 사무실 안에서 일하고 있는데, 외부에서 오는 택배·우편·전화를 **내부로 전달해 주는 수신함**이에요.
