## 1. 🔍 /ultrareview — 리서치 프리뷰로 더 많이 공개

### 뭐가 달라진 건가요?

Week 16에서 정식 출시됐던 `/ultrareview`가 이번 주에 **리서치 프리뷰(research preview)**로 전환돼, **더 많은 사용자에게 열렸어요**.

> 🍱 **비유로 설명하면**: 지난 주에 신제품이 VIP 멤버들한테만 출시됐는데, 이번엔 **일반 대기 명단에 있는 분들한테도 이용권이 배포된** 거예요.

| 구분 | 설명 |
|---|---|
| **리서치 프리뷰 (Research Preview)** | 정식 출시 전 테스트 단계. 기능이 완성됐지만 피드백 수집 중 |
| **대상** | Pro, Max 플랜 가입자 |
| **사용법** | 변동 없음: `/ultrareview` 또는 `/ultrareview <PR번호>` |

<div class="note-star">
★ 리서치 프리뷰 기간엔 기능이 바뀌거나 제한될 수 있어요.
<br />★ git 저장소 안에서만 실행 가능합니다. <code>[공식]</code>

## 2. 📋 자동 세션 요약 — "어디까지 했더라?" 해결

### 뭔가요?

Claude Code 터미널 세션에서 한동안 자리를 비웠다가 돌아왔을 때, 클로드가 **"지금까지 이런 작업을 했어요"라고 자동으로 요약해 줘요**.

> 🍱 **비유로 설명하면**: 오후에 잠깐 나갔다가 회사로 돌아왔더니, 팀 비서가 "오전에 A회의 완료, B안건 보류, C는 내일 처리 예정이에요"라고 브리핑해 주는 것과 같아요.

이전 상황:
```
[자리 비움: 2시간]
터미널 복귀

(내가 직접 기억해야 함: "아... 뭐 하다가 나갔더라?")
```

지금(Week 17부터):
```
[자리 비움: 2시간]
터미널 복귀

Claude: 📋 세션 요약
- user-auth 브랜치에서 JWT 토큰 만료 버그 수정 중
- auth/token.ts 파일 수정 완료, 테스트 2개 남음
- 마지막으로 멈춘 지점: validateToken() 함수 리팩터링
계속할까요?
```

### 어떻게 작동하나요?

- 세션이 일정 시간 비활성 상태가 되면, 클로드가 **현재 작업 맥락을 자동으로 요약**해 저장해요.
- 터미널로 돌아오면 자동으로 그 요약이 표시돼요.
- 별도 설정 없이 자동 적용됩니다. `[공식]`

## 3. 🎨 플러그인 컬러 테마 — 나만의 색깔 입히기

### 뭔가요?

이제 플러그인(Plugin)에 **커스텀 컬러 테마**를 만들어서 배포할 수 있어요. 내가 좋아하는 색 조합으로 Claude Code의 터미널 UI 색깔을 바꿀 수 있고, 그걸 팀원들과 나눠 쓸 수 있어요.

> 🍱 **비유로 설명하면**: 스마트폰 테마처럼, Claude Code 터미널도 "다크 그린 테마", "파스텔 테마", "회사 브랜드 컬러 테마" 등으로 꾸밀 수 있게 된 거예요.

```json
// 플러그인의 theme.json 예시
{
  "name": "my-dark-green",
  "colors": {
    "background": "#0d1117",
    "foreground": "#c9d1d9",
    "accent": "#3fb950",
    "error": "#f85149",
    "warning": "#d29922"
  }
}
```

| 항목 | 내용 |
|---|---|
| **만드는 법** | 플러그인 안에 `theme.json` 파일 추가 |
| **배포하는 법** | 플러그인 마켓플레이스에 올리거나 팀 내 공유 |
| **적용하는 법** | 플러그인 설치 후 자동 적용 |

## 4. 🖥️ Claude Code on the web 전면 재설계

### 뭔가요?

웹 브라우저에서 사용하는 Claude Code(code.claude.com 또는 claude.ai/code)의 **UI(화면 구성)가 전면 새롭게 바뀌었어요**.

> 🍱 **비유로 설명하면**: 오래 쓰던 문구점이 리모델링해서 훨씬 넓고 쾌적해진 것과 같아요. 파는 제품(기능)은 같지만, 매장 레이아웃이 훨씬 보기 좋아진 거예요.

주요 변경 사항:
- ✅ **더 직관적인 레이아웃** — 현재 작업 상태, 파일 변경 내역, 채팅 창이 한 화면에 잘 정리됨
- ✅ **파일 탐색 개선** — 왼쪽 사이드바에서 프로젝트 파일 쉽게 탐색
- ✅ **모바일 최적화** — 폰에서 보기 더 편해짐
- ✅ **PR 워크플로우 간소화** — "작업 완료 → PR 생성 → 검토" 흐름이 한 페이지 안에서 처리

★ 기존 작업 내역, 설정, 저장소 연결 등은 그대로 유지돼요.
<br />★ 2026-04-20부터 순차 적용됩니다. <code>[공식]</code>
