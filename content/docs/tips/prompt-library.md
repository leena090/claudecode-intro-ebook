## 프롬프트 라이브러리가 뭔가요?

처음 Claude Code를 열면 "뭐라고 말을 걸어야 하지?" 막막할 때가 있죠. **프롬프트 라이브러리(Prompt Library)**는 Anthropic이 직접 만든 **검증된 시작 문장 모음집**이에요.

> 🍱 **비유**: 요리책의 레시피처럼 — 처음부터 직접 레시피를 개발하지 않아도, 검증된 레시피를 그대로 따라하면 실패 없이 맛있는 요리가 나오는 것처럼요.

**특징:**
- 역할(개발자, 팀장, 초보자 등)별 분류
- 작업 유형(코드 리뷰, 리팩토링, 설명 등)별 분류
- 그대로 복붙 가능, 필요하면 조금씩 수정

---

## 자주 쓰이는 프롬프트 패턴

### 🔍 코드 이해하기

```
이 코드베이스를 처음 봐. 전체 구조를 설명해줘:
- 이 프로젝트가 무엇을 하는 소프트웨어인지
- 주요 폴더와 파일 역할
- 데이터가 어떻게 흐르는지 (입력→처리→출력)
```

> 💡 새 프로젝트를 맡았을 때 처음 30초에 쓰기 좋아요.

---

### 🐛 버그 잡기

```
이 에러가 발생하고 있어:
[에러 메시지 붙여넣기]

에러의 근본 원인을 찾아줘. 단순히 에러 메시지를 없애는 게 아니라, 왜 발생하는지부터 설명해줘.
```

---

### ✏️ 코드 리팩토링

```
이 코드를 리팩토링해줘. 단,
- 기존 동작은 100% 유지해야 해
- 더 읽기 쉽게만 바꿔
- 한 번에 다 바꾸지 말고, 가장 중요한 부분부터 설명하면서 진행해줘
```

---

### 📝 코드 리뷰 받기

```
이 코드를 리뷰해줘:
1. 버그 가능성이 있는 부분
2. 성능 문제가 생길 수 있는 곳
3. 보안상 위험한 패턴
4. 더 간결하게 쓸 수 있는 부분

각 항목마다 구체적인 예시 코드도 같이 써줘.
```

---

### 🧪 테스트 만들기

```
이 함수에 대한 테스트를 작성해줘:
- 정상 케이스 (happy path)
- 경계값 케이스 (빈 값, 최대값, 최소값)
- 에러 케이스 (잘못된 입력)

[테스트 프레임워크 이름] 형식으로 작성해줘.
```

---

### 📖 주석 달기

```
이 코드에 주석을 달아줘. 단,
- "이 줄은 ~를 한다" 식의 당연한 설명은 빼고
- "왜 이렇게 작성했는지 (이유)"만 주석으로 달아줘
- 한국어로
```

## 초보자를 위한 시작 프롬프트 5가지

처음 Claude Code를 쓴다면 이 5개 중 하나로 시작해보세요:

| 번호 | 상황 | 프롬프트 |
|------|------|----------|
| 1 | 코드가 뭔지 모르겠을 때 | `"이 코드가 뭘 하는지 초등학생도 이해할 수 있게 설명해줘"` |
| 2 | 에러가 났을 때 | `"이 에러 어떻게 고치는지 단계별로 알려줘: [에러 붙여넣기]"` |
| 3 | 기능 추가할 때 | `"[기능 설명]을 추가하고 싶어. 어디서 어떻게 시작할지 알려줘"` |
| 4 | 코드 개선할 때 | `"이 코드 더 좋게 만들 수 있어? 하나씩 설명하면서 바꿔줘"` |
| 5 | 배울 때 | `"이 코드를 보면서 [개념]을 이해하고 싶어. 이 코드를 예시로 설명해줘"` |

## 프롬프트를 더 잘 쓰는 3가지 원칙

### 1️⃣ 맥락(context) 먼저

나쁜 예:
```
버그 고쳐줘
```

좋은 예:
```
Python Flask 웹앱에서 로그인 기능을 만들고 있어.
사용자가 로그인 후 대시보드로 이동해야 하는데, 자꾸 로그인 페이지로 돌아와.
아래 코드에서 문제가 뭔지 찾아줘:
[코드 붙여넣기]
```

---

### 2️⃣ 원하는 형식 명시하기

```
결과를 아래 형식으로 줘:
1. 문제점 요약 (2~3줄)
2. 수정된 코드
3. 왜 이렇게 고쳤는지 (1~2줄)
```

---

### 3️⃣ 단계적으로 요청하기

한 번에 다 시키면 길어지고 헷갈려요. **작은 단위로 나눠서** 요청하면 더 정확해요.

```
# 대신에 "전체 프로젝트 만들어줘" 라고 하기보다...

1단계: "먼저 데이터베이스 설계만 해줘"
2단계: "이 설계로 테이블 생성 SQL 써줘"
3단계: "이제 Python으로 연결하는 코드 써줘"
```
