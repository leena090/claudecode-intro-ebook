## 작업을 어디서든 이어할 수 있다고요?

네, 가능합니다.

> 🍱 **비유로 설명하면**: 넷플릭스처럼요. TV에서 영화 보다가 외출하면서 폰으로 이어보고, 집에 돌아오면 다시 TV로 계속 볼 수 있잖아요. Claude Code도 마찬가지예요. 집 컴퓨터에서 시작한 작업을 카페에서 폰으로 이어하고, 사무실 터미널로 넘겨서 마무리할 수 있습니다.

이 기능들을 총칭해서 "원격 이동 기능"이라고 불러요.

---

## 4가지 이동 방법 한눈에 보기

| 방법 | 어디서 → 어디로 | 명령어 | 비유 |
|------|---------------|--------|------|
| Teleport | 웹/앱 → 터미널 | `claude --teleport` | USB로 파일 옮기기 |
| Remote Control | 터미널 → 모바일/웹 | `claude --rc` | TV 리모컨 |
| /desktop | 터미널 → Desktop 앱 | `/desktop` | 작은 화면 → 큰 화면 |
| Dispatch | 폰 → 컴퓨터 | Dispatch 메시지 | 카톡으로 비서에게 지시 |

하나씩 자세히 알아볼게요.

---

## Teleport — 웹 세션을 내 컴퓨터로 가져오기

```bash
# Mac 터미널 / Windows PowerShell
claude --teleport
```

> 🍱 **비유로 설명하면**: USB로 파일 옮기기예요. 회사 컴퓨터에서 작업 중이던 파일을 USB에 담아 집 컴퓨터에서 여는 것처럼, 웹에서 하던 작업을 내 터미널로 그대로 가져옵니다.

**왜 쓰나요?**
- claude.ai/code (웹)에서 작업을 시작했는데, 내 컴퓨터 파일에 접근해야 할 때
- 웹에서 아이디어를 구상하고, 터미널에서 실제로 구현하고 싶을 때

**사용 방법:**

```
1. claude.ai/code 웹에서 작업 시작
2. 터미널을 열고 아래 명령어 입력:

# Mac
claude --teleport

# Windows PowerShell
claude --teleport

3. 내 웹 세션 목록이 나타남
4. 원하는 세션 선택
5. 터미널에서 이어서 작업 시작
```

**주의:** claude.ai 계정으로 로그인이 돼 있어야 세션 목록이 보입니다.

## Remote Control — 모바일에서 터미널 조종하기

```bash
# Mac 터미널 / Windows PowerShell
claude --remote-control
# 또는 짧게
claude --rc
```

> 🍱 **비유로 설명하면**: TV 리모컨이에요. TV(컴퓨터)는 거실에 있고, 나는 소파(카페)에 앉아서 리모컨(폰)으로 조종하는 거예요. 컴퓨터 앞에 없어도 지시를 내릴 수 있어요.

**왜 쓰나요?**
- 외출 중에도 집 컴퓨터에서 돌고 있는 작업 상황을 확인하고 싶을 때
- 긴 빌드나 배포가 끝났는지 폰으로 확인하고 싶을 때
- 추가 지시를 내리거나 작업을 수정하고 싶을 때

**사용 방법:**

```
1. 컴퓨터 터미널에서 시작:

# Mac
claude --remote-control

# Windows PowerShell
claude --rc

2. QR코드 또는 링크가 표시됨
3. 폰의 Claude 앱 또는 claude.ai에서 접속
4. 폰에서 원격으로 지시 및 확인
```

<div class="note-star">
★ v2.1.110부터 <strong>푸시 알림</strong>도 됩니다. 작업이 완료되면 폰으로 알림이 와요. 결과 확인하러 직접 들어갈 필요 없어요.
</div>

## /desktop — 터미널에서 Desktop 앱으로 넘기기

```bash
/desktop
```

> 🍱 **비유로 설명하면**: 작은 휴대폰 화면에서 보던 걸 태블릿이나 TV로 캐스팅하는 거예요. 터미널의 좁은 화면보다 Desktop 앱의 넓은 화면에서 코드 변경사항을 눈으로 편하게 확인할 수 있습니다.

**왜 쓰나요?**
- 코드 변경사항(diff)을 시각적으로 보고 싶을 때
- "어디가 바뀐 거야?" 확인이 필요할 때
- Desktop 앱의 편리한 UI를 활용하고 싶을 때

**사용 방법:**

```
1. 터미널에서 작업 중
2. /desktop 입력
3. Desktop 앱이 자동으로 열리며
   코드 변경사항 시각적으로 표시
4. diff 확인 후 Desktop 앱에서 계속 작업 가능
```

<div class="note-circle">
○ Desktop 앱이 설치돼 있어야 사용 가능합니다. 설치 가이드를 먼저 확인해주세요.
</div>

## Dispatch — 폰에서 한마디로 지시

> 🍱 **비유로 설명하면**: 사장님이 비서에게 카카오톡으로 "이거 처리해" 하는 것과 같아요. 비서(AI)가 사무실(컴퓨터)에서 알아서 처리합니다. 사장님은 카페에서 커피 마시면서 지시만 하면 돼요.

**Dispatch는 Claude Code Desktop 앱에 있는 기능**이에요.

**사용 방법:**

```
1. 컴퓨터의 Claude Code Desktop 앱 실행
2. Dispatch 기능 활성화
3. 폰의 Claude 앱에서 메시지 전송:
   "어제 PR 리뷰해줘"
   "테스트 돌려줘"
   "배포 상태 확인해줘"
4. 컴퓨터의 AI가 자동으로 실행
5. 결과를 폰으로 받아봄
```

**Dispatch가 특히 편한 상황:**
- 출근길 지하철에서 "오늘 할 작업 목록 정리해줘" 지시
- 점심 먹으면서 "아까 코드 에러 고쳐줘" 전달
- 퇴근길 "빌드 돌려놓고 결과 알려줘" 지시

## 실전 시나리오: 하루 종일 작업 이어하기

아침부터 저녁까지, 어디서나 같은 작업을 이어하는 실제 예시예요.

```
오전 7시 — 출근길 지하철
폰에서 Dispatch: "오늘 작업할 PR 목록 정리해줘"
→ 컴퓨터가 목록 준비해놓음

오전 9시 — 사무실 도착
터미널에서: claude --teleport
→ 어제 웹에서 하던 세션 가져와서 이어서 작업

오전 11시 — 코드 변경 완료
터미널에서: /desktop
→ Desktop 앱으로 넘겨서 diff 시각적으로 확인

오후 1시 — 점심 외출
터미널에서: claude --remote-control
→ 폰으로 진행 상황 모니터링

오후 2시 — 카페에서
Remote Control로 폰에서: "이 부분 좀 더 최적화해줘"
→ 컴퓨터가 알아서 처리

오후 6시 — 퇴근길
Dispatch로 폰에서: "테스트 돌려놓고 결과 알려줘"
→ 집에 도착하면 결과 확인
```

장소가 바뀌어도 작업은 끊김 없이 이어집니다.

## 어떤 방법을 선택할까?

| 상황 | 추천 방법 |
|------|----------|
| 웹에서 시작한 작업을 터미널로 옮기고 싶다 | Teleport |
| 외출 중 진행 상황을 폰으로 확인하고 싶다 | Remote Control |
| 터미널 코드를 더 넓은 화면에서 보고 싶다 | /desktop |
| 폰에서 간단히 지시만 내리고 싶다 | Dispatch |
