## "Claude Code, 얼마나 나와요?"

비용은 사용하기 전에 가장 많이 걱정하는 부분이에요. 미리 알아두면 전혀 무서울 게 없어요!

---

## 요금제 종류 한눈에 보기

| 요금제 | 월 비용 | 특징 |
|--------|--------|------|
| **Pro** | $17(연간) / $20(월간) | 개인용, Sonnet 4.6 + Opus 4.7 포함 |
| **Max 5x** | $100 | 더 많은 사용량, 대용량 코드베이스 적합 |
| **Max 20x** | $200 | 파워 유저용, 가장 넉넉한 사용량 |
| **Team** | $20/인원 | 5~150명 팀, 자가 관리 + API 추가 사용량 |
| **Enterprise** | 별도 문의 | 고급 보안·데이터 관리 포함 |
| **Claude API** | 사용량 기반 | 개발자용, 토큰당 과금 |

> 💡 **참고**: 가격은 공식 발표 기준이며 변경될 수 있어요. 정확한 최신 가격은 [claude.ai](https://claude.ai)에서 확인하세요.

## API 사용 시 토큰 비용 (공식 발표 기준)

Claude Code를 Claude API(Console 계정)로 사용할 때는 **토큰 단위**로 과금돼요.

| 모델 | 입력 토큰 | 출력 토큰 |
|------|---------|---------|
| Claude Opus 4.7 | 비교적 높음 | 비교적 높음 |
| Claude Sonnet 4.6 | 중간 | 중간 |
| Claude Haiku 4.5 | 낮음 | 낮음 |

> 🪙 **비유**: 택시 미터기처럼, Claude와 주고받은 텍스트(토큰) 양에 따라 요금이 붙어요. 길게 얘기할수록 요금이 올라가요.

## 비용 절약 실전 팁

### 💡 팁 1: 모델을 작업에 맞게 선택하세요

| 작업 종류 | 추천 모델 | 이유 |
|---------|---------|------|
| 복잡한 아키텍처 설계 | Opus 4.7 | 깊이 있는 사고 필요 |
| 일반 코딩, 버그 수정 | Sonnet 4.6 | 가성비 최고 |
| 간단한 포맷팅, 문서화 | Haiku 4.5 | 빠르고 저렴 |

```bash
# 모델 직접 지정
claude --model claude-haiku-4-5-20251001 "이 파일 주석 추가해줘"
```

---

### 💡 팁 2: 컨텍스트 창을 효율적으로 관리하세요

가장 많은 토큰을 소모하는 원인이 **불필요하게 긴 대화 히스토리**예요.

**실천법:**
```bash
# 대화가 길어지면 초기화
/clear

# 특정 파일만 컨텍스트에 유지
/compact  # 대화 히스토리 압축
```

> 📚 **비유**: 책상이 서류로 가득 차면 필요한 걸 찾기도 느려지고, 새 작업하기도 힘들죠. 정기적으로 정리하면 효율이 올라가요.

---

### 💡 팁 3: 불필요한 파일 읽기를 줄이세요

Claude에게 "모든 파일을 읽어"라고 하면 토큰이 많이 나가요.

| ❌ 이렇게 | ✅ 이렇게 |
|---------|---------|
| "전체 프로젝트 분석해줘" | "src/auth 폴더만 분석해줘" |
| "모든 파일 확인해줘" | "login.tsx 파일만 봐줘" |

---

### 💡 팁 4: 훅으로 전처리하면 비용 절감

파일을 읽기 전에 불필요한 부분(주석, 빈 줄 등)을 제거하는 **PreToolUse 훅**을 설정하면 토큰을 절약할 수 있어요. (공식 문서 기반 추정)

---

### 💡 팁 5: /effort 설정으로 생각 깊이 조절

```bash
/effort low   # 빠른 답변 (간단한 작업)
/effort high  # 깊은 사고 (복잡한 작업, 토큰 더 사용)
```

> ⚙️ **참고**: v2.1.94 이후 기본값이 `high`로 변경됐어요. 간단한 작업에는 `low`로 바꾸면 비용 절약이 돼요.

## 팀에서 비용 관리하기

### 지출 한도(Spend Limits) 설정

Team/Enterprise 플랜에서는 팀 전체 또는 개별 인원의 **월 사용량 한도**를 설정할 수 있어요.

```
Claude Code 콘솔 → 팀 설정 → 사용량 한도
```

한도 초과 시 사용자에게 알림이 가요. 갑작스러운 과도한 사용을 막을 수 있어요.

### 사용량 분석 대시보드

```
Claude Code 콘솔 → Analytics(애널리틱스)
```

- 팀원별 사용량 확인
- 프로젝트별 비용 추적
- 주간/월간 트렌드 분석

> 📊 **비유**: 회사 법인카드 지출 내역서처럼, 누가 얼마나 쓰는지 한눈에 볼 수 있어요.

## 구독제 vs API 사용, 무엇이 유리할까?

| 상황 | 추천 방식 |
|------|---------|
| 매일 꾸준히 사용 | Pro/Max 구독 (월정액으로 예측 가능) |
| 가끔 대규모 작업 | API (사용량 기반 — 안 쓰면 비용 없음) |
| 팀 사용, 5명 이상 | Team 플랜 |
| 기업 배포, 100명 이상 | Enterprise 또는 API |

---

## 요약

- 📌 **구독제**: 예측 가능한 비용, 매일 쓰는 개인/팀에 적합
- 📌 **모델 선택**: 작업 복잡도에 맞게 Haiku/Sonnet/Opus 구분
- 📌 **컨텍스트 관리**: `/clear`, `/compact`로 주기적 정리
- 📌 **범위 제한**: 전체 프로젝트보다 필요한 파일만 지정
- 📌 **팀 한도**: 팀 플랜에서 지출 상한선 설정 가능
