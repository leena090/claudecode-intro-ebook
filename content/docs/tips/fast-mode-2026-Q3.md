## Fast Mode가 바뀌었어요

| 항목 | 이전 (Opus 4.8 시절) | 현재 (Opus 5.5) |
|---|---|---|
| **대상 모델** | claude-opus-4-8 | claude-opus-5-5 |
| **입력 가격** | $30/백만 토큰 | $8/백만 토큰 |
| **출력 가격** | $150/백만 토큰 | $40/백만 토큰 |
| **속도** | Opus 4.8 대비 2.5배 빠름 | Opus 5.5 기반 고속 |

> 🎉 **가격이 무려 73% 내려갔어요!** 이전에는 비싸서 아끼던 Fast Mode가 훨씬 접근하기 쉬워졌어요.

---

## Fast Mode가 뭔가요?

Fast Mode(패스트 모드)는 Opus 5.5를 더 빠른 속도로 실행하는 특별 설정이에요.

> ⚡ **비유로 설명하면**: 고급 레스토랑 요리사가 "빠른 서비스 모드"로 주문을 처리하는 것처럼, 최고급 모델인 Opus 5.5를 평소보다 훨씬 빠르게 쓸 수 있어요. 대신 요금이 조금 더 나와요.

---

## 언제 Fast Mode를 쓰면 좋나요?

```
✅ 긴 답변을 빠르게 받고 싶을 때
✅ 실시간에 가깝게 코드 생성이 필요할 때
✅ 여러 작업을 연달아 빠르게 처리할 때
✅ 소비 기반 플랜에서 Opus 5.5 성능이 필요할 때

❌ 답변 속도가 크게 중요하지 않은 경우
❌ 비용을 최소화해야 하는 경우 (일반 Opus 5.5나 Sonnet 5.5 추천)
```

---

## Fast Mode 켜는 방법

```bash
# Claude Code에서
/fast

# 또는 UI 상단 "⚡ Fast" 토글 클릭
```

> 💡 `/fast` 명령어 한 번으로 Fast Mode를 켜고 끌 수 있어요.

---

## 가격 비교 (공식 발표 기준)

```
일반 Sonnet 5.5:  훨씬 저렴, 일반 작업에 충분
일반 Opus 5.5:    높음, 복잡한 작업
Fast Mode Opus 5.5: $8/$40 (입력/출력 per 백만 토큰)
                    — 리서치 프리뷰 단계
```

> ⚠️ **주의**: Fast Mode는 현재 "리서치 프리뷰(research preview)" 단계예요. 가격이나 기능이 정식 출시 시 변경될 수 있어요 (공식 발표 기준).

## 어떤 플랜에서 쓸 수 있나요?

| 플랜 | Fast Mode |
|---|---|
| Pro/Max | 사용 크레딧으로 접근 가능 (공식 발표 기준) |
| Team/Enterprise | 소비 기반으로 접근 가능 |
| API (Console) | 소비 기반 플랜에서 가능 |

## 정리

Fast Mode가 Opus 4.8 → Opus 5.5로 바뀌면서:
1. **더 좋은 모델** (Opus 5.5가 Opus 4.8보다 뛰어남)
2. **더 낮은 가격** ($30/$150 → $8/$40, 약 73% 인하)
3. **동일한 고속 응답** 유지

이제 Fast Mode를 더 자주 써볼 수 있게 됐어요! 🚀
