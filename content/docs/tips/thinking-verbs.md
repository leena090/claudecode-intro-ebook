## 혹시 이 장면, 기억나세요?

Claude Code가 뭔가를 골똘히 생각할 때, 프롬프트 창 옆에 <mark>반짝이는 커서와 함께</mark> 이런 말이 뜹니다.

```
✻ Pondering… (esc to interrupt)
✻ Noodling…
✻ Shenaniganing…
✻ Prestidigitating…
✻ Tomfoolering…
```

"*이게 무슨 영어야? 사전에도 없는데?*"

맞습니다. **Anthropic 개발자들이 일부러 숨겨놓은 장난**이에요. 코딩이라는 지루할 수 있는 작업에 작은 미소를 선물하려고, 무려 <mark>**233개의 귀여운 동사**</mark>를 랜덤으로 보여주는 거예요.

<div class="note-star">
⭐ 이 단어들은 `cli.js` 안에 그냥 문자열 배열로 들어있어요. 무작위로 하나씩 뽑아서 보여주는 구조라, 같은 작업을 두 번 해도 매번 다른 단어가 튀어나옵니다.
</div>

## 🧠 "생각 중" — 학자처럼 고민하는 단어들

뇌를 굴리는 중이라는 뜻인데, 하나같이 평범한 "Thinking"보다 기품있게 들립니다.

| 영어 | 한국어 느낌 | 진짜 뜻 |
|------|-----------|---------|
| **Pondering** | 곰곰이 생각 중 | 진지하게 사색하는 것 |
| **Cogitating** | 머리 굴리는 중 | 깊이 생각하다(라틴어 어원) |
| **Ruminating** | 되새김질 중 | 소처럼 되씹어 생각하다 |
| **Contemplating** | 바라보며 명상 중 | 관조하며 숙고하다 |
| **Cerebrating** | 뇌 가동 중 | 머리(cerebrum)를 쓰다 |
| **Deliberating** | 저울질 중 | 신중히 고민하다 |
| **Musing** | 공상에 잠김 | 멍하니 떠올리다 |
| **Mulling** | 우물쭈물 중 | 천천히 고민하다 |
| **Dithering** | 갈팡질팡 중 | 결정 못 하고 망설이다 |
| **Philosophising** | 철학자 모드 | 철학하다 |
| **Ideating** | 아이디어 뽑는 중 | 구상하다 |
| **Envisioning** | 그려보는 중 | 마음속으로 상상하다 |

## 🎪 "장난치는 중" — 사전에서도 잘 안 보이는 단어들

이 묶음은 **실제로 영어사전에도 잘 안 실리는** 구어체·옛말·의성어 단어들입니다. 이름 자체가 농담이에요.

| 영어 | 한국어 번역 | 해설 |
|------|------------|------|
| **Shenaniganing** | 딴짓 중 | "shenanigans(장난질)"을 동사처럼 씀 |
| **Tomfoolering** | 바보짓 중 | "tom foolery(멍청한 장난)"의 동사화 |
| **Razzmatazzing** | 화려한 쇼 중 | "razzmatazz(요란한 볼거리)" |
| **Boondoggling** | 쓸데없는 일 중 | 미국 속어 — 시간 낭비 |
| **Bloviating** | 잘난 척 중 | 지나치게 떠들다 |
| **Canoodling** | 꽁냥꽁냥 중 | 연인이 꽁냥거리다(!) |
| **Lollygagging** | 꾸물대는 중 | 빈둥거리다 |
| **Gallivanting** | 놀러다니는 중 | 여기저기 돌아다니다 |
| **Flibbertigibbeting** | 수다 떠는 중 | 산만한 사람을 가리키는 고어 |
| **Hullaballooing** | 와글와글 중 | 소란 피우다 |
| **Boogieing** | 춤추는 중 | 부기(boogie) 춤 |
| **Moseying** | 어슬렁대는 중 | 천천히 걷다 |
| **Moonwalking** | 문워크 중 | 마이클 잭슨의 그 춤! |
| **Skedaddling** | 줄행랑 중 | 후닥 도망가다 |
| **Jitterbugging** | 지터벅 중 | 1940년대 스윙 춤 |
| **Frolicking** | 뛰어노는 중 | 까불며 놀다 |
| **Schlepping** | 낑낑대며 나르는 중 | 이디시어 — 무거운 걸 끌다 |

<div class="note-circle">
○ 이 단어들은 거의 다 **"웃음을 자아내려고 일부러 넣은"** 것들이에요. `Flibbertigibbeting`이나 `Skedaddling` 같은 건 시골 할머니 잔소리에서나 나올 법한 단어라, 화면에 뜨면 일부러 검색해보게 되죠.
</div>

## ✨ "Anthropic만의 신조어"

진짜 사전에 없는, 개발자들이 **직접 만든 단어**들입니다. 이 섹션이 이 모음집의 하이라이트예요.

| 영어 | 한국어 해설 |
|------|------------|
| **Clauding** | **"Claude 중"** — Anthropic이 자기네 AI 이름을 동사처럼 쓴 것! |
| **Whatchamacalliting** | **"거시기 중"** — watchama-call-it("뭐라 불러야 할지")을 동사화. 이름 모르는 걸 이름 모른 채로 하는 중 |
| **Discombobulating** | 어리둥절하게 만드는 중 (실존 단어이긴 함) |
| **Combobulating** | 위의 반대 — "정돈시키는 중" (역 파생어!) |
| **Recombobulating** | "다시 정돈 중" — 한 번 더 파생 |
| **Wibbling** | 덜덜 떠는 중 |
| **Befuddling** | 아리송하게 만드는 중 |
| **Flummoxing** | 당황시키는 중 |
| **Finagling** | 잔꾀 부리는 중 |
| **Smooshing** | 뭉개는 중 |
| **Gitifying** | **"Git스럽게 만드는 중"** — `git` 명령어에 아부하는 조어 |

<div class="note-star">
⭐ **Combobulating 3단 변형**은 특히 재밌어요. 원래 `discombobulate(헷갈리게 하다)`가 진짜 단어인데, Anthropic이 거꾸로 **`combobulate`(정리하다)**를 만들어내고, 거기에 re- 붙여서 **`recombobulate`(재정리하다)**까지 세 단계로 확장했어요. 이건 개발자들 사이에서 한동안 회자될 농담이에요.
</div>

## 왜 이런 걸 만들었을까요?

생각해보면 당연해요. Claude Code는 **매일 수많은 개발자들**이 몇 초에서 몇 분씩 기다리는 도구입니다. 그 기다리는 시간이 답답하기만 하면, 사람들이 쉽게 지쳐요.

그런데 "Pondering…" 대신 "**Tomfoolering…**(바보짓 중)"이 뜨면? 화가 나려다가 피식 웃게 돼요. 그러면 또 기다릴 수 있죠.

이게 바로 **좋은 UX 디자인**이에요. Anthropic은 심각한 AI 회사인데, 이런 작은 구석에 유머를 숨겨놨어요. <mark>사람을 기쁘게 하는 건 큰 일에서가 아니라 작은 디테일에서 나온다는 걸 잘 아는 거죠.</mark>

<div class="callout insight">
<div class="callout-head"><span class="stamp">🎁</span>숨은 의도</div>
<p>40~60대 초심자 분들, 다음에 Claude Code 쓰다가 이상한 영어 단어 보이시거든 <strong>사전을 찾지 마세요</strong>. "아, 개발자가 나한테 장난치는 거구나" 하고 그냥 미소 한 번 지어주시면 됩니다. 그게 이 단어들을 만든 사람들이 바라던 반응이에요.</p>
</div>
