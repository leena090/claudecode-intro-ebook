## 💰 요금제 & 비용

### Q: 무료로 쓸 수 있나요?

**웹앱 채팅만 무료**(제한적). Claude Code, 코워크, Code 웹은 **Pro($20/월) 이상** 필요합니다.

| 요금제 | 월 가격 | 웹앱 채팅 | 코워크 | Claude Code | Code 웹 |
|--------|--------|----------|--------|------------|---------|
| 무료 | $0 | ✅ 제한적 | ❌ | ❌ | ❌ |
| **Pro** | **$20** | ✅ | ✅ | ✅ | ✅ |
| Max 5x | $100 | ✅ | ✅ | ✅ | ✅ |
| Max 20x | $200 | ✅ | ✅ | ✅ | ✅ |

<mark>대부분의 분들은 Pro($20/월, 약 27,000원)면 충분합니다.</mark>

### Q: 사용량 한도가 있나요?

네. Pro 기준 일정 사용량이 지나면 속도가 느려집니다. Max 5x는 5배, Max 20x는 20배 한도예요.

### Q: 사용량을 확인하려면?

Claude Code 터미널에서 `/cost` 입력하면 모델별 사용량과 캐시 적중률까지 볼 수 있어요.

## 🤖 AI 모델

### Q: 어떤 AI 모델을 쓰나요?

| 모델 | 특징 | 추천 상황 |
|------|------|----------|

### Q: /fast 모드는 다른 모델인가요?

아니요. **같은 모델**이 더 빠르게 응답할 뿐입니다. 모델이 바뀌는 게 아니에요.

## 🌐 Claude 웹앱 (claude.ai)

### Q: 웹앱이 뭔가요?

브라우저에서 claude.ai에 접속해서 AI와 채팅하는 것. 가장 기본적인 Claude 사용법이에요.

### Q: 아티팩트가 뭔가요?

Claude가 만든 결과물(문서, 표, 코드, 다이어그램 등)을 채팅 옆에 **바로 보여주는 기능**. 복사하거나 다운로드할 수 있어요.

### Q: 프로젝트 기능이 뭔가요?

관련 대화, 파일, 지시사항을 **하나의 폴더처럼 묶어서 관리**하는 기능. "마케팅 프로젝트", "블로그 작성" 같이 주제별로 정리할 수 있어요.

### Q: 파일을 올릴 수 있나요?

네. 이미지, PDF, 엑셀, 워드 등 다양한 파일을 올려서 분석하거나 수정을 요청할 수 있어요.

### Q: 웹 검색이 되나요?

네. Claude가 실시간 웹 검색을 해서 최신 정보를 찾아줍니다.

## 🤝 코워크 (Cowork)

### Q: 코워크가 뭔가요?

Claude Desktop 앱 안에 있는 3개 탭(Chat / **Cowork** / Code) 중 하나. AI가 **내 컴퓨터를 직접 조작**해서 업무를 처리해주는 기능이에요.

> 비유: 옆에 앉아서 내 컴퓨터로 일해주는 비서

### Q: 일반 채팅이랑 뭐가 다른가요?

| | 웹앱 채팅 | 코워크 |
|---|---|---|
| 파일 접근 | 업로드만 | **내 PC 파일 직접 접근** |
| 앱 조작 | ❌ | **✅ 클릭, 타이핑 가능** |
| 맡기고 자리비움 | ❌ | **✅ 알아서 작업** |
| 결과물 | 텍스트 답변 | **파일 생성/수정** |

### Q: 데스크톱 제어(Computer Use)가 뭔가요?

Claude가 화면을 보고 **직접 마우스 클릭, 키보드 타이핑**을 하는 기능. 엑셀 열기, 웹사이트 탐색, 폼 작성 등을 자동으로 합니다.

- **Mac**: 손쉬운 사용 + 화면 녹화 권한 필요
- **Windows**: 2026년 4월 3일부터 지원

### Q: Dispatch(디스패치)가 뭔가요?

**폰에서 일을 시키면 데스크톱에서 자동 실행**되는 기능.

1. 출근길에 폰으로 "매출 보고서 정리해줘" 전송
2. 사무실 데스크톱에서 Claude가 알아서 작업
3. 완료되면 폰으로 알림
4. 도착하면 결과 확인

### Q: 예약 작업이 되나요?

네! 매일/매주/매월 반복 작업을 설정할 수 있어요.

- 매일 오전 9시 뉴스 요약
- 매주 월요일 주간보고 초안
- 매달 1일 경비 정산 정리

### Q: 코워크로 엑셀, PPT도 되나요?

네! 대표적으로:
- **엑셀**: 데이터 정리, 수식 자동 입력, 차트 생성
- **PPT/키노트**: 슬라이드 자동 생성
- **워드/한글**: 문서 서식 정리
- **파일 정리**: 폴더별 분류, 이름 변경

### Q: 외부 서비스 연결이 되나요?

MCP 커넥터로 연결 가능:
- Google Drive, Gmail
- Microsoft 365 (Word, Excel, PowerPoint, OneDrive)
- DocuSign 등

### Q: 코워크는 현재 어떤 상태인가요?

**Research Preview** (연구 미리보기) 상태입니다. 정식 출시 전이라 기능이 계속 추가되고 있어요.

## ⌨️ Claude Code (터미널)

> 아래 항목들은 Claude Code(터미널 버전)를 이미 쓰고 계신 분들을 위한 내용이에요. 아직 안 써보셨다면 건너뛰어도 괜찮습니다!

### Q: Claude Code가 뭔가요?

터미널(명령창)에서 AI가 **코드를 직접 작성하고, 파일을 만들고, 실행까지** 해주는 도구.

### Q: 코딩을 모르는데 가능한가요?

**네.** 한국어로 "이런 웹사이트 만들어줘"라고 말하면 Claude가 코드를 대신 짜줍니다.

### Q: ChatGPT랑 뭐가 다른가요?

| | ChatGPT | Claude Code |
|---|---|---|
| 코드 보여줌 | ✅ | ✅ |
| **코드 직접 실행** | ❌ | ✅ |
| **파일 직접 생성/수정** | ❌ | ✅ |
| **여러 파일 동시 작업** | ❌ | ✅ |

<mark>ChatGPT는 "이렇게 하세요"라고 알려주고, Claude Code는 "제가 해드릴게요"라고 직접 합니다.</mark>

### Q: 실수하면 되돌릴 수 있나요?

**네!** 두 가지 방법:
1. `/rewind` 명령어 입력
2. **Esc 키를 빠르게 두 번** 누르기

Claude는 파일 수정 전에 **자동으로 체크포인트를 저장**해서, 언제든 이전 상태로 돌아갈 수 있어요.

### Q: /powerup이 뭔가요?

Claude Code 안에 있는 **내장 튜토리얼**. 18개 인터랙티브 레슨으로 기능을 게임처럼 배울 수 있어요. 처음이라면 `/powerup`부터 시작하세요!

### Q: 토큰을 절약하려면?

**핵심 3가지:**
1. **`/compact`** — 대화 중간중간 압축하기
2. **구체적으로 말하기** — "홈페이지 만들어줘" 대신 "카페 소개 홈페이지, 메뉴+지도+영업시간 포함, 갈색 톤"
3. **CLAUDE.md 작성** — 매번 같은 설명 반복 안 해도 됨

### Q: 스킬(Skill)이 뭔가요?

**나만의 슬래시 커맨드**. SKILL.md 파일 하나로 만들어요.

예: `/blog 오늘의 주제` → 미리 정한 규칙대로 SEO 블로그 글 자동 작성

### Q: 에이전트 팀이 뭔가요?

**여러 AI가 동시에 다른 작업**을 하는 기능. 예를 들어:
- 에이전트1 → 프론트엔드 담당
- 에이전트2 → 백엔드 담당
- 에이전트3 → 테스트 담당

워크트리와 함께 쓰면 서로 충돌 없이 병렬 작업 가능.

### Q: /btw가 뭔가요?

Claude가 일하고 있을 때, **작업을 멈추지 않고** 따로 질문하는 기능. 대화 기록에 안 남아서 **토큰 최대 50% 절약**. `/btw 이거 뭐야?` 형태로 사용.

### Q: 어제 하던 작업을 이어하려면?

**`claude --continue`** (또는 `claude -c`). 최근 대화를 그대로 이어갑니다. 여러 세션 중 골라서 하려면 **`claude --resume`**.

### Q: 매번 "이거 해도 돼?" 묻는 게 귀찮아요

**`claude --permission-mode auto`** 로 시작하세요. 안전한 건 자동 승인, 위험한 것만 물어봐요. `--dangerously-skip-permissions`는 전부 건너뛰는 옵션인데, 연습용이 아니면 쓰지 마세요.

### Q: /buddy 다마고찌가 뭔가요?

Claude Code에 숨겨진 **디지털 펫** 기능. `/buddy` 입력하면 18종 중 하나가 나와요. 카피바라가 나오면 전설 등급(1%)! 재미 요소니까 한번 해보세요.

### Q: 음성으로도 명령할 수 있나요?

네! `/voice` 입력 후 **스페이스바를 누르고 있는 동안** 말하면 됩니다. 놓으면 전송돼요.

## ☁️ Claude Code 웹 (claude.ai/code)

### Q: Claude Code 웹이 뭔가요?

**브라우저에서 Claude Code를 쓰는 것**. 내 컴퓨터에 아무것도 설치하지 않아도 돼요. Anthropic 클라우드 서버에서 실행됩니다.

### Q: 터미널 버전이랑 뭐가 다른가요?

| | 터미널 (CLI) | 웹 (claude.ai/code) |
|---|---|---|
| 설치 | 필요 | **불필요** |
| 실행 위치 | 내 컴퓨터 | **클라우드** |
| 컴퓨터 꺼도 작업 | ❌ | **✅ 계속됨** |
| 파일 접근 | 로컬 전체 | GitHub 레포만 |
| 지원 저장소 | 모두 | GitHub만 |

### Q: Auto-fix가 뭔가요?

PR은 "내가 고친 코드를 확인해주세요"라고 요청하는 거예요. PR을 올리면, 자동 테스트 실패나 팀원 댓글을 **Claude가 자동으로 감지하고 고쳐서 다시 올려줍니다**. 24시간 대기하는 보조 개발자 같은 거예요.

### Q: --remote가 뭔가요?

터미널에서 `claude --remote "작업 내용"`을 입력하면 **웹에서 세션이 시작**됩니다. 컴퓨터를 꺼도 클라우드에서 계속 작업해요.

### Q: --teleport은?

반대로, 웹에서 작업하던 세션을 **내 터미널로 가져오는** 명령어.

## 🔄 플랫폼 비교

### Q: 웹앱, 코워크, Claude Code — 뭘 쓰면 되나요?

| 하고 싶은 일 | 추천 도구 |
|-------------|----------|
| AI랑 대화/질문 | **웹앱** (claude.ai) |
| 문서 작성/번역/요약 | **웹앱** |
| 엑셀·PPT·파일 자동화 | **코워크** |
| 폰에서 일 시키기 | **코워크** (Dispatch) |
| 웹사이트/앱 만들기 | **Claude Code** |
| 설치 없이 코딩 | **Claude Code 웹** |
| 컴퓨터 꺼놔도 되는 코딩 | **Claude Code 웹** |

### Q: 여러 개를 같이 쓸 수 있나요?

네! Pro 하나로 전부 다 쓸 수 있어요. 많은 분들이 상황에 따라 바꿔가며 씁니다.

### Q: 채팅은 다 같은 건가요?

겉보기에는 비슷하지만 **능력이 다릅니다**:

| | 웹앱 채팅 | 코워크 채팅 | Code 터미널 |
|---|---|---|---|
| 대화 스타일 | 일반 대화 | 작업 지시 | 명령 실행 |
| 파일 접근 | 업로드만 | PC 전체 | 현재 폴더 |
| 응답 방식 | 텍스트 | 파일 생성 | 코드 실행 |
| 실행 취소 | ❌ | ❌ | ✅ /rewind |

> 쉽게: 웹앱 = "알려줘", 코워크 = "해줘", Code = "만들어줘"

## 💻 설치 & 설정

### Q: 어디서 설치하나요?

| 방식 | Mac | Windows |
|------|-----|---------|
| Desktop 앱 | claude.ai/download → DMG | claude.ai/download → EXE |
| 웹 버전 | claude.ai/code 접속 | claude.ai/code 접속 |
| 터미널 | `npm install -g @anthropic-ai/claude-code` | 동일 |

Desktop 앱이 가장 쉬워요. 채팅 + 코워크 + Code가 한 앱에 다 들어있거든요.

### Q: Node.js가 뭔가요? 꼭 필요한가요?

터미널(npm)로 설치할 때만 필요합니다. Desktop 앱이나 웹 버전 쓸 거면 **필요 없어요**.

### Q: CLAUDE.md가 뭔가요?

프로젝트마다 AI에게 주는 **특별 지시서**. "이 프로젝트는 한국어로 대답해", "이 파일은 건드리지 마" 같은 규칙을 미리 적어두면 매번 말 안 해도 돼요.

### Q: 키보드 단축키를 바꿀 수 있나요?

네! `~/.claude/keybindings.json` 파일에서 변경 가능. 예: Enter를 줄바꿈으로, Ctrl+Enter를 전송으로 (카카오톡 스타일).

3. **캐시 무효화 버그 2개** — 비용 10~20배 증가

**대응**:
- ⏰ **피크타임 피하기** — 평일 한국 오후 9시~익일 오전 3시 (미국 동부 오전 8시~오후 2시)
- 💾 **캐시 히트율 관리** — `/cost`로 확인, 50% 이상 유지 목표

- ⚠️ 일부 사용자가 **v2.1.34 다운그레이드** 후 개선 보고 (자기 책임)

## 🆕 신규 기능 Q&A

### Q: /btw가 뭐예요?

**A**. Claude가 일하는 도중에 **기록을 남기지 않고** 잠깐 질문할 수 있는 명령어예요. 토큰을 최대 50% 절약할 수 있어요. → [3종 세트 가이드](/docs/tips/btw-side-questions)

### Q: /powerup이 뭐예요?

**A**. 2026-04-01 v2.1.90에 추가된 **인터랙티브 기능 학습 레슨**. 애니메이션 데모로 Claude Code 기능을 하나씩 배울 수 있어요. 처음 쓰시는 분께 강력 추천.

### Q: 1M 컨텍스트 제가 쓸 수 있나요?

**A**. Opus/Sonnet 4.6 모델 + **Max 5x 이상 플랜**이면 쓸 수 있어요. Pro는 제한적입니다. → [1M 컨텍스트 가이드](/docs/advanced/one-million-context)

### Q: Opus 4.6에서 effort 설정이 왜 이상해졌어요?

**A**. 2026-04-04 v2.1.92에서 **단순화됐어요**. 기존 ultrafast/fast/balanced/thorough/ultrathink → **low / medium / high** 3단계로. Opus + Max/Team은 기본값이 `high`입니다.

### Q: /tag, /vim이 없어요!

**A**. 2026-04-04 v2.1.92에서 **제거됐어요**. 대체 방법:
- `/tag` → 파일 북마크 기능은 `/memory`로 대체
- `/vim` → 에디터 통합 필요 시 Claude Code IDE 플러그인 사용
