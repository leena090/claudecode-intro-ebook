## Claude Code를 더 잘 쓰는 7가지 팁 (+ 신규 기능 3가지)

### 💡 Tip 1: 구체적으로 요청할수록 좋아요

**구체적인 요청 = 정확한 결과**

| ❌ 나쁜 예 | ✅ 좋은 예 |
|---------|---------|
| "파일 만들어줘" | "blog.html 파일을 만드는데, 파란색 배경에 흰 글씨로 헤더와 3개의 포스트 섹션이 있게 해줘" |
| "코드 짜줘" | "Python으로 CSV 파일을 읽고 각 행의 수치를 더해서 합계를 계산하는 스크립트를 만들어줘" |
| "웹사이트 만들어줘" | "우리 카페 소개 페이지 만들어줘. 메뉴 목록, 위치 지도, 영업시간이 있고, 색상은 따뜻한 갈색 계열로 해줘" |

**효과:** Claude가 정확히 이해하고 원하는 대로 만듭니다.

---

### 💬 Tip 2: 한국어로 편하게 말하세요

**영어 필요 없습니다!**

✅ 가능한 요청들:
```
"파일 만들어줄래?"
"이거 뭐 하는 코드야?"
"오류 고쳐줘"
"색 좀 이쁘게 바꿔줄래?"
```

- 존댓말, 반말 모두 가능
- 문법이 틀려도 상관없음
- 편한 대로 표현하면 됨

**효과:** 더 자연스럽고 빠른 대화가 가능합니다.

---

### ✏️ Tip 3: 마음에 안 들면 바로 수정 요청

**완벽할 때까지 수정하기**

```
첫 번째 요청:
> 계산기 웹사이트 만들어줘

만족도 70% → 수정 요청:
> 색을 빨간색으로 바꿔줄래?
✓ 수정 완료

만족도 80% → 추가 요청:
> 더 커 보이게 해줄래?
✓ 수정 완료

만족도 100% → 완성!
```

**효과:** 여러 번 수정해서 정확히 원하는 결과를 얻습니다.

---

### 💾 Tip 4: 작업 전 백업 습관 들이기

**AI도 실수할 수 있습니다**

- **중요한 파일은 미리 복사**하세요
- 기존 파일을 수정하기 전에 백업 생성
- "원본" 폴더와 "작업" 폴더 분리

```
작업 순서:
1. 원본 파일 복사 → backup_파일명.확장자
2. 작업 진행
3. 결과 확인 후 괜찮으면 원본 교체
```

**효과:** 실수로 인한 파일 손상을 방지합니다.

---

### 🔄 Tip 5: /clear로 새 주제 시작하기

**/clear의 장점**

```
대화 1:
> 파이썬 계산기 코드 작성해줘
> (여러 번 수정)

새로운 주제로 넘어갈 때:
> /clear

대화 2:
> HTML 웹사이트 만들어줘
> (이전 대화 맥락 없이 시작)
```

**효과:**
- 이전 대화 맥락이 지워져 더 정확해집니다
- 토큰 사용량이 줄어들어 비용 절감
- Claude가 새로운 주제에 집중합니다

### 📁 Tip 6: 올바른 폴더에서 시작하기

<div class="note-circle">
○ 이 팁은 터미널에서 Claude Code를 쓰시는 분들을 위한 내용이에요.
</div>

**파일 경로 오류 방지**

터미널에서 Claude Code를 쓸 때는 **작업할 폴더로 먼저 이동**한 다음 시작하세요.

```bash
# Mac 터미널 / Windows PowerShell
cd ~/Desktop/내프로젝트
claude
```

이렇게 하면 Claude가 해당 폴더의 파일들을 바로 인식합니다.

**cd 사용법:**
```bash
# 바탕화면의 "작업" 폴더로 이동
cd Desktop/작업

# 홈 폴더로 이동
cd ~

# 한 폴더 위로 이동
cd ..
```

**효과:** 파일 위치를 정확히 인식하고 오류가 줄어듭니다.

---

### ⏹️ Tip 7: Ctrl+C로 언제든 멈출 수 있어요

**작업 중단하기**

```
상황 1: AI가 잘못된 방향으로 가고 있을 때
> 파이썬 코드 만들어줘
(AI가 실행 중...)
Ctrl+C 누르기
→ 즉시 중단

상황 2: 오래 걸리는 작업을 멈추고 싶을 때
> 1000개 파일 생성 중...
Ctrl+C 누르기
→ 생성 중지
```

**안심하세요:**
- 한 번에 파일이 완전히 생성되거나 안 되거나
- 부분적으로 생성되지 않습니다
- 중단해도 이미 생성된 파일은 남아있습니다

## 🌟 가장 중요한 팁

> **틀려도 괜찮아요!**
>
> 반복해서 요청하면 점점 더 나아집니다.
> 처음부터 완벽할 필요는 없습니다.
> 시행착오를 통해 배우는 것이 클로드코드 사용의 진짜 묘미입니다.

## 🆕 2026년 3~4월 신규 숨은 기능 3가지

### 🔍 신규 Tip 1: Transcript 검색 (v2.1.83~)

대화가 길어지면 "아까 그 내용이 어디였지?" 싶을 때가 있죠. **Transcript 모드에서 `/` 키**를 누르면 단어 검색이 돼요.

```
Transcript 모드에서:
/  → 검색창 활성화
검색어 입력 → 일치 결과로 이동
n  → 다음 결과로
N  → 이전 결과로
```

> 🍱 **비유로 설명하면**: 긴 문서에서 Ctrl+F로 단어 찾는 거랑 똑같아요. 웹 브라우저 경험이 있다면 바로 익숙하실 거예요.

<div class="note-circle">
○ v2.1.83(2026-03-25)부터 지원. Transcript 모드는 전체 대화 기록을 스크롤로 보는 화면이에요.
</div>

---

### ⚡ 신규 Tip 2: 2026년 성능 개선 3종 (v2.1.77 ~ v2.1.92)

Claude Code가 몇 달 사이 **속도가 확 빨라졌어요**. 체감되는 3가지를 모아봤습니다.

#### ① `--resume` 세션 재개 45% ↑ (v2.1.77, 2026-03-17)

어제 하던 작업 이어서 할 때:

```bash
# Mac 터미널 / Windows PowerShell
claude --resume
```

- ⚡ 로딩 속도 **45% 향상**
- 💾 메모리 사용 **100~150MB 감소**
- 📂 대용량 프로젝트도 빠르게 재개

> 이전에는 재개할 때 10초 걸리던 게 이제 5초대로 줄었어요.

#### ② Write 도구 diff 연산 60% ↑ (v2.1.92, 2026-04-04)

파일 수정할 때의 내부 diff 계산이 **60% 빨라졌어요**. 특히:
- 탭(`\t`)이 많은 파일
- `&`, `$` 같은 특수문자가 많은 파일 (HTML, 쉘 스크립트 등)

> 🍱 **비유로 설명하면**: 이전에는 Claude가 "어디가 바뀌었지?" 하면서 한 글자씩 비교했다면, 이제는 한 덩어리씩 비교해서 훨씬 빨라진 거예요.

#### ③ 스크롤 성능 8배 ↑ (v2.1.78, 2026-03-17)

긴 대화를 스크롤할 때 버벅거림이 **8배 줄었어요**. 내부적으로 WASM yoga-layout을 순수 TypeScript로 교체한 결과.

> 1,000줄짜리 대화를 스크롤할 때도 부드럽게 넘어갑니다. 노트북 팬이 덜 돌아가요.

### 📜 신규 Tip 3: `/release-notes` 인터랙티브 버전 선택기 (v2.1.92~)

```bash
/release-notes
```

기존에는 최신 릴리스 노트만 쭉 보여줬는데, **v2.1.92부터는 인터랙티브 버전 선택기**가 떠요. 원하는 특정 버전의 릴리스 노트를 골라볼 수 있습니다.

**활용:**
- 내가 쓰는 버전의 변경점만 확인
- 특정 버그가 어느 버전에서 수정됐는지 찾기
- 업그레이드 전 영향도 확인

## 요약: 가장 중요한 3가지

1. **구체적으로 요청하기** — 이것만 해도 결과가 확 달라져요
2. **자주 저장하고 백업하기** — 혹시 모르니까
3. **/clear로 깔끔하게** — 주제 바뀌면 정리하고 새로 시작
