## Claude Code를 더 잘 쓰는 7가지 팁

### 💡 Tip 1: 구체적으로 요청할수록 좋아요

**구체적인 요청 = 정확한 결과**

| ❌ 나쁜 예 | ✅ 좋은 예 |
|---------|---------|
| "파일 만들어줘" | "blog.html 파일을 만드는데, 파란색 배경에 흰 글씨로 헤더와 3개의 포스트 섹션이 있게 해줘" |
| "코드 짜줘" | "Python으로 CSV 파일을 읽고 각 행의 수치를 더해서 합계를 계산하는 스크립트를 만들어줘" |
| "웹사이트 만들어줘" | "우리 카페 소개 페이지 만들어줘. 메뉴 목록, 위치 지도, 영업시간이 있고, 색상은 따뜻한 갈색 계열로 해줘" |

**효과:** Claude가 정확히 이해하고 원하는 대로 만듭니다.

---

### 💬 Tip 2: 한국어로 편하게 말하세요

**영어 필요 없습니다!**

✅ 가능한 요청들:
```
"파일 만들어줄래?"
"이거 뭐 하는 코드야?"
"오류 고쳐줘"
"색 좀 이쁘게 바꿔줄래?"
```

- 존댓말, 반말 모두 가능
- 문법이 틀려도 상관없음
- 편한 대로 표현하면 됨

**효과:** 더 자연스럽고 빠른 대화가 가능합니다.

---

### ✏️ Tip 3: 마음에 안 들면 바로 수정 요청

**완벽할 때까지 수정하기**

```
첫 번째 요청:
> 계산기 웹사이트 만들어줘

만족도 70% → 수정 요청:
> 색을 빨간색으로 바꿔줄래?
✓ 수정 완료

만족도 80% → 추가 요청:
> 더 커 보이게 해줄래?
✓ 수정 완료

만족도 100% → 완성!
```

**효과:** 여러 번 수정해서 정확히 원하는 결과를 얻습니다.

---

### 💾 Tip 4: 작업 전 백업 습관 들이기

**AI도 실수할 수 있습니다**

- **중요한 파일은 미리 복사**하세요
- 기존 파일을 수정하기 전에 백업 생성
- "원본" 폴더와 "작업" 폴더 분리

```
작업 순서:
1. 원본 파일 복사 → backup_파일명.확장자
2. 작업 진행
3. 결과 확인 후 괜찮으면 원본 교체
```

**효과:** 실수로 인한 파일 손상을 방지합니다.

---

### 🔄 Tip 5: /clear로 새 주제 시작하기

**/clear의 장점**

```
대화 1:
> 파이썬 계산기 코드 작성해줘
> (여러 번 수정)

새로운 주제로 넘어갈 때:
> /clear

대화 2:
> HTML 웹사이트 만들어줘
> (이전 대화 맥락 없이 시작)
```

**효과:**
- 이전 대화 맥락이 지워져 더 정확해집니다
- 토큰 사용량이 줄어들어 비용 절감
- Claude가 새로운 주제에 집중합니다

---

### 📁 Tip 6: 올바른 폴더에서 시작하기

<div class="note-circle">
○ 이 팁은 터미널에서 Claude Code를 쓰시는 분들을 위한 내용이에요.
</div>

**파일 경로 오류 방지**

터미널에서 Claude Code를 쓸 때는 **작업할 폴더로 먼저 이동**한 다음 시작하세요.

```bash
# Mac 터미널 / Windows PowerShell
cd ~/Desktop/내프로젝트
claude
```

이렇게 하면 Claude가 해당 폴더의 파일들을 바로 인식합니다.

**cd 사용법:**
```bash
# 바탕화면의 "작업" 폴더로 이동
cd Desktop/작업

# 홈 폴더로 이동
cd ~

# 한 폴더 위로 이동
cd ..
```

**효과:** 파일 위치를 정확히 인식하고 오류가 줄어듭니다.

---

### ⏹️ Tip 7: Ctrl+C로 언제든 멈출 수 있어요

**작업 중단하기**

```
상황 1: AI가 잘못된 방향으로 가고 있을 때
> 파이썬 코드 만들어줘
(AI가 실행 중...)
Ctrl+C 누르기
→ 즉시 중단

상황 2: 오래 걸리는 작업을 멈추고 싶을 때
> 1000개 파일 생성 중...
Ctrl+C 누르기
→ 생성 중지
```

**안심하세요:**
- 한 번에 파일이 완전히 생성되거나 안 되거나
- 부분적으로 생성되지 않습니다
- 중단해도 이미 생성된 파일은 남아있습니다

## 🌟 가장 중요한 팁

> **틀려도 괜찮아요!**
>
> 반복해서 요청하면 점점 더 나아집니다.
> 처음부터 완벽할 필요는 없습니다.
> 시행착오를 통해 배우는 것이 클로드코드 사용의 진짜 묘미입니다.

---

## 요약: 가장 중요한 3가지

1. **구체적으로 요청하기** — 이것만 해도 결과가 확 달라져요
2. **자주 저장하고 백업하기** — 혹시 모르니까
3. **/clear로 깔끔하게** — 주제 바뀌면 정리하고 새로 시작
