## 터미널에 다마고찌가 있다고요?

네, 진짜예요! Claude Code 안에 **귀여운 디지털 펫**이 살고 있습니다.

Anthropic이 2026년 4월에 추가한 기능으로, `/buddy`를 입력하면 나만의 펫을 만날 수 있어요.

---

## 만나는 법

```
/buddy
```

이렇게 입력하면 나만의 펫이 나타납니다!

---

## 어떤 펫이 나올까?

총 **18종**의 펫이 있어요:

| 희귀도 | 확률 | 예시 |
|--------|------|------|
| **Common** (일반) | 60% | 오리, 거위, 고양이, 토끼, 달팽이, 청크 |
| **Uncommon** (비일반) | 25% | 올빼미, 펭귄, 거북이 |
| **Rare** (희귀) | 10% | 드래곤, 문어, 아홀로틀 |
| **Epic** (에픽) | 4% | 유령, 로봇, 블롭 |
| **Legendary** (전설) | 1% | 선인장, 버섯, 카피바라 |

<mark>어떤 펫이 나올지는 내 계정 ID로 결정돼요. 항상 같은 펫이 나옵니다!</mark>

---

## 펫과 놀기

```
/buddy card    ← 펫의 스탯 카드 보기
/buddy pet     ← 펫 쓰다듬기
```

### 펫 스탯 5가지

| 스탯 | 설명 |
|------|------|
| DEBUGGING | 디버깅 실력 |
| PATIENCE | 인내심 |
| CHAOS | 혼돈 성향 |
| WISDOM | 지혜 |
| SNARK | 유머/까칠함 |

각 스탯은 0~100 사이 값이에요. 내 펫이 어떤 성격인지 확인해보세요!

---

## 진지한 기능은 아닙니다 (그래도 재밌어요)

/buddy는 Anthropic이 재미로 만든 이스터에그예요. 작업에 직접적인 도움은 안 되지만, 코딩하다 지칠 때 잠깐 웃을 수 있는 요소입니다.

<div class="note-circle">
○ Claude Code 2.1.89 이상 + Pro 구독이 필요합니다.
</div>
