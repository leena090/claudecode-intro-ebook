## 플러그인이 뭔가요?

스마트폰 앱스토어에서 "사진 편집 패키지"를 하나 받으면 어떻게 되나요?

필터, 밝기 보정, 콜라주, 스티커 기능이 한꺼번에 깔려요. 하나씩 따로 찾아서 설치할 필요가 없죠.

<mark>플러그인(Plugin)</mark>이 바로 그것과 같아요. "마케팅 담당자용 스킬 묶음", "인사팀용 스킬 묶음" 이런 식으로 **내 직업에 맞는 도구들을 한 번에 받는 패키지**예요.

```
플러그인 1개 설치
    ├── 스킬 ①  카피 작성
    ├── 스킬 ②  캠페인 분석
    └── 스킬 ③  SNS 콘텐츠 기획
```

<div class="note-circle">○ 비유하자면, 플러그인은 "신입사원이 첫날 받는 업무 도구 세트"예요. 마케팅 담당자에게는 마케팅 도구 세트를, 재무 담당자에게는 재무 도구 세트를 주는 거죠.</div>

## 플러그인 vs 커넥터 — 한 줄 차이

비슷해 보이지만 두 가지는 완전히 달라요.

| 구분 | 플러그인 (스킬 묶음) | 커넥터 (외부 서비스 연결) |
|------|-------------------|-----------------------|
| **하는 일** | 새로운 능력을 클로드에 추가 | 구글 드라이브, 이메일 등 외부 서비스 연결 |
| **예시** | "캠페인 기획 도와줘" | "구글 드라이브에서 파일 찾아줘" |
| **추가 비용** | 거의 없음 | 매 대화마다 토큰 소비 발생 |
| **설치 위치** | Settings > Customize > Plugins | Settings > Customize > Connectors |

<div class="note-star">★ <strong>핵심 원칙</strong>: 플러그인은 마음껏 설치하세요. 커넥터는 꼭 필요한 것만 켜두세요. 비용 차이가 꽤 크거든요. 이 내용은 아래 7번 섹션에서 자세히 다룹니다.</div>

### 내 직업과 딱 맞는 플러그인이 없다면?

걱정하지 마세요. 기본 클로드도 충분히 강력해요. 플러그인은 해당 분야의 특화된 스킬을 **미리 준비해 두는 것**일 뿐, 없어도 같은 일을 요청할 수 있어요.

## 플러그인 설치하기 — 두 가지 방법

### 방법 1: 처음 설정할 때 (추천)

코워크를 처음 시작할 때 `/setup-cowork` 명령어를 실행하면, 어떤 분야에서 일하는지 물어봐요. 답을 하면 맞는 플러그인을 자동으로 설치해 줘요.

```
/setup-cowork
```

처음 사용하시는 분께 가장 추천하는 방법이에요.

### 방법 2: 설정 화면에서 직접 설치

나중에 추가로 설치하거나, 다른 플러그인이 필요할 때 써요.

1. 클로드 앱 오른쪽 위 **설정(톱니바퀴)** 아이콘을 클릭하세요.
2. **Customize** 메뉴를 찾아서 클릭하세요.
3. **Plugins** 탭을 선택하세요.
4. 원하는 플러그인 옆의 **"Install"** 버튼을 클릭하세요.
5. 설치 완료 메시지가 뜨면 끝이에요.

```
Settings → Customize → Plugins → 원하는 플러그인 "Install" 클릭
```

<div class="note-circle">○ 설치는 1~2초면 끝나요. 인터넷에서 큰 파일을 받는 게 아니라, 클로드에게 새로운 능력을 알려주는 거라서 매우 빨라요.</div>

## 설치된 스킬 실행하기

플러그인을 설치하면 새로운 명령어가 생겨요. `/스킬이름` 형식으로 실행하면 됩니다.

### 실전 예시 ① Marketing 플러그인

```
/campaign-brief 여름 프로모션 이메일 캠페인 기획해줘
```

클로드가 캠페인 목표, 대상 고객, 핵심 메시지, 일정 등을 담은 기획서 초안을 바로 만들어줘요.

### 실전 예시 ② Design 플러그인

```
/design-critique 이 로고 디자인 피드백 줘
```

디자인 전문 관점에서 가독성, 색상 조화, 브랜드 일관성 등을 분석해 줘요.

### 실전 예시 ③ Operations 플러그인

```
/weekly-report 이번 주 업무 보고서 만들어줘
```

이번 주에 한 일, 진행 중인 업무, 다음 주 계획을 표로 정리한 보고서를 만들어줘요.

<div class="note-star">★ <strong>팁</strong>: 스킬 이름이 기억나지 않을 때는 그냥 "/" 를 입력하면 설치된 스킬 목록이 자동으로 나와요. 스크롤해서 원하는 걸 고르면 됩니다.</div>

## 플러그인 관리하기

설치한 플러그인은 언제든지 관리할 수 있어요.

### 설치 목록 확인

```
Settings → Customize → Plugins
```

설치된 플러그인에는 체크 표시가 되어 있어요.

### 비활성화 (잠깐 꺼두기)

당장 쓸 일이 없어도 삭제하지 않아도 돼요. 비활성화만 하면 스킬 목록에 보이지 않아서 깔끔해져요.

플러그인 옆의 스위치를 **꺼두면** 비활성화예요. 다시 켜면 바로 사용할 수 있어요.

### 완전 삭제

정말 필요 없다고 판단되면 **"Remove"** 버튼으로 삭제할 수 있어요. 나중에 다시 설치할 수 있으니 부담 갖지 마세요.

### 업데이트

플러그인이 업데이트되면 설치 목록에 **"Update available"** 표시가 생겨요. 클릭하면 바로 업데이트돼요.

| 관리 방법 | 언제 쓰나요? | 다시 복구? |
|----------|------------|---------|
| **비활성화** | 잠깐 안 쓸 때 | 스위치 켜면 즉시 복구 |
| **삭제** | 완전히 필요 없을 때 | 재설치 가능 |
| **업데이트** | 새 기능이 나왔을 때 | 자동 적용 |

<div class="note-circle">○ 안 쓰는 플러그인은 삭제보다 비활성화를 추천해요. 나중에 다시 필요할 때 설치 과정 없이 바로 켤 수 있거든요.</div>

## Claude Code에서 플러그인 쓰기 (개발자용)

터미널과 명령어가 편한 개발자분들을 위한 방법이에요.

<div class="note-circle">○ 이 섹션은 개발자나 명령어 사용이 익숙한 분들을 위한 내용이에요. 일반 업무 사용자분들은 건너뛰셔도 됩니다.</div>

### Claude Code의 플러그인 탭 4가지

Claude Code에서 `/plugin` 명령어를 실행하면 4개 탭이 나와요.

| 탭 이름 | 무엇을 하는 탭인가? |
|--------|------------------|
| **Discover** | 아직 설치하지 않은 새 플러그인 탐색 |
| **Installed** | 현재 설치된 플러그인 목록 |
| **Marketplaces** | 외부 마켓플레이스 연결 및 검색 |
| **Errors** | 플러그인 오류 로그 확인 |

### 명령어로 플러그인 관리하기

```bash
# 플러그인 설치 (원하는 플러그인 이름을 입력)
/plugin install marketing

# 플러그인 비활성화
/plugin disable marketing

# 설치된 플러그인 목록 보기
/plugin list

# 플러그인 업데이트
/plugin update marketing
```

### 데스크톱 앱 vs Claude Code — 플러그인 차이

| 구분 | 데스크톱 앱 | Claude Code |
|------|-----------|------------|
| **설치 방법** | GUI 버튼 클릭 | 명령어 입력 |
| **대상 사용자** | 일반 직장인 | 개발자 |
| **플러그인 호환성** | 코워크 최적화 | 코딩 작업 최적화 |
| **추천 시작점** | Settings > Customize | `/plugin` 명령어 |

## 플러그인 vs 커넥터 — 비용 차이 정리

이건 꼭 알아두셔야 해요. 두 기능은 비용 구조가 완전히 달라요.

비유로 설명할게요. 플러그인은 **직원에게 새 업무 매뉴얼을 주는 것**이에요. 매뉴얼을 줄 때 돈이 드는 게 아니라, 직원이 실제로 일을 시작할 때 시간이 드는 거죠.

커넥터는 다달이 요금이 나오는 **외부 서비스 구독**과 같아요. 연결만 해두어도 클로드가 대화할 때마다 "어떤 외부 서비스가 연결되어 있지?" 하고 목록을 확인하는데, 이 목록 자체가 토큰을 잡아먹어요.

### 실제 토큰 소비 비교 (커넥터 기준)

| 연결된 커넥터 수 | 대화 시작 시 토큰 소비 |
|--------------|------------------|
| 0개 | 약 2,000 토큰 |
| 4개 | 약 67,000 토큰 |
| 8개 | 약 150,000 토큰 |

커넥터를 8개 연결하면, 대화 한 번 시작할 때마다 아무 일도 안 했는데 15만 토큰이 사라져요.

반면 플러그인은 스킬 파일 자체가 매우 가벼워요. 여러 개를 설치해도 추가 비용이 거의 없어요.

```
플러그인 ✅  — 마음껏 설치하세요. 비용 걱정 없어요.
커넥터  ⚠️  — 꼭 필요한 것만 연결하세요. 매 대화마다 토큰이 나가요.
```

<div class="note-star">★ <strong>절약 팁</strong>: 커넥터는 쓸 때만 켜고, 쓰지 않을 땐 비활성화해 두는 습관을 들이세요. 커넥터 비용에 대한 더 자세한 내용은 <a href="/docs/config/mcp-setup#mcp-토큰-비용-경고">MCP 비용 상세 가이드</a>에서 확인하세요.</div>
