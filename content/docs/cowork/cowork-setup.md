## 코워크 AI 비서의 3가지 도구 — 한눈에 보기

코워크를 처음 열면 낯선 단어들이 보여요. <mark>스킬</mark>, <mark>플러그인</mark>, <mark>커넥터</mark>. 셋 다 비슷해 보이지만 역할이 달라요.

요리에 비유해서 설명할게요.

- <mark>스킬(Skill)</mark> = 요리 레시피 한 장. "비빔밥 만드는 법" 한 가지 방법이에요.
- <mark>플러그인(Plugin)</mark> = 레시피 모음집. 비빔밥, 된장찌개, 잡채... 여러 레시피가 한 권에 담긴 것처럼, 여러 스킬을 묶어 놓은 꾸러미예요.
- <mark>커넥터(Connector)</mark> = 냉장고 연결. 레시피가 있어도 재료가 없으면 못 만들죠. 커넥터는 클로드가 내 이메일, 구글 드라이브 같은 외부 서비스에 직접 접근할 수 있게 연결해주는 문이에요.

| 도구 | 쉬운 설명 | 예시 |
|------|----------|------|
| **스킬** | 클로드가 할 수 있는 능력 하나 | 디자인 피드백 주기, 이메일 요약하기 |
| **플러그인** | 스킬 묶음 (한 번에 여러 능력 설치) | Design 플러그인 → 7가지 디자인 스킬 포함 |
| **커넥터** | 외부 서비스와 연결하는 통로 | Gmail, Google Drive, Microsoft 365 |

<div class="note-star">★ <strong>플러그인과 커넥터는 비용이 다릅니다!</strong> — 플러그인(스킬 묶음)은 토큰 부담이 거의 없어요. 반면 커넥터(MCP)는 연결할수록 토큰을 많이 써요. 둘을 꼭 구분해서 이해해 주세요.</div>

---

### 커넥터(MCP)는 개수가 늘수록 비용이 올라가요

<mark>커넥터(MCP)</mark>는 무조건 많이 연결한다고 좋은 게 아니에요. 연결된 커넥터 수만큼 클로드가 대화를 시작할 때마다 미리 읽어야 하는 정보가 늘어나기 때문이에요.

마치 비서한테 매일 아침 출근하자마자 100페이지짜리 매뉴얼을 읽히는 것과 같아요. 커넥터가 많을수록 그 매뉴얼이 두꺼워지는 거예요.

| 커넥터 수 | 대화당 소비 토큰 | 체감 |
|-----------|----------------|------|
| 0개 | 약 2,000 토큰 | 부담 없음 |
| 4개 | 약 67,000 토큰 | 33배 증가 |
| 8개 | 약 150,000 토큰 | 75배 증가 |

<div class="note-star">★ <strong>커넥터는 꼭 필요한 2~3개만 연결하세요.</strong> 지금 당장 쓰지 않는 서비스는 연결하지 않는 게 좋아요. 나중에 필요하면 언제든 추가할 수 있어요. 자세한 비용 안내는 <a href="/docs/config/mcp-setup#mcp-토큰-비용-경고">MCP 토큰 비용 경고 페이지</a>를 참고해 주세요.</div>

## 1단계: 내 직업 선택하기

코워크 첫 설정의 시작은 "나는 어떤 일을 하는 사람인가?"를 클로드에게 알려주는 거예요.

직업을 선택하면 클로드가 내 업무에 맞는 플러그인을 자동으로 추천해줘요. 마치 새로 들어온 비서가 "어떤 일을 주로 하세요?"라고 먼저 묻는 것처럼요.

### 설정 방법 두 가지

**방법 ①: 명령어 사용**

코워크 입력창에 아래 명령어를 입력하세요.

```
/setup-cowork
```

설정 마법사가 시작되면서 직업을 선택하는 화면이 나와요.

**방법 ②: 설정 메뉴 사용**

1. 클로드 앱 오른쪽 위 설정 아이콘(⚙️)을 클릭하세요.
2. **Customize** 또는 **맞춤 설정** 메뉴를 찾으세요.
3. **직업(Occupation)** 항목에서 해당 직업을 고르세요.

### 선택할 수 있는 직업 14가지

| 영문 이름 | 한국어 설명 |
|----------|-----------|
| Product management | 제품 기획·관리 담당자 |
| Engineering | 개발자·엔지니어 |
| Human resources | 인사·채용 담당자 |
| Finance | 재무·회계 담당자 |
| Marketing | 마케팅 담당자 |
| Sales | 영업 담당자 |
| Operations | 운영·총무 담당자 |
| Data science | 데이터 분석가 |
| Design | 디자이너 |
| Scientist | 연구원·과학자 |
| Legal | 법무·법률 담당자 |
| Student | 학생 |
| Founder | 창업자·1인 사업자 |
| Healthcare | 의료·보건 종사자 |

<div class="note-circle">○ 정확히 내 직업과 맞지 않아도 괜찮아요. 가장 비슷한 것을 고르세요. 나중에 언제든지 바꿀 수 있고, 직접 원하는 플러그인을 추가하는 것도 가능합니다.</div>

## 2단계: 추천 플러그인 설치하기

직업을 선택하면 클로드가 "이런 플러그인이 도움이 될 것 같아요"라며 맞춤 추천을 해줘요.

레스토랑에서 셰프가 "오늘 이 메뉴 강추예요"라고 말해주는 것처럼, 내 직업에 어울리는 스킬 꾸러미를 한꺼번에 알려주는 거예요.

### 예시: Design 직업을 선택했을 때

Design을 선택하면 아래와 같은 플러그인이 추천돼요.

**Design 플러그인 (7가지 스킬 포함)**

| 스킬 이름 | 무슨 일을 해주나요? |
|----------|------------------|
| 디자인 피드백 | 디자인을 보고 개선 의견 제안 |
| UX 카피 작성 | 앱·웹의 버튼, 안내 문구 작성 |
| 접근성 감사 | 장애인도 쓸 수 있는지 확인 |
| 사용자 리서치 | 인터뷰 질문·설문 설계 |
| 개발 핸드오프 | 개발자에게 넘길 디자인 명세 작성 |
| 경쟁사 분석 | 다른 서비스의 디자인 패턴 분석 |
| 컬러 시스템 제안 | 브랜드에 맞는 색상 팔레트 추천 |

### 플러그인 설치 방법

1. 추천 플러그인 화면에서 설치하고 싶은 플러그인을 찾으세요.
2. 플러그인 이름 옆의 **"Add"** 또는 **"추가"** 버튼을 클릭하세요.
3. 버튼 하나로 그 안의 모든 스킬이 한꺼번에 설치돼요.
4. 설치 완료 메시지가 뜨면 끝이에요.

### 설치 후 바로 써보기

플러그인을 설치하고 나면, 스킬 이름 앞에 `/` (슬래시)를 붙여서 바로 쓸 수 있어요.

```
/디자인피드백 이 버튼 레이아웃 어때?
```

```
/UX카피 로그인 버튼 문구 3가지 만들어줘
```

<div class="note-circle">○ 플러그인은 토큰 부담이 거의 없어요. 커넥터와 다르게, 필요해 보이는 플러그인은 부담 없이 설치해도 됩니다. 안 쓰게 되면 나중에 제거하면 돼요.</div>

## 3단계: 커넥터 연결하기 (선택)

<mark>커넥터(Connector)</mark>는 클로드가 내 외부 서비스에 직접 접근할 수 있게 해주는 기능이에요.

지금까지는 파일을 직접 열어서 클로드에게 보여줘야 했는데, 커넥터를 연결하면 클로드가 알아서 내 Gmail이나 구글 드라이브에서 자료를 가져올 수 있어요.

<div class="note-star">★ <strong>커넥터는 선택 사항입니다.</strong> 처음 세팅할 때는 건너뛰어도 돼요. 기본 기능만으로도 충분히 쓸 수 있고, 필요해지면 그때 추가하면 됩니다.</div>

### 커넥터 연결 방법

1. 클로드 앱 오른쪽 위 설정 아이콘(⚙️)을 클릭하세요.
2. **Connectors** 또는 **커넥터** 메뉴를 찾으세요.
3. **"Browse connectors"** 또는 **"커넥터 찾아보기"** 를 클릭하세요.
4. 연결하고 싶은 서비스를 고르세요.
5. **"Connect"** 버튼을 클릭하면 로그인 창이 열려요 (OAuth 인증).
6. 해당 서비스 계정으로 로그인하고 "허용"을 클릭하면 연결 완료예요.

### 커넥터 종류: 웹 방식 vs 데스크톱 방식

커넥터는 크게 두 가지로 나뉘어요.

| 구분 | 웹 커넥터 | 데스크톱 확장 |
|------|----------|-------------|
| 연결 방식 | 인터넷을 통해 연결 | 내 컴퓨터에 직접 설치 |
| 예시 | Gmail, Google Drive, Zoom | 로컬 파일 시스템 접근 |
| 설치 위치 | 브라우저 API 기반 | 데스크톱 앱 내 설치 |
| 주의할 점 | 인터넷 연결 필요 | 컴퓨터가 켜져 있어야 동작 |

<div class="note-star">★ <strong>커넥터 비용 다시 한번 확인!</strong> — 커넥터를 1개 연결할 때마다 대화당 토큰 소비가 크게 늘어나요. 지금 당장 필요한 것만, 최대 2~3개만 연결하는 것을 강력히 추천드립니다.</div>

## 4단계: 작업 환경 마무리

직업 선택, 플러그인 설치, 커넥터 연결까지 마쳤다면 마지막으로 설정이 제대로 됐는지 확인해볼 시간이에요.

### 진행 상황 패널에서 확인하기

코워크 화면 오른쪽에 <mark>진행 상황 패널(Progress Panel)</mark>이 있어요. 여기서 지금까지 설정한 내용을 한눈에 볼 수 있어요.

- 선택한 직업이 표시되는지 확인하세요.
- 설치된 플러그인 목록이 보이는지 확인하세요.
- 연결된 커넥터 목록이 있다면 거기서도 확인하세요.

### 나중에 설정을 바꾸고 싶을 때

언제든지 다시 설정을 바꿀 수 있어요.

1. 클로드 앱 오른쪽 위 설정 아이콘(⚙️) 클릭
2. **Customize** 또는 **맞춤 설정** 클릭
3. 원하는 항목을 수정하고 저장하세요.

<div class="note-circle">○ 설정을 바꿔도 이전에 나눈 대화 내용은 사라지지 않아요. 언제든지 마음대로 조정할 수 있으니, 처음부터 완벽하게 맞출 필요는 없어요.</div>

## 설정 끝! 바로 써보기

세팅이 끝났다면 바로 써봐요. 설치한 스킬을 처음 쓸 때 어떻게 불러내는지 예시를 보여드릴게요.

### 예시 ① 이메일 초안 작성 스킬 사용하기

```
/이메일작성
수신자: 거래처 담당자
내용: 다음 주 월요일 오전 미팅 일정 확인 요청
톤: 정중하고 간결하게
```

클로드가 바로 이메일 초안을 만들어줘요. 마음에 들면 복사해서 바로 쓰면 되고, 아니면 "좀 더 부드럽게 고쳐줘"라고 하면 돼요.

### 예시 ② 데이터 요약 스킬 사용하기

```
/데이터요약
이번 달 판매 실적이 담긴 파일이야.
핵심 수치 3가지를 뽑아서 한 문단으로 요약해줘.
```

### 예시 ③ 스킬 이름을 모를 때

스킬 이름이 기억 안 나도 괜찮아요. 그냥 하고 싶은 일을 말하면 클로드가 맞는 스킬을 찾아서 써줘요.

```
오늘 받은 이메일들 요약해줘.
구글 드라이브에 있는 지난달 보고서 찾아서 핵심만 뽑아줘.
다음 주 발표 자료 피드백 해줘.
```

<div class="note-circle">○ `/`로 시작하는 명령어가 딱딱하게 느껴진다면, 평소 말하듯이 그냥 입력해도 돼요. 클로드는 일반 대화도 잘 이해해요.</div>

## 나중에 추가하거나 빼고 싶을 때

한 번 설정했다고 끝이 아니에요. 업무가 바뀌거나 새로운 필요가 생기면 언제든지 수정하면 돼요.

### 플러그인 추가·삭제하기

1. 설정 아이콘(⚙️) → **Customize** 또는 **맞춤 설정** 클릭
2. **플러그인(Plugins)** 섹션에서 추가하거나 삭제하세요.
3. 추가는 "Add" 버튼, 삭제는 "Remove" 또는 "X" 버튼이에요.

### 커넥터 추가·삭제하기

1. 설정 아이콘(⚙️) → **Connectors** 또는 **커넥터** 클릭
2. 연결하고 싶은 서비스를 찾아서 연결하거나, 기존 연결을 끊으세요.

### 정리할 때 기억할 것

| 상황 | 추천 행동 |
|------|---------|
| 잘 안 쓰는 커넥터가 생겼다 | 바로 삭제하세요 (비용 절감) |
| 업무가 달라졌다 | 직업 재선택 + 플러그인 재추천 받기 |
| 쓰고 싶은 플러그인이 추천 목록에 없다 | "플러그인 찾아보기"에서 직접 검색 |
| 커넥터를 더 추가하고 싶다 | 토큰 비용 확인 후 신중하게 결정 |

<div class="note-circle">○ 플러그인은 마음껏 바꿔도 괜찮지만, 커넥터는 추가할 때마다 비용이 올라간다는 것, 잊지 마세요. "적게, 꼭 필요한 것만" 이 원칙을 지키면 낭비 없이 쓸 수 있어요.</div>
