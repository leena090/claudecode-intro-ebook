## 반복 업무를 클로드에게 맡기면 어떨까요?

매일 하는 일이 있으신가요?

아침마다 뉴스를 확인하고 팀에 공유하는 일. 매주 월요일 주간 보고서 초안 잡는 일. 매달 말 경비 정산을 정리하는 일.

이런 일들은 중요하지만, 솔직히 매번 하기가 피곤하죠.

<mark>예약 작업(Scheduled Tasks)</mark>은 이런 반복 업무를 클로드에게 완전히 넘길 수 있는 기능이에요.

한 번 설정해두면, 내가 아무것도 안 해도 클로드가 알아서 정해진 시간에 일을 처리해요.

---

## 예약 작업 설정하는 방법

코워크 탭을 열고 이렇게 하면 돼요.

1. 코워크 입력창 근처에 있는 **"예약"** 또는 **"스케줄"** 버튼을 찾으세요.
2. 클릭하면 작업 설정 화면이 나와요.
3. 아래 내용을 채워요.

**설정 항목**

| 항목 | 예시 |
|------|------|
| 작업 이름 | 아침 뉴스 요약 |
| 반복 주기 | 매일 / 매주 / 매달 / 한 번만 |
| 실행 시간 | 오전 8시 30분 |
| 무슨 일을 할지 | 구체적으로 적기 |

<div class="note-circle">○ 예약 작업도 Dispatch처럼 컴퓨터가 켜져 있어야 실행돼요. 사무실 컴퓨터라면 절전 모드를 해제해두는 게 좋아요.</div>

---

## 실전 예시 ① 매일 오전 9시 뉴스 요약

**이런 분께 추천**: 팀장이나 관리직, 트렌드를 빠르게 파악해야 하는 분

**설정 방법:**

코워크 예약 설정 화면에 이렇게 입력하세요.

```
[매일 오전 9시 실행]

크롬을 열고 네이버 뉴스에 접속해서
오늘 IT·경제 카테고리의 주요 뉴스 5개를 골라줘.
각 뉴스의 제목, 한 줄 요약, 링크를 정리해서
바탕화면에 있는 "오늘의뉴스.txt" 파일에 저장해줘.
날짜도 같이 써줘.
```

**결과**: 매일 아침 9시에 사무실 컴퓨터가 뉴스를 정리해 놓아요. 출근해서 파일 열면 오늘의 핵심 뉴스가 기다리고 있어요.

---

## 실전 예시 ② 매주 월요일 주간 보고서 초안

**이런 분께 추천**: 매주 보고서를 올려야 하는 팀원, 팀장

**설정 방법:**

```
[매주 월요일 오전 7시 실행]

지난주 폴더(Desktop/주간보고/지난주/)에 있는
모든 파일의 내용을 요약해줘.
그리고 아래 형식으로 주간 보고서 초안을 작성해서
Desktop/주간보고/이번주보고서초안.docx로 저장해줘.

--- 보고서 형식 ---
1. 이번 주 완료한 일
2. 다음 주 계획
3. 이슈 및 요청사항
```

**결과**: 월요일 아침 출근 전에 초안이 완성되어 있어요. 내용만 조금 다듬으면 바로 제출할 수 있어요.

---

## 실전 예시 ③ 매달 1일 경비 정산 정리

**이런 분께 추천**: 경비 처리를 직접 하시는 분, 소규모 사업주

**설정 방법:**

```
[매달 1일 오전 8시 실행]

Desktop/경비영수증/ 폴더에 있는
이미지 파일들(영수증 스캔본)을 확인하고,
날짜·항목·금액을 읽어서
Desktop/경비정산.xlsx 파일에 표로 정리해줘.
합계도 맨 아래에 넣어줘.
```

**결과**: 매달 1일 아침, 지난 달 경비가 자동으로 엑셀에 정리돼요. 회계 담당자에게 바로 보낼 수 있는 상태로요.

## 예약 작업 관리하기

설정한 예약 작업을 보거나 수정하고 싶을 때는 어떻게 할까요?

코워크 탭 상단에 **"예약된 작업"** 또는 **"작업 목록"** 버튼이 있어요. 클릭하면 설정된 작업들이 목록으로 보여요.

**할 수 있는 것들:**
- 작업 일시 중지 (잠깐 멈추고 싶을 때)
- 작업 수정 (내용을 바꾸고 싶을 때)
- 작업 삭제 (더 이상 필요 없을 때)
- 지금 바로 실행 (예약 시간 전에 미리 돌려보고 싶을 때)

---

## 예약 작업 잘 만들기 위한 팁

**구체적으로 적을수록 좋아요**

이렇게 막연하게 쓰면 안 돼요.
```
❌ 매일 보고서 만들어줘
```

이렇게 구체적으로 써야 해요.
```
✅ 매일 오전 8시에 Desktop/데이터.xlsx 파일을 열고,
   A열 기준으로 정렬한 다음,
   첫 번째 행에 오늘 날짜를 입력하고 저장해줘.
```

**처음엔 한 번 테스트해보세요**

예약 작업을 설정하기 전에, 같은 내용을 일반 코워크로 먼저 한 번 해보세요. 클로드가 제대로 이해하는지 확인한 다음 예약으로 전환하면 실수가 줄어요.

<div class="note-circle">○ 예약 작업이 실패하면 스마트폰으로 알림이 와요. 오류 메시지를 확인하고 코워크 탭에서 내용을 조금 수정한 다음 다시 시도해보세요.</div>

## 예약 작업이 특히 빛나는 상황

| 언제? | 무슨 작업? |
|-------|----------|
| 출근 전 | 오늘 할 일 목록 정리 |
| 점심시간 | 오전 업무 내용 자동 요약 |
| 퇴근 후 | 내일 아침 회의 자료 준비 |
| 매주 금요일 | 이번 주 업무 성과 정리 |
| 매달 말 | 월별 통계 리포트 생성 |
