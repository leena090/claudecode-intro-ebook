## 클로드가 내 구글, 이메일까지 쓸 수 있다면?

지금까지 배운 건 클로드가 내 컴퓨터 파일을 직접 다루는 거였어요.

근데 요즘 업무는 컴퓨터 파일만이 아니죠. 구글 드라이브에 저장된 파일, 받은 이메일, 온라인 문서들도 있어요.

<mark>커넥터(Connectors)</mark>는 클로드를 이런 외부 서비스들과 연결해주는 기능이에요.

구글 드라이브에 있는 파일을 열어달라고 하면, 클로드가 직접 구글 드라이브에 접속해서 파일을 열어줘요. 이메일을 읽고 답장을 써달라고 하면, 클로드가 이메일을 열어서 내용을 분석하고 답장을 작성해줘요.

```
[이전]  내가 구글 드라이브 접속 → 파일 다운로드 → 클로드에게 붙여넣기
[이후]  "구글 드라이브에서 지난달 보고서 찾아줘" → 클로드가 직접 접속해서 찾아줌
```

## 연결할 수 있는 서비스들

코워크에서 현재 연결 가능한 주요 서비스예요.

| 서비스 | 할 수 있는 일 |
|--------|-------------|
| **Google Drive** | 파일 열기, 검색, 편집, 새 파일 만들기 |
| **Gmail** | 이메일 읽기, 답장 작성, 분류, 검색 |
| **Microsoft 365** | Word/Excel/PowerPoint 온라인 파일 작업 |
| **OneDrive** | MS 클라우드 파일 접근 |
| **SharePoint** | 회사 문서 시스템 접근 |
| **DocuSign** | 전자 서명 문서 처리 |
| **Zoom** | 회의 요약, 액션 아이템, 녹취록 접근 *(2026-04 신규)* |

## 구글 드라이브 연결하기

### 연결 방법

1. 코워크 탭에서 **설정** 또는 **커넥터** 버튼을 찾으세요.
2. 연결 가능한 서비스 목록에서 **Google Drive**를 찾아 클릭하세요.
3. **"연결하기"** 버튼을 누르면 구글 로그인 창이 열려요.
4. 구글 계정으로 로그인하고, 클로드가 드라이브에 접근하도록 **"허용"** 을 클릭하세요.
5. 연결 완료! 이제 클로드가 내 구글 드라이브를 쓸 수 있어요.

### 구글 드라이브로 할 수 있는 일들

**파일 찾기**
```
구글 드라이브에서 "2025년 4분기 보고서" 파일 찾아줘.
```

**파일 요약하기**
```
구글 드라이브에 있는 "회의록_3월.docx" 파일 열어서
핵심 내용 5줄로 요약해줘.
```

**새 파일 만들기**
```
구글 드라이브에 "4월 예산안"이라는 새 구글 시트를 만들고,
아래 항목들을 A열에 넣어줘:
인건비, 임대료, 마케팅비, 운영비, 기타
```

**공유 폴더 파일 정리**
```
구글 드라이브 "팀 공유 폴더"에 있는
파일들의 이름과 수정 날짜 목록을 만들어줘.
```

## Gmail 연결하기

### 연결 방법

구글 드라이브 연결과 같은 방식이에요. 커넥터 목록에서 **Gmail**을 선택하고 로그인하면 돼요.

<div class="note-circle">○ 구글 드라이브와 Gmail은 같은 구글 계정이라도 별도로 허용해야 해요. 두 서비스 모두 연결하려면 각각 "허용"을 클릭해야 합니다.</div>

### Gmail로 할 수 있는 일들

**받은 메일 요약하기**
```
오늘 받은 이메일 중 읽지 않은 것들을
발신자, 제목, 핵심 내용 한 줄로 요약해줘.
```

**이메일 작성하기**
```
김철수 부장님(kim@company.com)에게 이메일 써줘.
내용: 내일 오전 10시 회의 참석 가능한지 확인하는 내용.
정중하고 짧게.
```

**이메일 분류 및 정리**
```
받은 편지함에서 "배송 완료" 관련 이메일들을
"배송완료" 라벨로 분류해줘.
```

**특정 이메일 찾기**
```
지난 달에 홍길동 대리에게서 온 이메일 중에
"계약서" 관련된 것 찾아줘.
```

## Microsoft 365 연결하기

회사에서 마이크로소프트 제품을 쓰신다면 이 연결이 특히 유용해요.

### 연결 방법

1. 커넥터 목록에서 **Microsoft 365**를 선택하세요.
2. **"연결하기"** 클릭 → 마이크로소프트 계정 로그인 창이 열려요.
3. 회사 이메일 또는 개인 MS 계정으로 로그인하세요.
4. 접근 권한 허용 화면에서 **"수락"** 을 클릭하세요.

### M365로 할 수 있는 일들

**OneDrive에서 파일 작업**
```
OneDrive에 있는 "팀프로젝트" 폴더에서
이번 달 파일들 목록을 보여줘.
```

**SharePoint 문서 접근**
```
우리 회사 SharePoint에서
"인사팀" 사이트에 있는 문서 목록을 보여줘.
```

**온라인 Excel 작업**
```
OneDrive의 "매출현황.xlsx" 파일 열어서
1분기 합계를 구해줘.
```

## 실전 시나리오: 이메일 + 드라이브 통합 작업

이 두 서비스를 함께 쓰면 정말 강력해져요.

**상황**: 고객에게 받은 이메일에서 요청 사항을 뽑아서 구글 시트에 정리해야 해요.

```
1. 오늘 받은 이메일 중 제목에 "문의" 또는 "요청"이 들어간 것을 모두 찾아줘.
2. 각 이메일에서 발신자 이름, 요청 내용 한 줄 요약, 날짜를 뽑아줘.
3. 구글 드라이브에 "고객요청정리.xlsx" 파일을 만들고
   위 내용을 표로 정리해줘.
4. 완료되면 알려줘.
```

전에는 이메일 하나하나 열어서 읽고, 복사해서 엑셀에 붙여넣기 하는 작업이었어요. 이제는 클로드가 알아서 다 해줘요.

## 보안 및 개인 정보 관련 궁금한 점

**Q. 클로드가 내 이메일을 다 읽나요?**
작업을 지시할 때만, 그 작업에 필요한 이메일만 읽어요. 항상 감시하는 게 아니에요.

**Q. 구글 계정 비밀번호를 클로드가 알게 되나요?**
아니에요. 비밀번호 자체는 클로드에 저장되지 않아요. 구글이 "이 앱한테 접근 허가했다"는 표시만 클로드에 전달해요. 나중에 허가를 취소하면 바로 연결이 끊깁니다.

**Q. 나중에 연결을 끊고 싶으면요?**
언제든지 끊을 수 있어요. 클로드 코워크 설정에서 커넥터를 해제하거나, 구글/마이크로소프트 계정의 "연결된 앱" 설정에서 Claude를 삭제하면 돼요.

<div class="note-circle">○ 처음 연결할 때 어떤 권한을 허용하는지 꼭 확인해 보세요. 필요한 것만 허용하는 게 좋아요. 나중에 더 추가하거나 줄일 수 있어요.</div>

## DocuSign 연결하기

전자 서명이 필요한 업무를 하신다면 DocuSign 연결도 유용해요.

커넥터 목록에서 **DocuSign**을 선택하고 계정을 연결하면, 클로드가 서명 요청 상태 확인, 서명 대기 문서 목록 조회 등을 도와줄 수 있어요.

```
DocuSign에서 아직 서명을 못 받은 계약서가 몇 개 있는지
확인하고 목록으로 보여줘.
```

## 커넥터를 잘 활용하는 팁

**필요한 것만 연결하세요**
모든 서비스를 다 연결할 필요는 없어요. 자주 쓰는 서비스 1~2개만 연결해서 시작해보세요.

**구체적인 지시가 중요해요**
연결만 하면 끝이 아니에요. 어떤 파일을, 무엇을 위해, 어떻게 처리할지 구체적으로 알려줘야 해요.

**처음엔 읽기 작업부터 시작해보세요**
"이 이메일 요약해줘", "이 파일 내용 보여줘" 같은 읽기 작업부터 시작하면 안전하게 익힐 수 있어요.
