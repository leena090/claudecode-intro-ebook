## 프로젝트가 왜 필요한가요?

책상 서랍이 하나밖에 없다고 상상해 보세요.

회계 영수증, 고객 명함, 직원 계약서, 이번 달 홍보 계획서가 전부 그 서랍 안에 뒤섞여 있어요. 무언가 찾으려면 매번 전부 뒤져야 하고, 중요한 서류가 어디 갔는지 헷갈리기 시작해요.

<mark>프로젝트(Projects)</mark>는 클로드한테도 똑같이 적용되는 개념이에요.

프로젝트가 없으면, 재고 관리 얘기를 하다가 SNS 포스팅 얘기를 하다가 매출 정산 얘기를 하다가 — 모든 대화가 하나의 공간에 뒤섞여요. 클로드도 맥락을 혼동하기 쉽고, 나도 "어디서 그 얘기를 했더라" 하며 찾아 헤매게 돼요.

**프로젝트 = 업무별로 서류함을 나누는 것**이에요.

재고 관리용 서류함, SNS 마케팅용 서류함, 매출 정산용 서류함. 각자 따로 있으니 깔끔하게 관리되죠.

---

## 프로젝트 안에 뭐가 들어가나요?

프로젝트는 단순한 폴더가 아니에요. 프로젝트마다 <mark>독립된 AI 업무 공간</mark>이 따로 생겨요.

각 프로젝트에는 아래 다섯 가지가 독립적으로 들어갈 수 있어요.

| 항목 | 설명 | 예시 |
|------|------|------|
| **대화 기록** | 그 프로젝트에서 나눈 대화만 모아서 보여요 | "이번 달 발주서 만들어줘" 같은 대화들 |
| **지시사항** | 프로젝트별로 클로드의 성격과 역할을 따로 설정해요 | "항상 존댓말로, 결과는 표로 정리해줘" |
| **파일** | 그 프로젝트에서만 쓰는 전용 파일을 연결해요 | 재료현황.xlsx, 고객연락처.xlsx |
| **예약 작업** | 그 프로젝트 안에서만 실행되는 자동화 일정이에요 | "매일 저녁 9시 재고 점검" |
| **커넥터** | 그 프로젝트에서만 연결해서 쓰는 외부 서비스예요 | Gmail, 구글 드라이브 |

<div class="note-circle">○ 프로젝트 A의 파일은 프로젝트 B에서 보이지 않아요. 각 프로젝트는 완전히 독립된 공간이에요. 섞일 걱정 없이 각자의 업무에 집중할 수 있어요.</div>

## 프로젝트 만들기 — 3분이면 충분해요

### 1단계: 코워크 탭 열기

클로드 데스크톱 앱 상단에서 **Cowork** 탭을 클릭하세요.

### 2단계: 새 프로젝트 만들기

코워크 화면 왼쪽 사이드바를 보면 **"+ 새 프로젝트"** 버튼이 있어요. 클릭하세요.

### 3단계: 이름 짓기

프로젝트 이름을 정해요. 짧고 명확하게 지으면 나중에 찾기 쉬워요.

```
좋은 예: "빵집 재고관리", "SNS 마케팅", "매출 정산"
나쁜 예: "업무1", "기타", "새 프로젝트"
```

### 4단계: 지시사항 설정하기 (선택)

이 프로젝트에서 클로드가 어떻게 행동할지 미리 알려줄 수 있어요.

예를 들어, 재고 관리 프로젝트라면 이렇게 써두는 거예요.

```
이 프로젝트에서는 발주 기준표를 참고해서
항상 결과를 표로 정리해줘.
재고량이 기준치 아래로 내려간 항목은
빨간색으로 표시해줘.
```

한 번 써두면 이 프로젝트에서 나누는 모든 대화에 자동으로 적용돼요.

### 5단계: 파일 연결하기 (선택)

이 프로젝트에서 자주 참고할 파일을 미리 연결해 두면 편리해요.

파일 연결 버튼을 눌러서 엑셀 파일, 한글 문서, PDF 등을 업로드하거나 연결하면 돼요.

<div class="note-star">★ 지시사항과 파일은 나중에도 언제든지 추가하거나 수정할 수 있어요. 처음에 완벽하게 만들려고 오래 걸릴 필요 없어요. 일단 이름만 짓고 시작해도 됩니다.</div>

## claude.ai에서 쓰던 프로젝트 가져오기

이미 웹 브라우저에서 claude.ai를 쓰고 계셨다면, 거기서 만들어둔 <mark>프로젝트(Projects)</mark>가 있을 수 있어요.

좋은 소식은, 클로드 데스크톱 앱을 열면 claude.ai의 프로젝트가 **자동으로 보여요**. 별도로 가져오는 과정이 필요 없어요.

다만, 정확히 무엇이 넘어오고 무엇이 넘어오지 않는지 알아두면 편리해요.

| 항목 | 자동으로 보임 | 참고 사항 |
|------|:----------:|----------|
| 프로젝트 이름 | O | 동일하게 표시돼요 |
| 지시사항 (커스텀 지침) | O | 그대로 유지돼요 |
| 업로드했던 파일 | O | 연결된 파일도 보여요 |
| 대화 기록 | O | 이전 대화도 확인 가능해요 |
| 예약 작업 | X | 데스크톱 앱에서 새로 설정해야 해요 |
| 커넥터 설정 | X | 데스크톱 앱에서 다시 연결해야 해요 |

<div class="note-circle">○ 처음 데스크톱 앱을 열었을 때 "내 프로젝트가 안 보인다"고 느껴지면, 앱이 완전히 로그인되었는지 확인해 보세요. 인터넷 연결이 잠깐 느릴 경우 불러오는 데 몇 초가 걸릴 수 있어요.</div>

## 스마트폰에서 프로젝트 전환하기

Dispatch를 배우셨다면, 스마트폰에서도 프로젝트를 전환하면서 쓸 수 있다는 게 아주 편리하다는 걸 금방 느끼실 거예요.

스마트폰 클로드 앱을 열고 Cowork 탭을 보면, 상단 또는 사이드에 **프로젝트 선택** 버튼이 있어요. 원하는 프로젝트를 탭하면 바로 전환돼요.

실제로 하루가 어떻게 바뀌는지 볼게요.

**빵집 사장님의 하루**

| 시간대 | 전환할 프로젝트 | 보내는 메시지 |
|--------|--------------|------------|
| 출근길 오전 8시 | "재고관리" 프로젝트 | "오늘 발주해야 할 재료 목록 확인해줘" |
| 점심시간 | "SNS 마케팅" 프로젝트 | "오늘 인스타 포스팅 초안 만들어줘" |
| 퇴근 전 | "매출 정산" 프로젝트 | "오늘 매출 정리해서 요약해줘" |

서로 다른 업무인데, 같은 폰 하나로 다 처리돼요. 그것도 컨텍스트가 섞일 걱정 없이요.

<div class="note-circle">○ 프로젝트를 전환하면 이전 프로젝트의 대화 기록, 파일, 지시사항이 모두 바뀌어요. 재고관리 프로젝트에서 쓰던 엑셀 파일이 SNS 마케팅 대화에 갑자기 튀어나오지 않아요.</div>

## 실전 예시: 빵집 사장님의 프로젝트 3개

직접 보는 게 가장 이해가 빠르죠. 동네 빵집을 운영하는 박 사장님의 이야기를 보겠습니다.

박 사장님은 매일 세 가지 고민이 있어요.

첫째, 밀가루·버터·설탕 같은 재료가 얼마나 남았는지 파악하고 제때 발주하는 일.  
둘째, 손님들이 자꾸 "SNS에서 봤어요"라고 오는데, SNS 게시물 만들 시간이 없는 일.  
셋째, 하루 끝에 매출이 얼마인지, 재료비가 얼마인지 정산하는 일.

세 가지 일을 한 대화에서 섞어서 하면 클로드가 헷갈릴 수 있어요. 박 사장님은 프로젝트를 3개로 나눴어요.

---

### 프로젝트 1: "재고관리"

**지시사항 설정:**
```
나는 동네 빵집 사장이야.
재료 발주 기준표와 공급처 연락처 파일을 항상 참고해줘.
재고 현황을 알려줄 땐 항상 표로 정리해줘.
기준량 아래로 떨어진 재료는 ⚠️ 표시를 붙여줘.
```

**연결된 파일:**
- 재료현황.xlsx (현재 재고량)
- 발주기준표.xlsx (언제 얼마나 발주할지 기준)
- 공급처연락처.xlsx (어느 업체에 주문할지)

**예약 작업:**  
매일 저녁 9시, 재고 현황을 자동으로 점검하고 내일 아침 발주할 목록을 정리해둬요.

**실제 대화 예시:**
```
박 사장님: "밀가루 현황 어때?"

클로드: 현재 재료 현황입니다.

| 재료 | 현재 재고 | 발주 기준 | 상태 |
|------|---------|---------|------|
| 밀가루 | 5kg | 10kg | ⚠️ 발주 필요 |
| 버터 | 3kg | 2kg | 정상 |
| 설탕 | 8kg | 5kg | 정상 |

밀가루는 내일 아침 한국제분 업체에 20kg 발주하시면 됩니다.
연락처: 010-XXXX-XXXX
```

---

### 프로젝트 2: "SNS 마케팅"

**지시사항 설정:**
```
우리 빵집 SNS 담당이야.
톤앤매너: 동네 빵집 느낌, 따뜻하고 친근하게.
해시태그는 #동네빵집 #수제빵 #오늘의빵 을 기본으로 넣어줘.
너무 광고스럽지 않게, 이웃집 언니가 쓴 것처럼 써줘.
```

**연결된 파일:**
- 메뉴목록.xlsx (현재 판매 중인 빵 종류와 가격)
- 이벤트달력.xlsx (이번 달 할인·이벤트 일정)

**예약 작업:**  
매주 월요일·수요일·금요일 오전 7시, 그날 올릴 인스타 게시물 초안을 자동으로 작성해둬요.

**실제 대화 예시:**
```
박 사장님: "오늘 쑥크림빵이 새로 나왔어. 인스타 게시물 써줘."

클로드: 

봄이 왔나봐요 🌿

오늘부터 쑥크림빵이 나왔어요.
봄 들판 향기 가득 담은 진한 쑥 크림이
버터 향 폭신한 빵 안에 쏙 들어갔답니다.

매일 아침 직접 담는 크림이라,
오전 중에 다 팔릴 때도 있어요.
오늘 지나가다 들르신다면 꼭 드셔보세요!

#동네빵집 #수제빵 #오늘의빵 #쑥크림빵 #봄빵
```

---

### 프로젝트 3: "매출 정산"

**지시사항 설정:**
```
우리 빵집 회계 담당이야.
매출 정산할 때 재료비·인건비·기타 비용 항목별로 구분해줘.
월별 비교 차트나 표를 반드시 포함해줘.
부가세 계산도 자동으로 해줘.
```

**연결된 파일:**
- 매출정산표.xlsx (날짜별 매출 기록)
- 비용항목.xlsx (고정비, 변동비 목록)

**예약 작업:**  
매일 밤 10시, 그날 매출을 정리해요. 매주 일요일 밤, 주간 리포트를 만들어요. 매달 말일, 월간 정산 리포트를 만들어요.

**실제 대화 예시:**
```
박 사장님: "이번 주 매출 어때?"

클로드: 이번 주(4/7~4/13) 매출 요약입니다.

| 구분 | 금액 |
|------|------|
| 총 매출 | 1,240,000원 |
| 재료비 | 372,000원 (30%) |
| 인건비 | 248,000원 (20%) |
| 기타 비용 | 62,000원 (5%) |
| **순이익** | **558,000원 (45%)** |

지난주 대비 +8.5% 상승했어요.
토요일 쑥크림빵 판매가 특히 좋았습니다.
```

---

### 세 프로젝트가 서로 방해하지 않아요

중요한 점은, 이 세 프로젝트가 완전히 독립되어 있다는 거예요.

"재고관리" 프로젝트에서 "밀가루 발주 기준표" 얘기를 해도, "SNS 마케팅" 프로젝트에서는 그 내용이 전혀 보이지 않아요. 클로드가 SNS 글을 쓸 때 재고 데이터를 섞어서 헷갈리게 만들 일이 없어요.

마치 세 명의 직원을 따로 고용한 것처럼, 각자 자기 업무만 딱 집중해서 처리해요.

## 프로젝트 관리 팁

### 이름은 짧고 명확하게

나중에 스마트폰에서 빠르게 찾아야 할 때, 이름이 명확해야 바로 탭할 수 있어요.

| 좋은 이름 | 나쁜 이름 |
|---------|---------|
| 재고관리 | 업무1 |
| SNS 마케팅 | 마케팅관련 |
| 매출 정산 | 기타 |
| 고객 응대 | 새 프로젝트(3) |

### 새 프로젝트를 만들 때 vs. 기존 프로젝트를 쓸 때

헷갈릴 수 있으니 기준을 드릴게요.

**새 프로젝트를 만드는 게 좋은 경우:**
- 완전히 다른 업무 영역 (재고 관리 ↔ 마케팅)
- 관련 파일과 지시사항이 따로 필요한 경우
- 팀원이나 다른 역할과 섞이면 안 되는 경우

**기존 프로젝트를 계속 쓰는 게 좋은 경우:**
- 같은 주제의 연속된 작업 (지난달 정산 → 이번달 정산)
- 이전 대화 내용을 참고해야 하는 경우
- 같은 파일과 설정을 계속 쓰는 경우

### 끝난 프로젝트는 보관 처리하세요

일이 끝난 프로젝트는 삭제하지 말고 <mark>보관(Archive)</mark> 처리를 해두는 게 좋아요.

삭제하면 대화 기록과 설정이 사라져요. 보관해두면 사이드바에서 안 보이게 되지만, 필요하면 언제든 다시 꺼내볼 수 있어요.

보관 방법은 프로젝트 이름 오른쪽의 ··· 메뉴를 클릭하면 "보관" 옵션이 있어요.

<div class="note-star">★ 프로젝트는 3~5개가 딱 적당해요. 너무 많이 만들면 오히려 "어느 프로젝트에서 그 얘기를 했더라" 하고 또 찾아 헤매게 돼요. 처음엔 2~3개로 시작해서 필요할 때 하나씩 늘려가는 걸 추천해요.</div>

프로젝트 기능으로 업무를 깔끔하게 나눠봤다면, 각 프로젝트에서 쓸 수 있는 다른 기능들도 함께 활용해보세요.

- [예약 작업 설정하기](/docs/cowork/cowork-scheduled) — 프로젝트 안에서 반복 업무 자동화하기
- [외부 서비스 연결하기](/docs/cowork/cowork-connectors) — 프로젝트별로 구글 드라이브, Gmail 연결하기
- [Dispatch로 폰에서 지시하기](/docs/cowork/cowork-dispatch) — 이동 중에도 프로젝트 전환하며 일 맡기기
