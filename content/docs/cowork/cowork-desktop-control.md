## AI가 내 화면을 직접 본다고요?

처음 들으면 조금 놀라울 수 있어요.

클로드가 지금 내 화면이 어떻게 생겼는지 사진을 찍어서 봐요. 어디에 버튼이 있는지, 어떤 파일이 열려 있는지, 화면에 뭐라고 쓰여 있는지를 확인하는 거예요. 그리고 나서 마우스를 그 위치로 이동시키고 클릭해요.

이걸 <mark>데스크톱 제어(Computer Use)</mark>라고 불러요.

```
클로드의 작동 방식:
① 내 화면 캡처 → ② 화면 분석 → ③ 마우스 클릭 / 키보드 입력 → ④ 결과 확인 → 반복
```

마치 눈이 있는 AI가 내 옆에 앉아서 컴퓨터를 직접 써주는 것과 똑같아요.

## Mac 권한 설정 (처음 한 번만)

Mac에서 데스크톱 제어를 쓰려면 권한 두 가지를 허용해야 해요.

### 화면 녹화 권한

클로드가 내 화면을 볼 수 있게 해주는 권한이에요.

1. Mac 화면 **좌상단 메뉴 바의 Apple 메뉴(🍎)** 클릭
2. **시스템 설정** (또는 System Settings) 클릭
3. 사이드바에서 **개인 정보 보호 및 보안** 클릭
4. 스크롤 내려서 **화면 녹화** 클릭
5. 목록에서 **Claude** 찾아서 스위치를 **켜기**

### 손쉬운 사용 권한

클로드가 마우스와 키보드를 제어할 수 있게 해주는 권한이에요.

1. 같은 **개인 정보 보호 및 보안** 화면에서
2. **손쉬운 사용** 클릭
3. **Claude** 옆 스위치를 **켜기**

<div class="note-circle">○ 권한 설정 후 클로드 앱을 완전히 종료했다가 다시 시작해 주세요. 그래야 권한이 제대로 적용됩니다.</div>

## Windows 권한 설정

Windows는 Mac보다 설정이 간단해요.

앱 처음 실행 시 뜨는 팝업에서 **"예"** 를 클릭하면 대부분 자동으로 허용돼요.

만약 작동이 안 된다면 이렇게 해보세요.

1. **시작 메뉴** → **설정** 클릭
2. **개인 정보 및 보안** 클릭
3. **앱 권한** 섹션에서 각 항목 확인
4. Claude 앱이 필요한 권한을 가지고 있는지 확인

<div class="note-circle">○ Windows에서 데스크톱 제어는 2026년 4월부터 정식 지원됩니다. 이전 버전의 앱을 쓰고 있다면 최신 버전으로 업데이트해 주세요.</div>

## 클로드가 제어할 수 있는 것 vs 없는 것

중요한 내용이에요. 클로드가 모든 걸 다 할 수 있는 건 아니에요.

### 할 수 있는 것

- **파일 탐색기 / Finder**: 폴더 열기, 파일 이동, 이름 바꾸기
- **엑셀 / 한글 / Word**: 파일 열기, 내용 입력, 수식 작성, 저장
- **메모장 / 텍스트 편집기**: 파일 만들기, 내용 쓰기
- **이메일 앱(Outlook, 메일)**: 메일 열기, 내용 읽기, 답장 작성
- **웹 브라우저**: 사이트 열기, 스크롤, 링크 클릭, 텍스트 복사
- **계산기, 캘린더 등 일반 앱**: 대부분 사용 가능

### 제한이 있는 것

- **보안 팝업**: 비밀번호 입력창, 은행 앱 등 보안 레이어가 있는 화면은 클로드가 조작하지 않아요.
- **화상회의 앱**: Zoom, 팀즈 등 영상 화면은 제어에 제한이 있어요.
- **게임**: 게임 화면은 지원 안 해요.

<div class="note-circle">○ 클로드는 은행 비밀번호, 결제 정보 등 보안에 민감한 화면은 일부러 건드리지 않도록 설계되어 있어요. 이건 안심하셔도 되는 부분이에요.</div>

## 개인 정보와 보안은 괜찮을까요?

걱정하시는 분들이 많아요. 당연한 걱정이에요.

클로드가 화면을 볼 때는 **지금 작업하는 화면만** 봐요. 백그라운드에서 몰래 항상 녹화하는 게 아니에요. 작업을 시킬 때만, 그리고 그 작업에 필요한 화면만 봐요.

몇 가지 실용적인 팁을 드릴게요.

- 클로드에게 일 시킬 때는 불필요한 창을 닫아두세요.
- 인터넷 뱅킹이나 개인 계정 화면은 미리 닫아두세요.
- 작업이 끝나면 세션을 종료하세요.

## 실전 예시: 엑셀 파일 정리하기

말로 설명하는 것보다 예시를 보는 게 더 와닿겠죠.

**상황**: 바탕화면에 "매출현황.xlsx" 파일이 있어요. 이 파일에서 B열 합계를 구하고 싶어요.

**코워크에 이렇게 입력하세요:**
```
바탕화면에 있는 매출현황.xlsx 파일을 열고,
B열 전체의 합계를 B열 맨 아래에 =SUM 수식으로 넣어줘.
그리고 저장해줘.
```

**클로드가 하는 일:**
1. 화면에서 바탕화면을 찾아요
2. 매출현황.xlsx를 더블클릭해서 열어요
3. B열의 데이터가 어디까지 있는지 확인해요
4. 빈 셀을 찾아서 클릭해요
5. `=SUM(B1:B50)` 같은 수식을 입력해요
6. 저장(Ctrl+S)을 눌러요

이 모든 과정이 눈앞에서 펼쳐져요. 처음엔 신기해서 멍하니 보게 될 거예요.

## 실전 예시: 웹사이트에서 정보 찾기

**상황**: 경쟁사 제품 가격을 조사해야 해요.

**코워크에 이렇게 입력하세요:**
```
크롬 브라우저 열어서 "○○쇼핑몰" 사이트에 접속하고,
"무선 키보드" 카테고리에서 5만 원 이하 상품 목록을 찾아서
상품명과 가격을 메모장에 정리해줘.
```

클로드가 직접 브라우저를 열고, 사이트에 접속하고, 스크롤하면서 상품을 찾고, 메모장에 정리해줘요.

## 작업 중간에 클로드가 멈추면?

가끔 클로드가 작업 중간에 확인을 요청할 수 있어요.

```
"다음 단계로 진행할까요? 
파일을 저장하기 전에 내용을 확인해 주세요."
```

이런 메시지가 나오면 내용을 확인하고 "계속해줘" 또는 "중단해줘"라고 답하면 됩니다.

<div class="note-circle">○ 클로드가 확신이 없는 상황에서는 먼저 물어봐요. 이건 실수를 줄이기 위한 좋은 습관이에요. 귀찮아도 한번 확인해 주세요.</div>
