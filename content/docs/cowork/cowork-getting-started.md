## 시작 전에 확인할 것

코워크를 쓰기 전에 딱 두 가지만 확인해 주세요.

1. **클로드 Pro 또는 Max 요금제** 가입 여부
2. **클로드 데스크톱 앱** 설치 여부

웹 브라우저에서 claude.ai를 쓰고 계신다면, 코워크 탭이 보이지 않아요. 반드시 앱을 설치해야 합니다.

---

## 1단계: 클로드 데스크톱 앱 다운로드

### Mac 사용자

1. 브라우저에서 `claude.ai/download` 로 이동하세요.
2. **"Download for Mac"** 버튼을 클릭하세요.
3. 다운로드된 파일 이름이 `Claude.dmg` 형태일 거예요.
4. 파일을 더블클릭해서 열면 설치 화면이 나와요.
5. 클로드 아이콘을 **Applications 폴더**로 드래그하세요.

<div class="note-circle">○ Mac에서 처음 앱을 열 때 "인터넷에서 다운로드한 앱입니다" 경고가 나올 수 있어요. 이건 정상입니다. "열기" 버튼을 눌러주시면 됩니다.</div>

### Windows 사용자

1. 브라우저에서 `claude.ai/download` 로 이동하세요.
2. **"Download for Windows"** 버튼을 클릭하세요.
3. 다운로드된 파일 이름이 `ClaudeSetup.exe` 형태일 거예요.
4. 파일을 더블클릭해서 설치를 시작하세요.
5. "다음 → 다음 → 설치 완료" 순서로 진행하면 됩니다.

---

## 2단계: 앱 열고 로그인하기

설치가 끝나면 클로드 앱을 열어주세요.

- **Mac**: 런치패드 또는 Dock에서 Claude 아이콘 클릭
- **Windows**: 바탕화면의 Claude 아이콘 더블클릭

기존에 claude.ai 계정이 있으면 같은 이메일과 비밀번호로 로그인하면 됩니다.

---

## 3단계: Cowork 탭 찾기

로그인하면 화면 위쪽에 탭이 보여요.

```
[ Chat ]  [ Cowork ]  [ Code ]
```

가운데 **Cowork**를 클릭하세요.

처음 클릭하면 코워크 소개 화면이 나올 수 있어요. 잠깐 읽어보시고 계속 진행하시면 됩니다.

---

## 4단계: 필수 권한 허용하기

코워크가 내 컴퓨터를 제어하려면 몇 가지 권한이 필요해요. 처음 한 번만 설정하면 돼요.

### Mac 권한 설정

Mac은 보안이 꼼꼼해서 권한을 하나씩 허용해야 해요.

**화면 녹화 권한**
1. 화면 왼쪽 위 사과 아이콘 클릭 → **시스템 설정**
2. **개인 정보 보호 및 보안** 클릭
3. **화면 녹화** 항목 찾기
4. 목록에서 **Claude** 찾아서 켜기

**손쉬운 사용(접근성) 권한**
1. 같은 **개인 정보 보호 및 보안** 화면에서
2. **손쉬운 사용** 항목 찾기
3. **Claude** 옆에 있는 스위치를 켜기

<div class="note-circle">○ 이 권한들이 있어야 클로드가 내 화면을 보고, 마우스를 움직이고, 키보드로 입력할 수 있어요. 허용하지 않으면 데스크톱 제어 기능을 쓸 수 없습니다.</div>

### Windows 권한 설정

Windows는 대부분 자동으로 허용돼요.

앱을 처음 실행할 때 "이 앱이 컴퓨터를 변경할 수 있도록 허용하시겠습니까?" 창이 뜨면 **"예"** 를 클릭하세요.

추가로 팝업이 뜨면 마찬가지로 허용해 주세요.

---

## 5단계: 첫 번째 작업 시켜보기

이제 준비가 됐어요. 첫 번째 작업을 시켜볼게요.

코워크 입력창에 이렇게 써보세요.

```
내 바탕화면에 "테스트.txt" 파일을 만들고
"코워크 테스트 성공!" 이라고 써줘.
```

클로드가 화면을 열고, 메모장(Windows) 또는 텍스트편집기(Mac)를 실행해서 파일을 만드는 걸 직접 보실 수 있어요.

처음엔 조금 신기하고 놀라울 거예요. 마우스가 혼자 움직이거든요.

---

## 코워크 화면 구성 이해하기

코워크 화면을 살펴보면 이런 요소들이 있어요.

**입력창**
하단에 있어요. 여기에 하고 싶은 일을 적으면 됩니다.

**작업 진행 화면**
클로드가 무엇을 하고 있는지 실시간으로 보여줘요. 화면 캡처본이 표시되기도 해요.

**승인 버튼**
민감한 작업은 클로드가 먼저 물어보고 진행해요. "계속할까요?" 같은 질문이 나오면 확인해 주세요.

<div class="note-circle">○ 작업 중에 클로드가 멈추면, 입력창에 "계속해줘" 또는 "다음 단계로 넘어가줘"라고 적어보세요.</div>

## 자주 묻는 질문

**Q. 코워크 탭이 안 보여요.**
Pro 또는 Max 요금제인지 확인해 보세요. 무료 플랜에서는 코워크를 쓸 수 없어요.

**Q. Mac에서 권한 설정 후에도 작동이 안 돼요.**
클로드 앱을 완전히 종료했다가 다시 열어보세요. 권한은 앱 재시작 후 적용될 때가 많아요.

**Q. Windows에서 화면 제어가 안 돼요.**
2026년 4월부터 Windows도 정식 지원됩니다. 코워크가 정식 출시(GA)됐으니 안심하세요. 앱이 최신 버전인지 확인해 보세요.
