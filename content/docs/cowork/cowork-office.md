## 오피스 작업, 이제 말만 하면 됩니다

"엑셀 수식 모르겠어요."
"PPT 만들 시간이 없어요."
"한글 파일 서식 정리하기 귀찮아요."

이런 고민이 있다면 딱 맞는 챕터예요.

코워크는 엑셀, 한글, 파워포인트 같은 오피스 프로그램을 직접 열고, 내용을 채우고, 저장까지 해줍니다. 수식을 몰라도, 단축키를 몰라도 괜찮아요. 그냥 원하는 걸 말하면 돼요.

---

## 엑셀 자동화

### 기본 예시: 합계와 평균 구하기

**상황**: "1월판매현황.xlsx" 파일에서 각 제품별 합계와 전체 평균을 구하고 싶어요.

**코워크에 이렇게 입력하세요:**
```
Desktop에 있는 1월판매현황.xlsx를 열어줘.
B열부터 D열까지 각 열의 합계를 마지막 행 바로 아래에 넣어줘.
그리고 전체 평균도 그 아래 행에 넣어줘.
"합계"와 "평균" 레이블을 A열에 같이 써줘.
저장하고 파일 닫아줘.
```

**클로드가 하는 일:**
1. Desktop에서 파일을 찾아요
2. 엑셀을 열어요
3. 데이터가 몇 행까지 있는지 확인해요
4. 합계 행에 `=SUM()` 수식 입력해요
5. 평균 행에 `=AVERAGE()` 수식 입력해요
6. A열에 레이블 입력해요
7. 저장하고 닫아요

<div class="note-circle">○ 수식 이름을 몰라도 "합계 구해줘", "평균 구해줘" 처럼 말만 하면 클로드가 알아서 맞는 수식을 써줘요.</div>

---

### 응용 예시: 데이터 정렬 및 필터링

```
1월판매현황.xlsx에서
C열(매출액) 기준으로 내림차순 정렬해줘.
그리고 매출액이 100만 원 이상인 행만 따로 골라서
새 시트에 "우수제품" 이름으로 만들어줘.
```

---

### 응용 예시: 차트 만들기

```
1월판매현황.xlsx의 A열(제품명)과 C열(매출액)을
막대 차트로 만들어줘.
차트 제목은 "1월 제품별 매출 현황"으로 해줘.
차트를 2번 시트에 넣어줘.
```

## 파워포인트 / 키노트 자동화

### 기본 예시: 보고서를 PPT로 변환하기

**상황**: 텍스트로 작성한 보고서를 발표용 PPT로 만들어야 해요.

**코워크에 이렇게 입력하세요:**
```
Desktop에 있는 보고서.txt 파일 내용을 읽고,
파워포인트 프레젠테이션으로 만들어줘.
슬라이드는 아래 구성으로 해줘:
- 1번 슬라이드: 제목 페이지
- 2번 슬라이드: 목차
- 3~7번 슬라이드: 보고서 내용 (섹션별로 나눠서)
- 마지막 슬라이드: 감사합니다

완성된 파일은 Desktop에 "발표자료.pptx"로 저장해줘.
```

<div class="note-circle">○ 파워포인트가 설치된 Windows, Mac 둘 다 동작해요. Mac에서 키노트(.key)를 쓴다면 "키노트로 만들어줘"라고 하면 돼요.</div>

---

### 응용 예시: 기존 PPT에 내용 추가하기

```
Desktop에 있는 발표자료.pptx를 열고,
맨 뒤에 새 슬라이드 3장을 추가해줘.
내용은 이거야:
- 슬라이드 1: "향후 계획" 제목, 내년 매출 목표 20% 성장
- 슬라이드 2: "팀 구성" 제목, 총 5명 인원 소개
- 슬라이드 3: "Q&A" 제목만
저장해줘.
```

## 한글(HWP) / 워드(Word) 자동화

### 기본 예시: 문서 서식 정리하기

**상황**: 글꼴이 제각각인 보고서 파일을 깔끔하게 정리해야 해요.

**코워크에 이렇게 입력하세요:**
```
Desktop에 있는 보고서초안.docx를 열고,
전체 본문 글꼴을 맑은 고딕 11포인트로 바꿔줘.
제목들은 굵게, 18포인트로 해줘.
줄 간격은 1.5로 설정해줘.
저장해줘.
```

---

### 응용 예시: 반복 문서 자동 생성

**상황**: 10명 직원에게 같은 형식의 안내문을 보내야 해요.

```
Desktop/직원명단.xlsx에서 이름과 부서를 읽어와서,
각 직원마다 개인화된 안내문을 만들어줘.
형식은 이 템플릿을 써줘:

"[이름] [부서] 귀중
이번 달 교육 일정을 안내드립니다..."

파일은 Desktop/안내문/ 폴더에
"홍길동_안내문.docx" 형식으로 저장해줘.
```

<div class="note-circle">○ 한글 파일(.hwp)은 한글과컴퓨터 프로그램이 설치되어 있어야 클로드가 열고 조작할 수 있어요. 워드(.docx)는 마이크로소프트 워드 또는 한컴오피스가 있으면 돼요.</div>

## 파일 정리 자동화

### 예시: 폴더 안 파일 이름 정리하기

```
Desktop/사진백업/ 폴더 안에 있는 이미지 파일들의
이름을 "2026-01-01_001.jpg" 형식으로 바꿔줘.
날짜는 파일 수정 날짜 기준으로 해줘.
```

### 예시: 파일을 날짜별로 분류하기

```
Desktop/다운로드/ 폴더 안에 있는 파일들을
수정 날짜 기준으로
Desktop/다운로드/2026-01/, Desktop/다운로드/2026-02/ 처럼
월별 폴더를 만들어서 분류해줘.
```

## 실제 업무 시나리오: 월말 보고서 만들기

아래는 처음부터 끝까지 전체 과정을 보여드리는 예시예요.

**상황**: 월말에 영업팀 실적 보고서를 만들어야 해요.

**준비물:**
- `Desktop/영업실적/2026년3월.xlsx` — 날짜별 매출 데이터
- `Desktop/보고서템플릿.docx` — 보고서 기본 형식

**코워크에 이렇게 입력하세요:**

```
아래 두 단계로 진행해줘.

1단계:
Desktop/영업실적/2026년3월.xlsx를 열고
- 총 매출 합계
- 전월 대비 증감률 (2월 합계는 셀 B2에 있어)
- 가장 많이 팔린 제품 상위 3개
를 계산해줘.

2단계:
Desktop/보고서템플릿.docx를 열고
위에서 계산한 숫자들을 넣어서
완성된 보고서를 Desktop/2026년3월실적보고서.docx로 저장해줘.
```

**결과:**
클로드가 엑셀을 열고 계산하고, 워드 파일에 숫자를 채워 넣어서 완성된 보고서를 만들어줘요. 이 작업이 보통 30분이었다면 이제 5분도 안 걸려요.

## 잘 안 될 때 이렇게 해보세요

**파일을 못 찾는다고 할 때**
파일 이름과 경로를 정확하게 알려주세요.
```
❌ "엑셀 파일 열어줘"
✅ "C:\Users\홍길동\Desktop\매출.xlsx 열어줘"
```

**프로그램이 열리지 않을 때**
해당 프로그램이 컴퓨터에 설치되어 있는지 확인해 보세요.

**저장이 안 될 때**
파일이 다른 곳에서 이미 열려 있지 않은지 확인해 보세요.
