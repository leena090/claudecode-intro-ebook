## 딱 3개 영역만 알면 됩니다

클로드코드의 화면은 3개 영역으로 나뉩니다. 각 영역의 역할을 이해하면 사용이 훨씬 쉬워집니다.

---

## ① 상단 상태 표시

```
Working in: /Desktop/내작업 | claude-opus-4-5 | auto
```

**역할:**
- 현재 작업 중인 **폴더 위치** 표시
- 사용 중인 **AI 모델** 표시
- **권한 모드** 표시 (자동 또는 수동)

**알아야 할 것:**
- 폴더 위치가 맞는지 확인할 때 봅니다
- 모델은 자동으로 선택되므로 신경 쓸 필요 없습니다

---

## ② 대화 내역 영역

```
[나] 안녕하세요, 파이썬 코드 작성 도와줘
[Claude] 네, 어떤 기능을 만들고 싶으신가요?
```

**역할:**
- 나와 Claude의 대화가 **순서대로 표시**
- 이전 대화 내용을 계속 **참고**하면서 작업

**알아야 할 것:**
- 화면을 위로 스크롤하면 이전 대화 확인 가능
- Claude가 이전 대화를 기억하고 문맥을 이해합니다
- 새로운 주제로 시작할 때는 `/clear` 명령어로 초기화하면 좋습니다

---

## ③ 명령 입력창 (프롬프트)

```
> 여기에 요청사항을 입력하세요... █
```

**역할:**
- 클로드코드에게 **요청을 입력**하는 곳
- Enter 키를 눌러 전송

**알아야 할 것:**
- 한국어로 편하게 입력하세요
- 길게 설명해도 괜찮습니다
- 여러 줄로 입력하려면 Shift+Enter를 사용

---

## 실전 예시

### 상황: 파이썬 코드 작성 요청

```
① 상단에 표시됨
Working in: /Desktop/프로젝트 | claude-opus-4-5 | auto

② 대화 내역
[나] 파이썬으로 간단한 계산기를 만들어줄 수 있을까요?
[Claude] 물론이죠! 어떤 기능을 포함하고 싶으신가요?
[나] 더하기, 빼기, 곱하기 3가지만 되면 좋겠어요
[Claude] 알겠습니다. calculator.py 파일을 만들겠습니다
✓ calculator.py 생성 완료

③ 입력창
> █
```

## 각 영역의 크기 조절

터미널의 크기를 늘리면 각 영역도 함께 커집니다:
- 대화가 많으면 → 터미널 창을 크게 열기
- 입력이 길면 → 세로를 길게 조절

---

## UI 빠르게 익히기

화면 구조가 아직 낯설다면 `/powerup` 명령어를 입력해보세요. Claude가 각 영역의 역할과 자주 쓰는 기능을 **애니메이션 데모**로 안내해줍니다.

```bash
/powerup
```

## 🆕 2026년 UI 개선 — 꼭 알아두세요

### 1. Transcript 모드 검색 (v2.1.83~)

Transcript 모드(전체 대화 기록 스크롤)에서 **`/` 키**를 누르면 단어 검색이 활성화돼요.

```
Transcript 모드에서:
/    → 검색창 열기
검색어 입력 후 엔터 → 결과로 이동
n    → 다음 결과
N    → 이전 결과
```

> 🍱 **비유로 설명하면**: 웹 브라우저의 Ctrl+F처럼요. 긴 대화에서 원하는 부분을 빠르게 찾을 수 있어요.

### 2. Effort 레벨이 로고·스피너에 표시됨 (v2.1.69~)

현재 작업의 effort level(`low` / `medium` / `high`)이 **로고와 응답 중 스피너에 자동 표시**돼요. 어느 정도 품질로 작업 중인지 한눈에 확인 가능.

> v2.1.92부터 옵션이 단순화됐어요 — 기존 5단계 → **3단계**로. 그리고 v2.1.94(2026-04-07)부터 **기본값이 `high`**로 올라갔어요. 예전에는 `medium`이었지만 이제는 처음부터 꼼꼼하게 작업해줍니다. `[공식]`

### 3. Focus View — 입력에만 집중하기 (v2.1.97~)

대화가 길어지면 화면이 어지러워질 때가 있어요. 그럴 때 `Ctrl+O` (Mac은 `Cmd+O`)를 누르면 **Focus View**가 켜져요.

카카오톡에서 키보드만 보이게 하는 것처럼, 대화 내용이 접히고 입력창만 딱 보여요. 긴 작업 중에도 깔끔하게 새 지시를 내릴 수 있습니다. 다시 `Ctrl+O`를 누르면 원래 화면으로 돌아와요.
