## Claude Tag란?

**Claude Tag(클로드 태그)** 는 Anthropic이 2026년 6월 23일 출시한 **팀을 위한 새로운 Claude 협업 방식**이에요.

> 🍱 **비유**: 카카오톡 단체방에서 "@홍길동" 하고 특정 사람을 부르는 것처럼, 팀의 작업 공간에서 "@Claude"라고 태그하면 Claude가 바로 그 맥락으로 참여하는 거예요.

---

## 어떤 기능인가요?

Claude Tag는 **팀이 함께 Claude를 쓸 수 있는 새로운 인터페이스**예요.

| 특징 | 설명 |
|------|------|
| 팀 공유 | 혼자가 아닌 팀 전체가 Claude와 협업 |
| 태그 방식 | 특정 문서·작업에 Claude를 불러오는 방식 |
| 맥락 공유 | 팀원들이 Claude와 나눈 작업 내용을 공유 가능 |
| 협업 흐름 | 기존 팀 워크플로에 Claude를 자연스럽게 통합 |

> 🍱 **일상 예시**: 팀 문서 작업 중에 "이 부분 Claude한테 리뷰 맡겨볼까요?" 하고 Claude를 태그하면 → Claude가 그 문서의 맥락을 이해하고 바로 피드백을 줘요. 다음에 다른 팀원이 보면 Claude의 코멘트도 함께 보여요.

---

## 기존 Claude Code와 어떻게 다른가요?

| 비교 | Claude Code | Claude Tag |
|------|------------|------------|
| 주요 대상 | 개발자 개인 | 팀 전체 (개발자 포함) |
| 인터페이스 | 터미널·IDE | 팀 협업 도구 통합 |
| 작업 방식 | 1:1 대화 | 팀원들과 공유 |
| 주요 용도 | 코딩, 개발 | 팀 문서·리뷰·협업 |

---

## 어떤 분들께 유용할까요?

<div class="note-circle">
○ <strong>개발자</strong>: PR 리뷰 요청할 때 Claude를 팀원처럼 태그<br />
○ <strong>기획자</strong>: 기획 문서에 Claude를 불러 의견 받기<br />
○ <strong>관리자</strong>: 회의록·보고서에 Claude를 태그해서 요약·분석<br />
○ <strong>팀 전체</strong>: Claude와의 작업 결과를 팀원과 자연스럽게 공유
</div>

Claude Tag는 2026년 6월 23일 공식 출시됐어요. 정확한 플랜별 지원 범위와 사용 방법은 Anthropic 공식 채널에서 확인하세요.
