## 편 15. 복순 할머니의 블로그 — 논둑길에서 쓴 글이 1만 명에게 닿은 날

정복순(68세)은 농사 40년차다.

감 농사, 고추 농사, 뒤뜰 채마밭까지. 손마디에는 40년 흙이 박혀 있다. 컴퓨터는 2019년 **농협에서 디지털 교육 지원**으로 받은 Windows 데스크톱이 전부였다. 그것도 대부분 창고에 먼지 쌓인 채였다.

어느 봄날, 서울에서 대학 다니는 손녀 지윤이(21세)가 영상통화를 걸어왔다. 손녀는 **MacBook**을 쓰는 디자인 전공이었다.

*"할머니, 내가 할머니 블로그 하나 만들어드리고 싶어요. 할머니가 하시는 말씀이 너무 재밌거든."*

복순 할머니는 웃으며 손사래를 쳤다. *"내가 뭔 글을 써. 학교도 국민학교 나왔는데."*

손녀가 말했다. *"할머니, 그냥 **평소에 하시던 말** 그대로 하시면 돼요. 제가 도와드릴게요. Claude라는 게 있어요."*

---

### 첫 설치 — 손녀의 원격 안내

토요일 오후, 손녀가 영상통화로 단계별 안내를 했다.

*"할머니, 왼쪽 아래 시작 버튼 누르시고, 'powershell' 치세요. 파란 창 뜨면 성공이에요."*

복순 할머니는 돋보기 안경을 올리고 한 글자씩 쳤다. `p...o...w...e...r...s...h...e...l...l`. 파란 창이 열렸다. *"…떴네."*

손녀가 이어서 말했다. *"이제 제가 문자로 명령어 보내드릴게요. 그대로 복사해서 붙여넣기만 하세요. 붙여넣기는 `Ctrl+V`예요."*

```powershell
winget install Anthropic.ClaudeCode
```

*"할머니, 저는 Mac 써서 명령어가 `brew install`로 조금 다른데, 할머니는 Windows니까 이거만 쓰시면 돼요."*

복순 할머니는 붙여넣기를 했다. 엔터. 화면이 바빠지더니 2분 뒤 설치 완료. 손녀가 *"할머니 짱이에요!"* 외쳤고, 할머니는 *"에이, 뭐를…"* 하면서도 입꼬리가 올라갔다.

---

### CLAUDE.md — "할머니 말투 절대 바꾸지 마"

손녀는 화면 공유로 `CLAUDE.md` 파일을 직접 써줬다.

> 🍱 **CLAUDE.md가 뭐예요?** 내가 AI한테 미리 **"나는 이런 사람이에요, 이렇게 대답해주세요"**라고 알려주는 설명서예요. 이 파일만 써두면 매번 설명할 필요 없어요.

손녀가 쓴 파일 내용:

```markdown
# 복순 할머니를 위한 설정

## 절대 규칙
- **할머니 말투는 절대 바꾸지 마세요**. 사투리, 줄임말, 감탄사 그대로 유지.
- 할머니가 말씀하신 그대로가 글의 힘입니다.
- 맞춤법만 살짝 다듬고, 어색한 조사만 고쳐주세요.
- "~해유", "~라니께", "아이고" 같은 표현은 그대로 두세요.

## 글 길이
- 블로그 한 편 = 800~1,200자
- 소제목 2~3개
- 사진 들어갈 자리는 "[사진: 설명]" 으로 표시

— 손녀 지윤 씀, 2026년 4월
```

복순 할머니는 손녀가 설명해주는 걸 귀 기울여 들었다. *"그러니까 이거는 내가 말한 대로 쓰라고 AI한테 미리 일러두는 거여?"*

*"맞아요 할머니. AI가 평소엔 말투를 표준어로 바꾸려고 해요. 그러면 할머니 글이 안 되니까, 제가 이걸 먼저 써둔 거예요."*

---

### 첫 글 — "감나무 이야기"

손녀가 **글 쓰기용 프로젝트**도 하나 만들어줬다. Claude 웹앱에 *"복순 할머니 블로그"* 프로젝트.

복순 할머니는 떨리는 손가락으로 천천히 타이핑했다.

```
우리 집 앞에 감나무가 한 그루 있어유. 40년 전에
시아버지가 심어주셨는데, 올해도 열매를 또 맺었어유.
아이고 매년 이 나무 보면 시아버지 생각나고
그러네유.
```

그러고 나서 `↵ 엔터`. 한 줄 더 쳤다.

```
이거 블로그 글로 다듬어줘. 내 말투는 절대 바꾸지 말고.
```

Claude가 작업을 시작했다. 복순 할머니는 손녀가 알려준 대로 **"글 미리보기로 보여줘"** 를 이어서 쳤다.

오른쪽에 창이 스르르 열렸다. **블로그 글 미리보기**가 나타났다.

> 🍱 **쇼미!** 말 끝에 "보여줘"만 붙이면 오른쪽에 결과가 바로 나타나요. 공식 이름은 **아티팩트(Artifacts)**인데, 일부 사용자들은 이걸 *쇼미 더 머니*의 그 **"쇼미!"** 라고 부르기도 한답니다. 😄

글은 복순 할머니가 말한 그대로였다. "~해유", "아이고", "그러네유" 전부 살아 있었다. 맞춤법만 살짝 다듬어져 있었다.

복순 할머니는 한 줄씩 읽다가 손바닥으로 눈가를 닦았다.

*"…내 말투 그대로 남았네."*

---

### 논둑길의 기적 — Dispatch

봄이 끝나가는 5월, 복순 할머니는 매일 논에 나갔다. 집에 앉아서 글 쓸 시간이 없었다.

손녀가 또 가르쳐줬다.

*"할머니, **Dispatch**라는 기능이 있어요. 할머니 폰에 클로드 앱 깔면, 논둑에서도 집 컴퓨터한테 일 시킬 수 있어요. **말 한 마디만 보내면** 집 컴퓨터가 알아서 해요."*

복순 할머니는 논에서 호미를 놓고 폰을 꺼냈다. 앱을 열고 Dispatch 탭을 찾았다. 말로 녹음할까 하다가, 타이핑이 더 편해서 한 줄 쳤다.

```
오늘 논에 물 대는데, 옆집 할머니가 봄나물 한 움큼 주셨다.
두릅이랑 참나물. 이걸로 저녁에 나물밥 해먹을라고.
할머니 블로그 글 초안으로 다듬어줘.
```

전송. 논에 다시 물을 댔다.

저녁에 집에 들어와 노트북을 열었더니, **초안이 이미 준비**되어 있었다. 복순 할머니는 "~해먹을라고"까지 살아있는 글을 보며 혼잣말을 했다.

*"이 기계가 나 없을 때도 글 써놓고 기다렸네."*

---

### 매주 월요일, 예약 작업

손녀가 마지막 기능을 하나 더 알려줬다.

*"할머니, **예약 작업** 이라는 것도 있어요. 매주 월요일 오전 9시에 '이번 주 글감 정리' 같은 걸 자동으로 해놓게 할 수 있어요."*

손녀가 원격으로 설정을 도와줬다. 매주 월요일 오전 9시 — *"이번 주 농사일 중 블로그에 쓸 만한 글감 3개 제안"*.

다음 월요일 아침, 복순 할머니가 커피 한 잔 타서 자리에 앉았더니 이미 제안 3개가 기다리고 있었다.

1. *감나무 꽃 피는 날 — 작년이랑 비교*
2. *뒤뜰 채마밭 봄 씨앗 계획*
3. *옆집 할머니와 봄나물 이야기*

복순 할머니는 제일 가슴 뛰는 2번을 골라서 바로 쓰기 시작했다.

---

### 손녀가 만들어준 작은 스킬

5월 말, 손녀가 집에 왔다. 할머니 노트북을 보더니 **손녀가 직접 작은 스킬**을 만들어줬다.

```
~/.claude/skills/grandma-polish/SKILL.md
```

내용은 딱 한 가지 규칙이었다. *"복순 할머니 말투는 절대 바꾸지 마세요. 사투리·줄임말·감탄사 유지."*

이제 복순 할머니가 `/grandma-polish` 한 줄만 쳐도, 손녀가 설정한 말투 규칙이 자동 적용됐다.

*"이거는 뭐여?"* 복순 할머니가 물었다.

*"할머니, 스킬이라는 거예요. 자주 쓰는 규칙을 이름 하나로 저장해두는 거. `/grandma-polish` 라고 치시면 할머니 말투 그대로 다듬어줘요."*

---

### 6월, 조회수 1만

복순 할머니의 감나무 이야기가 어느 날 **조회수 1만**을 넘었다. 댓글이 쌓였다.

> *"할머니 글이 너무 따뜻해요 ㅠㅠ"*
> *"저희 할머니 생각나서 한참 울었어요."*
> *"제발 계속 써주세요."*

손녀가 영상통화로 댓글을 읽어줬다. 복순 할머니는 처음엔 믿지 않았다. *"이게 다 나 보고 쓴 거여?"*

손녀가 고개를 끄덕이며 조용히 말했다.

*"할머니, 사람들이 할머니 이야기를 **듣고 싶어 해요.**"*

복순 할머니는 창밖 감나무를 한참 봤다. 40년 전에 심어준 시아버지를 떠올렸다. 그리고 작은 목소리로 말했다.

*"아이고… 시아버님 덕분이네."*

---

> 💡 **이것 하나 기억하세요.** 글을 잘 써야 블로그를 시작할 수 있는 게 아닙니다. **내가 말한 그대로**가 이미 글입니다. AI는 그걸 다듬어줄 뿐이에요. 가장 강한 무기는 **나만의 말투**입니다.

#### 📦 이 편의 핵심 기능

| 기능 | 이 이야기에서 어떻게 썼나 |
|---|---|
| **Windows 설치** | 손녀가 영상통화로 `winget install Anthropic.ClaudeCode` 안내 |
| **Mac 조력자 (손녀)** | 디자인 전공 손녀가 Mac에서 `brew install`, 할머니는 Windows — 플랫폼 차이 자연스럽게 등장 |
| **CLAUDE.md** | 손녀가 "할머니 말투 절대 바꾸지 마" 규칙 미리 작성 — AI에게 내 취향 알려주는 사용설명서 |
| **프로젝트** | Claude 웹앱 "복순 할머니 블로그" 프로젝트로 글감·규칙·이전 글 모두 한 곳 관리 |
| **쇼미 (Artifacts)** | "글 미리보기로 보여줘" 자연어로 오른쪽에 블로그 미리보기 창 자동 열림 |
| **Cowork Dispatch** | 논둑에서 폰으로 글감 전송 → 집 Windows 데스크톱이 알아서 초안 작성 대기 |
| **예약 작업 (/schedule)** | 매주 월요일 오전 9시에 "이번 주 글감 3개 제안" 자동 준비 |
| **커스텀 스킬** | 손녀가 `~/.claude/skills/grandma-polish/SKILL.md` 직접 작성 — 할머니 말투 유지 규칙 저장 |
