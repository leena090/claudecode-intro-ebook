## 편 11. 진숙 여사의 검은 화면 첫 만남

이진숙(62세)은 32년간 초등학교에서 아이들을 가르쳤다.

칠판 앞에서는 당당했다. 그런데 노트북 앞에서는 달랐다. 지난 생일에 딸 지은이가 사준 **민트색 Windows 노트북**. 예쁘긴 한데, 진숙 여사가 쓸 줄 아는 건 이메일 확인과 카카오톡 PC 버전 정도였다.

---

오늘 아침, 출근하는 딸 지은이(35세, IT 회사 다님)가 주방 식탁에 포스트잇을 붙여두고 나갔다.

> *"엄마, 이거 그대로만 따라 하면 설치 돼요.*
> *엄마 노트북은 Windows니까 ① 번 줄만 치세요.*
> *나는 Mac이라 집에선 ② 번 줄 쓰는데, 엄마는 신경 쓰지 마세요.*
> *도저히 모르겠으면 그냥 닫아도 돼요. 사랑해. — 지은"*

진숙 여사는 포스트잇을 세 번 읽었다. *"나는 기계치인데…"* 중얼거리다가, 에이, 하고 노트북을 열었다.

---

### 1단계. PowerShell 찾기

포스트잇 첫 줄:
> **1. 바탕화면 왼쪽 아래 ⊞ (시작 버튼) 눌러서 "powershell" 입력 → 엔터**

진숙 여사는 돋보기 아이콘을 찾으려다 멈췄다. 아, 시작 버튼은 왼쪽 아래에 있다. 눌렀다. "powershell"을 한 글자씩 쳤다. `p...o...w...e...r...s...h...e...l...l`.

파란 창이 열렸다. 검은색이 아니라 파란색이었다. "검은 화면이라고 했는데?" 잠깐 망설였지만, 딸의 포스트잇을 다시 봤다. *"색깔은 다를 수 있어요."* 라고 쓰여 있었다.

---

### 2단계. 한 줄로 설치

포스트잇 두 번째 줄:

```powershell
# ① Windows — 엄마는 이 줄만 치세요
winget install Anthropic.ClaudeCode

# ② Mac — 엄마는 무시하세요
# curl -fsSL https://claude.ai/install.sh | bash
```

진숙 여사는 ① 번 줄만 조심스럽게 따라 쳤다. `winget install Anthropic.ClaudeCode`. 엔터 누르기 전에 세 번 확인했다. 창밖을 한 번 봤다. 그리고 눌렀다.

화면이 바빠졌다. 글자들이 주르륵 흘러내렸다. 진숙 여사는 숨을 참았다. *"이거 내가 뭘 잘못한 건가?"* 그런데 멈추지 않았다. 2분쯤 지나자 화면이 잠잠해졌다.

```
Successfully installed
```

*"…설치가 됐다고?"*

---

### 3단계. 첫 실행과 `/help`

포스트잇 세 번째 줄: **`claude` 라고 치고 엔터.**

```
claude
```

로그인 URL이 나왔고, 안내대로 브라우저에서 승인을 눌렀다. 다시 PowerShell로 돌아오자 인사가 떠 있었다.

```
> Welcome. What would you like to do?
```

진숙 여사는 `>` 기호를 한참 봤다. 이게 뭔가를 쓰라는 신호 같았다. 그런데 뭘?

포스트잇은 여기서 끝나 있었다. 이제는 혼자다. 진숙 여사가 조심스럽게 네 글자를 쳤다.

```
/help
```

화면에 명령어 목록이 주르륵 펼쳐졌다. `/clear`, `/status`, `/powerup`, `/model`… 전부 모르는 단어였다. 그런데 이상하게 겁나지 않았다. *"새 학년 반 아이들 명단을 처음 받은 것 같네."* 진숙 여사가 중얼거렸다. 아직 다 모르지만, 하나씩 알면 되는 것들.

`/powerup` 옆에 설명이 있었다. *"기능을 대화형으로 배우는 인터랙티브 레슨."*

---

### 4단계. `/powerup` — AI가 선생님이 되다

```
/powerup
```

Claude가 먼저 물었다.

> *"안녕하세요! 어떤 기능부터 시작할까요? 처음이시라면 기본 사용법부터 안내해드릴 수 있어요."*

진숙 여사의 손가락이 멈췄다. AI가 나한테 물어봤다. **선생님이 학생한테 묻는 것처럼 부드럽게.**

32년을 교실에서 이 말을 했던 사람인데, 오늘은 자기가 학생 자리에 앉은 기분이었다. 나쁘지 않았다. 조금 설렜다.

답장을 쳤다. 한 글자씩, 천천히.

```
안녕하세요. 저 처음이에요. 기본부터 알려주세요.
```

Claude가 한 단계씩 설명하기 시작했다. 화면 구조, 입력 방법, 자주 쓰는 명령어. 진숙 여사는 작은 노트를 꺼내 받아 적었다. 32년 교사의 습관이었다.

---

### 5단계. 딸의 편지 — `CLAUDE.md`

오후가 됐다. 잠깐 쉬려고 차를 끓이고 돌아왔는데, 안내 중에 *"`CLAUDE.md`는 Claude에게 내 취향을 알려주는 파일입니다"*라는 설명이 나왔다.

*"나는 아직 그런 거 없는데…"* 진숙 여사가 중얼거리며 포스트잇을 다시 봤다. 맨 아래, 아주 작은 글씨로 한 줄 더 있었다.

> *"엄마, C 드라이브 → 사용자 → 엄마 이름 폴더 안에 `.claude` 폴더 있어요. 열어보세요."*

진숙 여사는 파일 탐색기로 찾아갔다. 폴더가 있었다. 안에 `CLAUDE.md`라는 파일이 있었다. 열었다.

```markdown
# 엄마를 위한 Claude 설정

## 기본 규칙
- 항상 한국어로, 존댓말로 대답해주세요.
- 모르는 단어가 나오면 쉽게 풀어서 설명해주세요.
- 엄마가 헤매지 않도록 항상 친절하게 설명해주세요.
- 오류가 나도 "괜찮아요, 같이 해봐요" 라고 먼저 말해주세요.

  — 지은 씀, 2026년 4월
```

진숙 여사는 한 줄씩 읽었다. 마지막 줄에서 눈이 조금 따가워졌다.

딸이 새벽에 이걸 미리 써놨구나. **엄마가 헤매지 않도록.**

---

진숙 여사가 휴대폰을 꺼내 카카오톡을 켰다.

> *"엄마 해냈어 ㅠㅠ 이거 진짜 재밌어. 그리고 그 파일 봤다. 고마워 딸."*

저녁, 딸에게서 답장이 왔다.

> *"ㅠㅠ 엄마 최고. 내일은 사진 첨부하는 것도 가르쳐줄게."*

진숙 여사는 노트 제일 위에 오늘 날짜를 적었다.

> *"2026년 4월 8일. 오늘 검은 화면이 나한테 인사했다. 내가 대답했다."*

---

> 💡 **이것 하나 기억하세요.** 첫 화면은 누구에게나 낯섭니다. 엔터 한 번 누르면, 다음은 생각보다 쉬웠다고 모두가 말합니다.

#### 📦 이 편의 핵심 기능

| 기능 | 이 이야기에서 어떻게 썼나 |
|---|---|
| **설치 (Windows)** | PowerShell에서 `winget install Anthropic.ClaudeCode` 한 줄로 설치 |
| **설치 (Mac — 딸 버전)** | 포스트잇에 병기된 `curl -fsSL https://claude.ai/install.sh \| bash` — Mac 쓰는 딸이 조력자로 등장 |
| **`/help`** | 첫 실행 직후 명령어 목록 전체를 스스로 탐색 |
| **`/powerup`** | AI가 "어떤 기능부터 시작할까요?" 하고 물으며 단계별 학습 (v2.1.90~) |
| **첫 대화** | 한 글자씩 천천히 "안녕하세요. 저 처음이에요" 타이핑 |
| **CLAUDE.md** | `~/.claude/CLAUDE.md`에 딸이 미리 써둔 "엄마를 위한 규칙" — 감동 포인트 |
