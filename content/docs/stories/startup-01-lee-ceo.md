## 편 8. 이대표, 주말 이틀로 스마트스토어를 론칭하다

6개월이었다.

이민준(42세)이 회사를 그만두고 나서 딱 6개월. 아이템 후보 리스트만 노트 한 권이 넘었다. 반려동물 용품, 건강기능식품, 캠핑 소품. 결론은 매번 같았다. "좀 더 생각해보자."

부인이 조용히 말했다. "당신, 생각을 너무 오래 하는 것 같아."

---

토요일 아침 9시. 고등학교 친구 박 씨가 카카오톡을 보냈다.

"야, 스마트스토어 한번 해봐. 나 지난달 280만 원 벌었어."

이민준은 노트북을 열었다. 이번엔 달랐다. 머릿속에 계속 돌아다니던 아이템 하나가 있었다. 중장년 남성 전용 기능성 스포츠 양말. 발바닥 아치 지지대, 땀 흡수, 무릎 부담 감소. 자기가 써봐서 좋았던 것.

문제는 상품 페이지를 만들 줄 모른다는 것이었다.

그때 친구가 한 마디 더 했다. *"Claude Code 웹이라고 있어. 브라우저에서 바로 되거든. 코딩 몰라도 돼. 근데 GitHub는 먼저 만들어야 될걸?"*

이민준은 멈칫했다. *"깃… 뭐?"*

---

### "깃허브가 뭐야?"

친구가 가버린 뒤, 이민준은 구글에 **"깃허브 뭐에요"** 를 쳤다. 첫 번째 결과가 이랬다.

> *"GitHub은 Git 기반 분산 버전 관리 시스템 코드 호스팅 플랫폼으로…"*

이민준은 한 줄 읽고 창을 닫았다. 무슨 말인지 하나도 몰랐다. 이럴 때 5년 차 IT 회사 직원이었다면 이해했겠지만, 그는 전직 영업팀이었다.

딸한테 전화할까 하다가 — 어제 잔뜩 귀찮게 했으니까 — 설치해뒀던 Claude Code를 열었다. 솔직히 이 녀석한테 물어보는 게 낫겠다 싶었다.

```
GitHub 이게 뭐야? 
누가 스마트스토어 상품 페이지 만들려면 써야 한다는데,
나는 지금 이게 뭔지도 몰라. 
쉽게 설명해줘. 
내가 꼭 써야 하는 거면 어떻게 가입하는지까지 알려줘.
```

Claude가 답했다.

> *"GitHub을 쉽게 설명드릴게요."*
>
> 🍱 **GitHub = 코드·파일 전용 구글 드라이브**
>
> *"구글 드라이브 아시죠? 파일 올려두고 어디서든 다운받고, 수정 이력도 남고. **GitHub은 그거의 '코드·문서 전용 버전'** 이에요. 개발자들이 전 세계적으로 쓰는데, 비개발자도 쓸 수 있어요."*
>
> **기본 용어 4개만 기억하세요:**
>
> | 용어 | 쉽게 말하면 |
> |---|---|
> | **레포(Repository)** | 프로젝트 폴더 하나 — "양말 쇼핑몰" 폴더 같은 것 |
> | **커밋(Commit)** | "저장" 버튼 + 메모 남기기 ("오늘 대문 사진 교체함" 같은 기록) |
> | **푸시(Push)** | 내 컴퓨터 → GitHub으로 올리기 |
> | **PR(Pull Request)** | *"이 수정 반영해도 될까요?"* 라는 요청서 |
>
> *"사장님 지금 상품 페이지 만드시려면 GitHub 계정 하나는 필요해요. **가입은 5분** 걸려요. github.com 가셔서 'Sign up' 누르시고 이메일·비밀번호 넣으시면 돼요. 제가 단계별로 도와드릴게요."*

이민준은 *"오호 이해된다"* 중얼거리며 github.com을 열었다. Claude가 옆에서 *"이제 오른쪽 위 Sign up 버튼 누르세요"*, *"이메일 입력하세요"* 하고 단계별로 안내했다. 5분 뒤 계정 완성.

*"됐어. 다음은 뭐야?"*

---

### "니가 알아서 레포 만들어줘"

Claude가 이어서 답했다.

> *"이제 프로젝트 폴더(저장소)를 하나 만들어야 해요. GitHub 사이트에서 직접 만드셔도 되고, **제가 대신 만들어드려도 돼요**. 이름만 정해주세요."*

이민준은 이미 이름을 생각해뒀다. 5분 걸려 지은 이름. **`lee-sports-socks`**. 성씨 + 아이템.

```
그냥 니가 알아서 만들어줘. 
레포 이름은 lee-sports-socks.
스마트스토어 상품 페이지 만들 거고, 
공개 저장소로 해줘.
```

Claude가 잠깐 생각하더니 답했다.

> *"네, GitHub CLI(`gh`)로 `lee-sports-socks` 공개 저장소를 생성하겠습니다. 인증이 처음이라 브라우저 창 한 번만 열어 확인해주세요."*

브라우저가 뜨고 "Authorize" 버튼이 보였다. 이민준은 눌렀다. 다시 터미널로 돌아오자 Claude가 자동으로 진행했다.

```
✓ Created repository lee-sports-socks on GitHub
✓ https://github.com/lee-minjun/lee-sports-socks
```

*"…진짜 만들어졌네."* 이민준이 혼잣말로 중얼거렸다. 파일 하나 직접 안 만들었는데 GitHub에 자기 레포가 생겼다.

---

### 본격 작업 — claude.ai/code 열기

이제 브라우저로 `claude.ai/code`에 접속했다. Claude가 미리 알려준 URL이었다. 좀 전에 만든 레포 `lee-sports-socks`가 목록에 이미 보였다. 클릭했다.

그리고 처음으로 대화창에 이렇게 입력했다.

```
내가 스마트스토어에서 중장년 남성 기능성 양말을 팔려고 해.
타깃: 40~60대 남성, 등산·조깅·골프 하는 사람
상품명은 "아치케어 스포츠양말"

1) 상품 소개 랜딩페이지 HTML 만들어줘
   (심플하게, 모바일 최적화, 핵심 혜택 3가지 강조)
2) 상품 설명 카피 10개 써줘
   (스마트스토어에 올릴 문구, SEO 키워드 포함)
3) 썸네일 이미지 컨셉 5개 제안해줘
   (실제 이미지 만들 때 쓸 설명 형태로)
```

30분이 지났다. 화면 오른쪽에 변경 내역이 나타났다. `index.html` 파일이 생성됐다.

이민준은 Claude가 전에 알려준 용어를 떠올렸다. **PR = "이 수정 반영해도 될까요?" 요청서**. 그러니까 지금 PR을 만들면 이 변경이 내 레포에 저장된다.

화면의 **Create PR** 버튼을 눌렀다. *"PR 만들어졌어요"* 라는 메시지가 떴다. GitHub에 저장됐다.

Vercel이라는 것도 연동해야 배포가 된다고 했다. 이번에도 Claude한테 시켰다. *"Vercel 연결해줘"*. 안내대로 몇 번 클릭하니 **`lee-sports-socks.vercel.app`** 가 살아났다.

이민준은 그 URL을 스마트폰으로 열어봤다. 멍하니 30초를 봤다.

*"…내 사이트가 인터넷에 떠 있네."*

---

토요일 오후, 고객 자동응답 템플릿이 필요했다.

```
스마트스토어 판매자용 고객 응대 자동답장 템플릿 20개 만들어줘.
상황별로:
- 배송 문의 5개
- 교환·환불 5개
- 사이즈·착용감 문의 5개
- 리뷰 요청 5개

말투는 친근하되 신뢰감 있게.
상호명은 "아치케어샵"으로.
```

결과물: `자동응답_템플릿_20개.txt`. 복사해서 스마트스토어 설정 창에 붙여넣었다.

---

일요일 밤 11시 23분.

부인이 침대에서 물었다. "당신 뭐 해? 컴퓨터 앞에 48시간째야."

이민준이 대답하려던 순간, 스마트폰이 울렸다.

스마트스토어 앱 알림이었다.

**[주문 접수] 아치케어 스포츠양말 M사이즈 2켤레**

"헉."

소리가 그것밖에 안 나왔다.

부인이 물었다. "뭐야, 무슨 일이야."

이민준이 폰 화면을 들이밀었다.

"나 사장님이야 지금."

부인이 화면을 확인하고 잠시 침묵했다. 그리고 말했다.

"진짜네."

---

**이것 하나 기억하세요.**
완벽한 준비보다 **실제로 올라간 페이지**가 더 많은 것을 가르쳐 줍니다. 6개월 고민은 48시간 실행에 못 미쳤습니다.
