## 편 14. 컴맹 아내, 진짜 직원 다섯 명을 고용하다

남편은 IT 30년 경력이다.

제조업 전산팀에서 엑셀 VBA로 공장 재고 시스템을 짜는 사람. 집에서도 *"AI는 아직 멀었어, 엑셀이 최고야"* 가 입버릇이다. 아내가 뭘 물어보면 *"그건 내가 할게"* 하며 팔짱을 꼈다.

김선영(51세)은 스스로를 늘 **'컴맹'** 이라고 불렀다. 스마트폰도 딸한테 물어봤다. 가계부는 10년째 **손글씨 공책**이었다.

그러던 3월의 어느 날 밤, 유튜브 알고리즘이 영상 하나를 보냈다. *"클로드 왕초보 강좌 — 아무것도 몰라도 됩니다."* 썸네일에 50대 아주머니가 웃고 있었다.

김선영은 남편 몰래 영상을 처음부터 끝까지 봤다. 그리고 **노트 첫 장**에 이렇게 썼다.

> *"2026년 3월 5일. 오늘 처음 claude 입력. 검은 화면이 대답했다. 신기했다."*

---

### 한 달 공부 — 혼자서, 천천히

집 거실에 있는 **Windows 노트북**을 꺼냈다. 남편은 회사용 데스크톱만 썼고, 이 노트북은 사실상 아내 전용이었다.

유튜브 댓글에 적힌 대로 PowerShell을 열고 설치했다.

```powershell
winget install Anthropic.ClaudeCode
```

**첫 주** — `/help`로 명령어 목록을 탐색하고, Claude 웹앱에서 *"우리 집 가계부"* 프로젝트를 만들었다. 지난 3개월치 영수증 사진을 드래그앤드롭으로 올렸다.

**둘째 주** — 마지막 줄에 "**차트로 보여줘**" 를 치니 오른쪽에 막대 차트 창이 스르르 열렸다.

> 🍱 **잠깐, 쇼미?**  일부 사용자들이 이걸 "쇼미!" — 쇼미 더 머니의 그 쇼미! — 라고 부르기도 합니다. 😄 공식 이름은 **아티팩트(Artifacts)**인데, 말 끝에 "보여줘"만 붙이면 오른쪽에 그림·표·차트가 자동으로 열리는 기능이에요.

**셋째 주**, 김선영은 중요한 걸 발견했다. **CLAUDE.md**라는 파일.

---

### CLAUDE.md — "내가 AI한테 미리 알려주는 사용설명서"

처음엔 이 파일이 뭔지 감이 안 왔다. 유튜브 강사가 설명해줬다.

> *"여러분, 새 전자기기 사면 사용설명서 나오죠? CLAUDE.md는 그 반대예요. **내가 AI한테 '나는 이런 사람이에요' 미리 알려주는 설명서**. 한번 써두면, 다음부터 매번 말 안 해도 AI가 알아서 맞춰줘요."*

김선영은 무릎을 쳤다. *"아, 이래서 쓰는구나."*

그런데 **위치가 두 군데**였다.

| 종류 | 위치 | 언제 쓰나 |
|---|---|---|
| 🌍 **글로벌** (전체 규칙) | `C:\Users\선영\.claude\CLAUDE.md` | 어떤 프로젝트에서든 항상 적용 — 나의 기본 취향 |
| 📁 **프로젝트별** (방별 규칙) | `./우리집-가계부/CLAUDE.md` | 이 프로젝트에서만 적용 — 특수한 규칙 |

> *"집 전체 규칙(글로벌)과 방마다 다른 규칙(프로젝트)이 있는 거랑 똑같네."* 김선영은 이해했다.

#### 글로벌 CLAUDE.md — 어디서든 나를 알아주는 파일

김선영은 먼저 **글로벌** 파일에 이렇게 썼다.

```markdown
# 김선영 기본 설정

- 저는 50대 주부이고 컴퓨터를 잘 모릅니다.
- 항상 한국어로, 존댓말로 대답해주세요.
- 어려운 용어가 나오면 일상생활 비유로 풀어서 설명해주세요.
- 제가 실수해도 "괜찮아요" 라고 먼저 말해주세요.
```

다음 날부터 Claude가 다른 작업을 할 때도 **자동으로 친절**해졌다. 김선영이 갑자기 "주식이 뭐예요" 물어도, 존댓말로 일상 비유까지 섞어 설명해줬다. *"진짜 나를 기억하네…"*

#### 프로젝트 CLAUDE.md — 이 방에서만 적용되는 규칙

가계부 프로젝트 폴더 안에는 **따로** 또 썼다.

```markdown
# 우리 집 돈 관리 규칙

- 월 목표 생활비: 150만 원
- 외식 한도: 월 30만 원
- 카테고리: 식비·공과금·교통·의류·여가·예비비
- 카드는 항상 '남편 삼성/내 국민' 구분해서 집계
```

이제 가계부 프로젝트에서만 이 규칙이 적용됐다. 다른 프로젝트엔 영향이 없었다.

---

### 훅(Hooks) — 강제 안전장치

유튜브에서 **"훅"** 이라는 용어를 또 들었다. 김선영은 고개를 갸우뚱했다.

> *"CLAUDE.md는 권고예요. AI가 가끔 깜빡할 수도 있어요. 훅은 달라요. 훅은 **자동으로 실행되는 안전장치**. 내가 실수로 위험한 명령을 쳐도, 훅이 먼저 막아줘요."*

| 비교 | CLAUDE.md | 훅(Hooks) |
|---|---|---|
| 성격 | 권고 (AI가 읽고 참고) | **강제** (무조건 실행) |
| 비유 | 가정 교육 ("손 씻고 밥 먹자") | 자동 수도꼭지 (손 대면 물 나옴) |
| 언제? | 취향·원칙 | **돌이킬 수 없는 작업 차단** |

김선영은 "돌이킬 수 없는 작업 차단"이라는 말에 멈췄다. 혹시 실수로 **가족 사진 폴더를 날리면** 어떡하지?

유튜브를 보고 따라서, `settings.json`에 훅 한 줄을 등록했다.

```json
{
  "hooks": {
    "PreToolUse": {
      "Bash": "rm -rf 같은 위험 명령어는 반드시 차단"
    }
  }
}
```

며칠 뒤, 김선영이 정말로 실수했다. 빠른 정리를 한다고 *"그 폴더 정리해줘"* 했는데, Claude가 `rm` 명령을 실행하려 했다. **훅이 딱 멈췄다**.

```
⚠️ Hook blocked: 위험 명령어 감지됨
  해결: 수동 확인 필요
```

김선영은 모니터 앞에서 숨을 크게 쉬었다. *"아… 이게 훅이구나. 사진 폴더 살았다."*

---

### 결정적 발견 — Agent Teams

한 달이 끝날 무렵, 유튜브에서 **"Agent Teams 실험 기능"** 영상을 봤다. *"말로 팀을 꾸리면, AI 여러 명이 동시에 일해요."*

김선영은 Claude Code 설정 파일에 한 줄 추가했다.

```json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1"
  }
}
```

Claude Code를 껐다 켰다. 그리고 **말로** 지시했다.

```
팀 꾸려줘. 세 명 필요해.
- 영수증 담당: 사진 파일들을 카테고리로 분류
- 가계부 담당: 엑셀로 정리, 월별 합계
- 리포트 담당: 월말에 A4 한 장 요약 보고서
각자 역할대로 동시에 진행해줘.
```

화면이 **세 영역**으로 나뉘었다. 세 명의 에이전트가 **동시에** 일을 시작했다. 영수증 담당은 폴더를 읽고, 가계부 담당은 엑셀을 만들고, 리포트 담당은 CLAUDE.md 규칙을 먼저 읽고 있었다.

김선영은 입을 벌렸다. *"…진짜 직원 세 명이 우리 집에 들어왔다."*

팀원들끼리 잠깐 대화가 오갔다. *"영수증 분류 끝나면 넘겨주세요." "넵, 5분 안에."*

김선영이 본능적으로 **`Shift + ↓` 키**를 눌렀다. 영수증 담당의 대화 창이 크게 열렸다. 그가 지금 뭘 하고 있는지 한눈에 보였다.

10분 뒤 결과:

- 📂 `영수증/2026-03/` — 6개 카테고리 폴더로 정리 완료
- 📊 `가계부_2026_03.xlsx` — 지출 총합 1,874,300원 (목표 -24만 원 초과)
- 📄 `월말_리포트_2026_03.md` — *"외식 34%, 권장 20% 초과. 절감 여력: 외식비"*

---

### 토큰 걱정 — "이거 돈 많이 나오는 거 아니야?"

결과를 본 순간, 김선영의 얼굴이 잠깐 어두워졌다.

*"잠깐… AI 세 명이 한꺼번에 일했는데, 이거 돈 많이 나오는 거 아니야?"*

손가락이 떨렸다. 공과금도 아까워하는 사람인데, 몇만 원 훅 나오면 안 된다. 김선영은 조심스럽게 명령어를 쳤다.

```
/cost
```

```
Today: $0.42
This Month: $7.80
  claude-opus-4-6:   $3.20  (cache hit: 48%)
  claude-sonnet-4-6: $4.60  (cache hit: 31%)
```

김선영은 **푹** 숨을 내쉬었다. 한 달에 **만 원도 안 됐다**. 손글씨 가계부 공책 한 권보다 쌌다.

---

### 설 명절, 남편 앞에서

설 명절 저녁. 시누이(디자이너, Mac 사용)가 집에 왔다. 남편이 모처럼 물었다. *"여보, 이번 달 가계부 어때?"*

김선영이 조용히 노트북을 꺼냈다. Claude Code를 열고 말로 지시했다.

```
여보한테 이번 달 가계부 상황 설명해줘. 리포트 띄워서 보여줘.
```

팀원들이 **동시에** 움직였다. 10초 뒤, 오른쪽에 요약 차트가 스르르 열렸다.

남편이 의자를 당겨 앉았다. *"…여보. 저거 어떻게 한 거야? 저 세 창은 뭐야?"*

김선영이 차분하게 **`Shift + ↓`** 를 눌러 영수증 담당의 대화를 보여줬다. 남편의 30년 VBA 자존심이 **잠깐 멈췄다**.

"이거… 월급은 얼마야?"

김선영이 웃으며 `/cost`를 쳤다. 남편이 화면을 보더니 **의자에서 반쯤 일어났다**.

"야, 근데… 이거 실수로 뭐 날리면 어떡해?"

김선영이 여유 있게 답했다. *"훅으로 막아놨어요. rm 같은 거 못 돌아가."*

남편의 입이 잠깐 벌어졌다.

시누이가 웃으며 끼어들었다. *"올케언니, 저는 Mac이라 설정 경로가 `~/.claude/`라서 살짝 달라요. 이따 제가 알려드릴게요."*

김선영이 고개를 끄덕였다. 이제 시누이한테도 **동료**로 인정받았다.

---

그날 밤, 남편이 자기 데스크톱 앞에 혼자 앉아 첫 명령어를 쳤다.

```
claude --version
```

아내 노트 첫 장의 글귀가 문득 떠올랐다. *"검은 화면이 대답했다. 신기했다."* 남편은 그제야 그 말이 무슨 뜻인지 알았다.

---

> 💡 **이것 하나 기억하세요.** AI는 직원 한 명이 아닙니다. **CLAUDE.md로 취향 등록, 훅으로 안전장치**, 그리고 말 한 마디로 **팀 다섯 명을 동시에 부릴 수 있어요**. 월급은 커피 두 잔 값입니다.

#### 📦 이 편의 핵심 기능

| 기능 | 이 이야기에서 어떻게 썼나 |
|---|---|
| **Windows 설치** | PowerShell에서 `winget install Anthropic.ClaudeCode` |
| **글로벌 CLAUDE.md** | `C:\Users\선영\.claude\CLAUDE.md` — 모든 프로젝트 공통 취향 (존댓말, 50대 주부 설정) |
| **프로젝트 CLAUDE.md** | `./우리집-가계부/CLAUDE.md` — 이 프로젝트만의 규칙 (월 150만 원 등) |
| **Hooks (훅)** | `settings.json`에 PreToolUse 훅 등록 → `rm -rf` 같은 위험 명령 자동 차단 (권고 아님, **강제**) |
| **쇼미 (Artifacts)** | "차트로 보여줘" 자연어로 오른쪽 창 자동 열림 |
| **`/fork` 시뮬레이션** | "외식 절반 줄이면?" → 연 252만 원 절약 계산 |
| **Agent Teams** | `settings.json`에 `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS: "1"` 환경변수 → 말로 팀 꾸려 세 명 동시 작업 |
| **`Shift + ↓` 키** | 팀원 각각의 상세 대화 열어보기 — 누가 뭘 하는지 한눈에 |
| **`/cost` 명령어** | 토큰 비용 확인 — 한 달 $7.80, 캐시 히트율 48% |
| **Mac 조력자 (시누이)** | 디자이너 시누이가 "Mac 경로는 `~/.claude/`" 한 줄 조언 |
