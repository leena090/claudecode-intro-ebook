## 편 12: 오사장의 카페, 매일 아침 6시 30분의 기적

오재훈(54세)은 카페를 6년째 혼자 운영하고 있다.

골목 안쪽이라 인스타 광고 없이는 새 손님이 잘 안 왔다. 그 대신 단골이 많았다. "사장님이 얼굴 아는 카페"라는 말을 들을 때가 제일 뿌듯했다.

그런데 숫자 일이 문제였다. 매일 오전, 어제 매출을 엑셀에 정리하는 데 30분. 월말 결산은 2시간. 재고 파악은 감으로. 몇 년째 똑같은 루틴이었다.

---

설치는 아들 도움으로 이미 마쳤다. 오늘은 첫 사용일이다.

오전 10시. 손님이 아직 없는 카운터. 오 사장은 노트북 앞에 앉았다. 터미널에 `claude`를 입력하고 로그인했다. 화면에 `>` 기호가 깜박였다.

"그래서... 뭐라고 하지?"

30분이 그냥 지나갔다. 뭔가를 해야 할 것 같은데, 뭘 시켜야 할지 몰랐다. 인터넷 강의처럼 "이제 여기에 입력하세요" 같은 게 없으니까.

겨우 친 한 마디.

```
안녕하세요.
```

Claude가 대답했다.

> "안녕하세요! 무엇을 도와드릴까요? 파일 작업, 정보 정리, 글쓰기 등 어떤 것이든 말씀해주세요."

어색했다. 하지만 어색한 채로 계속 했다.

---

```
/help
```

명령어 목록이 쭉 나왔다. 오 사장은 항목들을 하나씩 훑었다. `/clear`, `/status`, `/voice`, `/powerup`...

"와... 이거 다 공짜야?"

Max 구독료 안에 포함된 기능들이었다. 따로 플러그인 구매 같은 게 없었다.

그다음에 한 일은 프로젝트 만들기였다. Claude 웹앱을 열고 왼쪽 사이드바에서 **Projects** 버튼을 눌렀다. 이름을 입력했다.

> **우리 카페 2026**

프로젝트 지침 칸에 썼다.

```
카페 이름: 골목로스터리 (동네 카페, 1인 운영)
단골 수: 약 80명
메뉴: 아메리카노, 라떼, 크로플, 스콘 등 10종
운영: 오전 10시 ~ 저녁 8시
이 프로젝트에서는 매출 관리, 재고 파악, 단골 정보를 다룹니다.
한국어로 답해주세요.
```

이걸 한 번 입력해두면 다음부터는 다시 설명 안 해도 됐다.

---

진짜 시작은 엑셀 파일을 올리면서였다.

바탕화면에 `매출_2026_03.xlsx`가 있었다. 지난달 매출 파일. 입력창 옆 `+` 버튼을 눌러 파일을 첨부했다. 그리고 입력했다.

```
이 파일 보고 지난달 매출 분석해줘.
요일별로 어느 날이 잘 됐는지,
메뉴 중에 뭐가 제일 많이 팔렸는지 알고 싶어.
차트로 보여줘.
```

오 사장은 마지막 줄 **"차트로 보여줘"**를 치고 엔터를 눌렀다. 그 순간, 화면 오른쪽에 새 창이 **스르르** 열렸다.

막대 차트가 나타났다. 토요일이 제일 높았다. 화요일이 제일 낮았다. 메뉴별 판매 순위도 표로 나왔다. 1위 아메리카노, 2위 크로플, 3위 카페라떼.

> 🍱 **잠깐, 방금 그 창은 뭐예요?**
>
> Claude 웹앱에서 **"차트로 보여줘", "표로 보여줘", "그림으로 보여줘"** 같이 자연어로 요청하면, 결과가 오른쪽에 별도 창으로 자동으로 열려요. 이걸 공식 이름으로는 **"아티팩트(Artifacts)"**라고 합니다. 복잡한 버튼 누를 필요 없어요. 그냥 말 끝에 "보여줘"만 붙이면 됩니다.
>
> 일부 사용자들은 이 기능을 **"쇼미!"**라고 부르기도 해요. *쇼미 더 머니*의 그 쇼미 맞습니다. 😄 "이 매출 차트로 쇼미~" 하면 오른쪽에 차트가 뿅 하고 나타나는 거죠.

오 사장은 차트를 가만히 봤다.

"화요일이 왜 이렇게 낮지… 근처 직장인들이 재택하는 날인가."

30분 엑셀 작업이 3분이 됐다. 그것도 이렇게 눈에 보이는 그림으로.

---

그 다음 주, 오 사장은 조금 더 욕심을 냈다.

```
매일 아침 6시 30분에 자동으로
어제 매출 요약이랑 오늘 날씨 기반 재고 제안을 만들어줘.
파일 이름은 "일일_브리핑_날짜.md"로 저장해줘.
```

예약 작업 설정이었다. 설정은 딱 한 번이었다. 이후에는 아침마다 알아서 돌아갔다.

다음 날 아침 10시에 카페 문을 열었다. 바탕화면에 파일이 하나 있었다.

`일일_브리핑_0410.md`

열어보니 이랬다.

```
📋 일일 브리핑 — 2026년 4월 10일

어제 매출: 487,000원 (전날 대비 +12%)
- 아메리카노 34잔 / 크로플 18개 / 라떼 11잔

오늘 날씨: 맑음, 기온 16°C → 아이스 음료 수요 예상

재고 제안:
- 아이스 컵: 현재 80개 → 100개 이상 확보 권장
- 크림치즈 (크로플용): 현재 재고 2일치 → 보충 권장
- 원두 (에티오피아 계열): 충분
```

오 사장은 커피를 내리다 말고 파일을 다시 읽었다.

"예전엔 내가 30분 걸리던 걸... 이제 6시 30분에 얘가 기다리고 있네. 나보다 부지런하네."

---

그 주 목요일, 장보러 외출했다. 걷다가 생각났다. 내일 마을 봄 축제가 있는데, 특별 메뉴를 뭘 낼지 아직 못 정했다.

폰을 꺼내 입력했다. Dispatch — 폰에서 집이나 카페 컴퓨터에 지시를 보내는 기능이다.

```
내일 마을 봄 축제 있어.
방문자 많을 것 같은데, 행사 메뉴 3개 제안해줘.
기존 재료로 만들 수 있는 거 위주로.
단가랑 예상 판매 수량도 같이.
```

장바구니 들고 10분 걷다 보니 알림이 왔다. 카페 컴퓨터가 처리를 끝냈다. 메뉴 제안 3개, 예상 단가, 재료 체크리스트.

오 사장은 마트 안에서 그 파일을 보며 쇼핑 목록을 수정했다.

---

Before: 매일 30분 매출 수동 정리 + 월말 2시간 결산.
After: 아침마다 6:30에 이미 완성된 브리핑 파일. 월말 확인 15분.

손님 할머니가 어느 날 말했다. "사장님, 요즘 아침에 여유 있어 보여요."

오 사장은 커피를 내리며 말했다.

"직원 한 명 뽑았어요. 새벽 6시 30분에 출근하는 직원."

할머니가 두리번거렸다.

"어디요?"

"저기요." 노트북을 가리켰다.

---

**이것 하나 기억하세요.** "뭘 시키지?"의 진공상태는 누구나 겪습니다. 그 공백을 이겨내는 방법은 딱 하나 — 작게라도 일단 "안녕하세요"부터 치는 것입니다.

## 📦 이 편의 핵심 기능

| 기능 | 이 이야기에서 한 일 |
|------|-------------------|
| **프로젝트** | "우리 카페 2026" 생성. 카페 정보 한 번만 입력 → 이후 대화마다 자동 기억 |
| **파일 첨부** | `매출_2026_03.xlsx` 드래그 업로드 → Claude가 파일 내용 직접 읽고 분석 |
| **아티팩트** | 일별 매출 차트 + 메뉴 판매 순위표를 오른쪽 창에 시각화 |
| **예약 작업** | 매일 오전 6:30 자동 실행 → `일일_브리핑_날짜.md` 생성, 어제 매출 + 재고 제안 포함 |
| **Dispatch** | 외출 중 폰으로 지시 → 카페 컴퓨터가 알아서 처리, 완료 알림 수신 |
