## 이 페이지는 뭔가요?

Claude Code를 **데스크톱 앱**으로 쓰시는 분들을 위해, 최근 몇 주 사이에 생긴 주요 변화를 한국어로 정리했어요.

> 🏪 **비유로 설명하면**: 자주 가는 편의점이 갑자기 계산대 자리를 바꾸거나 냉장고 위치를 옮겼을 때, 미리 알아두면 당황하지 않잖아요? 앱 업데이트도 마찬가지예요. 미리 읽어두면 "어, 갑자기 왜 이게 생겼지?" 하는 순간이 없어요.

## 🔧 한국어 입력 버그 수정 (v1.7196.0 · 2026-05-12)

### 무슨 문제였나요?

**Quick Entry**(앱 상단 입력창)에서 한글·한자·일본어처럼 **조합 문자**(입력 도중 글자가 완성되기 전에 미리 보이는 방식)를 쓸 때 **글자가 잘리거나 빠지는** 버그가 있었어요.

예를 들어 "안녕하세요"를 입력하려다가 "안녕세" 처럼 글자가 뭉개지는 현상이요.

### 지금은요?

이 버전부터 정상 동작합니다. 한국어 입력기(IME, 아이엠이)를 쓰시는 분들은 앱을 최신 버전으로 업데이트하면 해결돼요.

> 💡 앱 버전 확인: 화면 왼쪽 위 메뉴 → **Claude Code** → **About**에서 현재 버전 번호를 볼 수 있어요.

## 📬 입력한 메시지가 안 날아가요 (v1.6259.0 · 2026-05-05)

### 이전에는?

Claude가 한창 작업 중일 때 메시지를 입력해서 전송하면 **그냥 사라졌어요.** "아, 아직 작업 중이구나" 하고 기다렸다가 다시 타이핑해야 했죠.

### 지금은?

이제 메시지가 **대기열(큐, Queue)**에 쌓입니다. 작업이 끝나면 자동으로 전달돼요.

> 📮 **비유**: 택배 기사님이 배달 중일 때 전화해도 자동응답에 메시지를 남기면 나중에 확인하는 것과 같아요. 이제 "전화 받을 때까지 기다렸다가 다시 걸어야지" 할 필요가 없어요.

---

## 🖥️ 터미널 탭 여러 개 쓰기 (v1.5220.0 · 2026-04-28)

### 이전에는?

하단 터미널 창이 탭 하나뿐이었어요.

### 지금은?

터미널 창 오른쪽 **`+` 버튼**을 누르면 탭을 추가할 수 있어요. 탭 간 전환도 가능하고요.

> 🗂️ **비유**: 인터넷 브라우저에서 탭을 여러 개 열어두는 것처럼, 이제 터미널도 탭으로 나눠서 쓸 수 있어요.

**활용 예시:**
- 탭 1: 서버 실행 중 (`npm run dev`)
- 탭 2: 파일 편집·명령어 입력
- 탭 3: 테스트 실행

💡 채팅에서 **폴더를 오른쪽 클릭** → **"Open in terminal"** 을 선택하면 해당 폴더로 바로 새 탭이 열려요.

## 🔔 작업 완료 알림 (v1.6889.0 · 2026-05-08)

Claude Code가 **Code 세션**에서 작업을 마치면, 다른 앱을 쓰고 있더라도 **OS 알림**(알림 센터)이 와요.

> 📱 **비유**: 세탁기 돌려놓고 거실에서 TV 보다가 "삐삐" 소리 나면 다 됐구나 하고 가는 것처럼요. 터미널 창을 계속 쳐다보지 않아도 돼요.

## 📋 기타 개선 사항

### 예약 작업 관련 (v1.6608.0 · 2026-05-07)

- 예약 작업 삭제 시 **"디스크의 파일도 함께 삭제"** 옵션이 생겼어요.  
  체크하면 `~/.claude/scheduled-tasks/` 안의 관련 파일도 같이 지워져요.

- 예약 작업이 이전에 수동 승인 대기 중에 걸려서 다음 실행이 안 되는 버그 수정됨.

### Code 세션 복원 (v1.6608.0 · 2026-05-07)

- **아카이브(보관)**된 세션에서 메시지를 보내면 자동으로 복원돼요.
- 커밋 안 된 변경 사항이 있는 세션을 아카이브하려 하면 경고 메시지가 떠요.

## 자주 묻는 질문

**Q. 데스크톱 앱은 어떻게 업데이트하나요?**  
앱이 실행 중이면 자동으로 업데이트 알림이 와요. 메뉴 → **Check for Updates**로 수동 확인도 가능해요.

**Q. 버전 번호가 1.7196.0처럼 숫자가 크네요. 이게 정상인가요?**  
네, 정상이에요. Claude Code 데스크톱 앱은 빌드 번호(자동 증가) 방식을 씁니다. "큰 업데이트"와 "작은 패치"를 별도 숫자로 구분하지 않아요.

**Q. CLI(터미널 버전)와 데스크톱 앱 버전이 다른가요?**  
네, 별도로 관리돼요. 이 페이지는 **데스크톱 앱** 전용 changelog예요.  
CLI 변경 내역은 [공식 CLI changelog](https://code.claude.com/docs/en/changelog)에서 확인하세요.
