## 같은 AI, 다른 옷을 입은 것

claude.ai 웹앱, Cowork, Claude Code — 세 가지 모두 Claude와 대화하는 방법입니다.

중요한 것은 **AI 자체는 같다**는 점입니다. 다만 **어떤 환경에서 쓰느냐**에 따라 할 수 있는 것이 달라집니다.

비유하자면 이렇습니다.

> 같은 요리사가 카페, 일반 식당, 전문 레스토랑에서 일하는 것과 같습니다. 요리사는 같지만, 주방 설비에 따라 만들 수 있는 음식이 달라집니다.

## 한눈에 비교

| 항목 | 웹앱 채팅 | 코워크 (Cowork) | Claude Code |
|------|-----------|----------------|-------------|
| **접속 방법** | 브라우저 | 앱 설치 | 터미널 명령어 |
| **설치 필요** | 없음 | 있음 | 있음 |
| **내 파일 접근** | 올려야만 가능 | 직접 접근 가능 | 직접 접근 가능 |
| **코드 실행** | 불가 | 가능 (Computer Use) | 가능 |
| **자동화** | 불가 | 가능 (예약 작업) | 가능 |
| **대화 저장** | 자동 저장 | 자동 저장 | 세션 종료 시 초기화 |
| **초보자 접근성** | 매우 쉬움 | 쉬움 | 어려움 |
| **주요 용도** | 글쓰기, 정보 탐색 | 업무 자동화, 파일 직접 조작 | 개발, 파일 자동화 |

## 웹앱 채팅 (claude.ai)

### 어떤 사람에게 맞나요?

- Claude를 처음 써보는 분
- 설치 없이 바로 시작하고 싶은 분
- 글쓰기, 번역, 요약, 아이디어가 주 용도인 분

### 할 수 있는 것

- 이메일, 보고서, 기획서 작성
- 문서 번역 및 요약
- 아이디어 발상 및 정리
- 파일(PDF, 이미지 등) 올려서 분석
- 프로젝트 기능으로 맥락 유지

### 할 수 없는 것

- 내 컴퓨터 파일에 직접 접근하거나 수정
- 코드를 실행해서 결과 확인
- 반복 작업 자동화

---

## 코워크 (Cowork)

### 어떤 사람에게 맞나요?

- 팀에서 함께 Claude를 쓰고 싶은 분
- 엑셀, PPT, 파일 정리를 자동으로 하고 싶은 분
- 폰에서 일 시키고 퇴근하고 싶은 분 (Dispatch)
- 반복 업무를 예약 실행하고 싶은 분

### 할 수 있는 것

웹앱의 모든 기능 + 업무 자동화

- 내 컴퓨터 파일 직접 접근 및 수정
- 화면 직접 조작 (Computer Use)
- 폰에서 일 시키기 (Dispatch)
- 매일/매주 예약 작업 실행

### 할 수 없는 것

- Git/GitHub 연동 (이건 Claude Code의 영역)
- 코드 전문 작성 (간단한 건 가능)

<div class="note-circle">○ 코워크는 개인 업무 자동화에 특히 강력합니다. 혼자 쓰기에도 딱이에요!</div>

## Claude Code

### 어떤 사람에게 맞나요?

- **클로드 중급 세션** 단계로 올라가고 싶은 분
- 내 컴퓨터 파일을 AI가 직접 만지게 하고 싶은 분
- 반복 업무를 자동화하고 싶은 분
- 코드를 안 배워도 괜찮아요 — 한국어로 지시만 하면 됩니다

### 할 수 있는 것

- 내 컴퓨터 파일 직접 읽기·쓰기·수정
- 코드 작성 + 즉시 실행 + 결과 확인
- 폴더 전체를 분석하거나 수정
- 반복 작업 자동화 스크립트 실행

### 할 수 없는 것 (또는 어려운 점)

- 터미널(검은 화면)에서 시작해야 해요 — 처음엔 낯섦
- 설치·첫 실행 과정이 웹앱보다 살짝 복잡

## 자주 하는 질문

**Q. 웹앱에서 시작해서 나중에 Claude Code로 옮길 수 있나요?**

A. 네. 계정이 같으면 언제든 원하는 방식으로 접속할 수 있습니다. 처음부터 고민하지 않아도 됩니다.

---

**Q. 세 가지가 요금이 다른가요?**

A. Claude Code는 별도 요금이 있습니다. 웹앱과 Cowork는 동일한 구독 플랜(Free / Pro)을 사용합니다.

---

**Q. 웹앱에서 코드를 짜달라고 할 수 있나요?**

A. 코드 내용은 짜줄 수 있습니다. 하지만 그 코드를 직접 실행해서 결과를 확인하는 것은 Claude Code에서만 됩니다. 웹앱에서는 코드 텍스트만 받게 됩니다.
