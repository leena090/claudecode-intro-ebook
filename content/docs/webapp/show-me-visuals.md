## 대화하다가 그림이 불쑥 튀어나옵니다

Claude에게 "**복리가 어떻게 불어나는지 보여줘**"라고 물으면, 말로만 설명하는 게 아니라 **대화창 안에 바로 인터랙티브 차트**가 그려져요. 슬라이더를 움직이면 숫자가 실시간으로 바뀌고, 버튼을 누르면 그래프가 갱신됩니다.

이 기능의 공식 이름은 **"Custom visuals in chat(대화 속 맞춤 시각화)"**. 하지만 사람들은 주로 <mark>**"Show Me(보여줘) 기능"**</mark>이라고 부릅니다. 트리거 문구가 대부분 "보여줘"로 시작하거든요.

<div class="note-star">
⭐ **2026년 3월**에 베타로 공개. 모든 플랜(Free 포함)에서 기본 켜져 있어요. 웹과 데스크탑 앱에서만 동작합니다 — iOS / Android / 코워크(Cowork) 세션에서는 아직 지원 안 됨.
</div>

## 어떻게 불러내나요?

**두 가지 방법**이 있어요.

### 방법 1: Claude가 스스로 판단

뭔가를 설명할 때 "이건 그림으로 보여주는 게 낫겠다" 싶으면 Claude가 알아서 그림을 만들어요. 특히 **숫자·과정·비교** 같은 주제에서 자주 일어나요.

```
저 : 복리 이자가 단리랑 얼마나 달라?
Claude : (자동으로 인터랙티브 차트 생성) 슬라이더를 움직여보세요…
```

### 방법 2: "보여줘"로 직접 요청

원하는 시점에 직접 요청할 수도 있어요. 다음 문구들이 트리거예요.

| 한국어 트리거 | 영어 원문 |
|---|---|
| **"보여줘"**, "그림으로 보여줘" | "Show me…" |
| **"그려줘"**, "다이어그램으로 그려줘" | "Draw this as a diagram" |
| **"시각화해줘"** | "Visualize this" |
| **"시간에 따라 어떻게 바뀌는지"** | "How does this change over time" |
| **"차트로 만들어줘"** | "Chart this data" |

## 실제 예시 5가지

### 예시 1. 커피 비율 계산기 (인터랙티브 도구)

```
커피와 물 비율 계산기 만들어줘. 내리는 방식이랑
몇 잔 만들지 고르면 정확한 양이 나오게.
```

→ 대화창 안에 **드롭다운(내리는 방식) + 숫자 조절기(잔 수)**가 바로 나타나고, 선택을 바꾸면 커피·물의 양이 실시간으로 계산돼요.

### 예시 2. 복리 이자 차트

```
30년 동안 매달 30만 원씩 저축하면 복리로 얼마가 되는지 보여줘.
이자율을 슬라이더로 조절할 수 있게.
```

→ X축 시간, Y축 잔고의 라인 차트. **이자율 슬라이더**를 움직이면 선 모양이 즉시 변합니다.

### 예시 3. 비행기 착륙 패턴 다이어그램

```
비행기가 공항에 착륙할 때 어떤 경로로 도는지 그림으로 보여줘.
```

→ 공항 활주로 + 비행기가 선회하는 선이 애니메이션으로 그려져요.

### 예시 4. 프로세스 흐름도

```
신규 직원 온보딩 과정을 흐름도로 그려줘.
```

→ 블록과 화살표로 단계별 흐름을 시각화.

### 예시 5. 엑셀 데이터 → 차트

> 엑셀 파일을 먼저 채팅에 끌어다 붙이고 나서

```
이 데이터가 뭘 보여주는지 차트로 만들어줘.
```

→ 데이터를 해석해서 가장 적합한 차트 종류(막대 / 라인 / 파이)를 Claude가 고르고 바로 그려줘요.

## 🆚 아티팩트(Artifacts)랑 뭐가 다른가요?

이게 사실 이 챕터의 핵심이에요. 둘 다 "결과물을 따로 보여준다"는 건 비슷한데, **목적이 전혀 다릅니다**.

### 한눈에 보는 비교

| 항목 | **Show Me** (대화 속 시각화) | **아티팩트** (Artifacts) |
|---|---|---|
| 어디에 뜨나 | **대화창 안**에 바로 | 오른쪽 **별도 패널** |
| 수명 | **일회성** — 대화 진행하면 사라지거나 변함 | **계속 저장** — 나중에 다시 열 수 있음 |
| 목적 | **그 순간 이해 돕기** (화이트보드 스케치) | **최종 결과물** (완성본·전달용) |
| 공유 | 어려움 (내보내기 있지만 주 용도 아님) | **링크·다운로드 바로 가능** |
| 수정 | 같은 대화 안에서 자연스럽게 변경 | "이 부분만 고쳐줘" 하면 버전 관리 |
| 대표 예시 | 복리 계산기, 흐름도, 실시간 차트 | 블로그 글, 보고서, 표, 코드, HTML 페이지 |

### 비유로 이해하기

두 기능의 차이를 **회의실 풍경**으로 풀어볼게요.

<div class="note-circle">
🎨 <strong>Show Me</strong> = 회의하다가 <strong>칠판에 그림 그려가며 설명하는 것</strong>. 그 순간 이해를 도우려는 목적. 회의 끝나면 지우개로 지워요.
<br /><br />
📄 <strong>아티팩트</strong> = 회의 후 <strong>정식 보고서로 출력해서 나눠주는 것</strong>. 나중에 읽어보고 공유하려는 목적. 파일로 저장해둡니다.
</div>

### 언제 Show Me?

- "이거 어떻게 돌아가는지 **이해하고 싶어요**"
- "**말로 설명하는 것보다 그림이 나을 것 같아**"
- 대화하면서 숫자/조건을 **바꿔가며 탐색**하고 싶을 때
- 그 **순간**만 보면 되고, 저장할 필요 없을 때

### 언제 아티팩트?

- "이 결과물을 **완성해서 전달**해야 해요"
- "블로그 글 / 보고서 / 표 / 코드를 **다운로드**해야 해요"
- "**나중에 수정하러 다시 올** 거예요"
- "**동료한테 링크**로 보내줘야 해요"

## 자주 묻는 질문

### Q. "보여줘"라고 했는데 아티팩트가 나와요. 왜?

요청의 <mark>**성격이 '전달용 결과물'에 가까우면 Claude가 아티팩트로 판단**</mark>해요. 예를 들어:

- "우리 회사 조직도 보여줘" → **그냥 이미지/다이어그램으로 보고 싶다** → Show Me
- "우리 회사 조직도 **문서로 정리해줘**" → 나중에 공유할 결과물 → 아티팩트

더 명확히 하고 싶으면:
- "**채팅 안에 인터랙티브로** 그려줘" ← Show Me 강제
- "**아티팩트로** 만들어줘" ← 아티팩트 강제

### Q. Show Me는 저장이 안 되나요?

기본은 **일회성**이에요. 필요하면 **내보내기(Export) 버튼**으로 이미지/PDF로 저장할 수 있어요. 하지만 계속 쓸 거라면 처음부터 아티팩트로 만드는 게 편해요.

### Q. 왜 모바일에서는 안 되나요?

인터랙티브 요소(슬라이더·버튼·드롭다운)를 모바일 작은 화면에서 다루기 어렵고, 애니메이션 성능이 떨어져서 <mark>**현재는 웹·데스크탑에서만**</mark> 지원해요. 모바일 지원은 로드맵에 있지만 날짜 미공개.

### Q. 코워크(Cowork) 세션에서는요?

코워크는 제 컴퓨터의 화면을 Claude가 직접 제어하는 모드라, 대화창 안 UI가 단순해요. **코워크 세션에서는 Show Me 대신 일반 아티팩트만** 나옵니다.

### Q. 생성 속도는 어때요?

복잡도에 따라 **대략 20~30초** 걸려요. 구글 이미지 검색 같은 즉시 나오는 결과보다는 느리게 느껴질 수 있어요. 기다리는 동안 다른 걸 해도 됩니다.

## "보여줘"를 고수답게 쓰는 5가지 팁

### 1. 구체적 요청이 훨씬 좋은 그림을 만듭니다

```
❌ 막연히: "차트로 보여줘"
✅ 구체적: "X축은 월, Y축은 매출, 색깔은 지역별로 구분해서 차트로 보여줘"
```

### 2. "조절할 수 있게" 한마디를 넣으세요

인터랙티브 요소를 명시적으로 요청하면 슬라이더·드롭다운이 더 잘 생겨요.

```
"이자율을 슬라이더로 조절할 수 있게 그려줘"
"연도를 바꿔가며 볼 수 있게"
```

### 3. 엑셀·CSV 데이터는 먼저 붙여넣으세요

채팅에 파일을 드래그해서 넣고 "이 데이터를 차트로 보여줘" 하면, 숫자 해석부터 차트 그리기까지 한 번에 끝납니다.

### 4. 결과가 맘에 안 들면 말로 고쳐요

```
"색깔 좀 더 따뜻하게 바꿔줘"
"선 그래프 말고 막대 그래프로 바꿔줘"
"내림차순으로 정렬해줘"
```

대화 흐름 안에서 자연스럽게 수정돼요.

### 5. 저장할 거면 처음부터 아티팩트로

"이 결과를 공유할 거야" 싶으면 **"아티팩트로 만들어줘"** 한마디 추가. 나중에 링크/다운로드 원활합니다.
