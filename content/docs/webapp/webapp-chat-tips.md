## 그냥 쓰는 것과 제대로 쓰는 것은 다릅니다

"Claude한테 물어봤는데 별로 도움이 안 됐어요."

이런 경우 대부분은 Claude의 문제가 아닙니다. 질문 방식을 조금만 바꿔도 결과가 완전히 달라집니다.

---

## 좋은 질문 만드는 3가지 원칙

### 원칙 1: 맥락을 알려주세요

나쁜 예:
```
이메일 써줘.
```

좋은 예:
```
거래처 박 부장님께 보내는 이메일을 써줘.
다음 주 화요일 오후 2시 미팅을 확정 짓는 내용이야.
말투는 예의 바르게, 너무 딱딱하지는 않게.
```

<mark>누가, 무엇을, 어떤 말투로 — 이 3가지만 알려줘도 결과가 훨씬 좋아집니다.</mark>

---

### 원칙 2: 원하는 형식을 말해주세요

```
우리 매장 소개 글을 써줘.
- 분량: 300자 이내
- 형식: 짧은 문단 3개
- 마지막에 전화번호 안내 문구 포함
```

---

### 원칙 3: 예시를 보여주세요

```
이런 스타일로 제품 설명을 써줘:
"부드러운 크림치즈가 가득한 이 케이크는, 한 입 베어물면 입안에서 사르르 녹습니다."
우리 제품은 '유자 마카롱'이야.
```

예시를 하나 보여주면 Claude가 그 스타일을 파악해서 비슷하게 씁니다.

## 파일 첨부하기

입력창 왼쪽의 **클립 모양 아이콘** (또는 + 버튼)을 누르면 파일을 올릴 수 있습니다.

**Windows:**
- 클립 아이콘 클릭 → 파일 선택 → 열기
- 또는 파일을 입력창으로 끌어다 놓기 (드래그 앤 드롭)

**Mac:**
- 클립 아이콘 클릭 → 파일 선택 → 열기
- 또는 Finder에서 파일을 입력창으로 끌어다 놓기

### 올릴 수 있는 파일 종류

| 종류 | 예시 |
|------|------|
| 문서 | PDF, Word(.docx), 텍스트(.txt) |
| 이미지 | JPG, PNG, GIF |
| 데이터 | 엑셀(.xlsx), CSV |

### 활용 예시

```
(계약서 PDF 첨부 후)
"이 계약서에서 해지 조항 부분만 요약해줘."

(사진 첨부 후)
"이 사진에 있는 영어 안내문을 한국어로 번역해줘."

(엑셀 첨부 후)
"이 표에서 매출이 가장 높은 제품 3개만 골라줘."
```

<div class="note-circle">○ 개인 정보나 기밀 문서를 올릴 때는 주의하세요. 회사 보안 정책을 먼저 확인하는 것이 좋습니다.</div>

## 웹 검색 기능 쓰기

Claude는 기본적으로 학습 데이터로만 답합니다. 하지만 <mark>웹 검색 기능을 켜면 지금 이 순간의 최신 정보도 찾아줍니다.</mark>

입력창 옆의 **지구본 아이콘** 또는 검색 아이콘을 누르면 활성화됩니다.

```
(웹 검색 켠 상태)
"오늘 코스피 지수 알려줘."
"요즘 핫한 카페 인테리어 트렌드가 뭐야?"
"2026년 최저임금이 얼마야?"
```

## 대화 관리하기

### 대화 이름 바꾸기

왼쪽 사이드바에서 대화 위에 마우스를 올리면 옵션 버튼이 나옵니다. "이름 바꾸기"를 눌러서 알아보기 쉬운 이름으로 바꾸세요.

**예:** "New conversation" → "5월 거래처 제안서 작업"

### 대화 보관 (Archive)

끝난 프로젝트 대화를 삭제하기는 아깝고, 목록에 계속 보이긴 싫을 때 "보관(Archive)"을 씁니다. 목록에서 사라지지만 언제든 다시 찾을 수 있습니다.

## 키보드 단축키

마우스 없이 더 빠르게 쓰는 방법입니다.

| 동작 | Windows | Mac |
|------|---------|-----|
| 메시지 보내기 | Enter | Return |
| 줄바꿈 (보내지 않고) | Shift + Enter | Shift + Return |
| 새 대화 시작 | Ctrl + Shift + O | Cmd + Shift + O |
| 검색 | Ctrl + K | Cmd + K |

<div class="note-circle">○ 긴 글을 입력할 때는 Shift + Enter로 줄을 나눠 쓰면 읽기도 편하고 Claude도 더 잘 이해합니다.</div>

## 모델 선택하기

입력창 왼쪽 위에 모델 이름이 표시됩니다. 클릭하면 다른 모델을 고를 수 있습니다.

| 모델 | 특징 | 언제 쓰면 좋을까 |
|------|------|----------------|
| **Claude Opus** | 가장 똑똑함, 느림 | 복잡한 분석, 긴 문서 검토 |
| **Claude Sonnet** | 속도와 성능 균형 | 대부분의 일상 업무 |
| **Claude Haiku** | 가장 빠름, 간단한 작업 | 짧은 답변, 빠른 확인 |

솔직히 말씀드리면, 대부분의 경우 **Sonnet**으로 충분합니다. 특별히 아주 어려운 분석이나 긴 문서가 아니라면 Sonnet으로 시작하세요.

<div class="note-circle">○ 무료 플랜은 사용할 수 있는 모델이 제한됩니다. Opus는 Pro 플랜에서 주로 사용합니다.</div>
