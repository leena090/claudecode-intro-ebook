## 프로젝트가 왜 필요한가요?

Claude를 처음 쓰다 보면 이런 상황이 생깁니다.

- "어제 마케팅 계획 짰던 대화가 어디 갔지?"
- "우리 회사 소개를 매번 새 대화마다 다시 설명해야 하나?"
- "영업팀 업무랑 총무팀 업무 대화가 뒤섞여 있어서 찾기 힘들다."

**프로젝트**는 이 문제를 한번에 해결합니다.

비유하면 이렇습니다.

> 책상 서랍을 칸막이로 나눠서, "마케팅", "인사", "총무" 칸으로 분류해두는 것과 같습니다. 관련 서류가 섞이지 않고 각자 자기 칸에 있습니다.

<mark>프로젝트 안에서는 Claude가 이전 대화 내용을 기억합니다.</mark>

---

## 프로젝트 만들기

**Windows / Mac 모두 같은 방법입니다.**

1. 왼쪽 사이드바에서 **"프로젝트"** 섹션을 찾습니다
2. **"+ 새 프로젝트"** 를 클릭합니다
3. 프로젝트 이름을 입력합니다 (예: "마케팅 2026", "고객 응대")
4. 완료

이제 이 프로젝트 안에서 대화를 시작하면, 같은 프로젝트 내 모든 대화가 하나로 연결됩니다.

---

## 프로젝트 지침 설정하기

프로젝트에서 가장 강력한 기능입니다.

프로젝트를 만들면 **"지침(Instructions)"** 을 입력하는 칸이 있습니다. 여기에 Claude에게 항상 알려두고 싶은 것을 적어두면 됩니다.

### 예시: 고객 응대 프로젝트

```
우리 회사는 '행복한 베이커리'입니다.
제품은 케이크, 마카롱, 쿠키입니다.
가격은 케이크 45,000원, 마카롱 2,000원, 쿠키 세트 18,000원입니다.
고객 응대 말투는 친근하되 예의 바르게 해주세요.
환불 정책: 구입 당일 영수증 지참 시 100% 환불 가능.
```

이렇게 한 번 입력해두면, 이 프로젝트 안에서 하는 모든 대화에서 Claude가 이 내용을 이미 알고 시작합니다.

```
(매번 회사 소개 안 해도 됩니다)
나: 마카롱 대량 주문 문의 메일이 왔어. 답장 초안 써줘.
Claude: (행복한 베이커리 마카롱 가격과 정책을 알고 답장 초안을 써줍니다)
```

<div class="note-circle">○ 지침은 언제든 수정할 수 있습니다. 회사 정보나 정책이 바뀌면 지침만 업데이트하면 됩니다.</div>

## 파일 올려두기

프로젝트에 파일을 미리 올려둘 수 있습니다.

- 회사 소개서 PDF
- 제품 카탈로그
- 내부 규정 문서
- 자주 쓰는 양식

파일을 올려두면 대화할 때 "방금 올린 파일 참고해서 답해줘"라고 할 필요도 없습니다. Claude가 알아서 참고합니다.

### 파일 올리는 방법

프로젝트 설정 화면에서 **"파일 추가"** 버튼을 누르고 파일을 선택하면 됩니다.

지원 형식: PDF, Word, 텍스트, 이미지, 엑셀 등

<div class="note-circle">○ 파일 크기 제한이 있습니다. 매우 큰 파일(100MB 이상)은 올리기 전에 내용을 압축하거나 핵심만 발췌하는 것이 좋습니다.</div>

## 실제 활용 예시

### 활용 1: 업무 유형별 분리

| 프로젝트 이름 | 지침에 넣을 내용 |
|--------------|----------------|
| 마케팅 | 브랜드 톤앤매너, 타깃 고객, 캠페인 일정 |
| 고객 응대 | 자주 묻는 질문, 환불 정책, 제품 정보 |
| 인사 총무 | 사내 규정, 복리후생 정보 |
| 개인 학습 | 현재 공부 중인 분야, 수준, 학습 목표 |

---

### 활용 2: 장기 프로젝트 추적

3개월짜리 마케팅 캠페인을 기획한다면, 하나의 프로젝트 안에서 모든 논의를 이어갑니다.

```
[1월] 캠페인 주제 논의
[2월] 콘텐츠 초안 작성
[3월] 결과 분석 및 보고서
```

모두 같은 프로젝트 안에 있어서, 나중에 돌아봐도 흐름이 연결됩니다.

---

### 활용 3: 팀과 공유 (Pro 플랜)

유료 플랜에서는 프로젝트를 팀원과 공유할 수 있습니다.

같은 지침과 파일을 팀 전체가 공유하니, "Claude한테 우리 회사 정보 알려줬어?" 같은 말을 반복할 필요가 없습니다.

## 프로젝트 vs 일반 대화

| | 일반 대화 | 프로젝트 대화 |
|--|---------|-------------|
| 이전 대화 기억 | X (새 대화 시작 시 초기화) | O (프로젝트 내 누적) |
| 파일 미리 올리기 | X | O |
| 공통 지침 설정 | X | O |
| 팀 공유 | X | O (Pro) |

<mark>자주 같은 맥락에서 대화한다면 프로젝트를 쓰는 것이 훨씬 효율적입니다.</mark>
