## 아티팩트가 뭔가요?

Claude에게 "표 만들어줘" 또는 "블로그 글 써줘"라고 하면, 대화창 오른쪽에 별도 창이 하나 열립니다.

그 창에 결과물이 깔끔하게 정리되어 보입니다. 이게 바로 **아티팩트**입니다.

비유하자면 이렇습니다.

> 옆에 앉은 직원에게 보고서 써달라고 했더니, 대화는 대화대로 하면서 완성된 보고서를 옆에 따로 펼쳐서 보여주는 것과 같습니다.

<mark>대화 내용과 결과물이 분리되어 있어서 훨씬 보기 편합니다.</mark>

---

## 어떤 종류가 있나요?

### 문서 (Document)
블로그 글, 이메일, 기획서, 보고서 같은 텍스트 결과물입니다.

```
내일 거래처에 보낼 제안서 초안을 써줘.
우리 제품의 장점 5가지를 소개하는 블로그 글 써줘.
```

### 표 (Table / Markdown)
데이터를 정리한 표입니다.

```
우리 직원 5명의 이름, 부서, 입사일을 표로 만들어줘.
경쟁사 3개의 가격, 특징, 장단점을 비교표로 정리해줘.
```

### 코드 (Code)
프로그램 코드입니다. 비개발자도 자동화 스크립트 같은 간단한 것은 받아서 활용할 수 있습니다.

```
엑셀 파일에서 빈 행을 자동으로 지우는 파이썬 코드 만들어줘.
```

### 다이어그램 (Diagram)
업무 흐름도, 조직도 같은 시각 자료입니다.

```
신규 직원 온보딩 프로세스를 흐름도로 그려줘.
```

### 웹 페이지 미리보기 (React / HTML)
간단한 인터랙티브 화면도 만들 수 있습니다.

```
간단한 설문 폼을 만들어줘. 이름, 연락처, 방문 목적 3가지 입력받는 것으로.
```

## 아티팩트 창 사용법

아티팩트 창에는 여러 가지 버튼들이 있어요.

| 버튼 | 기능 |
|------|------|
| 복사 | 내용을 클립보드에 복사합니다 |
| 다운로드 | 파일로 저장합니다 |
| 전체화면 | 크게 봅니다 |
| 코드/미리보기 토글 | 코드 보기와 완성된 모습 보기 전환 (HTML/React만) |

<div class="note-circle">○ 복사 버튼을 누른 뒤 Word나 한글 문서에 붙여넣기 하면 바로 편집할 수 있습니다.</div>
<div class="note-circle">○ HTML·React 아티팩트는 <strong>코드 보기</strong>와 <strong>미리보기</strong> 두 모드가 있어요. 토글로 전환하면서 결과를 확인하세요.</div>

## 수정하고 싶을 때

아티팩트는 대화를 계속하면서 계속 수정할 수 있습니다.

```
(제안서 아티팩트가 열려 있는 상태)

나: 두 번째 단락을 좀 더 친근한 말투로 바꿔줘.
→ Claude가 아티팩트를 바로 수정해줍니다.

나: 마지막에 연락처 안내 문단 하나 추가해줘.
→ 또 바로 수정됩니다.
```

<mark>따로 저장할 필요 없이, 대화하면서 계속 다듬어 나갈 수 있습니다.</mark>

## 실제 활용 예시 3가지

### 예시 1: 블로그 글 쓰기

```
우리 카페의 새 메뉴 '유자 라테'를 소개하는 블로그 글을 써줘.
분량은 500자 정도, 따뜻하고 친근한 말투로.
```

오른쪽에 블로그 글이 바로 나타납니다. 마음에 안 드는 부분은 "두 번째 문단 좀 더 생생하게 써줘"처럼 이야기하면 됩니다.

---

### 예시 2: 비교표 만들기

```
아이폰 15, 삼성 S24, 구글 픽셀 8을 비교하는 표 만들어줘.
항목은 가격, 배터리, 카메라, 한국 서비스센터 유무로.
```

표가 아티팩트로 생성됩니다. 복사해서 보고서에 바로 붙여넣을 수 있습니다.

---

### 예시 3: 업무 흐름도

```
고객 불만 접수부터 처리 완료까지의 업무 흐름을 다이어그램으로 그려줘.
단계: 접수 → 담당자 배정 → 원인 파악 → 해결 → 고객 안내 → 완료
```

흐름도가 아티팩트로 나타납니다.

<div class="note-circle">○ 아티팩트가 안 보인다면? 화면 오른쪽이 숨겨져 있을 수 있습니다. 아티팩트 영역을 다시 열어보세요.</div>

## 다운로드는 어떻게 하나요?

아티팩트 창 안의 **다운로드 버튼(⬇️ 아이콘)**을 누르면 됩니다.

- 문서 → `.md` 또는 `.txt` 파일로 저장
- 코드 → 해당 언어 파일로 저장 (`.py`, `.js` 등)
- HTML → `.html` 파일로 저장

Word 파일로 바로 받을 수는 없지만, 복사해서 Word에 붙여넣기 하면 됩니다.

## 🤔 가장 헷갈리는 것들 — FAQ

> 이 섹션은 실제 사용자들이 가장 많이 묻고 헷갈려하는 **아티팩트 저장·컨텍스트·세션 이동** 관련 질문을 정리한 거예요. 꼭 읽어보세요.

### Q1. 작업하다가 **대화창을 닫으면** 아티팩트가 사라지나요?

**답: 안 사라집니다. 단, 플랜에 따라 다릅니다.**

| 플랜 | 닫으면? |
|---|---|
| **Free** | 대화 자체는 남아있고 거기서 열 수는 있음. 사이드바 영구 저장은 없음 |
| **Pro / Max / Team / Enterprise** | **사이드바 "Artifacts" 공간에 자동 등록** → 언제든 꺼내 볼 수 있음 |

사이드바에서 **Artifacts** 아이콘을 누르면 내가 만든 아티팩트가 한 곳에 모여있어요.

### Q2. **컨텍스트가 다 차면** 아티팩트도 날아가나요?

**답: 아니요. 아티팩트는 대화 컨텍스트와 별개로 저장됩니다.**

대화가 200K 토큰에 가까워지면 Claude가 **앞부분을 자동 요약**해서 공간을 확보해요(요약 처리는 사용량 한도에 안 잡힙니다). 이 과정에서:

- **✅ 아티팩트 자체**: 별도 저장소에 있어서 그대로 유지
- **⚠️ 대화 내용**: 일부가 요약으로 대체됨. Claude는 "왜 이렇게 만들었는지"의 **이유**를 일부 잊을 수 있음

### Q3. 대화가 너무 길어져서 **"최대 길이에 도달"** 하면?

이때 선택지는 3가지예요.

| 선택지 | 이럴 때 추천 |
|---|---|
| **새 대화 시작** | 다음 작업이 큰 틀에서 다른 주제일 때 |
| **아티팩트 참조하고 새 대화** | 같은 아티팩트를 이어서 다듬을 때 → 사이드바에서 아티팩트 열고 "이거 이어서 작업해줘" |
| **요약 후 새 대화** | "지금까지 한 작업을 3문단으로 요약해줘" → 복사 → 새 대화 첫 메시지로 붙여넣기 |

### Q4. **새 대화로 옮기면** 기존 작업이 날아가나요?

**답: 두 가지로 나눠서 기억하세요.**

#### 💡 아티팩트로 만든 결과물 → **안 날아갑니다**

사이드바 Artifacts에 남아있어요. **"Remix this Artifact"** 버튼으로 새 대화에서 이어 작업할 수 있습니다.

#### ⚠️ 대화 중 브레인스토밍·맥락·결정 근거 → **날아갈 수 있어요**

그래서 중요한 논의는 마지막에 **"아티팩트로 정리해줘"** 한 마디로 남겨두는 습관을 들이세요.

### Q5. **버전 관리**는 되나요?

네. 아티팩트 창 상단의 **버전 선택기**로 이전 버전으로 돌아갈 수 있어요. "아까 세 번째 버전이 나았던 것 같은데…" 할 때 복구 가능.

### Q6. **Published(공개)** vs **Private(비공개)** 차이는?

| | Private (기본) | Published |
|---|---|---|
| 접근 | 나만 | 공개 URL로 누구나 |
| 저장 | Pro+ 이상 사이드바 | **영구 저장 확실** |
| stateful(데이터 쌓는 앱) | ❌ | **✅ 가능** |
| Unpublish | — | 가능, 단 데이터는 남음 |

아티팩트가 **중요한 작업**이면 한 번 **Publish**해두면 가장 안전해요.

### Q7. 여러 대화에서 **같은 아티팩트 이어 쓰기** 가능한가요?

네. 사이드바에서 해당 아티팩트를 열고 **"Remix this Artifact"**를 누르면 그 아티팩트 내용을 새 대화 맥락에 불러와서 이어 작업합니다. 컨텍스트가 꽉 차서 대화를 옮겨야 할 때의 정석 방법이에요.
