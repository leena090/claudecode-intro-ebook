## Claude를 만나는 가장 쉬운 방법

Claude를 처음 쓰고 싶은데 어디서 시작해야 할지 모르겠다면, 답은 간단합니다.

<mark>브라우저를 열고 claude.ai에 접속하면 끝입니다.</mark>

설치할 것도 없고, 복잡한 설정도 없습니다. 인터넷이 되는 컴퓨터라면 바로 시작할 수 있습니다.

---

## 접속 방법

**Windows든 Mac이든 방법은 같습니다.**

1. 크롬, 엣지, 사파리 등 아무 브라우저나 엽니다
2. 주소창에 `claude.ai` 를 입력하고 엔터를 누릅니다
3. 회원가입 화면이 나옵니다

<div class="note-circle">○ 이미 구글 계정이 있으면 "Google로 계속하기"를 누르면 30초 만에 가입 끝입니다.</div>

---

## 무료로 쓸 수 있나요?

네, 무료 플랜이 있습니다. 처음에는 무료로 충분합니다.

| 구분 | 무료 (Free) | 유료 (Pro, 월 약 3만원) |
|------|-------------|------------------------|
| 사용량 | 하루 일정 횟수 제한 | 훨씬 많이 사용 가능 |
| 모델 | 기본 모델 | 최고 성능 모델 포함 |
| 프로젝트 | 제한적 | 무제한 |
| 우선 처리 | 보통 | 빠름 |

<div class="note-circle">○ 처음 2~3주는 무료 플랜으로 충분합니다. "이게 내 생활에 진짜 도움이 된다" 느껴질 때 유료로 바꿔도 늦지 않습니다.</div>

## 화면 구성 한눈에 보기

처음 접속하면 이런 화면이 나옵니다.

```
┌─────────────────────────────────────┐
│  ☰  Claude         [새 대화] [프로필] │  ← 상단 메뉴
├──────────┬──────────────────────────┤
│          │                          │
│  최근    │   안녕하세요!            │
│  대화    │   무엇을 도와드릴까요?   │  ← 대화 화면
│  목록    │                          │
│          │                          │
│  프로젝트│                          │
│          ├──────────────────────────┤
│          │  [메시지를 입력하세요  ] │  ← 입력창
└──────────┴──────────────────────────┘
```

- **왼쪽**: 이전 대화 목록, 프로젝트 목록
- **가운데**: 대화가 펼쳐지는 공간
- **아래**: 메시지를 입력하는 창

---

## 첫 대화 시작하기

아래 입력창에 하고 싶은 말을 그냥 쓰면 됩니다.

```
이메일 한 통 써줘. 거래처 김부장님께 다음 주 미팅 날짜 확인하는 내용으로.
```

엔터를 누르거나 오른쪽 보내기 버튼을 누르면 Claude가 바로 답변합니다.

<div class="note-circle">○ 말할 때 격식 차릴 필요 없습니다. "이메일 써줘"처럼 편하게 말해도 됩니다. Claude는 다 알아듣습니다.</div>

## 이런 것들을 바로 해볼 수 있습니다

### 글쓰기
```
부서 회의록을 정리해줘. (내용 붙여넣기)
보도자료 초안 써줘.
사과 문자 어떻게 쓰면 좋을까?
```

### 정보 찾기 / 요약
```
이 계약서 핵심 내용만 요약해줘. (파일 첨부)
요즘 ChatGPT랑 Claude 차이가 뭐야?
```

### 아이디어 만들기
```
신제품 이름 10가지 추천해줘.
직원 생일 파티 이벤트 아이디어 좀 줘.
```

### 번역
```
이 영어 이메일 한국어로 번역해줘.
내가 쓴 한국어를 자연스러운 영어로 바꿔줘.
```

---

## 대화가 끝나면

대화는 자동으로 저장됩니다. 왼쪽 사이드바에서 언제든 다시 볼 수 있습니다.

새로운 주제로 대화하고 싶으면, 왼쪽 위 "새 대화" 버튼을 누르세요.

<mark>이전 대화와 새 대화는 서로 연결되지 않습니다.</mark> 완전히 새로운 출발입니다.
