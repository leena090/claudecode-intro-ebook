# Claude Code 웹이란? — 브라우저에서 바로 코딩

## 한 줄 요약

<mark>설치 없이, 내 컴퓨터가 꺼져 있어도 AI가 코딩을 계속 해줍니다.</mark>

---

## 뭐가 다른 건가요?

지금까지 쓰던 Claude Code는 내 컴퓨터에 설치해서 쓰는 방식이었습니다.

Claude Code 웹은 다릅니다.

브라우저 주소창에 `claude.ai/code` 를 입력하면 바로 시작됩니다. 설치할 것도 없고, 터미널을 열 필요도 없습니다.

비유하자면 이렇습니다.

> 예전에는 내 집 주방에서 요리했다면, 이제는 음식점 주방을 빌려서 쓰는 것과 같습니다. 도구도 다 갖춰져 있고, 내가 자리를 비워도 요리는 계속 됩니다.

---

## 가장 큰 차이점 세 가지

### 1. 설치가 필요 없습니다

내 컴퓨터에 아무것도 깔지 않아도 됩니다. 크롬, 엣지, 사파리 — 평소 쓰는 브라우저만 있으면 됩니다.

### 2. 내 컴퓨터가 꺼져도 됩니다

AI는 Anthropic의 클라우드 서버(컴퓨터)에서 작동합니다. 내가 자리를 뜨거나 컴퓨터를 꺼도 AI는 코딩을 멈추지 않습니다.

<div class="note-circle">○ 쉽게 말하면, AI가 내 대신 밤새 일하고 아침에 결과를 가져다 줍니다.</div>

### 3. 개발 환경이 이미 준비되어 있습니다

서버 안에는 코딩에 필요한 도구가 이미 다 설치되어 있습니다.

- Python, Node.js, Ruby, PHP, Java, Go, Rust, C++
- PostgreSQL 16 (데이터베이스)
- Redis 7.0 (캐시 저장소)

내가 따로 뭔가를 설치할 필요가 없습니다.

---

## 누구에게 맞는 도구인가요?

Claude Code 웹은 이런 분들께 특히 잘 맞습니다.

- 컴퓨터에 뭔가 설치하는 게 불안한 분
- 노트북과 데스크톱 두 대를 번갈아 쓰는 분
- 카페나 외출 중에 스마트폰으로 진행 상황을 확인하고 싶은 분
- 큰 프로젝트를 AI에게 맡기고 기다리고 싶은 분

---

## 시작하기 전에 필요한 것

딱 두 가지만 있으면 됩니다.

| 필요한 것 | 설명 |
|---|---|
| Claude 유료 플랜 | Pro, Max, Team, Enterprise 중 하나 |
| GitHub 계정 | 무료 계정으로 충분합니다 |

<div class="note-circle">○ GitHub는 코드를 저장하고 관리하는 곳입니다. Claude Code 웹은 GitHub와 연결해서 작동합니다. GitHub 계정이 없다면 github.com에서 무료로 만들 수 있습니다.</div>

---

## 현재 상태 안내

Claude Code 웹은 지금 **리서치 프리뷰(Research Preview)** 단계입니다.

쉽게 말하면, 아직 개발 중인 기능을 먼저 써볼 수 있게 열어준 상태입니다. 기능이 계속 추가되고 있고, 간혹 예상치 못한 동작이 있을 수 있습니다.

<div class="note-circle">○ 리서치 프리뷰라도 실제 작업에 충분히 쓸 수 있는 수준입니다. 단, 중요한 프로젝트는 GitHub에 백업을 꼭 해두세요.</div>
