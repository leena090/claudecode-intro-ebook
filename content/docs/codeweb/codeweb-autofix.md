# Auto-fix — 코드 올리면 AI가 알아서 고쳐줌

## 먼저 알아두기: PR이 뭔가요?

**PR(Pull Request)**은 "내가 수정한 코드를 확인해주세요"라고 요청하는 것이에요. 

워드 문서로 비유하면 이렇습니다:
- 내가 문서를 수정함 → 팀장한테 "이렇게 바꿨는데 괜찮을까요?" 보냄 → 팀장이 확인하고 "OK" 하면 반영됨

코딩에서도 마찬가지예요. 코드를 고치고 → PR을 올리면 → 다른 사람(또는 AI)이 확인하고 → 괜찮으면 반영됩니다.

---

## 이 기능이 왜 대단한가요?

코딩을 하다 보면 이런 상황이 생깁니다.

1. 코드를 작성해서 GitHub에 올린다 (PR 생성)
2. 자동 테스트가 돌아가는데 "실패"가 뜬다
3. 팀원이 "이 부분 이렇게 바꿔줘"라고 댓글을 단다
4. 다시 수정하고, 다시 올리고, 다시 테스트…

이걸 사람이 하면 반나절이 날아갑니다.

<mark>Auto-fix를 켜두면 AI가 이 모든 과정을 자동으로 처리합니다.</mark>

---

## Auto-fix가 하는 일

Auto-fix는 PR을 지켜보다가 두 가지 상황에서 자동으로 행동합니다.

**상황 1 — 자동 테스트가 실패했을 때**

많은 프로젝트에는 코드를 올리면 자동으로 테스트가 돌아가는 설정(CI, Continuous Integration)이 있습니다. 테스트가 실패하면 AI가 오류 메시지를 읽고 직접 코드를 고쳐서 다시 커밋합니다.

**상황 2 — 리뷰어가 댓글을 달았을 때**

팀원이나 협업자가 PR에 "이 함수 이름 바꿔줘" 또는 "여기 에러 처리 빠진 것 같아"라고 댓글을 달면, AI가 그 댓글을 읽고 수정 작업을 자동으로 진행합니다.

<div class="note-circle">○ 마치 24시간 대기 중인 보조 개발자가 있는 것과 같습니다. PR을 올려두면 AI가 문제를 발견하고, 댓글 요청도 처리하고, 수정된 코드를 다시 올려줍니다.</div>

---

## Auto-fix 켜는 방법

Auto-fix는 Claude Code 웹 설정에서 켤 수 있습니다.

### 1. 설정 화면 열기

claude.ai/code에 접속한 후, 작업 중인 저장소를 선택합니다. 화면 오른쪽 상단 또는 설정 메뉴에서 **"Auto-fix"** 또는 **"자동 수정"** 옵션을 찾습니다.

### 2. Auto-fix 활성화

토글 버튼을 켜서 활성화합니다. 이제 이 저장소의 모든 PR에서 Auto-fix가 작동합니다.

### 3. 저장소별 설정

Auto-fix는 저장소마다 개별적으로 설정할 수 있습니다. 연습용 저장소에서 먼저 테스트해보는 것을 권장합니다.

---

## AI가 고친 내용은 어디서 확인하나요?

AI가 수정 작업을 완료하면, PR 페이지에 새로운 커밋이 추가됩니다.

GitHub에서 해당 PR을 열면 아래와 같은 내용을 볼 수 있습니다.

- AI가 추가한 커밋 목록
- 각 커밋에서 무엇이 바뀌었는지 diff 보기
- AI가 왜 이렇게 수정했는지 자동으로 작성된 설명

<mark>AI가 수정한 내용이 마음에 들지 않으면 언제든지 직접 다시 수정할 수 있습니다.</mark>

---

## 직접 개입해야 할 때

Auto-fix는 편리하지만, AI가 혼자 판단하기 어려운 상황도 있습니다. 이럴 때는 직접 확인하고 방향을 알려주세요.

**이런 상황에서 직접 개입하세요:**

- AI가 같은 오류를 3번 이상 계속 고치려고 시도할 때
- 오류 메시지가 코드 문제가 아니라 환경 설정 문제일 때 (예: 비밀번호, API 키 설정)
- 리뷰어의 댓글이 모호해서 여러 가지로 해석될 수 있을 때

이런 상황에서는 PR 댓글에 직접 설명을 추가하거나, Claude Code 웹 대화창에서 "이 오류는 환경 설정 문제야, 코드는 건드리지 마" 같이 명확하게 안내해주세요.

---

## 실제 사용 예시

혼자 개발하는 분들도 Auto-fix를 이렇게 활용할 수 있습니다.

```
1. 내가 코드를 작성하고 PR을 생성한다
2. 테스트가 자동으로 돌아간다
3. 실패한 테스트가 있으면 AI가 자동으로 고친다
4. 아침에 일어나서 보면 모든 테스트가 통과된 상태다
```

<div class="note-circle">○ 잠자는 동안 AI가 오류를 다 잡아준다는 게 처음엔 믿기 어렵지만, 실제로 그렇게 됩니다.</div>

## 자주 묻는 질문

**Q. AI가 잘못 고치면 어떻게 되나요?**

GitHub의 PR은 모든 변경 이력이 남습니다. AI가 잘못 고쳐도 이전 상태로 언제든지 되돌릴 수 있습니다. 두려워할 필요 없습니다.

**Q. Auto-fix를 켜두면 AI가 마음대로 코드를 바꾸나요?**

아닙니다. Auto-fix는 PR 안에서만 작동합니다. PR에 올라온 변경 내용과 관련된 오류, 그리고 리뷰어 댓글에 대해서만 수정합니다. 다른 파일이나 기능에 손대지 않습니다.

**Q. 개인 프로젝트에서도 쓸 수 있나요?**

네. 혼자 하는 프로젝트에서도 Auto-fix를 사용할 수 있습니다. 테스트 실패 자동 수정 기능이 특히 유용합니다.
