# 원격 세션 — 터미널과 웹을 오가며 작업하기

<div class="note-circle">
○ 이 가이드는 터미널(명령어 창)에 익숙한 분들을 위한 내용입니다. 아직 터미널이 낯설다면 건너뛰어도 괜찮아요!
</div>

터미널에서 Claude Code를 이미 써보셨다면, 여기서 소개하는 기능들이 굉장히 유용할 거예요.

---

## 핵심 개념: 세션이란?

세션(session)은 "AI와 나눈 하나의 작업 단위"라고 생각하면 됩니다.

터미널에서 `claude` 를 실행하면 하나의 세션이 시작됩니다. 이 세션을 웹 브라우저로 옮기거나, 반대로 웹 세션을 터미널로 가져올 수 있습니다.

---

## --remote: 터미널에서 웹 세션 시작하기

`--remote` 플래그를 사용하면 터미널에서 명령어를 입력해도, 실제 작업은 Anthropic 클라우드 서버에서 진행됩니다.

### Mac 터미널

```bash
claude --remote
```

### Windows PowerShell

```powershell
claude --remote
```

<div class="note-circle">○ Mac과 Windows 모두 명령어가 동일합니다.</div>

이 명령어를 실행하면 터미널에 링크가 하나 나타납니다. 그 링크를 브라우저에서 열면 claude.ai/code에서 세션을 이어볼 수 있습니다.

**언제 유용한가요?**

집에서 터미널로 작업을 시작했는데, 외출하면서 노트북을 들고 나가기 귀찮을 때. `--remote` 로 시작하면 클라우드에서 작업이 계속 돌아가고, 어느 기기에서든 브라우저로 확인할 수 있습니다.

---

## --teleport: 웹 세션을 터미널로 가져오기

반대 방향도 됩니다. claude.ai/code에서 작업 중인 세션을 내 컴퓨터 터미널로 가져올 수 있습니다.

웹 화면에서 세션 ID 또는 연결 코드를 복사한 후, 터미널에서 아래와 같이 입력합니다.

### Mac 터미널

```bash
claude --teleport [세션 ID]
```

### Windows PowerShell

```powershell
claude --teleport [세션 ID]
```

<mark>이제 터미널에서 계속 작업할 수 있습니다.</mark>

**언제 유용한가요?**

스마트폰으로 claude.ai/code에서 간단한 지시를 내리다가, 집에 돌아와서 본격적으로 터미널 작업을 이어가고 싶을 때 씁니다.

---

## 스마트폰으로 모니터링하기

Claude Code 웹에서 시작한 작업은 Claude iOS/Android 앱에서도 확인할 수 있습니다.

1. 스마트폰에 Claude 앱을 설치합니다 (App Store 또는 Google Play에서 무료 다운로드)
2. 같은 계정으로 로그인합니다
3. 진행 중인 세션 목록이 보입니다

<div class="note-circle">○ 외출 중에 "AI가 작업을 끝냈나?" 확인하고 싶을 때 아주 편리합니다. 결과를 보고 추가 지시를 내릴 수도 있습니다.</div>

---

## 멀티태스크: 여러 작업 동시에 돌리기

Claude Code 웹은 여러 세션을 동시에 실행할 수 있습니다. 각 세션은 서로 다른 독립된 서버에서 돌아갑니다.

예를 들어 이런 식으로 활용할 수 있습니다.

```
세션 1: 로그인 기능 만들기
세션 2: 상품 목록 페이지 만들기
세션 3: 관리자 대시보드 만들기
```

세 가지 작업이 동시에 진행됩니다. 내가 잠든 사이에 세 AI가 각자 맡은 일을 합니다.

**어떻게 시작하나요?**

claude.ai/code에서 새 세션을 시작하는 버튼(보통 "+" 또는 "New Task")을 클릭하면 됩니다. 각 세션에 저장소와 지시 사항을 입력하면 됩니다.

<div class="note-circle">○ 세션마다 별도의 서버가 할당되므로, 서로 간섭하지 않습니다. 각 세션의 결과는 따로 PR로 만들어집니다.</div>

---

## 스케줄 트리거: 정해진 시간에 자동 실행하기

매일 또는 매주 반복해야 하는 작업이 있다면, 스케줄 트리거를 설정할 수 있습니다.

시간을 정해두면 AI가 알아서 그 시간에 일을 시작합니다. 알람 시계처럼 "이 날 이 시간에 이 작업을 해줘"라고 예약하는 거예요.

**설정 예시 (claude.ai/code 설정 화면에서 입력):**

```
매일 오전 9시에 GitHub 이슈 목록을 정리해서 요약 파일을 만들어줘
```

```
매주 월요일에 지난 주에 추가된 코드를 검토하고 개선할 점을 리포트로 작성해줘
```

<mark>AI가 내 대신 정기 작업을 자동으로 처리해줍니다.</mark>

---

## 실제 워크플로우 예시

### 예시 1: 퇴근 후 자리 비우기

```
1. 퇴근 전에 claude.ai/code에서 세션 시작
2. "오늘 오후 6시부터 내일 아침 9시까지 이 기능 개발해줘"라고 지시
3. 귀가, 식사, 수면
4. 아침에 스마트폰 앱에서 결과 확인
5. 마음에 들면 PR 승인
```

### 예시 2: 외출 중 긴급 수정

```
1. 외출 중에 스마트폰으로 Claude 앱 접속
2. "로그인 버튼이 안 눌린다는 제보가 왔어, 바로 확인하고 고쳐줘"라고 지시
3. 카페에서 커피 마시는 동안 AI가 수정
4. 노트북을 열면 PR이 생성되어 있음
```

### 예시 3: 터미널 작업을 웹으로 이관

```
# Mac 터미널에서 작업 시작
claude --remote

# 터미널에 URL이 출력됨:
# https://claude.ai/code/sessions/abc123

# 브라우저에서 위 URL을 열면 동일한 세션 계속 진행
```

## 자주 묻는 질문

**Q. --remote로 시작하면 내 컴퓨터는 안 써도 되나요?**

네. `--remote` 플래그를 쓰면 실제 작업은 Anthropic 클라우드 서버에서 이루어집니다. 내 컴퓨터는 명령을 전달하는 역할만 합니다. 이후 브라우저나 앱으로 계속 모니터링할 수 있습니다.

**Q. 세션이 몇 개까지 동시에 가능한가요?**

Claude 플랜에 따라 다를 수 있습니다. Pro 플랜도 여러 세션을 동시에 실행할 수 있습니다. 정확한 한도는 claude.ai의 플랜 안내 페이지에서 확인하세요.

**Q. 스케줄 트리거는 어디서 설정하나요?**

claude.ai/code의 설정 메뉴에서 "Scheduled Tasks" 또는 "스케줄"을 찾으면 됩니다. 아직 리서치 프리뷰 단계이므로 기능이 계속 추가되고 있습니다.
