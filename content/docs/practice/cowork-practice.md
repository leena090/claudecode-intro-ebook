## 이번 실습에서 할 것

코워크(Cowork)를 써서 **내 컴퓨터의 파일을 자동으로 정리**하는 걸 해볼 거예요.

준비물:
- Claude Desktop 앱 (설치 완료)
- Pro 이상 요금제
- 정리하고 싶은 파일들이 있는 폴더

---

## Step 1: 코워크 탭 열기

Claude Desktop 앱을 실행하고, 상단의 **Cowork** 탭을 클릭하세요.

```
[Chat]  [Cowork]  [Code]
         ↑ 이걸 클릭
```

---

## Step 2: 파일 접근 허용하기

처음 코워크를 쓰면 파일 접근 권한을 요청해요.

**Mac:** "파일 접근 허용" 팝업 → "허용" 클릭
**Windows:** "폴더 접근 허용" 팝업 → "예" 클릭

---

## Step 3: 파일 정리 요청하기

코워크 채팅창에 이렇게 입력하세요:

```
Desktop 폴더에 있는 파일들을 종류별로 정리해줘.

- 이미지 파일(jpg, png) → "사진" 폴더로
- 문서 파일(pdf, docx, hwp) → "문서" 폴더로
- 나머지는 그대로 두기
- 정리 결과를 표로 보여줘
```

---

## Step 4: 결과 확인하기

Claude가 알아서:
1. Desktop 폴더를 스캔합니다
2. 파일 종류를 판별합니다
3. "사진", "문서" 폴더를 만듭니다
4. 파일을 이동합니다
5. 결과를 표로 보여줍니다

```
정리 완료!

| 파일명 | 원래 위치 | 이동한 폴더 |
|--------|----------|-----------|
| 가족사진.jpg | Desktop | Desktop/사진 |
| 보고서.pdf | Desktop | Desktop/문서 |
| ... | ... | ... |
```

<div class="note-circle">
○ 걱정 마세요! Claude가 파일을 이동하기 전에 "이렇게 할까요?" 하고 물어봅니다. 확인 후 진행돼요.
</div>

---

## Step 5: 추가 요청해보기

한 번 더 해볼까요? 이번엔 파일 내용 요약:

```
문서 폴더에 있는 PDF 파일들 제목과 내용 요약을 표로 정리해줘
```

Claude가 각 PDF를 읽고 한 줄씩 요약해줍니다!

---

## 코워크 실습 아이디어 모음

| 해보고 싶은 것 | 이렇게 요청하세요 |
|-------------|----------------|
| 사진 날짜별 정리 | "사진 폴더의 이미지를 연도별로 분류해줘" |
| 중복 파일 찾기 | "Desktop에 같은 파일이 여러 개 있는지 확인해줘" |
| 엑셀 데이터 요약 | "이 엑셀 파일의 월별 합계를 구해줘" |
| 이름 일괄 변경 | "이 폴더 파일들을 날짜_이름 형식으로 바꿔줘" |

---

## 주의할 점

- 중요한 파일을 다루기 전에 **백업을 먼저** 해두세요
- Claude가 하려는 작업을 보여줄 때 **꼼꼼히 확인**하고 승인하세요
- 처음에는 **중요하지 않은 파일**로 연습해보세요
