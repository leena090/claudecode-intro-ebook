## 다이나믹 워크플로우(Dynamic Workflows)가 뭔가요?

**다이나믹 워크플로우**는 Claude가 직접 **작업 계획 스크립트를 작성하고**, 그 스크립트대로 많은 **서브에이전트(subagent)** 를 동시에 실행해서 큰 작업을 빠르게 처리하는 기능이에요.

> 🍱 **비유**: 혼자 200칸짜리 건물 청소를 맡으면 열흘이 걸리지만, 청소 회사(Claude)가 청소부(서브에이전트) 200명을 각 방에 배치해서 동시에 청소하면 하루 만에 끝나는 것처럼요. 그 배치 계획도 Claude가 알아서 짜줘요.

핵심 포인트:
- Claude가 **스크립트(작업 계획)를 먼저 작성** → 여러분이 확인 → 실행
- 서브에이전트들이 **병렬로** 각자 맡은 부분 처리
- 스크립트를 **파일로 저장해서 나중에 다시 쓸 수 있어요**

---

## 어떤 상황에서 쓰면 좋을까요?

| 상황 | 예시 |
|------|------|
| 📁 **코드베이스 전체 감사** | "모든 파일에서 SQL 인젝션 취약점 찾아줘" |
| 🔄 **대규모 마이그레이션** | "Python 2 코드 전부 Python 3으로 바꿔줘 (파일 300개)" |
| 🔍 **교차 검증 연구** | "같은 버그를 3가지 다른 방법으로 각각 분석해줘" |
| 📊 **병렬 데이터 처리** | "API 응답 로그 파일 100개에서 에러 패턴 찾아줘" |

## 기본 사용법

### 1단계: 작업 시작

```bash
# Claude에게 큰 작업 요청
/workflow "프로젝트 전체에서 사용 안 하는 함수 찾아서 목록 만들어줘"
```

Claude가 먼저 **계획 스크립트를 보여줘요**:
```
📋 워크플로우 계획 (총 23개 서브태스크)
──────────────────────────────────────
1. 파일 목록 수집 (1개 에이전트)
2. 함수 사용 분석 (20개 에이전트 병렬)
3. 결과 취합 (1개 에이전트)
4. 최종 보고서 (1개 에이전트)

예상 소요 시간: 약 8분
예상 토큰: 약 45,000

실행하시겠어요? [y/n]
```

### 2단계: 확인 후 실행

계획이 마음에 들면 `y`로 승인해요. 서브에이전트들이 병렬로 작업을 시작해요.

### 3단계: 스크립트 저장 (재사용)

```bash
# 이번에 만든 워크플로우를 파일로 저장
/workflow save audit-unused-functions.json

# 나중에 다시 실행
/workflow run audit-unused-functions.json
```

> 🍱 **비유**: 한번 잘 짠 레시피(스크립트)를 저장해두면, 다음에 같은 요리를 할 때 처음부터 다시 만들 필요 없이 레시피대로 바로 조리할 수 있어요.

## 일반 서브에이전트와 뭐가 다른가요?

| 구분 | 일반 서브에이전트 | 다이나믹 워크플로우 |
|------|-------------------|-------------------|
| **에이전트 수** | 대개 1~5개 | 수십~수백 개 |
| **계획 주체** | 여러분이 직접 설계 | Claude가 스크립트 자동 작성 |
| **재사용** | 어려움 | 스크립트 저장 후 재실행 가능 |
| **적합한 작업 규모** | 중소 규모 | 대규모, 반복성 높은 작업 |

## 주의사항

<div class="note-circle">
○ 한 번에 너무 많은 토큰을 쓸 수 있어요 — 실행 전 예상 토큰 수 반드시 확인<br />
○ 계획 스크립트를 실행 전에 꼭 검토하세요 — Claude가 짠 계획도 틀릴 수 있어요<br />
○ 중간에 멈추고 싶으면: <code>Ctrl+C</code> → 이미 완료된 서브에이전트 결과는 보존돼요
</div>

## 실전 예시

### 예시 1: 보안 감사

```bash
/workflow "모든 REST API 엔드포인트에서 인증 누락 케이스 찾아줘 (src/api/ 폴더 기준)"
```

Claude가 각 파일을 에이전트에 분배하고, 발견된 취약점을 `security-audit-report.md` 파일로 취합해요.

### 예시 2: 번역 작업

```bash
/workflow "docs/ 폴더 안의 모든 영문 마크다운 파일을 한국어로 번역해줘"
```

파일당 에이전트 1개를 배치해서 병렬 번역 후 `docs-ko/` 폴더에 저장.
