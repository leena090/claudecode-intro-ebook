## 동적 워크플로란?

**동적 워크플로(Dynamic Workflows, 다이나믹 워크플로)** 는 Claude가 여러분의 작업을 위한 **JavaScript 실행 계획 스크립트** 를 직접 써주고, 그걸 수십~수백 개의 AI 에이전트가 동시에 처리하는 기능이에요.

> 🍱 **비유**: 대규모 이사를 생각해보세요.
> - **보통 방식**: Claude 혼자 방 하나씩 차례대로 정리 → 시간이 오래 걸림
> - **워크플로 방식**: Claude가 "부엌팀·안방팀·서재팀" 설계도를 먼저 작성 → 수십 명이 동시에 정리 → 빠르게 완료
>
> 동적 워크플로가 그 "설계도 작성 + 팀 배치"를 자동으로 해줘요.

---

## 언제 쓰면 좋나요?

일반 대화나 서브에이전트로 하기엔 **범위가 너무 크거나**, 결과를 **교차 검증**해야 할 때 유용해요:

| 상황 | 예시 |
|------|------|
| 코드 전체 감사 | `src/routes/` 아래 모든 API의 인증 체크 오류 찾기 |
| 대량 파일 변환 | 500개 파일의 `fetch()` 호출을 새 `HttpClient`로 교체 |
| 리서치 교차 검증 | 여러 소스를 서로 대조해서 신뢰할 수 있는 리포트 작성 |
| 다각도 플랜 작성 | 중요한 결정을 여러 AI가 각각 분석 후 비교 |

**일반 서브에이전트와의 차이:**

| | 서브에이전트 | 동적 워크플로 |
|--|-------------|-------------|
| 누가 계획 | Claude가 매 대화마다 | 스크립트(코드)가 |
| 결과 저장 | Claude 대화창 | 스크립트 변수 |
| 재실행 가능 | 아니오 | ✓ 예 (같은 스크립트 재사용) |
| 최대 에이전트 수 | 소수 | 최대 1,000개 |
| 일시정지/재개 | 불가 | ✓ 가능 |

## 사용 방법

### 방법 1: 내 요청에 키워드 넣기

**"workflow"** 또는 **"ultracode"** 라는 키워드를 요청에 넣으면 Claude가 워크플로를 작성해줘요:

```bash
# "workflow" 키워드 사용
> workflow를 써서 src/routes/ 아래 모든 API에 인증 체크가 있는지 검사해줘

# "ultracode" 키워드 사용
> ultracode: fetch() 호출 전부를 새 HttpClient 방식으로 바꿔줘

# 자연어로 요청해도 돼요
> 워크플로를 사용해서 전체 코드를 보안 감사해줘
```

### 방법 2: 내장 워크플로 `/deep-research`

딥 리서치(Deep Research, 깊은 조사) 워크플로는 처음부터 제공돼요:

```bash
/deep-research Node.js v20에서 v22 사이에 뭐가 바뀌었어?
```

작동 방식:
1. 여러 각도에서 웹 검색 실시
2. 소스들을 교차 검증
3. 신뢰할 수 있는 내용만 모아 리포트 작성

## 실행 중 관리하기

```bash
# 워크플로 목록 및 진행 현황 보기
/workflows
```

**키보드 단축키:**

| 키 | 동작 |
|----|------|
| `↑` / `↓` | 단계·에이전트 선택 |
| `Enter` 또는 `→` | 상세 보기 |
| `Esc` | 한 단계 뒤로 |
| `p` | 일시정지/재개 |
| `x` | 중단 |
| `r` | 선택한 에이전트 재시작 |
| `s` | 이 워크플로를 나만의 명령어로 저장 |

---

## 워크플로 저장하기

한 번 성공한 워크플로는 나만의 명령어로 저장할 수 있어요:

```bash
/workflows
# → 원하는 워크플로 선택 → 's' 눌러 저장
```

저장 위치 선택:

| 위치 | 경로 | 공유 범위 |
|------|------|----------|
| 프로젝트 | `.claude/workflows/` | 저장소 클론하는 모든 팀원 |
| 개인 | `~/.claude/workflows/` | 내 모든 프로젝트에서 사용 가능 |

저장 후에는 `/` 입력 시 자동 완성으로 나와요:

```bash
# 예: "security-audit"로 저장했다면
/security-audit
```

## 비용 관리 팁

워크플로는 수십~수백 개 에이전트를 동시에 쓰므로 **토큰 사용량이 많아요**:

1. **처음엔 작은 범위로 테스트**
   ```bash
   > workflow를 써서 src/routes/users.js 하나만 먼저 검사해줘
   ```

2. **진행 중 토큰 사용량 확인**
   ```bash
   /workflows
   # → 각 에이전트의 토큰 사용량 실시간 확인
   ```

3. **필요하면 중간에 중단 가능**
   - 완료된 에이전트 결과는 보존돼요
   - 같은 세션 내에서 다시 시작하면 완료된 부분을 건너뛰고 나머지만 계속해요

## 워크플로 끄기

모든 워크플로를 끄려면:

```bash
# 설정 파일로 끄기
# ~/.claude/settings.json 또는 .claude/settings.json에 추가
{ "disableWorkflows": true }

# 또는 /config에서 토글
/config
# → "Dynamic workflows" → 비활성화
```
