## 이게 뭔가요?

**Claude Security 플러그인(클로드 시큐리티 플러그인)**은 코드베이스 전체를 보안 관점에서 분석해서 **취약점(버그나 해킹 당할 수 있는 구멍)을 찾아내고, 바로 고칠 수 있는 패치 코드를 제안해주는** Anthropic 공식 기능이에요.

> 🏠 **비유로 설명하면**: 새 집을 지었는데 "혹시 도둑이 들어올 수 있는 곳 없나요?" 하고 보안 전문가를 부른다고 상상해봐요.  
> - 전문가가 창문 자물쇠, 현관 잠금장치, CCTV 사각지대를 싹 점검해주고  
> - "3층 창문 잠금장치가 약해요. 이런 자물쇠로 교체하세요." 하고 설명서까지 주는 것  
> - Claude Security가 딱 그 역할이에요. 코드 집 구석구석을 보안 전문가처럼 점검!

---

## 비슷한 기능과 뭐가 달라요?

Claude Code에는 보안 관련 기능이 두 가지 있어요. 헷갈리지 마세요!

| 기능 | 언제 작동하나요? | 어떤 목적? |
|---|---|---|
| **security-guidance 플러그인** | Claude가 코드를 **작성하는 그 순간** | 실시간 리뷰 (코드 짜면서 바로 체크) |
| **Claude Security 플러그인** ⭐ | **직접 스캔 명령**을 내릴 때 | 기존 코드베이스 전체 점검 |

> 🍱 더 쉬운 비유: security-guidance는 요리하면서 재료 확인, Claude Security는 완성된 요리 전체 위생 검사예요.

## 어떻게 써요?

### 1단계: 플러그인 설치

Claude Code 세션에서 플러그인 설치 명령을 실행해요 (공식 문서 기준 추정):

```bash
# 마켓플레이스에서 설치하거나 /plugin install 명령 이용
/plugin install claude-security
```

### 2단계: 스캔 실행

설치 후 Claude에게 스캔을 요청해요:

```
Claude Code 세션에서:
"코드베이스 전체 보안 취약점 스캔해줘"
"이 프로젝트의 보안 문제 찾아봐줘"
```

### 3단계: 결과 검토 & 패치 적용

Claude가 취약점 목록을 보여주면, 각 항목마다 **패치 코드를 제안**해줘요. 내가 검토하고 마음에 들면 적용하면 돼요.

---

## 어떤 취약점을 찾아줘요?

공식 발표 기준으로 코드베이스의 **보안 허점**을 전반적으로 스캔한다고 돼 있어요. 구체적인 취약점 종류는 설치 후 실제 사용 경험에 따라 다를 수 있어요 (추정).

일반적으로 코드 보안 스캐너가 잡는 것들은:

| 취약점 종류 | 영어 | 쉬운 설명 |
|---|---|---|
| SQL 주입 | SQL Injection | 데이터베이스에 악의적인 명령 넣기 |
| 크로스사이트 스크립팅 | XSS | 웹 페이지에 나쁜 스크립트 삽입 |
| 하드코딩 비밀번호 | Hardcoded Secrets | 코드에 비번·API키를 그대로 써놓기 |
| 인증 취약점 | Auth Vulnerability | 로그인 로직의 허점 |

## 이런 분들께 추천해요

✅ **레거시 코드**(오래된 코드)를 넘겨받아서 보안 점검이 필요한 분  
✅ 서비스를 **오픈 전 마지막 보안 체크**가 필요한 분  
✅ 보안 전문가 없이 **혼자 개발**하는 분  
✅ **팀 코드 리뷰**에 보안 관점을 추가하고 싶은 분

---

## 주의사항

- **Claude Security**는 Anthropic 공식 플러그인이에요. 제3자 보안 도구와 달리 Claude의 AI 이해력을 활용해서 코드 **맥락**을 파악해요.
- 찾아낸 취약점은 **항상 직접 검토**하세요. AI도 실수할 수 있어요.
- 대규모 코드베이스는 스캔 시간이 걸릴 수 있어요 (추정).
