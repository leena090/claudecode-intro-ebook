## 🏢 자체 호스팅 환경이란?

보통 Claude Code는 **Anthropic의 클라우드**에서 실행됩니다. 하지만 어떤 회사들은 이런 고민이 있어요:

> "우리 코드베이스가 외부 클라우드에 올라가도 될까? 사내 데이터베이스, 내부 API에는 어떻게 접근하지?"

**Self-hosted environments** (자체 호스팅 환경)는 이 문제를 해결합니다. Claude Code 세션을 **회사 자체 인프라** 안에서 실행할 수 있어요.

> 공식 발표 기준 (2026-08-06): "Claude Code 세션을 자체 인프라 위에서, 내부 네트워크 안에서, 내부 서비스 바로 옆에서 실행하세요. 현재 퍼블릭 베타."

---

## 💡 쉬운 비유로 이해하기

일반 Claude Code는 마치 **외부 편의점에서 재료를 사다가 요리하는 것**과 같아요. 외부에서 재료(코드, 데이터)를 가져와야 하죠.

자체 호스팅 환경은 마치 **회사 구내식당 안에서 요리사가 직접 요리하는 것**처럼, 내부 창고(데이터베이스, API)에 직접 접근하면서 작업할 수 있어요.

---

## 🔑 왜 필요한가요?

| 상황 | 자체 호스팅 없을 때 | 자체 호스팅 있을 때 |
|------|-------------------|-------------------|
| 내부 DB 접근 | 외부 노출 필요 | 직접 연결 가능 |
| 민감한 코드 | 클라우드 업로드 | 사내 서버에서만 처리 |
| 내부 API 연동 | VPN 설정 복잡 | 바로 접근 가능 |
| 규정 준수 | 외부 처리 불허 가능 | 데이터 사내 보관 |

## ⚙️ 구성 방식

자체 호스팅 환경은 여러 단계로 나뉘어요:

```
1. 빠른 시작 (quickstart)    — 기본 설치 및 설정
2. 배포 (deploy)             — 인프라에 Claude Code 에이전트 배포
3. 설정 (configuration)      — 환경 변수, 네트워크, 권한 설정
4. 테스트 (testing)          — 올바르게 작동하는지 검증
5. 신원 확인 (identity)      — 사용자/에이전트 인증 연동
```

> 🔗 전체 문서: [code.claude.com/docs/en/self-hosted-environments](https://code.claude.com/docs/en/self-hosted-environments)

## 📋 현재 상태 (2026-10-27 기준)

- **퍼블릭 베타** — 누구나 신청해서 사용할 수 있지만 아직 정식 출시 전
- **주요 클라우드 지원**: AWS, GCP (Azure 추정, 공식 확인 필요)
- **Enterprise 플랜 중심**: 팀 규모의 기업 환경 대상

> ⚠️ **추정 포함**: 세부 클라우드 지원 범위는 공식 문서 확인 권장

## 🤔 이게 필요한지 판단하기

**필요한 경우:**
- 금융, 의료, 법률 등 규제 산업
- 사내 네트워크 안의 서비스에 직접 접근이 필요한 경우
- 외부 클라우드 사용을 제한하는 보안 정책이 있는 경우

**일반 개인 개발자는 불필요:**
- 개인 프로젝트나 소규모 팀은 일반 Claude Code나 클라우드 환경으로 충분
