## 셀프 호스팅이 뭔가요?

> 🏘️ **비유로 설명할게요**:  
>
> 지금까지 Claude Code를 쓰는 건  
> "카페에서 카페 와이파이로 일하는 것"이었어요.  
> 편하긴 하지만, 내 정보가 카페 서버를 거치잖아요.  
>
> **셀프 호스팅(Self-hosted Environments)**은  
> "우리 회사 사무실에 전용 와이파이를 깔아서,  
> 외부와 완전히 독립된 환경에서 일하는 것"이에요.  
>
> 코드도, 대화 내용도, 전부 우리 서버 안에서만 오가요.

---

## 언제 필요한가요?

| 상황 | 설명 |
|---|---|
| 🏥 **의료·법률·금융** | 개인정보나 기밀 데이터를 외부 서버에 보낼 수 없는 규정 |
| 🏢 **대기업 보안 정책** | IT팀이 외부 API 연결을 허용하지 않는 경우 |
| 🌏 **데이터 주권** | 특정 나라 법상 데이터를 자국 서버에만 보관해야 하는 경우 |
| 🔒 **높은 보안 요구** | 방위산업, 정부기관 등 극도로 엄격한 보안이 필요한 경우 |

> 💡 **개인 사용자라면?**  
> 셀프 호스팅은 필요 없어요!  
> 일반 개발자나 소규모 팀은 기본 Claude Code로 충분합니다.  
> 이 기능은 100명 이상 규모의 기업이나 특수 보안 요건이 있는 조직을 위한 것이에요.

## 공식 문서 구성 (7개 페이지)

Anthropic이 이번에 셀프 호스팅 전용으로 7개 페이지를 새로 만들었어요:

| 문서 | 역할 | 누가 읽어야 하나 |
|---|---|---|
| **개요** (overview) | 셀프 호스팅이 무엇인지 설명 | 결정권자, IT 담당자 |
| **빠른 시작** (quickstart) | 처음 설치하는 단계별 가이드 | 담당 엔지니어 |
| **배포** (deploy) | 실제 서버에 올리는 방법 | DevOps 엔지니어 |
| **설정** (configuration) | 각종 옵션 세팅 방법 | IT 관리자 |
| **테스트** (testing) | 제대로 작동하는지 확인 | QA·담당 엔지니어 |
| **레퍼런스** (reference) | 설정값 전체 목록 | 개발자 참조용 |
| **신원 인증** (identity) | 사용자 인증·권한 관리 | 보안 담당자 |

## 셀프 호스팅 vs 기본 클라우드 비교

| 구분 | 기본 클라우드 | 셀프 호스팅 |
|---|---|---|
| **데이터 위치** | Anthropic 서버 | 우리 회사 서버 |
| **설치 난이도** | 바로 사용 가능 | 엔지니어 설정 필요 |
| **유지 관리** | Anthropic이 담당 | 우리 팀이 담당 |
| **보안 통제** | Anthropic 정책 따름 | 자체 정책 적용 가능 |
| **비용** | 구독/사용량 기반 | 인프라 비용 + 라이선스 |
| **업데이트** | 자동 | 수동 업데이트 필요 |

## 셀프 호스팅 환경의 핵심 개념

### 신원 인증 (Identity)

> 🪪 **비유**: 회사 출입 카드 시스템이에요.  
> 누가 어느 방(기능)에 들어올 수 있는지 관리해요.

셀프 호스팅 환경에서는 자체 인증 시스템을 연결할 수 있어요:
- SSO(Single Sign-On) 연동
- 기존 회사 계정 시스템 활용
- 권한 레벨 세분화

### 신원 인증 방식 (공식 발표 기준)
- SAML 기반 SSO
- OAuth 2.0
- 자체 IdP(Identity Provider) 연동

## 도입 전 체크리스트

셀프 호스팅을 검토하는 조직이라면 이런 준비가 필요해요:

- [ ] **인프라**: 전용 서버 또는 사설 클라우드(VPC) 준비
- [ ] **인력**: DevOps 엔지니어 1명 이상
- [ ] **네트워크**: 인터넷 ↔ 내부망 접근 규칙 설계
- [ ] **보안**: 인증 시스템(SSO 등) 연동 계획
- [ ] **유지보수**: 정기 업데이트·모니터링 계획
- [ ] **라이선스**: Anthropic Enterprise 플랜 계약 (추정 — 공식 확인 필요)

> ⚠️ **주의**: 셀프 호스팅은 Enterprise 플랜에서만 제공될 가능성이 높아요.  
> 정확한 요금·조건은 [Anthropic 영업팀에 문의](https://www.anthropic.com/contact-sales)하세요.

## 일반 사용자에게 미치는 영향

회사에서 셀프 호스팅으로 전환한다면, 직원 입장에서는:

1. **로그인 방법이 바뀔 수 있어요** — 회사 계정으로 자동 로그인
2. **URL이 달라져요** — `claude.ai` 대신 사내 주소 사용
3. **속도가 달라질 수 있어요** — 회사 서버 성능에 따라 다름
4. **사용 기능이 달라질 수 있어요** — IT팀이 허용한 기능만 사용 가능

> 💬 "그냥 평소처럼 쓰면 되나요?" → 네, 대부분 비슷해요.  
> 로그인하는 곳만 달라지고, 사용 방법은 동일해요.
