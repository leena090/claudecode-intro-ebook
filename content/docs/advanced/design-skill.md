## /design 스킬이란?

Claude Code에서 `/design` 명령어로 **UI 디자인 아트보드를 바로 만들어주는** 기능이에요.

> 🖌️ **비유로 설명하면**: 피그마 디자이너에게 "이런 화면으로 바꿔줘"라고 말하는 것처럼, 클로드한테 말로 설명하면 편집 가능한 디자인 초안이 뚝딱 나와요. 마음에 드는 아트보드를 고르면 바로 코드로 구현까지 해줘요.

---

## 어떻게 쓰나요?

### 기본 사용법

```bash
# Claude Code에서
> /design 사용자들이 실제로 쓰는 기능 중심으로 composer 화면을 재디자인해줘
```

```bash
# 더 구체적으로 요청하기
> /design 다크 테마로 설정 페이지 디자인해줘. 알림, 보안, 외관 섹션 포함.
```

### 실행 흐름

1. 클로드가 요청을 분석하고 **여러 개의 아트보드**를 만들어요
2. **아티팩트 링크**를 출력해줘요 (클릭해서 열기)
3. 아티팩트 캔버스에서 아트보드를 **시각적으로 직접 편집** 가능해요
4. 마음에 드는 옵션을 고르면 클로드가 **바로 코드로 구현**해줘요

---

## Claude Design 캔버스에서 할 수 있는 것

아티팩트를 열면 **Claude Design 캔버스**가 나와요:

| 기능 | 설명 |
|---|---|
| 클릭해서 요소 선택 | 버튼, 텍스트, 이미지 등 개별 요소 선택 |
| 속성 패널 | 색상, 크기, 여백 등 직접 조정 |
| 인라인 텍스트 편집 | 텍스트를 더블클릭해서 바로 수정 |
| 실행 취소/다시 실행 | Ctrl+Z / Ctrl+Y |
| PNG/PDF 내보내기 | 디자인 파일로 저장 (저장 기능이 있는 경우 자동 발행) |

## 활용 팁

### 좋은 /design 프롬프트 쓰는 법

```bash
# ✅ 좋은 예 — 목적과 맥락 포함
> /design 모바일 앱의 온보딩 화면 3단계 디자인. 
  처음 쓰는 40~60대 입문자 대상. 
  버튼은 크게, 텍스트는 크고 명확하게.

# ✅ 좋은 예 — 기존 화면 개선
> /design 현재 대시보드의 차트 영역을 재디자인해줘. 
  데이터가 너무 복잡해 보이는 문제 해결.

# ⚠️ 덜 좋은 예 — 너무 막연함
> /design 예쁘게 만들어줘
```

### 코드 구현 요청

```bash
# 아트보드를 고른 후 구현 요청
> 두 번째 옵션으로 실제 구현해줘. React로.
```
