## iOS 시뮬레이터 페인이 뭔가요?

**iOS 시뮬레이터 페인**(아이오에스 시뮬레이터 페인)은 Claude Code Desktop에서 iOS 앱을 개발할 때, 대화창 옆에 **실제 iPhone 시뮬레이터 화면이 자동으로 나타나는 기능**이에요.

> 🍱 **비유로 설명하면**: 레시피를 개발하면서 바로 옆에 작은 주방이 열려서, "이 재료 넣어줘"라고 하면 AI가 직접 재료를 넣고 요리하는 걸 실시간으로 볼 수 있는 것과 같아요. Claude가 앱 코드를 고치면 시뮬레이터에 바로 반영돼요.

Claude가 앱을 빌드하거나 실행하는 순간, 페인이 **자동으로 열리면서 실시간으로 디바이스 화면을 스트리밍**해요.

---

## 시작하기 전에 확인할 것

| 조건 | 내용 |
|------|------|
| OS | **macOS 전용** (Apple 시뮬레이터 사용) |
| 버전 | Claude Desktop **v1.24012.0** 이상 |
| 플랜 | Pro · Max · Team (Enterprise 미지원) |
| 도구 | **Xcode** + iOS 플랫폼 설치 필요 |
| 세션 유형 | 로컬 세션만 가능 (클라우드·SSH 세션 불가) |

> ⚠️ Xcode가 없거나 iOS 시뮬레이터가 설치 안 됐으면, 페인에서 설치 안내가 나와요.
> `xcodebuild -downloadPlatform iOS` 명령으로 수동 설치 가능.

## 사용법

별도 명령어나 설정이 필요 없어요! Claude가 시뮬레이터에서 앱을 실행하는 순간 **자동으로 페인이 열립니다**.

### 1단계: 프로젝트 열기

Claude Code Desktop → **Code 탭** → iOS 프로젝트 폴더를 세션 폴더로 지정

### 2단계: Claude에게 실행 요청

```
"앱을 시뮬레이터에서 빌드해서 온보딩 플로우를 확인해줄래?"
```

또는 특정 디바이스를 지정해서:

```
"iPhone SE 시뮬레이터에서 실행해봐"
```

### 3단계: 시뮬레이터 페인에서 확인

앱이 시뮬레이터에서 실행되는 순간 **iOS Simulator 페인이 옆에 열려요**. Claude가 직접:
- 앱을 설치하고
- 탭(터치)하고
- 화면을 읽어서 자신의 코드 변경이 맞는지 확인

...하는 과정을 실시간으로 볼 수 있어요.

## 직접 조작도 가능해요

시뮬레이터 페인은 단순 뷰어가 아니라 **인터랙티브**합니다:

| 동작 | 방법 |
|------|------|
| 탭·스와이프 | 페인에서 직접 클릭·드래그 |
| 홈 버튼 | `Cmd+Shift+H` |
| 잠금 | `Cmd+L` |
| 볼륨 | `Cmd+↑` / `Cmd+↓` |
| 화면 회전 | `Cmd+→` (90도 시계방향) |
| 스크린샷 저장 | `Cmd+S` (바탕화면에 저장) |
| 화면 녹화 | `Cmd+R` |
| 시뮬레이터 분리 | **Detach simulator** 버튼 |

> 💡 Claude가 디바이스를 조작 중일 때는 페인 위에 **"Claude is using this device"** 배지가 표시돼요. 이 배지가 사라질 때까지 기다렸다가 탭하세요.

---

## 여러 세션은 각각 별도 시뮬레이터

병렬 세션을 사용하면 각 세션이 **독립적인 시뮬레이터를 가져요**. 한 세션에서 버그 수정 중, 다른 세션에서 새 기능 테스트 — 서로 충돌 없이 작동합니다.

- 세션 전환 시 → 시뮬레이터 화면도 함께 전환
- 한 세션에서 최대 **4개 디바이스** 페인 지원
- Claude가 부팅한 디바이스 → 세션 종료·아카이브·Detach 후 10분 뒤 자동 종료
- 직접 켠 디바이스 → 자동 종료 안 됨

## 컴퓨터 유즈(Computer Use)와 차이점

| 항목 | iOS 시뮬레이터 페인 | 컴퓨터 유즈 (CLI) |
|------|---------------------|-------------------|
| 화면 방식 | 전용 스트리밍 페인 | 실제 macOS 화면 제어 |
| 다른 창 영향 | ❌ 없음 | ⚠️ 화면 가림 가능 |
| 권한 필요 | 없음 (자동) | macOS 접근성 권한 필요 |
| 세션별 격리 | ✅ 완전 격리 | ❌ 공유 화면 |

> 시뮬레이터 페인은 macOS 접근성·화면 녹화 권한이 **필요 없어요** (자체 스트리밍 방식).

## 처음 사용 시 권한 허용

Claude가 시뮬레이터를 처음 조작할 때 **한 번만 허용**하면 돼요 (디바이스당 1회). 그 이후엔 매번 묻지 않습니다.

> ⚠️ Claude가 찍는 디바이스 스크린샷은 Anthropic 서버로 전송되고, 일반 대화 보존 정책과 동일하게 관리돼요. **실제 계정으로 로그인한 앱은 시뮬레이터에서 사용하지 마세요.**

## 자주 있는 문제

### 페인이 안 열려요

- "시뮬레이터에서 실행해줘"처럼 명확하게 요청했나요?
- Xcode + iOS Simulator가 설치돼 있나요? (Simulator 앱으로 확인)
- Claude Desktop v1.24012.0 이상인지 확인 (`Claude → Check for Updates`)
- 조직에서 시뮬레이터 도구를 비활성화했을 수 있어요

### "시뮬레이터를 찾을 수 없다"고 나와요

Xcode는 있지만 iOS 시뮬레이터가 없는 상태예요:

```bash
xcodebuild -downloadPlatform iOS
```

위 명령 실행 후 다시 시도하세요.

## 정리

iOS 개발자라면 Claude Code Desktop의 시뮬레이터 페인이 **개발 속도를 크게 높여줄 거예요**. 화면 공유나 스크린샷 없이도 AI가 직접 앱을 보고 테스트하니까요.

아직 공개 베타라 일부 제한이 있을 수 있지만, macOS + Pro/Max/Team 사용자라면 지금 바로 써볼 수 있어요!
