## 코드를 짤 때 보안도 같이 잡을 수 있어요

코딩을 배우다 보면 "일단 동작만 하면 돼!"가 먼저가 되기 쉬워요. 근데 나중에 서비스를 오픈하면 보안 구멍 때문에 큰일이 나기도 해요.

`security-guidance` 플러그인('시큐리티가이던스 플러그인')을 쓰면 Claude가 코드를 짜는 순간 스스로 보안 검토도 해줘요. **별도의 보안 도구 없이**, Claude 안에서 코딩과 보안 검사가 동시에 이루어지는 거예요.

> 🍱 **비유로 설명하면**: 요리하면서 동시에 위생 검사도 해주는 주방 보조가 있다고 생각해요. "이 재료 상했어요, 다른 걸로 바꿀게요"라고 알아서 처리해주는 것처럼, Claude가 "이 코드 보안 구멍 있어요, 제가 고칠게요"라고 해줘요.

---

## security-guidance 플러그인 설치 방법

```bash
# 방법 1: 터미널에서
claude plugins install security-guidance

# 방법 2: Claude Code 세션 안에서
/plugins install security-guidance
```

설치 후엔 **별도로 켜거나 끄지 않아도** 자동으로 작동해요. Claude가 코드를 변경할 때마다 보안 검토가 함께 진행돼요.

---

## 어떻게 작동하나요?

```
나: 회원가입 기능 만들어줘. 이메일이랑 비밀번호 받아서 DB에 저장해줘.

Claude: [코드 작성 중...]

⚠️ 보안 검토 결과:
  - 비밀번호를 평문으로 저장하려 했어요. 해킹 시 비밀번호가 그대로 노출돼요.
  - bcrypt로 해싱해서 저장하도록 수정할게요.

[수정된 코드 제공]
✅ 비밀번호 해싱 적용 완료.
✅ SQL 인젝션 방지를 위해 파라미터화된 쿼리 사용.
```

Claude가 **문제를 발견한 즉시, 같은 세션에서 바로 수정**해요. 따로 보안 검토 요청을 할 필요가 없어요.

## 어떤 취약점을 잡아주나요?

| 취약점 종류 | 쉬운 설명 | 예시 |
|------------|----------|------|
| **SQL 인젝션** | 악성 DB 명령 삽입 | `'; DROP TABLE users; --` |
| **XSS** | 웹에 악성 스크립트 삽입 | `<script>alert('해킹')</script>` |
| **비밀번호 평문 저장** | 비밀번호를 암호화 없이 그대로 저장 | `password = "1234"` (DB에 그대로) |
| **하드코딩된 API 키** | 코드에 직접 쓰인 비밀 키 | `api_key = "sk-abc123..."` |
| **경로 조작** | 허용되지 않은 파일 접근 | `../../etc/passwd` |
| **안전하지 않은 난수** | 예측 가능한 보안 코드 생성 | `random.random()` 으로 토큰 생성 |

> ⚠️ **중요**: 이 플러그인이 모든 보안 취약점을 100% 잡아주진 않아요. "추가 방어선" 역할이지, 전문 보안 감사를 대체할 수는 없어요. 중요한 서비스라면 전문 보안 검토도 받으세요.

## 실제 사용 예시

### ❌ 플러그인 없이 생성한 코드 (위험!)

```python
# 사용자 입력을 그대로 DB 쿼리에 사용 → SQL 인젝션 취약!
def get_user(username):
    query = f"SELECT * FROM users WHERE name = '{username}'"
    return db.execute(query)
```

### ✅ security-guidance 적용 후 코드 (안전)

```python
# 파라미터화된 쿼리 사용 → SQL 인젝션 차단
def get_user(username):
    query = "SELECT * FROM users WHERE name = ?"
    return db.execute(query, (username,))
```

Claude가 자동으로 첫 번째 방식을 감지하고 두 번째 방식으로 바꿔줘요.

## 이런 분들께 특히 추천해요

| 상황 | 추천 이유 |
|------|-----------|
| 코딩 처음 배우는 분 | 보안 나쁜 습관을 처음부터 안 들일 수 있어요 |
| 개인 프로젝트를 웹에 올리려는 분 | 해킹 위험을 미리 줄여요 |
| 혼자 빠르게 개발하는 분 | 별도 보안 검토 시간을 아낄 수 있어요 |
| 팀 프로젝트에서 보안 리뷰어가 없는 분 | 기본적인 보안 게이트 역할을 해줘요 |

## 자주 묻는 질문

**Q. 플러그인이 없어도 Claude한테 "보안도 체크해줘"라고 하면 안 되나요?**
할 수 있어요! 하지만 플러그인은 **매번 말하지 않아도 자동으로** 체크해줘요. 깜빡 잊을 일이 없죠.

**Q. 보안 검토 때문에 코딩이 느려지지 않나요?**
아주 약간 느릴 수 있어요. 하지만 나중에 보안 구멍 뚫려서 수리하는 것보다 훨씬 빠르고 안전해요.

**Q. 이 플러그인 때문에 코딩 스타일이 강제로 바뀌나요?**
취약점이 없는 코드는 건드리지 않아요. 위험한 패턴이 발견될 때만 수정을 제안하거나 자동으로 수정해요.
