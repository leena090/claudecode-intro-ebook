# Code Review · Mods · Projects 세 가지 새 기능 🛠️

> 출처: claude.com/claude-code 마케팅 페이지 [공] — 2026년 9~10월 공식 발표 기준

2026년 9월부터 10월 사이, Claude Code에 실용적인 기능 세 개가 추가됐습니다.  
각각 "버그 잡기", "겉모습 바꾸기", "여러 작업 묶기"에 초점을 맞춘 기능들입니다.

---

## 1. Code Review (코드 리뷰) — 버그가 배포 전에 걸린다 🔍

> 발표: 2026년 10월 15일 | Team & Enterprise 플랜 정식 출시(GA)

### 무엇인가요?

**Code Review**는 코드를 배포하기 전에 Claude가 자동으로 버그를 찾아내는 기능입니다.

> 🔎 **비유**: 원고를 편집자에게 보내기 전에 맞춤법 검사기를 돌리는 것처럼, 코드를 팀원들이 보기 전에 AI가 먼저 훑어봐 주는 것입니다.

### 어떻게 쓰나요?

```bash
# PR(풀 리퀘스트)에 코드 리뷰 요청
/code-review

# 또는 울트라리뷰 (클라우드 멀티 에이전트 활용)
/ultrareview
```

### 주요 특징

| 특징 | 내용 |
|------|------|
| 대상 | PR(Pull Request) 단위 검토 |
| 출력 | 인라인 코멘트 또는 요약 보고서 |
| 가용 플랜 | **Team, Enterprise** (정식 출시) |
| 명령어 | `/code-review`, `--comment`, `--fix` |

## 2. Mods (모즈) — Claude Code 외모와 행동을 바꾼다 🎨

> 발표: 2026년 10월 1일 | CLI + 데스크톱 앱

### 무엇인가요?

**Mods**(모즈, Modifications의 줄임말)는 TypeScript 코드 몇 줄로 Claude Code의 **모습과 동작 방식을 바꾸는** 기능입니다.

> 🔎 **비유**: 스마트폰 테마를 바꾸거나, 게임 커스텀 스킨을 설치하는 것처럼, Claude Code도 원하는 대로 꾸밀 수 있습니다.

### 어떤 것을 바꿀 수 있나요?

- **테마(Theme)**: 색상, 폰트 스타일
- **패널(Panel)**: 채팅 옆에 항상 표시되는 패널
- **스테이터스 라인(Status line)**: 화면 하단 정보 표시
- **슬래시 명령어(Slash commands)**: 새 `/명령어` 추가
- **훅(Hooks)**: 도구 호출 전후에 자동 실행되는 동작

```typescript
// Mods 예시: 간단한 상태바 커스텀
export default {
  statusline: {
    text: () => `🕐 ${new Date().toLocaleTimeString('ko-KR')}`,
  }
}
```

### 어디서 만드나요?

`.claude/mods/` 폴더 아래에 `.ts` 파일을 만들면 됩니다. Claude Code가 자동으로 인식합니다.

## 3. Projects (프로젝트) — 여러 에이전트를 한눈에 관리 📁

> 발표: 2026년 9월 17일 | Claude Code 데스크톱 앱

### 무엇인가요?

**Projects**는 관련된 여러 코딩 세션을 하나의 "프로젝트"로 묶어서, 여러 Claude 에이전트를 동시에 감독할 수 있는 기능입니다.

> 🔎 **비유**: 혼자 여러 가게를 운영하는 사장님이 각 가게 직원들을 하나의 대시보드로 모니터링하는 것처럼, 여러 Claude 작업을 한 화면에서 볼 수 있습니다.

### 주요 특징

| 특징 | 내용 |
|------|------|
| 묶음 단위 | 관련 코딩 세션들을 프로젝트로 그룹화 |
| 가시성 | 여러 에이전트 작업 현황 동시 확인 |
| 감독 | 각 세션에 개입·방향 지시 가능 |
| 가용 환경 | **Claude Code Desktop** (데스크톱 앱) |

### 언제 유용한가요?

```
예시 시나리오:
├── 프로젝트: "쇼핑몰 리팩터링"
│   ├── 세션 1: 결제 모듈 버그 수정
│   ├── 세션 2: 상품 목록 성능 개선
│   └── 세션 3: 테스트 코드 작성
```

대형 작업을 여러 에이전트에게 나눠 맡기고 싶을 때, Projects로 전체 진행 상황을 한눈에 볼 수 있습니다.
