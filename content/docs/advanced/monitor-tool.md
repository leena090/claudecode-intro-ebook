## Monitor 도구란?

**백그라운드에서 무언가를 계속 지켜보다가, 이벤트가 생기면 즉시 Claude에게 알려주는 내장 도구**입니다.

> 🍱 **비유로 설명하면**: 편의점 카운터 직원 옆에 CCTV 모니터가 있는 것처럼요. 직원(Claude)은 손님(지시)을 응대하면서도, 모니터 화면이 바뀌면(이벤트) "어, 이상한 게 보여요!" 하고 즉시 반응합니다. `Bash sleep` 루프처럼 직원이 5초마다 카메라 영상을 직접 보러 갔다 오는 수고가 없어요.

---

## 어떤 상황에서 써요?

| 상황 | Monitor 없이 | Monitor 있으면 |
|------|-------------|--------------|
| 서버 로그에 에러 뜨면 알고 싶어요 | 직접 주기적으로 확인 | **에러 발생 즉시 Claude가 알아채고 반응** |
| CI(자동 테스트)가 언제 끝나는지 | 새로고침하며 기다림 | **완료되면 바로 알림** |
| 개발 서버가 갑자기 죽으면? | 한참 뒤에 발견 | **죽는 순간 자동 재시작 시도** |
| 파일이 특정 조건이 되면 다음 작업 | 직접 확인 후 지시 | **조건 충족 시 자동으로 다음 단계 진행** |

---

## 사용 방법

Claude에게 자연어로 말하면 됩니다. 명령어가 따로 없어요.

### 예시 1: 서버 로그 감시

```
> server.log를 백그라운드에서 감시하다가 5xx 에러가 뜨면 바로 알려줘
```

Claude가 Monitor 도구를 사용해서:
- 백그라운드에서 `server.log` 추적 시작
- 500, 502, 503 등 에러 감지 즉시 대화 창에 알림
- 내 터미널은 계속 사용 가능! (블로킹 없음)

### 예시 2: CI 결과 기다리기

```
> PR #42의 CI가 완료될 때까지 감시해줘. 실패하면 어떤 테스트가 틀렸는지 알려줘
```

### 예시 3: 개발 서버 자동 복구

```
> 개발 서버(포트 3000)가 죽으면 즉시 재시작해줘
```

### 예시 4: 빌드 완료 후 자동 다음 단계

```
> 빌드가 완료되면 자동으로 스테이징 서버에 배포해줘
```

## `/loop`와 함께 쓰기 — 셀프페이싱(self-pacing)

Week 15 업데이트로 `/loop`가 **셀프페이싱** 방식으로 진화했어요.

**기존 방식:**
```bash
/loop 5m CI 상태 확인해줘
# → 무조건 5분마다 체크 (사실은 불필요할 때도 있음)
```

**새 방식 (간격 생략 가능):**
```bash
/loop CI 상태 확인해줘
# → Claude가 스스로 판단해서 언제 다시 체크할지 결정
# → 또는 Monitor 도구를 쓰도록 스스로 선택 (폴링 없이!)
```

> 🍱 **비유로 설명하면**: 예전 알람시계는 "5분마다 울림" 고정이었는데, 새 알람은 "굳이 울릴 필요 없으면 안 울리고, 뭔가 생기면 즉시 울림"으로 스마트해진 거예요.

| 항목 | 기존 `/loop 5m` | 새 `/loop` (셀프페이싱) |
|------|----------------|----------------------|
| 간격 | 고정 5분 | **Claude가 스스로 결정** |
| 불필요한 체크 | 있음 | **줄어듦** |
| Monitor 연계 | 없음 | **자동으로 Monitor 활용** |
| 효율 | 보통 | **높음** |

## 실전 시나리오

### 시나리오: 야근 없이 배포 마치기

```
상황: 퇴근 전에 PR 머지하고 배포 시작

나: "PR #88 CI가 통과되면 스테이징 배포하고,
    배포 후 health check가 200이면 프로덕션 배포까지 해줘.
    각 단계마다 알려줘."

→ Claude가 Monitor 도구로 CI 감시 시작
→ (30분 후) CI 통과 → 자동 스테이징 배포
→ health check 확인 → 프로덕션 배포
→ 대화 창에 단계별 결과 알림
```

나는 퇴근 후 휴식 중에도 진행 상황 알림을 받을 수 있어요!

## Bash sleep 루프와 비교

이전에는 이런 식으로 했어야 했어요:

```bash
# ❌ 예전 방식: Bash sleep 루프 (터미널 점유, 비효율)
while true; do
  if grep -q "ERROR" server.log; then
    echo "에러 발견!"
    break
  fi
  sleep 5
done
```

Monitor 도구를 쓰면:
```
# ✅ 새 방식: 자연어로 말하기만 하면
> server.log에 ERROR가 뜨면 즉시 알려줘
```

- 터미널 블로킹 없음
- sleep 루프 코드 불필요
- 이벤트 발생 즉시 Claude가 대화에 메시지로 알려줌
