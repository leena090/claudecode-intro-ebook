## 한눈에 보기

> 🚉 **비유**: 데스크톱 앱이 매주 새 칸이 붙는 기차예요. 탄 날이 언제냐에 따라 모르는 기능이 생겼을 수 있어요. 이 글이 "이번 달 새로 붙은 칸 안내 방송"입니다.

아래는 **2026년 4월 28일 ~ 5월 12일** 사이에 출시된 데스크톱 앱 업데이트 핵심 요약이에요.

---

## 🇰🇷 한국어 사용자 필독 — 입력 버그 수정 (v1.7196.0, 5월 12일)

이게 제일 중요해요.

> **버그 증상**: Quick Entry(빠른 입력) 창에서 한글·일어·중문 등 **IME 입력 방식**(한글 자판으로 글자 조합할 때)으로 타이핑하면 글자가 잘못 입력되거나 일부가 빠지던 문제.

이번 업데이트에서 **공식 수정** 됐어요. `[공]`

IME(Input Method Editor, 입력기)란 한글·한자·일본어처럼 한 번에 글자를 조합해서 입력하는 방식을 말해요. Quick Entry는 `Cmd+Shift+.` 같은 단축키로 뜨는 작은 입력 팝업인데, 여기서 한국어가 제대로 안 들어가던 문제가 드디어 해결됐습니다.

## ✨ 이번 달 주요 신기능

### 1. 멀티탭 터미널 (v1.5220.0, 4월 28일)

**전**: 터미널 창이 하나뿐이라 동시에 두 가지 명령어를 실행하려면 앱을 두 개 띄워야 했어요.  
**후**: 터미널 탭을 여러 개 열 수 있어요.

어떻게 쓰나요?
- 터미널 패널 상단의 **`+` 버튼** 클릭 → 새 탭 열기
- 채팅 창에서 **폴더를 우클릭** → "터미널에서 열기" 선택

> 🍱 **비유**: 예전엔 주방에 가스버너 한 개뿐이었는데, 이제 인덕션이 두 개 생겼어요. 국도 끓이면서 볶음도 할 수 있어요.

---

### 2. 메시지 큐 — 작업 중에 보낸 말 안 사라져요 (v1.6259.0, 5월 5일)

**전**: Claude가 작업 중일 때 메시지를 보내면 무시되거나 사라졌어요.  
**후**: 작업이 끝나면 자동으로 처리돼요.

> 🍱 **비유**: 식당에서 주문을 받으러 간 종업원이 바쁠 때 "저기요!"를 외쳐도 기억해뒀다가 돌아와서 응대해주는 것과 같아요.

---

### 3. iOS에서 열면 Mac이 이어받아요 (v1.6259.0, 5월 5일)

**Handoff(핸드오프)** 기능이 추가됐어요.  
iPhone(iOS)에서 Code 세션 링크를 열면 → 같은 Wi-Fi의 Mac에서 해당 세션이 자동으로 계속돼요.

> 🍱 **비유**: 지하철에서 폰으로 보던 유튜브 영상을, 집에 들어서자마자 TV에서 이어서 보는 것과 같아요.

---

### 4. "항상 허용" 설정이 재시작 후에도 유지돼요 (v1.6259.0, 5월 5일)

**전**: 권한 프롬프트에서 "항상 허용"을 눌러도 앱을 껐다가 켜면 다시 물어봤어요.  
**후**: 영구 저장됩니다. 또한 어떤 범위(현재 세션/프로젝트/전체)에 대해 허용했는지도 표시돼요.

---

### 5. 작업 완료 시 OS 알림 (v1.6889.0, 5월 8일)

Claude가 작업을 마쳤는데 내가 다른 창을 보고 있을 때, **macOS 알림 센터로 알림**이 와요.  
("작업 완료!" 같은 소리·배너)

> 🍱 **비유**: 세탁기가 끝나면 삐 하고 알려주는 것처럼요.

---

### 6. MCP 앱 위젯 (v1.6889.0, 5월 8일)

Code 탭 세션 안에서 MCP(Model Context Protocol) 서버가 보내는 **앱 위젯**을 렌더링할 수 있게 됐어요.  
예를 들어 MCP 서버가 간단한 대시보드나 미리보기를 팝업으로 보여줄 수 있어요.

## 기업(3P 관리 배포) 전용 기능

회사에서 관리자가 Claude Code를 배포하는 경우에 해당해요. 개인 사용자는 몰라도 됩니다.

- **조직 배너** (v1.7196.0): 앱 상단에 IT 관리자가 지정한 배너 표시
- **stdio MCP 서버 지원** (v1.6889.0): 관리자가 `managedMcpServers` 설정으로 로컬 MCP 서버 배포 가능
- **`claude://` 딥 링크 비활성화 옵션** (v1.6889.0): 딥 링크 처리를 끌 수 있음
- **모델 표시 이름 커스터마이즈** (v1.6889.0): 모델 선택기에서 보이는 이름을 바꿀 수 있음
- **per-tool MCP 정책 버그 수정** (v1.6889.0): 관리자가 설정한 도구별 MCP 정책이 모든 세션 유형에 적용되도록 수정
