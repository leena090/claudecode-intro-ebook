## 새로 생긴 데스크톱 전용 체인지로그

Anthropic이 **데스크톱 앱 전용 변경 이력(changelog)** 페이지를 공식 문서에 추가했어요.  
CLI(터미널) 변경과 분리해서 관리해요.

> 📰 **비유로 설명하면**: 신문 본지와 주택 부록이 따로 있는 것처럼, 이제 "데스크톱 앱 업데이트"와 "터미널 CLI 업데이트"가 각각의 공식 노트로 관리돼요.

공식 링크: [code.claude.com/docs/en/desktop-changelog](https://code.claude.com/docs/en/desktop-changelog)

## 2026년 5월 핵심 업데이트 모음

### 🇰🇷 한국어·일본어·중국어 입력 버그 수정 (v1.7196.0 · 5월 12일)

**Quick Entry(빠른 입력)에서 한글 입력 시 글자가 잘리던 문제가 수정됐어요.**

이전에는 한글(IME)로 입력할 때 글자가 중간에 사라지거나 깨지는 현상이 있었는데, 이번 업데이트로 해결됐어요.

---

### 🔔 세션 완료 OS 알림 (v1.6889.0 · 5월 8일)

Code 세션이 작업을 마치면 **화면을 보고 있지 않아도 운영체제(macOS/Windows) 알림**이 떠요.

> 📱 **비유로 설명하면**: 세탁기가 다 돌면 "삐!" 소리를 내는 것처럼, Claude가 코드 수정을 끝내면 알림을 보내줘요. 다른 일 하다가 돌아오면 됩니다.

---

### 🔄 PR 자동 수정이 리뷰 스레드에 답글 달기 (v1.6889.0 · 5월 8일)

PR 자동 수정(auto-fix) 기능이 업그레이드됐어요:
- 수정한 리뷰 스레드마다 **답글을 자동으로 달아줘요**
- 해결된 스레드는 **자동으로 resolved 처리**해줘요

---

### ⏰ 예약 작업(Scheduled Task) 중 일정 수정 가능 (v1.6889.0 · 5월 8일)

예약 작업이 실행 중에 `update_scheduled_task` MCP 도구를 써서 **일정이나 프롬프트를 바꿀 수 있어요**.

---

### 📁 예약 작업 삭제 시 파일도 함께 삭제 옵션 (v1.7196.0 · 5월 12일)

예약 작업을 삭제할 때 "**디스크의 파일도 함께 삭제**" 옵션이 생겼어요.  
체크하면 `~/.claude/scheduled-tasks/` 의 관련 파일도 같이 지워져요.

---

### 🖥️ 멀티탭 터미널 창 (v1.5220.0 · 4월 28일)

터미널 창 안에 **여러 탭을 열 수 있어요!**

- 터미널 창 상단의 **`+` 버튼**을 눌러서 새 탭 열기
- 채팅에서 폴더를 **우클릭 → "터미널에서 열기"** 로 바로 열기

> 💻 **비유로 설명하면**: 예전엔 터미널 창이 하나뿐이었는데, 이제 브라우저처럼 탭을 여러 개 열 수 있어요. 서버 로그 보면서 동시에 명령어도 입력할 수 있어요.

---

### 📌 허용된 도구 권한 앱 재시작 후에도 유지 (v1.6259.0 · 5월 5일)

"이번 세션 동안 항상 허용" 했던 도구 권한이 **앱을 재시작해도 기억**돼요.  
그리고 이제 해당 권한의 **범위(scope)도 표시**돼요.

---

### 📱 iOS에서 시작 → macOS에서 이어가기 (v1.6259.0 · 5월 5일)

iPhone에서 Code 세션 링크를 열면 **Handoff 기능으로 맥(Mac)에서 이어서 작업**할 수 있어요.

---

### 📬 실행 중인 세션 관리 MCP 도구 (v1.5186.0 · 4월 28일)

세션 안에서 **다른 세션을 관리할 수 있는 MCP 도구** 3개가 추가됐어요:

| 도구 | 하는 일 |
|---|---|
| `list_sessions` | 세션 목록 보기 |
| `search_session_transcripts` | 세션 대화 내용 검색 |
| `archive_session` | 세션 보관처리 |

---

### 🏢 조직 관리자용 기능 (엔터프라이즈)

기업 IT 관리자를 위한 기능도 추가됐어요:

- **조직 배너**: 앱 상단에 IT 관리자가 설정한 배너 표시 (v1.7196.0)
- **로컬 MCP 서버 지원**: `managedMcpServers` 설정 키로 stdio-transport 로컬 MCP 서버 관리 (v1.6889.0)
- **모델 표시 이름 커스텀**: 모델 선택 화면에서 모델 이름을 다르게 표시 가능 (v1.6889.0)
- **플러그인 자동 설치**: 조직 프로비저닝 플러그인 자동 설치 지원 (v1.6608.0)
