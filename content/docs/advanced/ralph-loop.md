## 🔁 랄프 루프가 뭐예요?

**Geoffrey Huntley**라는 개발자가 공개해서 유명해진 **무한 루프 기법**이에요. Claude Code를 `while` 루프로 계속 돌려서, **한 번에 할 수 없는 큰 작업**을 자동으로 완성시키는 방법입니다.

가장 단순한 형태는 이 한 줄이에요:

```bash
while :; do cat PROMPT.md | claude-code; done
```

> 🍱 **비유로 설명하면**: 공사 현장에서 "오늘 할 일 리스트"를 벽에 붙여놓고, 인부(Claude)가 출근할 때마다 **"리스트에서 하나 가져가서 끝내고 다시 돌아오세요"** 하는 거예요. 인부 한 명이 한 번에 다 할 수 없어도, **매번 새 기운으로 출근해서 하나씩** 처리하면 결국 건물이 완성됩니다.

## 🎯 어떤 문제를 해결하나요?

### 컨텍스트 창 한계 (약 170K 토큰)

Claude Code는 한 세션에 **약 170K 토큰**의 기억 용량이 있어요. 큰 프로젝트(파일 수백 개)는 한 번에 다 넣을 수 없습니다. 넣어도 AI가 중요한 걸 잊어버려요 (희석 효과).

### 랄프 루프의 해결책

- **매 루프마다 새 컨텍스트로 시작** — 170K 꽉 채울 일 없음
- **한 루프 = 한 작업** — 한 번에 하나만 집중
- **계획서(`PLAN.md`)가 기억 역할** — 어디까지 했는지, 다음은 뭔지 파일이 알고 있음
- **서브에이전트로 병렬화** — 검색·요약 같은 비싼 작업은 별도 서브에이전트로

> 170K 안에서 **한 작업만** 처리하고, 다음 루프에서 **또 새 170K로** 다른 작업. 이게 핵심입니다.

## 🛠 실제 구현 — 3단계 구조

### 1단계: 계획서(`PLAN.md`) 만들기

먼저 Claude한테 계획을 세우게 시킵니다.

```
이 프로젝트 전체를 PLAN.md 파일로 만들어줘.
요구사항은 다음과 같아:
- 할 일을 100개 이하의 작은 태스크로 쪼개줘
- 각 태스크는 체크박스 [ ] 로 표시
- 우선순위 순으로 정렬
- 각 태스크는 5분 안에 끝낼 수 있는 크기로
```

결과: 체크박스 리스트가 담긴 `PLAN.md`

```markdown
# 프로젝트: 중장년 여행 블로그 플랫폼

## Phase 1 - 초기 설정
- [ ] Next.js 프로젝트 생성
- [ ] Tailwind CSS 세팅
- [ ] 디렉토리 구조 만들기

## Phase 2 - 기본 페이지
- [ ] 홈페이지 레이아웃
- [ ] 블로그 글 목록 페이지
- [ ] 블로그 글 상세 페이지
...
```

### 2단계: 프롬프트 파일(`PROMPT.md`) 만들기

매 루프마다 Claude가 읽을 지시서예요.

```markdown
# 지시사항

1. PLAN.md 파일을 열어라
2. 첫 번째 미완료 태스크([ ])를 찾아라
3. 그 태스크 하나만 완료해라
4. 완료하면 체크박스를 [x] 로 바꿔라
5. 테스트가 깨지면 바로 고쳐라
6. 완료 메시지를 PROGRESS.md에 한 줄 추가해라
```

### 3단계: 무한 루프 돌리기

```bash
# Mac 터미널 / WSL (Windows Subsystem for Linux)
while :; do
  cat PROMPT.md | claude -p --permission-mode acceptEdits
  sleep 10
done
```

이제 **밤새 돌려두면** 됩니다. 아침에 일어나면:
- `PLAN.md` 에 체크박스 80~100개 완료
- `PROGRESS.md` 에 완료 로그
- 실제로 작동하는 코드베이스

## 🔒 꼭 지켜야 할 안전장치

### 1. **훅(Hooks)으로 위험 명령 차단**

루프가 밤새 돌아가는 동안 **`rm -rf` 같은 위험 명령이 실행되면 재앙**이에요. 훅으로 미리 막아야 합니다.

Claude한테 말로 시키면 됩니다:

```
밤새 루프 돌릴 거라서 안전장치 필요해.
Hooks에 이거 걸어줘:
- rm, rmdir, del 같은 삭제 명령 차단
- 시스템 파일 수정 차단
- .env, .git 폴더 쓰기 차단
```

→ [Hooks 가이드](/docs/config/hooks-intro)

### 2. **`/cost` 로 비용 모니터링**

루프는 **돈 먹는 괴물**이에요. 실수로 밤새 돌리면 수십만 원 나갈 수 있습니다.

```
/cost
```

수시로 확인하고, 일정 금액 초과하면 자동으로 멈추는 장치도 필요합니다.

### 3. **`--dangerously-skip-permissions` 쓰지 마세요**

루프 편의성 때문에 유혹적이지만, **위험 명령까지 통과**시킵니다. 대안으로:
- `--permission-mode acceptEdits` (파일 편집만 자동, 위험 명령은 확인)
- 또는 [auto 모드](/docs/config/permissions-guide) (Team/Enterprise 전용, classifier가 안전 검사)

### 4. **격리된 환경에서 돌리기**

- Docker 컨테이너
- VM
- 별도 작업용 폴더 (`~/work/ralph-test/`)

절대 **`~`(홈 디렉토리) 에서 바로 돌리지 마세요**.

## 💰 실제 효과 — Huntley의 사례

Huntley가 공개한 사례:

> **"$50,000짜리 greenfield 계약 MVP를 $297로 완성했다."**

- 일반 개발자에게 맡기면 $50k
- 랄프 루프로 Claude Code 돌리면 $297 (API 비용)
- **약 168배 절감**

단, 중요 조건:
- 스펙이 명확해야 함 (`PLAN.md` 품질이 생명)
- 기존 레거시 프로젝트는 효과 떨어짐 (greenfield에 강함)
- **"완벽한 코드"가 아니라 "작동하는 MVP"** 수준
- 사람이 최종 QA 필수

## ⚠️ 솔직한 한계

### 잘 되는 경우
- ✅ 새 프로젝트(greenfield)
- ✅ 스펙이 명확한 작업
- ✅ 반복되는 패턴 (CRUD, 폼, 리스트)
- ✅ 단위 테스트가 있는 프로젝트

### 잘 안 되는 경우
- ❌ 기존 대형 레거시 리팩토링
- ❌ 복잡한 비즈니스 로직 (도메인 지식 필요)
- ❌ 예술적·창의적 UI 디자인
- ❌ 보안·금융 같은 민감한 영역

### 공통 실수
- 계획서가 너무 크거나 모호함 (한 루프에 2~3개 섞임)
- 테스트 없이 돌림 → 어디서 부러졌는지 몰라 결국 다 다시
- 비용 모니터링 안 함 → 아침에 카드 명세서 보고 기절

## 💡 입문자용 미니 루프 (안전한 시작)

처음부터 밤새 돌리지 말고, **10번 루프부터** 시작하세요.

```bash
# 10번만 돌리고 멈추는 안전 버전
for i in {1..10}; do
  echo "=== Loop $i / 10 ==="
  cat PROMPT.md | claude -p --permission-mode acceptEdits
  echo "=== Check /cost manually before continuing ==="
  sleep 30
done
```

이렇게 10번 돌리면서 `PLAN.md`가 잘 진행되는지, 비용이 얼마 나오는지 확인한 뒤 규모를 늘리세요.

## 🎯 노모어매뉴얼 `/ralph-loop` 커스텀 스킬

위의 bash 루프·`PLAN.md`·`PROMPT.md`·안전장치 전부 **수동으로 만들기 벅차다** 싶으시죠? 노모어매뉴얼에서는 이 모든 걸 **한 줄 스킬**로 묶어둔 **`/ralph-loop`** 이 있습니다.

### 사용법 (한 줄이면 끝)

```
/ralph-loop
```

발동하면 스킬이 자동으로:

1. **계획 수립** — 뭘 만들지 물어보고 `PLAN.md` 자동 생성
2. **안전장치 적용** — Hooks, 비용 한도, 격리 폴더 자동 설정
3. **루프 시작** — `while` 루프 돌리며 태스크 하나씩 처리
4. **진행 상황 추적** — `PROGRESS.md` 실시간 기록
5. **한도 도달 시 자동 정지** — 비용·시간·태스크 수 기준

### 왜 스킬로 만들었나요?

대표님(노모어매뉴얼 운영자)이 직접 만드신 이유:

- **40~60대 입문자도 쓸 수 있게** — `while :; do ...` 같은 bash 문법 공부 없이 한 줄로
- **실수 방지** — `rm` 차단, 격리 폴더, 비용 모니터링이 기본 탑재
- **재사용** — 프로젝트마다 매번 똑같은 셋업 반복 안 하도록
- **교육용** — 솔바드 수업·유튜브에서 실전 시연용

### 내 Claude Code에도 추가하려면?

`/ralph-loop` 스킬은 노모어매뉴얼 개인 스킬입니다. 본인 환경에 추가하려면:

```
"랄프 루프 기법을 쓰는 /ralph-loop 스킬을 만들어줘.
PLAN.md 자동 생성하고, Hooks로 rm 차단하고,
10번 루프 돈 뒤 /cost 확인시키는 안전 버전으로."
```

이렇게 **Claude한테 말로 시키면** 본인 환경에도 유사한 스킬이 생성돼요. (지금까지 이 ebook에서 본 "말로 시키기" 패턴 그대로)

## 💬 마지막 한마디

랄프 루프는 **마법이 아니에요**. Huntley 본인도 "완벽하지 않다, 망가진 결과물도 나온다"라고 인정합니다. 하지만 **계획을 잘 세우고 + 안전장치 걸고 + 감당 가능한 범위에서** 쓴다면, 혼자서는 불가능했던 프로젝트를 해낼 수 있는 강력한 도구입니다.

> 🍱 **핵심 요약**: "170K 안에서 한 작업만, 무한 루프로 반복, 계획서가 기억 역할" — 이 세 줄이면 랄프 루프를 이해한 거예요.
