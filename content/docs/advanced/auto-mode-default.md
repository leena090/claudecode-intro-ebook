## 무슨 변화인가요?

2026년 9월 17일부터 **Claude Code가 자동으로 오토 모드(auto mode)로 시작**해요.

이전에는:
- 기본값 = `default` 모드 (파일 수정할 때마다 일일이 물어봄)
- 오토 모드 쓰려면 → `Shift+Tab`으로 직접 전환하거나 플래그 설정 필요

지금은:
- 기본값 = `auto` 모드 (스스로 판단하고 작업, 위험한 명령만 멈춤)
- 별도 설정 없이 바로 시작됨

> 🍱 **비유로 설명하면**: 이전 Claude Code는 **"매번 확인받는 신입"** 이었어요. 파일 하나 만들 때마다 "이래도 될까요?"를 물었죠.
> 
> 이제는 **"믿을 수 있는 중견 직원"** 처럼 일해요. 혼자 판단하고 처리하되, 정말 중요한 결정(돈 이체, 파일 삭제 등)만 "이건 확인받아야 해요"라고 멈춥니다.

---

## 오토 모드의 안전장치는 그대로입니다

오토 모드가 기본이 된다고 해서 무방비 상태가 되는 건 아니에요.

오토 모드에는 **백그라운드 안전 분류기(classifier)**가 여전히 작동해요:

| 분류기가 보는 것 | 예시 |
|---|---|
| 💰 금전 관련 명령 | API 결제, 외부 결제 시스템 호출 |
| 🗑️ 되돌릴 수 없는 삭제 | `rm -rf`, 데이터베이스 드롭 |
| 🌐 외부 전송 | 민감한 데이터를 외부 서버로 전송 |
| 🔑 권한 상승 | sudo, 루트 권한 실행 |

이런 명령을 Claude가 실행하려 할 때는 **자동으로 멈추고 허락을 요청**해요.

---

## 이제 뭐가 더 편해지나요?

### 1. 더 긴 작업을 끊기지 않고

이전에는 파일 20개를 수정하는 작업이면 20번씩 "이 파일 수정해도 될까요?"를 물었어요. 이제는 클로드가 판단하고 처리하고, 마지막에 요약해줘요.

### 2. 멀티스텝 작업이 자연스러워짐

"이 API 연동하고, 테스트 짜고, PR 열어줘" 같은 여러 단계 작업을 한 번에 맡길 수 있어요.

### 3. 화면 앞에 없어도 작업 진행

자리를 잠깐 비워도 Claude Code가 알아서 다음 단계로 진행해요. 위험한 순간에만 멈추고 기다려줍니다.

---

## 이전처럼 일일이 확인받고 싶다면?

오토 모드가 기본이 돼도 **언제든지 모드를 바꿀 수 있어요**.

```
Shift+Tab         → acceptEdits 모드로 전환 (파일 수정만 자동, 나머지는 확인)
Shift+Tab 두 번  → plan 모드 (계획만 짜고 실행은 내가 허락)
Shift+Tab 세 번  → 기본 default 모드로 복귀
```

또는 시작할 때 플래그:

```bash
claude --permission-mode acceptEdits  # 파일 수정만 자동 승인
claude --permission-mode default      # 모든 것 확인받기
```

---

## 기업 환경에서는?

팀 또는 엔터프라이즈 플랜에서는 **관리자(admin)가 기본 모드를 다르게 설정**할 수 있어요.

예: 전체 팀원에게는 `acceptEdits`를 기본으로 → 개인이 필요할 때 오토로 전환

관련 설정: [auto-mode-config 가이드](/docs/advanced/auto-mode-config)
