## 세션 간 메시지란?

같은 컴퓨터에서 열린 **여러 Claude Code 세션이 서로에게 메시지를 보내는** 기능이에요. (v2.1.224, 2026년 8월 출시)

> 📡 **비유로 설명하면**: 이전까지는 여러 Claude Code 창을 열어도 각자 자기 일만 했어요. 이제는 **같은 팀 카카오톡 단톡방처럼**, 한 세션이 다른 세션에게 "나 이 부분 바꿨어, 네 코드도 확인해봐" 하고 알릴 수 있어요.

---

## 어떻게 쓰나요?

### 다른 세션에 메시지 보내기

세션 안에서 자연어로 부탁하면 클로드가 알아서 메시지를 전달해요:

```bash
# 세션 A에서
> "payments API 작업하는 세션한테 users.name이 users.display_name으로 바뀌었다고 알려줘"
```

W33 업데이트로 `@세션이름` 형식도 됩니다:

```bash
> "@payments-api users.name이 users.display_name으로 변경됐어. 네 코드 확인해봐"
```

### 어떤 세션들이 있는지 확인하기

```bash
> /list-agents
```

또는 Claude Code 안에서:

```bash
> "지금 이 컴퓨터에서 어떤 세션들이 열려 있어?"
```

### 메시지 확인하기

다른 세션에서 보낸 메시지가 오면 `Message from` 줄이 표시돼요.  
`Ctrl+O` 를 누르면 메시지 내용을 펼쳐볼 수 있어요.

## 활용 예시

### 예시 1: 함수 이름 변경 알리기

```
세션 A: frontend 작업 중
세션 B: backend API 작업 중

세션 A에서: "세션 B한테 getUser() 함수가 fetchUserById()로 바뀌었다고 알려줘"
→ 세션 B가 메시지 받고 자동으로 연관 코드 업데이트
```

### 예시 2: 작업 완료 알림

```
세션 A: 데이터베이스 마이그레이션 작업 중
세션 B: API 서버 작업 중

세션 A에서: "마이그레이션 완료됐어. 세션 B한테 이제 새 스키마 써도 된다고 알려줘"
```

### 예시 3: 유휴 상태 알림 받기 (W34 추가)

다른 세션이 작업을 마치고 **한가해졌을 때** 알림 받기:

```bash
> "migrations 세션이 한가해지면 나한테 알려줘"
```

## 알아두면 좋은 점

### 메시지로 전달되는 것 vs 안 되는 것

| 전달됨 | 전달 안 됨 |
|---|---|
| 텍스트 메시지 | 대화 이력 |
| 자연어 지시 | 파일 내용 |
| 알림·상태 정보 | 환경 변수, 권한 |

> 🔒 **보안 안내**: 메시지는 클로드가 다른 세션을 위해 작성한 **텍스트**만 전달돼요. 내 대화 내용이나 파일이 자동으로 공유되지는 않아요.

### 지원 환경

| 운영체제 | 지원 여부 |
|---|---|
| macOS | ✅ v2.1.224+ |
| Linux | ✅ v2.1.224+ |
| Windows | ✅ v2.1.234+ (W34에서 추가) |

### 세션 이름 충돌 방지 (W33 추가)

같은 이름을 가진 세션이 이미 있으면 `이름-단어-단어` 형식의 변형 이름이 자동으로 붙어요.

## 관련 명령어 정리

| 명령어/도구 | 역할 |
|---|---|
| `/list-agents` | 현재 접근 가능한 세션 목록 보기 |
| `@세션이름` | 프롬프트에서 세션 멘션 |
| `SendMessage` 도구 | Claude가 내부적으로 메시지 전송에 사용 |
| `ListAgents` 도구 | Claude가 내부적으로 세션 탐색에 사용 |
