## Fast Mode가 뭔가요?

**Fast Mode(패스트 모드)**는 Claude Code에서 **더 빠른 응답 속도**가 필요할 때 쓰는 설정이에요. 일반 모드보다 **2.5배 빠르게** 동작해요.

> 🍱 **비유로 설명하면**: 일반 모드가 "고속도로 법정 속도로 달리기"라면, Fast Mode는 **"긴급 차로를 이용해서 같은 길을 2.5배 빠르게 달리기"** 예요. 요금은 조금 더 내지만, 긴급하거나 반복적인 작업엔 훨씬 유리해요.

---

## 이번 업데이트 핵심 — 무엇이 바뀌었나요?

### 1. 기반 모델 교체: Opus 4.8 → Opus 5.5

이전 Fast Mode는 **Opus 4.8**을 고속화한 버전이었어요. 이제는 최신 **Opus 5.5**를 고속화한 버전으로 전환됐어요.

즉, Fast Mode를 쓰면 이제 **더 최신·더 강력한 모델**을 더 빠르게 쓸 수 있게 됐어요.

### 2. 가격 대폭 인하

| 항목 | 이전 (Opus 4.8 기반) | 지금 (Opus 5.5 기반) |
|---|---|---|
| 입력 토큰 (per million) | $30 | **$8** |
| 출력 토큰 (per million) | $150 | **$40** |
| 배 | — | **약 4배 저렴** |

> 💡 입력 토큰 기준으로 $30 → $8, 즉 **75% 가격 인하**예요. 같은 예산으로 4배 더 많이 쓸 수 있어요.

## Fast Mode 사용 조건

- **리서치 프리뷰** 상태 (아직 일반 출시 전)
- **소비 기반(consumption-based) 플랜**에서 사용 가능
- 구독 플랜(Pro/Max) 사용자는 **사용 크레딧**으로 접근 가능 (공식 발표 기준 추정)

> ⚠️ **추정**: 리서치 프리뷰 조건은 시간이 지나면 바뀔 수 있어요. 최신 내용은 공식 문서에서 확인하세요.

## 어떻게 켜나요?

### 방법 1: `/fast` 슬래시 명령어

세션 도중에 아래 명령어를 입력하면 됩니다:

```
/fast
```

다시 원래 속도로 돌아오려면 같은 명령어를 다시 입력하세요.

### 방법 2: 상태 표시줄에서 확인

화면 하단 상태 표시줄(status line)에 **"Fast"** 표시가 있으면 Fast Mode 중이에요.
