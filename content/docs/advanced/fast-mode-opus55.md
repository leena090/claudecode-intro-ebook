## Fast Mode, 무엇이 달라졌나요?

| 항목 | 이전 (Opus 4.8 시절) | 현재 (2026-10-20 기준) |
|---|---|---|
| **대상 모델** | Claude Opus 4.8 | **Claude Opus 5.5** |
| **속도** | 2.5배 빠름 | 2.5배 빠름 (동일) |
| **가격 (입력)** | $30/백만 토큰 | **$8/백만 토큰** |
| **가격 (출력)** | $150/백만 토큰 | **$40/백만 토큰** |
| **상태** | 리서치 프리뷰 | 리서치 프리뷰 |
| **사용 가능 플랜** | 소비 기반 플랜 | 소비 기반 플랜 |

> 💡 **가격 변화 요약**: 입력 기준 $30 → $8 (약 73% 인하), 출력 기준 $150 → $40 (약 73% 인하). **공식 발표 기준.**

---

## Fast Mode란?

> 🏎️ **비유로 설명하면**: 일반 고속버스(Opus 5.5 표준 속도)를 **KTX처럼 2.5배 빠르게** 달리게 하는 모드예요. 단, 요금은 일반 요금보다 조금 더 높아요.

Fast Mode는 Opus 5.5 모델을 **2.5배 빠르게** 실행하는 고속 설정이에요. 코드가 많은 복잡한 작업을 빠르게 끝내고 싶을 때 유용해요.

**Fast Mode 켜는 방법:**

```bash
# Claude Code CLI에서
/fast        # Fast Mode 켜기
/fast off    # Fast Mode 끄기

# 또는 Shift+F 단축키
```

## 어떤 상황에 Fast Mode를 쓰면 좋을까요?

| 상황 | Fast Mode 권장? |
|---|---|
| 대규모 마이그레이션 (수백 파일) | ✅ 강력 추천 |
| 복잡한 버그 추적 (긴 분석) | ✅ 추천 |
| 일상적인 파일 편집 1~2개 | ❌ 불필요 (Sonnet 5.5로 충분) |
| 비용이 매우 중요한 경우 | ❌ Haiku 5.5 고려 |

## 소비 기반 플랜이란?

Fast Mode는 **소비 기반 플랜(consumption-based plan)**에서만 사용할 수 있어요.

- **Claude Console** 계정 사용자: API 토큰 기반 과금, 바로 사용 가능
- **Pro/Max 구독자**: 플랜 내 사용 크레딧으로 사용 (추정 — 공식 발표 기준 확인 필요)
- **Team/Enterprise**: 별도 문의

> 📌 **참고**: "리서치 프리뷰" 상태라 추후 정식 출시 시 조건이 바뀔 수 있어요.
