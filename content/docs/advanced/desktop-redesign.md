## 뭐가 달라졌나요?

한마디로, Claude Code 데스크톱 앱이 **"채팅창 하나"에서 "나만의 작업 공간"으로** 변했어요.

> 🏢 **비유**: 예전에는 전화기 하나로 일했다면, 이제는 모니터 여러 개 달린 사무실 책상이 생긴 거예요. 채팅도 하고, 코드도 보고, 테스트도 돌리고, 결과도 미리 보고 — 다 한 화면에서!

---

## 새로운 기능 한눈에 보기

### 1. 멀티세션 사이드바

이제 **여러 프로젝트를 동시에** 작업할 수 있어요.

| 기능 | 설명 |
|------|------|
| 여러 세션 동시 열기 | 프로젝트A, 프로젝트B를 탭처럼 전환 |
| 상태별 필터 | "진행 중" / "완료" / "대기" 등으로 정리 |
| 프로젝트별 분류 | 폴더별로 세션을 그룹화 |

```
왼쪽 사이드바에서:
📁 블로그 프로젝트
  └─ 세션: 메인 페이지 수정 중…
📁 회사 보고서
  └─ 세션: 월간 분석 자동화
📁 개인 공부
  └─ 세션: Python 연습
```

> 마치 브라우저에서 탭을 여러 개 열어놓는 것처럼, Claude와의 대화도 여러 개 동시에 할 수 있어요.

---

### 2. 통합 터미널 & 파일 에디터

앱 안에서 바로 **코드를 편집하고, 명령어를 실행**할 수 있어요.

이전에는 이랬어요:
```
Claude에게 코드 요청 → 결과를 복사 → 다른 앱에서 붙여넣기 → 실행
```

이제는 이래요:
```
Claude에게 코드 요청 → 바로 옆 패널에서 편집 → 바로 아래서 실행 → 끝!
```

<div class="note-circle">
○ 파일 에디터가 내장됐지만, 간단한 수정용이에요. 복잡한 편집은 여전히 VS Code 같은 전문 에디터가 편해요.
</div>

---

### 3. HTML/PDF 미리보기

Claude가 만들어준 웹페이지나 문서를 **앱 안에서 바로** 확인할 수 있어요.

이전에는:
```
"index.html 만들어줘" → 파일 찾아서 → 브라우저에서 열기
```

이제는:
```
"index.html 만들어줘" → 오른쪽 패널에 바로 미리보기 표시!
```

PDF 파일도 마찬가지예요. 따로 앱을 열 필요 없이 앱 안에서 바로 확인!

---

### 4. 드래그 앤 드롭 레이아웃

화면 배치를 **내 맘대로** 바꿀 수 있어요.

```
┌──────────┬──────────┐
│  채팅     │  코드     │
│          │  에디터    │
├──────────┼──────────┤
│  터미널   │  미리보기  │
└──────────┴──────────┘
```

각 패널을 드래그해서 크기를 조절하거나, 위치를 바꿀 수 있어요.

> 🖥️ 사무실 책상 위에 모니터, 키보드, 서류를 내 편한 대로 배치하는 것처럼요.

<div class="note-star">
★ 패널 배치는 자동으로 저장돼요. 다음에 앱을 열면 내가 마지막으로 설정한 배치 그대로 나와요.
</div>

---

### 5. 3가지 보기 모드

Claude가 일하는 과정을 **얼마나 자세히 볼지** 선택할 수 있어요.

| 모드 | 보이는 것 | 추천 대상 |
|------|----------|----------|
| **Verbose** (자세히) | 모든 도구 호출, 중간 과정 전부 | 디버깅할 때, 과정이 궁금할 때 |
| **Normal** (보통) | 주요 단계만 | 일반적인 작업 |
| **Summary** (요약) | 최종 결과만 | 빠르게 결과만 보고 싶을 때 |

초보자는 **Normal** 모드를 추천해요. 익숙해지면 Verbose로 바꿔서 Claude가 어떻게 일하는지 구경해보세요!

---

### 6. SSH 원격 접속 지원

회사 서버나 클라우드 컴퓨터에 **원격으로 접속해서** Claude Code를 실행할 수 있어요.

```
내 Mac → SSH → 회사 Linux 서버 → Claude Code 실행
```

<div class="note-circle">
○ SSH는 개발자·IT 관리자용 기능이에요. 일반 사용자는 몰라도 됩니다!
</div>

---

### 7. 빨라진 Diff 뷰어

Claude가 파일을 수정할 때, **"어디가 바뀌었는지"** 보여주는 화면이 **60% 더 빨라졌어요**.

큰 파일도 탭 키 한 번으로 빠르게 변경 사항을 확인할 수 있어요.

---

## 데스크톱 앱은 어디서 받나요?

이미 Claude Desktop 앱을 쓰고 계시다면, **자동으로 업데이트**돼요.

아직 설치 안 하셨다면:
1. [claude.ai](https://claude.ai) 접속
2. "Desktop 앱 다운로드" 클릭
3. Mac 또는 Windows 버전 설치

<div class="note-circle">
○ 데스크톱 앱 리디자인은 <strong>Claude Code</strong> (터미널/CLI 도구)가 아니라, <strong>Claude Desktop</strong> (데스크톱 앱) 안에 포함된 Code 탭에 대한 거예요.
○ 터미널에서 쓰는 CLI 버전은 기존과 동일하게 사용할 수 있어요.
</div>
