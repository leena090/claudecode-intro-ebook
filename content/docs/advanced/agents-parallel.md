## 왜 여러 AI를 동시에 쓰나요?

> 🍱 **비유로 설명하면**: 혼자 방 4개짜리 집을 청소할 때 하나씩 순서대로 하는 것보다, 각 방에 한 명씩 배치해서 동시에 청소하면 훨씬 빠른 것처럼요.

Claude Code에서도 여러 AI 에이전트가 **동시에** 각자 다른 일을 처리하면 전체 작업이 훨씬 빨라집니다.

단, 방법이 여러 가지라서 헷갈릴 수 있어요. **어떤 상황에 뭘 쓰면 좋을지** 한 번에 정리해드릴게요.

---

## 4가지 방법 한눈에 비교

| 방법 | 무엇인가 | 이럴 때 쓰세요 |
|------|----------|--------------|
| **서브에이전트** | 대화 안에서 임시로 일 시키기 | 내 대화창을 복잡하게 만들 정보 수집이나 단순 반복 작업 |
| **에이전트 뷰** (`claude agents`) | 독립적인 여러 작업을 한 화면에서 파견·관리 | 각각 독립적인 일들을 맡기고 상태만 보고 싶을 때 |
| **에이전트 팀** | Claude가 알아서 역할을 나눠 팀 운영 | 큰 프로젝트를 Claude가 직접 쪼개서 배분하게 하고 싶을 때 (실험적 기능) |
| **워크트리** (`--worktree`) | Git 독립 공간에서 파일 충돌 없이 병렬 실행 | 여러 AI가 같은 파일을 건드릴 수 있어서 충돌 방지가 필요할 때 |
| **`/batch`** | 큰 변경을 30개 이하 워크트리 서브에이전트로 나눠 PR 생성 | 전체 코드베이스 마이그레이션이나 기계적 리팩토링 |

## 상황별 선택 가이드

### Q1. 누가 일을 나눠줄까요?

- **내가 하나하나 지시하고 싶다** → 서브에이전트 또는 에이전트 뷰
- **Claude가 알아서 나눠주면 좋겠다** → 에이전트 팀 (단, 실험적 기능)

### Q2. AI끼리 서로 통신이 필요한가요?

- **각자 독립적으로 하면 됨** → 에이전트 뷰 또는 서브에이전트
- **중간 결과를 공유해야 함** → 에이전트 팀 (공유 작업 목록으로 소통)

### Q3. 같은 파일을 여러 AI가 건드릴 수 있나요?

- **건드릴 수 있음 (충돌 위험)** → 워크트리로 격리
- **각자 다른 파일만 건드림** → 워크트리 없어도 됨

## 각 방법 자세히 설명

### 🔵 서브에이전트 (Subagent)

> 🍱 **비유**: 내가 팀장이고, "이 자료 좀 조사해와"라고 팀원을 잠깐 보내는 것. 팀원이 돌아와서 결과만 보고함.

한 대화 안에서 Claude가 **임시 도우미**를 불러서 일을 나눠 처리합니다. 도우미의 검색 결과나 긴 파일 내용이 내 대화창을 복잡하게 만들지 않아도 되는 상황에 적합해요.

```
# 예시: "파일 3개를 각각 다른 에이전트한테 분석시켜줘"
```

### 🟡 에이전트 뷰 (Agent View) — 리서치 프리뷰

> 🍱 **비유**: 콜센터 관리자처럼 여러 상담원에게 업무를 배분하고 한 화면에서 상태를 모니터링.

```bash
claude agents
```

- 독립적인 여러 작업을 동시에 파견
- 각 작업 상태를 한 화면에서 모니터링
- 막힌 작업에만 들어가서 답변

📖 자세한 사용법 → [에이전트 뷰 가이드](/advanced/agent-view)

### 🔴 에이전트 팀 (Agent Teams) — 실험적 기능

> 🍱 **비유**: 프로젝트 매니저 AI가 전체 계획을 세우고, 개발자 AI 여러 명에게 역할을 나눠주는 것.

Claude가 자동으로 프로젝트를 분석해서 작업을 나누고, 여러 AI끼리 서로 메시지를 주고받으며 협업합니다.

⚠️ 기본적으로 비활성화된 **실험적 기능**이에요. 설정에서 직접 켜야 합니다.

### 🟢 워크트리 (Worktrees)

> 🍱 **비유**: 같은 Word 파일을 A안·B안으로 복사해서 각각 독립적으로 편집하는 것.

```bash
claude --worktree 기능A작업
claude --worktree 버그수정
```

- Git 워크트리로 독립적인 작업 공간 생성
- 파일 충돌 걱정 없이 병렬 작업 가능
- 에이전트 뷰도 내부적으로 이걸 자동으로 활용

📖 자세한 사용법 → [워크트리 가이드](/advanced/worktrees)

### ⚪ `/batch` 명령어

큰 변경(전체 코드베이스 마이그레이션, API 일괄 교체 등)을 한 명령으로 실행할 때:

```
/batch 프로젝트 전체의 import 경로를 @components에서 @/components로 바꿔줘
```

Claude가 작업을 5~30개로 나눠서 각각 워크트리 서브에이전트로 실행하고, 각자 PR을 열어요.

## 진행 상황 확인 방법

| 상황 | 명령어 |
|------|--------|
| 백그라운드 세션들 | `claude agents` (에이전트 뷰) |
| 현재 대화의 서브에이전트 | `/agents` (Library 탭에서 생성/편집도 가능) |
| 현재 대화의 백그라운드 작업 | `/tasks` |
| 데스크톱 앱의 모든 세션 | 데스크톱 앱 사이드바 |
