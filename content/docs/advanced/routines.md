## 루틴이 뭔가요?

**루틴(Routines)**은 Claude Code에서 <mark>"한 번 설정해두면 내가 아무것도 안 해도 알아서 돌아가는 자동화"</mark>예요.

기존 예약 작업은 **내 컴퓨터가 켜져 있어야** 실행됐어요. 하지만 루틴은 달라요.

> 🏠 **비유**: 집에 세탁기를 예약해두면, 내가 외출해도 세탁기가 돌아가잖아요? 루틴도 똑같아요. Anthropic 서버(클라우드)에서 돌아가기 때문에 **내 컴퓨터를 꺼도, 인터넷이 끊겨도** 예약된 시간에 자동으로 실행돼요.

---

## 기존 예약 작업과 뭐가 다른가요?

| 비교 항목 | 코워크 예약 작업 | 루틴(Routines) |
|----------|----------------|---------------|
| 실행 위치 | 내 컴퓨터 | Anthropic 서버(클라우드) |
| 컴퓨터 꺼도? | ❌ 실행 안 됨 | ✅ 정상 실행 |
| 트리거 종류 | 시간 예약만 | 시간 + API + GitHub |
| 설정 방법 | 코워크 탭 UI | `/schedule` 명령 또는 claude.ai/code |
| 주요 용도 | 간단한 반복 업무 | 코드 리뷰, CI 자동화, 보고서 생성 |

<div class="note-circle">
○ 코워크 예약 작업이 "알람 시계"라면, 루틴은 "회사에 고용한 직원"이에요. 내가 자고 있어도 직원은 출근해서 일해요.
</div>

## 3가지 트리거 방식

루틴은 **"언제 실행할지"**를 3가지 방식으로 정할 수 있어요.

### ① 시간 예약 (Scheduled)

정해진 시간에 자동으로 실행돼요.

```
매시간 / 매일 밤 / 평일만 / 매주 월요일
```

**예시**: "매일 밤 11시에 코드 리뷰해줘"

### ② API 호출 (On-demand)

다른 프로그램이나 서비스에서 **"지금 실행해!"**라고 신호를 보내는 방식이에요.

```
HTTP POST → https://api.claude.ai/routines/실행
```

**예시**: "Slack에서 특정 명령어 치면 보고서 자동 생성"

### ③ GitHub 이벤트 (Webhook)

GitHub에서 뭔가 일어나면 자동으로 실행돼요.

```
PR이 열리면 → 자동으로 코드 리뷰
CI가 실패하면 → 자동으로 원인 분석
```

**예시**: "누가 PR 올리면 Claude가 자동으로 리뷰 댓글 달기"

<div class="note-star">
★ <strong>비개발자라면</strong> ① 시간 예약만 알아도 충분해요! ②③은 개발팀에서 주로 쓰는 방식이에요.
</div>

## 루틴 설정하는 방법

### 방법 1: Claude Code 터미널에서

```bash
/schedule
```

이 명령어를 입력하면 루틴 설정 화면이 나와요. 어떤 작업을 할지, 언제 실행할지 대화하듯이 정하면 돼요.

### 방법 2: claude.ai/code 웹에서

1. **claude.ai/code** 접속
2. 왼쪽 메뉴에서 **"Routines"** 클릭
3. **"+ 새 루틴"** 버튼으로 설정

---

## 실전 예시

### 예시 ① 매일 밤 코드 리뷰 (개발자용)

```
[매일 밤 11시 실행]

오늘 올라온 PR(Pull Request)들을 모두 확인하고,
코드 품질, 버그 가능성, 보안 이슈를 리뷰해줘.
리뷰 결과를 각 PR에 댓글로 남겨줘.
```

**결과**: 아침에 출근하면 밤새 Claude가 달아놓은 코드 리뷰가 기다리고 있어요.

### 예시 ② 매주 월요일 주간 요약 보고서

```
[매주 월요일 오전 7시 실행]

GitHub 레포의 지난 1주일 커밋을 분석하고,
어떤 기능이 추가됐는지, 버그가 몇 개 수정됐는지 정리해줘.
결과를 Slack #weekly-report 채널에 보내줘.
```

**결과**: 월요일 아침 회의 전에 자동으로 주간 보고가 올라와 있어요.

### 예시 ③ CI 실패 자동 수정 (고급)

```
[GitHub에서 CI 실패 시 자동 실행]

실패한 테스트의 원인을 분석하고,
간단한 수정이 가능하면 자동으로 PR을 만들어줘.
복잡한 문제면 Slack으로 알림만 보내줘.
```

**결과**: 빌드가 깨지면 Claude가 자동으로 고쳐서 PR을 올려요. 개발자는 승인만 하면 끝!

## 플랜별 하루 실행 한도

루틴은 무제한이 아니에요. 요금제에 따라 하루에 실행할 수 있는 횟수가 정해져 있어요.

| 요금제 | 하루 실행 횟수 |
|--------|-------------|
| Pro ($20/월) | 5회 |
| Max ($100/월) | 15회 |
| Team / Enterprise | 25회 |

<div class="note-circle">
○ 한도를 넘기면 추가 크레딧이 소모돼요. 처음엔 5회로도 충분하니 걱정 마세요!

## 꼭 알아두세요

- **루틴은 유료 플랜 전용**이에요. Free 플랜에서는 사용할 수 없어요.
- 루틴이 실행한 결과는 **claude.ai/code**에서 확인할 수 있어요.
- 실행 중 오류가 나면 **이메일 또는 앱 알림**으로 알려줘요.
- 루틴은 **연구 프리뷰(Research Preview)** 상태예요. 앞으로 더 좋아질 거예요.
