## Projects가 뭔가요?

> 🏗️ **비유로 설명하면**: 혼자서 건물을 짓는 게 아니라, **건축 감독(클로드)** 한 명이 벽돌공·배관공·전기공(각각의 쓰레드)들을 직접 배치하고 진행 상황을 관리해주는 거예요. 나는 "이 건물 지어줘"라고만 하면 돼요.

**기존 방식 vs. Projects**

| 기존 | Projects |
|---|---|
| 세션 하나씩 직접 열고 맥락을 반복 설명 | 클로드가 쓰레드를 알아서 시작 |
| "A 하고, B 하고, C 해" 직접 지시 | "이 작업 리스트 처리해줘" 한 번에 |
| 노트북 닫으면 중단 | 닫아도 클라우드에서 계속 실행 |
| 완료 여부 직접 확인 | Overview 창에서 한눈에 현황 파악 |

---

## 언제 Projects를 쓰면 좋나요?

✅ **이런 상황에 잘 맞아요**

- 🔄 **여러 저장소에 같은 변경 적용** — "전체 서비스 린트 설정 업데이트" → 저장소마다 쓰레드 하나씩
- 📥 **계속 들어오는 작업 처리** — 버그 리포트·스택 트레이스를 대화창에 붙여넣으면 클로드가 처리
- 🛠️ **세션 하나에 끝나지 않는 큰 작업** — "이 스펙 구현해줘", "레거시 ORM 교체"
- 📄 **코드 외 문서 작업** — 계약서 폴더·지원 티켓 분석

❌ **이런 경우는 Projects보다 다른 방법이 나아요**

| 상황 | 더 나은 방법 |
|---|---|
| 한 번에 끝나는 단순 작업 | 일반 클라우드 세션 |
| 내 PC에만 있는 데이터베이스·VPN 필요 | 로컬 세션 + Agent View |
| 스케줄 반복 자동화만 필요 | Routines |
| Slack 팀 채널에서 같이 사용 | Claude Tag |

## Projects 구조 한눈에 보기

```
나 (대화창에 작업 전달)
    ↓
[코디네이터 클로드] ← 쓰레드 시작 / 추적 / 보고 수신
    ↓           ↓           ↓
[쓰레드 1]  [쓰레드 2]  [쓰레드 3]
(각각 클라우드 세션 — 독립 브랜치 · PR 오픈)
    ↓
[Overview 창] — Ready for review / Waiting on you / Working
```

> 📌 **쓰레드 = 클라우드 세션**: 각 쓰레드는 내 PC가 아닌 클라우드에서 실행돼요. 노트북을 닫아도 계속 돌아가요.

## 시작하는 법

### 사전 조건 체크

| 조건 | 확인 방법 |
|---|---|
| Pro 또는 Max 플랜 | claude.ai 계정 확인 |
| 사이드바에 "Projects" 표시 | claude.ai/code 접속 후 확인 |
| GitHub.com 연결 (코드 작업 시) | Claude GitHub App 설치 필요 |

> ⚠️ GitHub Enterprise Server·GitLab·Bitbucket은 현재 미지원 (github.com만 지원)

### 처음 만들기

1. **claude.ai/code** 또는 Desktop 앱 열기
2. 사이드바 → **Projects** → **New project** 클릭
3. 이름 입력 (예: "payments API 최적화")
4. 선택 사항: Goal(목표 한 줄), 저장소 추가
5. **Create project** 클릭

### 프로젝트 지침서(Instructions) 쓰기

> 📝 **비유로 설명하면**: 직원에게 처음 일을 맡길 때 주는 **업무 매뉴얼**이에요. 한 번만 쓰면 모든 쓰레드가 읽고 시작해요.

**유용한 지침서 예시:**
```text
이 프로젝트는 payments API의 p95 지연을 200ms 이하로 유지합니다.

- main 브랜치에서 시작, 쓰레드마다 draft PR 오픈
- 완료 전 `make test`와 `make lint` 실행 후 결과 첨부
- 필요한 저장소·시크릿·API에 접근 못하면 첫 메시지에 정확히 명시 후 중단
- 병합·force-push·CI 설정 변경은 내 허락 먼저
```

## Overview 창 — 현황 파악

Overview 창에서 쓰레드 상태를 한눈에 봐요:

| 상태 | 의미 |
|---|---|
| 🟢 Ready for review | PR 오픈 완료, 내 리뷰 대기 |
| 🟡 Waiting on you | 내 답변·승인 필요 |
| 🔵 Working | 현재 실행 중 |
| ⬇️ Landing | PR 승인 완료·병합 대기 |
| ⚪ Idle | 작업 완료 (대기) |
| ✅ Resolved | 완전히 마무리 |

Desktop 앱에서는 쓰레드가 완료되거나 문제 생기면 **데스크톱 알림**도 와요.

## 비용과 사용량

> 💡 **주의**: Projects는 여러 세션이 동시에 돌아가기 때문에 **플랜 사용량을 빠르게 소모해요**. Pro 플랜에서는 특히 하루 한도에 일찍 도달할 수 있어요.

- 쓰레드 1개 = 세션 1개 소비 (동시 여러 개 가능)
- 하루 최대 200개 쓰레드 (프로젝트 전체 합산)
- PR을 감시 중인 유휴 쓰레드도 CI 실패·리뷰 댓글 오면 다시 깨어나 사용량 소모

**절약 팁:**
- 코디네이터 모델: 작은 모델(Sonnet) 사용 가능
- 쓰레드 모델: "Sonnet으로 작업해줘" 요청 가능
- 쓰레드 동시 실행 수 제한 요청 가능

## 자주 묻는 질문

**Q. 쓰레드가 멈춰 보여요**  
A. 클라우드 환경 준비하는 시간이 있어요. 쓰레드 카드 클릭해서 대화 내용 확인하세요. 권한 프롬프트가 뜨면 그 안에서 답변해야 해요.

**Q. 쓰레드가 엉뚱한 가정을 했어요**  
A. 대화창에 "모든 열린 쓰레드에서 가정한 내용과 막힌 내용 정리해줘" 물어보세요. 원인 파악 후 프로젝트 지침서(Instructions)를 수정하세요.

**Q. 프로젝트 중단하고 싶어요**  
A. Project settings > General → **Pause** (일시중단) 또는 **Archive** (보관) 선택. Delete는 복구 불가.
