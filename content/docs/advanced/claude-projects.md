## Claude Projects가 뭔가요?

**Projects**는 관련된 여러 Claude Code 세션을 하나의 "프로젝트"로 묶어서, 한 화면에서 여러 에이전트를 함께 감독하고 운영하는 기능이에요.

> 🏭 **비유로 설명하면**: 큰 공장의 현장 관리자를 생각해보세요. 각 작업대(세션)에서 다른 작업이 돌아가고 있지만, 관리자는 한 자리에서 모든 작업대 상태를 보면서 "A 작업대 계속해", "B 작업대 잠깐 멈춰"를 지시할 수 있어요. Projects가 그 역할이에요.

---

## 어떤 상황에 유용한가요?

### ✅ 이럴 때 써요
- 프론트엔드/백엔드/테스트를 각각 다른 세션이 처리할 때
- 긴 마이그레이션에서 여러 에이전트가 병렬로 파일을 수정할 때
- 주요 기능 하나에 여러 서브태스크가 엮여 있을 때
- 오래 걸리는 작업을 "감독"하면서 중간에 방향 수정이 필요할 때

### ❌ 이럴 때는 안 써요
- 단순 1:1 대화형 코딩 질문
- 짧은 일회성 작업
- CLI 터미널만 쓰는 환경

## Projects 사용법 (Claude Code Desktop)

### 1. 새 Project 만들기

Claude Code Desktop 앱에서:
1. 왼쪽 사이드바 → "New Project" 클릭
2. 프로젝트 이름과 작업 디렉토리 설정
3. 첫 세션 자동 시작

### 2. 여러 세션 추가하기

```
[Project: 쇼핑몰 리팩토링]
├── 세션 1: 프론트엔드 컴포넌트 분리
├── 세션 2: API 엔드포인트 정리
└── 세션 3: 테스트 코드 작성
```

각 세션은 독립적으로 작동하지만, 같은 프로젝트 아래에 묶여서 한 화면에서 볼 수 있어요.

### 3. 감독 & 조율

- 각 세션의 진행 상황을 한 화면에서 확인
- 특정 세션에 클릭해서 개입·수정 지시
- 세션 완료 시 다음 단계 세션에 결과 전달

## Agent View와의 차이

| 기능 | Agent View | Projects |
|---|---|---|
| 범위 | **모든** Claude Code 세션 | **특정 프로젝트** 세션만 |
| 용도 | 전체 모니터링 | 관련 세션 그룹화·관리 |
| 플랫폼 | 웹/모바일/데스크톱 | 데스크톱 전용 |

> 💡 **추천**: 하나의 큰 작업을 쪼개서 여러 에이전트에게 맡길 때는 Projects, 여러 무관한 세션을 한눈에 보고 싶을 때는 Agent View를 쓰세요.

## 실전 예시: 레거시 코드 마이그레이션

```
[Project: Python 2 → Python 3 마이그레이션]
│
├── [세션 A] 의존성 분석
│   "현재 코드베이스의 Python 2 전용 패키지 목록 뽑아줘"
│
├── [세션 B] 자동 변환 (2to3 도구 활용)
│   "2to3로 변환 가능한 파일 모두 처리해줘"
│
└── [세션 C] 수동 검토 필요 항목 처리
    "세션 A/B가 못한 부분만 수동으로 수정해줘"
```

각 세션이 완료되면 Projects 화면에서 체크하고 다음 단계를 지시할 수 있어요.

## 주의 사항

- **데스크톱 앱 전용**: 터미널 CLI에서는 Projects 기능이 없어요.
- **세션 간 공유**: 각 세션은 독립된 컨텍스트를 갖지만, 같은 로컬 파일시스템을 공유해요. 충돌 방지를 위해 세션별 작업 범위를 명확히 나누세요.
- **동시 편집 주의**: 같은 파일을 두 세션이 동시에 수정하면 충돌이 생길 수 있어요.

## 정리

> Projects = 여러 에이전트를 한 "폴더"에 묶어서, 큰 작업을 팀플레이처럼 운영하는 기능이에요. 오케스트라 지휘자처럼 여러 파트를 동시에 보면서 조율할 수 있어요.
