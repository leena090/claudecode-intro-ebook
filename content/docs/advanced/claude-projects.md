## Projects가 뭔가요? 📁

**Projects(프로젝트)**는 비슷한 목적을 가진 여러 Claude Code 세션을 하나의 폴더로 묶는 기능이에요.

> 💡 **비유**: 학교 과목별 필기 노트를 하나의 바인더에 모으는 것처럼, 관련 작업 세션을 하나의 프로젝트로 모아두는 거예요.

**이런 상황에 유용해요**:
- 🏗️ 큰 기능 하나를 여러 클로드가 병렬로 개발할 때
- 🔍 프론트엔드·백엔드·테스트를 각각 다른 세션에서 동시에 진행할 때
- 📋 여러 티켓/이슈를 각기 다른 클로드가 맡아 처리할 때
- 👀 여러 클로드 에이전트의 진행 상황을 한 화면에서 보고 싶을 때

---

## 기존 Agent View와 뭐가 달라요?

| 기능 | Agent View | Projects |
|------|-----------|---------|
| 목적 | 현재 활성 세션 모니터링 | 세션 그룹 조직화 |
| 범위 | 지금 돌아가는 세션들 | 관련 세션들을 미리 묶어 관리 |
| 편의성 | 감시에 특화 | 그룹화 + 감시 |
| 위치 | Claude Code 메인 화면 | 데스크톱 앱 사이드바 |

> 💡 Agent View가 "CCTV 모니터"라면, Projects는 "팀별로 나눠진 사무실 층 배치도"예요.

## Projects 시작하기 (데스크톱 앱 기준)

### 1단계 — 새 프로젝트 만들기

데스크톱 앱 사이드바에서:
1. `+ New Project` 클릭
2. 프로젝트 이름 입력 (예: "쇼핑몰 리팩터링")
3. 작업 디렉토리(워크스페이스) 연결

### 2단계 — 세션 추가

프로젝트 안에서 `+ New Session`으로 세션을 여러 개 만들어요:
- 세션 1: "프론트엔드 버그 수정"
- 세션 2: "API 엔드포인트 추가"
- 세션 3: "테스트 코드 작성"

### 3단계 — 동시 감독

사이드바에서 프로젝트를 클릭하면 그 안의 세션들이 나란히 보여요.  
각 세션이 뭘 하고 있는지 한눈에 파악할 수 있어요.

---

## 실전 예시: 기능 추가를 3개 클로드에 나누기

```
프로젝트: "결제 모듈 추가"
├── 세션 A: "결제 API 연동" (Claude 1)
│   └── POST /payments, Stripe SDK 연동
├── 세션 B: "결제 UI 컴포넌트" (Claude 2)  
│   └── CheckoutForm.tsx, PaymentModal.tsx
└── 세션 C: "결제 테스트 코드" (Claude 3)
    └── payments.test.ts, e2e 시나리오
```

세 클로드가 동시에 작업하면서, 여러분은 Projects 화면에서 감독만 하면 돼요.

## 주의사항과 팁

**세션 간 충돌 방지**:
- 같은 파일을 여러 세션이 동시에 수정하면 충돌이 날 수 있어요
- Worktrees(워크트리) 기능과 함께 쓰면 각 세션이 독립 브랜치에서 작업 가능

**클로드 에이전트 수 제한**:
- 계정 플랜에 따라 동시 실행 세션 수 제한이 있을 수 있어요 (공식 발표 기준 미확인)

**Projects vs Dynamic Workflows**:

| | Projects | Dynamic Workflows |
|--|---------|-----------------|
| 제어 방식 | 사람이 직접 감독 | Claude가 자동으로 오케스트레이션 |
| 적합한 상황 | 사람이 방향 잡아주며 진행 | Claude가 계획부터 실행까지 자율 |
| 복잡도 | 간단 | 복잡한 대규모 작업 |

## 데스크톱 앱이 없다면?

현재 Projects는 **Claude Code Desktop 전용**이에요.

터미널에서 비슷한 효과를 내려면:
- 여러 터미널 창에서 각각 `claude` 실행
- tmux나 iTerm2의 분할 창 활용

## 정리

| 질문 | 답변 |
|------|------|
| CLI 사용자도 쓸 수 있나요? | 현재는 데스크톱 앱 전용이에요 |
| 프로젝트당 세션 수 제한? | 공식 미발표 (추정: 계정 플랜 기준) |
| 세션 사이에 정보 공유가 되나요? | 직접적인 공유는 없고, 같은 파일을 통해 간접 공유 |
| Agent View와 함께 쓰나요? | 네, Projects 안에서 Agent View로 각 세션 상세 감시 가능 |
