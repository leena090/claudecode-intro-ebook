## Projects가 뭔가요?

**Projects**는 "하나의 대화에서 여러 관련 작업을 동시에 진행"할 수 있는 기능이에요. 클로드가 각 작업마다 별도의 **스레드(thread)**를 만들어서 동시에 처리해줘요.

> 🍱 **비유로 설명하면**: 기존 Claude Code는 "직원 한 명과 1:1로 일하는 것"이었다면, Projects는 **"팀장(내가) 지시를 내리면 여러 직원들이 각자 일을 처리하고, 나는 스마트폰으로 진행 상황을 확인하는 것"** 과 같아요.

---

## 핵심 개념 3가지

### 1. 프로젝트 (Project)
하나의 **지속되는 대화** 공간이에요. 여기서 여러 작업을 지시하고 결과를 받아봐요.

### 2. 스레드 (Thread)
각 개별 작업이에요. 보통 **클라우드 세션**으로 실행되는데, 클로드가 클라우드에서 실행되니까 내 컴퓨터를 끄더라도 계속 일해요.

### 3. 병렬 실행
여러 스레드가 **동시에** 돌아요. A 기능 수정하면서 동시에 B 버그도 잡고, 테스트 코드도 작성하는 식이죠.

## 어디에 있나요? (열기)

```
클로드 앱 사이드바 → Projects 클릭
또는
claude.ai/code 웹에서 Projects 탭
```

<div class="note-star">
★ 사이드바에 <strong>Projects</strong> 탭이 보이지 않는다면 아직 배포가 안 된 거예요. <a href="https://claude.com/form/projects">claude.com/form/projects</a>에서 대기자 명단에 등록하세요.
</div>

## 어떻게 사용하나요?

### 기본 흐름

```
1. 프로젝트 열기
2. 전체 목표를 자연어로 설명
   예: "이 저장소의 결제 모듈을 리팩토링하고, 테스트 커버리지도 80% 이상 만들어줘"
3. 클로드가 자동으로 작업을 쪼개서 스레드를 생성
4. 각 스레드가 병렬로 실행
5. 결과 확인 & 방향 수정
```

### 컴퓨터 자원이 필요한 작업

대부분의 스레드는 **클라우드에서** 실행되지만, 내 로컬 서버가 필요하거나 로컬 DB에 접근해야 할 때는 **내 컴퓨터에서** 실행하도록 지시할 수도 있어요 (Remote Control 기능 활용).

## 어떤 상황에서 쓰면 좋아요?

| 상황 | 예시 |
|---|---|
| **대규모 기능 추가** | "결제 시스템 전체 추가 — 백엔드 API, 프론트엔드 UI, 테스트 전부" |
| **여러 모듈 동시 수정** | "A 모듈 리팩토링하면서 B 모듈 테스트 커버리지도 올려줘" |
| **긴 마이그레이션** | "Python 2 → 3 마이그레이션, 파일 50개 이상" |
| **멀티팀 PR 준비** | "백엔드 PR 따로, 프론트 PR 따로, 문서 업데이트 따로 만들어줘" |

## 지금 당장 못 쓰는 경우 대안은?

Projects가 아직 배포 안 됐다면 비슷한 효과를 내는 방법:

| 방법 | 설명 |
|---|---|
| **[에이전트 병렬 실행](/docs/advanced/agents-parallel)** | 직접 `Agent` 명령으로 서브에이전트 띄우기 |
| **[Dynamic Workflows](/docs/advanced/dynamic-workflows)** | `/workflow` 명령으로 대규모 병렬 실행 |
| **[Worktrees](/docs/advanced/worktrees)** | git worktree로 여러 브랜치 동시 작업 |

## 이전 프로젝트 기능과의 차이

Claude.ai 채팅에도 "Projects"가 있었는데, 이건 다른 것이에요:

| 구분 | 기존 claude.ai Projects | **새 Claude Code Projects** |
|---|---|---|
| 목적 | 대화 정리 · 파일 공유 | **코딩 작업 병렬 실행** |
| 실행 방식 | 단일 대화 | **여러 클라우드 세션 동시** |
| 주 사용자 | 일반 Claude 사용자 | **Claude Code 사용자** |
