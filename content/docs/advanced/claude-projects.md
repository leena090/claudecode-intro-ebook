## "세션이 너무 많아서 뭐가 뭔지 모르겠어요"

Claude Code를 쓰다 보면 세션(대화창)이 쌓이기 시작합니다. "이건 로그인 버그 고치는 거였고, 저건 테스트 작성 중이었고…" 헷갈리죠?

**Projects**(프로젝트)가 그 문제를 해결합니다.

> 📁 **비유로 설명하면**: 책상 위 서류들을 종류별로 폴더에 정리하듯, 관련 있는 코딩 세션들을 하나의 "프로젝트 폴더"에 묶어두는 기능입니다.

---

## Projects란 무엇인가요?

**Projects**는 같은 목적을 가진 여러 Claude Code 세션을 한 그룹으로 묶고, **동시에 여러 에이전트가 작업하는 것을 한 화면에서 관리**하는 기능입니다.

| 항목 | 설명 |
|------|------|
| 위치 | Claude Code Desktop 앱 |
| 출시 | 2026-09-17 |
| 핵심 역할 | 세션 그룹화 + 병렬 에이전트 감독 |

---

## 어떤 상황에 유용한가요?

### 예시 1: 큰 기능 개발
새로운 결제 시스템을 만들 때:
- 세션 A: 결제 API 연동
- 세션 B: UI 컴포넌트 작성
- 세션 C: 테스트 코드 작성

이 세 세션을 "결제 시스템 v2" 프로젝트 하나로 묶으면, 진행 상황을 한눈에 볼 수 있어요.

### 예시 2: 버그 수정 스프린트
- 세션 1: 로그인 오류 수정
- 세션 2: 결제 이중 청구 버그 수정
- 세션 3: 모바일 레이아웃 깨짐 수정

> 🏢 **비유**: 팀장(여러분)이 여러 직원(에이전트)에게 각각 일을 맡기고, 사무실 화면에서 모든 직원의 진행 상황을 한 번에 보는 것과 같아요.

---

## 주요 기능

### 1. 세션 그룹화
- 관련 세션들을 같은 프로젝트 폴더에 추가
- 프로젝트 이름, 설명 직접 지정 가능
- 나중에 "아, 이 작업은 어느 세션이었지?" 하는 혼란 방지

### 2. 병렬 작업 관리
여러 에이전트가 동시에 작업 중일 때:
- 각 세션의 현재 상태 한눈에 확인
- 완료된 세션과 진행 중인 세션 구분
- 결정이 필요한 세션에 빠르게 개입

### 3. 컨텍스트 공유 (추정)
같은 프로젝트 내 세션들이 공통 맥락을 공유할 수 있습니다.

> ⚠️ **주의**: 세션 간 컨텍스트 공유 방식은 공식 세부 사항이 아직 명확히 발표되지 않았습니다. 현재 공식 문서를 직접 확인하세요.

## Agent View와의 차이점

| | Agent View | Projects |
|--|-----------|----------|
| 역할 | 현재 실행 중인 모든 세션 모니터링 | 관련 세션 그룹화·관리 |
| 범위 | 전체 세션 | 프로젝트별 그룹 |
| 비유 | 전체 현황판 | 팀별 프로젝트 보드 |

> Agent View는 "지금 뭐가 돌아가고 있지?" 확인용,  
> Projects는 "이 프로젝트 세션들을 한 곳에 모아두기" 위한 것.

---

## 사용 방법

1. **Claude Code Desktop 앱** 열기
2. 왼쪽 사이드바에서 **Projects** 메뉴 클릭
3. **새 프로젝트 만들기** → 이름 입력
4. 기존 세션 추가 또는 새 세션 시작
5. 프로젝트 화면에서 모든 세션 상태 확인

> 💡 **팁**: 큰 작업을 시작하기 전에 프로젝트를 먼저 만들어두면, 나중에 "이 세션이 뭘 하던 세션이었지?" 하는 혼란 없이 작업 이력을 깔끔하게 관리할 수 있어요.

---

## 📌 정리

Projects는 혼자 여러 에이전트를 굴리기 시작한 중급 사용자에게 특히 유용합니다.

- 세션이 3개 이상 동시에 돌아가고 있다면 → **Projects 도입 타이밍**
- Claude Code Desktop 앱 필수
- Agent View(`/agent-view`)와 함께 쓰면 더욱 강력
