## Projects(프로젝트)가 뭔가요?

**관련된 Claude Code 세션들을 하나의 폴더(프로젝트)로 묶고, 여러 AI 에이전트를 동시에 관리**하는 기능이에요.

> 📋 **비유로 설명하면**: 회사에서 "쇼핑몰 리뉴얼" 프로젝트를 진행한다고 생각해보세요.
> - 이전에는 각 담당자(Claude 세션)가 따로따로 일하는 느낌이었다면,
> - **Projects**는 "리뉴얼 팀 방"을 만들어서 프론트엔드 담당, 백엔드 담당, 테스트 담당을 한 공간에서 같이 보는 것과 같아요.

---

## Projects 기능 한눈에 보기

| 이전 방식 | Projects 사용 시 |
|----------|----------------|
| 세션마다 새 창 열기 | **하나의 프로젝트 뷰**에서 모든 세션 확인 |
| 진행 상황 따로 파악 | **통합 대시보드**에서 한눈에 감독 |
| 관련 세션 찾기 어려움 | **그룹별 정리**로 맥락 유지 |
| 에이전트 간 조율 수동 | 여러 에이전트를 **병렬 실행 + 감독** |

---

## 어떤 상황에서 유용한가요?

### 예시 1: 대규모 코드 마이그레이션

```
[프로젝트: Python 2→3 마이그레이션]
├── 에이전트 1: core/ 폴더 변환
├── 에이전트 2: tests/ 폴더 변환
├── 에이전트 3: 변환 결과 검증
└── 에이전트 4: 문서 업데이트
```

→ 4개 세션이 병렬로 작업하면서 진행 상황을 한 화면에서 봐요.

### 예시 2: 멀티 서비스 버그 수정

```
[프로젝트: 결제 시스템 장애 대응]
├── 세션 A: 백엔드 API 오류 추적
├── 세션 B: 프론트엔드 에러 로그 분석
└── 세션 C: DB 쿼리 검토
```

### 예시 3: 기능 개발 파이프라인

```
[프로젝트: 다크모드 추가]
├── 세션 1: 컴포넌트 설계 (진행 중)
├── 세션 2: 색상 토큰 정의 (완료 ✅)
└── 세션 3: 테스트 작성 (대기 중)
```

## 사용 방법 (Desktop 기준)

1. **Claude Code Desktop** 앱 실행
2. 좌측 사이드바에서 **"+ 새 프로젝트"** 클릭
3. 프로젝트 이름과 관련 저장소 경로 설정
4. 세션을 프로젝트에 추가하거나 프로젝트 내에서 새 세션 생성
5. 프로젝트 뷰에서 모든 에이전트의 진행 상황 확인 및 지시

---

## Agent View와의 관계

**Agent View**가 모든 세션을 한 화면에서 보는 기능이라면,  
**Projects**는 그 세션들에 **의미 있는 분류**를 추가하는 기능이에요.

| 기능 | 역할 |
|------|------|
| **Agent View** | 현재 실행 중인 모든 세션 실시간 모니터링 |
| **Projects** | 관련 세션을 그룹화·관리·감독 |

> 💡 두 기능을 함께 쓰면 여러 에이전트를 프로젝트별로 묶어서 체계적으로 운영할 수 있어요.

---

## Desktop 앱이 필요해요

Projects 기능은 현재 **Claude Code Desktop 앱**에서만 사용할 수 있어요.

- **macOS**: 바로 사용 가능
- **Windows**: 바로 사용 가능  
- **Linux**: 베타 버전
- **터미널(CLI)**: Projects UI 미지원 (세션 관리는 직접)
- **웹(claude.ai/code)**: 지원 여부 확인 필요 (공식 문서 참조)
