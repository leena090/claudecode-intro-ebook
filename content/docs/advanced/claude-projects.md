## Projects란?

**하나의 대화 창에서 Claude가 관련된 여러 작업을 동시에 처리해주는 기능**이에요.

지금까지는 한 세션에서 하나의 대화만 가능했죠. Projects를 쓰면 "이 세 가지 작업 처리해줘"라고 말하면 Claude가 각각을 별도 스레드(thread)로 나누어 **동시에 진행**합니다.

> 🧑‍💼 **비유로 설명하면**: 혼자 일하던 직원에게 팀장 역할을 준 것과 같아요. 팀장(Projects)은 각 팀원(스레드)에게 일을 배분하고 진행 상황을 한 화면에서 확인합니다. 작업마다 같은 회사 규정(지시사항)과 공유 자료(저장소)를 쓰고요.

---

## 무엇이 다른가요?

| 기존 방식 | Projects |
|---------|---------|
| 하나의 작업 | **여러 작업 동시 진행** |
| 세션이 닫히면 중단 | **클라우드에서 계속 실행** |
| 각 세션이 독립적 | **저장소·지시사항·메모리 공유** |
| PC에서만 확인 | **스마트폰에서도 현황 확인** |

---

## 핵심 개념: 스레드 (Thread)

Projects 안의 각 작업 단위를 **스레드**라고 해요.

- 각 스레드는 보통 **클라우드 세션** — 내 컴퓨터가 아닌 클라우드에서 돌아가요
- 내 컴퓨터의 파일이 필요한 작업은 Remote Control을 통해 **내 컴퓨터에서** 실행 가능
- 여러 스레드가 **동시에 병렬로** 실행
- PC를 꺼도 클라우드 스레드는 계속 실행 (내 컴퓨터 스레드는 PC가 켜져 있어야 함)

## Projects 사용 흐름

```
1. Projects 대화 시작
   "이번 주 할 일 목록: A 기능 개발, B 버그 수정, C 문서 작성"

2. Claude가 각 작업을 스레드로 나눔
   ├── 스레드 1: A 기능 개발 (클라우드 세션)
   ├── 스레드 2: B 버그 수정 (클라우드 세션)
   └── 스레드 3: C 문서 작성 (클라우드 세션)

3. 모두 동시 실행 🚀

4. 스마트폰에서 진행 상황 확인
   "스레드 2 완료, 스레드 1 진행 중..."

5. 필요할 때만 개입해서 방향 조정
```

## 어떤 플랜에서 쓸 수 있나요?

**공식 발표 기준:**

- ✅ **Pro, Max, Ultra 플랜** — 공개 베타 접근 가능 (순차적 출시 중)
- ❌ **Team, Enterprise 플랜** — 아직 미지원 (추후 출시 예정)
- 클라우드 세션을 써본 계정 위주로 먼저 열리고 있어요

> 📋 **대기 신청**: 아직 Projects가 보이지 않는다면 `claude.com/form/projects`에서 웨이팅 리스트에 등록할 수 있어요.

## 기존 에이전트 기능과의 차이

Projects 외에도 여러 에이전트를 돌리는 방법이 있어요.

| 기능 | 특징 | 적합한 상황 |
|------|------|-----------|
| **Projects** | 대화 허브에서 직접 관리 | 연관된 여러 작업을 한곳에서 |
| **Dynamic Workflows** | 10~100개 대규모 병렬 처리 | 코드 리뷰 등 대규모 분석 |
| **Agent Teams** | 에이전트끼리 직접 메시지 | 조직화된 팀 작업 |
| **Remote Control** | 내 PC를 클라우드에서 제어 | 로컬 환경이 필요한 경우 |

## 실용 활용 예시

### 여러 PR 동시 처리
```
"이 3개 PR 동시에 리뷰하고 수정해줘:
- PR #101: 로그인 버그
- PR #102: 결제 모듈 리팩토링
- PR #103: 테스트 커버리지 향상"
```

### 주간 작업 일괄 위임
```
"이번 주 할 일:
- 의존성 패키지 최신 버전으로 업데이트
- README 문서 한국어로 번역

"개발·스테이징·프로덕션 DB 스키마가
모두 일치하는지 각각 확인해줘"
```

## 정리

Projects는 "Claude에게 여러 작업을 동시에 맡기는 대화 허브"예요.

지금까지 한 번에 하나씩 대화해야 했다면, Projects는 여러 작업을 동시에 진행하면서 그 모든 것을 한 대화창에서 관리할 수 있게 해줍니다. 클라우드에서 돌아가니 PC를 닫아도 작업은 계속되고, 스마트폰으로 현황을 볼 수 있어요.

> 💡 **공식 발표 기준**: Projects는 2026년 9월 현재 공개 베타 단계예요. 기능이 계속 발전할 수 있습니다.
