## Projects가 뭔가요?

**Projects**는 관련된 코딩 작업들을 **하나의 대화창에서 Claude가 자동으로 조율**하는 기능이에요.

> 🍱 **비유로 설명하면**: 여러 직원에게 각자 다른 업무를 맡기고 싶을 때, 예전엔 한 명씩 찾아가서 설명해야 했어요. Projects는 **사무실 공용 메신저 채널**처럼, 거기에 할 일을 올리면 Claude가 알아서 담당자(스레드)를 만들고 배분해요.

한마디로: **"Claude한테 할 일 던지는 창구 하나"** 예요.

---

## Projects가 필요한 순간

**이럴 때 씁니다 ✅**

- 여러 버그를 동시에 수정하고 싶을 때
- 서로 관련된 기능들을 병렬 개발할 때
- 노트북을 닫아도 Claude가 계속 작업해야 할 때
- 스마트폰으로 진행 상황 확인·조율하고 싶을 때

**이건 필요 없어요 ❌**

- 버그 하나 수정
- 간단한 질문·답변
- 단일 파일 편집

## 핵심 개념

### 스레드 = 클라우드 세션

Projects에서 각 작업은 **스레드(thread)**로 만들어져요. 스레드는 실제로 **클라우드 세션** — 내 컴퓨터가 아닌 Claude 서버에서 실행되는 Claude Code 세션이에요.

```
Projects 대화창
  ├── 스레드 1: 더블 클릭 결제 버그 수정
  ├── 스레드 2: 결제 모듈 테스트 작성
  └── 스레드 3: 모바일 레이아웃 수정
```

> 🍱 **비유**: 스레드는 **각 팀원의 작업 공간**이에요. 한 팀원이 결제 로직을 고치는 동안, 다른 팀원은 테스트를 쓰고, 또 다른 팀원은 모바일 화면을 고쳐요.

### 병렬 실행

스레드들은 **동시에 진행**돼요. 한 작업이 끝날 때까지 기다리지 않아요.

### 공유 컨텍스트

모든 스레드가 **같은 저장소 정보·지침·메모리**를 공유해요:
- `CLAUDE.md` 파일의 프로젝트 지침
- 공유 저장소 접근
- 이전 맥락 기억

## 어떻게 쓰나요?

### 시작하기

1. [claude.ai/code](https://claude.ai/code) 또는 Desktop 앱 사이드바에서 **Projects** 클릭
2. 새 프로젝트 만들기
3. 할 일 던지기:

```
"결제 버튼 더블클릭 버그 고쳐줘. 재현 방법: 결제 버튼을 빠르게 두 번 누르면 이중 결제됨"
```

4. Claude가 자동으로 스레드를 만들어 작업 시작

### 스마트폰으로 모니터링

스레드는 **내 노트북을 꺼도 계속 실행**돼요. 나중에 스마트폰 앱에서:
- 진행 상황 확인
- 결정 필요한 질문에 답변
- 새 작업 추가

## Projects vs. 기존 방식 비교

| 항목 | 기존 (개별 세션) | Projects |
|---|---|---|
| **조율** | 내가 직접 각 세션 관리 | Claude가 자동 조율 |
| **컨텍스트** | 각 세션마다 설명 반복 | 한 번 설정, 전체 공유 |
| **병렬성** | 수동으로 여러 창 열기 | 자동 스레드 생성 |
| **모니터링** | 컴퓨터 앞에 있어야 | 스마트폰으로 확인 가능 |
| **지속성** | 노트북 닫으면 멈춤 | 계속 실행 |

## 지금 사용할 수 없다면?

Projects는 **순차적으로 배포 중**이에요. 아직 내 계정에 안 보인다면:

1. [claude.com/form/projects](https://claude.com/form/projects) 대기자 명단 등록
2. 그동안 [병렬 에이전트 실행](https://code.claude.com/docs/en/agents) 기능으로 유사하게 사용 가능

> ⚠️ **현재 제한**:
> - Pro·Max 계획만 가능 (공개 베타)
> - Team·Enterprise는 아직 미지원
> - 기존에 claude.ai 채팅/Cowork에서 Projects를 쓰던 계정은 클라우드 세션 사용 이력 있는 신규 계정 순으로 배포

## 실전 팁

### 잘 쓰는 방법

```
# 좋은 예: 구체적이고 독립적인 작업들
"다음 3개 버그 동시에 수정해줘:
1. [#234] 결제 버튼 더블클릭 이중 결제
2. [#241] 모바일 레이아웃 깨짐 (iOS 17)
3. [#248] 비밀번호 재설정 이메일 미발송"

# 피해야 할 예: 서로 의존하는 작업들
"먼저 DB 스키마 바꾸고, 그 다음 API 수정해줘"
# → 순서가 중요한 작업은 Projects보다 단일 세션이 적합
```

### CLAUDE.md 활용

프로젝트 루트에 `CLAUDE.md`를 만들어두면 모든 스레드가 이 지침을 공유해요:

```markdown
# 프로젝트 지침
- 테스트는 항상 작성할 것
- 커밋 메시지는 한국어로
- 절대 `main` 브랜치에 직접 push 금지
```
