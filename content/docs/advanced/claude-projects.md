## Claude Projects란?

**Projects(프로젝트)** 는 **관련된 코딩 세션들을 하나로 묶어서 여러 Claude 에이전트를 동시에 실행하고 감시**할 수 있는 기능이에요. Claude Code Desktop에서 사용할 수 있어요.

> 🍱 **비유**: 회사에서 여러 팀이 동시에 같은 큰 프로젝트를 진행할 때, 팀장(당신)이 각 팀(에이전트)의 진행 상황을 한 화면에서 확인하는 것과 같아요.

---

## 언제 쓰면 좋을까요?

| 이럴 때 유용해요 ✅ | 없어도 되는 경우 ❌ |
|---|---|
| 프론트엔드 + 백엔드 + 테스트를 동시에 진행할 때 | 파일 하나 수정할 때 |
| 여러 기능을 병렬로 개발할 때 | 대화 하나로 해결되는 작업 |
| 큰 마이그레이션을 여러 부분으로 나눌 때 | 단순 질문·답변 |
| 장기 작업의 진행 상황을 한눈에 보고 싶을 때 | |

> 🍱 **비유**: 혼자 집을 짓는 대신, "배관팀은 1층, 전기팀은 2층, 인테리어팀은 외관" 처럼 나눠서 동시에 진행하고 현장 감독(당신)이 전체를 보는 거예요.

---

## 어떻게 사용하나요?

### 기본 흐름

1. **Claude Code Desktop** 앱을 열어요
2. 왼쪽 사이드바에서 **Projects** 탭을 선택해요
3. **새 프로젝트** 만들기
4. 프로젝트 안에서 여러 **세션(에이전트)** 시작하기
5. 각 세션이 독립적으로 작업하는 걸 한 화면에서 감독해요

### 화면 구성

```
┌─────────────────────────────────────────────┐
│  📁 My Big Refactor (프로젝트 이름)           │
│  ────────────────────────────────────────   │
│  🤖 세션 1: "프론트엔드 컴포넌트 분리"    진행중  │
│  🤖 세션 2: "API 엔드포인트 업데이트"    완료  ✅ │
│  🤖 세션 3: "테스트 추가"               대기중  │
│                                             │
│  [새 세션 추가]   [전체 요약 보기]              │
└─────────────────────────────────────────────┘
```

## Agent View와의 차이점

Projects와 비슷한 기능으로 **Agent View**도 있어요. 두 가지 차이를 알아봐요.

| 기능 | **Agent View** | **Projects** |
|---|---|---|
| 용도 | **모든** Claude Code 세션 한 화면에서 보기 | 관련된 세션을 **묶어서** 관리 |
| 그룹화 | ❌ (전체 목록) | ✅ (프로젝트 단위) |
| 추천 상황 | 세션이 많아졌을 때 전체 현황 파악 | 큰 작업을 논리적으로 분리할 때 |

> 🍱 **비유**: Agent View는 회사 전체 직원 명단, Projects는 팀별 프로젝트 관리판이에요.

---

## 주의할 점

- **Claude Code Desktop 전용** 기능이에요. 터미널 CLI에서는 사용 불가.
- 세션마다 독립적으로 실행되므로, **세션 간에 자동으로 파일을 공유하지는 않아요**. 공유 코드베이스를 작업할 때는 git 기반으로 각 세션이 commit/push 하도록 설정하세요.
- **비용 주의**: 세션이 많을수록 토큰 소비가 늘어요. 필요 없는 세션은 종료하세요.
