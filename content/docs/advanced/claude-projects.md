## Projects가 뭔가요?

이제까지 Claude Code로 작업할 때 **한 번에 한 가지**만 할 수 있었어요. "버그 고쳐", 끝나면 "테스트 써", 끝나면 "배포 설정 확인해"… 순서대로 하나씩이었죠.

**Projects**는 이 흐름을 바꿔요.

> 🎬 **영화 감독 비유**: 혼자 모든 걸 하는 1인 촬영(기존)이 아니라, **감독(당신)**이 "촬영팀, 조명팀, 미술팀 동시에 go!"라고 지시하면 **각 팀이 병렬로 작업**하는 것과 같아요. Projects는 당신을 1인 촬영자에서 감독으로 바꿔줍니다.

구체적으로는:
- 하나의 대화(conversation)에서 **연관된 여러 작업을 지시**
- 클로드가 각 작업마다 **별도 스레드**를 시작
- 각 스레드는 보통 **클라우드 세션**(cloud session) → 내 컴퓨터 없이도 실행
- 스레드들이 **병렬 실행** → 내 랩톱을 닫아도 계속 진행
- 스마트폰으로 진행 상황 확인 및 방향 조정 가능

## 어떻게 생겼나요?

```
📁 Project: "결제 모듈 리팩토링"
├─ 🧵 Thread 1: 이중 청구 버그 수정 (진행 중 ✅)
├─ 🧵 Thread 2: 결제 모듈 테스트 작성 (완료 ✅)
├─ 🧵 Thread 3: API 문서 업데이트 (대기 중 ⏳)
└─ 🧵 Thread 4: CI 파이프라인 설정 (진행 중 ✅)
```

> 🍱 **도시락 비유**: 주방장이 "밥 짓기 + 국 끓이기 + 반찬 볶기"를 순서대로 하면 1시간이지만, 세 명이 동시에 하면 20분 안에 밥상이 차려지는 것과 같아요.

---

## 핵심 개념 3가지

### 1. 스레드(Thread) — 각 작업 단위

- 각 지시마다 클로드가 새 스레드를 열어요
- 대부분은 **클라우드 세션**: 클로드 서버에서 실행되니 내 컴퓨터 전원 끊어도 OK
- 내 컴퓨터만 할 수 있는 일(사내 DB 접근 등)은 **내 컴퓨터 스레드**로 실행 가능 (Remote Control 사용)

### 2. 병렬 실행(Parallel) — 동시에 여러 스레드

```
[순차 방식]  작업1 → 완료 → 작업2 → 완료 → 작업3  (총 3시간)

[Projects]   작업1 ─────────────────────────────── 완료
             작업2 ──────────────────── 완료
             작업3 ────────── 완료                   (총 1시간)
```

### 3. 공유 컨텍스트(Shared Context)

Projects 안의 모든 스레드는 **같은 저장소, 같은 지시사항, 같은 메모리**를 공유해요.

> 📋 **비유**: 팀 프로젝트를 할 때 모든 팀원이 같은 Google Drive 폴더를 보면서 작업하는 것과 같아요.

## 어떻게 시작하나요?

### 조건 확인

1. **Pro 또는 Max 플랜** 구독 중
2. claude.ai/code 에서 클라우드 세션을 써본 적 있음
3. 사이드바에 **Projects** 탭이 보임

### 기본 사용법

```
1. claude.ai/code 또는 데스크톱 앱 실행
2. 사이드바에서 [Projects] 클릭
3. [New Project] → 저장소 선택
4. 대화 창에 여러 작업 지시:
   "이 저장소에서 다음 세 가지를 동시에 해줘:
   1) checkout.ts의 이중 청구 버그 수정
   2) payments 모듈 테스트 작성
   3) README 업데이트"
5. 클로드가 스레드 3개를 열어 동시 진행
```

## 내 컴퓨터 vs 클라우드 스레드

| 구분 | 클라우드 스레드 | 내 컴퓨터 스레드 |
|---|---|---|
| 실행 위치 | 클로드 서버 | 내 PC/Mac |
| 내 컴퓨터 꺼도 동작? | ✅ 계속 진행 | ❌ 중단됨 |
| 사내 DB/서비스 접근? | ❌ 불가 | ✅ 가능 |
| 설정 방법 | 기본값 | Remote Control 연결 필요 |

> 💡 **입문자 팁**: 대부분의 코딩 작업은 클라우드 스레드로 충분해요. 내 컴퓨터만 접근 가능한 시스템(VPN 내 DB, 사내 서비스)이 필요할 때만 내 컴퓨터 스레드를 써요.

## 스마트폰으로 확인하기

> 📱 **이런 상황 상상**: 점심 먹으러 나갔다가 스마트폰으로 "스레드 2 완료, 스레드 1 질문 있음"을 확인하고, 이동 중에 방향만 잡아줄 수 있어요.

- iOS / Android 클로드 앱에서 Projects 탭 진입
- 각 스레드 진행 상황 확인
- 클로드가 막히면 알림이 오고, 간단한 답변만 해주면 계속 진행
