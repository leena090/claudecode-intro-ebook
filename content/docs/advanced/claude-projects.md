## Projects가 뭔가요?

**Projects(프로젝트)** 는 Claude Code Desktop에서 **관련된 작업들을 하나의 대화창에서 묶어서 관리**하는 기능이에요.

> 🏗️ **비유**: 혼자서 집 짓는 대신, "1팀은 기초 공사, 2팀은 배관, 3팀은 전기" 하고 여러 팀에게 지시하는 현장 감독처럼요.  
> Claude가 각 팀(스레드)을 클라우드에서 병렬로 실행하고, 여러분은 감독자로서 진행 상황을 확인해요.

---

## Projects의 핵심 개념

### 스레드(Thread)
- 프로젝트 안의 각 작업 단위
- 보통 **클라우드 세션**으로 실행 (내 컴퓨터가 꺼져도 계속 실행!)
- 내 컴퓨터가 필요한 작업은 Remote Control로 내 기기에서 실행 가능

### 병렬 실행
- 여러 스레드가 **동시에** 실행
- 휴대폰에서도 진행 상황 확인·조종 가능

---

## Projects와 기존 세션의 차이

| | 일반 세션 | Projects |
|--|---------|---------|
| 작업 단위 | 대화 1개 | 대화 1개 + 여러 병렬 스레드 |
| 실행 위치 | 내 컴퓨터 or 클라우드 | 주로 클라우드 |
| 컴퓨터 꺼지면? | 로컬 세션 중단 | 클라우드 스레드는 계속 실행 |
| 감독 방법 | 대화창 하나 집중 | 스레드 목록에서 여러 개 동시 감독 |

---

## 어떤 상황에 쓰나요?

| 상황 | 활용 예시 |
|------|---------|
| 여러 파일을 동시에 리팩토링 | 각 모듈별로 스레드 생성 |
| 여러 기능을 병렬로 개발 | 로그인·결제·알림 각각 별도 스레드 |
| 테스트 케이스 대량 작성 | 각 함수별 스레드로 병렬 작성 |
| 코드 리뷰 멀티에이전트 | 보안/성능/가독성 스레드 동시 진행 |

## 사용 방법

### Projects 열기

**claude.ai/code** 사이드바에서 **Projects** 메뉴를 찾거나,  
Claude Code Desktop의 Code 탭 사이드바에서 **Projects** 항목을 클릭해요.

> 아직 안 보인다면 → **More** 메뉴 아래 있거나, 아직 내 계정에 출시 안 됨  
> 대기자 명단 등록: [claude.com/form/projects](https://claude.com/form/projects)

### 프로젝트 생성 흐름

1. **대화 시작**: 무엇을 해야 하는지 설명
2. **Claude가 스레드 생성**: 각 작업을 별도 스레드로 나눔
3. **병렬 실행 시작**: 클라우드에서 동시 실행
4. **감독 & 조종**: 스레드별 진행 상황 확인, 필요시 개입
5. **결과 취합**: 각 스레드 결과물 확인

## 내 컴퓨터에서 실행이 필요한 경우

```
> "이 스레드는 내 로컬 데이터베이스에 접근해야 해"
```

Remote Control(리모트 컨트롤)을 통해 특정 스레드를 내 기기에서 실행할 수 있어요.  
단, 내 컴퓨터가 켜져 있어야 계속 실행돼요.

## Dynamic Workflows와 뭐가 달라요?

| | Projects | Dynamic Workflows |
|--|---------|-----------------|
| 접근 방식 | 대화형 감독 (사람이 조종) | 자동 오케스트레이션 (Claude가 자동 실행) |
| 스레드 생성 | Claude가 제안, 사람이 승인 | Claude가 자율적으로 생성·관리 |
| 실행 기간 | 장기 프로젝트 | 단일 작업의 대규모 처리 |
| 적합한 상황 | 사람이 중간중간 방향을 잡아야 할 때 | 계획이 명확하고 완전 자동화할 때 |

---

> 📌 **정리**: Projects는 "Claude가 여러 작업을 동시에 처리하는 걸 내가 감독하는 기능"이에요.  
> 기존에는 한 번에 하나씩 대화했다면, 이제는 여러 작업을 동시에 나눠서 처리할 수 있어요.  
> 큰 기능을 여러 조각으로 쪼개서 병렬로 개발할 때 특히 유용해요! 🚀
