## Projects가 뭔가요?

**Projects(프로젝트)** 는 연관된 코딩 작업들을 한 묶음으로 관리하고, 여러 Claude 에이전트 세션을 **한 화면에서 동시에 지시·감독**하는 기능이에요.

> 🏗️ **비유**: 아파트 공사 현장의 소장 역할이에요. 소장(나)이 "1층 팀은 배선 작업, 2층 팀은 타일 작업, 3층 팀은 도색 작업" 하고 각 팀에 지시를 내리면, 각 팀(에이전트 세션)이 독립적으로 작업을 진행해요. 소장은 현장을 오가며 중요한 결정만 내려요.

기존에도 여러 대화창을 열 수 있었지만, Projects는 한 묶음(프로젝트)에 속한 세션들이 **저장소(repo), 지시사항(CLAUDE.md), 메모리를 공유**해요.

## Dynamic Workflows와 뭐가 달라요?

| 비교 항목 | Projects | Dynamic Workflows |
|---------|----------|-------------------|
| 시작 주체 | **내가** 각 세션에 작업 지시 | **Claude가** 계획·분배·실행 |
| 적합한 상황 | 연속적·장기 작업 흐름 | 일회성 대규모 병렬 작업 |
| 감독 방식 | 내가 각 세션 직접 확인 | 결과물만 검토 |
| 비유 | 소장이 팀 감독 | 물류 회사에 통째로 위탁 |

## 어떻게 사용하나요?

### 1. Project 만들기

Claude Code Desktop에서:
1. 왼쪽 사이드바 → **Projects** 탭 클릭
2. **새 Project 만들기** → 이름 입력 (예: "쇼핑몰 리뉴얼")
3. 연결할 GitHub 저장소 지정
4. CLAUDE.md(공통 지시사항) 등록 (선택)

### 2. Project 안에서 세션 시작

```
[Project: 쇼핑몰 리뉴얼]
 ├── 세션 1: 로그인 버그 수정 중...
 ├── 세션 2: 결제 모듈 테스트 작성 중...
 └── 세션 3: 모바일 반응형 개선 대기 중
```

각 세션은 독립적으로 돌아가면서도 같은 Project 설정을 공유해요.

### 3. 여러 세션 한 번에 감독

Agent View 화면에서 모든 세션의 진행 상황을 한눈에 볼 수 있어요. 어떤 세션이 "결정이 필요해요" 하고 멈춰 있으면 바로 개입할 수 있죠.

## 어떤 작업에 어울리나요?

| 이럴 때 Projects 쓰세요 ✅ | 이건 굳이 필요 없어요 ❌ |
|------------------------|-------------------|
| 쇼핑몰 리뉴얼처럼 여러 기능을 동시에 개발 | 버그 1개 수정 |
| 프론트엔드 팀 / 백엔드 팀 역할 분리 | 간단한 질문·답변 |
| 여러 날에 걸친 장기 마이그레이션 | 단일 파일 작업 |
| 각 세션이 서로 다른 GitHub 브랜치에서 작업 | |

## 현재 제한 사항 (공식 발표 기준)

- 🖥️ **Claude Code Desktop 전용** (터미널·웹 미지원)
- ☁️ **클라우드 세션**으로 실행 (로컬 환경 아님)
- 세션 간 직접 소통은 별도의 `cross-session-messaging` 기능 필요

> **추정**: Desktop App에서 Projects 탭이 보이지 않는다면 앱 업데이트를 먼저 확인하세요. (공식 발표 기준)

## 한국 사용자에게 한마디

Projects는 혼자 여러 역할을 동시에 맡을 때 특히 강력해요. 프리랜서나 1인 창업자라면 "기획자 세션", "개발자 세션", "QA 세션"을 동시에 돌리면서 한 프로젝트를 빠르게 완성할 수 있어요. 마치 혼자서 작은 팀을 꾸린 것처럼요. 🚀
