## Claude Projects가 뭔가요?

여러 Claude Code 세션을 **하나의 "프로젝트" 폴더**로 묶어서 관리하는 기능이에요.

> 📁 **비유**: 회사에서 "결제 시스템 개선" 프로젝트를 할 때, 관련된 모든 티켓·회의록·코드 작업을 한 폴더에 모아두는 것과 같아요. 클로드 세션들도 마찬가지로 "프로젝트" 단위로 묶어두면 훨씬 체계적으로 관리할 수 있어요.

---

## 왜 필요한가요?

Claude Code를 쓰다 보면 세션이 여러 개 생겨요:
- 버그 고치는 세션 1개
- 테스트 작성하는 세션 1개  
- 문서화하는 세션 1개
- 리팩토링하는 세션 1개

Projects 없이는 이 세션들이 사이드바에 뒤죽박죽 섞여서 헷갈려요.

**Projects 적용 후:**
```
📂 결제 시스템 v2 프로젝트
  ├── 🤖 세션: 더블 결제 버그 수정
  ├── 🤖 세션: 결제 모듈 테스트 작성
  ├── 🤖 세션: 체크아웃 UI 리팩토링
  └── 🤖 세션: API 문서 업데이트

📂 인증 시스템 프로젝트
  ├── 🤖 세션: JWT 갱신 로직 개선
  └── 🤖 세션: 소셜 로그인 추가
```

## 사용 방법 (Desktop 앱)

### 1단계: 새 프로젝트 만들기

1. Claude Code Desktop 사이드바에서 **"+ 새 프로젝트"** 클릭
2. 프로젝트 이름 입력 (예: "결제 시스템 v2")
3. 관련 작업 디렉토리 연결 (선택)

### 2단계: 세션을 프로젝트에 추가

```
방법 A: 새 세션 시작할 때 프로젝트 선택
방법 B: 기존 세션을 드래그해서 프로젝트 폴더로 이동
```

### 3단계: 프로젝트 뷰에서 감독

- 프로젝트 폴더 클릭 → 소속 세션 전체 한눈에 보기
- 각 세션 상태 확인 (실행 중 / 완료 / 대기 중)
- 필요한 세션으로 빠르게 전환

## 멀티 에이전트와 함께 쓰기

Projects는 **동시에 여러 에이전트를 돌릴 때** 특히 유용해요.

```
🏗️ "API v3 마이그레이션" 프로젝트
  ├── 에이전트 A: auth/ 폴더 마이그레이션 [진행 중 🔄]
  ├── 에이전트 B: payment/ 폴더 마이그레이션 [완료 ✅]
  ├── 에이전트 C: notifications/ 마이그레이션 [대기 ⏸]
  └── 에이전트 D: 통합 테스트 작성 [대기 ⏸]
```

> ⚡ **팁**: 에이전트 B가 완료되면, 에이전트 D의 "대기" 상태를 확인하고 "통합 테스트 시작"을 클릭하면 돼요.

## 자주 묻는 질문

**Q: 한 세션이 여러 프로젝트에 속할 수 있나요?**
현재 한 세션은 하나의 프로젝트에만 속할 수 있어요 (추정 — 공식 발표 기준).

**Q: 프로젝트를 삭제하면 세션도 삭제되나요?**
프로젝트 폴더만 삭제되고, 세션 대화 내역은 유지됩니다 (추정).

**Q: 터미널(CLI)에서도 쓸 수 있나요?**
현재는 Desktop 앱 전용 기능입니다. 터미널 지원은 추후 공식 발표 기다려주세요.
