## 새로 생긴 도구 두 가지

Claude Code W36~W37 업데이트에서 **품질 관리 도구** 두 가지가 새로 나왔어요.

| 도구 | 목적 |
|------|------|
| `claude plugin eval` | 내 플러그인이 제대로 동작하는지 자동 채점 |
| `/skill-doctor` | 등록된 스킬 중 안 쓰거나 컨텍스트만 차지하는 것 진단 |

---

## 1️⃣ `claude plugin eval` — 플러그인 자동 채점기

### 뭔가요?

내가 만든 **플러그인**이 실제 사용 케이스에서 얼마나 잘 동작하는지 자동으로 점수를 매겨줘요.

> 🧪 **비유**: 식당을 열기 전에 시식단을 초대해서 '이 요리가 맛있나요?'를 점수로 매겨달라고 하는 것과 같아요. `claude plugin eval`은 Claude가 시식단이 되어서 플러그인을 테스트해요.

### 어떻게 쓰나요?

**Step 1: 테스트 케이스 초안 만들기**

```bash
claude plugin eval init
```

Claude가 "어떤 결과가 좋은 결과인지" 물어보고, 테스트 케이스와 채점 기준을 제안해요.

**Step 2: 점수 측정**

```bash
claude plugin eval .
```

결과가 터미널에 표로 나와요:

```
케이스 | 플러그인 있을 때 | 없을 때 | 차이 | 비용
──────────────────────────────────────────────
테스트1 |     8.2        |   6.1   | +2.1 | $0.03
테스트2 |     9.0        |   7.5   | +1.5 | $0.02
...
평균 차이: +1.8   총 소요: 45초   총 비용: $0.21
```

**Step 3: 상세 보고서 확인**

```
evals/results/report.html
```

> ⚠️ **주의**: 각 테스트 케이스는 실제 API 호출을 하므로 **요금이 발생**해요. 상세 보고서에 총 비용이 나와요.

### 필요 버전

v2.1.269 이상, Claude Code CLI

## 2️⃣ `/skill-doctor` — 스킬 사용량 진단기

### 뭔가요?

내가 등록해둔 **스킬** 중 실제로 잘 안 쓰거나 컨텍스트 창을 많이 차지하는 것을 진단해줘요.

> 🏥 **비유**: 건강검진처럼, Claude가 매 대화마다 "가방"에 챙기는 스킬 목록을 점검해요. 여행을 안 가는데 텐트를 챙기면 짐만 무거워지듯이, 안 쓰는 스킬은 컨텍스트 창만 차지해요.

### 어떻게 쓰나요?

```text Claude Code
> /skill-doctor
```

**결과**: `/plugin` 매니저의 **Stats** 탭에 스킬별 분석이 나와요.

- 📊 각 스킬이 컨텍스트에서 차지하는 크기
- 📈 얼마나 자주 사용되는지
- 💡 꺼도 될 스킬 추천

### 왜 중요한가요?

**모든 스킬은 매 대화마다 컨텍스트 창을 차지**해요. 쓰지 않는 스킬이 많으면:

- 응답이 느려질 수 있어요
- API 비용이 조금씩 올라가요
- Claude가 관련 없는 정보로 혼란스러울 수 있어요

### 필요 버전

v2.1.252 이상, 인터랙티브 세션

## Desktop 앱: 패인 팝아웃 (W37)

W37에서 Desktop 앱에 **패인 팝아웃** 기능도 추가됐어요.

> 🖥️ diff 창, 터미널 등 패인을 **별도 창으로 꺼내서** 다른 모니터에 놓을 수 있어요. 드래그로 꺼내고, 다시 붙이면 원래 자리로 돌아와요.

듀얼 모니터 환경에서 Claude가 작업하는 동안 diff를 옆 화면에서 실시간으로 볼 수 있어요.
