## 이 기능이 뭔가요?

클로드가 아이폰 앱 코드를 수정하거나 테스트할 때, 옆 창에 아이폰 화면이 자동으로 뜨는 기능이에요.

> 📱 **비유로 설명하면**: 새 직원이 보고서를 완성하면 상사가 직접 인쇄해서 읽는 게 아니라, 자동으로 화면에 띄워놓고 직원이 직접 페이지를 넘기며 "이 내용 맞죠?" 하고 확인해주는 느낌이에요. 클로드가 앱을 고치면 그 결과를 클로드 스스로 탭하며 검토해요.

---

## 어떻게 작동하나요?

1. 클로드가 iOS 앱을 빌드하거나 시뮬레이터에서 실행하면 → **시뮬레이터 창이 자동으로 열려요**
2. 클로드가 화면을 보면서 앱을 탭하고, 버그를 찾고, 수정하는 것까지 혼자 해요
3. 나도 그 화면을 보면서 같이 확인할 수 있어요

> **CLI에서는 다른 방식**: 터미널(CLI)에서 쓰는 클로드는 이 전용 창 대신 computer use(컴퓨터 사용)로 시뮬레이터를 제어해요. Desktop 앱만 이 전용 창을 지원해요.

---

## 쓰려면 뭐가 필요해요?

| 조건 | 내용 |
|---|---|
| **플랜** | Pro, Max, Team (⚠️ Enterprise 미지원) |
| **운영체제** | **macOS만 가능** (아이폰 시뮬레이터는 맥에서만 돌아가요) |
| **앱 설치** | **Xcode** + iOS 플랫폼 설치 필요 |
| **Claude Desktop 버전** | **v1.24012.0 이상** (Claude → 업데이트 확인) |
| **세션 종류** | **로컬 세션만** 지원 (클라우드·SSH 세션 불가) |

> ⚠️ 클라우드 세션에서는 이 기능이 안 돼요. 클로드가 돌아가는 원격 서버가 내 맥에 있는 시뮬레이터에 접근할 수 없기 때문이에요.

## 실제로 사용하는 방법

### 1단계: iOS 프로젝트 열기

Claude Code Desktop의 **Code 탭**에서 앱 프로젝트 폴더를 프로젝트 폴더로 설정해요.

### 2단계: 클로드에게 실행 요청하기

```text
시뮬레이터에서 앱을 빌드하고 실행해서 온보딩 화면이 잘 나오는지 확인해줘
```

### 3단계: 시뮬레이터 창 확인

앱이 시뮬레이터에서 뜨면 **iOS 시뮬레이터 창이 옆에 자동으로 열려요**. 처음엔 "이 기기를 사용해도 되냐"고 한 번 물어봐요. 허용하면 이후엔 안 물어봐요.

---

## 직접 찾아서 열 수도 있어요

자동으로 안 열리면 세션 도구 모음의 **Views** 메뉴 → **iOS Simulator**를 선택하거나, **Attach simulator** 버튼을 눌러요. Xcode가 없거나 시뮬레이터가 설치 안 됐으면 설정 안내가 나와요.

---

## 내가 직접 탭할 수도 있어요

시뮬레이터 창에서 나도 직접 조작할 수 있어요:

| 할 수 있는 것 | 방법 |
|---|---|
| 탭하기 · 스와이프 | 화면을 클릭 · 드래그 |
| 홈 버튼 | Cmd+Shift+H |
| 잠금 | Cmd+L |
| 볼륨 조절 | Cmd+위/아래 화살표 |
| 기기 회전 (90도) | Cmd+오른쪽 화살표 |
| 스크린샷 저장 | Cmd+S (바탕화면에 저장) |
| 화면 녹화 | Cmd+R |

> 💡 **팁**: 클로드가 조작 중일 때는 화면 위에 **"Claude is using this device"** 표시가 떠요. 이 표시가 사라질 때까지 기다렸다가 내가 탭하면 서로 엉키지 않아요.

---

## 여러 세션 동시에 쓸 때

- 각 세션마다 **별도의 시뮬레이터**가 배정돼요 (세션끼리 간섭 없음)
- 사이드바에서 세션을 전환하면 그 세션의 시뮬레이터 화면으로 바뀌어요
- 세션 하나에서 최대 **4개** 시뮬레이터 창 동시 사용 가능
- Desktop 앱을 종료하거나 세션을 아카이브하면 클로드가 부팅한 시뮬레이터는 자동으로 꺼져요 (내가 직접 부팅한 건 유지)

---

## 권한 설정

처음 기기에 클로드가 접근할 때 허용을 묻고, 이후엔 묻지 않아요. 단, 아래 두 가지는 **항상 권한 모드에 따라 물어봐요**:

- 기기에서 URL 열기 (딥링크 테스트 등)
- 앱 빌드 (`xcodebuild` 실행)

> 🔒 **기업 사용자**: `disableMobileSimulatorTools` 설정으로 조직 전체에서 클로드의 시뮬레이터 조작 권한을 끌 수 있어요.

## 문제 해결 Q&A

**Q. 앱을 빌드했는데 시뮬레이터 창이 안 열려요**
→ "시뮬레이터에서 실행해서 화면 확인해줘"처럼 **명확하게** 요청해보세요. Xcode와 iOS 시뮬레이터가 설치됐는지도 확인하세요.

**Q. "시뮬레이터를 찾을 수 없다"고 나와요**
→ Xcode → 설정에서 iOS 시뮬레이터 런타임을 다운받거나, 터미널에서 아래 명령어를 실행하세요:
```bash
xcodebuild -downloadPlatform iOS
```

**Q. 특정 아이폰 기종에서 테스트하고 싶어요**
→ 요청할 때 기종 이름을 명시하면 돼요:
```text
iPhone SE 시뮬레이터에서 실행해줘
```
