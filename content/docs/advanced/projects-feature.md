## Projects가 뭔가요?

**Projects(프로젝트)**는 관련 있는 코딩 세션들을 하나의 그룹으로 묶어서, **여러 Claude 에이전트를 동시에 실행하고 감독**할 수 있게 해주는 기능이에요.

> 🍱 **비유로 설명하면**: 지금까지는 Claude Code 채팅 창이 하나씩 따로 열렸다면, 이제는 **팀장 자리**에서 여러 팀원(에이전트)들이 각자 다른 일을 하는 걸 한 화면에서 지켜보고 지시할 수 있어요.

---

## 어디서 쓸 수 있나요?

**Claude Code Desktop** 앱에서 사용 가능합니다.

| 환경 | 지원 여부 |
|---|---|
| Claude Code Desktop (Mac/Win) | ✅ 지원 |
| 터미널 CLI | ⏳ 추후 지원 예정 (추정) |
| 웹 (claude.ai/code) | ⏳ 추후 지원 예정 (추정) |

## 핵심 기능

### 1. 📁 관련 세션 그룹화

여러 개의 Claude Code 세션을 하나의 프로젝트 아래 묶을 수 있어요.

> **예시**: "결제 시스템 리팩터링" 프로젝트에:
> - 세션 A: 백엔드 결제 로직 수정
> - 세션 B: 프론트엔드 체크아웃 폼 수정
> - 세션 C: 결제 관련 테스트 작성

### 2. 👀 여러 에이전트 동시 감독

각 세션(에이전트)이 어떤 작업을 하고 있는지, 무엇을 결정해야 하는지 한 화면에서 확인할 수 있어요.

> 🍱 **비유**: CCTV 여러 대를 한 모니터로 모아 보는 느낌이에요. 에이전트 1이 파일 수정 중, 에이전트 2가 테스트 실행 중, 에이전트 3이 내 승인을 기다리는 상태를 한눈에 볼 수 있어요.

### 3. ⚡ 병렬 작업으로 시간 절약

혼자 코딩할 때 순서대로 하던 작업들을 이제 동시에 진행할 수 있어요.

| 이전 방식 | Projects 활용 방식 |
|---|---|
| 버그 수정 → 테스트 → PR 작성 (순서대로) | 버그 수정 + 테스트 + 문서 작성 (동시에) |
| 1개 세션, 1개 작업 | 여러 세션, 여러 작업 병렬 진행 |

## 실전 사용 예시

### 예시 1: 대규모 기능 추가

```
프로젝트: "사용자 인증 시스템 추가"
├── 세션 1: JWT 토큰 처리 로직 작성
├── 세션 2: 로그인/회원가입 UI 컴포넌트 작성
├── 세션 3: 인증 미들웨어 테스트 작성
└── 세션 4: API 문서 업데이트
```

### 예시 2: 코드 마이그레이션

```
프로젝트: "Python 2 → Python 3 마이그레이션"
├── 세션 1: 핵심 비즈니스 로직 변환
├── 세션 2: 테스트 코드 변환
└── 세션 3: 의존성 패키지 업데이트
```

## Agent View와의 관계

Projects는 [Agent View](/advanced/agent-view) 기능과 함께 사용하면 더욱 강력해요.

- **Agent View**: 모든 Claude Code 세션을 한 화면에서 개요 보기
- **Projects**: 관련 세션을 그룹으로 묶어서 함께 관리

> 🍱 **비유**: Agent View가 "전체 현황 대시보드"라면, Projects는 "팀별로 구분된 업무 보드"예요.

## 주의사항

⚠️ **공식 상세 사양은 추정 포함** — 이 문서는 마케팅 페이지 발표 내용을 기반으로 작성됐어요. 세부 사용법은 [공식 문서](https://code.claude.com/docs/en/claude-projects)를 확인해 주세요.

- 각 세션은 독립적으로 실행되며 서로 다른 컨텍스트를 가져요
