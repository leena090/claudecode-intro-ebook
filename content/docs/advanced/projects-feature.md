## Projects가 뭔가요?

**Projects**는 **관련된 여러 Claude Code 세션을 하나의 그룹으로 묶어 한 화면에서 관리하는 기능**이에요.

> 🗂️ **비유로 설명하면**: 책상 위에 여러 서류 더미가 쌓여 있다면 찾기 어렵죠? 프로젝트 파일 케이스에 "쇼핑몰 개발", "고객 관리 시스템" 처럼 탭을 나누면 한눈에 정리되는 것과 같아요.

---

## 이전과 무엇이 달라졌나요?

| 이전 방식 | Projects 이후 |
|-----------|---------------|
| 세션들이 시간 순서로 쌓임 | 관련 세션을 그룹으로 묶어 관리 |
| 어느 에이전트가 뭘 하는지 따로 확인 | 한 화면에서 모든 에이전트 상태 파악 |
| 여러 작업 동시 진행 시 혼잡 | 프로젝트별로 분리해서 감독 |

---

## 어떻게 쓰나요?

### 1단계: 데스크톱 앱 열기

**Claude Code Desktop** 앱을 여세요 (터미널 버전에서는 지원 안 해요).

### 2단계: 프로젝트 만들기

새 프로젝트를 만들고 이름을 붙여요.
- 예: "쇼핑몰 결제 모듈 개발"
- 예: "회사 CRM 리팩토링"

### 3단계: 세션을 프로젝트에 연결

기존 세션이나 새 세션을 프로젝트에 연결할 수 있어요.

### 4단계: 여러 에이전트 동시 실행·감독

프로젝트 안에서 여러 Claude 에이전트가 **동시에** 다른 작업을 하도록 시작하고, 한 화면에서 진행 상황을 모두 볼 수 있어요.

---

## 어떨 때 쓰면 좋아요?

| 상황 | Projects 활용법 |
|------|----------------|
| 큰 기능 개발 (API + 프론트 + 테스트) | 세 에이전트가 각자 맡은 부분을 동시 진행 |
| 코드 마이그레이션 | 파일 그룹별로 에이전트 배정 후 한 화면 감독 |
| 버그 헌팅 | 여러 모듈을 동시 분석 |
| 주간 작업 관리 | 날짜·기능별로 세션 그룹화 |

---

## Agent view와의 차이

- **Agent view**: 현재 실행 중인 **모든** Claude Code 세션을 한 화면에서 보는 전체 대시보드
- **Projects**: 관련 세션들을 **테마별로 묶어** 정리하는 폴더 개념

> 💡 두 기능은 함께 써요 — Projects로 그룹을 만들고, Agent view에서 전체 상태를 한눈에 파악하는 방식이에요.
