## 음성 입력 & Fast 모드란?

**음성 입력**은 마이크로 말하기만 하면 AI가 이해하고 작업하는 기능입니다. **Fast 모드**는 같은 AI 모델을 그대로 유지하면서 응답 출력이 더 빠르게 이루어지도록 하는 모드입니다.

---

## 음성 입력 사용법

### 음성 입력 활성화

```bash
/voice
```

또는

```bash
claude --voice
```

**결과:**
```
🎤 음성 모드 활성화됨
스페이스바를 누르는 동안 말하세요 (push-to-talk)

> [스페이스바 누르고 유지] "파일 만들어줄래?" [스페이스바 뗌]
```

**Push-to-talk 방식:**
- 스페이스바를 **누르고 있는 동안**만 녹음됩니다
- 스페이스바를 **떼면** 녹음이 끝나고 AI가 처리합니다
- 배경 소음이 있는 환경에서도 정확하게 인식됩니다


## Fast 모드 사용법

### Fast 모드 활성화

```bash
/fast
```

또는

```bash
claude --fast
```

---

### Fast 모드 vs 일반 모드

> **중요:** `/fast`는 모델을 바꾸지 않습니다. 동일한 AI 모델을 사용하되, 응답을 더 빠르게 출력하도록 스트리밍 방식을 조정합니다.

| 항목 | 일반 모드 | Fast 모드 |
|------|---------|---------|
| 응답 속도 | 보통 | ⚡ 더 빠른 출력 |
| 사용 모델 | 동일 | 동일 (변경 없음) |
| AI 품질 | 기본 | 동일 |
| 비용 | 기준 | 동일 |
| 용도 | 일반 작업 | 빠른 응답이 필요할 때 |

## 실전 사용 예시

### 예시 1: 음성 + Fast 모드 조합

```
1️⃣ 음성 활성화
당신: /voice

2️⃣ Fast 모드 활성화
당신: /fast

3️⃣ 음성으로 지시
당신 (말로): "이 파일 요약해줄래?"

AI (빠르게 응답):
> 파일 요약: 사용자 관리 모듈입니다...
> (3초 만에 응답 완료)
```

---

### 예시 2: 회의 중 음성 사용

```
상황: 팀 회의 중
당신 (말로): "이 코드 리뷰해줄래?"

AI (마이크로 듣고):
> 코드 리뷰 완료
> 2가지 개선사항:
> 1. 변수명을 더 명확하게
> 2. 주석 추가 필요
```

---

### 예시 3: 운전 중 지시

```
상황: 자동차 운전 중

당신 (말로): "우리 프로젝트의 진행상황 알려줄래?"

AI:
> 프로젝트 진행율: 65%
> 남은 작업: 35개 중 12개
> 예상 완료: 3주
```

### 언어 설정 — 20개 언어 지원 (v2.1.69~ 2배 확장)

```json
{
  "voice": {
    "language": "ko-KR",
    "audioInput": "microphone"
```

```
✅ 간단한 파일 생성
✅ 코드 설명
✅ 빠른 검색
✅ 간단한 수정
✅ 요약
```

---

### Fast 모드 부적합한 작업

```
❌ 복잡한 알고리즘 구현
❌ 깊이 있는 분석
❌ 생각이 많이 필요한 작업
❌ 코드 아키텍처 설계
```

## 응답 품질 조절

### /effort 명령어

```bash
/effort low
```

→ 빠르지만 품질은 70% 수준

```bash
/effort medium
```

→ 균형잡힌 속도와 품질

```bash
/effort high
```

→ 최고 품질 (시간 더 걸림)

## 💡 쉽게 이해하기

음성 + Fast는 **택배 배송 옵션**과 같습니다.

**일반 배송:**
- 7~10일 걸림
- 정확하고 꼼꼼함
- 높은 비용

**특급 배송:**
- 하루 만에 도착
- 빠르지만 기본 서비스는 동일
- 약간 더 저렴

마찬가지로:
- **일반 모드:** 응답이 천천히 흘러나옴 (스트리밍 기본 속도)
- **Fast 모드:** 같은 모델, 같은 품질 — 단지 출력이 더 빨리 나옴
