## 딥링크(Deep Link)가 뭐예요?

**"링크를 클릭하면 특정 앱의 특정 화면이 바로 열리는 기능"**이에요.

> 🏠 **비유로 설명하면**: 카카오톡 채팅방에서 배달 링크를 클릭하면 배달앱이 열리면서 해당 음식점 페이지가 바로 뜨죠? 딥링크도 똑같아요. `claude-cli://` 주소를 클릭하면 Claude Code 터미널이 열리면서, **미리 지정해둔 프로젝트 폴더와 프롬프트(질문)까지 자동으로 입력**됩니다.

---

## 어떤 상황에서 유용해요?

| 상황 | 딥링크 없이 | 딥링크 있으면 |
|------|-----------|------------|
| 새벽 서버 장애 대응 매뉴얼 | "터미널 열고 → 폴더 이동 → Claude 실행 → 프롬프트 입력" 4단계 | **링크 클릭 → 즉시 Claude Code가 그 폴더에서 열림** |
| 팀 신입이 처음 온보딩할 때 | 설정 문서 보며 직접 입력 | **Notion 문서의 링크 클릭 → 환경 자동 설정** |
| 모니터링 대시보드에서 이상 감지 | 수동으로 해당 서비스 폴더 찾아가야 함 | **대시보드 경고 옆 링크 클릭 → 바로 해당 서비스 Claude 세션** |

---

## 딥링크 형식

```
claude-cli://open?repo=<저장소 경로>&prompt=<프롬프트>
```

예시:
```
claude-cli://open?repo=/Users/kim/myproject&prompt=오늘+할일을+정리해줘
```

이 링크를 클릭하면:
1. Claude Code 터미널이 자동으로 실행됩니다
2. `/Users/kim/myproject` 폴더로 바로 이동합니다
3. `오늘 할일을 정리해줘` 프롬프트가 자동 입력됩니다

---

## 어디에 심을 수 있어요?

📋 **운영 매뉴얼 (Runbook)**  
장애 대응 절차서에 "이 링크 클릭 → 바로 점검 시작" 형태로 삽입

🚨 **모니터링 알림 (Alert)**  
Slack·PagerDuty 경고 메시지에 "Claude로 분석하기" 버튼으로 삽입

📊 **대시보드 (Dashboard)**  
Grafana·Datadog 패널 옆에 "Claude에게 물어보기" 링크로 삽입

📄 **팀 위키·Notion**  
프로젝트 소개 페이지에 "개발환경 자동 설정" 링크로 삽입

---

## 실제 사용 예시

### 예시 1: Slack 장애 알림에 연결

```
🚨 결제 서비스 응답 지연 감지
▶ [Claude로 즉시 점검하기](claude-cli://open?repo=/srv/payment&prompt=결제+서비스+로그에서+에러+찾아줘)
```

팀원이 링크를 클릭하면 → 결제 서비스 폴더에서 Claude Code가 바로 열립니다.

### 예시 2: 온보딩 문서

```markdown
## 3단계: 개발 환경 설정
아래 링크를 클릭하면 Claude가 자동으로 환경을 점검해줍니다.
[환경 설정 자동 점검 시작](claude-cli://open?repo=.&prompt=CLAUDE.md를+읽고+신입+개발자+온보딩+시작해줘)
```

---

## 주의사항

- 링크를 클릭하면 **Claude Code가 설치된 로컬 PC에서 실행**됩니다 (클라우드가 아님)
- `repo` 경로는 **클릭하는 본인 컴퓨터의 경로**여야 합니다 — 팀 전체 공유 링크라면 각자 본인 경로로 조정 필요
- 프롬프트에 공백이 있으면 `+` 또는 `%20`으로 대체하세요

---

> 💡 **입문자 팁**: 딥링크는 "숙련된 개발자를 위한 자동화 도구"처럼 보이지만, 사실 **팀 신입이 복잡한 설정 없이 바로 시작하게 해주는 온보딩 도구**로도 딱 맞아요. 팀 위키나 회사 노션에 프로젝트별 딥링크를 하나씩 만들어두면, 누구든 클릭 한 번으로 Claude Code를 그 프로젝트에 연결해 시작할 수 있습니다.
