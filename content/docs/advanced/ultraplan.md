## `/ultraplan`이 뭔가요?

복잡한 계획을 세울 때 **로컬 터미널에서 플랜을 클라우드로 보내**, 브라우저의 Claude Code Web에서 **Opus 4.7이 더 깊이 있게 다듬도록** 한 뒤, 완성된 플랜을 **다시 내 로컬 터미널로 가져오는** 기능입니다.

> 🍱 **비유로 설명하면**: 동네 카페에서 레시피를 고민하다가 "이건 호텔 총주방장한테 물어봐야겠다" 싶을 때가 있죠? 카페는 그대로 열어두고(로컬 세션 유지), 레시피만 호텔로 전송해서(클라우드 전송) 총주방장이 다듬어준 걸(인터랙티브 다듬기) 다시 받아 실행하는 거예요(로컬로 가져오기).

---

## 언제 쓰면 좋아요?

### ✅ 이럴 때 유용해요
- **정말 복잡한** 대형 작업 계획을 세울 때 (예: 레거시 시스템 마이그레이션)
- 로컬 모델은 부담스럽고, **Opus 4.7의 깊은 사고**가 필요할 때
- **브라우저에서 플랜을 시각적으로 검토·수정**하고 싶을 때
- 최대 **30분 사고 시간**이 필요한 플래닝 작업

### ❌ 이럴 때는 그냥 `/plan` 쓰세요
- 간단한 기능 추가 (5분이면 끝날 것)
- 내 머릿속에 이미 계획이 있고, Claude는 실행만 하면 될 때
- 네트워크가 불안정할 때 (클라우드 왕복이 필요해요)

## 전체 흐름 — 4단계

### 1단계: 로컬 CLI에서 시작

```bash
# Mac 터미널 / Windows PowerShell
/ultraplan
> 우리 쇼핑몰에 결제 시스템 통합하려고 해. 
> Stripe, 토스페이먼츠, 카카오페이 3개 다 지원하면서 
> 기존 주문 시스템과 자연스럽게 연결되게 계획 세워줘
```

### 2단계: 플랜이 클라우드로 전송돼요

화면에:
```
🚀 플랜을 Claude Code Web으로 전송하고 있어요...
🔗 브라우저에서 확인: https://claude.ai/code/plans/abc123
```

브라우저 링크가 자동으로 열려요 (또는 클릭해서 접속).

### 3단계: 브라우저에서 인터랙티브 검토

Claude Code Web이 플랜 모드로 열리고, 여기서 Opus 4.7이:
- 📝 상세 단계별 플랜 작성
- 🤔 **최대 30분까지 사고**하며 검토
- 🔄 내가 브라우저에서 추가 지시 내리면 **실시간 반영**
- ✅ 최종 플랜 확정

> 🍱 **비유로 설명하면**: 건축 설계사와 카페에서 도면 보며 "이 벽은 여기로 옮기면 어때요?" 하는 느낌이에요.

### 4단계: 실행 위치 선택

브라우저에서 "이 플랜으로 작업 시작" 버튼을 누를 때, 2가지 선택지가 나와요:

| 옵션 | 언제 쓰나요? |
|---|---|
| **☁️ 클라우드에서 실행** | 내 컴퓨터 리소스를 쓰고 싶지 않을 때, 긴 작업을 백그라운드로 돌리고 싶을 때 |
| **💻 로컬로 가져와서 실행** (teleport) | 내 로컬 환경·파일·도구가 필요할 때 |

**로컬 가져오기** 선택 시 → 터미널로 플랜이 자동으로 돌아와서 `/plan`처럼 바로 실행 가능.

## 실전 예시

### 예시 1: 레거시 리팩토링 계획

```bash
/ultraplan
> @src/** 우리 백엔드가 5년 된 레거시야. 
> 모던 스택(FastAPI + PostgreSQL)으로 점진적 마이그레이션 전략 세워줘. 
> 서비스 중단은 최소화해야 해.
```

→ 클라우드에서 Opus 4.7이 전체 코드 맥락을 **1M 컨텍스트**로 읽고 단계별 마이그레이션 플랜 작성.

### 예시 2: 신기능 통합 계획

```bash
/ultraplan
> 결제 시스템에 환불 기능 추가하려고 해. 
> 기존 주문/배송/회계 시스템에 미치는 영향 전부 분석하고 
> 롤백 가능한 배포 계획까지 세워줘.
```

→ 브라우저에서 단계별로 검토하면서 "환불 알림 이메일도 추가해줘" 같은 추가 요청을 실시간 반영.

## ⚠️ 주의사항

### 1. Research Preview라 불안정할 수 있어요
- 가끔 클라우드 전송이 실패할 수 있어요 → 재시도
- 브라우저 UI가 갑자기 바뀔 수 있어요 (실험 단계)

### 2. 네트워크 안정성 필요
- 로컬 ↔ 클라우드 왕복이 일어나요
- 불안정한 Wi-Fi에서는 피하세요

### 3. 민감한 코드는 주의
- 플랜 내용과 맥락이 **클라우드로 전송**돼요
- 회사 보안 정책에 따라 사전 확인 필요

### 4. 비용
- 클라우드에서 Opus 4.7이 최대 30분 사고 → 토큰 비용 많이 나올 수 있어요
- 간단한 플랜은 그냥 `/plan` 쓰세요

## `/plan` vs `/ultraplan` 비교

| 비교 | `/plan` | `/ultraplan` |
|---|---|---|
| **실행 위치** | 로컬 | **클라우드 → 로컬** |
| **사고 시간** | 짧음 (수초~수분) | **최대 30분** |
| **컨텍스트** | 현재 세션 | **1M 컨텍스트 풀 활용** |
| **브라우저 UI** | 없음 | **인터랙티브 검토 가능** |
| **비용** | 저렴 | 비쌈 |
| **언제?** | 일반 플래닝 | **정말 복잡한 대형 작업** |
