## 스마트폰으로도 Claude Code를?

네, 됩니다! 🤳

Claude 모바일 앱을 통해 **집 밖에서도, 이동 중에도** Claude Code 작업을 다룰 수 있어요.

> 🍱 **비유로 설명하면**: 공장(데스크톱)에서 로봇(클로드)이 작업하는 동안 사장님(나)이 외출 중에도 **스마트폰으로 CCTV 보면서 지시 내리는** 것과 같아요.

---

## 스마트폰에서 할 수 있는 것들

| 기능 | 설명 |
|---|---|
| **작업 시작** | 폰에서 새 코딩 작업 요청 |
| **진행 상황 모니터링** | 클로드가 뭘 하고 있는지 실시간 확인 |
| **지시 보내기** | 진행 중인 작업에 새로운 지시 추가 |
| **푸시 알림** | 클로드가 결정이 필요할 때 알림 수신 |
| **PR 검토** | 완성된 코드 검토 및 승인 |

---

## 두 가지 모바일 활용 방식

### 방식 1: Remote Control — 내 PC 세션 이어가기

집 PC에서 시작한 Claude Code 세션을 **스마트폰으로 이어서** 작업할 수 있어요.

```
[집 PC] Claude Code 실행 중 → [스마트폰] 같은 세션 접속 → 대화 이어가기
```

> 🍱 **비유로 설명하면**: 집에서 요리하다가 마트에서 재료 부족한 걸 알았을 때, **전화로 "냉장고에 당근 있어?"라고 확인**하는 것처럼 세션을 이어가는 거예요.

**사용 방법:**
1. 모바일 Claude 앱에서 로그인
2. "Claude Code" 섹션 → 활성 세션 목록
3. 이어가고 싶은 세션 선택 → 바로 채팅 가능

### 방식 2: Dispatch — 폰에서 작업 지시 → PC에서 실행

스마트폰에서 **새 작업을 시작**하면 로컬 PC에서 클로드가 자동으로 실행해요.

```
[스마트폰] "버그 수정해줘" 입력 → [집 PC] 클로드가 코드 자동 수정 → [스마트폰] 결과 확인
```

> 🍱 **비유로 설명하면**: 회사 밖에서 부하직원(클로드)에게 **카카오톡으로 업무 지시**를 보내면 사무실에서 알아서 처리해두는 것과 같아요.

## 푸시 알림 — 클로드가 결정이 필요할 때

Claude Code는 중요한 상황이 되면 **스마트폰으로 알림을 보내줘요**.

알림이 오는 경우:
- 🔔 파일 수정 허가가 필요할 때
- 🔔 명령어 실행 전 확인이 필요할 때  
- 🔔 작업이 완료됐을 때
- 🔔 오류가 발생해서 사람의 판단이 필요할 때

**알림 설정하기:**
```
Claude 앱 → 설정 → 알림 → Claude Code 알림 켜기
```

<div class="note-star">
★ 알림을 켜두면 외출 중에도 클로드가 막히지 않고 작업을 계속 진행할 수 있어요. Auto mode와 함께 쓰면 특히 강력합니다.
</div>

## PR 검토도 폰에서

클로드가 만들어준 Pull Request를 **스마트폰으로 검토**할 수 있어요.

1. 알림 수신: "PR #42 생성됨"
2. 앱에서 코드 변경사항 확인
3. "승인" 또는 "수정 요청" 탭

> 🍱 **비유로 설명하면**: 부하직원이 작성한 보고서를 **카카오톡으로 받아서 검토하고 결재 도장 찍는** 것과 같아요.

## 자주 묻는 질문

**Q. 모바일로 복잡한 코딩 작업이 가능한가요?**  
A. 입력과 확인은 폰에서, 실제 코드 실행은 PC에서 해요. 복잡한 타이핑이 필요한 작업은 PC가 더 편리하지만, 짧은 지시와 모니터링은 폰으로 충분합니다.

**Q. PC가 꺼져 있으면 어떻게 되나요?**  
A. Remote Control은 PC가 켜져 있어야 해요. Dispatch도 마찬가지예요. 다만 Claude Code on the Web을 쓰면 PC 없이도 클라우드에서 실행할 수 있어요.

**Q. 데이터 요금이 걱정돼요.**  
A. 텍스트 기반이라 데이터 소비가 적어요. 코드 파일 내용을 많이 확인하면 조금 더 쓸 수 있어요.
