## Agent View가 뭔가요?

여러 개의 Claude Code 작업을 **한 화면에서 한꺼번에 보고 관리하는 대시보드**예요.

> 🍱 **비유로 설명하면**: 회사의 팀장이 각 팀원한테 일을 시켜놓고, 게시판 하나에서 "A팀원: 진행 중", "B팀원: 입력 필요", "C팀원: 완료"를 한눈에 보는 것과 같아요. 직접 일일이 찾아다니지 않아도 되죠.

---

## 어떻게 시작하나요?

터미널에서 단 한 줄:

```bash
claude agents
```

이러면 모든 백그라운드 세션이 표 형태로 보입니다:

```
📌 고정된 항목
  ✽ 홈페이지 리디자인     파일 수정 중...                  3분 전

⚠️ 입력 필요
  ✻ 결제 시스템 오류     질문: 어떤 방식으로 처리할까요?    1분 전

🔄 작업 중
  ✽ API 문서 작성        Draft 생성 중...                  2분 전

✅ 완료
  ✻ 테스트 작성          결과: 테스트 12개 생성 완료        9분 전
```

## 기본 사용법

### 작업 시키기 (Dispatch)

Agent View 화면 아래 입력창에 지시문 입력 → `Enter`:

```
버그 리포트 #234 확인하고 수정해줘
```

새 백그라운드 세션이 생성되어 바로 작업 시작!

### 결과 훑어보기 (Peek)

목록에서 줄을 선택하고 `스페이스`를 누르면 **미리보기 창**이 열려요. 지금 뭘 하고 있는지, 뭘 물어보는지 확인 가능합니다. 대부분의 경우 이 창에서 답변도 바로 보낼 수 있어요.

### 답변 보내기

미리보기 창에서 직접 타이핑 후 `Enter` → 해당 세션에 답변이 전송됩니다.

### 세션 붙기 (Attach)

더 자세히 보고 싶으면 `Enter` 또는 `→` 키로 해당 세션에 완전히 접속할 수 있어요.

**빠져나오기**: 빈 입력창에서 `←` 키 → Agent View 화면으로 돌아옴.

## 상태 아이콘 해석

| 아이콘 | 상태 | 의미 |
|--------|------|------|
| ✽ (움직임) | 작업 중 | 클로드가 열심히 일하는 중 |
| 노란색 | 입력 필요 | 내 답변을 기다리고 있어요 |
| 흐릿함 | 대기 중 | 특별히 기다리는 건 아닌 유휴 상태 |
| 초록색 | 완료 | 성공적으로 끝났어요 |
| 빨간색 | 실패 | 오류가 발생했어요 |
| 회색 | 중단됨 | 직접 중단한 세션 |
| ∙ | 프로세스 종료 | 재접속하면 자동으로 재시작돼요 |

## 백그라운드 세션 시작하기

### 방법 1: Agent View에서 직접

Agent View 열고 → 입력창에 지시문 → `Enter`

### 방법 2: 현재 세션을 백그라운드로 보내기

대화 중인 세션에서:

```
/bg 테스트 전체 돌리고 실패하는 거 고쳐줘
```

또는 `/background`라고 써도 돼요.

### 방법 3: 터미널에서 바로

```bash
claude --bg "로그인 버그 조사해줘"
```

이러면 바로 백그라운드에서 시작되고, 짧은 세션 ID를 알려줍니다.

---

## 파일 충돌 걱정 없어요

여러 세션이 동시에 작업할 때, **각 세션은 자동으로 별도 워크트리**(작업 공간)에서 작업해요. 서로의 파일을 건드리지 않습니다. `[공]`

> 🍱 **비유**: 같은 문서를 여러 명이 동시에 편집할 때 "충돌 방지 모드"로 각자 별도 복사본에서 작업하는 것과 같아요.

## 키보드 단축키 정리

| 단축키 | 기능 |
|--------|------|
| `↑` / `↓` | 세션 목록 이동 |
| `스페이스` | 미리보기 열기/닫기 |
| `Enter` 또는 `→` | 세션에 완전히 접속 |
| `←` (빈 입력창) | 세션에서 나와 Agent View로 |
| `Ctrl+T` | 세션 상단 고정 |
| `Ctrl+R` | 세션 이름 바꾸기 |
| `Ctrl+X` | 세션 중단 (한 번 더 누르면 삭제) |
| `Esc` | 미리보기 닫기 / 화면 나가기 |
| `?` | 전체 단축키 목록 보기 |

## 터미널에서 세션 관리

Agent View 화면 없이도 터미널 명령어로 관리할 수 있어요:

```bash
claude agents              # Agent View 열기
claude attach <세션ID>     # 특정 세션에 접속
claude logs <세션ID>       # 최근 출력 보기
claude stop <세션ID>       # 세션 중단
claude respawn --all       # 중단된 세션 전부 재시작
```

## 주의사항

<div class="note-circle">
○ <strong>요금 관련</strong>: 백그라운드 세션도 일반 세션과 똑같이 토큰을 소비해요. 10개를 동시에 돌리면 1개 대비 약 10배 소비됩니다.<br /><br />
○ <strong>컴퓨터가 잠자기 모드</strong>에 들어가면 백그라운드 세션도 멈춰요. 재시작하려면 <code>claude respawn --all</code>을 입력하세요.<br /><br />
○ <strong>리서치 프리뷰</strong>: 인터페이스와 단축키가 앞으로 바뀔 수 있어요.
</div>
