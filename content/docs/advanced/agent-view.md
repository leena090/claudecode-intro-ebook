## 에이전트 뷰가 뭔가요?

> 🍱 **비유로 설명하면**: 콜센터 관리자처럼, 여러 상담원(AI 세션)이 각각 다른 일을 처리하는 걸 **한 화면**에서 보고, 막힌 상담원한테만 가서 도와주는 거예요.

예전에는 Claude Code 작업을 하나씩 순서대로 했다면, **에이전트 뷰**를 쓰면 여러 작업을 동시에 뿌려놓고 진행 상황을 한 번에 볼 수 있어요.

```bash
# 에이전트 뷰 열기
claude agents
```

---

## 왜 필요한가요?

이런 상황에 딱 맞아요:

- 🐛 "버그 수정 + 기능 추가 + PR 리뷰" 동시에 시키고 싶을 때
- 🧪 여러 파일을 AI 여러 명한테 동시에 맡길 때
- 📱 내가 자리를 비워도 Claude가 계속 일하게 하고 싶을 때
- 🔍 무슨 작업이 지금 어느 단계인지 한눈에 보고 싶을 때

---

## 기본 사용 흐름

### 1단계: 에이전트 뷰 열기

```bash
claude agents
```

화면 아래쪽에 입력창이 생기고, 위에 세션 목록 표가 채워지기 시작해요.

### 2단계: 작업 파견

입력창에 작업 내용을 입력하고 `Enter`를 누르면 **새 백그라운드 세션**이 시작됩니다.

```
> 로그인 버그 고쳐줘 (엔터)
> PR #234 리뷰해줘 (엔터)
> 테스트 전부 실행해서 실패한 것만 알려줘 (엔터)
```

### 3단계: 상태 보기

화면에 각 세션이 줄로 표시돼요:

```
작업 중
  ✽ 로그인 버그 고쳐줘        src/auth/login.ts 수정 중          2분 전
  ✽ 테스트 실행               run 3 · 24개 성공, 2개 실패       1분 전

입력 대기
  ✻ PR 리뷰                   needs input: 코드 스타일 변경?     방금

완료
  ∙ 환경설정 파일 정리         result: .env.example 업데이트 완료 5분 전
```

### 4단계: 막힌 세션 도와주기

`Space` 눌러서 미리보기 → 답변 입력 → `Enter`로 전송.
`Enter` 또는 `→` 누르면 그 세션에 완전히 연결.

### 5단계: 작업 끝나면

`Esc` 누르면 에이전트 뷰 닫기 (세션은 계속 백그라운드에서 실행).
연결된 세션에서 `←`(비어있는 입력창에서) 누르면 에이전트 뷰로 돌아오기.

---

## 상태 아이콘 읽는 법

| 아이콘 | 상태 | 의미 |
|--------|------|------|
| ✽ (움직임) | 작업 중 | Claude가 지금 뭔가 하는 중 |
| ✻ (노란색) | 입력 대기 | 내 답변이 필요함 |
| 흐린색 | 유휴 | 입력 기다리는 중 (급하지 않음) |
| ✓ (초록) | 완료 | 작업 성공적으로 끝남 |
| ✗ (빨간색) | 실패 | 오류로 종료 |
| ■ (회색) | 중단 | Ctrl+X로 수동 중단됨 |

아이콘 모양도 신호를 담고 있어요:
- **✻** 또는 움직이는 **✽** → 프로세스 살아있음, 바로 답변 가능
- **∙** → 프로세스 종료됨, 하지만 대화 내용은 남아있어서 다시 연결하면 이어서 가능

## 세션 백그라운드로 보내기

지금 진행 중인 대화를 에이전트 뷰로 내보낼 수 있어요:

```bash
# 대화 중에 명령어 입력
/bg

# 추가 지시와 함께 내보내기
/bg 테스트 다 통과될 때까지 계속 고쳐줘

# 비어있는 입력창에서 ← 키 누르기 (백그라운드 + 에이전트 뷰 열기)
```

처음부터 백그라운드로 시작하려면:

```bash
# 새 백그라운드 세션 시작
claude --bg "레거시 API 마이그레이션해줘"
```

---

## 유용한 단축키 모음

| 단축키 | 동작 |
|--------|------|
| `↑` / `↓` | 세션 목록 이동 |
| `Enter` 또는 `→` | 세션에 연결 (전체 대화창 열기) |
| `Space` | 미리보기 패널 열기/닫기 |
| `Shift+Enter` | 파견 + 즉시 연결 |
| `←` | 세션 분리 (에이전트 뷰로 복귀) |
| `Alt+1`~`Alt+9` | N번째 세션에 바로 연결 |
| `Ctrl+S` | 그룹화 기준 전환 (상태↔디렉토리) |
| `Ctrl+T` | 세션 상단 고정/해제 |
| `Ctrl+R` | 세션 이름 변경 |
| `Ctrl+X` | 세션 중단 (2초 안에 한 번 더 → 삭제) |
| `Esc` | 미리보기 닫기, 입력 지우기, 또는 종료 |
| `?` | 전체 단축키 보기 |

## 쉘에서 세션 관리

에이전트 뷰 열지 않고도 터미널에서 직접 관리할 수 있어요:

```bash
claude agents             # 에이전트 뷰 열기
claude attach abc123      # 특정 세션에 연결
claude logs abc123        # 최근 출력 내용 보기
claude stop abc123        # 세션 중단
claude respawn abc123     # 중단된 세션 재시작
claude respawn --all      # 모든 중단 세션 재시작
claude rm abc123          # 세션 목록에서 제거
```

---

## 파일 수정은 어떻게 되나요?

> 🍱 **비유**: 여러 사람이 같은 Word 파일을 동시에 수정하면 충돌 나는 것처럼, Claude 세션들도 같은 파일을 동시에 건드리면 문제가 생겨요.

에이전트 뷰가 이걸 자동으로 해결해줍니다. 백그라운드 세션이 파일을 수정해야 하면 **워크트리(worktree)**라는 독립 작업 공간이 자동으로 생겨서 거기서 작업해요. 세션을 삭제하기 전에 변경사항을 merge하거나 push해두는 걸 잊지 마세요.

## 주의 사항

<div class="note-circle">
○ <strong>사용량 소모</strong>: 동시에 여러 세션이 돌아가면 요금이 세션 수만큼 소모돼요. 10개 동시 실행 → 1개의 10배 소모. 구독 한도에 주의하세요.
<br />○ <strong>컴퓨터 종료 시 중단</strong>: 백그라운드 세션도 PC가 꺼지거나 절전 모드에 들어가면 중단돼요. 재시작 후 <code>claude respawn --all</code>로 다시 시작할 수 있어요.
<br />○ <strong>v2.1.139 이상 필요</strong>: <code>claude --version</code>으로 버전 확인 후, 낮으면 업데이트하세요.
</div>
