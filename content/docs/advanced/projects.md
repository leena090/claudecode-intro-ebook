## Projects(프로젝트)가 뭐예요?

**Projects**는 관련된 여러 코딩 세션(대화창)을 **하나의 그룹**으로 묶고, 그 안에서 돌아가는 여러 Claude 에이전트를 **동시에 감독**할 수 있는 기능이에요.

> 🏗️ **비유로 설명하면**: 큰 건설 현장을 생각해보세요. 한 현장 소장이 목공팀, 전기팀, 배관팀을 각각 따로 만나서 지시하는 대신, **현장 사무실에 앉아서 세 팀이 무엇을 하고 있는지 한 화면에서 보면서 필요할 때만 개입**하는 거예요. Projects가 바로 그 "현장 사무실"이에요.

---

## 왜 필요한가요?

Claude Code를 쓰다 보면 이런 상황이 생겨요:

- "백엔드 API 고치는 세션" + "프론트엔드 버그 잡는 세션" + "테스트 작성 세션" → **세 창을 왔다갔다**
- 어떤 세션이 지금 어디쯤 진행됐는지 헷갈림
- 한 세션이 멈춰있는데 모르고 있음

Projects를 쓰면:
- 세 세션을 **하나의 프로젝트로 묶어서** 사이드바에서 한눈에 볼 수 있어요
- 각 에이전트의 현재 상태(작업 중 / 대기 중 / 완료)를 실시간으로 확인
- 필요한 세션만 클릭해서 개입

## 어떻게 생겼나요?

```
📁 내 프로젝트: "쇼핑몰 리팩토링"
├── 🔄 세션 1: "상품 목록 API 최적화" — 작업 중...
├── ✅ 세션 2: "결제 모듈 버그 수정" — 완료
├── ⏸️ 세션 3: "모바일 UI 개선" — 내 입력 대기 중
└── ➕ 새 세션 추가...
```

이렇게 한 화면에서 여러 에이전트가 무슨 일을 하고 있는지 볼 수 있어요.

---

## 사용 방법

> ⚠️ **주의**: Projects는 현재 **Claude Code Desktop 앱 전용**이에요. 터미널 CLI에서는 아직 지원되지 않아요.

### 프로젝트 만들기

1. Claude Code Desktop 앱 열기
2. 왼쪽 사이드바에서 **"+ 새 프로젝트"** 클릭
3. 프로젝트 이름 입력 (예: "v2.0 마이그레이션")
4. 관련 세션들을 이 프로젝트로 드래그하거나 새 세션 시작

### 여러 에이전트 동시 감독

```
한 화면에서:
- 세션 A는 지금 어떤 파일을 수정 중인지 보기
- 세션 B가 완료됐다는 알림 받기
- 세션 C에 "계속해"라고 짧게 지시하기
```

## Projects vs Agent View — 뭐가 달라요?

기존에 있던 **Agent View**와 비슷해 보이지만 다른 점이 있어요:

| | Agent View | Projects |
|---|---|---|
| **대상** | 모든 활성 세션 보기 | 관련 세션들을 그룹핑 |
| **구조** | 평면적 목록 | 프로젝트 단위 계층 |
| **용도** | 지금 뭐가 돌고 있나 파악 | 목적별로 세션 묶어 관리 |

> 💡 **쉽게 말하면**: Agent View는 "전체 현장 CCTV", Projects는 "건물별로 나눠진 CCTV 채널"이에요.

## 어떤 상황에 유용한가요?

✅ **대형 리팩토링**: 10개 모듈을 각각 다른 세션에서 동시 작업할 때

✅ **장기 프로젝트**: 몇 주에 걸쳐 진행되는 작업에서 세션 맥락 유지

✅ **팀 에이전트 운영**: 여러 기능 브랜치를 동시에 개발할 때 각 에이전트 현황 파악

✅ **복잡한 마이그레이션**: DB 마이그레이션 + API 변경 + 테스트 업데이트를 병렬 진행
