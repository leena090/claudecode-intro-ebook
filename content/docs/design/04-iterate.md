## 첫 결과가 100% 맘에 들 확률은 낮아요

당연한 거예요. 디자이너도 첫 시안 그대로 가는 경우는 거의 없어요.

<mark>중요한 건 **빠르고 정확하게 수정하는 방법**을 아는 것.</mark>

클로드 디자인은 수정 도구가 2가지입니다.

```
┌────────────────────┬───────────────────────┐
│  💬 채팅 수정       │  💭 인라인 코멘트      │
│                    │                       │
│  전체/넓은 변경     │  특정 부분만 변경      │
│  "분위기 바꿔"      │  "이 버튼만 크게"      │
└────────────────────┴───────────────────────┘
```

---

## 방법 A: 채팅 수정 (넓은 범위)

왼쪽 채팅창에 말로 요청하면 캔버스가 바뀝니다.

### 언제 쓰는가

- **전체 분위기** 바꿀 때
- **레이아웃 구조** 뒤집을 때
- **여러 곳 동시에** 고칠 때

### 예시 프롬프트

```
전체 색깔을 더 어둡고 미니멀하게 바꿔줘.

상단 메뉴를 왼쪽 사이드바로 옮겨줘.

대시보드 그래프 순서를 바꿔줘 —
매출 그래프가 제일 위, 방문자 그래프가 그 아래.

오른쪽에 설정 패널 추가해줘.

이 페이지랑 완전히 다른 2~3가지 레이아웃 시안 보여줘.
```

[[공식]](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)

---

## 방법 B: 인라인 코멘트 (특정 부분)

캔버스에서 **수정하고 싶은 요소를 직접 클릭** → 말풍선에 수정 사항 입력.

### 언제 쓰는가

- **한 요소만** 고칠 때
- "이 버튼" 같이 구체적 지시
- **색·크기·텍스트** 미세 조정

### 예시

1. 캔버스에서 "주문하기" 버튼 클릭
2. 말풍선에 입력:

```
이 버튼 패딩 크게.
```

```
이걸 라디오 대신 드롭다운으로.
```

```
여기 브랜드 프라이머리 컬러로.
```

```
이 텍스트를 더 크게, 폰트 굵게.
```

3. 그 요소만 정확히 바뀜.

> 💡 비유: 종이 시안에 **포스트잇 붙여** "여기 고쳐주세요"라고 적는 것과 같아요.

## 채팅 vs 인라인 — 언제 뭘 쓸지

| 상황 | 추천 방법 |
|------|-----------|
| 전체 톤 변경 | 💬 채팅 |
| 레이아웃 뒤집기 | 💬 채팅 |
| 여러 곳 한번에 | 💬 채팅 |
| 버튼 하나 색깔만 | 💭 인라인 |
| 특정 텍스트 수정 | 💭 인라인 |
| 한 영역 간격 조정 | 💭 인라인 |
| 2~3가지 변형 비교 | 💬 채팅 |

## 🎯 정확한 피드백 = 정확한 결과

같은 문제라도 표현에 따라 결과가 달라요.

### ❌ 모호한 피드백

```
이 부분이 좀 이상해.
어색해.
뭔가 비어 보여.
```

→ 클로드가 뭘 고칠지 추측합니다.

### ✅ 구체적 피드백

```
이 카드 간격을 8px로 좁혀줘.
제목 폰트를 24px Bold로.
오른쪽 여백이 너무 넓어 — 16px로 줄여.
이 영역에 고객 리뷰 섹션을 추가해서 빈 공간 채워.
```

<mark>숫자와 구체 지시가 들어가면 정확히 그대로 바뀝니다.</mark>

## 버전 관리 — 전 시안 보존하기

지금 시안을 버리지 않고 **다른 방향도 시도**하고 싶을 때.

### 전 버전 저장 후 새 시도

```
지금 이 시안 저장해두고, 완전히 다른 방향으로 시도해줘.
이번에는 다크 테마 + 미니멀 느낌으로.
```

[[공식]](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)

<mark>이 한 줄이면 클로드가 현재 버전을 보존한 뒤 새 방향을 그려줍니다.</mark>

언제든 "아까 그 버전으로 돌아가줘"라고 하면 복귀 가능.

## 접근성·사용성 검토 요청

디자인이 예쁘기만 하면 안 돼요. 색맹·고령자·모바일 사용자도 써야 합니다.

### 접근성 체크

```
이 디자인 WCAG AA 기준으로 검토해줘.
- 색 대비 4.5:1 이상인가
- 터치 영역 44x44px 이상인가
- 폰트는 16px 이상인가
- 스크린리더로 읽히는가
```

### 사용성 체크

```
50대 자영업자가 처음 써도 이해할 수 있는지 검토해줘.
어려운 용어나 모호한 버튼 있으면 짚어줘.
```

<mark>클로드가 문제점을 리스트로 뽑아서 수정안까지 제시합니다.</mark>

## 반복할 때 자주 쓰는 표현 모음

### 색깔·분위기

```
전체 톤을 한 단계 어둡게.
파스텔로 바꿔줘.
채도를 낮춰.
브랜드 프라이머리 컬러로 포인트 추가.
배경을 순백 대신 #FAFAFA로.
```

### 레이아웃·간격

```
여백을 넉넉하게.
상하 간격 2배로.
그리드 3열을 4열로.
이 영역을 오른쪽으로 옮겨줘.
상단 헤더를 고정(sticky)으로.
```

### 타이포그래피

```
제목을 더 크고 굵게.
본문 줄간격을 1.6으로.
이 폰트를 라운드한 산세리프로.
영문 폰트는 Inter, 한글은 Pretendard로.
```

### 추가·삭제

```
이 카드 옆에 "더보기" 버튼 추가.
이 섹션 통째로 삭제.
하단에 고객 로고 영역 추가.
이 아이콘을 라인 아이콘으로 교체.
```

### 반응형

```
모바일 화면(375px)도 보여줘.
태블릿에서는 2열 그리드로.
작은 화면에선 사이드바를 햄버거 메뉴로.
```

## 🚨 자주 겪는 문제

### 문제 1: 인라인 코멘트가 사라짐

> 원인: 리서치 프리뷰 버그 [[공식]](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)
> 해결: 같은 내용을 **채팅창에 그대로 붙여넣기**

### 문제 2: "Chat upstream error"

> 해결: 같은 프로젝트 안에서 **새 채팅 탭** 열기 (프로젝트는 유지)

### 문제 3: Save 에러

> 해결: **컴팩트 뷰 → 풀뷰**로 전환

### 문제 4: 코드 저장소 연결 시 느려짐

> 해결: 전체 레포 대신 **하위 디렉토리만** 링크

## 고수의 워크플로우

### 1단계: 빠른 초안 (1분)

```
카페 메뉴판 A4 만들어줘.
```

적당히 뭐라도 빨리 받기.

### 2단계: 큰 구조 조정 (5분)

```
상단에 로고 추가, 메뉴를 3단으로, 하단에 QR 주문 추가.
```

채팅으로 큰 덩어리 수정.

### 3단계: 디테일 다듬기 (10분)

인라인 코멘트로 요소별 미세 조정. 색·폰트·간격.

### 4단계: 변형 비교 (5분)

```
이거 분위기 완전히 다른 버전 2개 더 보여줘.
```

가장 좋은 걸로 확정.

### 5단계: 접근성 체크 (2분)

```
WCAG AA 검토해줘.
```

### 6단계: 내보내기

PDF/PPTX/Claude Code로 핸드오프 → [**내보내기 가이드**](/docs/design/05-export-handoff)

## 핵심 정리

1. **채팅** = 넓은 변경, **인라인 코멘트** = 특정 요소
2. "이상해" ❌ → **구체적 수치**로 피드백 ✅
3. **"저장하고 다른 방향"** 으로 버전 여러 개 유지
4. **접근성·사용성 검토** 꼭 요청
5. 문제 생기면 새 채팅 탭 / 풀뷰 / 하위 폴더 링크
