## 1️⃣ 박과장 — 월요일 경영진 보고 원페이저 (15분 완성)

### 상황

> **월요일 오전 10시 경영진 회의.** 보고 자료가 없다.
> "지난주 실적 원페이저로 정리해서 올려주세요."
> — 팀장

### 예전엔

```
파워포인트 켠다 → 템플릿 찾는다 → 텍스트 박스 만든다 →
아이콘 받는다 → 정렬한다 → 색깔 고민한다... (2시간)
```

### 지금 박과장은

1. **클로드 디자인 접속 (30초)**

```
월간 경영진 보고 원페이저.
A4 세로 1장.

[상단] 로고 + "2026년 4월 주간 리포트" + 날짜
[중앙 KPI 4개] 매출, 신규고객, 전환율, NPS (숫자 크게, 전주 대비 % 병기)
[하단 좌] 주요 이슈 3줄 불릿
[하단 우] 다음 주 액션 3줄 불릿

분위기: 미니멀, 골드 포인트, 정장 느낌.
타겟: 50대 임원.
```

2. **10초 안에 시안 완성**

3. **숫자 붙여넣기** (실제 데이터)

4. **Export → PDF**

5. **메일 첨부 → 끝**

> 🎯 총 **15분**. 예전엔 2시간.

## 2️⃣ 서사장 — 빵집 신메뉴 포스터 (퇴근 전 10분)

### 상황

> **화요일 출시 신메뉴 3종.**
> 매장에 붙일 포스터가 필요하다.
> 디자이너 부를 돈도 시간도 없다.

### 서사장의 프롬프트

```
동네 빵집 "아침빵" 신메뉴 포스터 A3 세로.

[메인 이미지] 빵 사진 3개 (크루아상, 치즈브레드, 앙버터)
[카피] "오늘 아침, 따뜻한 한 조각"
[하단] 매장 이름 + 주소 + QR (네이버 예약)

분위기: 크림 베이지, 손글씨 느낌 폰트,
베이커리 감성. 공간 많이.
```

### 결과

- 시안 완성 → **사진 영역에 실제 매장 빵 사진 교체**
- Export → PDF (A3)
- **동네 인쇄소에 PDF 전송**
- 아침에 매장 벽에 부착

> 🎯 **10분 + 인쇄비 3천원**. 예전엔 디자이너 위탁비 10만원.

## 3️⃣ 이대표 — 투자유치 덱 10장 (하루 만에)

### 상황

> **시드 투자 VC 미팅, 3일 후.**
> 덱이 없다.

### 이대표 워크플로우

#### 1일차 오전: 뼈대 잡기

```
[목표] 시드 투자유치용 10장 덱.
[흐름] 표지 → 문제 → 솔루션 → 시장 → 비즈니스모델 →
       제품 데모 → 경쟁 → 팀 → 재무 → 투자금 사용.
[분위기] 다크 배경 + 네온그린 포인트. 테크 스타트업 느낌.
[타겟] VC 심사역. 한 장 당 한 메시지.
```

#### 1일차 오후: 데이터 채우기

"제품 데모" 장에 스크린샷 붙이고, "재무" 장에 실제 숫자 입력.

#### 2일차: 변형 비교

```
"문제" 장, 완전히 다른 느낌 2개 더 보여줘.
```

→ 3개 중 가장 강한 걸로 선택.

#### 2일차 저녁: 검토

```
이 덱 10장, VC 관점에서 약한 부분 짚어줘.
어느 장이 메시지가 약한지, 데이터 부족한지.
```

클로드가 찝어준 부분 보강.

#### 3일차 아침: Export → PPTX

PPTX로 받아서 파워포인트에서 마지막 다듬기.

> 🎯 **2.5일**. 디자인 외주였으면 2주.

## 4️⃣ 복순 할머니 — 블로그 커버 이미지 (손녀 도움 없이)

### 상황

> **68세 복순 할머니.** "논둑길 산책" 블로그 운영.
> 매주 새 포스팅에 커버 이미지를 만들고 싶다.

### 복순 할머니의 프롬프트 (음성 없이 타이핑)

```
내 블로그 "할머니 논둑길" 이번 주 커버 이미지.
크기는 네이버 블로그용 960x450.

이번 주 주제: "봄나물 쑥 뜯기"
분위기: 따뜻한 햇살, 시골 논두렁,
       손녀가 그려준 그림 느낌.
글씨: "쑥 뜯기 좋은 4월"
```

### 결과

- 따뜻한 느낌 시안 완성
- Export → PNG 다운로드
- 네이버 블로그에 업로드 → 끝

> 🎯 **5분**. 예전엔 손녀한테 부탁.

---

## 5️⃣ 김선영 — 사내 온보딩 슬라이드 20장

### 상황

> **신입 5명 입사.** 사내 교육 슬라이드가 낡았다.
> HR 담당 김선영이 리뉴얼 요청받음.

### 김선영 워크플로우

#### 1단계: 디자인 시스템 먼저 등록

```
우리 회사 디자인 시스템 등록해줘.
- 색상: #1E3A8A (브랜드 블루), #FACC15 (포인트 옐로)
- 폰트: Pretendard
- 로고는 첨부한 SVG
- 버튼/카드 컴포넌트는 첨부한 피그마 파일 참고
```

#### 2단계: 대량 생성

```
신입사원 온보딩 슬라이드 20장.
각 장 주제:
1. 환영
2. 회사 소개
3. 미션·비전
...
20. Q&A

각 장: 제목 상단, 비주얼 중앙, 출처/페이지 하단.
```

#### 3단계: 인라인 코멘트로 디테일

어색한 장 몇 개만 찝어서 수정.

#### 4단계: Export → PPTX

파워포인트에서 애니메이션 추가 후 배포.

> 🎯 **반나절**. 예전엔 디자인팀 2주 대기.

## 6️⃣ 유작가 — 유튜브 썸네일 10장 (금요일 밤)

### 상황

> **유튜버.** 다음 주 영상 10개 일괄 녹화.
> 썸네일 10장이 필요.

### 유작가 프롬프트

```
유튜브 썸네일 10장.
크기: 1280x720.

공통:
- 왼쪽에 큰 텍스트 (임팩트 있는 한 마디)
- 오른쪽에 인물 컷 (내 얼굴 자리 표시)
- 상단에 시리즈 번호 "#1, #2..."
- 하단에 채널 로고

톤: 노란색 배경 + 검은 굵은 폰트. 자극적.

각 장 텍스트:
1. "이거 모르면 망함"
2. "진짜 써본 후기"
3. "10분만 투자하세요"
...
10. "이건 비밀인데"
```

### 결과

- 10장 일괄 생성
- Export → 각 PNG
- 썸네일 자리에 실제 본인 얼굴 컷 합성
- 유튜브에 예약 업로드

> 🎯 **30분 + 녹화 10편**. 한 주치 콘텐츠 완성.

## 7️⃣ 정여사 — 손주 생일파티 초대장 (즐거움 겸용)

### 상황

> **58세 정여사.** 손주 돌잔치 초대장이 필요.

### 정여사 프롬프트

```
손주 돌잔치 초대장 만들어줘.
카카오톡으로 보낼 거라 세로 긴 이미지 (1080x1920).

[상단] "준우 첫 생일에 초대합니다"
[중앙] 아기 사진 들어갈 자리 (원형 크롭)
[하단] 날짜·장소·시간, 참석 여부 회신 번호

분위기: 파스텔 핑크 + 크림, 사랑스럽고 따뜻함.
폰트는 동글동글하게.
손으로 그린 꽃 일러스트 장식.
```

### 결과

- 시안 완성 → 아기 사진 교체
- Export → PNG
- 카톡 단체방에 발송

> 🎯 **8분**. 즐거움 100점.

## 공통 교훈 — 이 7명이 한 일

| 공통점 | 설명 |
|--------|------|
| ✅ **구체적 프롬프트** | 목표·레이아웃·톤·타겟 4요소 |
| ✅ **레퍼런스 활용** | 사진/스크린샷/로고 첨부 |
| ✅ **Export 활용** | PDF/PPTX/PNG 용도에 맞게 |

| ✅ **돈·시간 절약** | 외주 대비 1/10 비용 |

## 지금 당장 해볼 수 있는 것

내 상황에 맞는 사례를 골라서 **프롬프트만 바꿔 쓰세요**.

| 내 상황 | 따라할 사례 |
|---------|------------|
| 보고서가 밀렸다 | 박과장 원페이저 |
| 가게 홍보물이 필요 | 서사장 포스터 |
| 투자유치 준비 | 이대표 덱 |
| 블로그/SNS 이미지 | 복순 할머니 / 유작가 |
| 사내 교육자료 | 김선영 슬라이드 |
| 개인 이벤트 | 정여사 초대장 |

## 마지막 — 실패 사례에서 배우기

### ❌ 박과장이 처음에 실패했던 프롬프트

```
보고서 원페이저 만들어줘.
```

→ 나온 시안이 맘에 안 들었음. "이상하게 비어 보여"

### ✅ 수정한 프롬프트

```
월간 경영진 보고 원페이저 A4 세로.
KPI 4개(매출/고객/전환율/NPS) + 이슈 3개 + 액션 3개.
미니멀, 골드 포인트, 50대 임원 타겟.
```

→ 첫 시안부터 거의 완성작.

<mark>교훈: 처음부터 구체적으로. "예쁘게"라는 말은 쓰지 않기.</mark>

## 핵심 정리

1. **실제 사용자들은 5~30분 안에 끝냄**
2. 비전문가(58세·68세)도 충분히 씀
3. **외주비 1/10**, **시간 1/10**
4. **레퍼런스 첨부**가 결과 품질을 좌우
5. "예쁘게" ❌ → **구체적 4요소** ✅
