## 한 줄로 말하면

> **"말로 설명만 하면, 클로드가 그림·시안·프레젠테이션을 바로 그려주는 도구"** 입니다.

2026년 4월 17일, 앤트로픽이 공개한 **리서치 프리뷰** 기능이에요. [[공식]](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)

---

## 비유로 이해하기

지금까지 디자인은 이랬어요.

> "피그마 프로그램을 켠다 → 메뉴를 찾는다 → 도형을 그린다 → 색을 고른다 → 글자를 넣는다 → 정렬을 맞춘다..."

**마치 요리 재료를 하나하나 손질하는 요리사** 같았죠.

클로드 디자인은 이렇게 바뀝니다.

> "오른쪽에 매출 그래프, 왼쪽에 필터 넣은 대시보드 만들어줘."
>
> → 클로드가 화면에 바로 그려서 보여줍니다.

**주문만 하면 완성 요리가 나오는 식당** 같은 거예요.

---

## 어떤 결과물을 만들 수 있나요?

<mark>진짜 디자이너가 하던 작업 거의 전부입니다.</mark>

| 종류 | 예시 |
|------|------|
| 🖥️ 웹/앱 UI 시안 | 대시보드, 랜딩 페이지, 로그인 화면 |
| 📱 모바일 앱 플로우 | 온보딩 4단계, 설정 화면, 알림 리스트 |
| 📊 프레젠테이션 | 투자유치 덱, 사내 보고서, 교육 슬라이드 |
| 📄 문서형 디자인 | 원페이저, 제품 소개서, 메뉴판 |
| 🧪 인터랙티브 프로토타입 | 버튼 눌리고 화면 이동하는 시안 |
| 🎨 마케팅 비주얼 | 이벤트 배너, SNS 카드, 포스터 |

## 어디서 쓸 수 있나요?

현재는 **리서치 프리뷰(실험판)** 입니다. 사용 조건을 먼저 봐주세요.

### ✅ 쓸 수 있는 플랜

- Claude **Pro** (월 20달러)
- Claude **Max** (월 100~200달러)
- Claude **Team** (팀 요금제)
- Claude **Enterprise** (엔터프라이즈)

### ⚠️ 주의사항

- **Enterprise는 기본 OFF** → 관리자가 켜줘야 합니다 [[공식]](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)
- **Free 플랜에서는 사용 불가**
- 리서치 프리뷰라 **언제든 바뀌거나 중단될 수 있음**

## 어떻게 생겼나요? (화면 구조)

접속하면 화면이 **좌우 2분할**로 보입니다.

```
┌──────────────┬────────────────────────┐
│              │                        │
│  💬 채팅창    │   🎨  캔버스 (디자인)   │
│              │                        │
│  "대시보드    │   ┌──────────────┐     │
│   만들어줘"   │   │ 월별 매출     │     │
│              │   │ ────────     │     │
│  클로드:     │   │  ▓▓▓▓▓       │     │
│  "만들었어요" │   │  ▓▓▓▓▓▓▓     │     │
│              │   └──────────────┘     │
└──────────────┴────────────────────────┘
      왼쪽              오른쪽
```

- **왼쪽 채팅창**: 말로 요청하고 대화
- **오른쪽 캔버스**: 클로드가 그린 결과물이 실시간으로 뜨는 공간

<mark>피그마처럼 직접 도구를 조작하는 게 아니라, 오른쪽 화면을 "가리키며 대화"해서 수정합니다.</mark>

## 기존 디자인 도구랑 뭐가 달라요?

| 항목 | 피그마 / 캔바 | 클로드 디자인 |
|------|---------------|---------------|
| 조작 방식 | 마우스로 직접 그리기 | **말로 설명** |
| 학습 시간 | 며칠~몇 주 | **5분** |
| 초안 만들기 | 한두 시간 | **30초** |
| 수정 | 도구 메뉴 찾기 | "이 버튼 색깔 브랜드 컬러로" |
| 코드 연결 | 별도 개발자 필요 | **클로드 코드로 바로 넘기기** |

특히 마지막이 중요해요. <mark>시안을 만든 뒤 "이걸 실제 코드로 짜줘"라고 클로드 코드에 바로 넘길 수 있습니다.</mark>

## 핵심 정리

1. **말로 설명 → 시안 생성** (피그마 조작 필요 없음)
2. Pro·Max·Team·Enterprise 플랜 전용 (Free 불가)
3. **리서치 프리뷰** — 실험판, 기능 바뀔 수 있음
4. 왼쪽 채팅 + 오른쪽 캔버스 구조
5. 완성 후 **PDF·PPTX·Canva·HTML·Claude Code로 내보내기**
