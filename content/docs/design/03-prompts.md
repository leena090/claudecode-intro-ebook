## 왜 프롬프트가 중요한가

<mark>클로드 디자인은 "말로 하는 도구"예요.</mark> 말이 엉성하면 결과도 엉성합니다.

같은 요청인데 결과가 완전히 달라요.

| 프롬프트 | 결과 |
|----------|------|
| ❌ "대시보드 만들어줘" | 일반적인 샘플 하나 |
| ✅ "월 매출 대시보드. 상단에 총매출·방문자·전환율 카드 3개, 아래 꺾은선 그래프, 오른쪽 필터(지역·기간)" | 원하던 바로 그것 |

---

## 🏆 황금 공식 — 4요소

앤트로픽 공식 가이드에서 권장하는 **4요소**입니다. [[공식]](https://support.claude.com/en/articles/14604416-get-started-with-claude-design)

```
┌─────────┬──────────────────────────────┐
│ 목표    │ 뭘 만드는가 (기능·용도)        │
├─────────┼──────────────────────────────┤
│ 레이아웃 │ 어떻게 배치하는가 (구조)       │
├─────────┼──────────────────────────────┤
│ 콘텐츠  │ 어떤 정보를 보여주는가         │
├─────────┼──────────────────────────────┤
│ 타겟    │ 누가 쓰는가 (사용자)           │
└─────────┴──────────────────────────────┘
```

### 실제 조립 예시

```
[목표] 카페 사장이 매일 매출 확인하는 대시보드.
[레이아웃] 상단 KPI 카드 3개, 그 아래 꺾은선 그래프, 오른쪽 최근 주문 리스트.
[콘텐츠] 오늘 매출, 어제 대비 %, 방문자 수, 시간대별 매출.
[타겟] 40~60대 자영업자. 복잡하면 안 되고, 숫자 크게.
```

→ 이대로 붙여넣으면 거의 바로 쓸 수 있는 시안이 나와요.

## 용도별 템플릿

### 1️⃣ 대시보드 (Admin 화면)

```
[목표] 이커머스 운영팀이 일일 성과 보는 대시보드.
[레이아웃] 좌측 사이드 네비 + 메인 3단 그리드.
[콘텐츠] 주문 건수, 매출, 환불률, 상품별 판매 순위, 고객 리뷰 피드.
[타겟] 30대 마케터. 다크모드 기본.
```

### 2️⃣ 랜딩 페이지 (마케팅)

```
[목표] 새 API 제품 소개 랜딩.
[레이아웃] 히어로 → 기능 3단 → 코드 예시 → 가격표 → 고객 로고 → CTA.
[콘텐츠] "10초 만에 연동" 헤드라인, 코드 스니펫 Python/JS 탭.
[타겟] 시니어 개발자. 다크 테마, 테크 느낌.
```

### 3️⃣ 모바일 앱 온보딩

```
[목표] 명상 앱 첫 실행 4단계 온보딩.
[레이아웃] 세로 한 화면씩, 하단 진행 점(●○○○).
[콘텐츠] 1.환영 → 2.관심사 선택 → 3.알림 허용 → 4.구독 권유.
[타겟] 20~30대 여성. 파스텔, 일러스트.
```

### 4️⃣ 프레젠테이션 (투자유치 덱)

```
[목표] 시리즈 A 투자유치용 10장짜리 덱.
[레이아웃] 한 장당 한 메시지. 큰 글씨 + 작은 보조.
[콘텐츠] 표지 → 문제 → 솔루션 → 시장 → 비즈니스모델 → 경쟁 → 팀 → 재무 → 투자금 사용 → CTA.
[타겟] VC 심사역. 검정 배경 + 골드 포인트.
```

### 5️⃣ 폼 / 설문

```
[목표] 고객 만족도 설문. 10문항.
[레이아웃] 한 문항씩 진행. 진행바 상단.
[콘텐츠] 5점 척도 7개 + 주관식 2개 + 이메일 1개. 조건부: "매우 불만족" 선택 시 이유 입력칸 추가.
[타겟] 일반 고객. 모바일 우선.
```

### 6️⃣ 내부 도구 (Internal Tool)

```
[목표] 운영팀이 유저 신고글 검토·승인하는 관리 툴.
[레이아웃] 왼쪽 신고 리스트 + 오른쪽 상세 + 하단 승인/반려 버튼.
[콘텐츠] 신고 사유, 신고자, 대상 글, 이전 처리 이력.
[타겟] 운영팀 직원. 정보 밀도 높게.
```

## 🎯 30개 즉시 쓰는 프롬프트 모음

### 💼 업무용

1. "월별 매출 대시보드. 지역·상품 필터 포함."
2. "직원 출퇴근 관리 화면. 주간 캘린더 뷰."
3. "재고 관리 테이블. 품목·재고·재주문 경고."
4. "회의실 예약 시스템. 시간 슬롯 그리드."

### 🏪 자영업·소상공인

6. "카페 메뉴판. 아메리카노 등 10종. 사진 + 가격 + 설명."
7. "미용실 예약 페이지. 시술별 가격 + 시간대 선택."

### 📱 앱 / 웹 프로덕트

11. "명상 앱 홈 화면. 오늘 추천 명상 3개 카드."

13. "독서 기록 앱 책장 뷰. 그리드 레이아웃."
14. "할 일 앱 설정 화면. 토글 스위치 7개."
15. "러닝 앱 경로 기록 화면. 지도 + 통계 카드."

### 🎓 교육·강의

16. "온라인 강의 상세 페이지. 커리큘럼 아코디언."
17. "퀴즈 풀이 화면. 4지선다 + 타이머."
18. "수강생 대시보드. 진도율 + 다음 강의 카드."
19. "줌 강의 안내 랜딩. 일정·강사 소개·FAQ."
20. "교사용 학생 성적 관리 테이블."

### 📊 데이터·리포트

21. "월간 KPI 보고서 PDF. 표지 + 요약 + 상세 차트 5장."
22. "경쟁사 비교표. 기능·가격·장단점 3열."
23. "설문 결과 인포그래픽. 원그래프 3개 + 핵심 인용."
24. "재무제표 요약 슬라이드. 매출·영업이익 YoY."
25. "고객 여정 지도(Customer Journey Map). 5단계."

### 🎨 마케팅·SNS

26. "블랙프라이데이 이메일 템플릿. 히어로 + 상품 3단."
27. "인스타그램 캐러셀 10장. 스토리텔링 구조."
28. "유튜브 썸네일 1280x720. 큰 텍스트 + 인물 컷."

## 🔥 고수의 프롬프트 기법

### ① 변형 요청하기

```
이 랜딩 페이지의 히어로 섹션, 2~3가지 다른 레이아웃으로 보여줘.
```

한 번에 여러 안을 받으면 비교·선택이 쉬워요.

### ② 레퍼런스 태그 쓰기

```
Stripe.com 느낌으로 만들어줘. 여백 넉넉하고 폰트는 Inter.
Notion 대시보드 스타일로.
Airbnb 카드 형태로.
```

유명 서비스 이름을 레퍼런스로 쓰면 클로드가 그 분위기를 이해합니다.

### ③ 디자인 시스템 컴포넌트 지정

```
"Primary 버튼" 컴포넌트 써줘.
헤딩은 H2 스타일로.
카드는 "Elevated Card" 변형으로.
```

팀 디자인 시스템이 등록돼 있으면 컴포넌트 이름을 바로 호출 가능해요.

### ④ 반응형 요청을 처음부터

```
모바일(375px), 태블릿(768px), 데스크톱(1440px) 3가지 다 만들어줘.
```

<mark>나중에 반응형 다시 짜느니 처음에 한꺼번에 요청이 빠릅니다.</mark>

### ⑤ 접근성 체크 요청

```
이 디자인 WCAG AA 기준으로 검토해줘.
색 대비, 터치 영역, 폰트 크기 괜찮은지.
```

### ⑥ 구체적 수치로 피드백

```
❌ "이 부분이 좀 이상해"
✅ "이 카드 간격을 8px로 좁혀줘. 제목은 24px로."
```

<mark>숫자로 말하면 정확히 그만큼 바뀝니다.</mark>

## 프롬프트 단계별 성장

### 왕초보 (1주차)

```
카페 메뉴판 만들어줘.
```

### 중급 (1개월차)

```
카페 메뉴판. 10종 메뉴. 사진 + 가격 + 짧은 설명. 모바일 우선.
```

### 고수 (3개월차)

```
[목표] 동네 카페 "블루밤부" 메뉴판 (벽 부착용 A3 인쇄).
[레이아웃] 3단 그리드, 상단 로고, 하단 QR 주문.
[콘텐츠] 커피 5종, 티 3종, 디저트 4종. 가격 + 원산지 + 알레르기.
[타겟] 30~40대 손님. 파스텔 민트 + 크림 화이트.
[참고] 첨부한 인테리어 사진 톤 반영.
[제약] CMYK, 상단 여백 20mm (인쇄 재단용).
```

<mark>고수 단계가 되면 "한 번에 원하는 게 나와요."</mark>

## 핵심 정리

1. **4요소 공식**: 목표 + 레이아웃 + 콘텐츠 + 타겟
2. "예쁘게" ❌ → 구체적 수치 ✅
3. **레퍼런스** 이름(Stripe, Notion 등)으로 분위기 전달
4. 반응형 3종(모바일·태블릿·데스크톱) **처음부터** 요청
5. **2~3가지 변형** 받아서 비교
