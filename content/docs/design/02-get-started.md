## 접속하기

### 1단계: 클로드 웹앱 열기

```
https://claude.ai
```

Mac은 Safari/Chrome, Windows는 Edge/Chrome 모두 됩니다.

### 2단계: 로그인 후 왼쪽 메뉴 확인

유료 플랜(Pro/Max/Team/Enterprise)이면 왼쪽 사이드바에 **"Design"** 메뉴가 새로 보여요.

> 💡 **안 보인다면?**
> - Free 플랜이면 안 보입니다 → Pro로 업그레이드 필요
> - Enterprise는 기본 OFF → 관리자에게 "Claude Design 켜주세요" 요청

### 3단계: Design 메뉴 클릭

들어가면 **좌우 2분할 화면**이 열립니다. 왼쪽 채팅, 오른쪽 캔버스.

## 프로젝트 만들기

디자인도 **Projects** 처럼 프로젝트 단위로 관리합니다.

### 빈 프로젝트부터 시작

```
새 프로젝트 → 이름만 입력 → 바로 대화 시작
```

가장 간단해요. 아무 참고 자료 없이 "이런 화면 만들어줘" 하면 됩니다.

### 컨텍스트 넣고 시작 (추천)

<mark>더 좋은 결과를 원하면 먼저 자료부터 넣으세요.</mark>

| 넣을 수 있는 것 | 왜 넣는가 |
|------------------|----------|
| 📸 스크린샷 | "이런 느낌으로 만들어줘" 참고용 |
| 🖼️ 경쟁사 화면 | "쟤네 디자인 분위기 반영해줘" |
| 📐 와이어프레임 | "이 구조로 예쁘게" |
| 💻 코드 저장소 링크 | 우리 회사 컴포넌트 자동 반영 |
| 🎨 기존 디자인 파일 | 기존 브랜드 톤 유지 |

## 첫 프롬프트 — 해봅시다

### 예시 1: 가장 간단한 시작

```
커피숍 홈페이지 랜딩 페이지 만들어줘.
```

30초 안에 캔버스에 홈페이지 시안이 뜹니다.

### 예시 2: 조금 더 구체적으로

```
카페 "블루밤부" 랜딩 페이지 만들어줘.
- 히어로 섹션: 큰 사진 + 제목
- 메뉴 소개 3개 (카드 형태)
- 매장 위치 지도 영역
- 하단: 인스타그램 링크
```

<mark>구체적일수록 결과가 정확합니다.</mark> "예쁘게"는 추상적, "3단 그리드 카드"는 구체적.

### 예시 3: 분위기까지 지정

```
카페 "블루밤부" 랜더 페이지.
- 분위기: 파스텔 민트, 친근하고 따뜻
- 타겟: 30~40대 여성
- 톤: 여백 많이, 폰트는 라운드한 스타일
```

## 캔버스 화면 살펴보기

시안이 뜨면 오른쪽에 여러 **도구 버튼**이 보입니다.

| 버튼 | 역할 |
|------|------|
| 🖱️ 선택 도구 | 화면 안 요소 클릭해서 고르기 |
| 💬 인라인 코멘트 | 특정 부분 찍어서 수정 요청 |
| 📤 Export | PDF·PPTX·HTML·Canva로 내보내기 |
| 🔗 공유 | 팀원에게 보기/댓글/편집 권한 주기 |
| ↩️ 버전 기록 | 이전 시안으로 되돌리기 |

## 원하는 게 아니면? 바로 수정

### 방법 A — 채팅에 말로

```
색깔을 더 어둡고 미니멀하게 바꿔줘.
상단 메뉴를 오른쪽으로 옮겨줘.
```

채팅창에 계속 대화하면 캔버스가 실시간 업데이트됩니다.

### 방법 B — 화면 찍어서 수정 (인라인 코멘트)

1. 캔버스에서 수정하고 싶은 부분 **클릭**
2. 말풍선이 뜨면 **"이 버튼 크게"** 입력
3. 그 부분만 딱 바뀜

> 비유: 종이 시안에 포스트잇 붙여서 "여기 고쳐주세요"라고 적는 것과 같아요.

자세한 수정법은 → [**수정·반복 완전 가이드**](/docs/design/04-iterate)

## 회사 브랜드 자동 반영하기

팀 플랜 이상이면 **디자인 시스템 등록**이 가능해요.

```
우리 회사 색상 #00FF88, 폰트 Noto Sans,
버튼 둥글기 8px 등록해줘.
```

이후 모든 시안에 자동 반영됩니다. <mark>"이 버튼 브랜드 컬러로"만 해도 정확히 #00FF88 으로 들어가요.</mark>

## 시작할 때 피해야 할 것

### ❌ 나쁜 요청

```
예쁘게 만들어줘.
세련되게.
고급스럽게.
```

→ 클로드가 뭘 기준으로 할지 모릅니다.

### ✅ 좋은 요청

```
파스텔 톤, 여백 넉넉히, 폰트는 라운드.
상단에 히어로 이미지, 그 아래 3단 그리드 카드.
모바일에서도 보이게.
```

→ 목표 + 레이아웃 + 분위기 + 타겟이 다 들어있어요.

프롬프트 공식은 → [**프롬프트 완전 가이드**](/docs/design/03-prompts)

## 자주 겪는 문제

| 증상 | 해결 |
|------|------|
| "Chat upstream error" 뜸 | 프로젝트 안에서 **새 채팅 탭** 열기 |
| 인라인 코멘트가 사라짐 | 채팅창에 직접 똑같이 입력 |
| 큰 코드 저장소 연결 시 느려짐 | 전체 대신 **하위 폴더**만 연결 |
| Save가 에러남 | 컴팩트 뷰 → **풀뷰**로 전환 |

## 핵심 정리

1. claude.ai 로그인 → 왼쪽 **Design** 메뉴
2. 프로젝트 만들 때 **스크린샷·코드·와이어프레임** 먼저 넣으면 결과 급상승
3. 좋은 프롬프트 = **목표 + 레이아웃 + 분위기 + 타겟**
4. 수정은 **채팅** 또는 **인라인 코멘트**
5. 팀 플랜은 **디자인 시스템 등록**으로 브랜드 자동 적용
