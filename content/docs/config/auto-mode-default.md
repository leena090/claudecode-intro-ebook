## 무엇이 바뀌었나요?

**2026년 9월 17일부터** Claude Code가 Pro, Max, Team 플랜에서 **오토 모드(auto mode)를 기본값으로** 실행해요.

> 🚀 **비유로 설명하면**: 이전에는 자동차 시동 걸 때마다 수동 기어를 선택해야 했다면, 이제는 처음부터 자동 변속기가 켜진 채로 출발하는 거예요. 더 편하지만, 원하면 수동으로 바꿀 수도 있어요.

|------|-------------|---------------------|
| 기본 실행 모드 | 수동 승인 모드 | **오토 모드** |

| 장시간 작업 | 자주 중단됨 | **더 길게 자율 실행** |
| 수동 모드 전환 | 불필요 (기본값) | 설정에서 변경 가능 |

## 오토 모드가 뭔가요?

오토 모드에서 Claude Code는:

1. **작업 흐름을 스스로 계획**하고 실행해요
2. **배경 안전 분류기**가 위험 명령을 감시해요
3. 안전하다고 판단되면 **승인 없이 진행**, 위험하면 멈추고 확인해요
4. 긴 작업(마이그레이션, 대규모 리팩토링 등)을 **끊김 없이** 처리해요

> 💡 **이전과 차이점**: 이전에는 파일 수정이나 명령 실행마다 일일이 "허락"을 받아야 했어요. 오토 모드에서는 claude가 스스로 판단해서 안전한 것들을 자율 처리해요.

| 행동 | 오토 모드에서 |
|------|------------|
| 파일 읽기 | 자동 진행 |

## 원래대로 돌리고 싶으면?

설정에서 오토 모드를 비활성화하고 이전 수동 승인 모드로 되돌릴 수 있어요.

### 방법 1: settings.json에서 설정

```json
// .claude/settings.json
{
  "autoMode": false
}
```

### 방법 2: 세션 시작 시 플래그 사용

```bash
claude --no-auto-mode
```

### 방법 3: Claude Code UI에서 변경

설정 패널 → 실행 모드 → "수동 승인" 선택

---

## 오토 모드와 권한 모드의 관계

오토 모드는 **권한 모드(permission modes)** 위에서 동작해요.

```
[오토 모드 활성화]
    ↓
[작업 실행 시]
    ↓
[배경 안전 분류기 판단]
    ├── 안전 → 자동 실행
    └── 위험 → 멈추고 확인 (권한 모드 설정 적용)
```

→ 오토 모드를 켜도 위험한 명령은 여전히 확인 요청을 받아요.

## 팀/기업 환경 (Enterprise 관리자)

Enterprise 플랜에서는 조직 전체에 기본 모드를 설정할 수 있어요:

```json
// 조직 레벨 managed-settings
{
  "defaultMode": "auto"    // 또는 "manual"
}
```

→ 자세한 내용은 [auto-mode-config 공식 문서](https://code.claude.com/docs/en/auto-mode-config)를 참고하세요.
