## 예전 방식과 뭐가 달랐을까요?

Claude Code를 처음 설치하면 Claude가 파일을 수정하거나 명령어를 실행할 때마다 "이 작업을 해도 될까요?" 하고 **일일이 물어봤어요**.

마치 집 청소 도우미가 청소 중에 "이 컵 치울까요?", "이 서랍 정리할까요?" 하고 매 단계마다 확인하는 것처럼요. 꼼꼼하긴 하지만 답답할 수 있죠.

---

## Auto 모드란?

> "Claude Code가 이제 Pro, Max, Team 플랜에서 **Auto 모드를 기본값**으로 실행됩니다. 더 오래 작업할 수 있으면서도 위험한 명령은 여전히 잡아냅니다."
> — Anthropic 공식 발표 기준 (2026-08-07)

Auto 모드에서는 Claude가 안전하다고 판단되는 작업들을 **스스로 진행**합니다. 하지만 위험할 수 있는 명령(예: 파일 삭제, 외부 서비스 접근)은 여전히 확인을 요청해요.

### 비유로 이해하기

**예전 방식**: 집 청소 도우미가 매번 허락을 받음  
**Auto 모드**: 청소는 알아서 하되, 귀중품 처리나 창문 닫기처럼 중요한 건 먼저 물어봄

---

## 달라지는 것들

### ① 더 긴 작업이 가능해집니다

예전에는 긴 작업 중간에 Claude가 승인을 기다리다 멈추는 경우가 있었어요. Auto 모드에서는 중단 없이 더 많은 단계를 자동으로 처리합니다.

### ② 위험한 명령은 여전히 잡습니다

Auto 모드에는 **백그라운드 안전 분류기(Safety Classifier)**가 내장돼 있어요. 위험도가 높다고 판단되는 명령은 자동으로 승인 요청을 띄웁니다.

예를 들어:
- `rm -rf` (파일 대량 삭제) → ⛔ 승인 요청
- `git commit` (코드 저장) → ✅ 자동 진행
- 외부 서버 API 호출 → ⛔ 승인 요청 (설정에 따라 다름)

### ③ 적용 대상 플랜

| 플랜 | Auto 모드 기본값 |
|------|----------------|
| **Pro** | ✅ 2026-08-07부터 기본값 |
| **Max** | ✅ 2026-08-07부터 기본값 |
| **Team** | ✅ 2026-08-07부터 기본값 |
| Enterprise | 관리자가 별도 설정 가능 |
| API (Console) | 개발자가 직접 설정 |

## Auto 모드를 끄고 싶다면?

Auto 모드가 불편하거나 더 세밀하게 제어하고 싶다면 설정에서 변경할 수 있어요:

```bash
# 대화 중 모드 전환
/permission-mode

# 또는 설정 파일에서
# .claude/settings.json → "autoMode": false
```

또는 Claude Code 인터페이스 상단의 모드 선택기에서 **Manual** 또는 **Review**로 바꿀 수 있습니다.

## 권한 모드 세 가지 비교

| 모드 | 특징 | 추천 대상 |
|------|------|----------|
| **Auto** (기본) | 안전한 작업은 자동, 위험한 건 확인 | 대부분의 사용자 |
| **Review** | 모든 작업 목록을 보여주고 승인 | 꼼꼼히 검토하고 싶은 분 |
| **Manual** | 매 단계 일일이 승인 | 처음 사용하거나 신중하게 |
