## 텍스트 워터마크가 뭔가요?

**텍스트 워터마크**는 사진에 넣는 로고 워터마크와 비슷한 개념이에요. 사진에 넣으면 눈에 보이지만, 텍스트 워터마크는 **글 속에 사람이 눈치채기 어려운 패턴을 심어** AI가 작성했다는 걸 나중에 확인할 수 있게 해요.

> 🍱 **비유로 설명하면**: 지폐에는 자외선을 비춰야만 보이는 숨은 그림이 있죠? 텍스트 워터마크도 비슷해요. 그냥 읽으면 자연스럽지만, 특별한 도구로 분석하면 "이건 Claude가 썼어요"라는 표시가 보이는 거예요.

---

## 왜 필요한가요?

AI가 생성한 콘텐츠가 넘쳐나는 요즘, 몇 가지 상황에서 중요해요:

| 상황 | 이유 |
|------|------|
| 학교 과제 | AI가 쓴 건지 학생이 쓴 건지 구분 필요 |
| 뉴스·정보 | 가짜 뉴스를 AI로 대량 생산하는 걸 감지 |
| 법적 문서 | 사람이 작성했다는 신뢰성 증명 필요 |
| 저작권 | AI 생성 콘텐츠의 출처 추적 |

---

## 어떻게 작동하나요?

공식 세부 내용은 추정입니다. 일반적인 텍스트 워터마킹 기술 방식:

1. **단어 선택 패턴**: 비슷한 의미의 여러 단어 중 특정 패턴으로 선택
2. **문장 구조 미세 조정**: 읽기에는 동일하지만 분석 시 패턴이 나타남
3. **통계적 서명**: 글 전체에 걸쳐 특정 확률 분포로 숨겨진 신호 삽입

→ 사람이 읽기엔 자연스럽지만, Anthropic 분석 도구로 확인하면 워터마크 감지

## Claude Code 사용자에게 의미하는 것

코드를 작성할 때도 관련이 있어요:

- 클로드가 생성한 코드·주석·문서에도 유사한 개념이 적용될 수 있어요
- 클로드가 쓴 코드를 그대로 제출할 때, 조직 정책에 따라 확인이 필요할 수 있어요

> 📝 **참고**: 현재 기술 수준에서 워터마크는 완벽하지 않아요. 글을 많이 수정하면 워터마크가 희미해질 수 있어요.
