## 9월 한 달에 세 개의 모델이 출시됐어요 🚀

9월은 정말 빡빡한 달이었어요. Anthropic이 9월 한 달 안에 **세 개의 업그레이드 모델**을 연달아 내놨거든요.

> 🍱 **비유로 설명하면**: 스마트폰 제조사가 Pro, Max, 일반 기종을 한꺼번에 업그레이드한 것처럼요. 각각 쓰임새가 달라요 — 최고 성능이 필요할 때, 비용을 아끼고 싶을 때, 속도가 중요할 때.

## 1. Claude Fable 5.1 + Mythos 5.1 (9월 1일) `[블]`

### 무엇이 달라졌나요?

| 항목 | 내용 |
|------|------|
| 출시일 | 2026년 9월 1일 |
| 성격 | 코딩·지식 업무용 가장 강력한 모델 |
| 핵심 | **연구 능력 강화** — AI가 과학 연구에 기여하는 방향으로 발전 |
| 모델 ID | `claude-fable-5-1` |

Fable 5.1은 기존 Fable 5의 **코딩 능력과 연구 기능을 동시에 강화**했어요. Anthropic은 "AI 모델이 과학적 연구에 어떻게 기여할 수 있는지 엿볼 수 있다"고 설명했어요.

> 💡 **Mythos 5.1도 함께 출시**됐어요. Fable 5.1의 쌍둥이 모델로, 전문 지식 업무에 특화된 버전입니다.

## 2. Claude Opus 5.5 (9월 22일) `[블]`

### Fable 5.1 수준 성능, 40% 저렴

> 🛒 **비유로 설명하면**: 명품 백화점 물건과 똑같이 좋은데 가격은 40% 싼 아울렛 같아요.

| 항목 | 내용 |
|------|------|
| 출시일 | 2026년 9월 22일 |
| 기준 | 대부분의 작업에서 **Fable 5.1 수준** 성능 |
| 비용 | 기존 Opus 5 대비 **40% 저렴** |
| 모델 ID | `claude-opus-5-5` |
| Fast Mode | Opus 5.5, **$8/$40 per MTok** (입력/출력, 이전 Opus 4.8의 $30/$150에서 크게 인하) |

### Claude Code에서 전환하기

```text
> /model claude-opus-5-5
```

### Fast Mode 가격 대폭 인하 💸

Opus 5.5 출시와 함께 **Fast Mode 가격도 대폭 인하**됐어요:

| 구분 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|------|-----------------|-----------------|
| 입력 | $30/MTok | **$8/MTok** |
| 출력 | $150/MTok | **$40/MTok** |
| 속도 | 2.5배 빠름 | 동일 |

> ⚠️ **추정**: 정확한 가격 책정은 공식 발표 기준입니다. 요금제에 따라 적용 방식이 다를 수 있어요.
