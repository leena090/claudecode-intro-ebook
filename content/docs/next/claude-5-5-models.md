## 🚀 Claude 5.5 시리즈 — 전 라인업이 한꺼번에 업그레이드됐어요

2026년 9월부터 10월 사이, Anthropic이 Claude 모델 전 라인업을 업그레이드했습니다. 마치 **주방 기기를 전부 새 제품으로 교체한 것처럼**, 빠르고 효율적인 5.5 세대가 등장했어요.

| **Claude Opus 5.5** | 2026-09-22 | 에이전트 코딩 선두, Opus 5 대비 40% 저렴 |

| **Claude Haiku 5.5** | 2026-10-07 | 가장 빠른 소형 모델, 서브에이전트·브라우저 특화 |

## 🔍 각 모델 상세

### Claude Opus 5.5 — 에이전트 코딩의 기준

> 공식 발표 기준: "에이전트 코딩과 지식 업무에서 선두를 달리며, 일반적인 워크로드에서 Opus 5 대비 40% 저렴합니다."

- **Claude Code 사용자에게**: 복잡한 멀티스텝 코딩 작업, 장시간 에이전트 작업에 가장 적합
- **가격**: Opus 5 대비 40% 절감 (공식 발표 기준)
- **Fast Mode**: Opus 5.5 기반으로 업데이트 — **$8/$40 per million tokens** (입력/출력, 리서치 프리뷰)

### Claude Sonnet 5.5 — 속도와 품질의 균형

> 공식 발표 기준: "Claude Sonnet 5의 명확한 업그레이드. 30% 이상 빠르고, 대부분의 작업에서 30% 저렴합니다."

- **일상 코딩에 최적**: 빠른 응답 + 좋은 품질의 균형
- 자동 모드 기본값 모델로 추정 (공식 확인 필요)

### Claude Haiku 5.5 — 빠른 서브에이전트의 엔진

> 공식 발표 기준: "가장 빠르고 유능한 소형 모델. 요약, 서브에이전트, 브라우저 사용 등 고용량 작업을 위해 설계됐습니다."

- **서브에이전트 실행에 최적**: 동시에 10~100개 서브에이전트를 돌릴 때 비용 절감
- **브라우저 자동화**: 웹 탐색, 스크래핑 등의 고빈도 작업에 탁월
- 마치 **"빠른 심부름꾼"** — 높은 정확도가 필요할 때는 Opus/Sonnet, 많은 양의 반복 작업은 Haiku

### Claude Mythos & Fable 5.1 — 연구 수준 최상위 모델

> 공식 발표 기준: "코딩과 지식 업무를 위한 세계 최첨단 모델. AI 모델이 과학 발전에 어떻게 기여할지 보여주는 초기 연구 능력."

- **Claude Mythos**: 지식 업무, 연구, 복잡한 추론에 특화
- **Fable 5.1**: 코딩·에이전트 작업에서 최고 성능
- **Life Sciences Verification Program (LSVP)**: 생명과학 전문가는 더 관대한 안전장치로 이 모델들에 접근 가능 (2026-09-17)

## ⚡ Fast Mode 업데이트

Fast Mode가 **Opus 5.5 기반**으로 업데이트됐습니다.

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|------|----------------|----------------|
| 기본 모델 | Claude Opus 4.8 | **Claude Opus 5.5** |
| 입력 가격 | $30/M | **$8/M** |
| 출력 가격 | $150/M | **$40/M** |
| 상태 | 리서치 프리뷰 | 리서치 프리뷰 |

💡 Fast Mode는 소비 기반 플랜과 구독 플랜의 사용 크레딧에서 이용 가능합니다.

## 📣 자동 모드(Auto Mode) 이제 기본값!

2026년 8월 7일부터 **Pro, Max, Team 플랜에서 자동 모드(auto mode)가 기본값**으로 변경됐습니다.

- 더 오래, 더 많은 작업을 자동으로 처리
- 위험한 명령어는 여전히 catch하는 안전 분류기 포함
- 이전처럼 수동으로 활성화할 필요 없음

> 🔗 자세한 설정은 [`auto-mode-config`](https://code.claude.com/docs/en/auto-mode-config) 문서 참조
