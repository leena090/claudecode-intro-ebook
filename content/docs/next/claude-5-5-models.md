## Claude 5.5 패밀리란?

2026년 9~10월, Anthropic이 **세 가지 모델을 연달아 업그레이드**했습니다.

> 🚗 **비유로 설명하면**: 자동차 회사가 소형·중형·대형 3가지 라인업을 한 번에 페이스리프트한 거예요. 각각 쓰임새는 다르지만 모두 이전 세대보다 더 좋아졌습니다.

## Opus 5.5 — 코딩·지식 작업의 최강자

🏆 **에이전트 코딩 & 지식 작업 부문 1위** (공식 발표 기준)

- Opus 5 대비 **40% 저렴한** 운영 비용
- 긴 시간 돌아가는 자율 작업에 최적화
- Claude Code에서 복잡한 멀티파일 리팩터, 장시간 마이그레이션에 활용 권장

> 💡 **언제 써요?** 몇 시간짜리 대형 작업, PR 전체 리뷰, 복잡한 버그 분석 등 "Claude Code가 며칠 동안 혼자 해줬으면 하는" 작업에.

---

## Sonnet 5.5 — 속도·비용·성능 균형

⚡ **Sonnet 5 대비 30%+ 빠름, 비용 최대 30% 절감**

- Claude Code의 기본 일상 작업에 가장 잘 맞는 모델
- 빠른 응답이 필요한 반복 작업에 유리
- 개발 팀의 "메인 작업 말" 역할

> 💡 **언제 써요?** 일반적인 코딩 도움, 코드 설명, 테스트 작성, 일상적인 PR 리뷰 등 "항상 쓰는" 작업에.

---

## Haiku 5.5 — 빠르고 가벼운 전문가

🚀 **가장 빠르고 가장 저렴한 새 모델**

- 요약, 서브에이전트(Sub-Agent), 브라우저 작업 등 고빈도·대량 작업 특화
- Dynamic Workflow에서 여러 개를 동시에 띄울 때 경제적
- "많이 써야 하는 반복 작업"에 최적

> 💡 **언제 써요?** 코드 파일 요약, 문서 처리, 멀티에이전트에서 각 에이전트에 배정, API 대량 호출 등에.

## Fast Mode 변경 사항 ⚠️

마케팅 페이지 기준으로 **Fast Mode 대상 모델이 바뀌었습니다**:

| 구분 | 이전 (2026-07-18) | 현재 (2026-10-29) |
|------|-------------------|-------------------|
| 대상 모델 | Opus 4.8 | **Opus 5.5** |
| 가격 | $30/$150 per M tokens | **$8/$40 per M tokens** |
| 속도 | 2.5배 빠름 | 저지연 응답 |

> ⚠️ **추정 포함**: 마케팅 페이지 텍스트 기반. 소비 기반(consumption-based) 플랜에서만 적용. 정확한 가격은 공식 콘솔에서 확인하세요.

## Claude Code에서 모델 바꾸는 방법

```bash
# 설정 파일에서 모델 지정
cat > .claude/settings.json << 'EOF'
{
  "model": "claude-opus-5-5"
}
EOF
```

또는 대화 중 `/model` 명령어로 바꿀 수 있습니다 (공식 발표 기준).
