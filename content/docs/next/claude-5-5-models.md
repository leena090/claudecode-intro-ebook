### 🧬 Claude Mythos — "과학자용 수퍼컴퓨터"

공식 발표: **2026-09-15** `[블]`

> 🔬 **비유**: 일반 병원 의사(Opus)와 달리, 대학병원 특수클리닉 교수(Mythos)는 희귀 질환 전문이에요. 그만큼 깊지만, 빠른 처방은 일반의가 더 빠릅니다.

- 세계 최고 수준의 **코딩 + 지식 작업 + 과학적 추론** 능력
- **연구 미리보기(early glimpse)**: AI 모델이 과학 발전에 기여하는 방식의 선구자
- Life Sciences Verification Program(생명과학 검증 프로그램) 등 전문가용으로 접근 가능
- **Claude Code에서 사용**: 모델 선택기에서 수동 선택 필요

### 💪 Claude Opus 5.5 — "에이전트 코딩의 강자"

공식 발표: **2026-09-22** `[블]`

> 🚀 **비유**: Opus 4.8이 "경험 많은 시니어 개발자"였다면, Opus 5.5는 **같은 실력으로 월급은 40% 깎인 셈**이에요. 회사 입장에서는 훨씬 이득이죠.

**주요 특징**:
- 에이전트 코딩(Agentic coding)과 지식 작업에서 **업계 선두**
- 전형적인 작업 기준 **운용 비용 40% 절감** (Opus 5 대비)
- **Fast Mode 지원**: Opus 5.5를 2.5배 빠른 속도로, $8/$40/백만 토큰

```bash
# Fast Mode로 Opus 5.5 사용하기
# Claude Code 설정에서 모델 선택 후 Fast Mode 토글
```

**Fast Mode 요금 변화**:
| 버전 | 모델 | 입력 | 출력 |
|---|---|---|---|
| 이전 (2026-07까지) | Opus 4.8 | $30/MTok | $150/MTok |
| **현재 (2026-10~)** | **Opus 5.5** | **$8/MTok** | **$40/MTok** |

> 💡 Fast Mode 요금이 **75% 가까이 내렸습니다**. 소비(consumption) 기반 플랜 사용자에게 특히 좋은 소식이에요.

### ⚡ Claude Sonnet 5.5 — "일상 코딩의 새 기본"

공식 발표: **2026-09-28** `[블]`

> 🛵 **비유**: 예전 오토바이(Sonnet 5)도 충분히 빠른데, 새 모델(Sonnet 5.5)은 **연비는 30% 오르고 속도도 30% 빨라졌어요**. 같은 기름으로 더 멀리, 더 빠르게.

**주요 특징**:
- Sonnet 5 대비 **명확한 업그레이드(clear upgrade)**
- 대부분의 작업에서 **30%+ 빠름**
- 대부분의 작업에서 **최대 30% 저렴**
- Claude Code의 **기본 모델**(default model)로 전환

```bash
# Sonnet 5.5가 기본 모델입니다
# 별도 설정 없이 Claude Code를 열면 이 모델이 동작합니다
```

### 🐝 Claude Haiku 5.5 — "초고속 소형 모델"

공식 발표: **2026-10-07** `[블]`

> 🐝 **비유**: 꿀벌처럼 빠르고 작아요. 한 번에 큰일은 못 하지만, **수백 번 반복하는 작업**(요약, 분류, 브라우저 자동화)엔 꿀벌이 최고예요.

**주요 특징**:
- 가장 빠른 + 가장 유능한 소형 모델
- 대량 처리(high-volume) 작업에 최적:
  - 📝 요약(summarization)
  - 🤖 서브에이전트(subagents)
  - 🌐 브라우저 사용(browser use)
- 비용 효율 최고 → 서브에이전트로 병렬 실행 시 최적

```bash
# 서브에이전트에 Haiku 5.5 지정 (Agent SDK 예시)
# 대량 병렬 작업에서 비용 절감 효과 큼
```

## Claude Code에서 어떤 모델을 쓸까요?

```
📋 모델 선택 가이드 (2026-10 기준)

일상적인 코딩 작업     → Sonnet 5.5 (기본값, 아무것도 안 해도 됨)
복잡한 에이전트 작업   → Opus 5.5 (또는 Fast Mode Opus 5.5)
대량 반복 처리 작업    → Haiku 5.5 (서브에이전트에 적합)
```
