## 한 눈에 보는 5.5 패밀리

2026년 9~10월, Anthropic이 주요 모델 3개를 모두 5.5 버전으로 업그레이드했어요.

| 출시일 | 모델 | 핵심 변화 |
|---|---|---|
| 2026-09-22 | **Claude Opus 5.5** | Fable 5.1 수준 성능, Opus 5 대비 40% 저렴 |
| 2026-09-28 | **Claude Sonnet 5.5** | 30% 빠름, 30% 저렴 (Sonnet 5 대비) |
| 2026-10-07 | **Claude Haiku 5.5** | 가장 빠르고 저렴한 소형 모델 |

> 🚗 **비유로 설명하면**: 같은 자동차 모델인데 2024년형 → 2025년형으로 업그레이드된 거예요. 더 빠르고 연비도 좋아졌는데 가격은 오히려 내렸어요.

## Claude Opus 5.5

### 무엇이 달라졌나요?

**Claude Opus 5.5** (`claude-opus-5-5`)는 Anthropic의 최고 성능 모델 라인업에서 **Fable 5.1(팹을 파이브 포인트 원)** 수준의 성능을 내면서도 Opus 5 대비 **40% 저렴**해졌어요.

> 📚 **비유로 설명하면**: 일등 과외 선생님이 수업료를 40% 내렸는데 가르치는 수준은 그대로인 거예요.

| 항목 | 내용 |
|---|---|
| **모델 ID** | `claude-opus-5-5` |
| **성능** | Fable 5.1(팹을 파이브 포인트 원) 수준 |
| **비용** | Opus 5 대비 **40% 절감** |
| **출시일** | 2026년 9월 22일 |
| **적합한 용도** | 복잡한 코딩, 긴 대화, 고품질 분석 |

### Fast Mode도 Opus 5.5로 전환

<div class="note-star">
★ <strong>중요!</strong> Fast Mode(패스트 모드) 기준 모델이 Opus 4.8에서 <strong>Opus 5.5</strong>로 바뀌었어요.
</div>

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|---|---|---|
| **속도 향상** | 2.5배 빠름 | 2.5배 빠름 |
| **가격** | $30/$150 per 1M tokens | **$8/$40 per 1M tokens** |
| **성능** | Opus 4.8 | Opus 5.5 (훨씬 강력) |

> 💰 **비유로 설명하면**: 더 좋은 차를 더 싸게 빌릴 수 있게 됐어요! 모델은 업그레이드됐는데 가격은 오히려 대폭 내렸습니다.

Fast Mode는 Claude Code에서 연구 프리뷰(리서치 프리뷰, research preview) 상태로 제공되며, 소비 기반 플랜(consumption-based plan)에서 사용할 수 있어요.

## Claude Sonnet 5.5

### 무엇이 달라졌나요?

**Claude Sonnet 5.5** (`claude-sonnet-5-5`)는 기존 Sonnet 5의 명확한 업그레이드 버전이에요.

> ⚡ **비유로 설명하면**: 같은 스마트폰 모델인데 칩이 바뀌어서 더 빠르고 배터리도 오래 가는데 가격은 같거나 오히려 내린 거예요.

| 항목 | 내용 |
|---|---|
| **모델 ID** | `claude-sonnet-5-5` |
| **속도** | Sonnet 5 대비 **30% 빠름** |
| **비용** | 대부분 작업에서 **30% 저렴** |
| **출시일** | 2026년 9월 28일 |
| **적합한 용도** | 일상적인 코딩, 빠른 응답이 필요한 작업 |

### 어떤 분께 추천하나요?

- ✅ Claude Code를 매일 사용하시는 분
- ✅ 빠른 응답 속도가 중요한 분
- ✅ 비용을 줄이고 싶은 분
- ✅ Pro/Max 플랜 구독자

## Claude Haiku 5.5

### 무엇이 달라졌나요?

**Claude Haiku 5.5** (`claude-haiku-5-5`)는 **"가장 빠르고 가장 저렴한 소형 모델"** 이에요.

> 🛵 **비유로 설명하면**: 대형 배달 트럭(Opus)과 중형 승용차(Sonnet)가 있다면, Haiku(하이쿠)는 **전동 킥보드**예요. 짧은 거리를 아주 빠르고 저렴하게 이동할 수 있어요.

| 항목 | 내용 |
|---|---|
| **모델 ID** | `claude-haiku-5-5` |
| **특징** | 고속 처리, 비용 최적화 |
| **출시일** | 2026년 10월 7일 |
| **적합한 용도** | 대량 처리, 비용 민감한 작업, 빠른 요약 |

### 언제 Haiku를 쓰면 좋을까요?

```bash
# 모델 직접 지정 예시
claude --model claude-haiku-5-5 "이 함수의 역할을 한 줄로 요약해줘"
```

- 코드 한 줄 설명
- 빠른 질의응답
- 반복적인 단순 작업
- 비용을 최소화해야 하는 프로젝트
