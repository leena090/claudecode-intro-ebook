## 한꺼번에 세대교체가 됐어요

2026년 가을, Anthropic이 약 한 달 사이에 주요 모델을 모두 5.5 버전으로 올렸어요.

> 🏭 **비유로 설명하면**: 자동차 공장에서 엔진·변속기·인테리어를 같은 연도에 한꺼번에 개선한 연식 변경 모델이에요. 겉모습은 비슷해 보여도 속은 완전히 달라졌죠.

| 모델 | 발표일 | 핵심 특징 |
|---|---|---|
| **Claude Opus 5.5** | 2026-09-22 | 에이전트 코딩·지식 업무 1위, Opus 5 대비 비용 40% 절감 |
| **Claude Sonnet 5.5** | 2026-09-28 | Sonnet 5 대비 30%+ 빠름, 비용 최대 30% 절감 |
| **Claude Haiku 5.5** | 2026-10-07 | 가장 빠른 경량 모델, 요약·서브에이전트·브라우저 사용 특화 |

## 각 모델 살펴보기

### 🧠 Claude Opus 5.5 — "깊이 파고드는 연구원"

Opus 5.5는 **에이전트 코딩과 지식 업무**에서 가장 높은 성능을 보여요.

특히 눈에 띄는 점은 **비용이 40% 줄었다**는 거예요. Opus는 원래 "비싸지만 똑똑하다"는 포지션이었는데, 이번에는 더 똑똑해지면서 더 저렴해졌어요.

> 💡 언제 쓰면 좋아요: 복잡한 코드베이스 분석, 여러 파일을 넘나드는 긴 작업, 중요한 비즈니스 의사결정 지원

### ⚡ Claude Sonnet 5.5 — "만능 베스트셀러"

Sonnet 5.5는 **속도와 비용이 모두 개선**된 균형형 모델이에요.

- Sonnet 5 대비 **30% 이상 빠름**
- 대부분의 작업에서 비용 **최대 30% 절감**
- Claude Code 기본 모델로 적합

> 💡 언제 쓰면 좋아요: 일상적인 코딩 작업, 코드 리뷰, 문서 작성, PR 초안

### 🐇 Claude Haiku 5.5 — "치타처럼 빠른 경량 주자"

Haiku 5.5는 **대량 처리 작업**에 최적화됐어요.

- 요약(Summarization)
- 서브에이전트(Subagent) 역할
- 브라우저 자동화(Computer use)

> 💡 언제 쓰면 좋아요: 반복적인 대량 작업, 비용을 아끼면서도 빠른 응답이 필요할 때

## Fast Mode 가격도 바뀌었어요

5.5 시리즈 출시와 함께 **Fast Mode 기준 모델과 가격**이 변경됐어요.

| 항목 | 이전 (5.x 시대) | 현재 (5.5 시대) |
|---|---|---|
| 대상 모델 | Opus 4.8 | **Opus 5.5** |
| 입력 가격 | $30/백만 토큰 | **$8/백만 토큰** |
| 출력 가격 | $150/백만 토큰 | **$40/백만 토큰** |

가격이 **약 1/4 수준**으로 낮아졌어요. Fast Mode를 쓰던 분이라면 체감 비용이 크게 줄었을 거예요.

> ⚠️ **추정 포함** — Fast Mode는 리서치 프리뷰 단계로, 위 가격은 소비 기반 플랜(Consumption-based plan) 기준이에요. 구독 플랜은 사용 크레딧으로 처리돼요.

## Claude Code에서 모델 고르기

```bash
# 기본값으로 사용 (Sonnet 5.5 권장)
claude

# Opus 5.5로 복잡한 작업
claude --model claude-opus-5-5

# Haiku 5.5로 빠른 작업
claude --model claude-haiku-5-5
```

> 📌 모델 설정은 `settings.json`의 `model` 항목에서도 지정할 수 있어요.
