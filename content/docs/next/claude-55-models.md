## Claude 5.5 패밀리란?

2026년 9~10월, **Anthropic이 세 모델을 연속으로 업그레이드**했어요.
Opus·Sonnet·Haiku, 세 형제 모두 "5.5" 버전으로 올라왔습니다.

> 🍱 **비유로 설명하면**: 스마트폰이 갤럭시 S25에서 S25 Ultra로 바뀐 게 아니라, **기존 모델 세 종류(S/A/M 등급)가 한꺼번에 1세대씩 업그레이드**된 것과 같아요. 성능도 좋아졌고 가격도 내렸어요.

---

## 세 모델 한눈에 비교

| 모델 | 출시일 | 한 줄 특징 | 주요 개선 |
|------|--------|-----------|----------|
| **Claude Opus 5.5** | 2026-09-22 | 에이전트 코딩·지식 업무 1위 | 비용 40% 절감 |
| **Claude Sonnet 5.5** | 2026-09-28 | Sonnet 5 대비 명확한 업그레이드 | 속도 30%+, 비용 최대 30% 절감 |
| **Claude Haiku 5.5** | 2026-10-07 | 가장 빠른 소형 모델 | 대용량 작업 (서브에이전트, 브라우저 등) 특화 |

---

## 각 모델 자세히 살펴보기

### 🧠 Claude Opus 5.5 — 에이전트 코딩의 왕

공식 발표 문구: *"에이전트 코딩과 지식 업무에서 1위, Opus 5 대비 일반 작업 비용 40% 절감"*

- 복잡한 코드 리뷰, 멀티스텝 에이전트 작업, 연구 목적에 적합
- Claude Code의 `/ultrareview`, `/ultraplan` 명령어와 최고의 궁합
- Opus 5보다 비용은 낮아졌지만 성능은 더 올라갔어요

> 💡 **쓸 때**: 하루 종일 돌아가는 대규모 리팩터링, 중요한 PR 리뷰, 복잡한 버그 추적에 사용하세요.

---

### ⚡ Claude Sonnet 5.5 — 균형의 대명사

공식 발표 문구: *"Sonnet 5 대비 명확한 업그레이드, 30% 이상 빠름, 대부분 작업에서 최대 30% 저렴"*

- Claude Code의 **기본 추천 모델**로 적합
- 속도와 품질의 균형이 필요한 일상적인 코딩에 최적
- Sonnet 5를 쓰고 있었다면 별다른 설정 없이 자동으로 혜택을 받을 수 있어요

> 💡 **쓸 때**: 일반적인 기능 개발, 테스트 작성, 문서 생성 등 하루 대부분의 작업에 사용하세요.

---

### 🐇 Claude Haiku 5.5 — 초고속 경량 모델

공식 발표 문구: *"가장 빠르고 유능한 소형 모델. 요약, 서브에이전트, 브라우저 작업 등 대용량 처리 목적으로 설계"*

- 같은 시간에 **더 많은 작업을 병렬 처리**할 때 사용
- 에이전트가 여러 서브에이전트를 띄울 때 Haiku 5.5를 각각에 배정하면 비용 절감 효과 큼
- 간단한 질문, 빠른 검색, 반복 작업에 최적화

> 💡 **쓸 때**: Dynamic Workflows에서 서브에이전트 모델로 지정하거나, 간단한 번역·요약 작업에 사용하세요.

## Claude Code에서 모델 바꾸는 법

```bash
# 설정 파일에서 직접 지정
/config → Model 선택

# 또는 명령줄에서
claude --model claude-opus-5-5
claude --model claude-sonnet-5-5
claude --model claude-haiku-5-5-20251001
```

> ⚠️ **참고**: 모델 ID는 추정 기준입니다. 실제 ID는 `/config` 화면에서 직접 확인하세요.

## 어떤 모델을 써야 할까요?

```
🤔 복잡한 에이전트 작업, 중요한 코드 리뷰 → Opus 5.5
🤔 일상적인 코딩 작업 → Sonnet 5.5 (기본 추천)
🤔 빠른 처리, 대용량, 서브에이전트 → Haiku 5.5
🤔 모르겠어요 → Sonnet 5.5로 시작!
```

40~60대 처음 시작하시는 분들은 **Sonnet 5.5**로 시작하시면 됩니다. 나중에 작업 성격에 따라 조절하면 돼요. 🙂
