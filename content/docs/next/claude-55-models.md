| 적용 플랜 | 기본 모델 |
|-----------|----------|
| Max / Team Premium / Enterprise | ✅ Opus 5 |
| Claude 콘솔(API) | ✅ Opus 5 |
| Amazon Bedrock / Google Vertex | ✅ Opus 5 (1M 변형 선택) |

```text
# Claude Code에서 전환하려면
> /model claude-opus-5
```

**1M 토큰 컨텍스트** — Anthropic API, Max, Team, Enterprise 플랜에서 Opus 5는 기본으로 100만 토큰 컨텍스트 창을 사용해요. 큰 코드베이스를 통째로 넣어도 잘 처리해요.

**Fast Mode 변화** (w30 기준)
- Fast Mode가 Opus 4.8 → **Opus 5**로 전환
- 가격: **$10 / $50** per MTok (입력/출력)
