## Fable 5.1 & Mythos 5.1이란?

2026년 9월 1일, Anthropic이 **Claude Fable 5.1**과 **Claude Mythos 5.1**을 공식 발표했어요.

> 🚀 **비유로 설명하면**: 스마트폰이 iPhone 15에서 iPhone 15 Pro Max로 업그레이드되는 것처럼, Fable 5와 Mythos 5의 **더 강화된 버전(.1)**이 나왔어요. 특히 코딩 능력과 전문 지식 처리가 한 단계 더 올라갔어요.

---

## 두 모델의 포지션

Claude의 모델 계층:

```
Haiku 4.5  — 빠르고 경제적 (일상 작업)
Sonnet 5   — 균형 (코딩·에이전트 작업 기본)
Fable 5.1  — 최상위 코딩·지식 작업 ⬅️ 신규
Mythos 5.1 — 최상위 심층 연구·추론 ⬅️ 신규
Opus 5     — 장시간 자율 에이전트 작업
```

> 🗺️ **쉽게 정리하면**: Fable과 Mythos는 Opus보다 빠르면서도 코딩이나 복잡한 지식 작업에서는 더 잘할 수 있는 특화 모델들이에요.

---

## 주요 특징

### 💻 Fable 5.1 — 코딩 특화

Fable 5.1은 **코딩과 기술적 지식 작업**에 최적화된 모델이에요.

| 강점 | 설명 |
|---|---|
| 복잡한 코드 생성 | 대규모 시스템 아키텍처, 멀티파일 수정 |
| 디버깅 | 복잡한 버그의 근본 원인 파악 |
| 코드 리뷰 | 보안 취약점, 성능 이슈 탐지 |
| 기술 문서 작성 | API 설계, 기술 명세서 |

### 🔬 Mythos 5.1 — 지식 작업·과학 연구

Mythos 5.1은 **깊은 연구와 복잡한 추론**에 강해요.

> 🧪 **공식 발표 포인트**: Mythos 5.1의 연구 능력은 "AI 모델이 과학적 진보에 기여하는 방식의 초기 모습"을 보여준다고 Anthropic이 밝혔어요.

| 강점 | 설명 |
|---|---|
| 과학 연구 | 가설 생성, 실험 설계, 문헌 분석 |
| 심층 추론 | 복잡한 다단계 논리 문제 |
| 전문 분야 | 법률, 의학, 금융 분야 전문 지식 |
| 지식 통합 | 여러 분야를 연결하는 통찰 |

## Fable/Mythos vs Opus 5 — 언제 뭘 써야 하나요?

| 상황 | 추천 모델 |
|---|---|
| 코드 작성, 디버깅, 리팩터링 | **Fable 5.1** |
| 복잡한 기술 문서, 설계 검토 | **Fable 5.1** |
| 과학 연구 보조, 논문 분석 | **Mythos 5.1** |
| 며칠씩 이어지는 자율 에이전트 작업 | **Opus 5** |
| 빠른 일상 코딩 작업 | **Sonnet 5** |
| 간단한 Q&A, 빠른 답변 | **Haiku 4.5** |

## 수출 통제 관련 안내

이전에 Fable 5(초기 버전)와 Mythos 5는 미국 정부 수출 통제로 일시적으로 접근이 제한됐었어요. 이후 글로벌 복귀(2026-07-01)가 이뤄졌고, 5.1 버전은 정상적으로 출시됐습니다.

> 🌍 **한국 사용자 안내**: 현재(2026-09-13 기준) Fable 5.1과 Mythos 5.1은 한국에서도 정상적으로 이용 가능한 것으로 확인됩니다. 공식 발표 기준으로 별도 제한이 없어요.
