## 최상위 모델이 업그레이드됐어요

2026년 11월 9일, Anthropic이 **Claude Fable 5.2**와 **Claude Mythos 5.2**를 발표했어요.

> 🏆 **비유로 설명하면**: 스마트폰으로 치면 같은 세대(5 시리즈)의 "프로 맥스" 버전이에요. 기존 Fable 5·Mythos 5보다 더 어려운 작업을 더 잘 처리하도록 개선됐어요.

**공식 설명**: "코딩·금융·과학 분야의 까다로운 기술 작업에서 새로운 기준을 세웠다"

---

## 어떤 분야에서 강해졌나요?

### 💻 코딩 (Coding)

Fable 5.2와 Mythos 5.2는 **복잡한 기술적 코딩 작업**에서 특히 강해졌어요. 대규모 코드베이스 분석, 아키텍처 설계, 보안 취약점 분석 등이 대표적인 사용 사례예요.

### 💰 금융 (Finance)

금융 분야 전문 지식과 추론 능력이 향상됐어요. 계량 분석, 리스크 평가, 복잡한 금융 모델 작업에 적합해요.

### 🔬 과학 (Sciences)

과학적 추론과 연구 보조 능력이 향상됐어요. 연구 논문 분석, 실험 설계 지원, 복잡한 데이터 해석 등에 활용할 수 있어요.

---

## Fable 5.2 vs Mythos 5.2 — 어떻게 다른가요?

> ⚠️ **추정 포함** — 두 모델의 구체적인 차이는 공식 세부 발표를 기다려야 해요. 일반적으로 Mythos는 멀티모달·연구 특화, Fable은 에이전트 작업 특화로 알려져 있어요.

| 모델 | 특화 분야 (추정) | 주요 사용처 |
|---|---|---|
| **Fable 5.2** | 에이전트 코딩, 긴 작업 | Claude Code 고급 작업 |
| **Mythos 5.2** | 연구·분석·멀티모달 | 과학·금융 전문 작업 |

이번 발표는 **Anthropic의 IPO(기업공개) 직전**에 이뤄졌어요.

- 2026-10-26: Anthropic이 SEC에 S-1 제출
