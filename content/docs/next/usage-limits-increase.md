## 무슨 일이 생겼나요?

2026년 5월 6일, Anthropic이 두 가지 큰 소식을 동시에 발표했습니다.

1. **Claude 사용 한도(Usage Limits) 상향** — Pro·Max·Team 플랜 사용자들이 하루에 Claude Code를 더 많이 쓸 수 있게 됨
2. **SpaceX와 컴퓨팅 인프라 협약** — 대용량 AI 컴퓨팅을 안정적으로 확보하기 위한 파트너십

> 🚀 **비유로 설명하면**: 인기 음식점이 "오늘부터 1인당 주문 가능 수량 2배로 늘렸어요!" 하고 공지한 거예요. 그리고 그게 가능한 이유는 SpaceX와 대형 식재료 공급 계약을 맺어서 재료가 더 풍부해졌기 때문입니다.

---

## Claude Code 사용자에게 어떤 영향이 있어요?

### ✅ 좋아진 점

| 항목 | 이전 | 변경 후 |
|------|------|--------|
| 일일 사용 한도 | 제한적 | **상향** (공식 발표 기준 — 구체적 수치는 플랜별 상이) |
| 한도 초과 빈도 | 간혹 발생 | 감소 예상 |
| 장기 안정성 | — | SpaceX 컴퓨팅 확보로 인프라 안정성 향상 |

### 📋 플랜별 확인 포인트

공식 발표 기준, 변경된 사용 한도는 **플랜별로 다를 수 있습니다**.

- **Pro 플랜** ($17/월 연간 또는 $20/월): 한도 확인 필요
- **Max 5x 플랜** ($100/월): 한도 확인 필요
- **Max 20x 플랜** ($200/월): 한도 확인 필요
- **Team 플랜** ($20/인원/월): 한도 확인 필요

> ⚠️ **추정**: 기사 제목만으로는 플랜별 정확한 숫자를 알 수 없습니다. Anthropic 공식 요금제 페이지에서 최신 내용을 확인하세요.

## SpaceX 컴퓨팅 딜이 뭔가요?

> 🛰️ **비유로 설명하면**: Anthropic이 AI를 돌리는 '슈퍼컴퓨터 서버'를 SpaceX의 인프라를 통해 추가로 확보한 거예요. 인터넷 회선이 빠를수록 더 많은 사람이 동시에 쓸 수 있는 것처럼, 서버가 많아지면 더 많은 사람이 Claude를 막힘 없이 쓸 수 있습니다.

이 계약은 단기적인 사용 한도 증가뿐 아니라, 장기적으로 Claude Code가 더 많은 사람에게 안정적으로 서비스될 수 있는 기반을 만드는 것입니다.

## 지금 내 사용 한도를 확인하려면?

Claude Code 안에서 `/usage` 명령어를 입력하면 현재 남은 한도를 볼 수 있어요.

```
/usage
```

출력 예시:
```
사용 현황 (오늘 기준)
  요청 수: 47 / 250 (19%)
  토큰: 124,500 / 1,000,000 (12%)
```

한도가 꽉 차면 Claude Code가 "사용 한도에 도달했습니다" 메시지를 보여줍니다. 이때 선택지는:
- **기다리기**: 다음 날 자정(UTC 기준)에 리셋
- **플랜 업그레이드**: Max 5x → Max 20x 등으로 변경

## 이번 발표가 중요한 이유

Anthropic이 **사용 한도 증가와 인프라 확장을 동시에 발표**한 것은, 단순한 요금제 조정이 아니라 "더 많은 사람이 Claude를 일상 업무 도구로 쓸 수 있도록 투자하겠다"는 신호로 볼 수 있어요.

Claude Code 입문자 분들께는 특히 좋은 소식입니다 — 처음 쓰다 보면 "어, 한도 다 썼네" 하는 순간이 답답할 수 있는데, 이번 상향으로 그런 경험이 줄어들 것으로 기대됩니다.
