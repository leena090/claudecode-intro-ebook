## 1. Claude Fable 5.1 & Mythos 5.1 (Sep 1, 2026)

### 🔬 "코딩과 지식 업무의 최전선"

Anthropic이 **Claude Fable 5.1**과 **Claude Mythos 5.1**을 동시에 발표했어요.

> 🍱 **비유로 설명하면**: 기존 Fable 5가 "최고의 프로그래머"였다면, Fable 5.1은 "최고의 프로그래머이면서 과학 논문도 직접 쓸 수 있는 연구자" 수준으로 업그레이드됐어요.

**주요 특징:**
- **코딩 최전선 성능**: 복잡한 멀티파일 리팩터링, 대규모 마이그레이션에서 탁월한 성과
- **과학적 추론**: AI 모델이 과학 발전에 기여하는 방향을 엿볼 수 있는 초기 성과
- **Mythos 5.1**: 심층 리서치·분석에 특화 (Claude Code 일반 코딩보다 연구 작업에 적합)

**공식 발표 기준** — Fable 5.1이 현재 `whats-new` 문서 기준 최상위 모델이에요.

## 2. Claude Opus 5.5 (Sep 22, 2026)

### ⚡ "Fable 5.1 수준 성능, 40% 더 저렴"

> 🍱 **비유로 설명하면**: 같은 식당 메뉴인데, 맛은 거의 똑같으면서 가격이 40% 내려간 격이에요.

**핵심 수치 (공식 발표 기준):**
- 성능: **Claude Fable 5.1과 대부분의 작업에서 동등**
- 비용: Opus 5 대비 **40% 절감**

**Fast Mode 변경 사항:**

⚠️ **중요 업데이트**: Fast Mode의 대상 모델이 **Opus 4.8 → Opus 5.5**로 변경됐습니다.

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|---|---|---|
| 대상 모델 | Opus 4.8 | **Opus 5.5** |
| 속도 | 2.5배 빠름 | 2.5배 빠름 |
| 입력 가격 | $30/M tokens | **$8/M tokens** |
| 출력 가격 | $150/M tokens | **$40/M tokens** |
| 제공 방식 | 리서치 프리뷰 | 리서치 프리뷰 (구독 플랜에서 usage credit으로도 사용 가능) |

> 💡 **입문자 팁**: Fast Mode를 쓰고 있다면 이제 훨씬 저렴해졌으니 부담 없이 사용할 수 있어요!

## 3. Claude Sonnet 5.5 (Sep 28, 2026)

### 🚀 "Sonnet 5 대비 30% 빠르고 30% 저렴"

**Claude Code의 일상적인 코딩 작업에서 가장 체감되는 업데이트**입니다.

> 🍱 **비유로 설명하면**: 클로드가 탑승한 기차가 같은 노선을 달리는데, 속도는 30% 빨라졌고 요금은 30% 내렸어요.

**주요 수치 (공식 발표 기준):**
- 속도: Sonnet 5 대비 **30% 향상**
- 비용: 대부분의 작업에서 **30% 절감**
- 포지셔닝: "Sonnet 5의 명확한 업그레이드"

**Claude Code에서의 영향:**
- 기본 작업 응답이 눈에 띄게 빨라짐
- 긴 코드 리뷰나 대용량 파일 분석에서 비용 절감
- Sonnet 5.5가 순차적으로 기본 모델로 전환될 예정
