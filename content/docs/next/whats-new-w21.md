### 1️⃣ Auto Mode — 이제 Pro 플랜 + Sonnet 4.6에서도 OK 🎉

**Auto Mode(오토 모드)** 가 이전에는 Max 플랜이나 고급 모델에서만 쓸 수 있었어요. 이번 주부터 **Pro 플랜 + Sonnet 4.6 조합에서도 사용 가능**해졌습니다.

> 🍱 **비유**: 이전에는 자동 운전이 고급 차에만 달려 있었는데, 이제 일반 승용차에도 기본으로 달려 나오는 거예요.

**Auto Mode가 뭔가요?**

Claude가 파일을 편집하거나 명령을 실행할 때마다 일일이 "허락해줄 거예요?" 라고 물어보지 않고, 안전 범위 안에서 **알아서 판단하고 실행**해요. `--dangerously-skip-permissions` 플래그보다 훨씬 안전한 방식이에요.

```bash
# Auto Mode 켜기
claude --auto-mode

# 또는 세션 안에서
/auto
```

| 구분 | 이전 | 이번 주 |
|------|------|---------|
| Auto Mode 사용 가능 플랜 | Max 이상 | **Pro 플랜도 OK** |
| 사용 가능 모델 | Opus 계열 | **Sonnet 4.6도 OK** |
| 안전 수준 | 동일 | 동일 |

<div class="note-circle">
○ Auto Mode는 배경에서 안전 분류기(safety classifier)가 계속 돌아가요<br />
○ 위험한 작업(파일 삭제, 외부 네트워크 요청 등)은 여전히 확인을 요청해요
</div>

### 2️⃣ `/usage` — 이제 뭐가 한도를 잡아먹는지 보여줘요 📊

요금제 한도에 도달했을 때 "왜 이렇게 빨리 다 썼지?"가 궁금했던 적 있죠? 이제 **`/usage`** 명령어를 치면 **스킬·서브에이전트·MCP 서버 중 뭐가 한도를 많이 쓰고 있는지** 항목별로 보여줘요.

```bash
/usage
```

출력 예시:
```
📊 이번 달 사용량 (Plan: Pro)
──────────────────────────────
전체: 67% 사용
  ├─ 스킬 (Skills)         : 32%  ⚡ 높음
  ├─ 서브에이전트           : 20%
  ├─ MCP 서버              : 11%
  └─ 직접 대화             : 4%

가장 많이 쓰는 항목: code-review 스킬 (18%)
```

> 🍱 **비유**: 전기 요금 청구서에 "냉장고 30%, 에어컨 50%, TV 20%" 식으로 항목별로 나오는 거예요 — 어디서 전기를 많이 쓰는지 한눈에 알 수 있죠.

이제 월말에 한도가 모자랄 것 같을 때, **어떤 기능을 아껴야 하는지** 파악할 수 있어요. `[공]`

### 3️⃣ `/code-review` — 코드 리뷰를 명령어 하나로 🔍

새 명령어 **`/code-review`** 가 나왔어요. PR(풀 리퀘스트)에 올린 코드나 현재 변경된 파일을 Claude가 **리뷰어처럼 꼼꼼히 살펴봐요**.

```bash
# 현재 브랜치의 변경사항 리뷰
/code-review

# 특정 파일 리뷰
/code-review src/payment.js

# PR 단위로 리뷰 (GitHub 연동 시)
/code-review --pr 123
```

> 🍱 **비유**: 팀 동료 개발자에게 "내 코드 한번 봐줘" 라고 부탁하는 것처럼 — Claude가 버그, 보안 문제, 개선 가능한 부분을 찾아서 설명해줘요.

리뷰 결과 예시:
```
🔍 코드 리뷰 결과 (src/payment.js)
──────────────────────────────────
⚠️ 보안 경고 (라인 47): 사용자 입력이 그대로 SQL에 들어갑니다 → 파라미터화 쿼리 사용 권장
💡 개선 제안 (라인 23): 중복 코드 3군데 → 함수로 묶으면 좋겠어요
✅ 로직 확인: 결제 실패 처리 흐름 문제없음
```

<div class="note-circle">
○ `/code-review ultra` 옵션을 쓰면 클라우드 멀티 에이전트로 더 깊이 분석해요 (ultrareview)<br />
○ 리뷰 결과는 채팅창에 출력되고, 자동 수정은 하지 않아요 — 수정은 여러분이 결정!
</div>
