## 1. Claude Opus 5.5 — 에이전트 코딩의 새 왕 👑

> 발표: 2026년 9월 22일

### 뭐가 달라졌나요?

**Opus 5.5**는 이전 Opus 5보다 에이전트 코딩과 지식 업무에서 더 뛰어나면서도, **비용이 40% 줄었습니다**.

비유를 들자면, 이전에는 "1등짜리 택시"를 불렀는데 요금이 비쌌다면, 이제는 같은 1등짜리 택시가 더 빠르고 요금도 싸진 셈입니다.

### Claude Code와의 연관

**Fast Mode**가 이번에 Opus 5.5를 기준으로 바뀌었습니다:

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|------|-----------------|-----------------|
| 모델 | Opus 4.8 | **Opus 5.5** |
| 가격 (입력) | $30/백만 토큰 | **$8/백만 토큰** |
| 가격 (출력) | $150/백만 토큰 | **$40/백만 토큰** |
| 속도 배율 | 2.5× | 비슷한 수준 |

Fast Mode 가격이 약 **4분의 1 수준**으로 내려갔습니다. 소비 기반 플랜(Consumption-based plan)에서 사용 가능합니다.

## 2. Claude Sonnet 5.5 — 일상 작업의 베스트셀러 🏃

> 발표: 2026년 9월 28일

Sonnet 5.5는 **Sonnet 5보다 30% 이상 빠르고, 최대 30% 저렴**합니다.

Claude Code에서 기본 모델로 주로 쓰이는 Sonnet 계열이 업그레이드됐으니, 별도 설정 없이도 더 빠른 응답을 경험하게 됩니다.

> 🔎 **비유**: 같은 고속도로인데 제한 속도가 100→130km/h로 올라가고, 통행료는 오히려 싸진 것과 같습니다.

---

## 3. Claude Haiku 5.5 — 빠른 소형 모델의 새 기준 ⚡

> 발표: 2026년 10월 7일

Haiku 5.5는 Anthropic이 "**가장 빠르고 유능한 소형 모델**"로 소개합니다.  
주요 용도: 요약(Summarization), 서브에이전트(Subagents), 브라우저 사용(Browser use) 등 **대량 반복 작업**.

| 특징 | 내용 |
|------|------|
| 처리 속도 | 모든 Claude 모델 중 최고 |
| 주요 용도 | 요약, 서브에이전트, 브라우저 조작 |
| 비용 | 가장 저렴한 계층 |

Dynamic Workflows(동적 워크플로우)에서 수십~수백 개의 서브에이전트를 돌릴 때 Haiku 5.5가 비용·속도 균형에 최적입니다.

## 4. Claude Fable 5.2 & Mythos 5.2 — 최상위 모델 갱신 🏆

> 발표: 2026년 11월 9일

Anthropic 모델 라인업의 최상단, **Fable 5.2**와 **Mythos 5.2**가 등장했습니다.

| 항목 | 내용 |
|------|------|
| 강점 | 코딩, 금융, 과학 분야 최고 성능 |
| 비교 | Fable 5 대비 "다루기 어려운 기술적 작업"에서 한 단계 위 |
| 쌍둥이 | 두 모델 동시 발표 |

> 💡 **Claude Code 사용자 관점**: Fable 5.2는 최고 사양 작업(대형 리팩터링, 복잡한 마이그레이션)에서 선택할 수 있는 최상위 옵션입니다. 소비 기반 플랜에서 사용 가능합니다.
