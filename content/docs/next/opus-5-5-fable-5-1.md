## Fable 5.1 — 코딩·연구의 최전선

### 뭐가 달라졌나요?

- **컨텍스트 창**: 1,000,000 토큰 (책 700권 분량을 한 번에 기억)
- **별칭(alias)**: `/model fable` 입력 시 이제 Fable 5.1이 선택돼요
- **기존 Fable 5**: Claude Apps Gateway 세션에선 여전히 Fable 5가 선택됨 (Gateway가 5.1을 서빙하면 `/model claude-fable-5-1`로 직접 지정)

### Claude Code에서 Fable 5.1 쓰는 법

```
# 현재 세션에서 Fable 5.1로 전환
> /model fable

# 기본 모델로 저장하려면 /model 피커에서 설정
```

> ⚠️ **주의 (공식 발표 기준)**: Fable 5.1은 v2.1.257 이상 버전이 필요합니다. `claude --version`으로 버전 확인 후, 낮으면 `npm update -g @anthropic-ai/claude-code`로 업데이트 하세요.

## Opus 5.5 — 비용 효율의 새 강자

### 핵심 특징

- **성능**: 대부분 업무에서 Fable 5.1과 **동등한 수준**
- **가격**: Opus 5 대비 **40% 저렴**
- **활용처**: Fable 5.1이 필요 없는 일반 코딩·업무 작업에 최적

> 🍱 **비유로 설명하면**: 100점짜리 답을 내는 AI와 97점짜리 AI가 있다고 할 때, 97점짜리가 40% 더 싸다면 대부분 상황에서는 97점짜리를 선택하는 게 합리적이에요. Opus 5.5가 딱 그 위치예요.

## Fast Mode 대폭 업데이트 🚀

Fast Mode(패스트 모드)의 기준 모델이 바뀌었어요.

| 항목 | 이전 (2026-07) | 현재 (2026-09) |
|---|---|---|
| **기준 모델** | Opus 4.8 | **Opus 5.5** |
| **속도** | 2.5배 빠름 | 2.5배 빠름 (동일) |
| **입력 가격** | $30/백만 토큰 | **$8/백만 토큰** ↓ |
| **출력 가격** | $150/백만 토큰 | **$40/백만 토큰** ↓ |
| **제공 방식** | 리서치 프리뷰 | 리서치 프리뷰 (유지) |

> 💡 입력 가격이 $30 → $8로, 출력이 $150 → $40로 줄었어요. **약 73% 가격 인하**입니다. 이런 변화가 생긴 건 기준 모델 자체가 비용 효율이 높은 Opus 5.5로 바뀌었기 때문이에요.

### Fast Mode를 쓰는 상황

```
# /fast 명령어로 Fast Mode 토글
> /fast

# 또는 터미널 위쪽 "Fast" 버튼 클릭
```

- ✅ 이럴 때 쓰면 좋아요: 빠른 답변이 필요한 반복 작업, 응답 속도가 중요한 상황
- ❌ 이럴 때는 일반 모드를 쓰세요: 복잡한 아키텍처 설계, 긴 사고가 필요한 작업
