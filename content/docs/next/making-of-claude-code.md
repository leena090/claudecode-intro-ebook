## Claude Code, 어떻게 시작됐을까요?

**Claude Code**는 처음부터 "공식 제품"으로 만들어진 게 아니에요. Anthropic 내부에서 쓰던 간단한 CLI 도구에서 시작했어요.

> 🍱 **비유**: 유명 요리사가 자기 집 부엌에서 편하게 쓰려고 만든 레시피 메모가, 나중에 요리책이 되고 레스토랑 메뉴판이 된 거예요. Claude Code도 그런 이야기예요.

---

## 이야기의 배경

**Anthropic** 내부의 연구자·엔지니어들은 Claude를 많이 쓰는 사람들이에요. 그런데 매번 브라우저 창을 열어서 복붙하는 게 번거로웠죠.

누군가 생각했을 거예요:

> "터미널에서 바로 Claude 쓸 수 있으면 안 되나?"

그게 **Claude Code의 시작**이었어요 (추정).

---

## 초기 내부 도구에서 공식 제품으로

### 1단계 — 내부 CLI 실험

처음엔 Anthropic 직원들이 자체 코드베이스를 다루는 데 쓰는 간단한 스크립트였어요.

- 터미널에서 코드 파일 직접 읽기
- Claude에 질문하고 답 받기
- 간단한 파일 편집

> 🍱 **비유**: 처음엔 "우리끼리 쓰는 단축키 모음"이었어요.

### 2단계 — 내부 사용자들의 반응

실제로 써보니 생산성이 **극적으로** 높아졌어요. Anthropic 팀들이 기능 요청을 쏟아냈고, 도구는 점점 발전했어요.

특히 다음 점들이 혁신적이었다고 해요:
- 코드베이스 전체를 컨텍스트로 이해
- 파일 여러 개를 동시에 편집
- 터미널 명령어를 Claude가 직접 실행

### 3단계 — 외부 출시 결정

"우리만 쓰기 아깝다"는 판단에서 공식 제품으로 발전했어요 (추정).

## 왜 이 이야기가 중요한가요?

Claude Code의 탄생 스토리는 **"AI 도구는 연구자들이 자기 문제를 해결하면서 만들어진다"**는 것을 보여줘요.

현장에서 실제로 쓰는 사람들이 만들었기 때문에:
- 터미널 개발자들의 워크플로를 잘 이해해요
- 실용적인 기능이 먼저 구현돼요
- "있으면 좋겠다" 싶은 기능이 계속 추가돼요

> 🍱 **비유**: 최고의 주방 도구는 주방장이 직접 만든 거예요. Claude Code는 프로그래머들이 자기 자신을 위해 만든 도구예요.

---

## Claude Code를 더 잘 이해하고 싶다면

이 탄생 스토리를 알면 Claude Code를 더 잘 쓸 수 있어요:

- **"왜 터미널 중심인가"**: Anthropic 엔지니어들이 터미널에서 일하기 때문
- **"왜 CLAUDE.md가 중요한가"**: 컨텍스트를 넘겨받는 게 핵심 설계 철학
- **"왜 계속 빠르게 업데이트되는가"**: 만드는 팀이 직접 쓰는 도구이기 때문
