## Claude Code는 어떻게 탄생했을까?

Anthropic이 2026년 7월 6일, Claude Code의 탄생 비화를 담은 장편 스토리를 공개했어요.

> "The inside story of how Claude Code went from an internal CLI to Anthropic's coding agent, told by researchers, engineers and early users who built it."

직역하면: **"내부 CLI에서 Anthropic의 코딩 에이전트가 되기까지의 뒷이야기 — 직접 만든 연구자·엔지니어·초기 사용자들의 목소리로."**

## 왜 이 이야기가 흥미로운가요?

> 🍱 **비유**: 지금 우리가 매일 쓰는 카카오톡이 처음엔 사내 직원들끼리 쓰던 메신저였던 것처럼, Claude Code도 처음엔 Anthropic 내부 개발자들이 자기 업무에 쓰려고 만든 도구였어요. 그게 어떻게 수십만 개발자가 쓰는 에이전트가 됐는지를 만든 사람들이 직접 풀어줘요.

## 요약: 우리가 알고 있는 Claude Code의 역사

공식 블로그 외에, 지금까지 알려진 Claude Code의 역사를 간략히 정리할게요:

### 초기: 내부 CLI

Claude Code는 처음에 Anthropic 내부에서 사용하던 **커맨드라인 도구(CLI)** 였어요. 개발자들이 Claude를 코딩 업무에 더 효율적으로 쓰기 위해 만든 내부 실험이었죠.

### 공개: 개발자 커뮤니티의 반응

외부에 공개되면서 개발자 커뮤니티의 반응이 예상을 훨씬 뛰어넘었어요. 단순 CLI에서 시작해서:

- 터미널 에이전트
- IDE 확장 (VS Code, JetBrains)
- 웹 앱
- 모바일 앱
- 슬랙 통합

으로 빠르게 확장됐어요.

### 지금: Anthropic의 대표 코딩 에이전트

2026년 현재 Claude Code는:
- macOS, Linux(베타), Windows 지원
- Desktop App, CLI, Web, Mobile 등 다양한 진입점
- 멀티 에이전트, 워크플로우, 플러그인 마켓플레이스
- 기업·팀을 위한 Cowork 기능

까지 갖춘 Anthropic의 핵심 제품이 됐어요.
