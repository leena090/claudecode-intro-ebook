## W25 (6월 15~19일) — 아티팩트·퍼미션 세밀화·/config 단축키

### 1️⃣ 아티팩트(Artifacts) — 클로드 세션에서 바로 웹페이지 발행 📄

**아티팩트**는 클로드가 세션 안에서 만든 페이지를 `claude.ai`의 **개인 전용 URL**로 공유하는 기능이에요. 페이지는 세션이 계속 작업하는 동안 자동으로 업데이트돼요.

> 🍱 **비유**: 클로드가 보고서를 만들어 줬는데, 그걸 그냥 터미널 텍스트로 보는 게 아니라 **이쁜 웹페이지로 바로 발행**해서 팀원한테 링크를 보낼 수 있는 것과 같아요.

**어떨 때 유용하나요?**
- PR 변경사항을 주석이 달린 시각적 페이지로 공유할 때
- 데이터를 대시보드로 만들어서 팀원과 공유할 때
- 복잡한 결과물을 가독성 있게 표현할 때

```text
# 아티팩트 만들기 예시
> 이번 PR의 변경 내용을 diff와 함께 보기 좋게 정리한 아티팩트 페이지 만들어줘
```

👉 [아티팩트 공식 문서](/docs/en/artifacts)

### 2️⃣ 퍼미션 규칙에서 도구 파라미터까지 매칭 🛡️

**Deny(차단)·Ask(확인 요청) 규칙**에서 이제 도구의 입력값까지 조건으로 걸 수 있어요.

```json
// .claude/settings.json 예시
// "opus 모델 사용하는 서브에이전트는 차단"
{
  "permissions": {
    "deny": ["Agent(model:opus)"]
  }
}
```

```json
// "격리(isolation) 설정이 있는 에이전트는 확인 요청"
{
  "permissions": {
    "ask": ["Agent(isolation:*)"]
  }
}
```

> 🍱 **비유**: 지금까지는 "에이전트 전부 차단"만 됐는데, 이제 "Opus 쓰는 에이전트만 차단" 같은 **세밀한 조건**을 걸 수 있어요. 와일드카드(`*`)로 부분 매칭도 돼요.

---

### 3️⃣ `/config` 단축키 — 설정을 프롬프트에서 바로 변경 ⚙️

설정을 바꾸려면 메뉴를 열어야 했는데, 이제 **프롬프트에서 바로** 바꿀 수 있어요.

```text
# "사고 기능 끄기"를 한 줄로
> /config thinking=false

# 비대화형(-p) 모드에서도 사용 가능
claude -p "/config model=claude-sonnet-5 실제 작업 시작"
```

## W26 (6월 22~26일) — MCP 로그인 CLI·`!` 명령어 응답·/rewind 기능 강화

### 1️⃣ `claude mcp login` — MCP 서버 인증을 터미널에서 바로 🔑

MCP(MCP 서버, 외부 서비스 연동) 인증을 이제 **터미널 명령어 하나**로 처리할 수 있어요. 세션을 열지 않아도 돼요.

```bash
# 'sentry' MCP 서버 OAuth 인증
claude mcp login sentry

# 로그아웃
claude mcp logout sentry
```

> 🍱 **비유**: 예전엔 카드를 등록하려면 은행 앱을 열어야 했는데, 이제는 터미널에서 `claude mcp login 은행`이라고 치면 바로 등록되는 것과 같아요.

---

### 2️⃣ `!` 명령어 결과에 클로드가 자동 응답 🔄

터미널 명령어(`!` 접두사)를 실행하면, 결과가 나온 뒤 **클로드가 자동으로 설명**해줘요.

```text
# npm test 실행 후 실패 원인 자동 분석
> ! npm test
```

테스트가 실패하면 "왜 실패했는지" 클로드가 바로 설명해줘요. 두 번 물어볼 필요가 없어요.

> 🍱 **비유**: 요리사(클로드)한테 "맛 좀 봐줘"라고 하면, 맛을 보고 "간이 짜네요, 소금을 줄이세요"까지 바로 말해주는 것과 같아요. 예전엔 맛 보여주고 나서 "어때?"를 또 물어봐야 했거든요.

<div class="note-circle">
○ 이 기능이 싫으면: <code>settings.json</code>에 <code>"respondToBashCommands": false</code> 추가<br />
○ 응답 비용은 일반 프롬프트와 같아요
</div>

---

### 3️⃣ `/rewind` — `/clear` 이전 대화로 돌아가기 ⏪

`/clear`로 대화를 지운 후에도, `/rewind`로 **지우기 전 상태로 되돌아갈 수 있어요**.

> 🍱 **비유**: 화이트보드를 지워버렸는데 다시 꺼내볼 수 있는 것과 같아요. "아, 지우기 전으로 돌아가고 싶다"에 딱 맞는 기능이에요.

## W27 (6월 29일 ~ 7월 3일) — Sonnet 5 기본 모델, 리눅스 데스크톱, /radio

### 1️⃣ 🌟 Sonnet 5(소넷 5) — 새 기본 모델

**Sonnet 5**가 Pro·Team Standard·Enterprise 플랜의 **기본 모델**이 됐어요.

| 항목 | 내용 |
|---|---|
| 모델 ID | `claude-sonnet-5` |
| 특징 | 코딩·에이전트·전문 업무에서 최상위 성능 |
| 컨텍스트 창 | 기본 1M(100만 토큰) |
| 사고 모드 | 어댑티브 씽킹(적응형 사고) 기본 활성화 |
| API 홍보 가격 | $2/$10 per MTok (2026년 8월 31일까지) |
| 최소 버전 | v2.1.197 이상 |

```text
# Sonnet 5로 전환
> /model claude-sonnet-5
```

> 🍱 **비유**: 삼성 갤럭시 S시리즈가 올해 플래그십 모델을 바꾸듯, 클로드의 기본 모델이 Sonnet 4.6에서 Sonnet 5로 업그레이드된 거예요. 같은 요금제에서 더 좋은 모델을 쓸 수 있어요.

👉 [Sonnet 5 자세히 보기](/docs/next/claude-sonnet-5)

### 2️⃣ 🐧 리눅스 데스크톱 앱 베타 출시

Claude 데스크톱 앱이 **리눅스**(Ubuntu 22.04+ / Debian 12+)에서도 설치 가능해졌어요.

- x86_64, arm64 아키텍처 지원
- macOS·Windows와 동일한 Chat·Cowork·Claude Code 경험
- apt 저장소로 설치 → 일반 패키지 업데이트로 최신 버전 유지

👉 [리눅스 설치 가이드](/docs/codeweb/desktop-linux)

### 3️⃣ `/radio` — 코딩할 때 클로드 FM 틀기 🎵

```text
> /radio
```

`/radio` 명령어를 치면 **클로드 FM(lo-fi 라디오)** 스트림을 브라우저에서 열어줘요. 브라우저가 없으면 스트림 URL을 출력해줘요.

> 🍱 **비유**: 코딩하면서 카페 음악 같은 거 틀고 싶을 때, 따로 유튜브 열 필요 없이 `/radio` 한 줄로 끝!

<div class="note-circle">
○ Amazon Bedrock·Google Vertex·Microsoft Foundry 환경에서는 사용 불가
</div>

### 4️⃣ Chrome 통합 정식 출시(GA)

**Claude in Chrome** 기능이 리서치 프리뷰를 벗어나 **전체 공개(GA)**됐어요. Anthropic 직접 플랜 사용자 전체 사용 가능.

클로드 코드가 Chrome 확장 프로그램을 통해 탭을 열고, 페이지를 탐색하고, 폼을 채우고, 콘솔 로그도 읽을 수 있어요.

---

### 5️⃣ 서브에이전트 백그라운드 실행 기본값 변경

이제 서브에이전트는 **기본적으로 백그라운드**에서 돌아요. 클로드가 서브에이전트 결과를 기다리는 동안 멈추지 않고 계속 작업해요.

> 🍱 **비유**: 예전엔 심부름꾼(서브에이전트)이 돌아올 때까지 문 앞에서 기다렸는데, 이제는 심부름꾼을 보내놓고 클로드가 다른 일을 계속 하다가 심부름꾼이 돌아오면 결과를 받아요.

## W28 (7월 6~10일) — 데스크톱 내장 브라우저·/doctor 강화

### 1️⃣ 🖥️ 데스크톱 내장 브라우저

Claude Code 데스크톱 앱에 **내장 브라우저**가 생겼어요. 이제 클로드가 외부 사이트도 직접 열어서 읽고, 클릭하고, 상호작용할 수 있어요.

> 🍱 **비유**: 예전엔 클로드가 "이 사이트 좀 봐줘"라고 하면 사람이 직접 사이트를 열어서 내용을 복붙해줬는데, 이제 클로드가 **스스로 사이트를 열고** 필요한 정보를 가져올 수 있어요.

**특징:**
- 외부 사이트 접속 가능 (문서, 디자인 파일 등)
- 샌드박스(격리) 환경 — 보안 분류기가 외부 사이트 작업을 검토
- 브라우징 세션 유지 여부 설정 가능

---

### 2️⃣ `/doctor` — 설정 진단 + 직접 수리 🔧

`/doctor` 명령어가 단순한 "읽기 전용 진단"에서 **직접 고쳐주는 기능**으로 업그레이드됐어요 (`/checkup`도 같은 명령어예요).

```text
> /doctor
```

**이제 /doctor가 해주는 것:**

| 진단 항목 | 설명 |
|---|---|
| 설치 상태 확인 | Claude Code 설치가 정상인지 |
| 사용 안 하는 스킬·MCP·플러그인 | 컨텍스트 비용 낭비 여부 |
| CLAUDE.md 중복 제거 | 체크인된 파일 vs 로컬 파일 중복 |
| CLAUDE.md 트리밍 제안 | 클로드가 코드베이스에서 유추 가능한 내용 제거 제안 |
| 느린 훅 감지 | 성능 저하 원인 찾기 |

> 🍱 **비유**: 자동차 정기 점검처럼, `/doctor`를 실행하면 문제를 찾아서 "이거 고칠까요?"라고 물어보고 OK하면 자동으로 수리해줘요.
