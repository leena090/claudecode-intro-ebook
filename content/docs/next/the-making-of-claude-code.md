## Claude Code는 어떻게 만들어졌을까요? 🔨

**2026년 7월 6일**, Anthropic이 **Claude Code 제작기**를 공식 블로그에 공개했어요. Anthropic 내부에서 쓰던 CLI 도구가 어떻게 오늘날의 코딩 에이전트로 성장했는지, 처음부터 만든 연구원·엔지니어·초기 사용자들이 직접 이야기해요.

> 🍱 **비유**: 동네 빵집에서 만들어 먹던 특제 빵이 인기를 끌어 전국 프랜차이즈가 된 것처럼, Anthropic 개발자들이 자기들끼리 쓰던 도구가 세상에 나오게 된 거예요.

---

## 탄생 배경 — 처음엔 "내부 도구"였어요

Claude Code는 처음부터 외부 제품으로 기획된 게 아니었어요. Anthropic 내부 개발자들이 **Claude를 코딩에 활용하는 CLI 도구**를 직접 만들어 쓰다가, 그 유용성이 입증되면서 외부에 공개하게 됐어요.

**핵심 여정:**

| 시기 | 단계 |
|---|---|
| 초기 | Anthropic 내부 CLI 도구로 시작 |
| 성장 | 내부 팀 전체로 사용 확산 |
| 검증 | 코드 작성·리뷰·테스트 등 실제 업무 효율화 확인 |
| 공개 | 2025년 외부 공식 출시 |
| 진화 | 터미널 → IDE → 데스크톱 앱 → 웹·모바일 확장 |

---

## "처음엔 정말 거칠었어요"

블로그에서 초기 개발자들은 첫 버전이 지금과 많이 달랐다고 말해요. 지금처럼 세련된 UI나 자동 권한 관리 같은 건 없었고, **그냥 터미널에서 Claude와 대화하며 파일을 수정하는 수준**이었다고 해요.

하지만 그 단순한 형태도 **실제 코딩 속도를 크게 끌어올렸고**, 팀 내에서 빠르게 입소문이 났어요.

○ Anthropic 팀 내부의 개발 생산성이 먼저 검증됐어요

## 핵심 설계 원칙 — 왜 이렇게 만들었나요?

제작기에서 공유된 설계 원칙들이에요.

### ✅ "코드베이스를 직접 읽어야 한다"

Claude Code가 파일을 읽고, 검색하고, 터미널 명령을 실행할 수 있는 건 처음부터 의도된 설계예요. 단순히 "코드 생성"이 아니라 **프로젝트 맥락을 이해하는 에이전트**를 목표로 했어요.

### ✅ "개발자 환경에 맞춰야 한다"

별도의 IDE나 UI를 강요하지 않고 **개발자가 이미 쓰는 환경(터미널, 에디터)**에서 작동하도록 설계했어요. "끼어들지 않는 도구"라는 철학이에요.

### ✅ "권한과 안전을 명확히 해야 한다"

파일 수정이나 명령 실행 전에 허락을 구하는 건 처음부터 핵심 원칙이었어요. 단순 편의 기능이 아니라 **신뢰를 쌓기 위한 필수 설계**라고 봤다고 해요.

## 초기 사용자들의 이야기

블로그에서 초기 사용자들(Anthropic 직원들)이 경험을 공유했어요.

> "처음 써봤을 때 '이게 이렇게 돼?'라는 느낌이었어요. 버그 찾는 속도가 달라졌어요." (추정 인용 — 정확한 내용은 공식 블로그 확인)

처음엔 주로 **버그 찾기, 코드 설명, 테스트 작성** 같은 보조 작업에 쓰다가, 점점 **전체 기능 구현**까지 맡기게 됐다고 해요.

## 오늘날의 Claude Code — 얼마나 달라졌나요?

**초기 vs 현재 비교:**

| 항목 | 초기 (내부 CLI) | 현재 |
|---|---|---|
| 실행 환경 | 터미널만 | 터미널·IDE·데스크톱 앱·웹·모바일 |
| 권한 관리 | 수동 | Auto mode, 권한 모드 시스템 |
| 병렬 작업 | 불가 | 서브에이전트, Agent view, 워크플로 |
| 기업 지원 | 없음 | 팀·엔터프라이즈, SSO, 관리 정책 |
| 플랫폼 | macOS만 | macOS·Linux·Windows |
| 확장성 | 없음 | MCP, 플러그인, 스킬 시스템 |

## 왜 이 글이 중요한가요?

Claude Code를 처음 쓰는 분들에게 이 블로그는 단순한 흥미로운 이야기를 넘어서, **"이 도구가 왜 이렇게 작동하는지"**를 이해하는 데 도움이 돼요.

- **왜 파일을 다 읽으려 하나?** → 맥락 이해가 설계 목표이기 때문
- **왜 매번 허락을 구하나?** → 신뢰 구축이 핵심 원칙이기 때문
- **왜 터미널 중심인가?** → 개발자 기존 환경에 맞추는 철학 때문
