2026년 가을, Anthropic이 한 달 사이에 **클로드 5.5** 세 모델을 연달아 발표했어요.  
마치 스마트폰 제조사가 프리미엄·스탠다드·보급형을 함께 내놓는 것처럼, 각자 역할이 달라요.

| 모델 | 출시 | 한 줄 특징 | 비유 |
|------|------|------------|------|
| **Claude Opus 5.5** | 2026-09-22 | 에이전트 코딩·지식 업무 최강. 비용 40% ↓ | 🏆 올라운드 에이스 |
| **Claude Sonnet 5.5** | 2026-09-28 | 30%+ 빠름 + 최대 30% 저렴 | ⚡ 빠른 중간 선수 |
| **Claude Haiku 5.5** | 2026-10-07 | 요약·서브에이전트·브라우저 사용에 최적 | 🐇 고속 경량 처리기 |

## Opus 5.5 — "더 강한 에이스, 더 싼 가격"

**이전 Opus 5 대비**:
- 에이전트 코딩, 지식 업무에서 **리더십** 유지
- 운영 비용 **40% 절감** (공식 발표 기준)
- 같은 작업을 더 적은 토큰으로 처리

> 💡 **비유**: 같은 명탐정인데, 사무실 임대료를 40% 깎은 느낌이에요. 실력은 그대로, 가격만 낮아졌어요.

**Claude Code에서 선택하려면**:
```
/model claude-opus-5-5
```
또는 설정 파일에서:
```json
{
  "model": "claude-opus-5-5"
}
```

---

## Sonnet 5.5 — "30% 빠르고, 30% 저렴"

**이전 Sonnet 5 대비**:
- 응답 속도 **30% 이상 향상**
- 대부분 작업에서 비용 **최대 30% 절감**
- 코딩·분석·글쓰기 전반에서 "명확한 업그레이드" (공식 표현)

> 💡 **비유**: 같은 택배 기사인데, 배달이 30% 빨라지고 요금도 30% 싸진 거예요. 안 쓸 이유가 없죠.

**Claude Code 기본 모델 변경**:
```json
{
  "model": "claude-sonnet-5-5"
}
```

---

## Haiku 5.5 — "대량 처리의 왕"

**용도**:
- 📋 **요약** (대량 문서 처리)
- 🤖 **서브에이전트** (dynamic workflows에서 여러 개 동시 실행)
- 🌐 **브라우저 사용** (computer use 작업)

> 💡 **비유**: Haiku는 "팀의 막내 사원"이에요. 한 명이 하기엔 많은 일을 10명이 동시에 처리할 때 가장 빛나요. 토큰 비용이 낮아서 대량으로 굴려도 부담이 없어요.

**서브에이전트에서 쓰는 법**:
```json
{
  "subagentModel": "claude-haiku-5-5"
}
```

## Claude Code에서 모델 선택 가이드

```

대량 파일 처리·서브에이전트   → Haiku 5.5 (저비용 대량 처리)
Fast Mode (저지연 필요)        → Opus 5.5 고속 모드 ($8/$40 per M tokens)
```

## Fast Mode 가격 업데이트

마케팅 페이지 기준 Fast Mode가 **Opus 5.5** 기반으로 변경됐어요:

| 항목 | 가격 (공식 발표 기준) |
|------|----------------------|
| Fast Mode 입력 | $8 / 100만 토큰 |
| Fast Mode 출력 | $40 / 100만 토큰 |
| 대상 플랜 | 소비 기반(consumption) 플랜 |

> ⚠️ **참고**: 이전에는 Opus 4.8 기준 $30/$150였어요. 모델이 5.5로 바뀌면서 가격도 함께 조정됐어요.
