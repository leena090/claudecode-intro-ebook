## Claude Opus 5가 뭔가요?

**장시간 자율 에이전트 작업에 최적화된 Anthropic의 새 최상위 모델**입니다. 2026년 7월 24일 공식 출시됐어요.

공식 설명을 빌리면 "*Opus 5는 장시간 실행 에이전트를 지원하면서 코딩과 전문 업무 전반에서 한 단계 높은 성능을 제공합니다.*" [공식 발표 기준]

> 🏆 **비유로 설명하면**: Opus 4.8이 뛰어난 프리랜서 개발자라면, Opus 5는 복잡한 대형 프로젝트를 혼자 처음부터 끝까지 이끌 수 있는 시니어 테크 리드 같은 존재예요. 오래 실행되는 작업에서 더 안정적이고 정확합니다.

## Claude Code에서 어떻게 쓰나요?

### 기본 모델 설정

`/config`에서 모델을 변경하거나, `claude.md`에 명시할 수 있어요:

```bash
# 세션에서 직접
/config → Model 항목에서 claude-opus-5 선택

# CLAUDE.md에 고정
model: claude-opus-5
```

### Fast Mode 변경 사항

Fast Mode가 이번에 **Opus 5 기반으로 전환**됐습니다. [공]

- **대상 모델**: Opus 4.8 → **Opus 5**
- **속도**: 2.5배 빠름 (동일)
- **가격**: $30/$150 → **$10/$50** per million tokens (리서치 프리뷰, 소비 기반 플랜)
- **활성화**: `/fast` 토글

> 💡 Fast Mode는 소비 기반 플랜(consumption-based plan) 사용자 또는 구독 플랜의 사용 크레딧을 통해 이용 가능합니다. [공식 마케팅 페이지 기준]

## 어떤 작업에 Opus 5가 잘 맞나요?

### ✅ 효과가 크게 나는 작업

- 🤖 **장시간 에이전트 자율 실행** — 수십 단계에 걸친 복잡한 워크플로우 자동화
- 💻 **대규모 코드베이스 리팩토링** — 여러 파일에 걸친 체계적 변경
- 📊 **심층 기술 분석** — 아키텍처 설계, 성능 병목 진단
- 🔍 **복잡한 버그 추적** — 원인이 여러 단계에 걸쳐 있는 문제

### ⚖️ 성능 vs 비용 고려

Opus 5는 가장 강력하지만 비용도 높아요. 일상적인 코드 수정·질문은 Sonnet 5로도 충분해요.

| 작업 유형 | 추천 모델 |
|---------|---------|
| 간단한 수정, 설명 요청 | Sonnet 5 |
| 복잡한 설계, 장시간 에이전트 | **Opus 5** |
| 빠른 응답 필요 (속도 우선) | **Fast Mode (Opus 5)** |
| 경량 작업 | Haiku 4.5 |
