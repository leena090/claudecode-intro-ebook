## Claude Opus 5 — 어떻게 달라졌나요?

### 핵심 개선 포인트

Anthropic 공식 발표에 따르면, Opus 5는 **Opus 계층의 단계적 도약(step change)**이에요.

> 🏗️ **비유로 설명하면**: Opus 4.8이 "공사 현장을 혼자 다 감당하는 베테랑 기술자"였다면, Opus 5는 **"며칠 밤새도 지치지 않고, 더 복잡한 공사도 혼자 설계부터 마무리까지 해내는 슈퍼 기술자"** 예요.

| 강점 영역 | 내용 |
|---|---|
| 🤖 **장기 에이전트** | 수십 단계짜리 복잡한 자동화 작업을 안정적으로 완주 |
| 💻 **코딩** | 코딩 능력 전반 개선 — 버그 추적, 리팩토링, 대규모 코드베이스 이해 |
| 📊 **전문 업무** | 분석·리서치·문서 작성 등 전문 영역에서 성능 향상 |

### 모델 ID


## Fast Mode 대대적 변경 🚀

### 무엇이 바뀌었나요?

**Fast Mode**(빠른 모드)는 Opus 모델을 **2.5배 빠르게** 실행하는 고속 설정이에요.

이번에 두 가지가 함께 바뀌었어요:

1. **기준 모델 교체**: Opus 4.8 → **Opus 5**
2. **가격 대폭 인하**: $30/$150 → **$10/$50** per million tokens

```
Fast Mode 가격 변화
-----------------------
이전: $30 입력 / $150 출력 (백만 토큰당)
이후: $10 입력 / $50 출력 (백만 토큰당)
→ 약 3배 저렴해짐!
```

### Fast Mode 켜는 방법

```bash
# 세션에서 빠른 모드 토글
/fast

# 또는 Shift+Tab으로 모드 순환 중 Fast Mode 선택
```

> 📌 **공식 발표 기준**: Fast Mode는 현재 **리서치 프리뷰**로 운영 중이에요. **소비 기반 플랜** 또는 **사용 크레딧**으로 이용 가능합니다.

### 언제 Fast Mode를 써야 하나요?

| 상황 | 추천 모드 |
|---|---|
| 빠른 응답이 필요한 반복 작업 | ✅ Fast Mode |
| 복잡한 에이전트 장기 작업 | 일반 Opus 5 |
| 코딩 스프린트 · 디버깅 | ✅ Fast Mode |
| 정밀한 분석 · 설계 결정 | 일반 Opus 5 |

## 이런 분께 Opus 5가 도움 돼요

### 🤖 복잡한 자동화·에이전트 작업을 하는 분

루틴으로 설정한 **수십 단계짜리 자동화**가 중간에 멈추지 않고 완주하길 원한다면 Opus 5가 적합해요.

```bash
# 루틴 + Opus 5 조합 예시
/model claude-opus-5
"주간 보고서 자동화 루틴 실행해줘"
```

### 💻 대규모 코드베이스를 다루는 분

수십만 줄 규모의 레거시 코드를 이해하고 리팩토링할 때, Opus 5의 향상된 코딩 능력이 빛을 발해요.

### 📋 정밀한 분석이 필요한 전문가

긴 문서 분석, 데이터 해석, 전문적인 의사결정 보조 작업에서 Opus 계열 특유의 깊이 있는 응답을 경험할 수 있어요.
