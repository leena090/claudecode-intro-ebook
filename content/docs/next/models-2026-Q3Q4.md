## 🧠 Claude Opus 5.5 — 에이전트 코딩의 최강자

**출시일:** 2026년 9월 22일

| 항목 | 내용 |
|---|---|
| 별명 | 에이전트 코딩 + 지식 업무 선두 |
| 핵심 장점 | Opus 5 대비 **40% 저렴** |
| 적합한 작업 | 복잡한 멀티스텝 코딩, 긴 연구·분석 작업 |

**Opus 5.5가 빛나는 순간:**
- 🏗️ 대규모 리팩토링 (수십 개 파일 동시 수정)
- 🔍 복잡한 버그 추적
- 📊 긴 문서나 코드베이스 전체 분석
- 🤖 여러 서브에이전트를 조율하는 복잡한 자동화

> 💡 **40% 더 저렴해졌다는 게 얼마나 큰 차이냐면**: 한 달에 토큰을 많이 쓰는 개발자라면 월 비용이 꽤 줄어들 수 있어요. 성능은 오르고 가격은 내렸으니, 이제 Opus를 아끼지 않아도 된다는 뜻이에요.

## ⚡ Claude Sonnet 5.5 — 더 빠르고 더 싸게

**출시일:** 2026년 9월 28일

| 항목 | 내용 |
|---|---|
| 별명 | 일상 코딩의 업그레이드된 주력 |
| 핵심 장점 | Sonnet 5 대비 **30%+ 빠름**, 최대 **30% 저렴** |
| 적합한 작업 | 일반 코딩, PR 리뷰, 문서 작성 |

**Sonnet 5.5가 적합한 상황:**
- 📝 코드 작성·리뷰 (매일 쓰는 작업)
- 💬 대화형 디버깅
- 📄 문서화, 테스트 작성
- 🔧 중간 규모 리팩토링

> 🏎️ **30% 더 빠르다는 체감은**: 프롬프트를 보내고 답이 올 때까지 기다리는 시간이 눈에 띄게 줄어요. 하루에 수백 번 쿼리를 날리는 개발자라면 작업 흐름이 훨씬 부드러워져요.

## 🐇 Claude Haiku 5.5 — 고속·대량 처리 최적화

**출시일:** 2026년 10월 7일

| 항목 | 내용 |
|---|---|
| 별명 | 가장 빠르고 가벼운 소형 모델 |
| 핵심 장점 | 고용량 반복 작업에 최적화 |
| 적합한 작업 | 요약, 서브에이전트, 브라우저 자동화 |

**Haiku 5.5가 빛나는 순간:**
- 📋 대량 요약 (수백 개 문서 처리)
- 🤖 서브에이전트(보조 AI) 역할
- 🌐 브라우저 사용(Computer Use) 자동화
- 💰 비용을 최소화해야 하는 고빈도 작업

> 🐣 **비유하면**: Opus 5.5가 경험 많은 수석 개발자라면, Haiku 5.5는 단순 작업을 엄청나게 빠르게 처리해주는 신입 직원 여러 명이에요.
