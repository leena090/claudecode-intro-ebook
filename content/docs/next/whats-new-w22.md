### 1️⃣ Claude Opus 4.8 — 더 강해진 기본 모델!

**Opus 4.8(오퍼스 포인트 에이트)** 이 새로 나왔어요. Max·Team·Enterprise·API 플랜의 기본 모델이 됩니다.

```bash
# Opus 4.8로 직접 전환
/model claude-opus-4-8

# 또는 모델 선택창 열기
/model
```

**노력 수준(Effort) 조정:**

Opus 4.8은 기본적으로 **높은 노력(high)** 으로 실행돼요. 특히 어려운 작업엔 최고 수준을 요청할 수 있어요:

```bash
# 특히 어려운 작업에 최고 수준
/effort xhigh
```

> 🍱 **비유**: 직원에게 "적당히 해줘(high)" vs "이건 정말 최선 다해줘(xhigh)" 라고 말하는 것처럼요. 평소 업무는 high로 충분하고, 중요한 결정이 들어간 작업엔 xhigh를 쓰세요.

| 항목 | Opus 4.7 (이전) | Opus 4.8 (신규) |
|------|-----------------|-----------------|
| 기본 적용 플랜 | Max, Team, Enterprise | Max, Team, Enterprise, API |
| 기본 effort | high | high |
| xhigh effort | 지원 | ✓ 지원 |
| 최소 버전 | — | v2.1.154 이상 |

### 2️⃣ 동적 워크플로(Dynamic Workflows) — 수십 명의 AI 동시 투입! 🔬

**동적 워크플로** 는 Claude가 여러분의 작업을 위한 **실행 계획 스크립트** 를 직접 써주고, 그걸 수십~수백 개의 AI가 동시에 실행하는 기능이에요.

> 🍱 **비유**: 큰 이삿짐 정리를 혼자 하면 며칠 걸리지만, "누가 부엌, 누가 방, 누가 서재"처럼 설계도(스크립트)를 만들어 수십 명이 동시에 하면 반나절에 끝나는 것처럼요. 동적 워크플로가 그 "설계도 작성 + 인원 배치"를 자동으로 해줘요.

**언제 쓰면 좋나요?**

- 코드 전체를 한 번에 보안 검사할 때
- 수백 개 파일을 새 방식으로 한꺼번에 변환할 때
- 여러 자료를 모아 교차 검증 후 리포트 만들 때

**사용 방법:**

```bash
# "workflow" 또는 "ultracode" 키워드로 요청
> workflow를 써서 src/routes/ 아래 모든 API에 인증 체크가 있는지 검사해줘

# 내장 워크플로 — 딥 리서치
/deep-research Node.js v20에서 v22 사이에 뭐가 바뀌었어?
```

**실행 중인 워크플로 관리:**

```bash
/workflows    # 진행 현황 보기
```

| 키 | 동작 |
|----|------|
| `↑` / `↓` | 단계 선택 |
| `Enter` | 상세 보기 |
| `p` | 일시정지/재개 |
| `x` | 중단 |
| `s` | 워크플로를 명령어로 저장 |

<div class="note-circle">
○ 리서치 프리뷰(Research Preview) 단계예요 — Pro 플랜은 /config에서 활성화 필요<br />
○ 최소 Claude Code v2.1.154 이상 필요<br />

○ 토큰 사용량이 많아요 — 처음엔 작은 범위(한 폴더, 좁은 질문)로 테스트해 보세요
</div>

### 3️⃣ 보안 가이드 플러그인 — Claude가 코드 짜면서 스스로 보안 검사 🛡️

**Security guidance plugin(시큐리티 가이던스 플러그인)** 은 Claude가 코드를 짤 때 **자동으로 보안 취약점을 검사하고 바로 고쳐주는** 기능이에요. 별도 명령어 없이 설치만 하면 자동으로 작동해요.

```bash
# 1. 공식 마켓플레이스에서 설치
/plugin install security-guidance@claude-plugins-official

# 2. 현재 세션에 바로 적용
/reload-plugins
```

> 🍱 **비유**: 워드 프로세서에서 글을 쓸 때 빨간 밑줄이 자동으로 맞춤법 오류를 표시하는 것처럼, 설치해두면 Claude가 코드를 짜면서 "이 부분 보안 위험 있어요, 바로 고칠게요"라고 알아서 처리해요.

📄 자세한 사용법 → [보안 가이드 플러그인 가이드](/docs/advanced/security-guidance-plugin)

### 4️⃣ Fast Mode 가격 대폭 인하! 💰

**Fast Mode(패스트 모드)** 가 이제 **Opus 4.8** 을 기반으로 작동하고, 가격이 크게 내렸어요.

| 항목 | 이전 (Opus 4.7 기준) | 이번 주 변경 (Opus 4.8 기준) |
|------|----------------------|------------------------------|
| 입력 요금 | $30/백만 토큰 | **$10/백만 토큰** ⬇️ 67% 인하 |
| 출력 요금 | $150/백만 토큰 | **$50/백만 토큰** ⬇️ 67% 인하 |
| 속도 | 2.5배 빠름 | 약 2.5배 빠름 (유사) |
| 기반 모델 | Opus 4.7 | **Opus 4.8** (업그레이드) |

> ⚠️ **알림**: Opus 4.6 기반 Fast mode는 이번 업데이트로 **지원 종료(Deprecated)** 됩니다.
> Opus 4.7·4.6 fast mode는 기존 $30/$150 요금 유지.

```bash
# Fast mode 켜기/끄기
/fast
```
