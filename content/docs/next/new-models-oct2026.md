## 한꺼번에 3개가 나왔어요 🎉

2026년 9~10월, Anthropic이 한 달 사이에 새 모델 세 개를 내놨어요.

| 모델 | 발표일 | 특징 |
|---|---|---|
| **Claude Opus 5.5** | 2026-09-22 | Fable 5.1 수준 성능, Opus 5 대비 **40% 저렴** |
| **Claude Sonnet 5.5** | 2026-09-28 | Sonnet 5 대비 **30% 빠름 + 30% 저렴** |
| **Claude Haiku 5.5** | 2026-10-07 | 가장 빠르고 저렴한 소형 모델 최신판 |

> 🍱 **비유로 설명하면**: 스마트폰 라인업이랑 비슷해요.
> - **Haiku** → 갤럭시 A 시리즈 (빠르고 가볍고 저렴)
> - **Sonnet** → 갤럭시 S 시리즈 (균형 잡힌 주력 모델)
> - **Opus** → 갤럭시 Z 폴드 (최고 성능, 무거운 작업용)
>
> 이번에 세 라인업이 모두 `.5` 버전으로 업그레이드된 셈이에요.

---

## 각 모델 자세히 보기

### 🔵 Claude Sonnet 5.5 — 일상 코딩의 새 기준

**언제 쓰면 좋아요?**: 매일 쓰는 코딩 보조, 문서 작성, 일반 질문 등 대부분의 작업에서요.

- Sonnet 5 대비 **30% 빠름** — 응답이 체감상 확 달라졌어요
- **30% 저렴** — 같은 토큰을 30% 덜 내고 쓸 수 있어요
- Claude Code 기본 모델로 곧 전환될 가능성이 높아요 (공식 발표 기준)

---

### 🟣 Claude Opus 5.5 — Fable 수준, Opus 가격

**언제 쓰면 좋아요?**: 복잡한 멀티 에이전트 작업, 어려운 추론이 필요한 코드 리팩토링 등

- 성능은 Fable 5.1에 필적 — 최상위 모델급이에요
- Opus 5 대비 **40% 저렴** — 같은 성능이 훨씬 경제적으로
- **Fast Mode**의 새 대상 모델 (아래 참조)

---

### 🟢 Claude Haiku 5.5 — 제일 빠르고 가벼운 모델

**언제 쓰면 좋아요?**: 짧은 코드 스니펫 생성, 빠른 질문 답변, 배치 작업

- Haiku 4.5 대비 더 빠르고 저렴 (공식 발표 기준)
- "고용량·저비용 작업 설계"가 목적이에요 — 한 번에 수천 건 처리하는 자동화에 적합

## ⚡ Fast Mode 가격이 확 내려갔어요

| 항목 | 이전 (2026-07) | 현재 (2026-10) |
|---|---|---|
| **대상 모델** | Opus 4.8 | **Opus 5.5** |
| **속도** | 2.5배 빠름 | 2.5배 빠름 |
| **가격** | $30/$150 / 1M 토큰 | **$8/$40 / 1M 토큰** |
| **이용 조건** | 소비 기반 플랜 | 소비 기반 플랜 |

> 🍱 **비유로 설명하면**: KTX 특실 요금이 일반실 2배였는데, 이제 1.3배로 내려간 느낌이에요. 그러면서 열차 자체도 더 좋은 차종으로 바뀐 거고요.

**정리하면**: 같은 속도(2.5배 빠름)를 훨씬 비용 효율적으로 쓸 수 있게 됐어요.

> ⚠️ **주의**: Fast Mode는 현재 **리서치 프리뷰(Research Preview)** 상태예요. 소비 기반 플랜(Consumption-based plan)에서만 이용 가능하고, 구독 플랜 사용자는 사용 크레딧으로 쓸 수 있어요.

## 🤖 Auto Mode가 기본값이 됐어요

마케팅 페이지 기준으로, **2026년 9월 17일**부터 아래 플랜에서 Auto Mode가 기본 설정으로 바뀌었어요:

- **Pro 플랜**
- **Max 플랜** (5x·20x 모두)
- **Team 플랜**

> 🍱 **비유로 설명하면**: 이전에는 '수동 모드'가 기본이었는데, 이제 '자동 모드'가 기본이 된 거예요. 자동으로 달리다가 위험한 상황에서만 멈추는 방식이에요.

Auto Mode에서는 클로드가 허락을 덜 물어보면서 스스로 긴 작업을 이어가요. 단, 위험한 명령은 백그라운드 안전 분류기(classifier)가 잡아줘요.

자세한 설정은 → `Shift+Tab`으로 모드 전환하거나, `/config`에서 바꿀 수 있어요.

```
👉 어렵고 복잡한 프로젝트 → Opus 5.5
👉 빠른 속도가 중요하면  → Fast Mode (소비 기반 플랜)
```
