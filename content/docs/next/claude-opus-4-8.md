## Claude Opus 4.8이 나왔어요

2026년 5월 28일, Anthropic이 **Claude Opus 4.8**을 정식 발표했어요. Claude Code에서 가장 강력한 모델인 Opus 계열의 새 버전이에요.

> 🍱 **비유로 설명하면**: 스마트폰이 Galaxy S24에서 S25로 업그레이드된 것과 같아요. 디자인은 비슷하지만 속 성능이 올라갔고, 특히 오래 쓸수록 배터리가 안 떨어지는(=장시간 작업 일관성) 부분이 크게 좋아진 거예요.

---

## 무엇이 달라졌나요?

Anthropic 공식 발표 기준으로 세 가지가 핵심이에요:

| 항목 | Opus 4.7 (이전) | Opus 4.8 (신규) | 체감 차이 |
|------|-----------------|-----------------|----------|
| **코딩 성능** | 강함 | 더 강함 | 복잡한 버그 수정, 리팩토링 정확도 향상 |
| **에이전트 작업** | 우수 | 더 우수 | 긴 자동화 작업 중 실수가 줄었음 |
| **전문 업무** | 양호 | 향상 | 설계 문서, 기술 분석 품질 향상 |
| **장시간 일관성** | 보통 | 크게 향상 | ★★★ 가장 큰 개선점 |

**장시간 일관성**이 가장 눈에 띄는 변화예요. 긴 에이전트 세션에서 중간에 방향을 잃거나, 앞에서 한 말을 잊어버리거나, 갑자기 스타일이 바뀌는 현상이 크게 줄었어요.

## Claude Code에서 어떻게 쓰나요?

### Pro 플랜부터 Opus 4.8 사용 가능

마케팅 페이지 공식 기준으로, **Pro 플랜도 Opus 4.8에 접근**할 수 있어요:

- **Pro ($17/월)**: Sonnet 4.6 + **Opus 4.8** 접근 가능
- **Max 5x ($100/월)**: 더 많은 Opus 4.8 사용량
- **Max 20x ($200/월)**: 파워유저용, 최대 Opus 4.8 접근

```bash
# 현재 사용 중인 모델 확인
/model

# Opus 4.8로 직접 전환
/model claude-opus-4-8
```

> ⚠️ Pro 플랜에서 Opus 4.8 사용에는 **사용량 제한**이 있어요. 많이 쓰면 Sonnet 4.6으로 전환돼요.

## Fast Mode도 Opus 4.8로 업데이트

[Fast Mode](/docs/advanced/voice-fast)가 이제 Opus 4.7이 아닌 **Opus 4.8 기반**으로 업데이트됐어요.

```bash
# Fast Mode 활성화
/fast
```

| 항목 | 내용 |
|------|------|
| 속도 | 일반 Opus 4.8보다 **2.5배 빠름** |
| 비용 | 입력 $30/백만 토큰, 출력 $150/백만 토큰 |
| 가용 플랜 | Pro/Max 리서치 프리뷰, 소비 기반 플랜 |

## 언제 Opus 4.8을 써야 할까요?

모든 작업에 Opus 4.8을 쓰면 좋지만, 비용 때문에 상황에 맞게 고르는 게 현명해요.

| 상황 | 추천 모델 | 이유 |
|------|-----------|------|
| 간단한 코드 수정, 오타 고치기 | **Sonnet 4.6** (기본) | 충분히 잘 해요, 빠르고 저렴해요 |
| 복잡한 아키텍처 설계 | **Opus 4.8** | 깊은 생각이 필요한 작업 |
| 긴 에이전트 자동화 작업 | **Opus 4.8** | 장시간 일관성이 핵심 |
| `/ultrathink` 키워드와 함께 | **Opus 4.8** | 확장 사고(Extended Thinking) 최대 활용 |
| 비용이 중요한 상황 | **Sonnet 4.6** | 좋은 성능에 저렴한 비용 |
| 빠른 응답이 필요 | **Fast Mode** | 속도 우선 |

> 💡 Claude Code는 기본적으로 작업의 복잡도에 따라 자동으로 적절한 모델을 선택해줘요. 직접 지정하지 않아도 돼요.

## Haiku 4.5는 어떻게 됐나요?

Opus 4.8과 함께 **Haiku 4.5**도 계속 사용 가능해요. Claude Code 모델 라인업:

| 모델 | 특징 | 언제 사용 |
|------|------|-----------|
| **Opus 4.8** | 최고 성능 | 복잡한 작업, 긴 에이전트 |
| **Sonnet 4.6** | 균형형 | 일반적인 코딩 작업 |
| **Haiku 4.5** | 경량·빠름 | 간단한 질문, 비용 절약 |

---

## 실제로 이런 점이 좋아졌다는 게 느껴지나요?

공식 발표 기준으로, 다음 상황에서 체감 차이가 클 거예요:

1. **긴 리팩토링 작업**: 100개 파일을 수정하는 도중 처음 세운 규칙을 잊어버리지 않아요
2. **복잡한 버그 추적**: 3~4단계 이상 들어간 원인도 더 잘 찾아줘요
3. **/ultrathink 사용 시**: 더 깊고 체계적인 분석을 해줘요
4. **긴 에이전트 루프**: 수십 번 도구를 써야 하는 작업에서 일관성 유지가 더 잘 돼요

> ⚠️ 개인 체감 차이는 다를 수 있어요. Anthropic 공식 발표 기준의 내용이에요.
