## Opus 4.8이 뭐가 달라졌나요?

2026년 5월 28일, Anthropic이 **Claude Opus 4.8**을 출시했어요.

> 🍱 **비유로 설명하면**: Opus 4.7이 "코딩도 잘하고 글도 잘 쓰는 반장"이었다면, Opus 4.8은 "그 반장이 이번에 코딩 경시대회까지 1등을 차지한" 버전이에요. 특히 코딩·에이전트 자동화 작업과 긴 작업을 끝까지 일관성 있게 이어가는 능력이 눈에 띄게 향상됐습니다.

### 주요 개선 분야 (공식 발표 기준)

| 분야 | 설명 |
|---|---|
| 💻 코딩 성능 | 코드 작성·디버깅·리팩토링 전반 향상 |
| 🤖 에이전트 작업 | 긴 흐름의 자동화 작업에서 일관성 강화 |
| 💼 전문 업무 | 문서 분석, 복잡한 계획 수립 등 개선 |
| ⏱️ 장시간 작업 | 여러 단계에 걸쳐도 품질 유지 |

## 어떤 요금제에서 쓸 수 있나요?

Opus 4.8은 기존 Opus 4.7이 기본이었던 자리를 대부분 이어받았어요. `[공식 발표 기준]`

| 요금제 | Opus 4.8 포함 여부 |
|---|---|
| **Pro** ($17~20/월) | ✅ Sonnet 4.6과 함께 포함 |
| **Max 5x** ($100/월) | ✅ 기본 모델 |
| **Max 20x** ($200/월) | ✅ 기본 모델 |
| **Team Premium** | ✅ 기본 모델 |
| **Enterprise** (소비형) | ✅ 기본 모델 |
| **Anthropic API** | ✅ 기본 모델 |

> 📌 Opus 4.8은 기본적으로 **high effort** 모드로 실행돼요.

## Claude Code에서 어떻게 쓰나요?

### 먼저 버전 업데이트

Opus 4.8은 **v2.1.154 이상**에서만 작동해요:

```bash
claude update
```

### 모델 전환

```
> /model claude-opus-4-8
```

또는 모델 선택 화면(Model picker)에서 선택할 수 있어요.

### Effort(노력도) 조절

Opus 4.8의 기본값은 `high`예요. 더 어려운 작업에는 `xhigh`로 올릴 수 있어요:

```
> /effort xhigh
```

> 🍱 **비유**: `high`가 "열심히 공부하는 학생"이라면, `xhigh`는 "시험 전날 밤새 모든 문제를 풀어보는 학생"이에요. 결과는 더 좋지만 시간과 토큰 비용이 더 들어요.

## Fast mode(패스트 모드) 요금이 대폭 낮아졌어요!

Fast mode는 같은 Opus 모델을 약 2.5배 빠르게 실행하는 기능이에요. Opus 4.8 출시와 함께 **요금이 크게 인하**됐습니다:

| 모델 | Fast mode 요금 (입력/출력, 백만 토큰당) | 상태 |
|---|---|---|
| Opus 4.6 | $30 / $150 | 🚫 **지원 종료 (Deprecated)** |
| Opus 4.7 | $30 / $150 | 여전히 사용 가능 |
| **Opus 4.8** | **$10 / $50** ← **70% 인하!** | ✅ **기본** |

Fast mode 켜기:

```
> /fast
```

> 📌 Fast mode는 Pro·Max 리서치 프리뷰(research preview) 또는 소비 기반(consumption-based) 플랜에서 이용 가능해요.

---

## 기존 Opus 4.7은 어떻게 되나요?

Opus 4.7은 당장 사라지지 않아요. 원한다면 계속 쓸 수 있어요:

```
> /model claude-opus-4-7
```

다만 Fast mode의 **기본값은 Opus 4.8**로 전환됐고, Opus 4.6 Fast mode는 지원이 종료됐으니 참고하세요.
