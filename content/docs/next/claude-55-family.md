## 한 달 만에 모델 세 개? 무슨 일이죠?

2026년 9~10월 사이에 Anthropic이 **5.5 패밀리** 세 모델을 연달아 발표했어요. 이전 5 패밀리보다 가격이 내려가고 속도는 빨라진 업그레이드 버전들입니다.

> 🎁 비유하자면, 작년 스마트폰에 더 나은 카메라와 배터리를 달고 출시 가격은 낮춘 "2026년형 모델"이에요.

| **Claude Haiku 5.5** | 2026-10-07 | 소형·고속·대용량 처리용 | 역대 가장 빠른 소형 모델 |

## 1️⃣ Claude Opus 5.5 — 코딩과 지식 업무의 최강자

### 어떤 모델인가요?
Opus는 Claude 라인업에서 **가장 강력한 모델**이에요. 복잡한 코딩 작업, 오랜 시간이 걸리는 에이전트 작업, 깊이 있는 분석에 쓰입니다.

### Opus 5.5의 달라진 점
- **에이전트 코딩 1위** (공식 발표 기준) — Claude Code와 함께 쓸 때 더욱 강력
- **비용 40% 절감** — 같은 작업을 Opus 5보다 훨씬 저렴하게 처리

> 💡 **입문자 꿀팁**: Claude Code에서 `/fast` 모드를 켜면 Opus 5.5를 더 빠른 속도로 사용할 수 있어요. 이제 Fast Mode도 Opus 5.5 기준으로 작동합니다.

---

## 2️⃣ Claude Sonnet 5.5 — 빠르고 경제적인 범용 모델

### 어떤 모델인가요?
Sonnet은 "속도와 성능의 균형"을 맞춘 모델이에요. 대부분의 일상적인 개발 작업에 적합합니다.

### Sonnet 5.5의 달라진 점
- **30% 이상 빠름** — 응답이 훨씬 빠릿빠릿해졌어요
- **비용 최대 30% 절감** — 많이 쓸수록 절약 효과 큼
- 현재 Claude Code의 **기본 모델**로 계속 활용됨

> 🚀 비유하자면, 기존 패밀리카가 연비는 더 좋아지고 가속도 빨라진 느낌이에요.

---

## 3️⃣ Claude Haiku 5.5 — 더 빠르고 똑똑해진 소형 모델

### 어떤 모델인가요?
Haiku는 세 모델 중 **가장 작고 빠른** 모델이에요. 요약, 서브에이전트 처리, 브라우저 작업처럼 대용량·반복 작업에 최적화됐어요.

### Haiku 5.5의 달라진 점
- **역대 가장 빠른 소형 모델** (공식 발표 기준)
- 요약, 서브에이전트, 브라우저 사용에 특화
- 가성비 최고 — 많은 양을 처리할 때 적합

> 🏎️ 비유하자면, 가볍고 빠른 오토바이 같은 모델이에요. 짐을 많이 실을 순 없지만 좁은 길을 쌩쌩 달려요.

---

## 어떤 모델을 써야 할까요?

```
📌 선택 가이드 (Claude Code 사용자 기준)

복잡한 코딩 작업 (멀티스텝, 에이전트 작업) → Opus 5.5
일반 코딩·질문·수정 작업 (기본값) → Sonnet 5.5
빠른 처리, 대량 반복 작업 → Haiku 5.5
```

### Claude Code에서 모델 변경하기

```bash
# 설정에서 모델 변경
/config
```

또는 대화 중에:

```bash
# Opus로 전환
/model opus

# Haiku로 전환
/model haiku
```

## Fast Mode도 함께 업데이트됐어요

Fast Mode는 이제 **Opus 5.5**를 기반으로 고속 실행해요.

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|------|-----------------|-----------------|
| 모델 | Opus 4.8 | Opus 5.5 |
| 가격 | $30/$150 (1M 토큰) | **$8/$40 (1M 토큰)** |
| 속도 배수 | 2.5배 | 2.5배 |

> 💰 Fast Mode 가격이 $30/$150에서 **$8/$40로 대폭 인하**됐어요! 소비 기반 플랜(API, Console) 사용자에게 반가운 소식입니다.
