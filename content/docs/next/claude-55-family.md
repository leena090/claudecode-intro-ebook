## 한 눈에 보는 Claude 5.5 패밀리

2026년 9월~10월, Claude 모델 전 라인이 **5.5 버전**으로 업그레이드됐어요.

> 🍱 **비유**: 작년에 나온 스마트폰(5)이 1년 만에 개선판(5.5)으로 돌아왔어요. 같은 브랜드인데 속도가 빠르고 가격이 내려갔죠.

| 모델 | 출시일 | 핵심 특징 |
|---|---|---|
| **Claude Mythos + Fable 5.1** | Sep 15, 2026 | 코딩·지식 업무 세계 최고 수준 + 과학 연구 역량 |
| **Claude Opus 5.5** | Sep 22, 2026 | 에이전트 코딩·지식 업무 1위, **Opus 5 대비 40% 저렴** |
| **Claude Sonnet 5.5** | Sep 28, 2026 | Sonnet 5 대비 **30%+ 빠름, 최대 30% 저렴** |
| **Claude Haiku 5.5** | Oct 7, 2026 | 가장 빠른 소형 모델, 대량 처리에 최적화 |

## Claude Mythos + Fable 5.1 — 최상위 계층 업그레이드 (9/15)

### 무엇이 달라졌나요?

**Mythos**와 **Fable 5.1**은 Claude 모델 중 최상위 계층이에요. 2026년 9월 15일, 두 모델이 동시에 발표됐어요.

> 🍱 **비유**: 아이폰 라인에서 "Pro Max" 위에 "Ultra" 모델이 새로 나온 것처럼, Claude도 기존 최상위보다 한 단계 더 높은 모델이 나왔어요.

| 항목 | 내용 |
|---|---|
| **강점** | 코딩 + 지식 업무에서 세계 최고 수준 |
| **특이점** | 과학 연구 역량 미리 보기 포함 |
| **Claude Code에서** | Fable 5.1 — 복잡한 장기 코딩 프로젝트에 활용 |

## Claude Opus 5.5 — 에이전트 코딩 새 왕좌 (9/22)

### 핵심 요약

**Opus 5.5** (`claude-opus-5-5`)는 **에이전트 코딩과 지식 업무에서 1위**를 차지하면서도, Opus 5보다 **40% 저렴**해졌어요.

> 🍱 **비유**: 기존 최고급 노트북보다 성능은 올라가고 가격은 내려갔어요. 같은 돈으로 더 좋은 걸 살 수 있게 된 셈이에요.

| 항목 | Opus 5 | **Opus 5.5** |
|---|---|---|
| 에이전트 코딩 | 최상 | **더 높음** |
| 지식 업무 | 최상 | **더 높음** |
| 운영 비용 | 기준 | **40% 절감** |
| Fast Mode | $30/$150 | **$8/$40** per M tokens |

### Fast Mode 가격 변경 ⚠️

기존에는 Fast Mode가 Opus 4.8 기준 **$30/$150**이었어요. 이번 업데이트로 Opus 5.5 기준 **$8/$40**으로 대폭 내려갔습니다 (공식 확인: 2026-10-28).

```
Fast Mode (Opus 5.5)

  속도: 일반 모드보다 2.5배 빠름
  이용: 소비 기반 플랜(Consumption-based) 또는 구독 크레딧
```

## Claude Sonnet 5.5 — 기본 모델 업그레이드 (9/28)

### 핵심 요약

**Sonnet 5.5** (`claude-sonnet-5-5`)는 Sonnet 5를 **뚜렷하게 앞서면서** 더 빠르고 저렴해졌어요.

> 🍱 **비유**: "에이스 직원"이 더 빨라지고 비용도 줄었어요. Claude Code 일상 작업에서 가장 많이 만날 모델이에요.

| 항목 | Sonnet 5 | **Sonnet 5.5** |
|---|---|---|
| 성능 | 최전선 | **뚜렷한 향상** |
| 속도 | 빠름 | **30%+ 더 빠름** |
| 비용 | 기준 | **최대 30% 절감** |

## Claude Haiku 5.5 — 빠른 소형 모델 업그레이드 (10/7)

### 핵심 요약

**Haiku 5.5** (`claude-haiku-5-5`)는 **가장 빠른, 가장 유능한 소형 모델**이에요. 요약·서브에이전트·브라우저 사용(browser use) 같은 **대량 처리 작업**에 최적화됐어요.

> 🍱 **비유**: 서울 시내 배달을 전담하는 빠른 오토바이 배달원 — 짐(작업)이 무겁지 않을 때는 이쪽이 훨씬 효율적이에요.

| 용도 | Haiku 5.5 적합? |
|---|---|
| 서브에이전트(하위 AI) 실행 | ✅ 최적 |
| 긴 문서 요약 반복 처리 | ✅ 최적 |
| 웹 브라우저 자동화 | ✅ 최적 |
| 복잡한 코드 리팩토링 | ❌ Sonnet/Opus 사용 |

## 어떻게 해야 하나요?

**일반 사용자 (Pro/Max)**
- 특별히 설정할 필요 없어요. Claude Code가 자동으로 최신 모델을 씁니다.

**설정 바꾸고 싶은 분**
```json
// claude.json (CLAUDE.md 옆에 두거나 ~/.claude/ 안에)
{
  "model": "claude-opus-5-5"
}
```

**비용이 걱정되는 분**
- Sonnet 5.5: 일반 코딩 작업에 충분하고 저렴해요.
- Haiku 5.5: 반복되는 단순 작업은 여기에 맡기면 비용이 크게 줄어요.
