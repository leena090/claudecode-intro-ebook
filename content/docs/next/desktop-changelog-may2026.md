## 데스크톱 앱 전용 체인지로그가 생겼어요

Claude Code에는 두 가지 업데이트 흐름이 있어요.

| 구분 | 체인지로그 위치 | 주로 다루는 내용 |
|---|---|---|
| **CLI (터미널 명령어)** | `/en/changelog` | claude 명령어, 모델, API 동작 |
| **데스크톱 앱 UI** | `/en/desktop-changelog` *(← 이번에 신설)* | 앱 창, 코드 탭, 예약 작업, SSH |

> 🍱 **비유로 설명하면**: CLI 체인지로그는 "요리 레시피(조리법)가 바뀐 것"이고, 데스크톱 앱 체인지로그는 "주방 도구(냄비·칼·화구)가 바뀐 것"이에요. 둘 다 챙겨봐야 해요.

## ★ 한국어 사용자 최우선 — IME 버그 수정 (v1.7196.0)

이게 제일 중요한 소식이에요.

이전까지 Claude Code 데스크톱 앱에서 **한국어 입력기(IME)**를 쓰면 **Quick Entry(빠른 입력창)에서 글자가 씹히거나 사라지는** 버그가 있었어요. 일본어·중국어 입력기도 같은 문제였고요.

**v1.7196.0(2026-05-12)부터 이 버그가 수정됐어요.** 이제 한국어로 프롬프트를 쓸 때 글자가 씹히지 않아요.

> 🍱 **비유로 설명하면**: 한국어 자판으로 "안녕하세요"를 입력했는데 "안안하" 처럼 반토막이 나서 올라가던 문제예요. 이제 "안녕하세요"가 제대로 올라가요.

```
Quick Entry 열기: Cmd+Shift+Space (macOS) / Ctrl+Shift+Space (Windows)
```

## 멀티탭 터미널 (v1.5220.0, 4월 28일)

데스크톱 앱 터미널 창에서 이제 **탭을 여러 개** 열 수 있어요.

- 터미널 창 헤더의 **`+`** 버튼으로 새 탭 추가
- 채팅에서 폴더 우클릭 → **Open in terminal** 로 그 폴더에서 바로 새 탭 열기

> 🍱 **비유로 설명하면**: 예전엔 터미널 창이 탭이 하나짜리 책이었어요. 이젠 탭 여러 개짜리 바인더가 됐어요. 앞에선 서버 돌리고, 뒤에선 로그 확인하고.

```
활용 예:
탭 1: npm run dev  (개발 서버 실행)
탭 2: git log (커밋 내역 확인)
탭 3: cd test_folder && pytest (테스트 실행)
```

## 세션 완료 OS 알림 (v1.6889.0, 5월 8일)

Claude Code가 긴 작업을 끝냈을 때 **컴퓨터 알림창(OS notification)** 이 뜨게 됐어요. 앱 화면을 보고 있지 않아도 알 수 있어요.

> 🍱 **비유로 설명하면**: 세탁기 돌려놓고 TV 보다가 "삐-" 하는 소리에 세탁이 끝난 걸 아는 것과 같아요.

---

## "항상 허용" 권한이 이제 기억돼요 (v1.6259.0, 5월 5일)

도구 사용 허가 창에서 **"Always allow(항상 허용)"** 를 클릭하면, 이제 **앱을 껐다가 켜도** 그 설정이 유지돼요. 예전엔 재시작하면 다시 물어봤거든요.

```
허용 범위:
- 이 세션만 (기존)
- 이 프로젝트에서 항상 허용 (기존)
- ★ 앱 재시작 후에도 항상 허용 (신규 — 이제 지속됨)
```

---

## 아카이브 세션에서 메시지 보내면 자동 복원 (v1.6608.0, 5월 7일)

실수로 **아카이브(보관)** 처리한 Code 세션에 메시지를 보내면, 이제 **자동으로 복원**돼요. 따로 "언아카이브" 버튼을 찾을 필요가 없어요.

---

## PR 바에서 stacked PR도 한눈에 (v1.6259.0, 5월 5일)

데스크톱 앱 Code 탭의 **PR 바**에서 이제 현재 브랜치의 PR뿐 아니라 **stacked PR(쌓인 PR)**과 형제 PR도 함께 표시돼요. 여러 작업을 병렬로 진행할 때 상태를 한눈에 볼 수 있어요.

---

## 버전 확인과 업데이트 방법

```
macOS: 메뉴 막대 → Claude → About Claude → 버전 확인
Windows: 시스템 트레이 → 우클릭 → About
```

**자동 업데이트**: 기본적으로 자동 업데이트가 켜져 있어요. 앱이 백그라운드에서 새 버전을 다운로드하고, 재시작 시 적용돼요.

> 🍱 **비유로 설명하면**: 스마트폰 앱처럼 알아서 업데이트돼요. 다만, 실제로 적용되려면 앱을 한 번 껐다 켜야 해요.
