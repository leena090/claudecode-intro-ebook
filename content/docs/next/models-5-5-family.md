## 세 모델이 한꺼번에?

2026년 9~10월, 약 2주 간격으로 **Claude 5.5 패밀리** 3종이 출시됐습니다.

> 🚌 **비유로 설명하면**: 같은 버스 회사에서 **급행(Opus)·일반(Sonnet)·마을버스(Haiku)** 를 동시에 신형으로 바꾼 것과 같아요. 각 버스는 목적이 달라도, 전부 이전 세대보다 연비(비용) 좋고 더 빨라졌습니다.

## 각 모델 자세히

### 🔵 Claude Opus 5.5 — 에이전트 코딩의 왕

**"에이전트 코딩 및 지식 업무에서 선두"**

- Opus 5 대비 **40% 저렴** — 성능은 유지하면서 비용이 크게 낮아졌습니다
- 장시간 멀티스텝 코딩 태스크에 최적화
- Fast Mode(고속 모드)의 기준 모델: **$8/$40 per million tokens** (리서치 프리뷰)

> 📌 **Fast Mode 가격 갱신**: 이전 Opus 4.8 Fast Mode는 $30/$150였는데, Opus 5.5로 전환되며 **$8/$40으로 대폭 낮아졌습니다** (공식 발표 기준 — 추후 변동 가능).

### 🟢 Claude Sonnet 5.5 — 균형의 업그레이드

**"Sonnet 5의 명백한 업그레이드"**

- Sonnet 5 대비 **30% 이상 빠름**
- 대부분의 작업에서 비용 **최대 30% 절감**
- 팀·엔터프라이즈 플랜 기본 모델로 적합

### 🟡 Claude Haiku 5.5 — 빠르고 가볍게

**"가장 빠른 소형 고성능 모델"**

- 요약(Summarization), 서브에이전트, 브라우저 사용 등 **대용량 작업** 특화
- 속도와 비용이 가장 중요한 시나리오에서 권장
- 멀티에이전트 시스템에서 "도우미 에이전트" 역할로 활용

## Claude Code에서 모델 바꾸는 방법

```bash
# 기본 모델 설정 (settings.json)
{
  "model": "claude-opus-5-5"
}

# 명령줄에서 직접 지정
claude --model claude-opus-5-5 "이 코드를 리팩터링해줘"
```

> ⚙️ 더 자세한 모델 설정 방법은 [모델 설정 가이드](/docs/config/model-config)를 참고하세요.

## 어떤 모델을 선택할까?

| 상황 | 추천 모델 |
|------|-----------|
| 복잡한 장시간 코딩 태스크 | Opus 5.5 |
| 일상적인 코딩·리뷰·문서 작업 | Sonnet 5.5 |
| 빠른 답변, 반복 대량 작업 | Haiku 5.5 |
| 비용 절약이 최우선 | Haiku 5.5 → Sonnet 5.5 순 |

## 요금제별 접근

- **Pro / Max**: Sonnet 5.5가 기본, Opus 5.5는 크레딧 소모
- **Team**: Sonnet 5.5 기본, 필요 시 Opus 5.5 선택
- **API (Console)**: 모든 모델 토큰 기반 과금

> 📊 **정리**: 5.5 패밀리 전체가 전 세대 대비 **성능은 올라가고 비용은 내려간** 방향으로 출시됐습니다. Claude Code를 매일 쓰는 분이라면, 모델 설정을 5.5 버전으로 업데이트하는 것만으로도 비용 절감 효과를 바로 볼 수 있어요.
