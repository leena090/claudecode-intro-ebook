## Claude Mythos · Fable 5.1 — 최정상 모델 (Sep 15)

**공식 발표 기준**, Mythos와 Fable 5.1은 현재 세계에서 가장 앞선 코딩·지식 작업 모델이라고 해요.

> 🔬 **특징**: 연구 기능을 초기 형태로 제공 — AI 모델이 과학적 발견에 기여하는 첫 모습이에요.

- **Mythos**: 복잡한 추론이 필요한 고급 작업에 최적
- **Fable 5.1**: 2026년 6~12월 사이 출시된 Fable 시리즈 최신판

> ⚠️ **주의**: Mythos는 특수 프로그램(생명과학 검증 등) 가입자에게만 일부 제공될 수 있어요. 일반 플랜 사용자는 Opus 5.5를 사용합니다.

## Claude Opus 5.5 — 에이전트 코딩의 새 기준 (Sep 22)

**공식 발표 기준:**

- **에이전트 코딩·지식 작업** 최고 성능
- **Opus 5보다 40% 저렴** — 같은 작업에 비용이 크게 줄어요
- 긴 멀티스텝 작업에 강함

> 💼 **실용적으로 말하면**: 하루 종일 코드를 짜게 맡기는 에이전트 작업에서 "성능은 최고, 비용은 현실적"인 선택지가 됐어요.

## Claude Sonnet 5.5 — 더 빠르고 더 저렴하게 (Sep 28)

**공식 발표 기준:**

- **Sonnet 5보다 30% 이상 빠름**
- **대부분 작업에서 최대 30% 저렴**
- 이미 뛰어난 Sonnet 5를 명확히 뛰어넘는 업그레이드

> ⚡ **Claude Code에서**: Sonnet 5.5는 일반 작업의 기본 모델로 자리 잡고 있어요. 빠른 반응 속도와 적당한 비용의 균형이 좋습니다.

---

## Claude Haiku 5.5 — 초고속 소형 모델 (Oct 7)

**공식 발표 기준:**

- **가장 빠르고 가장 유능한 소형 모델**
- 요약, 서브에이전트, 브라우저 사용 등 **대량 처리 작업에 최적**
- 반복적이고 많은 양의 작업을 저렴하게 처리

> 🏃 **비유로 설명하면**: Haiku 5.5는 마라토너가 아닌 단거리 달리기 선수예요. 짧은 작업을 번개처럼 빠르게, 많이 처리합니다. 여러 에이전트가 동시에 작은 작업을 처리할 때 특히 유리해요.

## Fast Mode 가격 대폭 인하 🎉

**가장 반가운 소식**: Fast Mode 요금이 크게 낮아졌어요.

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|------|----------------|----------------|
| 대상 모델 | Opus 4.8 | **Opus 5.5** |
| 입력 토큰 | $30/백만 | **$8/백만** |
| 출력 토큰 | $150/백만 | **$40/백만** |
| 속도 | 2.5배 빠름 | 2.5배 빠름 |

> 💡 **공식 발표 기준**: Fast Mode는 리서치 프리뷰 상태이며, 소비 기반 플랜(Consumption-based)에서 사용 가능해요. 구독 플랜은 사용 크레딧 차감 방식.
