## Claude Opus 5.5 — 에이전틱 코딩 왕좌

### 무엇이 달라졌나요?

**Claude Opus 5.5** (`claude-opus-5-5`)는 에이전틱 코딩과 지식 업무에서 1위를 차지하면서도 **기존 Opus 5보다 40% 저렴**해진 모델이에요.

> 🍱 **비유로 설명하면**: 최고급 요리사가 같은 솜씨로 요리하는데 재료비가 40% 줄었어요. 맛은 그대로(오히려 개선), 비용만 내려간 것이죠.

### 주요 특징

| 항목 | 내용 |
|---|---|
| **모델 ID** | `claude-opus-5-5` |
| **강점** | 에이전틱 코딩, 지식 업무, 복잡한 추론 |
| **비용** | Opus 5 대비 **40% 절감** |
| **Fast Mode** | Opus 5.5 고속 버전: **$8/$40** per M tokens |

### Fast Mode 가격 변경 ⚠️

Fast Mode가 **Opus 4.8 기준 $30/$150**에서 **Opus 5.5 기준 $8/$40**으로 변경됐어요. 더 강한 모델로 더 저렴하게 쓸 수 있게 된 것이에요.

> **추정**: 마케팅 페이지 기준이며, 실제 과금은 Console에서 확인하세요.

## Claude Sonnet 5.5 — 균형형 업그레이드

### 무엇이 달라졌나요?

**Claude Sonnet 5.5** (`claude-sonnet-5-5`)는 Sonnet 5의 직접 업그레이드 버전이에요.

> 🍱 **비유로 설명하면**: 이미 쓸만한 스마트폰을 최신형으로 바꿨더니 같은 가격에 더 빠르고 더 싸졌어요.

### 주요 특징

| 항목 | 내용 |
|---|---|
| **모델 ID** | `claude-sonnet-5-5` |
| **속도** | Sonnet 5보다 **30% 이상 빠름** |
| **비용** | 대부분 작업에서 **최대 30% 저렴** |
| **위치** | 성능과 속도의 균형 — 일반 용도 추천 |
