## Anthropic, 드디어 한국에 왔어요! 🇰🇷

## Claude Code를 쓰는 우리한테 왜 중요한가요?

Claude Code를 만든 회사가 한국에 직접 들어온다는 건, 한국어 사용자·한국 기업에 더 가까워진다는 뜻이에요.

- 한국어 Claude Code 문서 품질이 올라갈 수 있어요
- 한국 기업 API 계약·엔터프라이즈 도입이 쉬워져요
- 한국 개발자 커뮤니티 행사에서 Anthropic을 만날 수 있어요
