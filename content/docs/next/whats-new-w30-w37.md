## 🔄 /resume — 터미널 세션을 데스크톱에서 이어받기 (W35, 2026-08-24)

터미널에서 시작한 Claude Code 세션을 **데스크톱 앱에서 그대로 이어받을 수 있어요**. 마치 스마트폰에서 보던 영상을 TV로 이어보는 것처럼요.

```bash
# 데스크톱 앱 프롬프트에서
/resume
# → 이전 세션 목록 표시 → 선택하면 이어서 진행
```

세션을 제목·폴더·브랜치로 검색하고, 미리보기로 어디까지 했는지 확인한 뒤 불러올 수 있습니다.

## 📝 Claude가 피드백 초안을 대신 써줘요 (W35, 2026-08-24)

도구가 계속 실패하거나, 실수를 지적했을 때 Claude가 **자동으로 버그 리포트 초안**을 작성합니다. 프롬프트 위에 카드로 나타나고, 검토 후 전송하거나 무시할 수 있어요.

```bash
/feedback
# → 자동 작성된 피드백 초안 목록 확인
```

Anthropic에 보내기 전까지 아무것도 전송되지 않으니 걱정하지 않아도 됩니다.

## 🔒 Restricted mode — 안전한 평가 환경 (W35, 2026-08-24)

평가(eval) 하네스나 공용 머신에서 Claude Code를 돌릴 때 쓰는 **제한 모드**입니다. 명령 실행·코드 실행 도구가 비활성화되고, 파일 도구는 작업 디렉터리 안으로만 제한됩니다.

```bash
# 제한 모드로 실행
claude --restricted -p "이 코드에서 SQL 인젝션 위험 찾아줘"

# 환경 변수로 설정
CLAUDE_CODE_RESTRICTED=1 claude ...
```

## 🧪 Plugin eval — 플러그인을 테스트 케이스로 검증 (W37, 2026-09-07)

플러그인을 배포하기 전에 **자동화된 평가 스위트**로 테스트할 수 있게 됐어요. 테스트 케이스를 직접 만들 필요 없이 Claude가 제안해주고, 점수도 채점해줍니다.

```bash
# 플러그인 루트 디렉터리에서
claude plugin eval init    # Claude가 테스트 케이스 초안 작성
claude plugin eval .       # 모든 케이스 실행 → 점수표 출력
```

결과는 `evals/results/report.html`에 상세 리포트로 저장됩니다.

## 🪟 데스크톱 패널 팝아웃 (W37, 2026-09-07)

Claude Code Desktop에서 diff 뷰나 터미널 패널을 **별도 창으로 꺼낼 수 있어요**. 듀얼 모니터 환경이라면 한 화면엔 대화, 다른 화면엔 코드 diff를 띄워놓을 수 있습니다.
