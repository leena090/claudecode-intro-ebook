## ⭐ W32 하이라이트 (2026년 8월 3~7일)

W32는 이 기간 중 가장 큰 변화가 있었던 주간이에요.

### 1. Auto mode가 기본값으로 바뀌었어요

```
이전: Claude Code 실행 시 수동 허가 모드가 기본값
지금: Auto mode가 Pro, Max, Team 플랜 기본값으로 전환 (2026-08-07)
```

**Auto mode란?**  
Claude가 작업 중 허가를 덜 요청하고 더 자율적으로 움직이는 모드예요. 단, 위험한 명령어(파일 삭제, 외부 전송 등)는 여전히 확인을 거칩니다.

> 🚗 비유하자면, 이전엔 운전할 때마다 "차선 변경해도 될까요?"를 물어봤는데, 이제는 알아서 차선을 바꾸되 위험한 상황만 물어보는 식이에요.

**Auto mode 되돌리기**:
```bash
# 수동 모드로 전환하고 싶다면
/config
# 또는 대화 중에
"허가 모드로 바꿔줘"
```

**배경 안전 장치**: Auto mode에는 위험한 작업을 감지하는 안전 분류기가 내장돼 있어요. 완전히 혼자 달리는 게 아니라, 필요할 때는 꼭 멈추는 구조입니다.

### 2. Self-hosted 환경 공개 베타 시작

```
발표일: 2026-08-06
상태: Public Beta (공개 베타)
```

이제 **회사 내부 서버에서 직접 Claude Code 세션을 실행**할 수 있어요.

**어떤 경우에 쓰나요?**
- 회사 보안 정책상 외부 클라우드 사용이 제한될 때
- 사내 네트워크에서만 접근 가능한 내부 서비스와 함께 쓸 때
- 데이터가 외부로 나가면 안 되는 금융·의료·법무 분야

> 🏢 비유하자면, 이전엔 카페(클라우드)에서만 일할 수 있었는데, 이제 회사 사무실(내부 서버)에서도 동일한 도구로 일할 수 있게 된 거예요.

**사용 조건**: Team 또는 Enterprise 플랜 + 별도 인프라 설정 필요 (공식 문서 참조).
