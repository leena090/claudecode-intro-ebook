### 1️⃣ /cd — 세션 유지한 채로 작업 폴더 이동 📁

새 명령어 `/cd`가 추가됐어요. Claude와의 대화(세션)를 처음부터 다시 시작하지 않고도, **작업 디렉토리(폴더)를 바꿀 수 있어요**.

```bash
# 현재 프로젝트 폴더에서 다른 폴더로 이동
/cd ../another-project

# 절대 경로로 이동
/cd /home/user/my-new-project
```

> 🍱 **비유**: 전화 통화를 끊지 않고도 "잠깐만요, 다른 방에서 이야기할게요" 하고 장소를 바꾸는 것과 같아요. Claude와의 대화는 유지되면서 작업하는 프로젝트만 바뀌어요.

**언제 유용할까요?**

| 상황 | 예시 |
|------|------|
| 여러 프로젝트 작업 | A 프로젝트 마무리 후 B 프로젝트로 이동 |
| 하위 폴더 집중 | 루트에서 시작 → 특정 패키지 폴더로 이동 |
| 모노레포 내 이동 | `packages/api` → `packages/frontend` |

<div class="note-circle">
○ <code>/cd</code>는 세션 대화 내용은 그대로 유지해요<br />
○ 이동 후 Claude는 새 폴더의 CLAUDE.md와 설정을 다시 로드해요
</div>

### 2️⃣ 서브에이전트 중첩 — 에이전트가 에이전트를 만들다 🤖🤖

이제 **서브에이전트(Subagent, 서브에이전트)가 직접 자신의 서브에이전트를 만들 수 있어요**. 예전엔 Claude 메인만 서브에이전트를 만들 수 있었는데, 이제는 계층 구조가 가능해졌어요.

> 🍱 **비유**: 팀장(메인 Claude)이 팀원A(서브에이전트)에게 일을 맡겼더니, 팀원A도 알아서 인턴(서브에이전트의 서브에이전트)을 쓸 수 있게 된 거예요. 더 복잡한 일을 더 체계적으로 나눌 수 있어요.

**어떤 작업이 가능해질까요?**

```
메인 Claude
├── 서브에이전트 A (백엔드 분석)
│   ├── 서브에이전트 A1 (DB 스키마 검사)
│   └── 서브에이전트 A2 (API 보안 검토)
└── 서브에이전트 B (프론트엔드 분석)
    ├── 서브에이전트 B1 (컴포넌트 리뷰)
    └── 서브에이전트 B2 (성능 분석)
```

| 이전 | 이후 |
|------|------|
| 메인만 서브에이전트 생성 가능 | 서브에이전트도 서브에이전트 생성 가능 |
| 2단계(메인→서브) | 다단계 계층 가능 |
| 큰 작업은 메인이 직접 분배 | 서브에이전트가 자율적으로 재분배 |

<div class="note-circle">
○ Dynamic Workflows (다이나믹 워크플로)와 함께 쓰면 더욱 강력해요<br />
○ 대규모 코드 감사, 복잡한 마이그레이션 등에서 활용 가능
</div>

### 3️⃣ Safe Mode — 설정이 꼬였을 때 비상구 🛟

Claude Code를 열어봤더니 **훅(Hook)·MCP·설정 등이 꼬여서 시작조차 안 되는 상황**이 생길 수 있어요. 이럴 때 쓰는 **Safe Mode(세이프 모드)**가 추가됐어요.

```bash
# Safe Mode로 실행
claude --safe-mode
```

> 🍱 **비유**: 컴퓨터가 부팅이 안 될 때 F8 눌러서 '안전 모드'로 들어가는 것처럼요. 불필요한 것들 다 내려놓고 최소한으로만 켜서 무엇이 문제인지 진단할 수 있어요.

**Safe Mode에서 달라지는 점:**

| 항목 | 일반 모드 | Safe Mode |
|------|-----------|-----------|
| CLAUDE.md | 로드 O | 스킵 |
| 훅(Hooks) | 실행 O | 비활성 |
| MCP 서버 | 연결 O | 비활성 |
| 스킬/플러그인 | 로드 O | 비활성 |
| 기본 도구 | 사용 O | 사용 O |

**이런 상황에 쓰세요:**

```bash
# 상황 1: Claude Code가 시작할 때 오류 발생
claude --safe-mode
# → 최소 환경으로 실행 → 원인 파악

# 상황 2: 특정 훅이 계속 충돌할 때
claude --safe-mode
/hooks  # 어떤 훅이 문제인지 확인
/doctor # 전체 설정 진단
```

<div class="note-circle">
○ Safe Mode는 진단용이에요 — 평소엔 일반 모드로 사용<br />
○ 문제 찾은 후엔 다시 일반 모드로 복귀하면 돼요<br />
○ <code>/doctor</code> 명령과 함께 쓰면 원인을 더 빨리 찾을 수 있어요
</div>
