### 1️⃣ `/cd` — 세션을 끊지 않고 다른 폴더로 이동 📂

작업하다가 다른 프로젝트 폴더로 옮기고 싶을 때, 이제 Claude Code를 종료하지 않아도 돼요.

```bash
# 현재 세션에서 바로 다른 폴더로 이동
/cd ../other-project

# 절대 경로도 가능
/cd /home/user/my-new-project
```

> 🍱 **비유**: 회사 사무실에서 일하다가 회의실로 이동할 때, 컴퓨터를 껐다 켜지 않아도 되는 것과 같아요. 자리만 옮기면 작업이 이어져요.

**어떻게 작동하나요?**

| 항목 | 설명 |
|---|---|
| 캐시 유지 | 프롬프트 캐시를 새로 쌓지 않아 비용 절약 |
| CLAUDE.md 처리 | 새 폴더의 CLAUDE.md가 **추가**로 불러와짐 (기존 것 대체 아님) |
| 이력 관리 | 새 폴더의 프로젝트 저장소로 세션이 이동 (나중에 `--resume`으로 재개 가능) |
| 신뢰 확인 | 처음 방문하는 폴더면 "이 폴더 신뢰하시겠어요?" 질문이 나와요 |

<div class="note-circle">
○ 같은 프로젝트 내 다른 모듈로 이동할 때 유용해요<br />
○ 폴더를 옮겨도 이전 대화 맥락은 그대로 유지돼요
</div>

### 2️⃣ 서브에이전트가 서브에이전트를 만들 수 있어요 🤖🤖🤖

Claude Code는 복잡한 작업을 처리할 때 **서브에이전트**(보조 AI)를 생성해요. 이번 업데이트로 그 서브에이전트가 다시 자기 서브에이전트를 만들 수 있게 됐어요.

> 🍱 **비유**: 팀장(Claude)이 직원(서브에이전트)한테 일을 나눠줬는데, 그 직원이 자기 직속 직원들(서브-서브에이전트)한테 또 나눠주는 것과 같아요. 여러 계층으로 동시에 일을 처리하는 거예요.

**최대 5단계까지** 중첩 가능해요. 그 이상은 자동으로 차단돼요.

**진행 상황 보기:**
```bash
/agents
```

서브에이전트 패널에서 중첩 트리 전체를 볼 수 있어요. 각 행에 하위 에이전트 수와 `main`까지의 경로가 표시돼요.

<div class="note-circle">
○ 자동으로 실행되는 기능이에요 — 별도 설정 불필요<br />
○ 대규모 코드베이스 분석이나 복잡한 마이그레이션 작업에서 속도가 빨라져요
</div>

### 3️⃣ `--safe-mode` — 설정 문제 진단용 안전 모드 🩺

Claude Code가 갑자기 이상하게 작동할 때, 어디서 문제가 생겼는지 찾기가 어려웠어요. 이제 **안전 모드**로 시작하면 모든 커스터마이징을 끄고 기본 상태로 실행할 수 있어요.

```bash
# 안전 모드로 시작
claude --safe-mode

# 또는 환경 변수 설정
export CLAUDE_CODE_SAFE_MODE=1
claude
```

> 🍱 **비유**: 스마트폰이 이상하게 작동할 때 "안전 모드"로 부팅해서 기본 앱만 켜보는 것과 같아요. 기본 상태에서는 잘 되면 → 내가 설치한 앱(플러그인/훅) 중 하나가 문제예요.

**안전 모드에서 꺼지는 것들:**

| 꺼짐 | 켜짐 |
|---|---|
| CLAUDE.md 파일 | 로그인 인증 |
| 스킬(Skills) | 모델 선택 |
| 플러그인 | 기본 도구 |
| 훅(Hooks) | 권한 설정 |
| MCP 서버 | |
| 커스텀 명령어·에이전트 | |

**진단 방법:**
1. `claude --safe-mode`로 실행
2. 문제가 없으면 → 커스터마이징 중 하나가 원인
3. 하나씩 다시 켜면서 어디서 문제가 생기는지 확인

### 기타 개선사항

| 항목 | 내용 |
|---|---|
| `fallbackModel` 다중 설정 | 기본 모델 오류 시 최대 3개 대체 모델을 순서대로 시도 |
| 세션 제목 자동 번역 | 한국어로 대화하면 세션 제목도 한국어로 생성됨 |
