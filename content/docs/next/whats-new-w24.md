## 이번 주 핵심 3가지

이번 Week 24는 에이전트 AI의 깊이를 한 단계 더 높인 주간이에요. 서브에이전트가 서브에이전트를 부를 수 있게 됐고, 고장난 설정을 진단할 수 있는 "안전 모드"가 생겼어요.

## 📁 1. /cd — 재시작 없이 작업 폴더 이동 (v2.1.169)

> **"A 프로젝트 작업하다가 B 프로젝트로 넘어가야 하는데, 새로 시작해야 하나요?"** 이제 안 해도 돼요!

새 명령어 `/cd`가 생겼어요. 현재 세션을 끊지 않고 다른 디렉토리로 이동할 수 있어요. 프롬프트 캐시도 유지되고, 이동한 폴더의 `CLAUDE.md`가 메시지로 추가돼요.

```
> /cd ../other-project
> /cd /home/user/another-repo
```

> 🍱 **비유로 설명하면**: 한 회의실에서 다른 회의실로 이동해도 지금까지 나눈 대화 내용을 다 들고 가는 것과 같아요. 대화를 처음부터 다시 시작할 필요 없이 새 장소에서 계속 이어가는 거예요.

**편리한 점:**
- `--resume` / `--continue`로 이어할 때도 이동한 디렉토리 기준으로 찾음
- 처음 가는 폴더라면 신뢰 여부 확인 후 이동

## 🤖 2. 서브에이전트가 서브에이전트를 부른다 (v2.1.172)

> **"Claude가 혼자 일하다가 필요하면 동료를 부르고, 그 동료도 또 동료를 부를 수 있어요."**

이번에 **중첩 서브에이전트(nested subagents)**가 지원됩니다. 서브에이전트(부하 직원)도 자기 서브에이전트를 만들 수 있어요. 최대 **5단계**까지 허용돼요.

```
> /agents  # 에이전트 트리를 한 번에 볼 수 있어요
```

에이전트 패널에서 각 행마다 하위 에이전트 수와 `main`까지의 경로가 표시돼요.

> 🍱 **비유로 설명하면**: "팀장이 팀원에게 일 맡기고, 그 팀원이 또 다른 팀원에게 일 나눠주는" 다단계 위임과 같아요. 복잡한 작업일수록 이 구조가 빛나요. 단, 5단계까지만 허용돼서 무한 반복은 막혀 있어요.

이것이 바로 마케팅 페이지에서 홍보하는 **Dynamic Workflows**의 핵심 기술이에요.

## 🔧 3. --safe-mode — 설정이 꼬였을 때 진단법 (v2.1.169)

> **"이상하게 클로드가 제대로 안 되는데, 내 설정 파일 때문인지 어떻게 알죠?"**

`--safe-mode`(또는 `CLAUDE_CODE_SAFE_MODE` 환경변수)로 시작하면 **모든 커스터마이징이 비활성화**돼요.

**비활성화되는 것들:**
- CLAUDE.md 파일
- Skills, Plugins, Hooks
- MCP 서버
- 커스텀 명령어·에이전트

**계속 작동하는 것들:**
- 인증, 모델 선택
- 기본 내장 도구
- 권한 시스템

```bash
claude --safe-mode        # 안전 모드 시작
# 또는
CLAUDE_CODE_SAFE_MODE=1 claude
```

> 🍱 **비유로 설명하면**: 새 앱 설치 후 컴퓨터가 이상해졌을 때 "안전 모드"로 부팅하면 내 설치 앱 없이 기본 상태로 켜지는 것과 같아요. 안전 모드에서 문제가 없으면 내 커스텀 설정 중 하나가 범인이에요.
