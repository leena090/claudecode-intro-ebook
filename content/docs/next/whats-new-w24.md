### 1️⃣ `/cd` 명령어 — 세션 도중 작업 폴더 바꾸기 📁

세션을 닫고 다시 시작하지 않아도, **대화 도중 작업 디렉토리를 바꿀 수 있어요**.

```bash
# 세션 중 다른 폴더로 이동
/cd ~/projects/backend-api

# 또는
/cd ../frontend

# 확인
/context   ← 현재 디렉토리 포함 컨텍스트 확인
```

**언제 유용한가요?**

> 🍱 **비유로 설명하면**: 이전에는 "주방에서 요리하다가 지하창고 재고 확인하려면 주방을 완전히 나갔다가 다시 들어와야" 했어요. 이제는 주방에서 지하창고로 그냥 이동했다가 다시 돌아올 수 있어요.

| 상황 | 이전 방법 | 이제 |
|------|-----------|------|
| 모노레포에서 frontend→backend 이동 | 세션 종료 후 재시작 | `/cd ../backend` |
| 서로 다른 프로젝트 비교 | 두 터미널 창 | 한 세션에서 `/cd` |
| 특정 파일 찾으러 상위 폴더로 | 다른 터미널 | `/cd ..` |

<div class="note-circle">
○ 이동 후 컨텍스트는 이어서 유지돼요 — 이전 대화 내용은 사라지지 않아요<br />
○ git 워크트리와 함께 쓰면 더 강력해요 → <a href="/docs/advanced/worktrees">워크트리 가이드</a>
</div>

### 2️⃣ 서브에이전트가 서브에이전트를 만든다 — 계층형 멀티 에이전트 🤖🤖🤖

이전까지는 Claude(메인) → 서브에이전트(하위) 1단계 구조였어요. 이제는 **서브에이전트가 직접 자신의 서브에이전트를 생성**할 수 있어요.

```
이전 구조:
Claude (메인)
├── 서브에이전트 A
├── 서브에이전트 B
└── 서브에이전트 C

이제 가능한 구조:
Claude (메인)
├── 서브에이전트 A (분석 담당)
│   ├── 서브에이전트 A-1 (파일 리딩)
│   └── 서브에이전트 A-2 (데이터 집계)
└── 서브에이전트 B (수정 담당)
    ├── 서브에이전트 B-1 (frontend)
    └── 서브에이전트 B-2 (backend)
```

> 🍱 **비유로 설명하면**: 건설 현장 소장(Claude)이 반장(서브에이전트)들에게 일을 나눠주면, 반장이 각자 팀원(하위 서브에이전트)을 부려서 세세한 작업을 처리해요. 지휘 체계가 2단계에서 여러 단계로 깊어진 거예요.

**어떤 작업에 좋을까요?**

| 작업 종류 | 예시 |
|-----------|------|
| 대형 코드베이스 마이그레이션 | 모듈별 서브에이전트 → 각 파일별 하위 에이전트 |
| 전사 테스트 실행 | 기능별 에이전트 → 각 테스트 케이스별 에이전트 |
| 대규모 문서화 | 섹션별 에이전트 → 각 항목 작성 에이전트 |

### 3️⃣ Safe Mode (안전 모드) — 망가진 설정 진단 🛠️

CLAUDE.md나 settings.json, 훅, MCP 서버 등 설정이 잘못돼서 Claude Code가 제대로 안 작동할 때, **안전 모드**로 실행하면 최소한의 설정만 로드해서 원인을 진단할 수 있어요.

```bash
# 안전 모드로 실행
claude --safe-mode

# 또는
claude --safemode
```

**Safe Mode에서는 무엇이 비활성화될까요?**

| 항목 | Safe Mode에서 |
|------|--------------|
| CLAUDE.md 파일 | 로드 안 함 |
| 사용자 정의 훅(hooks) | 비활성화 |
| MCP 서버 연결 | 비활성화 |
| 플러그인 | 비활성화 |
| 기본 내장 기능 | ✅ 정상 작동 |

> 🍱 **비유로 설명하면**: 컴퓨터가 안 켜질 때 "안전 모드"로 부팅해서 어떤 프로그램이 문제를 일으키는지 찾는 것과 똑같아요. Claude Code도 이제 그게 가능해요.

**진단 순서:**

```bash
# 1. 안전 모드로 켠다
claude --safe-mode

# 2. 정상 작동하면 → 내 설정 파일 중 하나가 문제
# 3. /doctor 로 추가 진단
/doctor

# 4. /hooks 로 훅 목록 확인
/hooks
```
