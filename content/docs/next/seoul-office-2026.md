|---|---|

## Claude Code와 한국어 사용

현재 Claude Code는 **한국어로 완전히 대화 가능**해요. 이번 서울 오피스 개설 이후 한국어 지원이 더 강화될 것으로 기대돼요.

**지금 당장 한국어로 쓸 수 있는 것들:**

```
# 한국어로 코드 설명 요청
이 코드가 어떤 역할을 하는지 한국어로 설명해줘.

# 한국어로 에러 해결 요청
이 에러를 고쳐줘. 이유도 한국어로 설명해줘.

# 세션 제목도 한국어로 자동 생성 (Week 24 업데이트)
# 한국어로 대화하면 세션 이름이 자동으로 한국어로 붙여요
```
