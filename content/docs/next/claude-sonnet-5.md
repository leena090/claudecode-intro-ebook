## Sonnet 5(소넷 5)가 뭐예요?

**Sonnet 5**는 2026년 6월 30일 출시된 Claude의 새 모델이에요. 출시와 동시에 **Pro·Team Standard·Enterprise 플랜의 기본 모델**로 지정됐어요.

> 🍱 **비유**: 스마트폰에서 기본 카메라 앱이 더 좋은 버전으로 업그레이드된 거예요. 따로 설정을 바꾸지 않아도 이제 더 좋은 모델을 쓰고 있는 거예요.

---

## 뭐가 달라졌나요?

| 항목 | Sonnet 4.6 (이전) | Sonnet 5 (현재) |
|---|---|---|
| 코딩 성능 | 높음 | **최상위 수준** |
| 컨텍스트 창 | 200K 토큰 | **1M(100만) 토큰** |
| 사고 모드 | 별도 설정 필요 | **어댑티브 씽킹 기본 활성화** |
| 에이전트 작업 | 좋음 | **대폭 향상** |

### 1M 컨텍스트가 얼마나 큰 건가요?

1M 토큰은 영어 소설 약 4권 분량이에요. 한국어로는 대략 60~80만 글자예요.

> 🍱 **비유**: 이전에는 책 한 권 분량의 코드만 한 번에 볼 수 있었는데, 이제는 **책 4~5권 분량의 코드 전체**를 한 번에 보면서 작업할 수 있어요. 큰 프로젝트를 통째로 분석할 때 큰 차이가 나요.

### 어댑티브 씽킹(Adaptive Thinking)이 뭔가요?

클로드가 **문제의 복잡도에 따라 자동으로 사고 깊이를 조절**하는 기능이에요. 간단한 질문엔 빠르게, 복잡한 문제엔 더 깊이 생각해요.

> 🍱 **비유**: 주방장이 간단한 요리는 빨리 만들고, 복잡한 코스 요리는 시간을 들여 정성스럽게 만드는 것처럼요. 이게 이제 **기본값**이에요.

## 어떻게 사용하나요?

이미 Pro/Max/Team/Enterprise 플랜이면 **자동으로** Sonnet 5를 쓰고 있어요. 확인하거나 명시적으로 선택하려면:

```text
# 모델 선택 메뉴에서 선택
> /model

# 직접 Sonnet 5 지정
> /model claude-sonnet-5
```

**최소 버전 확인 필요**: v2.1.197 이상이어야 Sonnet 5가 기본 모델로 적용돼요.

```bash
# 버전 확인
claude --version

# 업데이트
claude update
```

## 어떤 작업에 특히 좋아요?

Sonnet 5는 특히 이런 작업에서 강점을 보여요:

| 작업 유형 | 설명 |
|---|---|
| 🐛 **복잡한 버그 디버깅** | 여러 파일에 걸친 버그도 추적 |
| 🏗️ **대규모 리팩토링** | 1M 컨텍스트로 전체 코드베이스 파악 후 리팩토링 |
| 🤖 **에이전트 작업** | 서브에이전트 조율·다단계 워크플로 |
| 📊 **코드 분석** | 대형 코드베이스 전체 분석 |
| 🔗 **도구 사용(Tool Use)** | 여러 도구를 엮어 복잡한 작업 처리 |

## Sonnet 5 vs 다른 모델

| 모델 | 특징 | 추천 상황 |
|---|---|---|
| **Sonnet 5** (기본) | 최고 성능·1M 컨텍스트 | 대부분의 코딩 작업 |
| Opus 4.8 | 가장 강력한 추론 | 극도로 복잡한 문제 |
| Haiku 4.5 | 빠르고 가볍 | 간단한 반복 작업 |
| Fable 5 / Mythos 5 | 최상위 모델 ⚠️ | 수출통제로 접근 제한 중 |

## 자주 묻는 질문

**Q: 기존에 Sonnet 4.6을 쓰던 설정이 있으면 어떻게 되나요?**
A: `CLAUDE.md`나 settings.json에서 모델을 명시적으로 지정했다면 그 설정이 유지돼요. 기본값만 바뀐 거예요.

**Q: 1M 컨텍스트를 항상 쓰는 건가요?**
A: 필요한 만큼만 써요. 작은 파일 하나를 편집할 때는 전부 쓰지 않아요.

**Q: 홍보 가격이 끝나면 API 가격이 많이 오르나요?**
A: 공식 확정 가격은 2026년 8월 31일 이후 발표 예정이에요. "추정" 처리 — 공식 발표 기준으로 확인하세요.
