## Claude 5.5 시리즈 (Opus·Sonnet·Haiku)

### Opus 5.5 (2026년 9월 22일)
- 에이전트 코딩·지식 작업 분야 1위
- Opus 5 대비 **40% 저렴** (같은 성능에 비용 절감)
- Claude Code의 기본 고성능 모델로 활용

> 💡 **비유**: 최고급 주방장인데 인건비가 40% 줄었어요. 같은 요리 실력에 비용만 낮아진 거예요.

### Sonnet 5.5 (2026년 9월 28일)
- Sonnet 5 대비 명확한 성능 향상
- **30% 이상 빠르고**, 대부분의 작업에서 **최대 30% 저렴**
- 일상적인 코딩 작업에 가장 균형 잡힌 선택

### Haiku 5.5 (2026년 10월 7일)
- 가장 빠르고 가장 저렴한 소형 모델
- 요약·서브에이전트·브라우저 사용 등 **대량 처리 작업** 전용
- 빠른 응답이 필요한 반복 작업에 최적

## Fast Mode — 가격 대폭 인하 🎉

Fast Mode는 Opus 계열을 고속으로 사용하는 옵션이에요. **기준 모델이 Opus 4.8 → Opus 5.5로 바뀌면서 가격도 크게 내려갔어요.**

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|-----|---------------|---------------|
| Input 가격 | $30/백만 토큰 | **$8/백만 토큰** |
| Output 가격 | $150/백만 토큰 | **$40/백만 토큰** |
| 속도 | 2.5배 빠름 | 2.5배 빠름 |
| 플랜 | 소비 기반 | 소비 기반 |

> 🎯 **핵심**: 가격이 무려 **73% 인하**됐어요! 빠른 응답이 필요한 대형 프로젝트에 더 부담 없이 쓸 수 있어요.

Fast Mode 토글 방법:
```
Claude Code에서: /fast
또는 세션 우측 상단의 ⚡ 아이콘 클릭
```

## Fable 5.2 + Mythos 5.2 (2026년 11월 9일)

### 어떤 모델인가요?

Fable 5.2와 Mythos 5.2는 **코딩·금융·과학 분야에서 가장 도전적인 작업**을 위한 최상위 모델이에요.

| 모델 | 특징 |
|-----|-----|
| **Fable 5.2** | 최고급 범용 모델. 코딩·수학·추론 최강 |
| **Mythos 5.2** | Fable 5.2의 특화 버전 (특정 도메인 강화 — 추정) |

> 💎 **비유**: Sonnet이 "실력 좋은 주니어 개발자", Opus가 "베테랑 시니어 개발자"라면, Fable은 "10년 경력 아키텍트"예요.

### Claude Code에서의 활용

```
/model fable-5-2   ← Fable 5.2로 전환
/model opus-5-5    ← Opus 5.5로 복귀 (기본)
```

복잡한 아키텍처 설계나 까다로운 버그 해결에 Fable 5.2를 써보세요.
