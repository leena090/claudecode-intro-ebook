## 2026년 가을, 모델이 한꺼번에 업그레이드됐어요 🚀

2026년 9월부터 11월 사이, Anthropic(앤트로픽)이 Claude(클로드) 모델 라인업을 대대적으로 갱신했어요. 마치 스마트폰 제조사가 갤럭시 S 시리즈를 한꺼번에 발표하듯, **거의 모든 모델이 새 버전으로 교체**됐습니다.

> 🛒 **비유로 설명하면**: 편의점에 가봤더니 삼각김밥 전 품목이 "NEW 더 맛있어진 버전"으로 바뀐 것과 같아요. 소, 돼지, 참치 모두 업그레이드된 거죠. Claude도 마찬가지로 작은 것(Haiku), 중간 것(Sonnet), 큰 것(Opus)이 전부 새 버전이 나왔어요.

## 모델별 자세히 보기

### 🏆 Claude Mythos & Fable 5.1 (9월 15일)

> *"세계에서 가장 고도화된 코딩·지식 작업 모델"* — Anthropic 공식 발표 기준

- **Mythos**: 최상위 연구 능력. AI가 과학 발전에 기여할 수 있다는 첫 힌트가 담겨 있어요.
- **Fable 5.1**: Fable 5(2026년 7월 복귀)에서 한 단계 더 개선된 버전.
- 두 모델 모두 **수출 통제 이슈가 있었던 Fable 5**의 보안 프레임워크를 강화한 뒤 재출시됐어요.

> ⚠️ **추정**: Mythos와 Fable 5.1의 세부 성능 벤치마크는 공식 발표 기준. 개인 요금제에서의 접근 가능 여부는 확인 필요.

### ⚡ Claude Sonnet 5.5 (9월 28일)

Claude Code에서 기본 모델로 주로 사용되는 Sonnet 계열의 업그레이드예요.

- **30% 이상 빠름** — 같은 질문에 더 빨리 답해요
- **비용 최대 30% 절감** — API를 통해 개발 중이라면 비용 절약 효과 체감 가능
- Claude Code에서 `claude-sonnet-5-5` 로 사용 가능 (공식 발표 기준)

### 🐇 Claude Haiku 5.5 (10월 7일)

> *"가장 빠른, 가장 능력 있는 소형 모델"* — 공식 발표 기준

- **대량 처리 작업 특화**: 요약, 서브에이전트, 브라우저 자동화
- Claude Code에서 여러 작업을 동시에 돌릴 때 비용·속도 균형을 위해 사용하기 좋아요
- **비유**: Haiku는 "빠른 배달 오토바이"예요. 큰 짐은 못 싣지만, 가벼운 짐을 10개 동시에 배달하는 데 최고예요.

### 👑 Claude Opus 5.5 (11월 6일, 오늘!)

오늘(2026-11-06) 공식 출시된 가장 최신 모델이에요.

- **에이전트 코딩·지식 작업 1위** (공식 발표 기준)
- **기존 Opus 5 대비 비용 40% 절감** — 더 강한데 더 싸요!
- Fast Mode(패스트 모드)도 Opus 5.5 기반으로 업그레이드됐어요

## Fast Mode 가격이 크게 내렸어요! 💸

> ⚠️ **중요 변경**: 이전 감시 기록(2026-07-18)에서 Fast Mode 가격이 $30/$150이었는데, **공식 마케팅 페이지 기준으로 현재는 $8/$40 per million tokens**으로 대폭 인하됐어요.

| 항목 | 이전 (Opus 4.8 기준) | 현재 (Opus 5.5 기준) |
|------|---------------------|---------------------|
| 모델 | claude-opus-4-8 | claude-opus-5-5 |
| Input 가격 | $30/백만 토큰 | **$8/백만 토큰** |
| Output 가격 | $150/백만 토큰 | **$40/백만 토큰** |
| 속도 | 2.5배 빠름 | 저지연 고속 응답 |

> 💡 **현재 상태**: 리서치 프리뷰(Research Preview). 소비 기반 플랜(Consumption-based plan)에서 사용 가능. 구독 플랜에서는 사용 크레딧으로 제공. 공식 마케팅 페이지 기준.

## Claude Code에서는 어떻게 쓰나요?

```bash
# 모델 직접 지정 (공식 문서 기준)
claude --model claude-opus-5-5

# 설정 파일로 기본 모델 변경
# .claude/settings.json
{
  "model": "claude-sonnet-5-5"
}

# Fast Mode 켜기 (Opus 5.5 고속 버전)
/fast
```

> 💡 **팁**: 일상적인 코딩 작업엔 **Sonnet 5.5**, 복잡한 아키텍처 설계나 긴 리팩토링엔 **Opus 5.5**, 대량 서브에이전트 작업엔 **Haiku 5.5**를 쓰는 게 비용 효율적이에요.
