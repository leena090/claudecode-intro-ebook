## 모델 패밀리 한눈에 보기

> 🏃‍♂️ **비유로 설명하면**: Claude 가족이 모두 체력 훈련을 받고 돌아왔어요.
> - 큰형(Opus)은 더 빠르고 40% 저렴해졌고
> - 중간형(Sonnet)은 30% 빠르고 30% 싸졌고
> - 막내(Haiku)는 더 똑똑해졌어요
> - 특공대(Fable·Mythos)는 코딩·금융·과학 분야에서 한 단계 더 올라갔고요

## 1. Claude Opus 5.5 — 에이전트 코딩 최강 🥇

**발표일**: 2026년 9월 22일

| 항목 | 내용 |
|---|---|
| 위치 | Opus 패밀리 최신 버전 |
| 특징 | 에이전트 코딩·지식 작업 선도 |
| 비용 | 기존 Opus 5 대비 **40% 절감** |
| 적합 | 복잡한 멀티스텝 에이전트 작업 |

Opus 5.5는 단순히 성능이 오른 게 아니에요. **같은 성능에 비용이 40% 줄었다**는 게 핵심이에요. 오랫동안 Opus를 쓰고 싶었지만 비용 때문에 Sonnet을 택하던 분들에게 반가운 소식이에요.

> 💡 **Claude Code 사용자라면**: Fast Mode(고속 모드)의 대상 모델이 Opus 5.5로 바뀌었어요. 가격도 대폭 내렸고요 → 아래 "Fast Mode 변경" 섹션 참고

## 2. Claude Sonnet 5.5 — 일상 작업의 새 기준 ⚡

**발표일**: 2026년 9월 28일

| 항목 | 내용 |
|---|---|
| 위치 | Sonnet 패밀리 최신 버전 |
| 속도 | Sonnet 5 대비 **30%+ 빠름** |
| 비용 | 대부분 작업에서 **최대 30% 저렴** |
| 적합 | 코딩·글쓰기·분석 일반 업무 |

속도와 비용이 동시에 개선된 버전이에요. 일반적인 코딩 작업에서 Sonnet 5.5가 첫 번째 선택이 될 가능성이 높아요.

## 3. Claude Haiku 5.5 — 고속 소형 모델 최강 🐣

**발표일**: 2026년 10월 7일

| 항목 | 내용 |
|---|---|
| 위치 | 가장 빠른 소형 모델 |
| 특징 | 요약, 서브에이전트, 브라우저 사용 |
| 적합 | 대용량 처리, 반복 자동화 |

Haiku 5.5는 **엄청나게 많은 양을 빠르게 처리**할 때 쓰는 모델이에요. 예를 들어, 에이전트 워크플로우에서 단순한 하위 작업을 처리하는 서브에이전트로 최적이에요.
