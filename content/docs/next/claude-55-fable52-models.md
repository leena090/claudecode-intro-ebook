## 3. Claude Haiku 5.5 (2026년 10월 7일) `[블]`

### 무엇이 달라졌나요?

> 🐦 **공식 설명**: "가장 빠르고, 가장 유능한 소형 모델. 요약·서브에이전트·브라우저 사용 같은 대량 처리 작업을 위해 만들어졌습니다."

| 용도 | 설명 |
|------|------|
| 🔄 서브에이전트 | 여러 에이전트가 동시에 돌아갈 때 비용 절감 |
| 📄 요약 | 긴 문서를 빠르게 처리 |
| 🌐 브라우저 사용 | 웹 자동화, 화면 클릭 등 Computer Use |
| 💰 대량 처리 | 토큰을 많이 써야 할 때 경제적 선택 |

> 🍱 **비유**: 짐을 나르는 작업차예요. 고급 세단(Opus)보다 짐 옮기기엔 훨씬 적합하고, 기름도 훨씬 덜 써요.

```bash

/model claude-haiku-5-5
```
