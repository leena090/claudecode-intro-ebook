## 한 줄 요약

2026년 가을부터 Claude 모델이 **5.5 시리즈**로 대폭 업그레이드됐어요. Opus·Sonnet·Haiku 모두 새 버전이 나왔고, 더 빠르고·더 저렴하고·더 똑똑해졌어요. 거기에 11월에는 초고성능 **Fable 5.2 / Mythos 5.2**까지 추가됐습니다.

> 🚗 **비유로 설명하면**: 작년에 산 차가 갑자기 연비는 30% 올라가고 속도도 빨라졌는데, 가격은 더 싸졌다는 소식 같아요. 차를 바꿀 필요도 없어요 — 클로드 쓰던 그대로 더 좋아진 거예요.

## 모델별 정리

### 🔵 Claude Opus 5.5 (Sep 22, 2026)

**공식 한 줄**: "에이전트 코딩과 지식 업무에서 선두, 일반 작업에서 Opus 5 대비 **40% 저렴**"

| 항목 | 내용 |
|------|------|
| 출시일 | 2026년 9월 22일 |
| 강점 | 에이전트 코딩, 지식 집약 업무 |
| 비용 | Opus 5 대비 **40% 절약** |
| Fast Mode | **Opus 5.5 기반** (입력 $8 / 출력 $40 per M 토큰) |

> 💡 **입문자 팁**: Opus는 가장 "무거운" 모델이에요. 복잡한 코드 리팩토링, 긴 문서 분석, 까다로운 버그 추적 — 이럴 때 Opus가 유용해요. 가격이 내려갔으니 부담이 줄었어요.

### 🟢 Claude Sonnet 5.5 (Sep 28, 2026)

**공식 한 줄**: "Sonnet 5보다 뚜렷한 업그레이드, **30%+ 빠르고**, 대부분 작업에서 **최대 30% 저렴**"

| 항목 | 내용 |
|------|------|
| 출시일 | 2026년 9월 28일 |
| 강점 | 속도와 성능의 균형 — 가장 범용적인 모델 |
| 속도 | Sonnet 5 대비 **30%+ 빠름** |
| 비용 | 대부분 작업에서 **최대 30% 절약** |

> 💡 **입문자 팁**: 클로드 코드를 처음 쓰신다면 Sonnet 5.5가 기본입니다. 일상적인 코딩 작업, 파일 수정, 간단한 질문 — 이 모든 걸 빠르고 저렴하게 처리해줘요.

### 🟡 Claude Haiku 5.5 (Oct 7, 2026)

**공식 한 줄**: "가장 빠르고 작은 모델. 요약, 서브에이전트, 브라우저 사용 등 **대용량 작업** 전용"

| 항목 | 내용 |
|------|------|
| 출시일 | 2026년 10월 7일 |
| 강점 | 초고속, 경량, 대용량 반복 작업 |
| 주요 용도 | 요약, 서브에이전트, 브라우저 조작 |
| 특징 | 같은 가격에 더 많은 토큰 사용 가능 |

> 💡 **입문자 팁**: Haiku는 "심부름꾼" 역할이에요. 여러 파일을 한꺼번에 훑거나, 반복 작업을 빠르게 처리할 때 유용해요. Opus/Sonnet보다 훨씬 저렴하게 쓸 수 있어요.

---

### 🔴 Claude Fable 5.2 / Mythos 5.2 (Nov 9, 2026)

**공식 한 줄**: "코딩·금융·과학 분야에서 **새로운 기준**을 세운 최고 성능 모델"

| 항목 | 내용 |
|------|------|
| 출시일 | 2026년 11월 9일 |
| 강점 | 최고 난이도 기술 작업 (코딩·금융·과학) |
| 위치 | Opus 위에 있는 최상위 티어 |
| 비고 | Fable 5.2는 개발·코딩 중심, Mythos 5.2는 연구·분석 중심 (추정) |

> ⚠️ **참고**: Fable 5.2 / Mythos 5.2는 Fable 5 / Mythos 5의 개선 버전이에요. 모든 플랜에서 바로 쓸 수 있는지, 별도 조건이 있는지는 **공식 발표 기준**으로 확인하세요.

> 🏆 **비유**: 일반 도로에서는 Sonnet 5.5로 충분하고, 고속도로 레이스엔 Opus 5.5를 써요. Fable 5.2 / Mythos 5.2는 F1 레이싱카 — 전문가 수준의 초고난도 작업용이에요.

2026년 하반기에 **Fast Mode**가 Opus 5.5 기반으로 바뀌었어요.

- **이전**: Opus 4.8 기반, 입력 $30 / 출력 $150 per M 토큰

가격이 크게 내려갔어요. Fast Mode는 클로드 코드 리서치 프리뷰 기능이에요.
