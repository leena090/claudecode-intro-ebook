## 1. Claude Sonnet 5 출시 `[블]`

### 어떤 모델인가요?

Sonnet 5는 **Sonnet 계열의 새 세대 모델**이에요. 기존 Sonnet 4.6보다 한 단계 강력해졌으며, 코딩·에이전트·전문 업무 전반에서 성능이 향상됐어요.

```
업데이트된 모델 계층 (2026-06-30 기준):
────────────────────────────────────────
🏆 Fable 5          ← 최상위 (7/1 귀환!)
🥇 Opus 4.8         ← 무거운 작업용
🥈 Sonnet 5  ← NEW! ← 균형형 (강력해진 중간 모델)
   Sonnet 4.6        ← (이전 균형형)
   Haiku 4.5         ← 경량·빠름
```

> 🍱 **비유**: 스마트폰 라인업에 비유하면, 기존 "일반형(Sonnet 4.6)"이 지금까지 잘 쓰던 모델이었다면, Sonnet 5는 **프리미엄 일반형** — 가격 대비 성능이 확 올라간 중간 급이에요. 최상위(Opus, Fable)보다는 저렴하고, 경량(Haiku)보다는 훨씬 강력해요.

### Claude Code에서 사용하기

```bash
# 모델 전환
/model claude-sonnet-5

# 또는 설정 파일에서
```

```json
// .claude/settings.json
{
  "model": "claude-sonnet-5"
}
```

### 어떤 작업에 적합한가요?

| 작업 유형 | Sonnet 5 적합도 |
|-----------|----------------|
| 일상적인 코딩 작업 | ⭐⭐⭐⭐⭐ 매우 적합 |
| 에이전트 자동화 | ⭐⭐⭐⭐⭐ 매우 적합 |
| 복잡한 대규모 리팩토링 | ⭐⭐⭐⭐ 좋음 (최상위는 Opus/Fable) |
| 빠른 응답이 필요할 때 | ⭐⭐⭐⭐ 좋음 (Haiku만큼 빠르진 않음) |
