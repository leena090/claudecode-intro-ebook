## 7월에 무슨 일이 있었나요?

2026년 6월 말~7월 초, Claude 모델에 두 가지 큰 변화가 있었어요.

1. **소네트 5 (Sonnet 5)** — 완전히 새 모델이 출시되면서 바로 "기본 모델"이 됐어요
2. **Fable 5 복귀** — 6월 12일 수출통제로 잠겼던 모델이 7월 1일 전 세계에 돌아왔어요

## 1. Claude Sonnet 5 — 최고 성능이 소네트 가격에 `[블]`

### 한 줄 요약

> 🏆 "Opus급 실력으로 Sonnet 가격만 내세요"

### 무엇이 다른가요?

| 항목 | Sonnet 4.6 (이전 기본) | Sonnet 5 (신규 기본) |
|------|----------------------|-------------------|
| 코딩 실력 | 좋음 | **최상급** |
| 도구 활용 | 좋음 | **최상급** |
| 컨텍스트 창 | 200K 토큰 | **100만 토큰** (네이티브) |
| 적응형 사고 | 수동 활성화 | **기본 활성화** |
| 가격 (API) | $3/$15 per MTok | **$2/$10** (홍보가, 8월 31일까지) |
| Claude Code 기본 | ✅ (일부 플랜) | ✅ **Pro, Team Standard, Enterprise** |

> 🍱 **비유**: 예전에 "소네트"는 중형차, "Opus"는 고급 세단이었다면, 소네트 5는 **고급 세단 성능을 중형차 가격에** 살 수 있게 된 거예요.

### 100만 토큰이 뭔가요?

100만 토큰이면 얼마나 긴 내용인지 감이 안 잡히죠?

| 100만 토큰으로 처리할 수 있는 것 |
|-------------------------------|
| 소설 책 10권 분량 |
| 코드 파일 1,000개 이상 |
| PDF 리포트 500쪽 이상 |

큰 회사의 대형 코드베이스 전체를 한 번에 분석할 수 있어요!

### 어떻게 쓰나요?

```bash
# Claude Code 최신 버전 업데이트 (v2.1.197 이상 필요)
claude update

# 소네트 5 선택
/model claude-sonnet-5
```

Pro, Team Standard, Enterprise 구독자라면 이미 **기본값으로 설정**돼 있어요. 별도 설정 없이 자동 적용돼요.

<div class="note-circle">
○ API 홍보 가격 ($2/$10 per MTok)은 2026년 8월 31일까지 적용돼요<br />
○ 적응형 사고(Adaptive Thinking)가 기본으로 켜져 있어요 — 어려운 문제에서 특히 강력해요
</div>

## 2. Fable 5 복귀! — 7월 1일 전 세계 재개 `[블]`

### 무슨 일이 있었나요?

지난 6월 12일, 미국 정부 수출통제 지시로 **Fable 5·Mythos 5 접근이 전면 정지**됐어요. ([new-models-2026-06.md](/docs/next/new-models-2026-06) 참조)

그런데 불과 19일 만인 **7월 1일**, Fable 5가 전 세계에 복귀했어요! 🎉

### 왜 다시 열렸나요?

Anthropic이 **보안 프레임워크**를 새로 마련해서예요.

| 조치 | 내용 |
|------|------|
| 잼브레이크(Jailbreak) 심각도 채점 체계 | 업계 공동 기준 제안 |
| 참여 파트너 | Amazon, Microsoft, Google, Glasswing 파트너사 |
| 추가 사이버 보안 장치 | Fable 5 전용 강화 |

> 🍱 **비유**: 강력한 새 금고(Fable 5)를 만들었는데, 처음엔 도난 걱정으로 창고에 잠가뒀다가, 더 튼튼한 잠금장치를 달고 보험도 들고 나서야 내보낸 것과 같아요.

### 현재 상태

| 모델 | 상태 |
|------|------|
| Fable 5 | ✅ **7월 1일부터 전 세계 정상 이용 가능** |
| Mythos 5 | ✅ **동시 복귀** |

<div class="note-circle">
○ 복귀 후에도 모든 플랜에서 바로 쓸 수 있는 건 아닐 수 있어요 — 이용 가능한 플랜을 공식 페이지에서 확인하세요<br />
○ 수출통제 상황은 향후 변경될 수 있어요 (공식 발표 기준)
</div>
