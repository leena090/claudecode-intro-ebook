## Agent Skills 오픈 표준이 뭔가요?

**Agent Skills**는 AI 에이전트에게 **전문 지식과 워크플로우를 추가하는 표준 형식**이에요. 2025년 12월 Anthropic이 처음 공개한 이 표준을, 이제 **Agentic AI Foundation이라는 중립 재단에 기증**하기로 했어요.

> 📡 **비유로 설명하면**: USB가 표준화된 덕분에 삼성 충전기로 LG 휴대폰을 충전할 수 있잖아요? Agent Skills가 오픈 표준이 되면, Claude Code용으로 만든 Skills를 ChatGPT나 Cursor에서도 그대로 쓸 수 있게 되는 거예요.

---

## 어떤 플랫폼이 참여하나요?

2025년 12월 표준 발표 이후, **70개 이상의 AI 에이전트 플랫폼**이 Agent Skills를 통합했어요.

| 플랫폼 | 분야 |
|--------|------|
| **ChatGPT** | 범용 AI 어시스턴트 |
| **Cursor** | AI 코드 에디터 |
| **GitHub Copilot** | GitHub 통합 코딩 보조 |
| **VS Code** | 마이크로소프트 코드 에디터 |
| + 66개 이상 | 다양한 AI 에이전트 플랫폼 |

---

## Claude Code 사용자에게 어떤 의미인가요?

### 이전

- Claude Code용 Skills = Claude Code에서만 사용 가능
- 팀 안에 Cursor 쓰는 동료, VS Code 쓰는 동료가 있으면 각자 따로 설정

### 이후 (표준화 이후)

- **한번 만든 Skill을 여러 AI 에이전트에서 공유**
- 회사 코드베이스 분석 Skill을 Claude Code, Cursor, Copilot에서 모두 사용
- Skills 생태계가 훨씬 빠르게 성장

---

## Agentic AI Foundation이란?

**Agentic AI Foundation**은 AI 에이전트 기술의 오픈 표준을 관리하는 **중립 재단**이에요. Anthropic이 만들었지만, 이제 재단에 기증함으로써 어떤 한 회사에 종속되지 않는 **진정한 오픈 표준**이 됩니다.

> 🏛️ **비유**: 인터넷 표준(HTTP, HTML)을 W3C라는 중립 재단이 관리하는 것처럼, Agent Skills 표준도 중립 재단이 관리하게 됐어요.
