## Agent Skills가 뭔가요?

Claude Code에서 `/skill-name`처럼 쓰는 **스킬(skill)**을 알고 계시죠? 이 스킬이라는 개념을 **표준화한 형식**이 Agent Skills예요.

> 📋 **비유로 설명하면**: 
> - 예전에는 Samsung 충전기, Apple 충전기, LG 충전기가 다 달랐어요.
> - 이제는 USB-C로 통일되어 어떤 기기든 같은 케이블을 쓸 수 있잖아요.
> - Agent Skills는 AI 에이전트의 **USB-C 같은 공통 표준**이에요.

## 70개 플랫폼이 이미 쓰고 있어요

주목할 만한 통합 플랫폼들:

| 카테고리 | 플랫폼 |
|---|---|
| 대화형 AI | ChatGPT |
| 코딩 AI | Cursor, GitHub Copilot |
| 에디터 | VS Code |
| 기타 | 60개+ |

> 💡 **왜 중요한가요?** 이제 "Claude Code용 스킬"이 ChatGPT나 Cursor에서도 동작할 수 있어요. 반대로 Cursor의 스킬을 Claude Code에서도 쓸 수 있는 길이 열린 거예요.

---

## Claude Code 사용자에게 무슨 의미인가요?

### 지금 당장 변하는 것

솔직히 지금 당장은 체감 변화가 크지 않을 수 있어요. 표준이 정해지고 생태계가 성숙하는 데는 시간이 걸리거든요.

### 앞으로 기대되는 것

1. **크로스 플랫폼 스킬**: Claude Code에서 쓰던 스킬을 다른 AI 도구에서도 그대로 사용
2. **더 풍부한 스킬 생태계**: 여러 회사가 같은 표준으로 스킬을 만들면 선택지가 늘어남
3. **스킬 마켓플레이스 확장**: Plugin/Skill Marketplace가 더 다양해질 수 있음

> 🌐 **비유로 계속**: USB-C 표준이 생기고 나서 보조배터리·이어폰·도킹스테이션 등 관련 기기가 폭발적으로 늘었잖아요. Agent Skills도 그런 방향을 기대해볼 수 있어요.

## Agentic AI Foundation이 뭔가요?

AI 에이전트 관련 **오픈 표준을 관리하는 비영리 재단**이에요. (공식 발표 기준)

Anthropic처럼 한 회사가 표준을 가지고 있는 것보다, 중립적인 재단이 관리하면:
- 특정 회사에 종속되지 않음
- 경쟁 회사들도 부담 없이 참여 가능
- 장기적으로 더 넓은 생태계 형성

---

## Claude Code 스킬 현재 상태

지금 Claude Code에서 스킬은 이렇게 작동해요:

```bash
# 스킬 사용 예시
/code-review        # 코드 리뷰 스킬
/ultraplan          # 구현 계획 수립
/simplify           # 코드 단순화
```

이런 스킬들이 앞으로는 **다른 AI 도구에서도 같은 방식으로 동작**할 수 있는 기반이 생긴 거예요.
