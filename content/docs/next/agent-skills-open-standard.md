## 무슨 일이 생겼나요?

**발표일**: 2026년 10월 22일

Anthropic이 **Agent Skills**(에이전트 스킬)를 **Agentic AI Foundation**이라는 비영리 재단에 기부했어요.

> 🏛️ **비유로 설명하면**: 레고가 자기 블록 규격을 공개해서, 이제 레고뿐 아니라 다른 모든 장난감 회사도 같은 규격으로 블록을 만들 수 있게 된 것과 같아요.

---

## Agent Skills가 뭔가요?

Agent Skills는 **AI 에이전트에게 특수한 지식과 워크플로우를 주는 오픈 표준**이에요.

```
Claude Code의 스킬(예: /code-review, /deep-research)
↓
이 표준을 Agentic AI Foundation에 기부
↓
ChatGPT, Cursor, Copilot, VS Code 등도 같은 스킬 형식 사용 가능
```

---

## 어떤 플랫폼이 채택했나요?

2026년 10월 기준, **70개 이상의 에이전트 플랫폼**이 Agent Skills를 통합했어요:

| 플랫폼 | 종류 |
|---|---|
| **ChatGPT** | AI 어시스턴트 |
| **Cursor** | AI 코드 에디터 |
| **GitHub Copilot** | 코드 자동완성 |
| **VS Code** | 코드 에디터 |
| + 70개 이상 | 각종 에이전트 플랫폼 |

> 💡 Agent Skills 표준은 **2025년 12월**에 처음 발표됐고, 10개월 만에 70개 이상이 채택했어요.

---

## Claude Code 사용자에게는 어떤 의미?

1. **내가 만든 스킬이 다른 에이전트에서도 동작**할 수 있어요
2. **다른 플랫폼의 스킬을 Claude Code에서 가져다 쓸 수** 있는 미래가 열릴 수도 있어요
3. AI 도구끼리 **표준화된 언어로 소통**하는 생태계가 만들어지는 중이에요

## MCP와의 관계

| | MCP (Model Context Protocol) | Agent Skills |
|---|---|---|
| 주도 | Anthropic → 오픈소스 | Anthropic → Agentic AI Foundation |
| 역할 | 도구·데이터 연결 | 에이전트 행동 패턴·워크플로우 |
| 비유 | USB 포트 (연결 규격) | 앱 설명서 (할 수 있는 일 목록) |

> 💡 MCP가 "어떻게 연결할지"를 표준화했다면, Agent Skills는 "무엇을 할 수 있는지"를 표준화해요.
