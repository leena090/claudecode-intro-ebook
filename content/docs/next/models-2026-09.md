## Claude Sonnet 5.5 — 빨라지고 저렴해진 일상용 모델

> 🍱 **비유로 설명하면**: Sonnet 5는 "일 잘하는 직원"이었는데, Sonnet 5.5는 같은 능력에 **출근 속도가 30% 빨라지고 점심값도 30% 내려간** 버전이에요.

### 핵심 변경점 (공식 발표 기준)

- **속도**: Sonnet 5 대비 **30% 빠름**
- **비용**: 대부분의 작업에서 최대 **30% 저렴**
- **성능**: Sonnet 5 대비 명확한 업그레이드

### Claude Code에서 사용하기

```bash
# Sonnet 5.5로 전환
> /model claude-sonnet-5-5

# 또는 모델 피커에서 선택
> /model
```

**언제 쓰면 좋을까요?**

- 📝 일상적인 코드 작성·리뷰
- 🔍 파일 탐색, 리팩터링
- 💬 빠른 질문·답변이 필요할 때
- 💰 비용 절약이 중요한 대용량 작업

## Claude Opus 5.5 — 최고급 모델을 더 합리적인 가격으로

> 🍱 **비유로 설명하면**: 고급 레스토랑 코스 요리(Fable 5.1)와 같은 맛인데 가격은 **40% 더 저렴한 메뉴**가 생긴 거예요.

### 핵심 변경점 (공식 발표 기준)

- **성능**: 대부분의 작업에서 **Fable 5.1 수준**
- **비용**: Opus 5 대비 **40% 저렴**
- **용도**: 복잡한 추론, 장시간 에이전트 작업

### Fast Mode 변경 (공식 발표 기준)

🔔 **중요 변경**: Fast Mode가 이제 **Opus 5.5** 기준으로 작동합니다.
- 이전: Opus 4.8/5 → $10/$50 per MTok  
- 현재: **Opus 5.5 → $8/$40 per MTok** (더 저렴해졌어요!)

```bash
# Opus 5.5로 전환
> /model claude-opus-5-5

# Fast Mode 켜기 (Opus 5.5에 적용)
> /fast
```

## Claude Fable 5.1 & Mythos 5.1 — 코딩·연구의 최전선

9월 1일 Anthropic이 발표한 **Fable 5.1**과 **Mythos 5.1**은 각각 코딩·지식 업무와 과학 연구에 특화된 최상위 모델입니다 (공식 발표 기준).

### Fable 5.1 주요 특징

- 1M(100만) 토큰 컨텍스트 윈도우
- `fable` 별칭으로 빠르게 선택 가능
- Claude Apps Gateway에서는 `/model claude-fable-5-1` 필요 (v2.1.257+)

```bash
# Fable 5.1 선택
> /model fable

# 또는 정확한 모델 ID로
> /model claude-fable-5-1
```

### AI가 과학을 돕는 사례 [블]

Fable 5.1·Mythos 5.1 발표와 함께 Anthropic은 AI가 실제 과학 연구에 기여하는 사례도 공개했습니다:

- 🧬 Claude가 CRISPR 유사 구조를 가진 새로운 효소 시스템 발견 (Sep 23, 공식 발표 기준)
- 🦠 에볼라 확산 대응에 AI 활용 (The Situation Report, Sep 22)

이는 Claude Code 사용과 직접 관련은 없지만, Anthropic이 AI 모델의 과학적 능력을 적극 발전시키고 있음을 보여줍니다.
