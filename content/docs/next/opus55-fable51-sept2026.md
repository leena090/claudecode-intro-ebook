## Claude Fable 5.1 + Mythos 5.1 — 더 강해진 최상위 모델

### 무엇이 달라졌나요?

**Claude Fable 5.1**과 **Claude Mythos 5.1**은 코딩과 지식 업무에서 Anthropic의 **가장 앞선 모델**이에요.

Anthropic에 따르면, 두 모델의 연구 능력은 **"AI 모델이 과학 발전에 어떻게 기여할 수 있는지를 엿볼 수 있는 초기 신호"** 라고 해요. 단순히 더 잘 코딩하는 것을 넘어서, 과학적 문제 풀기에도 가능성을 보이기 시작했다는 의미예요.

> 🍱 **비유로 설명하면**: 기존 Fable 5가 "대형 로펌의 시니어 변호사"였다면, Fable 5.1은 **"학술 논문도 쓰고, 법정에도 서고, 새 판례도 만드는 파트너 변호사"** 예요. 일의 범위가 더 넓어졌어요.

### 주요 특징

| 항목 | 내용 |
|---|---|
| **강점** | 코딩, 지식 업무, 과학적 추론 |
| **연구 능력** | 과학 발전 기여 가능성 (공식 발표 기준) |
| **버전 구분** | Fable 5 → Fable 5.1 (점진적 개선) |

## Claude Opus 5.5 — "저렴한 Fable급"의 등장

### 왜 이게 중요한가요?

**Claude Opus 5.5** (`claude-opus-5-5`)는 이번 9월 발표 중 가장 실용적인 소식이에요.

공식 발표에 따르면:
- 대부분의 작업에서 **Fable 5.1과 동급 수준** 성능
- Opus 5 대비 **비용 40% 절감**

> 🍱 **비유로 설명하면**: Fable 5.1이 "특급 호텔 스위트룸"이라면, Opus 5.5는 **"같은 침대, 같은 조식, 가격은 40% 싼 슈페리어 룸"** 이에요. 대부분의 경우 체감 차이가 거의 없어요.

### 실전에서 뭐가 달라지나요?

**API 비용이 낮아진다는 건**:
- Claude Code를 API로 연결해서 쓰는 팀이라면 → 월 사용료가 줄어요
- 자동화 파이프라인을 운영하는 분이라면 → 같은 예산으로 더 많이 돌릴 수 있어요
- 개인 Max 플랜 사용자라면 → 구독 안에서 더 많은 토큰을 쓸 수 있는 효과

### 어떤 작업에 잘 맞나요?

| 작업 유형 | 추천 모델 |
|---|---|
| 일반 코딩, 버그 수정, 코드 설명 | **Opus 5.5** (충분) |
| 대규모 리팩터링, 복잡한 아키텍처 설계 | **Fable 5.1** (추가 성능 필요시) |
| 과학적 추론, 연구 수준 업무 | **Mythos 5.1** (연구 특화) |
| 빠른 응답이 우선일 때 | **Sonnet 5** 또는 Fast Mode |

## Fast Mode와의 관계

마케팅 페이지 기준으로, Fast Mode는 이제 **Opus 5.5 고속 실행 버전**을 의미해요.

- 기본 속도보다 **2.5배 빠름**
- 가격: **$8/$40 per million tokens** (입력/출력)
- 이전 버전(Opus 4.8 기반, $30/$150)에서 크게 저렴해졌어요

→ 자세한 내용은 [Fast Mode 업데이트 문서](/docs/advanced/fast-mode-opus55) 참조.
