## ① Claude Opus 5.5 — 에이전트 코딩의 새 기준

> 🏋️ **비유**: Opus 4는 100킬로 역도 선수였다면, Opus 5.5는 같은 무게를 들면서 비용은 40% 덜 쓰는 효율 선수예요.

**공식 발표 (2026-09-22)**:
- 에이전트 코딩·지식 작업에서 **리더십 유지**
- 같은 작업 기준 Opus 5 대비 **40% 저렴**
- Fast Mode(고속 버전)가 Opus 5.5 기준으로 전환 → **$8/$40 per MTok**

```
# Fast Mode (고속 버전) 가격 변경
이전: Opus 4.8 기준, $30/$150 per MTok
현재: Opus 5.5 기준, $8/$40 per MTok (공식 발표 기준)
```

> 💡 Fast Mode는 Opus 5.5를 더 빠르게 돌리는 옵션이에요. 이전 Opus 4.8 Fast Mode보다 훨씬 저렴해졌어요.

## ② Claude Sonnet 5.5 — 일상 코딩의 새 기본

> 🚗 **비유**: 소나타 5가 중형차라면, 소나타 5.5는 같은 가격에 엔진도 더 좋고 연비도 20% 오른 연식 변경 모델이에요.

**공식 발표 (2026-09-28)**:
- Sonnet 5 대비 **30%+ 빠름**
- 대부분 작업에서 **최대 30% 저렴**
- 전반적인 품질은 Sonnet 5 대비 **명확한 업그레이드**

```
# Claude Code에서 모델 전환 (추정)
claude --model claude-sonnet-5-5
```

## ③ Claude Haiku 5.5 — 고속 대량 처리의 왕

> ⚡ **비유**: 대형 트럭이 짐을 많이 나르지만 느리다면, 하이쿠(하이쿠·俳句처럼 짧고 빠른)는 오토바이 배달부예요. 양은 적지만 속도가 압도적이에요.

**공식 발표 (2026-10-07)**:
- 가장 빠른, 가장 성능 좋은 **소형 모델**
- 용도: **요약·서브에이전트·브라우저 사용** 같은 대량 처리 작업
- 대규모 에이전트 팀에서 "일꾼 에이전트" 역할에 최적

```yaml
# 멀티 에이전트 설정 예시 (추정)
# 복잡한 판단은 Opus 5.5, 반복 작업은 Haiku 5.5로
orchestrator: claude-opus-5-5
worker_agents: claude-haiku-5-5
```
