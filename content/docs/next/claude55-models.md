## 🏆 Claude Opus 5.5 — 최강 에이전트 코딩 모델

> 🏋️ **비유**: Opus 5가 "국가대표 선수"라면, Opus 5.5는 **"더 빠르고 더 저렴한 국가대표"**예요.

공식 발표에서 Anthropic은 Opus 5.5가 **에이전트 코딩과 지식 업무**에서 최고 성능을 낸다고 강조했어요.

### 핵심 특징

- ✅ 이전 Opus 5 대비 **40% 저렴** (같은 성능으로 토큰 비용 절감)
- ✅ 아직도 최고 난이도 코딩·분석 작업에 최적
- ✅ Claude Code에서 **Fast Mode** 적용 가능 — **$8/$40 per million tokens** (인풋/아웃풋)

> 💡 **Fast Mode 가격 변동 안내**: 기존 Opus 4.8 기반 Fast Mode($30/$150) → Opus 5.5 기반 Fast Mode($8/$40)로 **대폭 인하**. 같은 속도 혜택을 훨씬 저렴하게 누릴 수 있어요.

### Claude Code에서 Opus 5.5 선택하는 법

```bash
# 설정 파일로 지정
# ~/.claude/settings.json
{
  "model": "claude-opus-5-5"
}

# 또는 실행 시 플래그
claude --model claude-opus-5-5 "복잡한 아키텍처 설계해줘"
```

## ⚡ Claude Sonnet 5.5 — 균형의 업그레이드

> 🚗 **비유**: Sonnet 5가 "준중형 세단"이라면, Sonnet 5.5는 **"연비도 좋고 가속도 빠른 신형 세단"**이에요.

Sonnet 5.5는 이전 Sonnet 5 대비:
- **30%+ 더 빠른** 응답 속도
- **최대 30% 저렴한** 토큰 비용
- 대부분의 코딩·분석 업무에 최적 균형점

### 왜 중요한가요?

Claude Code의 기본 모델은 이미 2026-07월에 Sonnet 5로 전환됐는데, Sonnet 5.5가 나오면서 **"더 싸고 더 빠른 기본값"**이 생긴 거예요. 평소 코딩 작업의 90%는 Sonnet 5.5로 충분해요.

## 🐦 Claude Haiku 5.5 — 고속 소형 모델

> 🏍️ **비유**: Haiku 5.5는 자전거 배달처럼 **"가볍고 빠르고 많이"** 할 때 쓰는 모델이에요.

공식 발표 내용:
- **가장 빠른 소형 모델** — 고속 응답이 필요한 대량 작업용
- 주요 용도: 요약(summarization), 서브에이전트(subagents), 브라우저 사용(browser use)
- 많은 양의 반복 작업을 낮은 비용으로 처리할 때 최고

### 언제 Haiku 5.5가 유리한가요?

```
대량 파일 요약이 필요할 때
서브에이전트로 여러 작업을 동시 처리할 때
웹 자동화(computer use)처럼 반복 동작이 많을 때
비용을 최소화하면서 빠른 응답이 필요할 때
```
