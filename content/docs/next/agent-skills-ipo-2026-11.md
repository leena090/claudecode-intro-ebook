## 2026년 10월~11월: 큰 뉴스 두 가지

이 글에서는 Claude Code 사용자에게 의미 있는 두 가지 큰 소식을 정리합니다.

---

## 📂 Agent Skills, 오픈 스탠다드가 되다

> 📢 **공식 발표** (2026-10-22): "Donating Agent Skills to the Agentic AI Foundation"

### Agent Skills가 뭔가요?

**Agent Skills**(에이전트 스킬스)는 AI 에이전트에게 **전문 지식과 작업 흐름을 패키지로 넣어주는 표준**입니다. Claude Code의 `/skills` 기능이 바로 이 표준을 사용합니다.

예를 들어:
- "React 컴포넌트 작성 방법" 스킬
- "데이터베이스 마이그레이션 스킬"
- "PR 리뷰 체크리스트 스킬"

### 무슨 일이 있었나요?

Anthropic이 Agent Skills 오픈 스탠다드를 **Agentic AI Foundation**(에이전틱 AI 파운데이션)이라는 비영리 단체에 기증했습니다.

| 항목 | 내용 |
|------|------|
| 기증 단체 | Agentic AI Foundation |
| 발표일 | 2026-10-22 |
| 기존 채택 플랫폼 | ChatGPT, Cursor, GitHub Copilot, VS Code 등 70개+ |
| 최초 표준 발표 | 2025년 12월 |

> 🤝 **비유**: 충전기 규격이 USB-C로 통일되듯, AI 에이전트의 스킬 패키지 형식을 하나의 표준으로 통일한 것입니다. 이제 Claude Code용 스킬을 Cursor에서도 쓸 수 있고, GitHub Copilot용 스킬을 Claude Code에서도 쓸 수 있게 됩니다.

### Claude Code 사용자에게 의미하는 것

- Claude Code의 **Skills 기능**이 다른 AI 도구와 호환될 가능성 증가
- 커뮤니티에서 만든 스킬을 더 쉽게 공유하고 재사용 가능
- 70개 이상의 플랫폼이 이미 채택 → 풍부한 스킬 생태계 기대

## 🏦 Anthropic, 주식 시장에 상장되다 (IPO)

> 📢 **공식 발표** (2026-11-20): "Anthropic announces closing of initial public offering"

### IPO가 뭔가요?

**IPO**(아이피오, Initial Public Offering)는 회사가 처음으로 일반 대중에게 주식을 팔아 주식시장에 올라오는 것을 말합니다.

### Anthropic IPO 타임라인

| 날짜 | 사건 |
|------|------|
| 2026-10-26 | S-1 서류 SEC 제출 (IPO 첫 발표) |
| 2026-11-10 | 로드쇼 시작 (기관투자자 설명회) |
| 2026-11-18 | 공모가 확정: **주당 $83** |
| 2026-11-20 | IPO 완료, 상장 |

### 규모

- 공모가: **주당 $83**
- 총 공모 주식: **약 11억 2,700만 주**
- 클래스 A 보통주 상장

### Claude Code 사용자에게 의미하는 것

| 항목 | 의미 |
|------|------|
| 서비스 안정성 | 더 큰 자본 → 서비스 안정적 운영 가능 |
| 가격 변동 가능성 | 상장 기업은 수익성 압박 증가 |
| 기능 확장 | 추가 투자 → 새 기능 개발 가속 |
| 투명성 | 상장사는 재무·사업 계획 공개 의무 |

> 💡 **참고**: Anthropic은 **PBC**(Public Benefit Corporation, 공익 법인) 형태를 유지합니다. 순수 영리 목적만이 아닌 "안전한 AI 개발"이라는 공익 목적도 함께 추구하는 구조입니다.
