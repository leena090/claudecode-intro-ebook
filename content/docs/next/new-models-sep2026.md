## 1. Claude Fable 5.1 & Mythos 5.1 (9월 1일)

Anthropic 공식 발표:
> "코딩과 지식 작업에서 가장 앞선 모델. 연구 역량은 AI가 과학 발전에 기여하는 방식의 초기 모습을 보여줍니다."

### Fable 5.1 — 코딩 최전선

Fable 5.1은 6월에 나온 Fable 5를 업그레이드한 버전이에요.

🍳 비유: Fable 5가 "3성 셰프가 처음 오픈한 식당"이라면, Fable 5.1은 "반년 영업해서 레시피와 서비스가 완숙해진 그 식당"이에요.

Claude Code에서 복잡한 다중 파일 리팩토링, 큰 코드베이스 탐색, 긴 시간 자율 실행 작업에 적합해요.

### Mythos 5.1 — 지식 작업 특화

Fable 5.1과 같은 날 나온 쌍둥이 모델이에요. 과학 연구·심층 분석·문서 작성처럼 **지식 집약적인 작업**에 특화됐어요. 코드보다 글과 논리가 중심인 작업에 더 강해요.

## 2. Claude Opus 5.5 (9월 22일)

Anthropic 공식 발표:
> "Opus 5.5는 대부분의 작업에서 Fable 5.1 수준의 성능을 내면서, Opus 5 대비 40% 저렴하게 운영할 수 있습니다."

핵심은 딱 두 줄이에요:

✅ **성능** → Fable 5.1과 거의 같은 수준  
✅ **가격** → Opus 5 대비 40% 절감

🏪 비유: Fable 5.1이 "백화점 3층 레스토랑"이라면, Opus 5.5는 "같은 셰프가 만드는 합리적인 런치 세트"예요. 맛은 거의 같은데 값은 훨씬 낫죠.

API로 Claude Code를 직접 연동하거나 팀 단위로 많이 쓰는 경우 비용 절감 효과가 커요.

## 3. Claude Sonnet 5.5 (9월 28일)

Anthropic 공식 발표:
> "Sonnet 5의 명확한 업그레이드. 대부분의 작업에서 30% 더 빠르고, 비용도 최대 30% 저렴합니다."

| 항목 | Sonnet 5 | Sonnet 5.5 |
|---|---|---|
| 속도 | 기준 | **+30% 빠름** |
| 가격 | 기준 | **최대 30% 저렴** |
| 성능 | 기준 | 명확한 업그레이드 |

📱 비유: 스마트폰의 "S 업그레이드"예요. 모델 번호 끝에 .5가 붙었지만 실제로 속도·효율이 체감될 만큼 올랐어요.

Claude Code에서 일상적인 코드 수정, 빠른 질문 답변, 파일 검색 등 자주 반복되는 작업에 기본으로 많이 쓰이게 될 모델이에요.

## ⚡ Fast Mode도 바뀌었어요

Opus 5.5 출시와 함께 **Fast Mode 기준 모델**이 바뀌고 가격도 크게 내려갔어요.

| | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|---|---|---|
| 기준 모델 | Opus 4.8 | **Opus 5.5** |
| 입력 가격 | $30/100만 토큰 | **$8/100만 토큰** |
| 출력 가격 | $150/100만 토큰 | **$40/100만 토큰** |
| 속도 | 2.5배 빠름 | 2.5배 빠름 유지 |

가격이 무려 73% 내려간 거예요! 소비 기반 플랜(consumption-based plan)을 쓰는 분들께 특히 좋은 소식이에요.

<div class="note-circle">○ Fast Mode는 현재 리서치 프리뷰(research preview) 상태예요. 소비 기반 플랜과 구독 플랜의 사용 크레딧에서 사용 가능해요 (공식 발표 기준).</div>
