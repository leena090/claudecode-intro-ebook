## Claude Sonnet 5.5 — 일상 코딩의 새 기준 ⭐

### 왜 중요한가요?

**Claude Sonnet 5.5**는 2026년 9월 28일 출시됐어요. 대부분의 Claude Code 사용자에게 가장 직접적인 영향을 주는 업데이트예요.

> "대부분의 작업에서 Sonnet 5 대비 30% 빠르고, 비용도 최대 30% 저렴합니다." — Anthropic 공식 발표

| 항목 | Sonnet 5 (이전) | Sonnet 5.5 (신규) |
|---|---|---|
| **속도** | 기준 | **30% 빠름** |
| **요금** | 기준 | **최대 30% 저렴** |
| **모델 ID** | `claude-sonnet-5` | `claude-sonnet-5-5` |

> 🍱 **비유로 설명하면**: 쓰던 자동차가 업그레이드됐는데, 연비도 좋아지고 속도도 빨라진 거예요. 게다가 유지비까지 싸졌어요.

## Fast Mode 가격 대폭 인하 💡

### 이전 vs 현재

**Fast Mode**란 Claude Code에서 Opus 계열 모델을 2.5배 빠르게 실행하는 고속 설정이에요.

| 항목 | 이전 (Opus 4.8) | 현재 (Opus 5.5) |
|---|---|---|
| **대상 모델** | Opus 4.8 | **Opus 5.5** |
| **속도** | 2.5배 | 2.5배 |
| **요금 (입력)** | $30/M tokens | **$8/M tokens** |
| **요금 (출력)** | $150/M tokens | **$40/M tokens** |

> 🍱 **비유로 설명하면**: 빠른 배달 서비스 요금이 4분의 1로 내려갔어요. 게다가 배달 품질(모델 성능)도 더 좋아졌고요.

<div class="note-star">
★ Fast Mode는 리서치 프리뷰 상태이며, 소비 기반(consumption-based) 플랜에서 이용 가능합니다.<br />
★ 구독 플랜 사용자는 사용 크레딧(usage credits)으로도 이용 가능.
</div>
