## 1. Claude Opus 5 — 새로운 최고 모델

> 🍱 **비유로 설명하면**: 지금까지 회사 최고의 시니어 개발자가 Sonnet 5였다면, 이제 Opus 5라는 테크 리드가 들어온 거예요. 더 오래 걸리는 복잡한 프로젝트를 맡겼을 때 진가가 나와요.

**Claude Opus 5** (`claude-opus-5`)는 **장시간 실행 에이전트 작업** 과 **코딩, 전문 업무**에서 한 단계 올라선 성능을 보여줘요.

### 어디서 기본 모델로 쓰이나요?

| 플랜 | 기본 Opus 모델 |
|---|---|
| Max, Team Premium, Enterprise | ✅ Opus 5 기본 |
| Anthropic API | ✅ Opus 5 기본 |
| Amazon Bedrock | Opus 5 (1M 컨텍스트 변형 별도 선택) |
| Google Cloud Agent Platform | Opus 5 (1M 컨텍스트 변형 별도 선택) |

### 컨텍스트 창 — 100만 토큰!

Opus 5는 **100만(1M) 토큰** 컨텍스트 창을 지원해요. 책 한 권 분량의 코드를 통째로 올려서 분석시킬 수 있는 크기예요.

> 🍱 **비유**: 기존 Sonnet 5가 A4 50장짜리 서류를 한 번에 읽는다면, Opus 5는 책 5권 분량을 한 번에 읽는 느낌이에요.

### 모델 전환 방법

Claude Code 세션 안에서:

```text
> /model claude-opus-5
```

또는 세션 시작 시:

```bash
claude --model claude-opus-5
```

### Fast 모드도 Opus 5로 전환!

**Fast 모드**(`/fast`)가 이제 **Opus 5**를 빠르게 돌려요. 요금도 바뀌었어요:

| 구분 | 이전 (Opus 4.8) | 변경 (Opus 5) |
|---|---|---|
| 대상 모델 | claude-opus-4-8 | **claude-opus-5** |
| 요금 | $30/$150 per MTok | **$10/$50 per MTok** |
| 속도 | 2.5× 빠름 | 2.5× 빠름 유지 |

> 💡 **참고**: Fast 모드는 더 이상 Opus 4.7을 지원하지 않아요. `/fast` 명령어는 Opus 5와 Opus 4.8에만 적용돼요.

## 2. Auto 모드가 기본값이 됐어요 (2026-08-14~)

> 🍱 **비유로 설명하면**: 새 직원이 매 단계마다 "이거 해도 돼요?"라고 묻는 대신, 이제는 회사 규정 범위 안에서 알아서 판단하고 일하게 된 거예요. 본인이 다른 설정을 해뒀다면 그대로예요.

**8월 14일부터** Pro, Max, Team 플랜에서 **Auto 모드**가 새 세션의 기본 권한 모드가 됐어요.

### 영향 받는 사람 / 안 받는 사람

| 상황 | 적용 여부 |
|---|---|
| 내가 기본 모드를 직접 설정해둔 경우 | ❌ 그대로 유지 (전환 프롬프트 한 번 표시) |
| 회사(조직)가 관리하는 기본 모드인 경우 | ❌ 변경 없음 |
| 아무것도 설정 안 해둔 경우 | ✅ Auto 모드로 자동 전환 |

### Auto 모드를 지금 바로 기본값으로 설정하는 방법

```json
// ~/.claude/settings.json
{
  "permissions": {
    "defaultMode": "auto"
  }
}
```

새 세션을 열면 상태바에 `auto mode on`이 표시돼요.

### Auto 모드란?

파일 수정·명령어 실행 대부분을 물어보지 않고 수행하지만, **백그라운드 안전 분류기**가 위험한 작업은 잡아내는 모드예요. 긴 작업을 맡기고 자리를 비울 때 유용해요.

> 🍱 **비유**: "알아서 해. 대신 안전 담당자가 옆에서 감시하고 있어." 느낌.

## 3. 세션 간 메시지 보내기 (Cross-session messaging)

> 🍱 **비유로 설명하면**: 클로드를 여러 창에서 동시에 돌리고 있을 때, 한 창의 클로드가 다른 창의 클로드한테 쪽지를 보낼 수 있게 됐어요. "저쪽 팀한테 이거 전달해" 하는 느낌.

v2.1.224부터 **여러 Claude Code 세션이 서로 메시지를 보낼 수 있어요**.

### 어떻게 작동하나요?

1. `ListAgents` 도구로 같은 머신에 있는 다른 세션을 찾고
2. `SendMessage` 도구로 텍스트 메시지를 보내요
3. 받은 세션은 `Message from [세션명]` 행을 표시하고, `Ctrl+O`로 내용 확인

### 사용 예시

두 개의 Claude Code 창이 열려 있을 때:

```text
> payments API 작업하는 세션한테 users.name이 users.display_name으로 바뀌었다고 전해줘
```

또는 어떤 세션들이 있는지 확인:

```text
> /list-agents
```

> **참고**: macOS와 Linux에서만 지원. v2.1.224 이상 필요.

## 4. 기타 주목할 변경 (W30 · W32)

### ✅ /code-review가 백그라운드에서 실행

`/code-review`가 이제 **별도 서브에이전트**로 실행되어 내 대화 창과 분리돼요. 리뷰하는 동안 다른 작업을 계속할 수 있어요.

> **참고**: `/review`는 `/code-review`의 별칭(alias)이에요. 둘 다 같은 기능.

### ✅ 이모지 단축코드 자동완성

프롬프트 입력창에서 `:heart:` 처럼 입력하면 이모지로 자동 변환돼요. 두 글자 이상 입력하면 추천 이모지도 떠요. 끄고 싶으면 설정에서 `emojiCompletionEnabled: false`.

### ✅ 동시 서브에이전트 기본값 20개

한 세션에서 기본 20개 서브에이전트가 동시에 실행될 수 있어요. 환경변수로 변경:

```bash
CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS=30 claude
```

### ✅ /fork가 별도 워크트리 생성

`/fork` 명령어로 복사한 세션이 이제 원본과 **별도 워크트리(worktree)**에서 코드 변경을 해요. 원본 작업 중인 코드와 충돌 안 생겨요.

### ⛔ /ultraplan 제거됨

`/ultraplan` 명령어와 관련 기능이 **제거**됐어요. 대신 plan 모드(`Shift+Tab`) 또는 Claude Code on the web을 사용하세요.
