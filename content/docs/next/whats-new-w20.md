### 1️⃣ 에이전트 뷰(Agent View) — 모든 세션을 한 화면에서

지금까지 Claude Code를 여러 개 띄워놓으면, 어디서 뭐가 진행 중인지 확인하려면 창을 하나씩 열어봐야 했어요. **에이전트 뷰(Agent View)**가 그 불편함을 해결해줘요.

```bash
# 터미널에서 에이전트 뷰 열기
claude agents

# 데스크톱 앱에서는 사이드바에서 바로 확인 가능
```

| 기능 | 설명 |
|------|------|
| 한 화면 모니터링 | 모든 세션이 뭘 하는지 실시간 표시 |
| 입력 필요 감지 | 어떤 세션이 내 승인을 기다리는지 즉시 표시 |
| 세션 전환 | 클릭 한 번으로 원하는 세션으로 이동 |

> 🍱 **비유**: 여러 대의 택배 차량을 관리하는 물류센터 현황판 같아요. 각 차량에 전화해서 "지금 어디예요?" 물어보는 대신, 한 화면에서 어느 차가 배달 중이고 어느 차가 집 앞에 도착해서 사인을 기다리는지 한눈에 볼 수 있어요.

→ 상세: [에이전트 뷰 완전 가이드](/docs/advanced/agent-view) `[공]`

### 2️⃣ `/goal` — 완료 조건이 충족될 때까지 자동으로 계속

"테스트가 전부 통과할 때까지 고쳐줘"처럼 **목표 조건**을 주면, Claude가 조건이 충족될 때까지 알아서 여러 턴에 걸쳐 작업을 이어가는 기능이에요.

```bash
/goal 모든 유닛 테스트가 통과할 때까지 버그 수정
/goal ESLint 에러 0개 달성
/goal 빌드가 성공할 때까지 의존성 문제 해결
```

Claude는 조건이 충족될 때까지 **스스로 반복해서 시도**하며, 중간에 막히면 다른 접근법을 시도해요.

> 🍱 **비유**: 요리를 배우는 학생에게 "간이 딱 맞을 때까지 계속 맛보면서 조절해"라고 시키는 것과 같아요. 선생님이 매번 옆에서 "이제 됐어"라고 신호를 주지 않아도, 학생이 스스로 기준이 충족될 때까지 소금을 넣고 맛보기를 반복하는 방식이에요.

→ 상세: [/goal 가이드](/docs/advanced/goal) `[공]`

### 3️⃣ 패스트 모드(Fast Mode) 기본 모델 — Opus 4.6 → Opus 4.7 변경 ⚡

**이번 주에서 가장 중요한 변경사항**이에요. 패스트 모드(Fast Mode)의 기본 모델이 **Opus 4.7로 업그레이드**됐어요.

| 구분 | 이전 | 이후 (w20~) |
|------|------|------------|
| 패스트 모드 기본 모델 | Opus 4.6 | **Opus 4.7** ⭐ |
| 속도 | 일반 모드 대비 2.5배 빠름 | 동일 |
| 성능 | Opus 4.6 수준 | **Opus 4.7 수준으로 향상** |
| 요금 | $30/$150/백만 토큰 | 동일 |

#### 패스트 모드 켜는 법

```bash
# 현재 세션에서 토글 (터미널 내 명령어)
/fast

# 또는 처음 시작할 때 플래그로 지정
claude --fast
```

> 🍱 **비유**: 고속도로 버스가 있는데, 빠른 차선(패스트 모드)으로 달리는 건 그대로인데 이번에 버스 자체를 2023년식에서 2024년식 신형으로 바꾼 거예요. 같은 빠른 차선인데 더 좋은 차라 더 편안하게 도착해요.
