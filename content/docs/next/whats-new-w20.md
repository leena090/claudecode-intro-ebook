## 이번 주 핵심 변경

### 1️⃣ 에이전트 뷰(Agent View) — 모든 세션을 한 화면에서

여러 개의 Claude Code 세션을 동시에 띄워 작업할 때, 이제 **한 화면에서 전체 현황**을 볼 수 있어요.

```bash
# 에이전트 뷰 열기
/agent-view
```

> 🍱 **비유**: CCTV 모니터 화면처럼 — 가게 여러 곳을 한 번에 보는 것처럼, 내가 Claude에게 시킨 여러 작업이 지금 어느 단계인지 한 눈에 볼 수 있어요.

각 세션이 "무엇을 하고 있는지", "내 입력이 필요한지"를 한눈에 파악하고 빠르게 전환할 수 있어요. `[공]`

📄 자세한 사용법 → [에이전트 뷰 가이드](/docs/advanced/agent-view)

---

### 2️⃣ `/goal` — 조건이 충족될 때까지 자동 실행

Claude에게 **"이 조건이 될 때까지 계속 해"** 라고 말할 수 있어요.

```bash
# 테스트가 모두 통과할 때까지 계속
/goal 모든 단위 테스트가 통과될 때까지 코드를 고쳐

# 파일이 생성될 때까지 계속
/goal report.pdf 파일이 만들어질 때까지
```

> 🍱 **비유**: 빨래를 돌리고 나서 "다 마를 때까지 건조기 계속 돌려" 라고 말하는 것처럼 — 조건이 충족되면 알아서 멈춰요.

이전에는 Claude가 한 번 시도하고 멈췄다면, 이제는 조건이 될 때까지 스스로 여러 번 시도하고 수정해요. `[공]`

📄 자세한 사용법 → [/goal 명령어 가이드](/docs/commands/goal-command)

---

### 3️⃣ Fast Mode — 이제 Opus 4.7에 기본 적용 🆕

**Fast Mode(패스트 모드)** 가 이전에는 Opus 4.6 기준이었지만, 이번 업데이트로 **Opus 4.7이 기본**이 됐어요.

| 항목 | 이전 (Week 19 이전) | 이번 주 (Week 20) |
|------|---------------------|------------------|
| Fast Mode 대상 모델 | Opus **4.6** | Opus **4.7** (기본) |
| 속도 | 2.5배 빠름 | 2.5배 빠름 (동일) |
| 요금 | $30/$150 per million tokens | 동일 |
| 활성화 방법 | `/fast` 토글 | `/fast` 토글 |

> 🍱 **비유**: 최신형 차(Opus 4.7)에 터보 엔진을 달았어요 — 이전 모델(Opus 4.6)에 달려 있던 터보를 더 강력한 최신 차에 업그레이드한 거예요.

**Fast Mode 켜는 방법:**
```bash
/fast
# 또는
Ctrl+Shift+F  (데스크톱 앱)
```
