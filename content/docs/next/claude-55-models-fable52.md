## Sonnet 5.5: "일반 코딩의 새 표준"

**공식 발표 (2026-09-28)**: Sonnet 5.5는 Sonnet 5의 직접 업그레이드입니다.

✅ 성능: Sonnet 5 대비 명확한 업그레이드  
✅ 속도: 30% 이상 빠름  
✅ 비용: 대부분의 작업에서 최대 30% 저렴  

```
> 이 버그를 고쳐줘    ← Sonnet 5.5가 처리 (기본 모델)
```

---

## Opus 5.5: "에이전트 코딩의 왕"

**공식 발표 (2026-09-22)**: Opus 5.5는 에이전트 코딩과 지식 집약 작업에서 1위를 차지하면서, Opus 5 대비 **40% 저렴한** 비용으로 운영됩니다.

```
# Fast Mode (Opus 5.5 고속 버전)
# 2.5배 더 빠름 — 비용은 더 높지만 대기 시간 단축
# 요금: $8/$40 per million tokens (입력/출력) — 이전 Opus 4.8 대비 $30/$150에서 대폭 인하!
```

> 🏎️ **비유**: Fast Mode는 택시 콜에서 '즉시 배차' 옵션과 같아요. 조금 비싸지만 기다리기 싫을 때 씁니다.

**Fast Mode 활성화**:
```
/fast    ← 토글로 켜고 끄기
```

## Fable 5.2: "2026년 11월 최상위 모델"

**공식 발표 (2026-11-09)**: Claude Fable 5.2와 Claude Mythos 5.2는 **코딩·금융·과학** 분야에서 새로운 기록을 세웠습니다.

> 🏆 **비유**: Fable 5.2는 아파트 탑층 펜트하우스예요. 월세(토큰 비용)가 비싸지만, 가장 복잡한 기술 과제를 맡길 때 씁니다.

**언제 Fable 5.2를 써야 할까요?**

| 상황 | 추천 모델 |
|------|---------|
| 일반 코딩, 버그 수정 | Sonnet 5.5 (기본) |
| 복잡한 리팩토링, 장기 에이전트 | Opus 5.5 |
| 최고 난이도 기술 과제, 과학 계산 | Fable 5.2 |
| 대량 반복 처리, 서브에이전트 | Haiku 5.5 |

## 모델 직접 지정하는 방법

```bash
# 설정 파일로 기본 모델 변경

  "model": "claude-opus-5-5"
}
```
