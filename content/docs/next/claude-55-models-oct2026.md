## Claude Opus 5.5 — "에이전트 시대의 주력"

> 🏋️ **비유로 설명하면**: Opus 5가 중량급 선수였다면, Opus 5.5는 **같은 체급에서 더 빠르고 더 저렴하게** 경기를 뛰는 선수예요.

Opus 5.5는 **에이전트 코딩과 지식 업무**에서 가장 강력한 성능을 보여줘요. 특히 여러 도구를 연달아 사용하는 복잡한 자동화 작업에 적합해요.

**핵심 변화:**
- Opus 5 대비 비용 **40% 절감** (공식 발표 기준)
- 에이전트 루프, 멀티 스텝 코딩에서 더 안정적
- Fast Mode (고속 모드) 대상 모델로 전환 (Opus 4.8에서 변경)

### Fast Mode 가격 변경 (공식 발표 기준)

마케팅 페이지 최신 내용 기준으로 Fast Mode 요금이 바뀌었어요:

| 구분 | 이전 (Opus 4.8 기준) | 이후 (Opus 5.5 기준) |
|---|---|---|
| 입력 토큰 | $30 / 1M | **$8 / 1M** |
| 출력 토큰 | $150 / 1M | **$40 / 1M** |
| 속도 | 2.5배 빠름 | 동일 |
| 적용 플랜 | 소비 기반 | 소비 기반 (리서치 프리뷰) |

> 💡 **입문자 팁**: Fast Mode는 소비 기반 플랜(Claude Console API 등) 사용자에게만 해당돼요. 개인 Pro/Max 구독 플랜은 Fast Mode 가격이 직접 청구되지 않아요.

## Claude Haiku 5.5 — "대량 처리의 경량 엔진"

> 🏍️ **비유로 설명하면**: Haiku는 오토바이예요. 버스(Opus)나 승용차(Sonnet)보다 작지만, **복잡하지 않은 짧은 거리를 엄청 빠르게** 갈 수 있어요.

Haiku 5.5는 다음 용도에 최적화돼 있어요:
- **요약(Summarization)** — 긴 문서를 빠르게 줄이기
- **서브에이전트(Subagents)** — 대규모 병렬 작업에서 소형 역할 담당
- **브라우저 자동화(Browser use)** — 반복적인 웹 작업 처리
