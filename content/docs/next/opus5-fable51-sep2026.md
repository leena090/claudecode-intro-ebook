## Claude Opus 5 — 2026년 7월 24일 공식 출시 `[블]`

**"Opus 티어의 한 단계 도약"** — 이게 Anthropic의 공식 발표 문구예요.

### 어떤 점이 좋아졌나요?

> 🏗️ **비유**: Opus 4.8이 "혼자서도 잘하는 건설 반장"이었다면,
> Opus 5는 **"몇 주짜리 대형 프로젝트도 처음부터 끝까지 맡길 수 있는 현장 소장"** 수준이에요.

- **장기 에이전트 작업** (Long-running agents)에서 강화
- **코딩 능력** 향상 — 복잡한 멀티파일 편집, 디버깅
- **전문 업무** (Professional work) 지원 강화

### Fast Mode도 바뀌었어요

Fast Mode(패스트 모드)는 Opus를 **2.5배 더 빠르게** 쓸 수 있는 옵션인데,  
이번에 Opus 4.8 → **Opus 5 기반**으로 바뀌었고 가격도 내려갔어요:

| 구분 | 이전 (Opus 4.8) | 현재 (Opus 5) |
|---|---|---|
| 입력 가격 | $30/백만 토큰 | **$10**/백만 토큰 |
| 출력 가격 | $150/백만 토큰 | **$50**/백만 토큰 |
| 속도 | 2.5배 빠름 | 2.5배 빠름 |

> 💡 **참고**: Fast Mode는 리서치 프리뷰 단계로, 소비 기반(Consumption) 플랜에서 이용 가능합니다. 구독 플랜 사용자는 사용량 크레딧으로 이용해요.

## Claude Fable 5.1 + Mythos 5.1 — 2026년 9월 1일 공식 발표 `[블]`

Anthropic이 **"코딩과 지식 작업에서 가장 앞선 모델"**이라고 발표했어요.

### Fable 5.1이란?

> 🔬 **비유**: Fable 5는 "프로 축구 선수"였는데,
> Fable 5.1은 **"올림픽 선수 수준으로 훈련받은 프로"** 정도예요.

- 코딩(Coding)과 지식 작업(Knowledge work)에서 최고 성능
- **과학 연구 보조** 기능을 처음으로 엿볼 수 있어요 — "AI 모델이 과학 발전에 어떻게 기여할 수 있는지 보여주는 초기 모습"
- Fable 5에서 이어진 안전장치 + 성능 개선 버전

### Mythos 5.1이란?

- Fable 5.1과 함께 발표된 동반 모델 (공식 발표 기준)
- "코딩·지식 작업에서 가장 앞선 모델"이라는 같은 설명 포함
- 구체적인 용도 차이는 추정 — Mythos 계열은 **특수 분야 심화 작업**에 특화된 것으로 알려짐

> ⚠️ **주의**: Fable 5.1/Mythos 5.1의 상세 벤치마크나 접근 방법은  
> 이 글 작성 시점(2026-09-14) 기준으로 추가 공식 발표를 기다리는 중이에요.

## Claude Code에서 모델 바꾸는 방법

```bash
# 기본 사용 (현재 기본값: Sonnet 5)
claude

# Opus 5로 전환
claude --model claude-opus-5

# Fable 5.1로 전환 (계정 접근 권한 필요)
claude --model claude-fable-5-1
```

또는 `settings.json`에서 고정:
```json
{
  "model": "claude-opus-5"
}
```

> 📌 **공식 문서**: [모델 설정 가이드](https://code.claude.com/docs/en/model-config)
