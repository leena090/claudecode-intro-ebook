## W30 (7월 20~24일)

### 1️⃣ Claude Opus 5 — 기본 Opus 모델 전환 🆕

[공식 발표는 7월 24일이었지만 W30부터 Claude Code에 적용됐어요.]

**Opus 5**가 Claude Code의 기본 Opus 모델이 됐어요.

```bash
# Opus 선택 시 자동으로 Opus 5 적용
/model claude-opus-5
```

> 🍱 **비유**: 스마트폰 기본 카메라 앱이 구형에서 신형으로 업그레이드된 것처럼, 별도 설정 없이 더 좋은 Opus를 자동으로 쓰게 됐어요.

### 2️⃣ Desktop에 iOS 시뮬레이터 창 추가

Claude Code Desktop에서 **iOS 앱을 빌드하면 내장 시뮬레이터 창이 열려요**.

더 이상 Xcode를 따로 열어 시뮬레이터를 확인할 필요 없이, Claude Code Desktop 화면 안에서 앱 미리보기가 가능해요.

> 🍱 **비유**: 이전에는 코드 작성과 앱 확인을 두 화면에서 해야 했다면, 이제는 하나의 화면 안에서 다 해결돼요.

### 3️⃣ Claude Security 플러그인 — 코드 취약점 자동 스캔

새로운 **Claude Security 플러그인**이 출시됐어요.

```bash
# 플러그인 설치 후
> 이 코드베이스에서 SQL 인젝션 취약점 찾아서 수정해줘
```

Claude가 코드베이스 전체를 스캔하고, 발견한 취약점에 대한 패치 제안을 바로 해줘요.

> 🍱 **비유**: 집에 보안업체 직원을 불러서 "여기 허술한 곳 없는지 봐줘"라고 하는 것처럼, Claude Code가 코드의 보안 허점을 직접 찾아줘요.

## W32 (8월 3~7일)

### 4️⃣ 세션 간 메시지 전송 — 여러 Claude가 서로 대화 📨

**Claude Code 세션끼리 메시지를 주고받을 수 있어요.** (`cross-session-messaging`)

```bash
# 다른 세션 목록 확인
/sessions

# 다른 세션에게 메시지 보내기
# (Claude Code가 자동으로 다른 세션과 협력)
```

> 🍱 **비유**: 이전에는 개발팀 직원들이 각자 혼자 일했다면, 이제는 직원 A가 직원 B에게 "이 작업 끝났어, 이제 네 차례야"라고 쪽지를 보낼 수 있어요.

**어떤 상황에 유용한가요?**
- 큰 프로젝트를 여러 세션으로 나눠 처리할 때
- 한 세션이 끝나면 다음 세션에 알림을 보낼 때
- 에이전트 팀 작업에서 세션 간 조율이 필요할 때

### 5️⃣ 자체 호스팅 환경 — 내 서버에서 Claude Code 클라우드 세션 실행

**Self-hosted environments(자체 호스팅 환경)** 기능이 추가됐어요.

클라우드 세션을 **내 회사 서버에서 직접 실행**할 수 있어요. 코드와 데이터가 외부로 나가지 않아도 돼요.

> 🍱 **비유**: 배달 앱에서 주문하되, 음식을 배달하는 건 우리 직원이 하는 것처럼 — Claude의 두뇌(AI)는 Anthropic에서 빌리되, 실제로 일하는 공간은 우리 서버를 쓸 수 있어요.

엔터프라이즈 보안이 중요한 팀에서 특히 유용해요.

### 6️⃣ Auto Mode가 기본 권한 모드로 변경 🔄

**Auto Mode(자동 모드)** 가 이제 Claude Code의 **기본 권한 모드**가 됐어요.

| 이전 기본 | 새 기본 |
|---|---|
| Manual(수동 확인) | **Auto Mode(자동 판단)** |

Auto Mode는 안전한 명령은 자동으로, 위험할 수 있는 명령은 허락을 구해요.

```bash
# 권한 모드 변경 (Shift+Tab으로도 전환)
# Auto Mode: 대부분 자동 실행, 위험 명령만 확인
# Manual Mode: 모든 변경 전에 확인
```

> 🍱 **비유**: 이전에는 모든 문서에 도장을 직접 찍어야 했다면, Auto Mode는 "일반 문서는 자동, 계약서만 저한테 가져와요"처럼 스마트하게 필터링해요.

## W33 (8월 10~14일)

### 7️⃣ Desktop 앱 — 사용 한도 초과 후 자동 재개 🔁

Claude Code Desktop이 이제 **사용 한도(usage limit) 초과 후 한도가 리셋되면 자동으로 작업을 재개**해요.

이전에는 사용 한도가 차면 작업이 멈추고, 수동으로 다시 시작해야 했어요. 이제는 Claude가 알아서 기다렸다가 다시 시작해요.

> 🍱 **비유**: 이전에는 갤러리에서 저녁 6시에 문을 닫으면 다시 아침에 와서 줄을 서야 했어요. 이제는 사전 예약을 해두면 아침에 자동으로 입장이 되는 것처럼요.

### 8️⃣ Fork 모드 기본 활성화

**Fork 모드(포크 모드)** 가 이제 기본으로 켜져 있어요.

Fork 모드를 쓰면 대화를 이전 지점으로 되돌린 후 새로운 방향으로 진행할 수 있어요. 이제 별도 설정 없이 항상 사용 가능해요.

```bash
# 이전 지점으로 되돌리기
/fork   # 또는 /rewind
```

> 🍱 **비유**: 게임에서 세이브 포인트처럼, 언제든 이전 지점으로 돌아가 다른 선택을 해볼 수 있어요.

### 9️⃣ GitLab 지원 확장 — MR 자동화 + 마켓플레이스

**GitLab 머지 리퀘스트(MR)** 와 **GitLab 플러그인 마켓플레이스**가 공식 지원돼요.

이전에는 GitHub 위주였다면, 이제 GitLab 팀도 Claude Code의 자동화 기능을 온전히 쓸 수 있어요.

| 기능 | GitHub | **GitLab** (신규) |
|---|---|---|
| PR/MR 자동 리뷰 | ✅ | ✅ |
| 플러그인 마켓플레이스 | ✅ | ✅ |
| CI/CD 통합 | ✅ | ✅ |

## W34 (8월 17~21일)

### 🔟 /design 스킬 — 편집 가능한 UI 목업 직접 생성

새 `/design` 스킬로 Claude Code가 **편집 가능한 UI 목업(artboard)을 직접 그려줘요**.

```bash
# 예시
> /design 대시보드 로그인 화면 만들어줘
```

결과물은 단순한 이미지가 아니라 **클릭해서 직접 편집할 수 있는 아트보드**예요. 요소를 선택하고 색상·크기·텍스트를 바꿀 수 있어요.

> 🍱 **비유**: 이전에는 디자이너에게 "이렇게 생긴 화면 만들어줘"라고 말로 설명해야 했다면, 이제는 Claude가 실제로 수정 가능한 스케치를 바로 그려줘요.

### 1️⃣1️⃣ Concise 출력 스타일 — 짧고 핵심만

**Concise(간결) 출력 스타일**이 추가됐어요.

```bash
# 간결 모드로 전환
/style concise

# 또는 설정에서
# outputStyle: "concise"
```

| 스타일 | 특징 |
|---|---|
| 기본 | 상세한 설명 포함 |
| **Concise** | 핵심만, 짧게 |
| 코드 중심 | 코드 위주 응답 |

> 🍱 **비유**: 레시피 앱에서 "초보자 설명 모드" vs "고수 간략 모드"처럼, 이미 잘 아는 분들은 Concise로 빠르게 답을 받을 수 있어요.

### 1️⃣2️⃣ 폰에서 내 컴퓨터 Claude Code 세션 시작

이제 **스마트폰에서 내 로컬 컴퓨터의 Claude Code 세션을 시작할 수 있어요**.

Remote Control 기능이 확장돼서, 단순히 기존 세션을 이어가는 것뿐 아니라 **새 세션을 폰에서 시작**하는 것도 가능해요.

> 🍱 **비유**: 이전에는 퇴근 후 집에서 회사 컴퓨터를 켜야 했다면, 이제는 지하철에서 폰으로 "내일 아침까지 이 작업해놔" 하고 세션을 시작할 수 있어요.
