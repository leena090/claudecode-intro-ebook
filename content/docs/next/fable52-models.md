## Fable 5.2 & Mythos 5.2란?

2026년 11월 9일, Anthropic이 **최상위 모델 두 종을 동시에 발표**했습니다.

> 🍱 **비유로 설명하면**: 스마트폰으로 치면 갤럭시 S26 Ultra의 "최고 성능 버전"과 "최고 연구 버전"이 동시에 나온 것과 같아요. 일반 사용자는 Fable, 연구자·특수 목적은 Mythos라고 보면 됩니다.

공식 설명: *"코딩, 금융, 과학 분야에서 새로운 기준을 세운 가장 강력한 모델들"*

---

## 두 모델의 차이점

| | **Claude Fable 5.2** | **Claude Mythos 5.2** |
|--|---------------------|----------------------|
| 성격 | 범용 최고 성능 | 고난도 기술 특화 |
| 주요 강점 | 코딩, 복잡한 추론 | 과학, 수학, 금융 연구 |
| 접근성 | Claude Code에서 사용 가능 | 주로 API·특수 플랜 |
| 한국 사용 가능? | 추정 — 이전 수출통제 이력 있음¹ | 추정 — 동일 |

> ¹ 2026년 6월, Fable 5와 Mythos 5는 미국 정부 수출통제로 일시 접근이 제한된 적이 있었어요. 5.2 버전에서는 추가 안전장치가 적용되어 복귀한 것으로 보입니다. 공식 발표 기준.

---

## Claude Code에서 어떻게 활용하나요?

```bash
# Fast Mode로 Fable 사용
/fast  # Fast Mode 활성화 (현재 Opus 5.5 기준, Fable 5.2로 전환될 수 있음)

# 모델 직접 지정 (ID는 추정)
claude --model claude-fable-5-2
```

> ⚠️ **추정**: 모델 접근 방법은 플랜과 지역에 따라 다를 수 있습니다. Claude Code `/config`에서 사용 가능한 모델을 확인하세요.

## 어떤 작업에 쓰면 좋을까요?

### Fable 5.2가 빛나는 순간 🌟

- **대규모 레거시 코드 마이그레이션**: 수만 줄짜리 오래된 코드를 최신 패턴으로 변환
- **복잡한 아키텍처 설계**: 여러 서비스가 얽힌 시스템 재설계
- **멀티스텝 에이전트 작업**: 며칠짜리 대형 프로젝트를 Claude가 혼자 진행

### Mythos 5.2가 빛나는 순간 🔬

- 과학 논문 분석 및 코드 구현
- 금융 모델 개발 (공식 발표 기준 — "금융 분야 새로운 기준")
- 수학적 증명이 필요한 알고리즘 개발

```
Mythos 5.2  ← 최고난도 기술 특화 (Nov 2026)
Fable 5.2   ← 범용 최고 성능 (Nov 2026)
Opus 5.5    ← 에이전트 코딩 1위 (Sep 2026)
Sonnet 5.5  ← 균형 추천 모델 (Sep 2026)  ← 입문자 추천 ✅
Haiku 5.5   ← 초고속 경량 (Oct 2026)
```

처음 시작하는 분들은 여전히 **Sonnet 5.5**를 추천합니다. Fable·Mythos는 더 많은 비용이 필요하고, 일반 코딩 작업에서는 Sonnet 5.5로도 충분히 훌륭한 결과를 얻을 수 있어요. 🙂
