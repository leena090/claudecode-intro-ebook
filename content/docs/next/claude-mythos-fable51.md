## Claude Fable 5.1 — 코딩의 새 기준

### 무엇이 달라졌나요?

**Claude Fable 5.1** (`claude-fable-5-1`)은 Fable 5의 성능을 한 단계 더 끌어올린 업데이트 버전이에요.

| 항목 | 내용 |
|---|---|
| **모델 ID** | `claude-fable-5-1` |
| **강점** | 코딩, 지식 집약 업무, 다단계 추론 |
| **위치** | Claude 모델 라인업 최상위 |

### 어떤 작업에 좋을까요?

```
💻 복잡한 버그 수정 — 여러 파일에 걸친 원인 추적
📐 시스템 설계 — 대규모 아키텍처 제안
📚 깊은 연구 — 최신 논문·문서 분석·요약
🔬 과학 계산 — 수식 검증, 데이터 분석
```

> 🍱 **비유로 설명하면**: Sonnet이 "만능 사원"이라면 Fable 5.1은 **10년 경력 시니어 개발자**예요. 단순 작업보단 어렵고 복잡한 것을 맡길 때 진가를 발휘합니다.

## Claude Mythos — 과학 연구의 AI 동반자

### 연구자를 위한 특별 모델

**Claude Mythos**는 과학 연구에 최적화된 최상위 모델이에요. 코딩뿐 아니라 **과학적 추론**과 **연구 보조** 능력이 특히 뛰어납니다.

| 특징 | 내용 |
|---|---|
| **연구 능력** | 실험 설계, 가설 검토, 논문 분석 |
| **코딩 + 과학** | 연구 코드 작성과 과학적 해석 동시 수행 |
| **미래 비전** | "AI가 과학 발전에 직접 기여하는 초기 모습" |

## Claude Code에서 사용하기

### 모델 선택 방법

```bash
# 특정 모델 지정해서 실행
claude --model claude-fable-5-1

# 설정 파일에서 고정
# .claude/settings.json
{
  "model": "claude-fable-5-1"
}
```

### 언제 쓸까요?

| 상황 | 추천 모델 |
|---|---|
| 일상적인 코딩 작업 | Sonnet 5.5 (기본) |
| 복잡한 버그, 설계 리뷰 | Fable 5.1 |
| 과학 연구, 논문 분석 | Mythos |
| 빠른 단순 작업 | Haiku 5.5 |

> 🍱 **비유로 설명하면**: 자전거(Haiku) → 승용차(Sonnet) → SUV(Fable) → 레이싱카(Mythos). 용도에 맞는 차를 타세요. 동네 마트 가는 데 레이싱카가 필요하진 않아요!
