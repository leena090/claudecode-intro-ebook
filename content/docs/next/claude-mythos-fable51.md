## Mythos와 Fable 5.1이 뭔가요?

Anthropic의 모델 라인업에서 **가장 위에 있는 두 모델**이에요.

> 🏔️ **비유로 설명하면**: 등산로에 비유하면 이래요.
> - **Haiku** — 동네 산책로 (가볍고 빠름)
> - **Sonnet** — 중급 등산로 (일상 코딩에 적합)
> - **Opus** — 고급 등산로 (복잡한 작업)
> - **Fable** — 국립공원 정상 코스 (최고 난이도)
> - **Mythos** — 에베레스트 (최전선 연구용)

| 항목 | Claude Fable 5.1 | Claude Mythos |
|---|---|---|

| 접근 방식 | 일반 사용자 | 전문가 인증 필요 가능 |

## Fable 5.1이 5와 다른 점

Fable 5는 2026년 6월에 글로벌 복귀했던 모델이에요. **.1 버전**으로 업그레이드된 주요 변화는:

- **코딩 성능 향상**: 에이전트 코딩 벤치마크에서 성능 개선 (공식 발표 기준)
- **지식 작업 강화**: 복잡한 분석·문서 작업에서 정확도 향상

## Claude Mythos — 처음 등장한 이름

Mythos는 **이전에 없던 새로운 계층**이에요. Anthropic은 "연구 능력이 AI 모델이 과학 발전에 기여하는 방식을 처음으로 보여주는 사례"라고 설명했어요.

> 🔬 **과학 연구와 코딩**: Mythos는 코딩을 넘어서 **복잡한 과학적 문제 해결**을 지원해요. 예를 들어 약물 후보 물질 탐색, 생명과학 데이터 분석 같은 영역이에요.

## Life Sciences Verification Program (생명과학 인증 프로그램)

Sep 17, 2026에 같이 나온 프로그램이에요.

- **대상**: 생명과학 분야 전문가 (연구자, 의학자 등)
- **혜택**: Claude Mythos, Opus, Sonnet 모델에 생명과학 관련 **완화된 안전 설정** 적용
- **의미**: 전문가에게는 더 많은 자유도를 주면서, 일반 사용자에게는 안전을 유지하는 방식

> ⚠️ **참고**: 인증 프로그램은 자격 요건이 있으며 Anthropic의 심사가 필요해요. (공식 발표 기준)

## 한국어 코딩 입문자에게는?

솔직히 말씀드리면, **Mythos는 일반 코딩 입문자보다는 연구자·고급 사용자**를 위한 모델이에요.

하지만 **Fable 5.1**은 다릅니다:
- Claude Code 콘솔에서 모델 선택 시 이용 가능 (요금제에 따라 다름)
- 어려운 버그, 복잡한 리팩터링에서 차이를 느낄 수 있어요

> 💡 **실용적 조언**: 일반 코딩은 Sonnet 5.5로 충분해요. Fable 5.1은 "어떻게 해도 안 풀리는 문제"가 생겼을 때 꺼내는 '비장의 카드'로 생각하세요.
