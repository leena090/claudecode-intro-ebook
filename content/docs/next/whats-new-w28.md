### 1️⃣ Desktop 내장 브라우저 — 외부 사이트도 바로 열어요 🌐

Claude Code Desktop 앱에 **빌트인 브라우저**가 생겼어요. 이제 Claude가 로컬 개발 서버뿐 아니라 **외부 사이트도** 직접 열고 조작할 수 있어요.

> 🍱 **비유**: 지금까지 Claude에게 "이 외부 문서 페이지 확인해봐"라고 하면 Claude가 "직접 가서 복사해오세요"라고 했다면, 이제는 Claude가 직접 그 페이지를 열고 내용을 읽고 클릭까지 해줘요.

**무엇이 가능해지나요?**

| 기능 | 예시 |
|---|---|
| 외부 문서 참조 | "이 npm 패키지 공식 문서에서 API 사용법 찾아줘" |
| 디자인 시안 확인 | "피그마 공유 링크 열고 버튼 색상 확인해줘" |
| 외부 사이트 테스트 | 스테이징 서버와 프로덕션 화면 비교 |

**안전 장치:**

| 항목 | 설명 |
|---|---|
| 샌드박스 격리 | 브라우저 세션은 앱과 분리되어 실행돼요 |
| 세션 유지 여부 선택 | 브라우저 세션을 유지할지 매번 초기화할지 설정 가능 |
| 안전 분류기 | 외부 사이트 작업은 자동으로 안전성 검토를 거쳐요 |

<div class="note-circle">
○ Claude Desktop (macOS·Windows·Linux 베타) 전용 기능이에요<br />
○ 세션 유지 여부는 Desktop 설정에서 조절 가능
</div>

### 2️⃣ `/doctor` — 이제 문제를 직접 고쳐줘요 🩺

`/doctor` 명령어가 대폭 업그레이드됐어요. 이전엔 보고서만 출력했지만, **이제는 문제를 직접 수정**해요.

```text
> /doctor
```

또는 별칭:
```text
> /checkup
```

> 🍱 **비유**: 예전 `/doctor`가 "혈압이 높네요, 운동하세요"라고만 말하던 의사였다면, 이제는 "혈압이 높네요, 지금 바로 처방전 드릴게요. 괜찮으세요?"라고 직접 처방까지 해주는 의사예요.

**진단 항목:**

| 항목 | 설명 |
|---|---|
| 설치 상태 | Claude Code 설치 이상 여부 확인 |
| 미사용 스킬·MCP·플러그인 | 컨텍스트 비용만 잡아먹는 미사용 항목 감지 |
| `CLAUDE.md` 중복 | 로컬 파일이 저장소 파일과 중복되면 정리 제안 |
| `CLAUDE.md` 최적화 | Claude가 코드베이스에서 직접 파악할 수 있는 내용은 제거 제안 |
| 느린 훅 | 세션 속도를 떨어뜨리는 훅 감지 |

**동작 방식:**
1. 전체 진단 먼저 실행
2. 수정할 내용을 목록으로 보여줌
3. **"수정할까요?"** 확인 후 실행

<div class="note-circle">
○ v2.1.205 이상에서 사용 가능해요<br />
○ 확인 없이 자동 수정하지 않아요 — 항상 먼저 물어봐요<br />
○ <code>/checkup</code>은 <code>/doctor</code>의 별칭이에요
</div>
