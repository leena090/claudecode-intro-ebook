### 1️⃣ Desktop 내장 브라우저 — 외부 사이트 탐색 🌐

Claude Code 데스크톱 앱에 **브라우저가 내장**됐어요. Claude가 공식 문서, 디자인 참고 사이트, 어떤 외부 사이트든 직접 열어서 읽고, 클릭하고, 상호작용할 수 있어요.

> 🍱 **비유**: 이전에는 Claude가 "이 라이브러리 공식 문서 보고 코드 짜줘"라고 하면 내가 링크를 복사해서 줘야 했어요. 이제는 Claude가 스스로 `react.dev`를 열어서 최신 문서를 읽고 코드를 짜줘요. 내 로컬 개발 서버와 외부 사이트를 동시에 다룰 수 있어요.

**가능한 작업:**
- 공식 문서 직접 열어서 읽기
- 디자인 시안(Figma, 이미지 등) 보면서 구현
- 외부 서비스와 상호작용
- 내 로컬 개발 서버 + 외부 사이트 함께 테스트

**보안 설계:**
- 브라우저는 **샌드박스** 처리됨
- 외부 사이트 접근 시 **안전 분류기**가 동작 검토
- 브라우징 세션 지속 여부 직접 설정 가능

<div class="note-circle">
○ Desktop 앱 전용 기능 (CLI에서는 Chrome 확장 사용)<br />

</div>

### 2️⃣ `/doctor` — 설치 전체 진단 + 자동 수정 🩺

`/doctor` 명령어가 단순 리포트에서 **진단 → 수정**까지 한 번에 처리하도록 업그레이드됐어요. `/checkup`으로도 실행할 수 있어요.

> 🍱 **비유**: 병원에서 건강검진받으면 의사가 "이런 문제가 있네요, 수술이나 약 처방을 해드릴게요"라고 하잖아요. 이전 `/doctor`는 검진 결과만 알려줬다면, 이제는 직접 "고쳐드릴까요?" 물어보고 수정까지 해줘요.

```
> /doctor
```

**진단 항목:**

| 항목 | 확인 내용 |
|---|---|
| 설치 상태 | Claude Code 버전, 의존성 확인 |
| 미사용 스킬/플러그인 | 설치됐지만 사용 안 하는 것들 (컨텍스트 낭비) |
| MCP 서버 | 설정됐지만 사용되지 않는 서버 |
| CLAUDE.md 중복 | 로컬 파일이 레포에 체크인된 것과 동일한 내용 |
| CLAUDE.md 최적화 | Claude가 코드베이스에서 유추 가능한 내용 제거 제안 |
| 느린 훅 | 응답 속도를 느리게 하는 훅 감지 |

**동작 방식:**
1. 진단 결과를 먼저 보여줌
2. "수정할까요?" 확인 후 변경 진행
3. 원하지 않으면 리포트만 보고 종료 가능
