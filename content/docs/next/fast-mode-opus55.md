## Fast Mode가 뭐였더라?

Fast Mode(패스트 모드)는 Claude Code에서 강력한 모델을 **2.5배 더 빠르게** 쓸 수 있는 특별 설정이에요.

마치 고속도로 하이패스처럼, 요금을 조금 더 내는 대신 기다림 없이 빠르게 통과하는 거라고 보면 됩니다.

---

## 이번에 뭐가 바뀌었나요?

### ① 대상 모델 교체: Opus 4.8 → Opus 5.5

| 항목 | 이전 (2026-05 ~ 2026-10) | 이후 (2026-10 기준) |
|------|--------------------------|---------------------|
| 대상 모델 | Claude Opus 4.8 | **Claude Opus 5.5** |
| 속도 | 2.5배 빠름 | 2.5배 빠름 (유지) |
| 성능 | Opus 4.8 수준 | **Opus 5.5 수준** (더 강력) |

더 강력해진 Opus 5.5에 Fast Mode가 적용됐습니다. 같은 속도에 더 좋은 성능이에요.

### ② 가격 대폭 인하: $30/$150 → $8/$40

| 항목 | 이전 | 이후 |
|------|------|------|
| 입력 토큰 (100만개) | $30 | **$8** |
| 출력 토큰 (100만개) | $150 | **$40** |
| 절감률 | — | **약 73% 인하** |

> 💡 토큰(Token)은 글자를 잘게 쪼갠 단위예요. 한국어 1글자가 보통 1~2토큰, 영어 단어 1개가 약 1토큰입니다.

### 비유로 이해하기

프리미엄 택시를 탈 때 기본요금이 3만원이었는데 갑자기 8천원으로 내려간 거예요. 그것도 차는 더 좋아졌는데요!

## Fast Mode를 언제 쓰면 좋을까요?

**쓰면 좋은 경우:**
- ⏰ 응답이 너무 느려서 답답할 때
- 🔄 같은 코드를 반복해서 수정할 때
- 🚀 배포 직전 빠른 버그 수정이 필요할 때

**안 써도 되는 경우:**
- 🕐 시간이 충분할 때 (일반 모드로도 충분)
- 💰 API 요금을 아끼고 싶을 때 (Fast Mode는 더 비쌈)

---

## Fast Mode 켜는 방법

Claude Code에서 `/fast` 명령어를 입력하면 On/Off를 전환할 수 있어요.

```
/fast
```

또는 대화창 상단의 **Fast** 토글 버튼을 클릭하면 됩니다.
