## 왜 3종이 한꺼번에 나왔나요?

Claude 5 (Sonnet 5, Fable 5 등)가 2026년 6~7월에 출시된 지 두 달 만에, Anthropic이 **5.5 버전**을 내놨어요. "5.5"는 **5의 업그레이드판**이에요. 더 빠르고, 더 저렴하고, 성능도 더 좋아진 버전이라고 생각하면 됩니다.

> 📱 **비유로 설명하면**: 스마트폰 "갤럭시 S25"가 나온 지 몇 달 후에 "갤럭시 S25 FE(팬에디션)"이 나오는 것처럼, 같은 세대에서 더 실속 있는 버전이 나왔어요.

| **Claude Haiku 5.5** | 2026-10-07 | 가장 빠른 소형 모델, 고용량 작업 특화 | 요약, 서브에이전트, 브라우저 자동화 |

## 모델별 자세히 알아보기

### 🔵 Claude Opus 5.5 (Sep 22)

"에이전트 코딩과 지식 작업에서 최고 성능"이라고 Anthropic이 발표했어요.

- **성능**: 코딩 에이전트 벤치마크 최상위권 (공식 발표 기준)
- **가격**: Opus 5 대비 **40% 저렴** — 같은 성능을 더 낮은 비용에 쓸 수 있어요
- **Fast Mode 적용**: Fast mode가 이제 Opus 5.5 기반으로 바뀌었어요

> 💡 **Opus를 쓰면 언제 좋아요?** 며칠짜리 대형 리팩터링, 복잡한 버그 추적, 긴 문서 생성처럼 **오래 걸리는 고급 작업**에 어울려요.

---

### 🟢 Claude Sonnet 5.5 (Sep 28)

일상적인 코딩 작업의 주력 모델. "Sonnet 5의 명확한 업그레이드"라는 표현을 Anthropic이 사용했어요.

- **속도**: Sonnet 5보다 **30% 이상 빠름**
- **가격**: 대부분의 작업에서 **최대 30% 저렴**
- **기본 모델**: Claude Code 표준 사용자라면 주로 이 모델을 만나게 돼요

> 💡 **Sonnet을 쓰면 언제 좋아요?** 매일 쓰는 코드 작성, PR 리뷰, 테스트 작성 등 **반복 작업**에 최적이에요. 빠르고 저렴하니까요.

---

### 🟡 Claude Haiku 5.5 (Oct 7)

"가장 빠른, 가장 유능한 소형 모델"이라는 설명이 붙었어요. 특히 **서브에이전트**와 **브라우저 자동화**에 맞게 설계됐어요.

- **속도**: Claude 모델 중 가장 빠름
- **용도**: 요약, 분류, 서브에이전트 실행, 브라우저 use
- **특징**: 고용량 반복 작업에 경제적

> 💡 **Haiku를 쓰면 언제 좋아요?** 에이전트가 수십 개씩 병렬로 돌아가는 Dynamic workflows처럼 **대량 처리 작업**에서 비용 절감에 유리해요.

## Fast Mode 가격 변경 정리

마케팅 페이지 기준으로 Fast mode에 큰 변화가 있었어요.

| 항목 | 이전 (Opus 4.8 기준) | 현재 (Opus 5.5 기준) |
|---|---|---|
| 기반 모델 | Claude Opus 4.8 | **Claude Opus 5.5** |
| 입력 토큰 (per million) | $30 | **$8** |
| 출력 토큰 (per million) | $150 | **$40** |
| 속도 | 2.5배 빠름 | 저지연 고속 |

> ⚠️ **참고**: Fast mode는 리서치 프리뷰 상태이며, 소비 기반 플랜(Consumption plan)에서 이용 가능해요. 구독 플랜 사용자는 사용 크레딧으로 이용합니다. (공식 발표 기준)
