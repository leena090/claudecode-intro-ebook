## 🔑 `claude mcp login` — 터미널에서 MCP 서버 인증 (v2.1.186)

### 기존 방식의 불편함

MCP 서버에 로그인하려면 세션을 열고 `/mcp` 메뉴를 탐색해서 인증을 진행해야 했어요. 스크립트 자동화나 빠른 재인증이 필요할 때 번거로웠죠.

> 🍱 **비유**: 매번 앱을 켜서 설정 메뉴 → 계정 → 로그인 순서를 거치는 것과 비교해, 이제는 터미널 한 줄로 바로 로그인하는 거예요.

### 새 명령어

```bash
# MCP 서버 로그인 (OAuth 인증 흐름 시작)
claude mcp login sentry

# 특정 서버 로그아웃
claude mcp logout sentry
```

`claude mcp login <서버이름>`을 실행하면 **브라우저에서 OAuth 인증 화면**이 열리고, 완료되면 인증 정보가 저장돼요. 이후 세션을 다시 열 때 별도 로그인 없이 바로 사용할 수 있어요.

<div class="note-circle">

○ 세션을 새로 시작하지 않아도 돼요 — 터미널 어디서나 실행 가능  
○ `/mcp` 메뉴의 인증 기능과 동일한 결과예요  
○ CI 파이프라인은 개발자 승인이 필요한 OAuth 흐름 특성상 이 방식을 사용할 수 없어요

</div>

## ⚡ `!` 명령어 — 실행 후 Claude 자동 응답 (v2.1.186)

### 기존 `!` 명령어 사용 방식

세션 안에서 `!` 를 붙이면 셸 명령을 바로 실행할 수 있었어요. 하지만 결과가 화면에 나오면 끝이었고, Claude의 분석을 받으려면 추가로 메시지를 보내야 했어요.

### 이제 결과에 Claude가 자동 응답해요

```
> ! npm test
```

테스트 결과가 출력되고 나면 **Claude가 자동으로 내용을 분석해서 설명**해줘요. 실패한 테스트가 있다면 이유를 설명하고 수정 방향도 제안해요.

> 🍱 **비유**: 성적표를 받았을 때 선생님이 바로 옆에 있어서 "이 과목이 왜 낮은지, 어떻게 올릴 수 있는지" 바로 설명해주는 것과 같아요.

### 비용과 설정

| 항목 | 내용 |
|---|---|
| 비용 | 일반 프롬프트를 보내는 것과 동일하게 청구 |
| 이전 동작으로 되돌리기 | `settings.json`에서 `"respondToBashCommands": false` |

```json
// 이전 동작으로 되돌리기 (결과만 컨텍스트에 추가, 응답 없음)
{
  "respondToBashCommands": false
}
```

<div class="note-circle">

○ `! 명령어`로 실행되는 명령에만 적용돼요  
○ 자동완성도 강화됐어요 — `!` 뒤에 파일 경로 입력 시 자동완성 지원

</div>

## ⏪ `/rewind` — `/clear` 이전으로 대화 되감기

### 상황: /clear를 실수로 눌렀을 때

긴 코딩 세션 도중 `/clear`를 쳐서 컨텍스트가 다 지워진 경험 있으신가요? 이제 `/rewind`로 `/clear` **이전 시점으로 되돌릴 수 있어요.**

> 🍱 **비유**: 문서 편집 중에 "전체 선택 후 삭제"를 했더라도 Ctrl+Z로 되돌릴 수 있는 것과 같아요.

```
> /rewind
```

`/rewind`를 실행하면 직전 `/clear` 이전의 대화 상태로 복구돼요.

## 📦 이번 주 기타 개선

| 기능 | 내용 |
|---|---|
| **`sandbox.credentials` 설정** | 샌드박스 명령이 자격증명 파일과 시크릿 환경변수를 읽지 못하도록 차단 |
| **조직 모델 제한 강화** | 어드민이 설정한 모델 제한이 `/model`, `--model`, `ANTHROPIC_MODEL`, 모델 선택기 UI 모두에 적용됨 |
| **서브에이전트 권한 프롬프트 개선** | 백그라운드 서브에이전트가 권한 요청 시 메인 세션에 표시 (이전에는 자동 거부됐음). 어떤 에이전트인지도 표시 |
| **스트리밍 CPU 37% 절감** | 응답 스트리밍 시 CPU 사용량이 약 37% 줄어들어 더 빠르고 조용하게 작동 |
| **긴 세션 메모리 개선** | 터미널 출력 캐시로 인한 장기 세션 메모리 증가 현상 개선 |
| **`/review <pr>`** | 이제 `/code-review medium`과 동일한 리뷰 엔진 사용 |
| **샌드박스 네트워크 허용 호스트 기억** | 허용한 호스트가 세션 종료 전까지 기억됨 (이전에는 매번 재확인 요청) |
| **`/install-github-app` 개선** | GitHub App만 설치하고 Actions 워크플로우·시크릿 설정 단계는 건너뛸 수 있는 옵션 추가 |
