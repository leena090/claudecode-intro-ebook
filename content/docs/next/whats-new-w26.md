## ① `claude mcp login` — 터미널에서 MCP 서버 인증 (v2.1.186)

### 이게 뭔가요?

지금까지 MCP(엠씨피) 서버를 인증하려면 Claude Code를 열고 `/mcp` 메뉴에 들어가야 했어요. 이제는 **터미널(명령 프롬프트)에서 직접** 로그인할 수 있습니다.

> 🏧 **비유로 설명하면**: 인터넷뱅킹을 쓰려면 은행 앱을 열어야 했는데, 이제 터미널 창에서 `bank login`만 입력하면 바로 로그인되는 거예요.

### 사용 방법

```bash
# sentry(센트리) 서버 로그인
claude mcp login sentry

# 로그아웃
claude mcp logout sentry
```

- **세션을 열지 않아도** OAuth(오어스) 플로우가 바로 실행됩니다
- 저장된 자격증명이 사용되므로 다음에 Claude Code를 열면 바로 연결

### 어떤 MCP 서버에 쓸 수 있나요?

GitHub, Sentry, Linear 등 **OAuth 인증이 필요한 모든 MCP 서버**에 사용 가능합니다.

## ② `! 명령` 자동 응답 — 실행 결과를 Claude가 바로 분석 (v2.1.186)

### 이게 뭔가요?

Claude Code의 쉘 모드(Shell mode)에서 `!` 접두사로 명령을 실행하면, 지금까지는 결과가 대화창에 추가되기만 했어요.

이제는 **명령 실행 결과가 나오면 Claude가 자동으로 분석해줍니다** — 별도 질문 없이도요.

> 📝 **비유로 설명하면**: 선생님께 시험 답안지를 제출하면 그 자리에서 바로 채점해주시는 거예요. 예전엔 제출하고 나서 "이 결과 봐줄래요?"라고 다시 물어봐야 했는데, 이제는 제출하면 자동으로 피드백이 옵니다.

### 사용 방법

```
> ! npm test
```

→ 테스트가 실행되고, 실패한 테스트가 있으면 Claude가 자동으로 **원인과 해결 방법**을 설명해줘요.

```
> ! git diff HEAD~1
```

→ diff 결과가 나오면 Claude가 자동으로 **변경 내용을 요약**해줘요.

### 자동 응답을 끄고 싶다면?

```json
.claude/settings.json
{
  "respondToBashCommands": false
}
```

→ 기존처럼 결과가 대화 맥락에 추가만 되고 자동 응답은 없어요.

> 💡 **비용 참고**: 자동 응답은 일반 메시지를 보내는 것과 같은 비용이 청구됩니다.

## ③ `/rewind` 확장 — `/clear` 이전으로도 되돌아가기

### 이게 뭔가요?

`/clear`로 대화를 지웠는데, 아까 맥락이 필요할 때가 있죠? 이제 `/rewind`로 **`/clear` 이전 대화**로도 돌아갈 수 있어요.

> 🎬 **비유로 설명하면**: 화이트보드를 지웠는데 실수한 걸 깨달았을 때, 칠판 지우개를 "되감기"할 수 있게 된 거예요. 일종의 대화 타임머신입니다.

### 사용 방법

```
> /rewind
```

→ 대화 기록에서 돌아갈 지점을 선택할 수 있어요. `/clear` 이전 상태도 포함됩니다.

| 항목 | 내용 |
|------|------|
| CPU 37% 절약 | 스트리밍 응답 처리 최적화 |
| 장기 세션 메모리 감소 | 터미널 출력 캐시로 인한 메모리 증가 문제 개선 |

배경에서 실행 중인 서브에이전트(Subagent)가 권한을 요청할 때, 이제 **메인 세션에 팝업**으로 표시됩니다.

- 어떤 에이전트가 요청하는지 표시
- Esc 키를 누르면 그 에이전트의 해당 도구만 거부 (다른 에이전트 영향 없음)

> 📌 이전에는 백그라운드 서브에이전트의 권한 요청이 자동 거부되어 작업이 실패하는 경우가 있었어요.
