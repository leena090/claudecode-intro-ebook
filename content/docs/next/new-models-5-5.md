## 한눈에 보기 — 5.5 시리즈 3종

Anthropic이 2026년 9~10월에 걸쳐 모델 3개를 차례로 업데이트했어요.

> 🍱 **비유로 설명하면**: 자동차 신형 모델처럼, 차체(아키텍처)는 같지만 엔진 튜닝(학습)을 다시 해서 연비(비용)는 더 좋고 최고속도(성능)도 올라갔어요.

| 모델 | 출시일 | 핵심 변화 | 이전 대비 |
|------|-------|----------|---------|
| **Opus 5.5** | 2026-09-22 | 에이전틱 코딩·지식 업무 1위 | 비용 40% ↓ |
| **Sonnet 5.5** | 2026-09-28 | Sonnet 5 대비 명확한 업그레이드 | 30%+ 빠름, 최대 30% 저렴 |
| **Haiku 5.5** | 2026-10-07 | 가장 빠른 소형 모델 | 요약·서브에이전트·브라우저 특화 |

---

## Claude Opus 5.5 — 에이전틱 코딩의 새 챔피언

### 뭐가 달라졌나요?

Opus 5.5는 **에이전틱 코딩**(장시간 자율 작업)과 **지식 업무**(복잡한 문서 작성·분석)에서 벤치마크 1위를 기록했어요.

가장 중요한 변화는 **비용**: 일반적인 워크로드에서 Opus 5보다 **40% 저렴**하게 실행돼요.

> 🍱 **비유**: 이전엔 고급 레스토랑 풀코스 가격이었다면, 이젠 같은 맛인데 점심 특선 가격으로 즐길 수 있게 된 거예요.

### Claude Code에서 쓰려면?

```text
> /model claude-opus-5-5
```

또는 Fast Mode에서 Opus 5.5를 사용하면 더 빠른 응답과 함께 에이전틱 작업을 할 수 있어요.

---

## Claude Sonnet 5.5 — 빠르고 실용적인 업그레이드

### 뭐가 달라졌나요?

Sonnet 5.5는 "**명확한 업그레이드**"라는 표현이 공식 발표에 쓰일 만큼, 전작 Sonnet 5보다 모든 면에서 나아졌어요.

- ⚡ **30%+ 더 빠름** — 같은 질문에 훨씬 빠른 응답
- 💸 **최대 30% 저렴** — 대부분의 작업에서 비용 절감
- 🎯 **일반 코딩·분석 최적** — 대부분의 일상 Claude Code 사용에 적합

### 언제 써야 좋을까요?

| 상황 | 추천 |
|------|------|
| 일상적인 코드 작성·수정 | ✅ Sonnet 5.5 |
| PR 리뷰, 문서 작성 | ✅ Sonnet 5.5 |
| 복잡한 멀티스텝 에이전트 작업 | Opus 5.5 고려 |
| 빠른 요약·간단한 서브에이전트 | Haiku 5.5 |

---

## Claude Haiku 5.5 — 가장 빠른 소형 모델

### 뭐가 달라졌나요?

Haiku 5.5는 "**가장 빠르고, 가장 유능한 소형 모델**"로 소개됐어요. 특히 세 가지 용도에 집중 최적화됐어요:

1. 🗂️ **대량 요약** — 수백 개 파일 처리나 로그 분석
2. 🤖 **서브에이전트** — 멀티에이전트 시스템에서 개별 작업 담당
3. 🌐 **브라우저 사용** — 웹 자동화·크롤링 작업

> 🍱 **비유**: Haiku는 공장 라인의 '전문 공구'예요. 못 박는 데만 쓰는 망치처럼, 특정 반복 작업을 아주 싸고 빠르게 처리해요.

### Dynamic Workflows에서의 활용

[동적 워크플로우](/docs/advanced/dynamic-workflows)에서 수십~수백 개의 서브에이전트를 돌릴 때, 개별 서브에이전트에 Haiku 5.5를 배정하면 전체 비용을 크게 줄일 수 있어요.

```text
> /model claude-haiku-5-5  (서브에이전트 기본값으로 설정 시)
```

## 어떤 모델을 선택할까요?

```
복잡한 장시간 작업  →  Opus 5.5
일상 코딩 / 리뷰    →  Sonnet 5.5 (기본값)
빠른 단순 작업       →  Haiku 5.5
```

대부분의 Claude Code 사용자는 기본값인 Sonnet 5.5로 충분해요. Opus 5.5는 며칠짜리 대형 마이그레이션이나 복잡한 아키텍처 설계에 꺼내 쓰세요. Haiku 5.5는 멀티에이전트 서브작업 비용 절감용으로 활용하세요.
