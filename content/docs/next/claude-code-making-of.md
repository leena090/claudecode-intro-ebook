## Claude Code, 어떻게 탄생했나요?

> 🍱 **비유**: 지금 여러분이 쓰는 Claude Code는 어느 날 갑자기 뚝 떨어진 제품이 아니에요. 마치 동네 작은 빵집이 소문 나서 프랜차이즈가 된 것처럼, **내부 팀원 몇 명이 쓰던 실험적인 CLI**가 수백만 명의 개발자가 쓰는 제품이 된 이야기예요.

Anthropic이 공식 블로그를 통해 Claude Code 탄생의 내막을 공개했어요. 연구자·엔지니어·초기 사용자가 직접 이야기를 들려줘요.

---

## 시작: 내부 CLI 실험

Claude Code는 **Anthropic 내부에서 쓰던 비공개 CLI 도구**로 시작했어요.

초기 목표는 단순했어요: "Claude가 코드베이스를 직접 보면서 작업하면 어떨까?"

- 파일 읽기·쓰기 권한을 Claude에게 주면 어떻게 될까?
- 터미널 명령어를 Claude가 직접 실행하면?
- 단순한 Q&A가 아니라 실제 작업을 처리하면?

이 질문들로 내부 팀에서 조용히 실험이 시작됐어요.

---

## 성장: 동료들 사이에서 퍼지기 시작

처음에는 소수 엔지니어만 쓰던 도구가 **입소문으로 퍼지기 시작**했어요.

> 🍱 **비유**: 회사 구내식당에서 셰프가 직원들 몰래 시험하던 신메뉴가 "그거 어디서 먹었어요?"라는 질문을 받기 시작한 것과 같아요.

**초기 사용자들이 발견한 것:**
- 코드베이스 전체를 맥락으로 갖고 있는 AI와 작업하는 경험이 달랐어요
- "이 버그 찾아줘"가 아니라 실제로 파일을 열어 수정해주는 AI
- PR을 요청하면 실제로 커밋까지 만들어주는 경험

---

## 공개: 2025년 정식 출시

내부 실험을 넘어 **외부 개발자들에게 공개**하기로 결정했어요.

이 결정에는 용기가 필요했어요. 왜냐하면:
- 파일 쓰기·명령어 실행 권한을 가진 AI는 **잘못되면 큰일**이 날 수도 있으니까요
- 사용자가 실수로 "모든 파일 삭제해줘"라고 하면?
- 악의적인 코드가 AI를 통해 실행되면?

이 우려들을 해결하기 위해 **권한 모드 시스템, 훅, 샌드박스**가 만들어졌어요.

---

## 지금: Anthropic 대표 제품

2026년 현재 Claude Code는 Anthropic의 가장 빠르게 성장하는 제품 중 하나가 됐어요.

**수치로 보면:**
- Claude Code 팀이 기록한 **7.6배 더 잦은 배포**
- **14% 주간 배포 성장률**
- 전 직원 89% AI 채택률

> 🍱 **비유**: 동네 작은 빵집이 프랜차이즈가 됐지만, 초창기 "빵을 굽는 본질"은 그대로예요. Claude Code도 처음 그 실험 정신 — "AI가 실제로 일하게 하자" — 이 지금도 제품 전체에 흐르고 있어요.
