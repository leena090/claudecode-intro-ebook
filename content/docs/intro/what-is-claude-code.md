## Claude Code, 한마디로 뭔가요?

Claude Code는 **AI가 직접 코드를 짜주는 도구**입니다. Anthropic(앤쓰로픽)이라는 회사가 만들었어요.

여러분이 "이런 웹사이트 만들어줘", "이 파일 정리해줘"라고 말하면, Claude가 알아서 코드를 작성하고 파일을 만들어줍니다.

---

## 어디서 쓸 수 있나요?

Claude Code는 여러 곳에서 쓸 수 있습니다:

| 방식 | 어떻게 쓰나 | 특징 |
|------|-----------|------|
| **터미널** (CLI) | 컴퓨터 명령창에서 직접 실행 | 가장 강력, 이 가이드의 메인 |
| **VS Code 확장** | VS Code 에디터 안에서 사용 | 코드 편집과 동시에 |
| **JetBrains 플러그인** | IntelliJ, WebStorm 등에서 사용 | Java/웹 개발자용 |
| **Desktop 앱** | Claude Desktop 앱의 "Code" 탭 | 앱 하나로 채팅+코워크+코드 (4월 대규모 리디자인!) |
| **웹 버전** | claude.ai/code 접속 | 설치 없이 브라우저에서 바로 |

---

## 코딩을 모르는데, 가능한가요?

네. 이 가이드를 보고 있는 분 중에 코딩을 해본 적 없는 분도 많을 거예요. **그래도 됩니다.**

Claude Code의 핵심은 이거예요:
- 여러분은 **한국어로 원하는 걸 말합니다**
- Claude가 **코드를 대신 짜줍니다**
- 결과물(웹사이트, 앱, 자동화 도구)이 **바로 나옵니다**

> 마치 인테리어를 직접 못 해도, 인테리어 전문가에게 "이런 느낌으로 해주세요"라고 말하면 되는 것과 같아요.

---

## Claude Code는 뭘 할 수 있나요?

실제로 사람들이 이런 걸 만들고 있어요:

- 🌐 **웹사이트/랜딩페이지** — 내 사업 홍보 페이지를 직접 만들기
- 📊 **데이터 정리 도구** — 엑셀 파일 1000개를 자동으로 정리
- 🤖 **업무 자동화** — 매일 반복하는 작업을 AI가 대신
- 📱 **간단한 앱** — 매출 계산기, 예약 폼, 퀴즈 앱
- 📝 **문서 생성기** — 계약서, 보고서 템플릿 자동 생성

---

## 다른 AI 도구와 뭐가 다른가요?

ChatGPT나 일반 Claude 채팅과의 차이점:

| | 일반 AI 채팅 | Claude Code |
|---|---|---|
| 코드를 보여줌 | ✅ | ✅ |
| **코드를 직접 실행** | ❌ | ✅ |
| **파일을 직접 만들고 수정** | ❌ | ✅ |
| **여러 파일을 한꺼번에 작업** | ❌ | ✅ |
| **완성된 프로그램을 바로 실행** | ❌ | ✅ |

<mark>일반 AI는 "이렇게 하세요"라고 알려주고, Claude Code는 "제가 해드릴게요"라고 직접 합니다.</mark>

## 현재 사용 가능한 AI 모델

Claude Code에서 쓸 수 있는 AI 모델이 여러 개 있어요:

| 모델 | 특징 | 추천 상황 |
|------|------|----------|
| **Sonnet 4.6** | 빠르고 똑똑함 (기본값) | 대부분의 작업 |
| **Opus 4.7** | 가장 똑똑함 (최신, 2026-04-16 출시) | 복잡하고 어려운 작업 |
| **Haiku 4.5** | 가장 빠름 | 간단한 질문 |

세 모델 모두 **1M 토큰**을 지원합니다. 이게 무슨 말이냐면, 책 한 권 분량의 내용을 통째로 읽고 이해할 수 있다는 뜻이에요.
