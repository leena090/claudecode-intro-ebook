## Claude, 너무 많은데 뭘 써야 하죠?

Claude를 처음 접하면 헷갈립니다. "웹앱이 뭐고, 코워크가 뭐고, 코드가 뭐야?" 이 가이드 하나면 정리됩니다.

---

## 🏠 Claude의 4가지 공간

Claude에는 크게 **4가지 사용 공간**이 있습니다. 같은 AI지만 **용도가 다릅니다.**

| 공간 | 한마디 설명 | 누구를 위한 건가? |
|------|-----------|-----------------|
| **Claude 웹앱** (claude.ai) | 브라우저에서 채팅 + 문서 작성 | 모든 사람 |
| **코워크** (Cowork) | 내 컴퓨터를 AI가 직접 조작 | 사무직/자영업자 |
| **Claude Code** (터미널) | 코드 작성/수정 전문 도구 | 개발자/학습자 |
| **Claude Code 웹** (claude.ai/code) | 브라우저에서 코딩 | 개발자 |

> 💡 비유하자면:
> - 웹앱 = **카카오톡** (가볍게 대화)
> - 코워크 = **비서** (일을 맡기면 알아서 처리)
> - Claude Code = **전문 기술자** (공구를 들고 직접 만듦)
> - Claude Code 웹 = **원격 기술자** (내 컴퓨터 없어도 클라우드에서 작업)

## 🎯 "나는 이걸 쓰면 됩니다"

### 📌 "AI랑 그냥 대화하고 싶어요"
→ **Claude 웹앱** (claude.ai)
- 브라우저만 열면 바로 시작
- 문서 작성, 번역, 요약 등 일상 업무

### 📌 "엑셀 정리, PPT 만들기, 파일 분석을 맡기고 싶어요"
→ **코워크** (Cowork)
- Desktop 앱 설치 후 "코워크" 탭 클릭
- AI가 내 컴퓨터 파일을 직접 열어서 작업
- 출근길에 폰으로 일 시키고, 사무실 도착하면 완성

### 📌 "웹사이트, 앱, 프로그램을 만들고 싶어요"
→ **Claude Code** (터미널)
- 코드를 직접 작성하고 수정
- 이 가이드가 바로 Claude Code를 다루고 있습니다!

### 📌 "코딩은 하고 싶은데 설치가 귀찮아요"
→ **Claude Code 웹** (claude.ai/code)
- 브라우저에서 바로 코딩
- GitHub 연결만 하면 끝

## 🔄 서로 연결되나요?

네! Claude의 각 공간은 서로 연결됩니다.

```
📱 폰에서 코워크로 일 시키기
    ↓
💻 데스크톱에서 결과 확인
    ↓
⌨️ Claude Code로 수정
    ↓
☁️ Claude Code 웹에서 배포
```

### 실제 예시

1. **폰**에서 "이번 달 매출 데이터 정리해줘" (코워크 Dispatch)
2. 사무실 도착 → **데스크톱**에서 완성된 엑셀 확인 (코워크)
3. "이 데이터로 대시보드 웹페이지 만들어줘" → **Claude Code**
4. 완성된 웹페이지를 **Claude Code 웹**에서 자동 배포

## 💡 팁: 같은 채팅인데 뭐가 다른가요?

웹앱 채팅, 코워크 채팅, Claude Code 채팅 — 겉으로는 비슷해 보이지만:

| 구분 | 웹앱 채팅 | 코워크 채팅 | Code 터미널 채팅 |
|------|----------|-----------|----------------|
| 대화 스타일 | 일반 대화 | 작업 지시형 | 명령 실행형 |
| 파일 접근 | 업로드만 | 내 PC 전체 | 현재 폴더만 |
| 응답 방식 | 텍스트 답변 | 파일 생성/수정 | 코드 실행 |
| 중간에 자리 비워도 | 대기 | 계속 작업 | 대기 |
| 실행 취소 | 불가 | 불가 | ✅ /rewind |

> 💡 쉽게 말하면:
> - 웹앱 = "알려줘" (정보 제공)
> - 코워크 = "해줘" (작업 수행)
> - Code = "만들어줘" (코드 생성)

### 2. 경쟁 도구 대비 — "하나만 쓰지 말고 조합하세요" <code>[R]</code>

30일 실전 비교(Remis Haroon)와 커뮤니티 합의:

| 도구 | 강점 | 약점 | 정확도 (SWE-bench) |
|---|---|---|---|
| **Claude Code** | 🏆 정확도 압도적, 대규모 리팩토링, 보안 | 5~10분 느림 | **80.8%** |
| **Cursor** | ⚡ 속도, 코드베이스 탐색 | 정확도 보통 | ~65% (추정) |
| **Copilot** | 📝 보일러플레이트 자동완성 | 대규모 작업 약함 | - |

**커뮤니티 합의** <code>[R]</code>:
> *"Copilot is a better typist, Cursor is a better explorer, Claude Code is a better collaborator."*
> (Copilot은 타이피스트, Cursor는 탐색가, Claude Code는 협업자)

**추천 조합**:
- 일상 코딩·자동완성 → **Cursor/Copilot**
- 대규모 리팩토링·보안 감사·복잡한 설계 → **Claude Code**
