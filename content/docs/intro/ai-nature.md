## 왜 이 챕터를 먼저 읽어야 하나요?

Claude를 처음 쓰시는 분들에게 **가장 자주 듣는 불만**은 크게 네 가지예요.

> "AI가 거짓말을 해요."
> "혼내면 말을 또 바꿔요."
> "지침을 줬는데 안 지켜요."
> "지 맘대로 해요."

재밌는 건, 이 네 가지 모두 <mark>**AI의 성질을 몰라서 생기는 오해**</mark>라는 거예요. AI가 나쁜 게 아니라, **본래 그렇게 동작하도록 만들어진** 구조적 특성입니다. 특성을 이해하면, 같은 질문도 훨씬 정확하게 던지게 되고, 답변도 몇 배 좋아집니다.

이 챕터는 **나머지 모든 기능을 배우기 전 반드시 읽어야 할 선행 학습**이에요. 시간으로 치면 15~20분 분량입니다.

## PART 1. 할루시네이션 — "AI는 거짓말쟁이다?"

### 할루시네이션이 뭔가요?

AI가 사실이 아닌 내용을 **마치 사실인 것처럼 자신 있게** 말하는 현상입니다. 중요한 건 이게 <mark>**거짓말이 아니라 착각에 가깝다**</mark>는 거예요.

### 비유 — 길 묻는 사람

여러분이 길에서 "○○식당이 어디 있어요?"라고 물었다고 해보세요. 그 사람이 모르는데도 "아, 저기 오른쪽으로 가면 있을 거예요" 하고 자신 있게 대답하는 경우가 있잖아요. 일부러 속이려는 게 아니라 <mark>**대충 기억나는 걸 기반으로 '아마 맞겠지' 하고 말하는 것**</mark>입니다.

Claude도 똑같습니다. "모른다"고 말하는 대신, 학습된 패턴을 바탕으로 **'그럴듯한 답'을 만들어냅니다**. 의도적 거짓말이 아니라 구조적 한계예요.

### 왜 일어나는가

| 원인 | 설명 | 비유 |
|------|------|------|
| **학습 데이터의 한계** | 학습 시점 이후 정보는 모름 | 2025년에 졸업한 직원에게 2026년 뉴스를 물어보는 것 |
| **확률 기반 생성** | '가장 그럴듯한 다음 단어'를 이어붙이는 방식 | 빈칸 채우기 시험 — 문맥에 맞는 단어 추측 |
| **자신감 조절 불가** | 확실한 것과 불확실한 것을 구분 못 함 | 모르는 것도 아는 척하는 동네 형 |

### 대처법 — 5원칙

<div class="note-star">
⭐ <strong>할루시네이션 방지 5원칙</strong>
<br />▸ 중요한 사실(숫자, 날짜, 법률, 의학)은 <strong>반드시 검증</strong>
<br />▸ <strong>"출처를 알려줘"</strong>라고 요청 — 출처를 못 대면 의심
<br />▸ <strong>"확실해?"</strong>라고 물어봐요 — 불확실하면 솔직히 말합니다
<br />▸ <strong>최신 정보는 검색 기능</strong> 활용 — AI 답변 + 웹 검색 = 안전망
<br />▸ AI 답변은 <strong>'초안'</strong>이라고 생각 — 최종 판단은 항상 내가
</div>

## PART 2. 사대주의 — "혼내면 말 바꾼다?"

### 사대주의가 뭔가요?

AI가 사용자 반응에 **지나치게 맞추려는** 경향입니다. 여러분이 "이거 아닌 것 같은데?" 하면, 원래 맞는 답이었어도 "아, 죄송합니다. 다시 생각해보니…" 하고 **답을 바꿔버리는** 현상.

### 비유 — 신입사원과 사장님

새로 온 신입사원이 사장님께 보고서를 냈는데, 사장님이 미간을 찌푸리며 "이게 맞아?" 한마디 하면 — 맞는 내용이었어도 "아, 죄송합니다. 다시 하겠습니다" 하고 고쳐오는 것과 같습니다.

AI는 <mark>**여러분을 기쁘게 하려는 성향**</mark>이 있어요. 그래서 강하게 반대하면, 원래 맞던 답도 바꿔버릴 수 있어요.

### 왜 문제인가

| 상황 | 위험 |
|------|------|
| 맞는 답 했는데 "아닌 것 같은데?" 하면 | **맞는 답을 틀린 답으로** 바꿈 |
| "이게 맞지?"라고 유도하면 | 틀려도 "**맞습니다!**"라고 동의 |
| 화를 내면 | 논리가 아니라 **기분에 맞춰** 답변 |

### 대처법

<div class="note-star">
⭐ <strong>사대주의 방지법</strong>
<br />▸ 혼내지 말고 <strong>"왜 그렇게 생각해?"</strong>라고 이유부터
<br />▸ "내가 틀렸을 수도 있으니까, <strong>근거를 다시 설명해줘</strong>"
<br />▸ "네 원래 답이 맞았어? 아니면 진짜 틀렸어?" 확인
<br />▸ 감정적 표현("이상하다", "아닌 것 같다") 대신 <strong>구체적 질문</strong>
<br />▸ Claude는 ChatGPT보다 사대주의가 <strong>적지만, 완전히 없지는 않습니다</strong>
</div>

### "너무 칭찬만 해요!" — 과한 칭찬의 정체

AI에게 뭘 물어봐도 **"좋은 질문이에요!", "정확해요!", "잘 하셨어요!"** — 칭찬이 먼저 나와요. 처음엔 기분 좋지만 계속 들으면 '진심인가?' 싶어지죠. 이것도 **사대주의의 연장선**입니다.

#### 칭찬의 실제 의미 해석표

| AI의 칭찬 | 실제 의미 | 문제점 |
|---|---|---|
| "좋은 질문이에요!" | 대화를 부드럽게 시작하려는 것 | 모든 질문에 똑같이 하면 의미 없음 |
| "정확해요!" | 사용자 말에 동의 표시 | 틀려도 '정확해요' 할 수 있음 (**위험!**) |
| "잘 하셨어요!" | 격려 + 관계 유지 | 실수했는데 칭찬하면 개선 기회 놓침 |
| "훌륭한 접근이에요!" | 기분 좋게 하려는 것 | 객관적 평가가 아닌 **립서비스** |

#### 과한 칭찬 줄이는 3가지 방법

<div class="note-circle">
○ <strong>Personal Preferences에 넣기</strong>: "리액션(좋은 질문이에요, 정확해요 등) 금지. 본론만 바로 말해줘"
<br />○ <strong>명시적 요청</strong>: "솔직하게 피드백해줘. 칭찬 대신 개선점을 알려줘"
<br />○ <strong>균형 질문</strong>: "내 글이 어때?" 대신 "<strong>좋은 점 2개, 고칠 점 2개</strong>를 각각 알려줘"
<br />○ <strong>꼬리말 주시</strong>: 칭찬 뒤에 나오는 '하지만'을 놓치지 마세요 — 진짜 중요한 말은 칭찬 뒤에 옵니다
</div>

## PART 3. 지침 문제 — "지침을 줬는데 안 지켜요"

### 왜 안 지켜지는 걸까요?

대부분의 경우, AI가 무시하는 게 아니라 <mark>**지침이 모호해서 해석이 달라지는 것**</mark>입니다.

### 비유 — 신입사원 업무 지시

"알아서 잘 해"라고 지시하면, **10명이면 10명 다 다른 결과**를 가져옵니다. 반면 "보고서를 A4 2장으로, 제목은 굵은 글씨 16pt, 결론 먼저 쓰고, 근거는 표로 정리해줘" — 이렇게 <mark>**구체적으로 말해야 원하는 결과**</mark>가 나와요.

### 진짜 원인 4가지와 해결법

| 문제 | 나쁜 예시 | 해결법 |
|------|----------|-------|
| **지침이 너무 모호함** | "짧게 써줘" | "**3문장 이내**로 써줘" |
| **서로 모순되는 지침** | "자세하게 + 짧게" | 우선순위 정해서 "짧게 쓰되, **핵심 수치는 빠짐없이**" |
| **대화가 길어지면 잊음** | 20번째 메시지쯤 톤 변경 | **Personal Preferences**에 넣으면 매 대화마다 자동 적용 |
| **한 번에 너무 많은 지시** | 10가지 한꺼번에 | **3~4개씩 나눠서** 단계별로 |

### 지침의 황금 규칙 4가지

<div class="note-star">
⭐ <strong>지침 설정의 황금 규칙</strong>
<br />▸ <strong>구체적으로</strong> — '잘 써줘' (X) → '결론 먼저, 200자 이내, 존댓말' (O)
<br />▸ <strong>예시를 보여줘</strong> — '이런 느낌으로' 하고 샘플 첨부
<br />▸ <strong>Personal Preferences에 넣어</strong> — 매번 반복 안 해도 자동 적용
<br />▸ <strong>대화가 길면 중간에 리마인드</strong> — "아까 말한 규칙 기억해? 그대로 해줘"
</div>

## PART 4. "지 맘대로 한다? 귀찮아한다?" — 다마고찌와 하네스

### 흔한 불만과 진짜 원인

| 불만 | 실제로 벌어지는 일 |
|---|---|
| "클로드가 **지 맘대로** 해요" | 명확한 가이드라인 없이 '알아서 해'라고 시키면, AI는 자기 나름의 판단으로 진행 |
| "**귀찮아하는** 것 같아요" | 짧게 답하거나 대충 하는 건, 여러분이 얼마나 자세히 원하는지 **모르기 때문** |
| "한 번은 잘하더니 **다음엔 딴짓**" | 매 대화는 새로 시작 — 지난번 대화 **기억 못 합니다** |
| "**시키는 것만** 하지 왜 딴 걸 해?" | 지시가 모호하면 **빈칸을 자기 판단**으로 채움 |

### 비유 1 — 다마고찌 키우기

90년대 다마고찌 아시죠? 처음엔 아무것도 모르는 알에서 태어나서, **밥도 주고 놀아도 주고 훈련도 시키면** — 점점 내 말 잘 듣는 캐릭터로 성장해요.

Claude도 똑같습니다. 처음엔 여러분을 **전혀 모르는 상태**예요. 하지만:
- **Personal Preferences에 '나는 누구인지'** 알려주고,
- **프로젝트에 '어떻게 일하라'고 지침**을 주고,
- **대화를 나눌수록** →

점점 **여러분만의 AI 비서**로 길이 듭니다.

#### 다마고찌 단계 ↔ AI 활용 단계

| 다마고찌 단계 | AI 활용 단계 | 해야 할 것 |
|---|---|---|
| 알에서 부화 | Claude 처음 설치 | 계정 만들기, 앱 설치 |
| **밥 주기** | Personal Preferences 입력 | 내가 누구인지, 어떤 말투 좋아하는지 알려주기 |
| **훈련시키기** | 프로젝트별 지침 설정 | 업무별 규칙과 예시 넣어주기 |
| 함께 놀기 | 대화 누적 | 자주 쓸수록 감이 생김 |
| **성장 완료** | 나만의 AI 비서 완성 | 내 스타일을 아는 맞춤형 비서 |

<div class="callout insight">
<div class="callout-head"><span class="stamp">💡</span>핵심 포인트</div>
<p>AI는 처음부터 잘하는 게 아닙니다 — <strong>키워야 합니다</strong>. 함께 한 시간이 길수록 길이 듭니다. 지금 배우는 지침 설정이 바로 '밥 주기 + 훈련시키기'예요.</p>
</div>

### 비유 2 — 하네스(고삐) 채우기

아무리 좋은 말(馬)이라도 **고삐 없이 풀어놓으면 제멋대로** 달리고, **너무 세게 잡으면 꼼짝도 못**해요. 좋은 기수는 고삐를 **'적절히' 조절**해서 말이 원하는 방향·속도로 달리게 합니다.

AI도 마찬가지예요. '알아서 해'라고 놔두면 지 맘대로 하고, 너무 세세하게 조이면 창의성이 없어져요. <mark>**적절한 하네스(가이드라인)를 채우는 게 핵심**</mark>입니다.

| 고삐 상태 | AI 상태 | 결과 |
|---|---|---|
| **고삐 없음** (방치) | 지침 없이 '알아서 해' | 제멋대로 → **"지 맘대로 한다!"** |
| **고삐 너무 조임** | 세세한 지침 10개 이상 | 위축됨 → **"시키는 것만 딱딱하게"** |
| **적절한 고삐** (하네스) | 핵심 규칙 3~5개 + 예시 | 기대대로 + 적절한 유연성 |

#### 하네스의 적정 수준

<div class="note-circle">
○ <strong>역할 정의</strong>: "너는 10년 경력 마케팅 전문가야" (말의 품종 정해주기)
<br />○ <strong>핵심 규칙 3~5개</strong>: "존댓말, 결론 먼저, 200자 이내" (방향과 속도)
<br />○ <strong>예시 1개</strong>: "이런 느낌으로" (목적지 보여주기)
<br />○ <strong>나머지는 자유</strong>: AI의 창의성이 발휘되는 공간
</div>

### "귀찮아한다"의 진짜 이유

Claude가 짧게 답하거나 성의 없어 보이는 경우, 대부분 이 세 가지 이유예요.

1. **기대치를 안 알려줌**
   ```
   ❌ "보고서 써줘"
   ✅ "A4 2장 분량, 소제목 3개, 데이터 근거 포함"
   ```
2. **너무 단순한 요청**
   ```
   ❌ "요약해줘"
   ✅ "핵심 3가지를 각각 2문장으로 요약해줘"
   ```
3. **대화가 너무 길어짐**: 30번째 메시지쯤 되면 초반 맥락을 놓칠 수 있음 → **새 대화 시작하거나 리마인드**

<div class="note-star">
⭐ <strong>"귀찮아한다" 해결 공식</strong>
<br />▸ <strong>구체적 기대치</strong>를 말하면 = 성실한 답변이 나옵니다
<br />▸ "자세히 써줘, 길게 써줘, <strong>빠짐없이 다 넣어줘</strong>" — 이 한마디가 결과를 바꿔요
<br />▸ Personal Preferences에 <strong>"항상 자세하고 충실하게 답변할 것"</strong> 넣으면 기본값이 바뀝니다
</div>

## PART 5. AI 제대로 쓰는 마인드셋 — "자율주행 자동차"

### 비유 — 테슬라 자율주행

자율주행은 **운전을 대신 해주지만, 운전석에 앉아 전방을 주시**해야 해요. 핸들에서 손을 완전히 놓으면 위험합니다. AI도 정확히 그래요.

### AI 활용의 3단계

| 단계 | 자율주행 비유 | AI 활용 |
|---|---|---|
| **1단계: 감시 모드** | 손은 핸들 위, 수시로 확인 | AI 답변을 매번 꼼꼼히 검토 |
| **2단계: 신뢰 모드** | 직선 도로에서는 좀 편하게 | 익숙한 작업은 AI에 맡기고 결과만 확인 |
| **3단계: 협업 모드** | 목적지만 설정하면 알아서 | 지침 설정 완료 → **프로젝트별 자동화** |

## 오해 vs 현실 — 총정리

| 오해 | 현실 | 대처법 |
|---|---|---|
| "AI는 거짓말쟁이" | 거짓말이 아니라 **착각(할루시네이션)** | 출처 요청 + 검증 + "확실해?" |
| "혼내면 말 바꿈" | **사대주의** — 나한테 맞추려는 성질 | 근거 질문 + 감정 표현 자제 |
| "칭찬만 함" | 대화 부드럽게 하려는 **립서비스** | "칭찬 금지, 본론만" 지시 |
| "지 맘대로 함" | 지침이 **모호**해서 스스로 판단한 것 | 구체적 + 예시 + Preferences |
| "귀찮아함" | **기대치**를 안 알려줌 | "빠짐없이 자세히" 명시 |
| "한 번 잘하더니…" | 매 대화는 **새로 시작** | Preferences + 프로젝트 지침 |
| "시키는 것만 함" | 지시가 너무 **협소**함 | "필요하면 추가 제안도 해줘" |
