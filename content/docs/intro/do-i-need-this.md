## 나한테 맞는 Claude 도구는?

Claude에는 여러 도구가 있어요. 전부 다 쓸 필요는 없습니다. 나에게 맞는 걸 하나만 골라서 시작하면 돼요.

---

## 상황별 추천

### 📝 "문서 작업이 많아요" — 보고서, 기획서, 번역

**추천: Claude 웹앱** (claude.ai)

- 브라우저만 열면 바로 시작
- 문서 작성, 요약, 번역, 교정
- 아티팩트 기능으로 결과물을 바로 확인

**예시:** "이 회의록을 보고서 형식으로 정리해줘" → 깔끔한 보고서 완성

---

### 💼 "엑셀, PPT, 파일 정리를 자동으로 하고 싶어요"

**추천: 코워크** (Cowork)

- Claude가 내 컴퓨터의 파일을 직접 열어서 작업
- 엑셀 정리, PPT 제작, 파일 분류까지
- 출근길에 폰으로 일 시키고, 도착하면 완성

**예시:** "Desktop에 있는 매출 데이터로 월별 비교표 만들어줘" → 엑셀 파일 자동 생성

---

### 🌐 "웹사이트나 앱을 직접 만들고 싶어요"

**추천: Claude Code** (이 가이드의 메인!)

- 홈페이지, 랜딩페이지, 간단한 앱 제작
- 코딩을 몰라도 한국어로 말하면 됨
- 만든 걸 인터넷에 바로 배포 가능

**예시:** "우리 가게 소개 홈페이지 만들어줘" → URL을 받아서 바로 공유

---

### 📱 "설치가 귀찮은데 코딩을 해보고 싶어요"

**추천: Claude Code 웹** (claude.ai/code)

- 브라우저에서 바로 코딩
- 내 컴퓨터에 아무것도 설치 안 해도 됨
- 컴퓨터를 꺼도 AI가 계속 코딩

**예시:** "GitHub에 있는 내 프로젝트 버그 고쳐줘" → 자동으로 수정 완료

---

## 하나만 골라야 하나요?

아니요! 여러 개를 같이 쓸 수 있어요. 많은 분들이 이렇게 쓰고 있습니다:

| 상황 | 쓰는 도구 |
|------|----------|
| 간단한 질문/글 작성 | 웹앱 |
| 파일 작업/사무 자동화 | 코워크 |
| 웹사이트/앱 개발 | Claude Code |

<mark>처음이라면 **웹앱**부터 시작하세요. 익숙해지면 코워크나 Claude Code로 확장하면 됩니다.</mark>

---

## 요금제는 어떻게 되나요?

| 요금제 | 가격 | 쓸 수 있는 도구 |
|--------|------|---------------|
| **무료** | $0 | 웹앱 채팅 (제한적) |
| **Pro** | $20/월 (~27,000원) | 웹앱 + 코워크 + Claude Code + Code 웹 |
| **Max 5x** | $100/월 (~135,000원) | Pro의 5배 사용량 |
| **Max 20x** | $200/월 (~270,000원) | Pro의 20배 사용량 |

<div class="note-circle">
○ 대부분의 분들은 Pro($20/월)로 충분합니다. 하루에 커피 한 잔 값이에요.
</div>

## Claude Code로 할 수 있는 것들

이 가이드를 끝까지 따라오면 이런 것들을 만들 수 있어요:

- 🌐 내 사업 소개 웹사이트
- 📊 데이터 분석 대시보드
- 🤖 업무 자동화 도구
- 📱 간단한 웹 앱 (예약 폼, 계산기, 퀴즈)
- 📝 문서 자동 생성 시스템
- 🎨 포트폴리오 사이트
