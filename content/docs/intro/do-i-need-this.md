## 나한테 맞는 Claude 도구는?

Claude에는 여러 도구가 있어요. 전부 다 쓸 필요는 없습니다. 나에게 맞는 걸 하나만 골라서 시작하면 돼요.

---

## 상황별 추천

### 📝 "문서 작업이 많아요" — 보고서, 기획서, 번역

**추천: Claude 웹앱** (claude.ai)

- 브라우저만 열면 바로 시작
- 문서 작성, 요약, 번역, 교정
- 아티팩트 기능으로 결과물을 바로 확인

**예시:** "이 회의록을 보고서 형식으로 정리해줘" → 깔끔한 보고서 완성

---

### 💼 "엑셀, PPT, 파일 정리를 자동으로 하고 싶어요"

**추천: 코워크** (Cowork)

- Claude가 내 컴퓨터의 파일을 직접 열어서 작업
- 엑셀 정리, PPT 제작, 파일 분류까지
- 출근길에 폰으로 일 시키고, 도착하면 완성

**예시:** "Desktop에 있는 매출 데이터로 월별 비교표 만들어줘" → 엑셀 파일 자동 생성

---

### 🌐 "웹사이트나 앱을 직접 만들고 싶어요"

**추천: Claude Code** (이 가이드의 메인!)

- 홈페이지, 랜딩페이지, 간단한 앱 제작
- 코딩을 몰라도 한국어로 말하면 됨
- 만든 걸 인터넷에 바로 배포 가능

**예시:** "우리 가게 소개 홈페이지 만들어줘" → URL을 받아서 바로 공유

---

### 📱 "설치가 귀찮은데 코딩을 해보고 싶어요"

**추천: Claude Code 웹** (claude.ai/code)

- 브라우저에서 바로 코딩
- 내 컴퓨터에 아무것도 설치 안 해도 됨
- 컴퓨터를 꺼도 AI가 계속 코딩

**예시:** "GitHub에 있는 내 프로젝트 버그 고쳐줘" → 자동으로 수정 완료

---

## 하나만 골라야 하나요?

아니요! 여러 개를 같이 쓸 수 있어요. 많은 분들이 이렇게 쓰고 있습니다:

| 상황 | 쓰는 도구 |
|------|----------|
| 간단한 질문/글 작성 | 웹앱 |
| 파일 작업/사무 자동화 | 코워크 |
| 웹사이트/앱 개발 | Claude Code |

<mark>처음이라면 **웹앱**부터 시작하세요. 익숙해지면 코워크나 Claude Code로 확장하면 됩니다.</mark>

| **무료** | $0 | 웹앱 채팅 (제한적) |

## Claude Code로 할 수 있는 것들

이 가이드를 끝까지 따라오면 이런 것들을 만들 수 있어요:

- 🌐 내 사업 소개 웹사이트
- 📊 데이터 분석 대시보드
- 🤖 업무 자동화 도구
- 📱 간단한 웹 앱 (예약 폼, 계산기, 퀴즈)
- 📝 문서 자동 생성 시스템
- 🎨 포트폴리오 사이트

## 🤔 다른 AI 코딩 도구와 뭐가 달라요? (Cursor, Copilot)

요즘 AI 코딩 도구가 여러 개 있어요. Claude Code 말고도 **Cursor**, **GitHub Copilot**, **Windsurf** 등이 유명하죠. 뭐가 다른지 궁금하실 거예요.

### 30일 실전 비교 결과 <code>[R]</code>

커뮤니티에서 세 도구를 **30일 동안 같은 작업에 써본** 개발자들의 정리입니다.

| 도구 | 강점 | 약점 | 정확도 (SWE-bench) |
|---|---|---|---|
| **Claude Code** | 🏆 **정확도 압도적**, 대규모 리팩토링, 보안 감사, 협업 | 5~10분 살짝 느림 | **80.8%** |
| **Cursor** | ⚡ 속도, 코드베이스 탐색 빠름 | 복잡한 작업에서 정확도 보통 | ~65% (추정) |
| **GitHub Copilot** | 📝 자동완성, 보일러플레이트 | 대규모 작업 약함 | - |

### 커뮤니티 합의 한 줄 <code>[R]</code>

> *"Copilot is a better typist, Cursor is a better explorer, Claude Code is a better collaborator."*
>
> → Copilot은 타이피스트, Cursor는 탐색가, **Claude Code는 협업자**

### 🍱 비유로 설명하면

- **Copilot** = 받아쓰기 잘하는 비서 (내가 말한 대로 빠르게 타이핑)
- **Cursor** = 동네 지리 잘 아는 택시기사 (코드베이스 안을 빠르게 누비기)
- **Claude Code** = 같이 일하는 동료 개발자 (생각하고 판단하고 제안)

### 👍 추천 조합

**하나만 쓰지 마세요!** 커뮤니티 공통 조언은 **용도별 조합**입니다:

| 상황 | 추천 도구 |
|---|---|
| 일상 코딩, 자동완성 | **Cursor** 또는 **Copilot** |
| 대규모 리팩토링, 보안 감사 | **Claude Code** |
| 복잡한 설계, 플래닝 | **Claude Code** (+ `/ultraplan`) |
| 긴 로그 파일·대용량 분석 | **Claude Code** (1M 컨텍스트) |
| 단순 함수 만들기 | 아무거나 |
